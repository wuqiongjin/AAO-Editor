## 落点

1. **新增 `src/pages/projects/chartImport.ts`**：core 唯一序列入口 `importChart(source, deps, input)`。
   - 拥有：trail start/end（`meta.kind`）、`ids / now / staged`、每段前 abort 检查与 stage 发射、`createOfficialProject` Apply、`store.save`、`get → probe → 容差内不写 → 超差二次 save`、`notifyCatalogChanged`、统一 `ImportResult`。
   - `ChartImportSource<Input>`：`kind` + 可选 `validate(input)` + `audio` / `cover` / `chart` / `projectMeta`；`validate` 在 ids/now/staged 之后、abort/stage audio 之前调用，保持社区 misuse 的抛错时机。
   - `deps` 不含 `transport`；源工厂闭包 transport。
   - `withChart=false` 时不调 `chart()`，传给 `projectMeta` 的 chart 为 `null`；chart 文本由 core 填进工程。
   - abort 检查点逐条保留：audio 前、cover 前、chart 前、save 前；chart 与 Apply 之间不新增检查。
2. **`officialImport.ts` / `communityImport.ts`**：保留 `*ImportInput`、`*ErrorText` / `*ApplyErrorText`、各自常量；新增 `createOfficialImportSource(transport)` / `createCommunityImportSource(transport)`；删除旧编排入口、store/deps/result/stage 类型与 `throwIfImportAborted` 依赖。
3. **`ProjectsPage.tsx`**：仍保留两个 handler，只把调用改成 `importChart(source, deps, input)`；source 用 `useMemo` 从 `communityTransport` 构造；`isImportCancelled` 从 core 取。
4. **`ProjectDialogs.tsx`**：只把 `OfficialImportStage` / `CommunityImportStage` 两处 type import 换成 core 的 `ImportStage`；submit 分支与文案不动。
5. **测试**：既有 `OfficialImport.test.ts` / `CommunityImport.test.ts` 只改 import/call 形状，断言语义逐条不动；新增 `tests/unit/project/ChartImport.test.ts`（fake source）锁 core 序列。
6. **静态锁**：新增 `tests/static/ChartImportSingleSequence.test.ts`，只锁接线事实（`importChart` / trail / probe / Apply 只在 core；两个源模块不出现 save/probe/Apply；ProjectsPage 改走新入口）。
