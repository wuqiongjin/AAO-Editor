# 159 · 倒流区撞 y 的 BPM 数值纵向错开

Type: grilling（重开 issue 105「压字不做避让」；落地 = feature）
Status: resolved（2026-09-25 错开 + 定案 2 折叠摘要已落地）
Blocked by: —

## 来源

用户 2026-09-25：倒流区不同层叠在同一时间轴 y 时，BPM 数字互相覆盖（beat 5 盖住 beat 3），无法看出有几条 BPM。样例：

```
[
{"beat":0,"type":"BPM","bpm":120},
{"beat":3,"type":"BPM","bpm":-178},
{"beat":4,"type":"BPM","bpm":178},
{"beat":5,"type":"BPM","bpm":178}
]
```

## 症状

`positionOfBeat(3)` 与 `positionOfBeat(5)` 在该 BPM 序列下时间轴秒数相同 → 沟槽 **BPM 数值** 画在同一 y，后画者盖住先画者。轨道内 **BPM 横线** 同位是倒流保真（issue 104/105），不是算错 beat。

## 根因

issue 105 已知边界：「折返带内多层 BPM 数值可能落在同一 y 上互相压字。本票不做避让/错位」。`renderBpmLabels` 逐条 `layoutGutterLabel(..., 'centered')`，无聚类。

## 定案（用户 2026-09-25）

grill：Q2=B / Q7=A。

1. **只处理沟槽 BPM 数值**。横线、网格、滑条折返仍允许同位。
2. **文字盒在画布 y 上相交**的收成一组；组内沿沟槽 **纵向错开**（间距按字号），组中心仍对准该时间轴 y。
3. 组内顺序 = **beat 升序**（作者轴）。上例 −178（beat 3）与 178（beat 5）分成两颗可读的字。
4. **就地编辑 / 命中盒跟字走**（`bpmLabelBox` / `hitBpmLabel` 用错开后的 y）。点哪颗编哪条。
5. 算法对 **任何** 撞 y 生效（不限倒流；同拍多条 BPM 同样错开）。正/负换色、末条负警示（issue 142）不变。

## 定案 2（用户 2026-09-25 · 折叠摘要）

grill：Q1=C / Q3=A / Q4=B / Q5=`184 [2], -184 [1]` / Q6=B / Q7=A / Q8=A / Q9=A / Q10=A / Q11=A。

错开解决压字后，同位多层仍占多行。折叠是 **显示态**，不改 BPM 条数、不改横线。

1. **谁折**：仅 **线 y 相同** 的 BPM 同位组（时间轴同位、beat 可不同）。字盒相交但线 y 不等 → 只保持 159 错开，不折摘要。
2. **相同值**：带符号全等（`184 !== -184`）。摘要里每个带符号值单独计数。
3. **文案**：带符号值按组内 **最小 beat 升序**，中间用英文 **`, `**（逗号+空格）。同一值出现 ≥2 次才写 `[n]`；次数为 1 只写数值（例：`-178, 178`；`184 [2], -184`）。不用 `×`、`/`、`x2`、`[1]`。各段着色 = 该带符号值平时的色（正值主题色 / 负值倒流色；若该值含末条负警示则该段警示色）。
4. **手风琴**：同时最多展开一组。点摘要 → 展开为本组 159 错开真数字（**不**进就地编辑）。再点某颗真数字 → 就地编辑。点另一组摘要 → 先折当前再展开那一组。
5. **不折回的点击**：展开后各数字盒的纵向包络（含盒间缝），横向仍是数字带，不吃整条横线。点缝 ≠ 折叠。
6. **Esc**：取消本次就地编辑，**留在展开态**（不是折回摘要）。**Enter** 提交后也留在展开态。失焦 = 提交；若点在组外则再折摘要，点在组内缝则留下展开。
7. **滚动折回**：以共用 **线 y** 计。落到画布 `[-2×字号, 高+2×字号]` 之外才折；播放滚与手滚同一条。不要刚出边就折。
8. **贴边**：展开叠 **整组平移** 进画布（间距与 beat 序不变），禁止逐颗 clamp 压回同一 y。

实现时修订 **ADR-0008 §5**：点摘要 ≠ 单击即编辑；仅展开后的真数字走原就地编辑。不改 ADR-0010。

### 定案 2 锁测

- 同位组（票面样例 beat 3/−178 与 beat 5/178 → `-178, 178`；截图类 `184 [2], -184`）折叠文案；线 y 不等的近距组不出现 `[n]` 摘要。
- 点摘要 → 展开、不进入输入框；再点上盒/下盒 → 对应 beat。点组内缝不折。点组外折回。

- 线 y 在缓冲内保持展开；超出 2×字号缓冲才折。
- 贴底展开：整叠仍在画布内且盒不相交。
