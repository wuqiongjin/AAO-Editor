### #2 · 内容页侧栏索引选中态英文换行

**症状**：`AppPageShell` 侧栏项选中后标签换行（英文更明显）；选中加粗可接受，布局跳动不可接受。

**根因**：`.app-page-shell__sidebar-item` 默认 `font-weight: 600`，`.is-active` 为 `650`（`AppPageShell.css`）；侧栏宽 `clamp(140px, 12.5%, 200px)`，标签区扣除 icon+padding 后约 ≤90px，「Note tools」「Edit tools」等两词英文在加粗后常超宽换行。选中态 icon `scale(1.08)` 对水平空间影响次要。

**修法（待实现择一或组合）**：侧栏标签 `white-space: nowrap` + 必要时 `text-overflow: ellipsis`；或选中态不改字重、仅用颜色/边框/背景区分；或用 `font-synthesis`/固定行高减少跳动。影响面：设置 / 音频 / 素材 / 快捷键四页共用 `SidebarItem`。

**锁测**：单测难锁 DOM 换行 → Playwright 或手工：英文 UI、最窄侧栏（约 140px）、逐项点选侧栏无增高换行。

**Status**: resolved（选中态与默认同 `font-weight: 600`；标签允许换行；去掉 ellipsis。英文 pill 同步 `In use`）

### #4 · 工作台右栏去掉多选音符详情列表

**症状**：框选大量音符时，右栏为每个音符渲染类型/轨道/节拍卡片，冗余且拖慢 React。

**根因**：`NoteInfoPanel.tsx` L57–106：`selectedNoteObjects.map` 全量 DOM；`selectionNoteIndices` + `notes[index]` 每次选区变化重算。ADR-0003 §11.1 只要求正文「已选中 n 个音符」+ 操作，未要求 per-note 列表。

**修法**：删除详情滚动区（含多选卡片与「未选中音符」空态块）；保留标题、选中计数、`删除`/`镜像`。无选区时计数文案即可表达空态。顺带删不再使用的 `noteInfo.single/slide/bpm/...` 键仅当全库无引用（grep 后决定）。

**锁测**：无现成 NoteInfoPanel 单测 → 手工：0 选 / 1 选 / 大框选右栏无列表、操作按钮仍可用；可选静态断言 `NoteInfoPanel` 不含 `selectedNoteObjects.map`。

**Status**: resolved
