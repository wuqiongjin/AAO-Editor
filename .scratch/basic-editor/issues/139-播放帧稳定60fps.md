# 139 · 播放帧稳定 60fps（静态层滚动 + RAF 不进 React）

Type: chore
Status: resolved
Blocked by: —

## 来源

用户 2026-09-21：138 验收通过后正常播放仍 **50–57** 波动；对比 Bestdori 能稳 60。拍板：**验收目标 = 稳定 60**，不开 120。

## 症状

默认缩放播放（含 `150030`）帧数贴着 vsync 掉帧。60 来自显示器同步，不是代码封顶；单帧经常 >16.7ms。

## 根因

1. `staticLayerCache` 失效键含 `scrollY` → 播放每帧 miss → 按 dpr 2.5 整张重画网格/背景（issue 36「滚动帧重建」在持续滚动下等于每帧全量）。
2. 播放 RAF 每帧 `setCurrentSeconds` + `setScrollY`→`setViewport` → React commit 后再 `renderCanvas`。

## 修法

**定案（用户 2026-09-21）**：稳 60，不追高刷新。**2026-09-21 对齐**：不代码封顶 60、不关 vsync；高刷新屏允许 RAF 自然跟到 120，验收仍只要求 60Hz 稳 60（掉到 120 不算失败）。

1. **静态层**：拆两层——屏幕空间（黑底/背景/轨道底/竖线）与 `scrollY` 无关；横网格+起止线走 **pos 条带** blit，播放中禁止每帧 `renderGrid`。倒流区多段拍区间仍要画对（issue 104/105 口径不回退）。不要整张静态位图跟着滚（背景会错）。
2. **播放 RAF**：画布 `scrollY` 走 ref / imperative 绘制；HUD（PlayBar 时间码+进度条、画布左下时间/右下已过音符）**降频**写 React（约 10–15Hz）。不改键音 `tick`、不关 vsync。暂停/seek 仍立刻写 React。
3. 1+2 后仍不稳 60 再议播放档 dpr（本票默认不做）。

## 锁测

1. `staticLayerCache`：仅 `scrollY` 变时第二次 `drawStaticLayer` **不得**再跑 `renderGrid`（修前会跑）。倒流 fixture 网格仍覆盖折返带（对照 issue 104 可见拍区间）。
2. 静态源码 / 协调器单测：RAF 循环不每帧 `setCurrentSeconds`；`setScrollY` 不经 `setViewport` 触发整树 commit（或等价：播放帧不 `setState` 视口）。
3. 单测锁不住真 60fps → 页面验收：默认缩放播 `150030`（含 ~5s 折返）帧数贴 60、不再 50–57 晃；观感对齐 Bestdori「稳」而不是「更高上限」。

## Answer

屏幕层与 pos 条带分离：仅 `scrollY` 变时 blit 横网格，不重跑 `renderGrid`。播放 RAF 经 `scrollYRef` 立即绘制；HUD 80ms 写一次 React，停播/seek 立刻刷秒数。基线 150030 折返窗静态重建 60/60 → 1/60。真 60fps 仍待页面播这段验收。
