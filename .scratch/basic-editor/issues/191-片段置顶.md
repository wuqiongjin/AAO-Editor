# 191 · 片段置顶

Type: feature
Status: open
Blocked by:

**来源**：2026-10-31 用户确认 Pin（置顶）要做。184–187 已 resolved，本票在片段库上新增本地置顶能力。

## 定案

- 置顶是**本地偏好**，不是片段内容：不随分享文件导出，导入时忽略。
- 卡片 ⋯ 菜单提供「置顶片段 / 取消置顶」；名字旁显示一个**非按钮**的小 pin 图标表示状态。
- 不往卡片右上角再加常驻按钮（185 已定：卡片动作统一收在 ⋯ 菜单）。
- 排序：置顶组始终在最前；组内按 `pinnedAt` 倒序（最近置顶的更靠上），其余按 `createdAt` 倒序，同值按 id 全序。后续排序票（192）在此基础上扩展，置顶组优先规则不变。

## 数据

- `Pattern` 增可选字段 `pinnedAt?: number`（毫秒时间戳）；缺省 / 无 = 未置顶。置顶时写当前时间，取消时删除字段。
- 库文件（Electron `patterns.json` / IndexedDB 单 record）照常持久化该字段。
- 分享：
  - `serializePatterns` 导出时**剥掉** `pinnedAt`；
  - `parsePatternsFile` 解析导入时忽略 / 剥掉外来 `pinnedAt`；
  - 信封 `schemaVersion` 不变。
- `record.ts` 读取与校验：`pinnedAt` 存在但非有限数字 → 按未置顶处理并剥掉，**不因本地偏好字段拒收整条片段**。
- ADR-0023 §1 / §3 补一行：`pinnedAt` 是本地视图偏好，不进入分享信封。

## 写入口

- 复用 `usePatternLibrary` 的 `commit`（内存先改 → 整库落盘；失败回滚并 toast），新增 `setPinned(id, pinned): Promise<boolean>`。
- 置顶 / 取消置顶是低频动作，整库落盘可接受；不要为此引入第二个存储。
- 失败时保持原状态，不留下「界面置顶了、磁盘没有」。

## UI

- `PatternCardMenu` 加一项：置顶时显示「取消置顶」，否则「置顶片段」；菜单项 `Pin` / `PinOff` 图标。
- 卡片名字前或名字旁加小 `Pin` 图标（仅状态，不可点）；tooltip 可给「已置顶」。
- i18n zh-CN + en：置顶 / 取消置顶 / 已置顶。
- 与 189 的关系：导入覆盖同内容片段时保留本地 `pinnedAt`；「保留两者」的新条目不带置顶。

## 锁测

- `tests/unit/chart/patterns/PatternLibrary.test.ts`（改 / 新增）：置顶组优先；多个置顶按 `pinnedAt` 倒序；未置顶按 `createdAt` 倒序；取消置顶回原位；同值按 id 全序；`setPinned` 不存在 id / 未载入 / 落盘失败。
- `tests/unit/chart/patterns/PatternShare.test.ts`（改）：导出信封不含 `pinnedAt`；导入文件若带 `pinnedAt` 不落到库；round-trip 其余字段不变。
- `tests/unit/chart/patterns/PatternStore.test.ts` / `record` 相关（改）：库文件里的 `pinnedAt` 正常读回；非法 `pinnedAt` 按未置顶且不丢整条。
- `tests/dom/workspace/PatternLibraryDrawer.test.tsx`（改）：⋯ 菜单置顶 / 取消；名字旁 pin 图标；置顶后排到最上；搜索过滤后仍置顶优先；只读态下置顶仍可用（不写谱面）。
- 静态锁：分享序列化路径确实剥掉 `pinnedAt`（防止置顶随文件外泄）。
