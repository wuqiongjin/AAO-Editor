# 246 曲线胶囊滚轮穿透画布与短窗底部裁切

- **Type**: bug
- **Status**: open
- **关联**: [182](./182-曲线工具选项胶囊与展开面板.md) · [242](./242-曲线选项胶囊常驻展开与缓动图形化选型.md) · 同批 [247](./247-档位自由切换配置行1px抖动.md)

---

## 来源

用户复核曲线胶囊面板（问题 3）：面板内滚到底后继续滚，画布跟着滚；顺带发现短窗口下面板最后一行被裁掉、面板自己又不能滚。

## 症状

- 指针在模板网格上、滚到底再下滚：画布宿主 `scrollTop` 400 → 880；滚到顶再上滚：400 → 0。
- 指针在控件行或胶囊顶栏上滚一格：同样 400 → 880（面板上没有「安全区」）。
- 800×600 窗口：面板高 474px，画布区可视高仅 393px，末行「基线」落在可视区外被裁，面板无内部滚动可救。

## 根因

- 胶囊挂在 `.ws-chart-area`（`overflow: auto`，`WorkspacePage.css:74`）内的 sticky 层里（`WorkspacePage.tsx:582-610`），浮在画布上但不是画布。
- 画布滚轮逻辑只监听 `canvas` 元素本身（`FinalVirtualCanvas.tsx:933`），胶囊上的 wheel 到不了；浏览器按默认规则交给最近的滚动祖先 = 画布宿主。
- 唯一内部滚动容器 `.ccp__grid`（`max-height: 228px`，`CurveConfigPanel.css:78-84`）未设 `overscroll-behavior`，边界处链式外溢。

## 修法

1. `.coc` 改 flex 列 + 整体高度上限（按画布区实测高，`ResizeObserver` 写 CSS 变量，退路 `min(60vh, 480px)`）；`.coc__body` 吃剩余高度并 `overflow-y: auto` + `overscroll-behavior: contain`；`.ccp__grid` 同样加 contain。
2. 胶囊根加非被动 `wheel` 监听：指针所在链上没有「还能滚」的容器时 `preventDefault()`，彻底不落到画布。
3. `PatternPastePill` 同外壳同宿主，按同一口径处理（它面板小，暂未踩到）。

## 锁测

jsdom 无布局引擎，`scrollTop`/`getBoundingClientRect` 不可信——沿用 `shots/capture.mjs` 的 headless Edge + CDP 范式实测（脚本本地留存不入库）：

1. 指针位置 × 滚动状态矩阵：网格中部 / 网格到底 / 网格到顶 / 控件行 / 顶栏，各滚 3 格，断言 `host.scrollTop` 恒为初值。
2. 网格内滚动仍生效（`ccp__grid.scrollTop` 走到端点），且到端点后胶囊本体接续滚动。
3. 800×600 下末行控件可滚到可见区（`getBoundingClientRect().bottom <= 画布区 bottom`），1280×720 / 1440×900 下面板不出现无谓滚动条。
