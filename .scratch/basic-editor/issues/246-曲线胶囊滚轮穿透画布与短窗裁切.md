# 246 曲线胶囊滚轮穿透画布与短窗底部裁切

- **Type**: bug
- **Status**: resolved（2026-11-22 已实现并实测）
- **关联**: [182](./182-曲线工具选项胶囊与展开面板.md) · [242](./242-曲线选项胶囊常驻展开与缓动图形化选型.md) · 同批 [247](./247-档位自由切换配置行1px抖动.md)

---

## 来源

用户复核曲线胶囊面板（问题 3）：面板内滚到底后继续滚，画布跟着滚；顺带发现短窗口下面板最后一行被裁掉、面板自己又不能滚。

## 症状

- 指针在模板网格上、滚到底再下滚：画布宿主 `scrollTop` 400 → 880；滚到顶再上滚：400 → 0。
- 指针在控件行或胶囊顶栏上滚一格：同样 400 → 880（面板上没有「安全区」）。
- 800×600 窗口：面板高 474px，画布区可视高仅 393px，末行「基线」落在可视区外被裁，面板无内部滚动可救。

## 根因

- 胶囊挂在 `.ws-chart-area`（`overflow: auto`，`WorkspacePage.css:74`）内的 sticky 层里（`WorkspacePage.tsx:582-610`），浮在画布上但不是画布。
- 画布滚轮逻辑只监听 `canvas` 元素本身（`FinalVirtualCanvas.tsx:933`），胶囊上的 wheel 到不了；浏览器按默认规则交给最近的滚动祖先 = 画布宿主。
- 唯一内部滚动容器 `.ccp__grid`（`max-height: 228px`，`CurveConfigPanel.css:78-84`）未设 `overscroll-behavior`，边界处链式外溢。

## 修法

1. `.coc` 改 flex 列 + 整体高度上限（按画布区实测高，`ResizeObserver` 写 CSS 变量，退路 `min(60vh, 480px)`）；`.coc__body` 吃剩余高度并 `overflow-y: auto` + `overscroll-behavior: contain`；`.ccp__grid` 同样加 contain。
2. 胶囊根加非被动 `wheel` 监听：指针所在链上没有「还能滚」的容器时 `preventDefault()`，彻底不落到画布。
3. `PatternPastePill` 同外壳同宿主，按同一口径处理（它面板小，暂未踩到）。

## 锁测

jsdom 无布局引擎，`scrollTop`/`getBoundingClientRect` 不可信——沿用 `shots/capture.mjs` 的 headless Edge + CDP 范式实测（脚本本地留存不入库）：

1. 指针位置 × 滚动状态矩阵：网格中部 / 网格到底 / 网格到顶 / 控件行 / 顶栏，各滚 3 格，断言 `host.scrollTop` 恒为初值。
2. 网格内滚动仍生效（`ccp__grid.scrollTop` 走到端点），且到端点后胶囊本体接续滚动。
3. 800×600 下末行控件可滚到可见区（`getBoundingClientRect().bottom <= 画布区 bottom`），1280×720 / 1440×900 下面板不出现无谓滚动条。

## Comments

- **2026-11-22 实现**：
  - **高度上限**（`useCapsuleMaxHeight.ts` + `CanvasCapsule.css`）：`.ccap` 加 `max-height: var(--capsule-max-h, min(60vh, 480px))`；hook 用 `offsetParent`（画布区的 sticky 层）实测高写变量，`ResizeObserver` 跟随窗口 / 侧栏变化。上缘偏移取**声明的 `top`** 而非实测 rect —— 入场动画 `ccap-pop` 带 `translateY(-4px)`，首帧量 rect 会少 4px、上限就多给 4px，面板正好贴到画布区底边。
  - **面板自己滚**：`.coc` 改 flex 竖排（顶栏 `flex: 0 0 auto`），`.coc__body` 吃余量（`flex: 1 1 auto` + `min-height: 0` + `overflow-y: auto` + `overscroll-behavior: contain`）；`.ccp__grid` 也加 `contain`。`.ppp` 按同一口径处理（片段粘贴胶囊同外壳同宿主）。
  - **滚轮封口**（`useCapsuleWheelContainment.ts`）：胶囊根挂**非被动** `wheel`，由内向外找第一个「还能往该方向滚」的容器（网格 → 面板）就滚它，一个都没有时只吞默认行为。Shift+滚轮按纵向接（Windows 只给 `deltaX`，与画布同口径取较大者）；`Ctrl+滚轮` 是缩放，不拦。
- **实测（headless Edge + CDP，激活态工作台，尖刺 4 行配置，指针 × 滚动状态各滚 3 格，`host.scrollTop` 初值 400）**：
  - 修前：网格中部下滚 `400 → 520`；网格到底 / 控件行 / 顶栏 / 网格到顶上滚 `400 → 760`（上滚 `400 → 40`）。修后：五个位置**全部 `400 → 400`**；网格中部 `scrollTop 0 → 180`（到底）。
  - 逐级接续（800×560，面板可滚）：网格到底后下滚，网格停在 180、`coc__body 0 → 68`；面板到底后下滚，host / body 都不动。
  - 高度（`host` = 画布区可视高，`max-h` = 写入的上限）：800×600 `506 / 486 / 面板 474`（不出滚动条，底边距画布区 22px）；800×560 `466 / 446 / 446`（面板可滚，末行滚动后 `bottom <= 画布区 bottom`）；800×520 `426 / 406 / 406`；1280×720 `626 / 606 / 474`、1440×900 `806 / 786 / 474`，两档 `coc__body` 均无滚动条。
  - Shift+滚轮（网格页）：`grid 0 → 180`、`host 400 → 400`。折叠态 pill `272×30`，与改前一致。
- **锁测**：`tests/static/CapsuleScrollContainment.test.ts`（上限 / 竖排 / contain / 非被动监听的接线事实）、`tests/dom/workspace/CapsuleWheelContainment.test.tsx`（滚谁 + 是否吞掉默认行为，滚动尺寸显式注入）、`tests/unit/pages/workspace/CapsuleShellHeight.test.ts`（上限取值）。真实几何走 headless 探针（`shots/probe-246.mjs`，临时脚本不入库）。
- **2026-11-22 补修 · 滚轮起点不是 HTML 元素**：`scrollableTargetFor` 原先只认 `HTMLElement` 起点，而模板 / 缓动族卡的缩略图是 `<svg>` —— 指针压在图上时 target 是 SVG 元素，判不过就整条链都走不到，表现为「压在卡片图上滚不动、移到卡片文字上又能滚」。改为先把 target 归到最近的 HTML 祖先（`nearestHtmlAncestor`）再向外找滚动容器。
  - 实测（800×600，尖刺 4 行）：指针压在卡片缩略图上（`elementFromPoint` = `line`）下滚 3 格，`grid 0 → 180`、`host 400 → 400`（修前 `grid 0 → 0`）；压在卡片文字上同一结果。
  - 缓动页（800×520）：面板 `scrollHeight == clientHeight`（本就不用滚），族卡缩略图上滚 3 格 `host 400 → 400`，不穿透。
  - 锁测：`CapsuleWheelContainment.test.tsx` 补「target 为卡片内 `<svg>`」一例（修前红）。
- **与 242 的接续**：242 会把缓动页改成 5×2 免滚动网格，届时面板内会有两处滚动面（网格 + 面板），高度上限与封口逻辑不用改，只需确认缓动页在短窗下不出现无谓滚动条。
