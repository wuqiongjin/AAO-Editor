# 68 · 选中态的暗底遮罩遮挡相邻音符

## 症状

被选中的音符，其选中态周围有一圈**遮罩**（暗底 halo），会盖住紧邻的其它音符。
issue 56 已对 **Slide 结点 / Slide 段**用 compact 修过，**其它音符类型漏修**（用户原话：
"漏修了其它音符类型的这个选中态 hover 的遮挡问题"）。

## 根因

选中描边 = 外侧暗底 `rgba(0,0,0,0.45)` + 内侧亮面，暗底画在 `outset + darkBand` 的外扩路径上 →
总外扩量把描边推到音符本体之外，压住相邻音符/轨道。
Slide 结点/段因"紧贴连接带、外扩会截断带子"早已改走 `compact`（无暗底、无外扩），
单键/方向键仍是旧口径。

## 定案（用户 2026-09-09 拍板）

**和 Slide 一致，完全 compact** —— 单键/方向键也走 compact：去掉暗底、去掉外扩，
只留亮面黄边贴 ink 边。全类型口径统一，彻底消除遮罩。（用户从"保留窄底衬 / 完全 compact"
两档中明确选了后者。）

- 选中 ↔ hover 的可辨性改由**线宽**（`hoverLineWidth 3` > `lineWidth 2`）+ **α**（0.85 vs 1）
  承担（原靠外扩区分）；
- BPM 是 `line` 形态，本就不画暗底、不外扩，无需改；
- `SELECTION_OUTLINE.outset / hoverOutset / darkBand` 与 `SELECTION_COLORS.dark`
  **目前无消费点**（常量保留，仅当某类型显式 `compact: false` 时重新生效），已在 `selectionStyle.ts` 注明。

## 实现落点

| 文件 | 改动 |
| --- | --- |
| `src/visual/render.ts` | Single / Directional 两处 `emit` 的 rect 加 `compact: true` |
| `src/visual/selectionStyle.ts` | 注释改写：说明全类型 compact 后上述常量的失效状态 |

## 锁测

`tests/unit/SelectionVisual.test.ts` 原「单键/方向键矩形 ≠ compact（保持外圈 + 暗底）」
**反转**为「= compact」—— 该用例锁的正是本次要消除的遮罩。
`InteractionPerf` 等既有全绿。
