Type: task
Status: open

## 来源

自 issue 56 的 b) 项拆出（Q29 / Q30 / Q31 / Q32 / Q35，2026-09-09 定案）。grill 原始对话见 [56 的 Comments](../issues/56-谱面画布音符选中状态整改.md)。

> 前置结论：**多选的"编辑"通道全废**（独立视图 / `‹i/N›` / 导航游标 / 回写 / 画布跟踪都不做），**只保留单向导出通道**：选中集合 → JSON 片段，不可编辑、无回写。

## Spec

### 1. 入口

- **NoteInfoPanel**（`src/chart/components/side-panel/NoteInfoPanel.tsx`）新增「复制为谱面代码」按钮，紧邻"已选中 N 个音符 / 删除选中 / 镜像选中"—— 它本质是对**选中集合**的操作，与后两者同族，无需先打开代码弹窗。
- 无选区时按钮置灰。

### 2. 导出内容

- **触碰即整条**（Q31=A）：只选中 Slide/Long 的部分结点 → 导出**整条**（沿用 ADR-0008 §4 口径）。
- **绝对 beat**（Q32=C）：`convertNotesToChartCode` 现状即如此；**相对 beat 归一化归 [58](./58-谱面配置预设的导出与导入.md)**（预设复用才需要）。
- 产物 = 谱面代码 JSON 数组的片段，可直接粘回编辑器。

### 3. 告知（Q35=C，点前 + 点后都要）

- **点前**：按钮文案随选区动态——无滑条 → `复制为谱面代码`；含滑条 → `复制为谱面代码（含 N 条完整滑条）`。
- **点后**：按钮**就地**变成结果摘要，约 2 秒后恢复原文案：`已复制 4 个对象：3 音符 + 1 滑条(12 结点) ✓`。
- **不新增 toast 组件**（本票不做全局 UI 原语）；「统一提示体系」单开小 issue。

### 4. 供未来复用

- 导出逻辑实现为**纯函数**（`SelectionItem[] → ChartCodeNote[]`），[58](./58-谱面配置预设的导出与导入.md) 的"保存为预设"直接复用。

## 实现落点

| 文件 | 改动 |
| --- | --- |
| `src/chart/editing/`（新纯函数，如 `SelectionExport.ts`） | 选中集合 → 谱面代码片段（触碰即整条、绝对 beat） |
| `src/chart/components/side-panel/NoteInfoPanel.tsx` | 按钮 + 动态文案 + 点后就地反馈（2s 复原） |
| `src/chart/Editor.tsx` | 按钮接线（与删除选中/镜像选中同族） |

## 验收

- 框选 3 个单键 + 1 条 12 结点滑条（只框到其中 3 个结点）→ 剪贴板为 4 个对象、滑条完整 12 结点；按钮文案与点后摘要正确。
- 无选区时按钮不可点。
- 复制结果可直接粘回编辑器并还原同样音符（往返一致，走现有粘贴覆盖规则）。
- 单测覆盖：触碰即整条、混合选区计数、绝对 beat。
