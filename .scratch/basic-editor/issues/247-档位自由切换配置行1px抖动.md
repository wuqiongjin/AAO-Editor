# 247 档位/自由切换配置行 1px 抖动

- **Type**: bug
- **Status**: open
- **关联**: [241](./241-形状模板参数自由调节模式.md)（模式开关）· 同批 [246](./246-曲线胶囊滚轮穿透画布与短窗裁切.md)

---

## 来源

用户复核曲线胶囊面板（问题 4）：在「档位 / 自由」间切换时，下面配置项的文字位置有细微移动，初判是右侧按钮换滑杆影响了列宽。

## 症状

实测标签 y（同一模板、切模式前后）：

- 档位：419 / 447 / 475 / 503
- 自由：419 / 446.5 / 473.5 / 500.5

第 1 行不动、越往下偏得越多（累计 2.5px）。标签 x 恒为 144——**横向没动**，不是滑杆宽度问题。

## 根因

`.ccp__ctrl-row`（`CurveConfigPanel.css:137-142`）没有固定行高，由内容撑开；两套控件的盒高不同：`.ccp__pill-btn` 23px（`:198`）、`.ccp__num-input` 22px（`:173`）。所以自由模式每行矮约 0.8px，逐行累积。

## 修法

统一控件盒高为 23px（`.ccp__num-input` 提到 23，与按钮一致；滑块行按 23px 对齐），并给 `.ccp__ctrl-row` 一个 `min-height: 23px` 兜底，行高不再由内容决定。列宽（52px 标签列）不动。

## 锁测

jsdom 无布局，走 headless Edge 实测（沿用 `shots/capture.mjs` 范式）：

1. 同一模板在档位 / 自由间来回切换 3 次，每行标签的 `getBoundingClientRect().top` 各自恒为同一个值（不随模式变）。
2. 1100 / 1280 / 1440 三个窗宽重复上述断言，全部通过。
3. 面板总高不因本改动变化超过 2px（避免挤压短窗可用高度，与 246 的高度上限联调）。
