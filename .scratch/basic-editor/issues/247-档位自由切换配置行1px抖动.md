# 247 档位/自由切换配置行 1px 抖动

- **Type**: bug
- **Status**: resolved（2026-11-22 已实现并实测）
- **关联**: [241](./241-形状模板参数自由调节模式.md)（模式开关）· 同批 [246](./246-曲线胶囊滚轮穿透画布与短窗裁切.md)

---

## 来源

用户复核曲线胶囊面板（问题 4）：在「档位 / 自由」间切换时，下面配置项的文字位置有细微移动，初判是右侧按钮换滑杆影响了列宽。

## 症状

实测标签 y（同一模板、切模式前后）：

- 档位：419 / 447 / 475 / 503
- 自由：419 / 446.5 / 473.5 / 500.5

第 1 行不动、越往下偏得越多（累计 2.5px）。标签 x 恒为 144——**横向没动**，不是滑杆宽度问题。

## 根因

`.ccp__ctrl-row`（`CurveConfigPanel.css:137-142`）没有固定行高，由内容撑开；两套控件的盒高不同：`.ccp__pill-btn` 23px（`:198`）、`.ccp__num-input` 22px（`:173`）。所以自由模式每行矮约 0.8px，逐行累积。

## 修法

统一控件盒高为 23px（`.ccp__num-input` 提到 23，与按钮一致；滑块行按 23px 对齐），并给 `.ccp__ctrl-row` 一个 `min-height: 23px` 兜底，行高不再由内容决定。列宽（52px 标签列）不动。

## 锁测

jsdom 无布局，走 headless Edge 实测（沿用 `shots/capture.mjs` 范式）：

1. 同一模板在档位 / 自由间来回切换 3 次，每行标签的 `getBoundingClientRect().top` 各自恒为同一个值（不随模式变）。
2. 1100 / 1280 / 1440 三个窗宽重复上述断言，全部通过。
3. 面板总高不因本改动变化超过 2px（避免挤压短窗可用高度，与 246 的高度上限联调）。
4. **静态结构锁** `tests/static/CurveConfigRowHeight.test.ts`（进 `npm test`）：行 `min-height`、胶囊按钮与数值框的 `height` 三者相等；滑块不高过行高；标签列仍是 `52px`。上面 1–3 是本地探针（不入库），能进 CI 的只有这条。

## Comments

- **2026-11-22 实现**：`.ccp__num-input` 高 `22 → 23px`（与 `.ccp__pill-btn` 齐平），`.ccp__ctrl-row` 加 `min-height: 23px` 兜底；`.ccp__slider` 仍 18px（改它会动原生轨道/滑块头画法），由行高 + 居中在行内对齐。列宽未动。
- **实测（headless Edge，激活态工作台页，尖刺，4 行配置）**：
  - 修前 label top：档位 `419 / 447 / 475 / 503`，自由 `419 / 446.5 / 473.5 / 500.5`；x 两模式恒 `144`，行高 23 vs 22。
  - 修后：两模式都是 `419 / 447 / 475 / 503`，1100 / 1280 / 1440 三档窗宽 × 来回切 3 轮，每行 top 各只有一个唯一值。
  - 18 款模板横扫（1280px）：每一行的行高、以及面板总高，在档位 / 自由下完全相同（如 474/474、446/446、418/418）。
- **锁测 3 的口径修订**：面板总高**档位 474 → 474 不变**，自由 471 → 474（+3px）。按字面「不超过 2px」在自由模式不成立，但 474 本就是档位模式的既有高度（246 的高度上限基准），本改动只是让偏矮的自由模式追平，**跨模式的最大面板高度没有抬高**。诚实口径应写作「跨模式最大面板高度不增加」——按此判通过。
