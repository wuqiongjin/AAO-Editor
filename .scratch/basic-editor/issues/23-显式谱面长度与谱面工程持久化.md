## Question

按 [ADR-0005《显式谱面长度与谱面工程持久化》](../../../docs/adr/0005-显式谱面长度与谱面工程持久化.md) 实施三个关联 bug（9/10/11）的修复 + 谱面工程持久化。根因：谱面长度为"由音符推算"的导出量，需改为**显式、秒域、与音符解耦**的第一性属性，并引入**谱面工程（Chart project）**持久化单元。

## 实现范围（ADR-0005 各节）

- [x] 谱面长度模型（§1/§4/§5/§7）：画布虚拟高度/网格范围/滚动范围/播放宽改跟随**显式谱面长度**（秒→BPM→拍），不再由最大音符 beat 推算；**取消 +1 拍尾量**；**放置音符永不改变谱面长度**（超出谱面末端的放置禁止）。
- [x] 时长同步（§4）：有音频＝音频时长（加载后覆盖持久化值）；无音频＝持久化谱面时长（默认 30s）；PlayBar"时长"编辑**写入谱面时长字段并持久化**（废弃 `durationEditedRef` 会话级语义）。
