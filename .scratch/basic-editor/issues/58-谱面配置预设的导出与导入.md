# 58 · 谱面配置（预设）的导出与导入

Type: grilling
Status: open
Blocked by:

> **切片 1 = [60 选中集合导出为谱面代码](./60-选中集合导出为谱面代码.md)（已定案，可先行）** —— 本票是同一需求的后续切片（预设库 / 导入 / 放置 / 相对 beat），grill 未完成前不阻塞切片 1 落地。

## Question

把"一组音符"当作**可复用资产**：导出成谱面代码、保存为配置预设、下次从工作台快捷放置、以及导入外部片段。范围、格式、放置语义、预设库的管理形态，全部待 grill。

## 来源（立案依据）

- 2026-09-08 issue 56 grill 第四轮，用户提的 **Q19 衍生场景**：「未来要支持『特定谱面配置的保存』——把常用配置保存到工作台的自定义配置区域，方便下次快捷放置」。该场景需要"多选音符 → 保存"。
- 判定结论：**这是导出/复用，不是编辑**——与 56 的"多选代码视图（编辑通道）"切开，后者已废弃。
- 56 已为它预留的地基（`2026-09-08` 五/六轮定案）—— **已落地为切片 1 = [60](./60-选中集合导出为谱面代码.md)**：
  - 导出入口 = **NoteInfoPanel「复制为谱面代码」**（Q30=B），与"删除选中/镜像选中"同族；
  - **触碰即整条**（Q31=A）：只选中 Slide 的部分结点 → 导出整条 Slide，且必须让用户知道（Q35=A：按钮文案动态 + 点后就地反馈"已复制 N 个对象：X 音符 + Y 滑条(Z 结点)"）；
  - **beat 归一化 = 本票决定**（Q32=C：切片 1 只做绝对 beat，"相对 beat 归一化归未来的谱面配置/预设 issue" ← 就是本票）。
  - 切片 1 的导出逻辑实现为**纯函数**（`SelectionItem[] → ChartCodeNote[]`），本票的"保存为预设"直接复用。

## 范围（建议切四块，grill 时逐块拍）

1. **格式**：谱面配置 = 什么？候选——
   - A. 就是谱面代码 JSON 数组的一个**片段**（与 `convertNotesToChartCode` 同构，可直接粘回编辑器）；
   - B. 片段 + 包围元信息（宽/高/lane 跨度/是否含滑条/作者/标签）；
   - C. 独立文件格式（未来与素材包/皮肤包同构的"配置包"）。
2. **导出**：**剪贴板 = 切片 1，已定案并归 [60](./60-选中集合导出为谱面代码.md)**；本票剩"另存为预设"是否一步到位、是否需要文件导出。
3. **导入 / 放置**：
   - 粘贴语义复用 ADR-0008 §2.1（锚点 = 包围盒左上角对齐光标、越界钳制保持组宽）；
   - 落点覆盖规则是否走 ADR-0001 §1（粘贴走覆盖，那"放置预设"走不走？）；
   - **beat 归一化**：相对 beat（首个音符 = 0）还是绝对 beat —— 56 定的是绝对，预设要可用必须相对，需拍。
4. **预设库**：存在哪（settings JSON / IndexedDB / 文件后端）、命名与分组、UI 形态（工作台自定义配置区的一排卡片？）、增删改排序、导入导出 JSON（与 ADR-0003 的 settings 导入导出是什么关系）、与 issue 29「素材包导入」格式的关联性。

## 已定的相邻口径（勿重开）

- 56：**不追求兼容 bestdori 边界行为**（原则裁决，建议固化到 ADR-0001 / issue 02）——导入的非法片段同样一律拒绝、不静默修正。
- 55 / ADR-0008：放置/粘贴的覆盖规则、锚点、钳制、持工具态与选区模型。
- 09：SP 绿条**形状模板**是"单条滑条的形状"，与本票的"一组音符的配置"是两种资产，需划清（或决定合并）。
