# 101 · 点击播放后开头谱面卡顿一下（初次播放 / 换肤后 / 换音频后初次播放）

Type: bug
Status: resolved

## 来源

用户 2026-09-12 复报第七批 #1。

## 症状

点击播放后，最开始谱面会卡顿一下；初次播放、换音符皮肤素材后的初次播放、换音频素材后的初次播放均有概率遇到。

## 根因

分诊排查出三个"首开重活"都可能落在开播时刻（实现时先实测锁定主因再动刀）：

1. **换肤后首播（渲染侧，主嫌疑）**：换肤 bump `skinVersion` → `noteLayerCache` 瓦片全量失效（`src/visual/noteLayerCache.ts:300,308`）；播放 RAF 每帧 `setScrollY` 触发重渲，**非手势帧无重建预算上限**（`:329` `rebuildBudgetUntil = Infinity`，`:336-339` miss 瓦片同步现建 `renderTile`）→ 开播后滚动经过的每块瓦片都在帧内同步重建，开头掉帧。
2. **初次播放（键音侧）**：`AudioEngine.play()` 阻塞在 `await keySetReady`（`src/audio/AudioEngine.ts:190`）= 键音 chunk 动态 import + 全采样逐个 `decodeAudioData`（`:312-345`）；未预热完则开播被推迟，且 `startPlaybackLoop` 要等 `play()` resolve 才启动 → 谱面滚动在等待窗口内是**静止**的（用户看到的"卡一下"同族症状）。
3. **开播帧全谱编译**：编辑中 `setChart` 防抖 300ms，但 `isPlaying` 翻 true 时立即同步执行（`src/chart/components/Editor.tsx:193-201`）→ 全谱 `getBpmEvents` + `buildKeyEvents` O(n) 同步编译（`src/audio/AudioTiming.ts:16,105`）落在开播帧。换音频后首播：音频解码在导入时已完成（`AudioSession.ts:157-181`），嫌疑收敛到 ②③。

## 修法

本轮实现口径（待验收，不是用户定案）：

- 瓦片：播放帧同样套帧预算（同 issue 96 二轮"手势帧 4ms 预算渐进重建"口径），miss 瓦片按预算渐进出，滚动不等全图重建。
- 键音：预热提前到进入工作台/切键音包时；实测"等待开播"与"先播、键音就绪即补"两种口径的观感，择一实现（若改不等待，属 ADR-0004 播放语义边角，实现时在票内记录）。
- 谱面编译：`setChart` 编译移出开播帧（提前或分片），不在开播帧做全量 O(n)。

## 锁测

1. `tests/unit/RendererPerf.test.ts` 新增用例：瓦片缓存全量失效后，播放滚动态每帧 `renderTile` 次数受帧预算约束（现状 = Infinity，修复前红）。
2. `tests/unit/AudioEngine.test.ts`（或新文件）：`keySetReady` 未 resolve 时 `play()` 不得阻塞滚动启动 ≥1 帧（假定时器/静态源码断言 `play()` 不再 await `keySetReady`）。
3. 单测覆盖不到真实掉帧观感 → Playwright 实测三场景（首播/换肤/换音频）开播 rAF 帧间隔，无 >250ms 长任务；脚本不入库（照 96/98 惯例）。手工验收 = 用户页面开播无感卡顿。

## Answer

三处首开重活都动了（锁测先红后绿）：

1. 播放帧 miss 瓦片套 4ms 预算；`setPlaybackActive` 在 RAF 启动前同步打标，避免 React `isPlaying` 晚一帧。
2. `play()` 不再 await 键音预热；未就绪走 ADR-0004 §7 振荡器兜底，采样就绪即补。预热仍在 `AudioSession` 构造 / `setKeySetId`（进工作台/切包）。
3. `setChart` 不再因 `isPlaying` 翻转同步全谱编译；编辑仍 300ms 防抖，播放中改谱 `setTimeout(0)`。

## Comments

- 键音口径记录（2026-09-20）：选「先播、键音就绪即补」，不等待。与 ADR-0004 §7「采样未就绪时振荡器兜底」一致，不改 ADR。
- Playwright 三场景脚本按票面不入库；真实掉帧观感交用户页面验收。
- 锁测落点：`tests/perf/RendererPerf.test.ts`（路径与票面 `tests/unit/` 不一致，跟现仓 perf 分层）、`tests/unit/audio/AudioEngine.test.ts`、`tests/static/PlayStartChartCompile.test.ts`。
