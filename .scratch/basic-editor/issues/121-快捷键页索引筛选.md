# 121 · 快捷键页索引筛选

Type: grilling
Status: open（2026-09-18 `/grill-with-docs` 已拍板，待实现）
Blocked by: —

## 来源

内容页几何（120）不再给快捷键留空 `__slot`。用户要求该页增加 **侧边索引**，用来 **筛选** 快捷键表，不是装饰占位。

## 定案（用户 2026-09-18）

术语：**索引筛选**（粗桶）。勿称 **类别**——类别仍是 ADR-0002 里给 tooltip 用的细分组（`单键` / `复制`…）。

| 索引筛选 | 内容 |
| --- | --- |
| 全部 | 不筛选（默认；**不写入设置对象**） |
| 系统 | 切页五条（现页头只读、不可改键）+ `布局` |
| 音符工具 | `鼠标` `BPM` `单键` `滑键` `技能` `左滑` `右滑` `滑条` `曲线` |
| 编辑工具 | `复制` `粘贴` `剪切` `删除` `镜像` `音符代码` `撤销` `重做` |
| 播放 | `播放` |
| 其它 | 默认空；尚未入桶的新功能落点 |

- 切页五行 **进表、归「系统」**；删页头重复只读区。
- 搜索 ∩ 当前桶（且）；空结果走现有 EmptyState。
- 不改「一功能一键」；ADR-0002 只补展示层。

## 实现落点

- `ShortcutsPage` 接入 `<AppPageShell.Sidebar>`；切页条目并入表（仍不可改键）。
- 桶映射表驱动，避免和 `category` 字段混名。

## 锁测

- 纯逻辑：每条 `FunctionId` + 切页五行恰好落入一个非「全部」桶；「其它」默认空。
- 搜索 ∩ 桶：桶=播放 + 搜索「单键」→ 空。
- 静态断言：无筛选字段写入 `AppSettings`。
