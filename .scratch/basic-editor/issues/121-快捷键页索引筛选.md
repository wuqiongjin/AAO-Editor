# 121 · 快捷键页索引筛选

Type: grilling
Status: resolved
Blocked by: —

## 来源

内容页几何（120）不再给快捷键留空 `__slot`。用户要求该页增加 **侧边索引**，用来 **筛选** 快捷键表，不是装饰占位。

## 定案（用户 2026-09-18）

术语：**索引筛选**（粗桶）。勿称 **类别**——类别仍是 ADR-0002 里给 tooltip 用的细分组（`单键` / `复制`…）。


| 索引筛选 | 内容                                            |
| ---- | --------------------------------------------- |
| 全部   | 不筛选（默认；**不写入设置对象**）                           |
| 系统   | 切页五条（现页头只读、不可改键）+ `布局`                        |
| 音符工具 | `鼠标` `BPM` `单键` `滑键` `技能` `左滑` `右滑` `滑条` `曲线` |
| 编辑工具 | `复制` `粘贴` `剪切` `删除` `镜像` `音符代码` `撤销` `重做`     |
| 播放   | `播放`                                          |
| 其它   | 默认空；尚未入桶的新功能落点                                |


- 切页五行 **进表、归「系统」**；删页头重复只读区。
- 搜索 ∩ 当前桶（且）。
- 不改「一功能一键」；ADR-0002 只补展示层。

## 验收补记（用户 2026-09-18）

1. **多键并排**：切页行 Ctrl / ⌘ 两套组合**同一行并排**，不换行（换行会被行高裁切）。
2. **两套空态**：桶里没有可改/切页条目 →「这个分类暂无快捷键」+「查看全部」；桶有条目但搜索无命中 →「没有匹配的功能」+「清除搜索」。空桶优先于搜索空。
3. **恢复默认跟当前索引**（用户拍板）：「全部」= 整表出厂；其它桶只重置该桶 **可改** FunctionId（切页五行不在配置里）。「其它」无可改项则按钮禁用。若桶外出厂键被占用，先卸掉占用方，避免一键两功能。
4. **换桶进入动效**：只重挂表体（`key={indexFilter}` + 全局 `app-stagger`），搜索栏/表头不动。表体 `flex: 0 0 auto` + `overflow: clip`：按内容撑高、滚动仍在 `.shortcut-table`；clip 只挡 translateY，避免装得下时闪条。内容壳 Body 不再挂 stagger（滚动容器上的位移会闪条）。

## 实现落点

- `ShortcutsPage` 接入 `<AppPageShell.Sidebar>`；切页条目并入表（仍不可改键）。
- 桶映射表驱动，避免和 `category` 字段混名。
- `shortcutIndexFilter.ts`：`shortcutTableEmptyKind` / `restoreDefaultsInFilter`。

## 锁测

- 纯逻辑：每条 `FunctionId` + 切页五行恰好落入一个非「全部」桶；对照表钉死类别→桶；「其它」默认空。
- 搜索 ∩ 桶：桶=播放 + 搜索「单键」→ 空。
- 空态：其它=空桶；播放+「单键」=搜索空。
- 恢复默认：全部=整表；播放桶不改单键；其它=原样；桶外占出厂键则卸占用方。
- 静态断言：无筛选字段写入 `AppSettings`；页用 `restoreDefaultsInFilter`；滚动在 `.shortcut-table`、clip 不在全局 `.app-stagger` / Body。

## Answer

落地：`src/settings/shortcutIndexFilter.ts` 表驱动粗桶；`ShortcutsPage` 接 `AppPageShell.Sidebar`；切页五行进表归系统；搜索 ∩ 桶；`useState` 默认「全部」，不写 `AppSettings`。ADR-0002 只补展示层。验收三项见上。锁测 `tests/unit/shortcutIndexFilter.test.ts`。
