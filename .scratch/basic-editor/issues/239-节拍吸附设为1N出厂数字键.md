# 239 · 节拍吸附「设为 1/N」出厂数字键

Type: grilling
Status: resolved
Blocked by: —

## 来源

用户反馈当前节拍吸附快捷键不顺手，希望对标 Bestdori 数字键「设为 1/N」（`1→1/1` … `0→1/16`）。216 只提供未绑定的调密/调疏/循环，注册表里没有「设为 1/N」，自定义键也绑不出这套肌肉记忆。2026-11-17 `/grill-with-docs` 拍板。

## 定案（用户 2026-11-17）

1. **补八个具体功能**「设为 1/N」：`beatSnapSet1` / `2` / `3` / `4` / `6` / `8` / `12` / `16`。按下即写 `settings.beatSnap`，不是轮切。
2. **出厂裸键抄 Bestdori**：`1 2 3 4 6 8 9 0` 对应上列八档（`9` = 1/12，`0` = 1/16）。`5`、`7` 出厂不占。
3. **键可改、档不可改**：单键绑定仍走 ADR-0002；不能把「设为 1/4」改成别的 N；不为 1/24 等其余预设、不为任意 1–192 再注册「设为 1/N」或用户槽位。自定义细分仍走顶栏胶囊。
4. **216 三功能保留**，出厂仍 `null`。循环常用档只承担短列表轮切，不当「设为 1/N」的替代，文档不把「列表只留一项」写成用法。
5. **兼容**：只保护已出现过的 `functionId` 及其用户键位。新 id 不在快照 → 套出厂数字键；撞老功能 → 新功能退 `null`（ADR-0002 / issue 230 载入去重）。不 bump `schemaVersion`。删循环才算非兼容——本次不删。
6. **叫法**：类别仍「节拍吸附」；功能就叫「设为 1/N」，不造「直达档」。胶囊预设格不画数字键标注。
7. 作用域 `canvas`、类别 `snap`、不进 `CHART_EDIT_FUNCTIONS`；切档反馈仍只改胶囊与参考线。数字行与小键盘 NumLock 开时 `e.key` 相同，不另绑 Numpad。

ADR-0002 / CONTEXT.md 已于同日写入。
