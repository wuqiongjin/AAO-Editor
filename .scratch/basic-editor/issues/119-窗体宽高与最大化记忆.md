# 119 · 窗体宽高与最大化记忆

Type: feature
Status: resolved

## Answer

主进程 `electron/windowState.cjs` 读写 `userData/window-state.json`（仅 `width` / `height` / `isMaximized`，无位置）；`createWindow` 恢复几何并在 `ready-to-show` 时 `maximize()`；关闭时 `saveWindowStateSync` 原子写入。锁测 `tests/unit/WindowStateMemory.test.ts`。
Blocked by: —

## 来源

用户要「窗口大小记忆」。现 `electron/main.cjs` 每次 `1260×800`，不记最大化。

## 症状 / 根因

OS 窗体几何未持久化。`settings.layout` 只记工作台左右面板，与窗体无关。

## 修法

- 记 **宽、高、是否最大化**；**不记位置**（多屏）。
- 存主进程 `userData/window-state.json`（或同等），**不进设置对象、不进「导出配置」**。
- 恢复时尊重现有 `minWidth/minHeight`；缺文件仍默认 1260×800。

## 锁测

- 纯函数：序列化/反序列化、非法值回退默认、最大化标志与宽高并存。
- Electron 手工：拉大/最大化 → 退出 → 重开；「导出配置」JSON 不含窗体字段。
