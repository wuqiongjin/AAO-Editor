# 157 · SP 滑条材质整条传染（同条直段被画成普通 Slide）

Type: bug
Status: resolved（2026-09-24 实现 + 锁测，**用户页面验收通过**）
Blocked by: —
Related: 09 / ADR-0009 §5

## 来源

用户 2026-09-24：Official-786（`docs/resource/StressTestChart/Official/786_SP.json`）在 **1:19.94 之后** 多处 Slide 的子段把曲线材质画成了普通 Slide。

## 症状

同条 Slide 里只要后面有 hidden（SP 段），开头那些**没有 hidden 的子段**仍走普通 `slideBand`。用户给的最小例：beat `240 / 240.5 / 241.5(hidden) / 242.5` 的同拍多 lane 条，**最开头子段**被画成普通 Slide。

## 根因

`isSpRegion`（`SlideSegments.ts`）按 **逻辑段** 判定：`span.end - start > 1` 才用 `slideBandSp`。这是 ADR-0009 §5 / issue 09 Q4 的「段级、非整条」口径，`HiddenNode.test.ts` 的混合条用例（`[A,B,H,C]` 前段 false）把错误口径锁死了。官方谱的同拍多臂 + 后段 hidden 正好打中这条。

## 修法

**定案（用户 2026-09-24，Bestdori 对照表 #0–#8 全过）**：同条 Slide / Long 任一 `hidden` → **所有子段**用 SP 材质；邻条无 hidden 不被染。改 `isSpRegion` 为整条级；作废 ADR-0009 §5「段级、混合条直段保持普通材质」。数据/导出不动。

## 锁测

- 改写 `tests/unit/chart/editing/HiddenNode.test.ts`「issue 09 S1 · SP 段材质判定」：混合条 `[A,B,H,C]` / `[A,H,B,C]` 全部边 `true`；纯 `[A,B]` 仍 `false`。用用户最小例（含同拍多 lane）加一条。回退源码应红。
- 像素级材质单测覆盖不到 → 手工验收 Official-786 @ 1:19.94：原先发灰/发直的开头子段应与后续 SP 带同材质。**2026-09-24 用户页面验收通过。**
