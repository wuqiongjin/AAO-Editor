## Answer（结论）

**已定稿 + 已实现（2026-08-16）。决策全文见 [ADR-0003 §11 增补](../../../docs/adr/0003-工作台UI与配置系统.md#11-issue-22-增补布局信息架构与交互模型定稿2026-08-16)。**

### grill 定稿摘要（用户逐条确认）

- **信息架构归位**：播放 → 仅底部播放条（移除工具栏"播放"区块）；键型工具 → 左侧 3 列网格；编辑 → 2 列网格；缩放 → 画布顶栏（双击 % 复原 100%）；删除右侧"谱面"死 footer；音符总数并入右侧信息面板（去"共"前缀底色徽标）。
- **顶栏实时区**：当前播放线区间 BPM + 缩放；起点标记提示迁往右栏底部（tip 型 footer）。
- **画布信息叠加（常显，pointerEvents:none）**：左下 = 精确时间（0.1s），右下 = 已过判定线音符数（不含总数）。
- **播放条改造**：可拖拽进度条（点击/拖动 seek，暂停不自动播 + 画布跟随滚动）+ 音量；时间码 0.1s 精度，无音频时双击原地编辑定位；移除素材选择（issue 29）与标记提示。
- **按钮交互统一**：新增 `IconButton`（hover/pressed/active/disabled/danger + focus-visible），废弃内联/手写态并存写法。
- **布局持久化**：折叠态 + 面板宽回写 `settings.layout`（ADR-0003 §6），挂载初始化。
