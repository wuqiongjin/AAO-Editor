## Question

新增**快捷键系统与自定义配置**：统一的功能注册表（一功能多键、一键不多功能、冲突检测）、音符/编辑功能目录与默认键位、工具态 + 执行键双交互、预览、localStorage 持久化 + 设置面板 UI。

权威规则见 **`docs/adr/0002-快捷键系统与自定义配置.md`**（grill-with-docs 定案，2026-08-08）。实现须与 ADR 一致；冲突时先改 ADR 并经用户确认。

## 范围（本次实现）

- **重构快捷键**：废弃 `Editor.tsx` 现有硬编码 `onKeyDown`（Ctrl+C/X/V/Z/Y/A/M/D + Delete/Backspace），改走统一注册表。
- **音符类型目录**（工具键 / 执行键）：单键 F/Ctrl+F、滑键 G/Ctrl+G、技能键 A/Ctrl+A、左滑键 S/Ctrl+S、右滑键 D/Ctrl+D。执行键 = 光标处立即放置。
- **编辑目录**（工具键 / 执行键）：鼠标 R、复制 C/Ctrl+C、粘贴 V/Ctrl+V、剪切 X/Ctrl+X、删除 T/Ctrl+T、镜像 Q/Ctrl+Q、撤销 —/Ctrl+Z、重做 —/Ctrl+Y。
- **工具态（Model A）**：C/X/T/Q 切换工具态，点击音符 = 选中并立即执行（每次单音符）；粘贴工具态点击位置落剪贴板组。
- **预览**：音符放置（放置幽灵）、粘贴（剪贴板组幽灵）、镜像（悬停单键幽灵 + 框选含滑条连接区域的镜像结果）；复制/剪切/删除无预览。
- **自定义配置**：`ShortcutConfig.ts`（功能注册表 + 默认绑定 + 改键冲突检测），localStorage 持久化，设置面板 UI，可选导出/导入 JSON。
- **作用域**：仅画布；焦点在 INPUT/TEXTAREA/SELECT/contentEditable 时放行原生。

## 不在本次范围

- 滑条工具 / BPM 工具 / 全选 / 组合状态 / 缩放 / 播放 的快捷键。
- Electron `userData` JSON 文件存储后端（仅留统一接口，未来切换）。

## 验收

- `npx tsc -b` 全绿；`npm run build` 通过。
- 现有单元测试通过，并为 `ShortcutConfig`（默认绑定、一功能多键、一键冲突拒绝）补单测。
- 工具态点击执行、执行键即时执行、预览幽灵、localStorage 持久化与设置面板改键冲突提示均可用。
