## Question

提交后的强化缺陷：复制音符后粘贴，与既有音符同坐标时不会覆盖，直接在谱面中产生**多个重叠音符**。粘贴需要遵守 ADR-0001 覆盖规则（含滑条结点被覆盖时的表现：单键忽略、滑键仅尾部加 flick、技能键两端加 skill、方向键拆条）。

## Answer（已修复，2026-08-09）

- 新增 [NoteReplacementRules.pasteChartNotes](..\..\src\utils\NoteReplacementRules.ts)：粘贴不再直接 `concat`，每个粘贴音符按覆盖规则处理：
  - **空位** → 原样粘贴（保留 flick/skill/subBeat/方向键 length）。
  - **与既有普通音符重叠** → 放置覆盖规则（替换 / 方向键 length+1 / 替换为方向键，ADR §1.1）。
  - **与滑条结点重叠** → 单键忽略、滑键仅尾部加 flick、技能键两端加 skill、方向键拆条（ADR §1.2）。
  - **滑条本身** → 清理其连接点覆盖的普通音符后作为独立实体加入，不与既有滑条组合（ADR §6.3）。
  - 方向键在覆盖/拆条后保持粘贴件的 length（>1 时）。
- [Editor.tsx] 两个粘贴入口（`pasteNotes` 执行键 Ctrl+V / `handleEditToolPaste` 粘贴工具态点击）统一改走 `pasteChartNotes`，返回 `newStartIndex` 供选中粘贴结果（覆盖/拆条可能改变数组长度，越界条目过滤不选）。
- 移除 Editor 中不再使用的 `shiftGroupToAnchor` import（收敛到 NoteReplacementRules 内部使用）。

**验证**：新增 `tests/unit/PasteOverwrite.test.ts` 10 个用例（空位保留标记/length、普通覆盖替换、方向键 length+1、滑条结点 3/5 结点拆条、滑键尾端、滑条清理重叠独立加入）。`tsc -b` + `vite build` 全绿；vitest **84** 测试通过。
