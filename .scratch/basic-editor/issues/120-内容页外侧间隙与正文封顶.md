# 120 · 内容页外侧间隙与正文封顶

Type: grilling
Status: resolved
Blocked by: 121

## 来源

二次调整内容页（音频 / 视觉素材 / 快捷键 / 设置）**组件到窗口边缘**的距离，以及窗口变宽时正文是否跟长、min/max。不改页内卡片排布（issue 49 已做过）。工作台不接入内容壳，本票不动工作台。

## 现状（与诉求冲突）

ADR-0007 / issue 44：L=51、R=32 固定；正文 ≤1440 锁 920，更宽按 **0.3/px** 涨（1920 折叠导航时正文约 1060）→ 全屏右侧空一大块。**没有** body `max-width` 封顶。快捷键页用空 `__slot` 占侧栏位。

## 定案（用户 2026-09-18）

内容壳宽度 `W` = 窗口宽 − **应用导航**。一行：`L + 侧边索引 + gap(24) + 正文 + R = W`。

1. **默认窗 1260×800**：正文锚点 **920**；左右都有可压缩的 **外侧间隙**。
2. **再变窄**：L 与 R **一起减**，到 **L_min = R_min = 16** 之后才减正文。
3. **再变宽**：间隙先冻在默认窗那档，正文 **1:1** 变宽直到 **`B_max = 1440`**；再宽则左右间隙一起加；**`L_max = 96`（可调，不锁死 ADR 数字）** 之后只加 R。
4. 侧边索引维持 `clamp(140px, 12.5%, 200px)`，不跟窗口 1:1 抢宽度。
5. 快捷键页 **按有侧栏排**（真索引，不是空 `__slot`）→ **Blocked by 121**。
6. **720px 断点保留**（侧栏改顶上横条，L/R=16）。

实现时修订 ADR-0007 §5 / CONTEXT「几何自适应」；issue 44 不改写，只 Comments。

## 实现落点

- `AppPageShell.css` 替换 `--aps-body-w` 的 0.3 公式为上述规则；L/R 改为可变外侧间隙。
- 删快捷键页对空 `__slot` 的依赖（121 落地后 `hasSidebar=true`）。
- `L_max` 做成令牌，注释写明可调。

## 锁测

- 几何纯函数（若抽出）：给定 `W` → L/R/正文，覆盖默认窗 / 更窄先吃间隙 / 1:1 到 1440 / L 封顶后只加右。
- 四页手工：1260 缩、拉、全屏右侧空应明显小于现状；快捷键与设置 **正文左缘同线**（有真侧栏之后）。

## Answer

落地：`layoutContentShell(W)`（`src/layouts/contentShellGeometry.ts`）按默认窗锚点算 L/R/正文/侧栏；`AppPageShell` ResizeObserver 写入 CSS 变量。废 0.3 与 `--aps-body-bump`。`L_max` = `--aps-inset-l-max`（出厂 96，可调）。默认窗 L 仍 51、R=62（Q18 不对称）。快捷键真侧栏由 121 提供。ADR-0007 §5 / CONTEXT 几何自适应已改。锁测 `tests/unit/contentShellGeometry.test.ts`。
