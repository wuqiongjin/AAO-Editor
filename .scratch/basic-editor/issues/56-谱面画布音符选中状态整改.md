## Spec · a) 选中态视觉

**A1 形态**：贴合 sprite **ink 矩形**的**圆角矩形描边**（双色：外侧暗底 + 内侧亮面，**不用 `shadowBlur`**）。废除 `strokeSelectedCircle` 的正圆黄圈。

**A2 配色**：一套**浅黄**，收进新建的画布专用常量模块 `src/visual/selectionStyle.ts`（**不接 CSS token**，画布恒定深色）。选中 / hover / 滑条子部分**共用**；框选矩形保留独立色（"进行中"的临时反馈）。初值（目检可调）：亮面 `#FFE066`、暗底 `rgba(0,0,0,0.45)`、危险红 `#FF5A5A`。

**A3 统一旧色**：issue 55 遗留的"整条滑条选中 = 结点青圈 + 带青框"（`render.ts` `drawSlideSelection` 的 `#00e5ff` 两处）**统一改浅黄**。

**A4 各形态描边**：

| 对象 | 描边 |
| --- | --- |
| 键型音符（Single / 滑键 / 技能） | 本体 ink 圆角矩形一个 |
| 方向键 | **每条本体各一个**矩形（箭头不描） |
| 滑条结点 `slideNode` | 该结点的 ink 矩形 |
| 滑条段 `slideRegion` | 沿**平行四边形四边**描边封口 —— **段是斜的必须描斜的**（按连接带宽度方向法向量 × `noteSize` 算四顶点），**禁止退化成轴对齐包围盒** |
| 整条 `note` | 逐子部分并集（所有结点矩形 + 所有段带轮廓） |
| `Long` | **≡ Slide**（`src/chart/types.ts:30` 两者结构完全等价），同一套规则 |
| BPM 线（完整框选入选） | **整条线改浅黄 + 加粗**（细线描边不明显） |

**A5 缩放**：描边**随 `noteSize` 缩放**，永远贴合外边缘；顺带统一 `render.ts` 的漏乘口径 —— 结点圆 `L405`（现不乘 ns）、区域半宽 `L416`（乘）、叠加层 `L444/448`（漏乘）**一律乘 `noteSize`**。

**A6 hidden 结点**：叠加层**不画**（`findItemAt`/`computeItemsInBox` 已跳过 hidden，选不中自然画不出）。

**A7 绘制位置**：仍在叠加层 `renderSelectionOverlay`，**不进瓦片缓存键**（保持 issue 35 F1 的"选择变化 0 瓦片重建"不变量）。

**A8 色觉辅助**：**无关**（该开关只替换音符材质），选中 / hover 配色不随之切换。

## Spec · c) hover 层级

**C1 命中**：完全复用 `src/visual/hitTest.ts` 的 `findItemAt`（含滑条子部分），重叠时取**数组序首个**（与点选同结果 = "所见即所中"）。

**C2 形态**：复用 a) 定稿的描边，**只画亮面、不画暗底**，α **0.7** —— 比真实选中轻一档；hover 到已选中音符时两者可辨。

**C3 层级**：真实选中（暗底 + 亮面）> hover 亮面 > 幽灵（0.35）。**与幽灵叠加不互斥**（描边在 ink 外缘、幽灵在本体，物理不重叠）。

**C4 适用范围**：所有态都判定，但**已有幽灵预览的态不画**（放置 / 粘贴 / 镜像）。

**C5 删除工具持工具态 = 危险色**：hover 改**红**（同形态换色，只画亮面、α 0.7）；画在 `findItemAt` 命中的**那个子部分**（与点选结果一致）；**已选中的音符被 hover 时该轮廓整体转红**（覆盖浅黄选中色）。删除态 hover **BPM 不画红**（单击无效果）、**跳过 hidden 结点**。

**C6 状态来源**：`FinalVirtualCanvas.tsx` 已有 `hoverPos`（L188 声明 / L423 更新 / L557 进 `RenderCtx`）。hover 命中项**只在 `hoverPos` 变化时重算**，不要每帧 `findItemAt`。

**C7 设置项**：hover 不进设置项；颜色与 α 全收进 `selectionStyle.ts`（开发期可调）。

## 验收

目检矩阵：**音符类型**（单键 / 滑键 / 技能 / 左·右方向键 / 滑条结点 / 滑条段 / 整条滑条 / Long / BPM 线）× **`noteSize`**（设置项 10–200 取 3 档）× **画布缩放** × **色觉辅助开关**（应无变化）× **删除态红 hover** × **hidden 结点**（应无任何反馈）。

回归：issue 35 F1 的"选择变化 0 瓦片重建"不变量不破；`RendererPerf` / `InteractionPerf` 测试全绿。
