## Comments

### Grill 第 1 轮（2026-08-11）

- 目标用户：同时服务新手与熟练用户，默认面向熟练用户，并以渐进披露照顾新手。
- 信息架构采用两层模型：应用级页面承载工作台、音频、设置、快捷键等单例目的地；未来的谱面工程文档标签位于工作台内部，两者不混为同一层 Tab。
- issue 28 严守边界：本次不实现 issue 26 的多谱面创建、列表、切换与隔离，也不展示无实际能力的占位页面；但页面注册机制须允许后续扩展。
- 设置与快捷键拆为两个平级页面：设置承载外观、布局、音频等通用配置，快捷键专注检索、录入、冲突与启停。
- 设计语气：冷静专业的桌面创作工具。性能、不卡顿、操作流程和便捷性高于装饰性；画布始终是视觉与操作焦点。

### Grill 第 2 轮（2026-08-11）：应用壳、生命周期与操作作用域

- 应用级导航形态：最左侧窄导航栏（约 52–60px），图标 + 短标签或稳定 tooltip，与应用内未来工程文档 Tab 明确分层；入口始终可见、不折叠。四个入口一次点击切换。
- 工作台保活策略：保留工作台组件、滚动位置、选区、工具态与画布实例；页面不可见时暂停其渲染循环与输入响应（隐藏内容 inert、禁用指针/键盘）。
- 离开工作台播放行为：自动暂停并保留当前位置；回到工作台不自动恢复、由用户手动继续（避免设置页误以为卡顿或找不到声音来源）。
- 快捷键作用域：仅工作台响应编辑快捷键；其他页面只响应页面自身与应用级少量快捷键；快捷键录入页、输入框、文件选择期间完全隔离。
- 应用级切页快捷键：`Ctrl/Cmd + Shift + 1…4`（不用裸数字或 `Ctrl+数字`，避免撞编辑功能）；tooltip 显示；不进入用户自定义快捷键表，优先级高于工作台快捷键，但录入器激活时禁用。
- 启动/刷新默认页面：每次启动直达工作台（符合 ADR-0003 入口直达），不记住上次停留的页面。
- 应用页面语义：固定顺序、不可关闭、不可拖动重排、仅切换当前页；关闭/重排/恢复语义留给未来的工程文档标签（issue 26）。

### Grill 第 3 轮（2026-08-11）：各页内部信息架构与工作流

- Q13=A「设置」页信息架构：左侧次级索引（外观 / 布局 / 配置数据 三类），右侧详情；**音频偏好本期不进设置页**（音频页自管，避免配置跨页散落；未来有全局音频偏好时再加"音频"分类）。
- Q14=A「快捷键」页工作流：**导入/导出统一到"设置 → 配置数据"单一入口**，快捷键页只做 搜索 / 点击键位编辑 / 启用·禁用 / 恢复默认；**页顶只读信息区**列出应用级快捷键（切页 `Ctrl/⌘+Shift+1…4` 等，标注"不可编辑"）便于发现；保留**平铺搜索表 + 类别列**（沿用现有交互，改动最小）。
- Q15「音频」页反馈状态：
  1. 导入/解码失败用**内联横幅**就地反馈（文字需醒目，可即时重试）；
  2. 成功仅更新状态、不加 toast（减少打扰）；
  3. **移除页内"返回工作台"按钮**（切页由导航承担），保留"切换到此页自动暂停播放并保留位置"的说明性提示；
  4. 清除音频**不需二次确认**（低风险、可重新导入），但旁加文案说明"清除后需重新导入"。
- Q16=OK 工作台与 issue 22 接口边界：issue 28 只做**页面壳 + 生命周期**（稳定挂载点、隐藏时暂停渲染与输入、离开时自动暂停播放）；工作台内部布局/交互/控件属 issue 22；本期仅依赖工作台"可保活挂载 + `onPausePlayback`"表面契约，**黑盒接入，不触碰其内部状态**。

### 决策修订（覆盖第 2 轮 Q6=B）

- 应用级导航**可折叠且默认折叠**：折叠为 52px 窄图标栏（隐藏标签/快捷键，保留 tooltip），工作台需要时可展开（宽屏 156px）。理由：释放横向空间、缓解工作台工具区偏挤、降低视觉不对称。**原 Q6=B「入口始终可见、不折叠」作废**；"固定顺序、不可关闭/拖动"等其余应用页面语义不变。
