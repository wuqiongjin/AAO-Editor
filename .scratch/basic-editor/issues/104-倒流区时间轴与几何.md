# 104 · 倒流区时间轴与几何（去掉「秒 → 拍」反查依赖）

Type: feature
Status: open
Blocked by: 103

## 来源

[issue 100 负数 BPM 语义](./100-负数BPM语义.md) 定案（2026-09-14），权威 = [ADR-0010](../../../docs/adr/0010-负数BPM与倒流区.md) 结论 3/4/5/10 与 [ADR-0005 §7 修订](../../../docs/adr/0005-显式谱面长度与谱面工程持久化.md)。

## 症状

放行负 BPM 之后（issue 103 完成），**正向渲染链路本来就对**——`perBeatValue = BEAT_HEIGHT·verticalRatio·120/bpm` 与 `60/bpm` 都带符号，负 BPM 下自动折返，与 Bestdori「`pixel = 时间 × pps`」同构。坏掉的全是**反查与单调假设**：

| 位置 | 症状 |
| --- | --- |
| `ChartGeometry.ts` L97 `chartEndVirtualY = positionOfBeat(secondsToBeat(时长))` | 倒流区里 `secondsToBeat` 多值 → 画布高度/虚拟高度错乱 |
| `BpmTimeline.ts` L77-95 `beatOfPosition` | 二分假设 `offsets` 单调 → 落错段，返回值系统性错误 |
| `ChartGeometry.ts` L141-143 `virtualYToBeat` | 鼠标→拍全链路（hover 读数、放置、拖动、命中）错位 |
| `render.ts` L112-117 `visibleBeatRange` | 可见拍区间反查错 → 剔除错 → 该画的没画 |
| `noteLayerCache.ts` L169-177 `invalidateTilesForBeatRange` | L163 注释明写「pos 随 beat 递增」→ 错瓦片失效（复现 issue 36 那个 bug 形态） |
| `PlaybackScrollModel.ts` L72-85 | 依赖秒 ↔ scrollY 严格互逆 |
| `AudioTiming.ts` L99-103 `maxNoteEndSeconds` | 「最大 beat 的秒」≠「最大秒」→ 自动延长谱面长度算错 |
| `Editor.tsx` L74-80 `currentRegionBpm`、`FinalVirtualCanvas.tsx` L1163-1164 `playheadBeat` | 拍号/实时 BPM 取到的解不对 |

## 根因

ADR-0005 §7 曾假定「拍只是一层显示换算」——即秒 ↔ 拍互为可逆单值映射。含倒流区时该假定不成立（ADR-0010 结论 5）。

## 修法

1. **画布高度由秒直出**：`chartEndVirtualY` = 谱面长度（秒）× 同一像素密度系数（= `positionOfBeat` 的斜率），**不再经过 `secondsToBeat`**。
2. **`BpmTimeline` 补正向的按秒接口**：「秒 → 值（布局坐标）」单调、可直接二分；「值 → beat」保留但**必须显式取解**（不再是无条件可逆）——取解口径 = **最大 beat 解**（见修法 8）。
3. **几何/命中/拖动/hover 一律走「拍 → 秒」正向**：把 `virtualYToBeat` 拆成 `virtualYToSeconds`（布局轴直读，hover 秒读数用它）+ 需要拍时显式取解。
4. **`visibleBeatRange` 与瓦片失效改为按元素的布局坐标算范围**（正向逐点求 min/max），不再从 beat 区间反推。
5. **播放滚动改由秒驱动**：`scrollYForSeconds = chartEndVirtualY − 秒 × 像素密度`，反向同理；不经 `secondsToBeat`。
6. **`maxNoteEndSeconds` 改为「布局坐标最大值对应的秒」**（= 全谱最大秒），而非「最大 beat 的秒」。
7. 拍号显示（BPM 实时区 / 判定线拍号）改为按**当前秒所在的时间轴区间**取，不依赖拍反查。
8. **折返重叠区的落点取解 = 「最大 beat 解」**（时间轴上最后一个经过该值的段；2026-09-15 定，与 Bestdori **逐操作等价**）：正 BPM 谱面只有一解、行为完全不变。**作用域**：只作用于「光标 → 拍」的**空白处新增**；**既有音符永远待在自己的层**——它的 beat 是数据，不因光标落在哪一层而变；**拖拽的 Δy→Δ拍 换算锚定"被拖元素自己所在的层"**，因此明确、与实机一致。**已知代价（接受）**：落在折返带内的那些"倒流区之前"的拍（例中 beat 3.5–5）**无法用点击新增**——要放它们走「先画后折」（先放、后插 BPM），与 Bestdori 一致。**不做**层切换 UI。推论：**插入负 BPM 的那一刻，区内已存在的音符会折返跳位**（beat 不变、画布位置变）——这是保真的必然结果，必须保证**一次 undo 可回退**。
9. **曲线工具的两击直放预览必须实时按折返几何显示**——锚点已挂、光标移动时，`previewSpanConnections` 产出的**跨区段烘焙点**要显示折返（不得用单调布局预览、落子才跳）。画笔不再有"带内预览"（跨层直接接续，见 [issue 106](./106-SP画笔点序回折废止.md) 修法 6）。

## 锁测

- `tests/unit/BpmTimeline.test.ts`：含负段的折返值；多值反查的显式取值口径。
- `tests/unit/AudioTiming.test.ts`：带符号 `beatToSeconds` 在倒流区回退；`maxNoteEndSeconds` 取最大秒（构造"最大 beat 的秒 < 中间某拍的秒"用例）。
- `tests/unit/ChartGeometry.test.ts`（或新增）：画布高度 = 谱面长度（秒）× 像素密度。
- **Playwright 像素实测**（响应式/滚动时序单测覆盖不到）：倒流谱滚动可正常滚到底、hover 秒读数连续不跳变、画笔**跨层接续**的实时预览与落子形态逐顶点一致。
- `tests/unit`：折返重叠区取解 = **最大 beat 解**（同一 y 三解 → 取最大者；与 Bestdori 逐操作等价）；插入负 BPM 后**一次 undo 完全回退**。
