## 来源

[issue 100 负数 BPM 语义](./100-负数BPM语义.md) 定案（2026-09-14），权威 = [ADR-0010](../../../docs/adr/0010-负数BPM与倒流区.md) 结论 3/4/5/10 与 [ADR-0005 §7 修订](../../../docs/adr/0005-显式谱面长度与谱面工程持久化.md)。

## 症状

放行负 BPM 之后（issue 103 完成），**正向渲染链路本来就对**——`perBeatValue = BEAT_HEIGHT·verticalRatio·120/bpm` 与 `60/bpm` 都带符号，负 BPM 下自动折返，与 Bestdori「`pixel = 时间 × pps`」同构。坏掉的全是**反查与单调假设**：

| 位置 | 症状 |
| --- | --- |
| `ChartGeometry.ts` L97 `chartEndVirtualY = positionOfBeat(secondsToBeat(时长))` | 倒流区里 `secondsToBeat` 多值 → 画布高度/虚拟高度错乱 |
| `BpmTimeline.ts` L77-95 `beatOfPosition` | 二分假设 `offsets` 单调 → 落错段，返回值系统性错误 |
| `ChartGeometry.ts` L141-143 `virtualYToBeat` | 鼠标→拍全链路（hover 读数、放置、拖动、命中）错位 |
| `render.ts` L112-117 `visibleBeatRange` | 可见拍区间反查错 → 剔除错 → 该画的没画 |
| `noteLayerCache.ts` L169-177 `invalidateTilesForBeatRange` | L163 注释明写「pos 随 beat 递增」→ 错瓦片失效（复现 issue 36 那个 bug 形态） |
| `PlaybackScrollModel.ts` L72-85 | 依赖秒 ↔ scrollY 严格互逆 |
| `AudioTiming.ts` L99-103 `maxNoteEndSeconds` | 「最大 beat 的秒」≠「最大秒」→ 自动延长谱面长度算错 |
| `Editor.tsx` L74-80 `currentRegionBpm`、`FinalVirtualCanvas.tsx` L1163-1164 `playheadBeat` | 拍号/实时 BPM 取到的解不对 |

## 根因

ADR-0005 §7 曾假定「拍只是一层显示换算」——即秒 ↔ 拍互为可逆单值映射。含倒流区时该假定不成立（ADR-0010 结论 5）。

## 修法

1. **画布高度由秒直出**：`chartEndVirtualY` = 谱面长度（秒）× 同一像素密度系数（= `positionOfBeat` 的斜率），**不再经过 `secondsToBeat`**。
2. **`BpmTimeline` 补正向的按秒接口**：「秒 → 值（布局坐标）」单调、可直接二分；「值 → beat」保留但**必须显式取解**（不再是无条件可逆）——取解口径 = **最大 beat 解**（见修法 8）。
3. **几何/命中/拖动/hover 一律走「拍 → 秒」正向**：把 `virtualYToBeat` 拆成 `virtualYToSeconds`（布局轴直读，hover 秒读数用它）+ 需要拍时显式取解。
4. **`visibleBeatRange` 与瓦片失效改为按元素的布局坐标算范围**（正向逐点求 min/max），不再从 beat 区间反推。
5. **播放滚动改由秒驱动**：`scrollYForSeconds = chartEndVirtualY − 秒 × 像素密度`，反向同理；不经 `secondsToBeat`。
6. **`maxNoteEndSeconds` 改为「布局坐标最大值对应的秒」**（= 全谱最大秒），而非「最大 beat 的秒」。
7. 拍号显示（BPM 实时区 / 判定线拍号）改为按**当前秒所在的时间轴区间**取，不依赖拍反查。
8. **折返重叠区的落点取解 = 「最大 beat 解」**（时间轴上最后一个经过该值的段；2026-09-15 定，与 Bestdori **逐操作等价**）：正 BPM 谱面只有一解、行为完全不变。**作用域**：只作用于「光标 → 拍」的**空白处新增**；**既有音符永远待在自己的层**——它的 beat 是数据，不因光标落在哪一层而变；**拖拽的 Δy→Δ拍 换算锚定"被拖元素自己所在的层"**，因此明确、与实机一致。**已知代价（接受）**：落在折返带内的那些"倒流区之前"的拍（例中 beat 3.5–5）**无法用点击新增**——要放它们走「先画后折」（先放、后插 BPM），与 Bestdori 一致。**不做**层切换 UI。推论：**插入负 BPM 的那一刻，区内已存在的音符会折返跳位**（beat 不变、画布位置变）——这是保真的必然结果，必须保证**一次 undo 可回退**。
9. **曲线工具的两击直放预览必须实时按折返几何显示**——锚点已挂、光标移动时，`previewSpanConnections` 产出的**跨区段烘焙点**要显示折返（不得用单调布局预览、落子才跳）。画笔不再有"带内预览"（跨层直接接续，见 [issue 106](./106-SP画笔点序回折废止.md) 修法 6）。

### 2026-09-17 实现（commit 待记）

**开工前与用户确认的三点**

1. **取解接口 = 甲**（评审建议形态）：`BpmTimeline` 出解集（`beatSolutionsOf(pos) → { beat, segmentIndex }[]`）+ 便捷单值 `maxBeatSolutionOf`；秒域糖 `AudioTiming.secondsSolutionsOf`，虚拟域糖 `ChartGeometry.virtualYSolutions` / `virtualYToSeconds`。「层」= **BPM 段序号**，**不给音符新增字段**。
2. **`chartEndBeat` 两处同式重复计算并入本票归一**（画布与滚动模型都改为「传秒、由构造函数派生拍」）。
3. **本轮只交单测 + 静态断言**（Playwright 像素实测三条改为手工验收，见下）。

**实现口径（本轮；语义均来自 ADR-0010 结论 3/4/5/9）**

- `BpmTimeline`（反查单一所有者，`src/chart/geometry/BpmTimeline.ts`）：**删除 `beatOfPosition`**（旧二分假设 `offsets` 单调，倒流区必错），改为
  - `beatSolutionsOf(position)`：段内解析求交，段区间取**半开** `[beatStart, 下一段起点)`（恰在段界的解归后段，与 `positionOfBeat` 同口径、不重复计入）；低于首段/高于末段分别按首/末段斜率外推延续；`perBeat` 为 0 或非有限 → 该段跳过而不是除零。
  - `maxBeatSolutionOf` = 解集末项（无更多上下文时的默认口径）。
  - `segmentIndexAtBeat` / `perBeatOfSegment` / `beatInSegment`（层内换算，段外按该层斜率外推）。
  - `positionRangeOfBeats`（拍区间 → 布局坐标**精确** min/max：折点 = 段起点，故取端点 + 段界极值）与 `beatRangesForPositionRange`（布局坐标区间 → 每段一个**半开**拍区间）。
- `ChartGeometry`（`src/chart/geometry/ChartGeometry.ts`）：
  - 构造函数第二参由 `chartEndBeat` 改为 **`ChartLengthSpec = { seconds } | { endBeat }`**：应用侧一律 `{ seconds }`（`chartEndVirtualY = 秒 × virtualPxPerSecond`，**不经 `secondsToBeat`**）；`{ endBeat }` 只服务测试/工具，语义与旧实现逐位相同（`positionOfBeat(endBeat)`）。
  - 新增 `virtualPxPerSecond = 2·BEAT_HEIGHT·verticalRatio`（**与 bpm 无关的常数**，倒流区也一样）、`chartLengthSeconds`（末端身份，供缓存/重建判定）。
  - `virtualYToSeconds`（布局轴直读）、`virtualYSolutions`、`virtualYToBeat`（= 最大 beat 解）、`layerBeatFromCanvas`（层内换算）、`posRangeOfBounds` / `posRange` / `visibleBeatRanges`。
  - `visibleNotes` 的排序索引由**拍**改为**布局坐标 pos**（滑条按 `positionRangeOfBeats` 求 pos 区间）→ 折返带内各层音符不再被剔掉（旧实现按 beat 窗口反推只留最后一层）。
- `AudioTiming`：`secondsToBeat` = 最大 beat 解；新增 `secondsSolutionsOf`；**删除 `chartLengthToEndBeat`**（两处调用点已归一进几何构造函数）；`maxNoteEndSeconds` 改**全谱最大秒**（逐位置点正向求值取 max，滑条取全部结点——倒流区里末端点未必是最后的秒）。
- `PlaybackScrollModel`（修法 5）：秒 ↔ scrollY 改**纯线性**（`scrollY = chartEndVirtualY − 秒 × 像素密度`），不再借道拍；像素密度为 0 的退化几何给 0 不给 NaN/Infinity。
- `render.ts`：`visibleBeatRange` → **`visibleBeatRanges`**（返回拍区间**集合**，由布局坐标区间正向派生；网格逐区间枚举）；hover 秒读数改 `virtualYToSeconds`（已过音符数仍按最大 beat 解的拍口径，与播放 HUD 同源——拍域定义，本票不改）。
- `noteLayerCache`：拍区间 → pos 区间走 `positionRangeOfBeats`（折返的回落点也纳入失效范围）；`posRangeOf` 委托 `geometry.posRange`；**缓存失效键把 `chartEndBeat` 换成 `chartEndVirtualY`**（静态层与音符层各一处——位图活在 pos 空间，其原点就是它）。
- `Editor.currentRegionBpm`（修法 7）：按当前秒的解集取**末项所在段**的 BPM。
- 拖拽（修法 8）：`DragAnchor` 增 `layerSegment`；按下意图里用 `segmentIndexAtBeat(anchorBeat)` 定层、`layerBeatFromCanvas` 取按下拍位；`dragDelta` 的 `rawCurBeat` 也走 `layerBeatFromCanvas(…, drag.layerSegment)` → Δy→Δ拍 全程同层。
- 末端归一（Q2/修法 1）：`FinalVirtualCanvas` 与 `useScrollModel` 都不再各自反查末端拍，`chartEndBeat` 由 `geometry` 派生（`{ seconds: 谱面长度 }`）；几何复用判定改用 `chartLengthSeconds`。
