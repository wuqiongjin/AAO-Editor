## Question

issue 39 的 #4 色觉辅助需要「虚拍 tap 图标」在 RhythmGameSprites.png 中的坐标，但用户能认出图上哪个是虚拍款、却无法向开发侧报出坐标（现有负百分比偏移坐标系太抽象，用户在图上定位不了音符的实际区域）。用户明确"未来还要做更好的其它音符样式皮肤，也是这种图"——同一痛点会反复出现。

需要一个**精灵图可视化定位工具**：加载 skin 大图，让用户用点选/框选锁定一个音符区域，直接导出该区域可粘贴进注册表的坐标条目。

## 实现概要

独立于谱面制作器本身：同一仓库、独立 HTML 入口，不占主导航、不进主 bundle 依赖图、不随主应用发布。它是 issue 29 路上的内部工具。

### 工具功能

- **图片加载**：下拉预设（4 张皮肤图）+ 本地图片文件输入
- **视图操纵**：滚轮缩放（锚定光标）、空格/中键拖拽平移、自适应缩放
- **选区**：拖拽框选，自动吸附 1px 整数坐标；多选区命名、删除、清空
- **选区微调**：点击激活后，8 向手柄拖拽、方向键 1px / Shift+方向键 10px / Alt+方向键按边缩放、右侧 x/y/w/h 数值输入
- **墨迹（ink）**：选区位于另一选区内部时可勾选「墨迹」，输出时自动折算 inkLeft/inkRight（方向滑键连接线贴合用）
- **输出**：生成与 BaseSpriteIcons 一致的 {x, y, w, h} + 可选 inkLeft/inkRight 代码段，一键复制
- **辅助**：自适应网格（difference 混合反色保证可见）、像素标尺、透明棋盘格、状态栏实时坐标

### 组件状态

- 工具不持久化皮肤数据，只负责「从图上取坐标 → 生成可粘贴条目」
- 输出 `out` 字段（收紧源矩形时的目标屏幕尺寸）按 issue 40 规则另行补写，本工具不生成
- tapVirtual 的具体坐标待用户使用本工具定位后填入
- 发布：`npm run build:release` / `electron:build` 不产出 `sprite-locator.html` 及其 chunk
