# 184 · 片段库：数据层与存储

Type: feature
Status: open
Blocked by:

**来源**：[164 片段收藏](./164-片段收藏.md) 定案 §1 / §2 / §4；权威 = [ADR-0023](../../../docs/adr/0023-片段收藏的载荷与存储边界.md)。拆四刀的第 1 刀，**无 UI**。

**目标**：片段能被采集、命名、持久化、序列化/解析；上层（185 / 186 / 187）只消费，不各自碰数据。

**修法**：

- `src/chart/patterns/types.ts`：`Pattern { id, name, createdAt, notes: ChartNote[], bpmContext: { startBpm, events: { deltaBeat, bpm }[] } }`；库文件 `{ schemaVersion: 1, patterns: Pattern[] }`。
- `capturePattern(notes, selection)`：**复用** `SelectionEditing.copySelection`（形态归一不另写）→ `structuredClone` 后**递归剥 `source`**（音符本体 + 滑条连接点）；`minBeat / maxBeat` 按全部连接点算包围盒；`startBpm` = 按 beat 稳定排序后最后一条 `beat ≤ minBeat` 的 BPM 值；`events` = `(minBeat, maxBeat]` 内的事件、`deltaBeat = beat − minBeat`。
  - 「按 beat 稳定排序取前驱」与 `src/chart/editing/BpmTail.ts` 的「末条」判据同一口径 → **抽一个公共函数**给两边用，不写第二份（ADR-0023 Consequences）。
- 命名：「片段 N」/ "Pattern N"，按**生成时的界面语言**定格（之后切语言不追改，同「副本命名」先例）；N = 库内最大序号 + 1，删除不回收。
- 存储后端 `PatternLibraryBackend { load(): Promise<Pattern[]>; saveAll(patterns): Promise<void> }`（v1 单文件全量；将来分片只换实现），两条路照 `ChartProject.ts` 的 `autoDetectBackend` 先例：
  - **Electron**：数据根下 `patterns.json`。`electron/dataRoot.cjs` 加文件名常量与读写，`electron/preload.js` 新桥 `electronAPI.patternLibrary`（现在只有 `projectStore` / `backgroundSkin` 两条，本票是第三条）。
  - **浏览器**：IndexedDB 新库，单 record 存整份。
- 首次载入：文件不存在 → 空库，**不写盘**（空库不该在用户没收藏过时先造一个文件）；文件损坏 → 回落空库并保留原文件（改名 `.broken` 备份，不静默覆盖）。
- 分享（只做数据层，入口在 187）：`serializePatterns(patterns)` / `parsePatternsFile(text)` → 统一信封 `{ schemaVersion, exportedAt, patterns }`；解析**逐条**校验，坏条目收集成清单随结果返回（不整包失败）；整包 `schemaVersion` 不认识 → 整包拒绝并说明。导入生成新 id（`crypto.randomUUID`）、**允许重名**。

**本轮实现口径（待验收）**：`patterns.json` 的"体量超阈值提示导出备份"阈值初值 5 MB（用户只定了"要提示"，没定数字）。

**锁测**：

- `tests/unit/chart/patterns/PatternCapture.test.ts`（新增）：剥 `source`（音符 + 连接点都剥）、`startBpm` 取前驱（同拍多条取数组序最后）、`events` 恰为 `(minBeat, maxBeat]`、`deltaBeat` 归一、滑条按全部结点算包围盒、空选区不产出。
- `tests/unit/chart/patterns/BpmPredecessor.test.ts`（新增）：新抽的公共排序/前驱函数与 `indexOfTrailingNegativeBpm` 同口径（含同拍多条、beat 非有限条目跳过）。
- `tests/unit/chart/patterns/PatternStore.test.ts`（新增）：两后端 round-trip；Electron 路径正确；文件不存在不落盘；损坏文件 → 空库 + `.broken` 备份且原内容不丢。
- `tests/unit/chart/patterns/PatternShare.test.ts`（新增）：信封 round-trip、版本不认识整包拒绝、坏条目跳过并报数、导入生成新 id、重名不报错。
- 静态锁 `tests/static/PatternBackendWiring.test.ts`（新增）：`autoDetectBackend` 两条实现都被引用、preload 桥已注册。
