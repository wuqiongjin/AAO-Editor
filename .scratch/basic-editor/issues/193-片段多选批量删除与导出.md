# 193 · 片段多选：批量删除 / 批量导出

Type: feature
Status: open
Blocked by:

**来源**：[185 片段库：浏览与收藏](./185-片段库浏览与收藏.md) 已把多选定为「将来单独做『选择模式 + 抽屉底部选区工具条』」；2026-10-31 用户确认本票只做**批量删除 / 批量导出**。

## 范围

- 做：进入 / 退出选择模式、勾选、全选当前搜索结果、批量删除、批量导出。
- 不做：批量置顶、批量移动、文件夹、拖拽排序、拖拽进画布。

## 交互

- **入口**：抽屉头 ⋯ 菜单新增「选择片段」；进入选择模式后，⋯ 菜单项变为「退出选择」或由底部工具条提供退出。
- **退出**：Esc、关闭抽屉、点「取消 / 退出选择」都回到普通浏览态；选中集合清空。
- **卡片**：选择模式下点击卡片 = 勾选 / 取消勾选，**不进入片段粘贴态**；卡片显示勾选标记与勾选态高亮（进入选择模式时已退出片段粘贴态，不再保留粘贴来源高亮）。
  - 名字双击改名在选择模式下禁用；
  - 卡片 ⋯ 菜单在选择模式下禁用 / 隐藏；
  - 只读谱面下卡片仍可勾选（删除 / 导出是片段库操作，不写谱面）。
- **进入选择模式时应退出片段粘贴态**（回指针），避免「点卡片到底是贴还是选」的双重语义；剪贴板不受影响。
- 搜索 / 过滤变化**不清空已选**（按 id 记录）；工具条显示 `已选 N`，若部分选中项不在当前搜索结果中，再显示 `其中 X 条不在当前结果`。

## 底部工具条

选择模式下，footer 的「收藏选区」区域换成选区工具条（退出后恢复原 footer）：

- `已选 N`
- `全选当前结果`
- `导出所选`
- `删除所选`
- `取消 / 清空选择`

没有选中项时：`导出所选` / `删除所选` 置灰。

## 批量删除

- 复用既有 `ConfirmDialog`（`sm` 档），文案带条数：`删除选中的 N 条片段？`，并说明不可恢复。
- 一次操作只走一次 `commit` / 一次整库落盘；失败回滚 + toast（沿用 `usePatternLibrary` 现有写入口径）。
- 成功后清空选择并退出选择模式；不建撤销栈（与 185 单条删除一致）。

## 批量导出

- 仍是 184 的统一信封，`patterns` 里放选中的 N 条；**不新增第二种文件格式**。
- 文件名新增 `aao-patterns-selected-YYYYMMDD.json`（本地日期）；单条导出仍走卡片的「导出片段」与 `<片段名>.aao-pattern.json`。
- Electron 走既有 `electronAPI.patternLibrary.saveAs` 桥，浏览器走 Blob 下载；取消保存 = 什么都不发生。
- 导出的是**当前选中集合的快照**；导出期间库发生改名 / 删除不影响已发出的内容。

## 实现落点

- 抽屉本地状态：`selectionMode: boolean`、`selectedIds: Set<string>`（或等价结构）；选择相关纯函数放 `library.ts` 或单独 `selection.ts`，不散在 JSX。
- `library.ts` 新增批量删除纯函数（或复用 `removePatternFromLibrary` 逐条过滤后一次 commit），确保只写一次。
- `shareFile.ts` 增加批量导出文件名函数；复用 `savePatternsWithFilename`。
- `PatternLibraryMenu` 增加「选择片段」入口；底部工具条新组件（建议 `PatternSelectionBar`）。
- 只读态、`status === 'loading'` / `'error'`：选择模式入口在非 ready 时禁用；只读谱面只影响粘贴，不影响片段库批量操作。
- i18n zh-CN + en。
