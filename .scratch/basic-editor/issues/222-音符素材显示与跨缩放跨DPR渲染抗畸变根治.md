# 222 · 音符素材显示与跨缩放跨DPR渲染抗畸变根治

Type: grilling
Status: resolved (2026-11-08 完成分析、方案定案与代码落地，单元测试 482/482 全绿，全矩阵视觉验收 20/20 达标)
Blocked by:

## 来源

用户 2026-11-08 反馈：
Windows 本地环境下，音符素材显示在缩放比例很大时（300%）与缩放比例较小时（<140%）出现明显边缘瑕疵与模糊破面。
该问题此前多次修复，但在不同尺寸屏幕、刷新率、电脑（DPR/平台）下反反复复复现，要求彻底排查根因并给出长效不再复现的方案。

## 症状

1. **大缩放（300% / es=3.0）**：
   - 方向滑键本体（`note_flick_l`）与外侧小箭头（`note_flick_top_l`）接合处露出本体原厂空心白色圆环，形成破洞；
   - 瓦片 blit 时由于 `imageSmoothingEnabled = false`，在浮点坐标与最近邻采样下，本体右下角出现矩形黑色缺口，上下外轮廓出现阶梯状硬锯齿。
2. **小缩放（<140% / es < 1.4）**：
   - 在 Windows 常见高分屏（DPR=1.25 / 125%）下，当 `es < 1.4` 时，`mipLevelFor` 阶跃进入 Level 2（1/4 图集）；
   - 图集未隔离图元，降采样卷积将图集相邻精灵及残留底色 `rgba(76,105,113,0)` 混入白色高亮描边，导致外轮廓严重发灰、变暗、断裂（Atlas Bleeding）。

## 根因

1. **图集全局 Mipmap 链下采样渗色（Atlas Bleeding）**：
   整张 1024×1024 图集直接生成逐级减半位图，各音符切片间无安全 Padding，背景带深青色杂色，L2 级下采样（4x 步长）导致边缘混色走样。
2. **瓦片 Blit 阶段强制关闭平滑（Nearest Neighbor）**：
   `noteLayerCache.ts` 中 `ctx.imageSmoothingEnabled = false`，在浮点 DPI（125%、150%）或非整数缩放下产生亚像素硬截断与锯齿。
3. **方向滑键接合几何偏差**：
   `noteSkin.ts` 中 `DIR_CHEVRON_INTO_BODY = 3` 过小，小箭头外推过度，暴露出本体原图自带的空心尖角。
4. **历史遗留矩形未收紧**：
   Issue 40 仅收紧了 `tap/flick/skill`，方向键 `dirL/dirR` 保持粗切片，右边缘紧挨深青色背景。
5. **跨环境差异导致反复复现**：
   - macOS（整数 DPR 2.0）下无 subpixel 撕裂，临界点与 Windows（浮点 DPR 1.25/1.5）完全错开；
   - 高刷新率（120Hz/144Hz）下帧预算更紧，瓦片拉伸过渡时在关闭平滑下加剧走样；
   - 缺少全矩阵跨 DPI / 跨缩放的自动化像素级视觉回归测试守卫。

## 定案（用户 2026-11-08 拍板）

1. **图集采样与 Mipmap 隔离策略**：
   - 采纳 **Q1=A**（内存图元切片解耦，带 4px 纯净透明 Padding + 独立 Mip 链）；
   - 彻底阻断图集内相邻图元相互渗色（Atlas Bleeding）与透明背景残留底色污染。
2. **瓦片 Blit 的平滑抗锯齿策略**：
   - 采纳 **Q2=A**（浮点与缩放自适应平滑 Adaptive Smoothing）；
   - 仅在瓦片物理像素与主画布物理像素达到严格 1:1 整数映射时关闭平滑；当处于 Windows 浮点 DPI（125%、150% 等）或存在缩放拉伸时，强制启用 `imageSmoothingEnabled = true` + `high`，消除最近邻采样造成的硬锯齿与右下角小方块。
3. **方向滑键接合几何**：
   - 采纳 **Q3=A**（墨迹完全咬合对齐，`DIR_CHEVRON_INTO_BODY` 调整至 7px）；
   - 小箭头向内咬合完全包裹本体原厂左尖端的空心白圈，恢复实机一体化形态。
4. **长效防复发保证机制**：
   - 采纳 **Q4=A** 与 **Q6=A**（双层视觉守卫体系）；
   - 日常单测运行轻量离屏 Micro-Harness 内存断言（耗时 ~1s，不拖慢日常开发）；
   - 独立提供 `npm run test:visual` 命令，全量输出 Windows 100%、125%、150% 与 macOS 200% 全矩阵快照供目测与 CI 门禁检查。
5. **内存切片生命周期**：
   - 采纳 **Q5=A**（惰性按需切片 + 弱引用 WeakMap 缓存）；
   - 用到什么音符切什么，随源图释放自动 GC，零冷启动开销与显存泄漏风险。
6. **数据源历史遗留债务清理**：
   - 采纳 **Q7=A**（数据源收紧 + 管道清洗双保险）；
   - 在切片解耦时将所有 `alpha=0` 背景重置为纯净 `rgba(0,0,0,0)`。

## 实现落地

1. **切片解耦管线 (`src/ui/spriteDecoupling.ts` & `src/ui/CanvasSpriteIcon.tsx`)**：
   - `CLEAN_PADDING_PX = 4` 安全边距包裹；
   - `cleanTransparentPixels`: 强制重置 `alpha === 0` 像素为 `rgba(0,0,0,0)`，清除图集原厂残留的 24699 个深青色 `(76,105,113)` 杂色像素；
   - `getDecoupledSprite`: 独立 Canvas 提取 + WeakMap 弱引用生命周期；
   - `getDecoupledMipLevel`: 增量单图元下采样链（High 双三次滤波），避免整图卷积互相渗色；
   - `CanvasSpriteIcon.drawSingle`: 优先通过解耦位图与独立 Mip 链绘制，非 DOM / Node 环境安全降级。
2. **瓦片 Blit 自适应平滑 (`src/rendering/pipeline/noteLayerCache.ts`)**：
   - 导出 `shouldEnableTileBlitSmoothing`；
   - 在 DPR 1.25/1.5 等浮点环境或缩放拉伸态（手势中）开启 `imageSmoothingEnabled = true` + `high`；
   - 仅在 1:1 整数无拉伸状态下关闭平滑以保帧率。
3. **方向滑键咬合几何 (`src/rendering/skin/noteSkin.ts` & `src/rendering/primitives/noteGlyph.ts`)**：
   - `DIR_CHEVRON_INTO_BODY: 7`，小箭头深度咬合本体，完美消灭空心白圈漏洞；
   - `glyphBox` 对齐到 4 的整数倍，避免工具栏字形在 1.25x DPR 下掉落半像素台阶。
4. **双层自动化防守卫体系**：
   - **日常单测微断言 (`tests/unit/rendering/NoteVisualMicroHarness.test.ts`)**：~1s 极速覆盖几何咬合、浮点自适应平滑矩阵、透明底色清洗与 Mip 阶跃；
   - **全矩阵快照独立命令 (`scripts/verify-visual.mjs` & `npm run test:visual`)**：~2s 覆盖 DPR 1.0/1.25/1.5/2.0 与缩放 100%/130%/140%/200%/300% 全 20 种排列组合，自动断言接缝连续性、白度纯净度与平滑策略。
