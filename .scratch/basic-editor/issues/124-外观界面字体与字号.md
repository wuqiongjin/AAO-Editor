# 124 · 外观：界面字体与字号

Type: grilling
Status: open
Blocked by: —

## 来源

用户 2026-09-19：设置里要能调 **字体大小**、**字体切换**。与画布「文字大小」(`display.labelScale`) 不是同一件事。

## 定案（用户 2026-09-19）

1. **范围**：只调 **应用 chrome**（导航、内容页、设置、弹窗等）。不改画布标线 `labelScale`，不做整窗界面缩放（不碰内容壳几何常数）。
2. **界面字号**：外观一条百分比滑杆，**80%–120%、步长 10%**，默认 100%；写入设置对象，与主题一同导入导出；只乘现有 `--text-*`。
3. **界面字体栈**（语言中立三档，每档是回退链不是单文件；**不**随界面语言自动切）：
   - Geist + 系统中文回退（出厂，同 issue 49）
   - 微软雅黑
   - Noto Sans / 思源黑体（CJK）（日/韩/繁中混排比雅黑稳）
   - 拉丁靠 Geist 或 Noto 西文。阿拉伯/泰/印地等本票不做（等 122 真要那些语言再加栈）。
4. **等宽**：`--font-mono` **不随字体切换**；字号可以跟 chrome 比例变。

## 本轮实现口径（待验收）

- additive 字段，不 bump `schemaVersion`；缺/脏值回落出厂。
- **不打包** CJK webfont（体积）；第三档用系统已装族名回退链（Noto Sans CJK / Source Han / 思源）。
- 浏览器没有某族名时静默走链上下一档，不弹窗。

## 不做

- 本机已装字体枚举、`locale` 自动换字体、画布音符图标（精灵图）。

## 实现落点

- `AppSettings` + 设置页外观段；`tokens.css` / `documentElement` 上挂字号比例与 sans 栈。
- CONTEXT「界面字体栈 / 界面字号」。

## 锁测

- `mergeSettings`：非法字号夹紧到 0.8..1.2 步长 0.1；未知字体档回落出厂；导入导出带上这两字段。
- 静态：`--font-mono` 不随 sans 预设改写。
- 手工：外观改档立即生效；工作台 chrome 变、画布 BPM 字不随界面字号变。
