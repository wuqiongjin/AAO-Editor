## Question

按 ADR-0004《播放预览交互（判定线模型）》对 ticket 14 的首版播放实现做**交互模型修订**：
- 由"静止谱面 + 移动预览线"改为"判定线固定画布底部 + 谱面随播放上移"；
- 无音频（跳过/无歌曲、或谱面代码导入）也要能"播放谱面"（合成时间线）；
- 临时起点标记 + Ctrl+空格 回跳；
- 键音素材包 KeySoundSet（四类 + 切换 + 持久化 + 占位）；
- 底部播放条承载播放类控件。

## 实现范围（ADR-0004 各节）

- [ ] 判定线模型：FinalVirtualCanvas 播放 RAF 按秒→beat→虚拟 Y 驱动滚动跟随；删除旧移动线；判定线常显。播放中完全锁定滚动、暂停滚动=设播放起点（不自动播），见 ADR-0004 §1 修订。
- [ ] 合成时间线：AudioEngine 双时钟 `getSeconds`（有音频=AudioContext，无音频=performance.now+RAF）；无音频时 canPlay 恒真。
- [ ] 播放时长：有音频=音频长度；无音频=谱面末端（最大 beat 经 BPM 换算 + 1 小节尾量，1 小节=4 拍）；空谱默认 30s；播放条可改（会话级）。虚拟高度按谱面末端动态自适应（滚动条随谱面长度变化、无空白，ADR-0004 §3 修订）。
- [ ] 起点标记：左沟槽双击放置/双击删除/选中后 Delete 删除；单一标记（新设替换旧，ADR-0004 §4 确认）；Ctrl+空格（`jumpToMarker` 新增 FunctionId，默认 ctrl+space，入 ADR-0002 配置面板）跳回并播放。标记状态放 FinalVirtualCanvas 内 + ref 暴露（实现确认）。
- [ ] 底部播放条组件：播放/暂停、时间码、时长编辑（无音频）、音量、素材切换、起点标记提示。
- [ ] 键音素材接口（KeySoundSet`{tap,flick,skill,slide}`）+ 占位实现 + 当前激活素材持久化进 settings（轻量 localStorage `bangdream.settings.v1` 仅存 `audio.keySet`，实现确认）。
- [ ] 播放到终点自动停住、停在当前位置（不循环）。
- [ ] ADR-0002 注册表新增 `jumpToMarker`（默认 ctrl+空格），tooltip/设置面板适配。

## 实测问题（2026-08-09 修订）

- Bug1：播放几秒后谱面停止滚动 → 根因：播放头↔滚动条双向反馈（RAF 写 scrollTop + 回写 setScrollY）自锁。修复：播放中 onScroll 忽略、滚动条只由播放头写、不反向回写。
- Bug2：交互模型改为"暂停滚动=设播放起点（不自动播）、播放中完全锁滚动"（ADR-0004 §1 修订）。
- Bug3：滚动条固定长度、播完有空白 → 虚拟高度按谱面末端动态自适应（ADR-0004 §3 修订）。
- Bug4：确认单一临时标记（新设替换旧）。
