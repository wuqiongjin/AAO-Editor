# 73 · 粘贴越出谱面末端 → 拒绝整组放下

Type: bug（语义已定：三条入口同口径）
Status: resolved（2026-09-10 实现 + 锁测，待你在页面验收）
Blocked by:

## 来源

用户 2026-09-10 清单 #3 前半（后半的"END 之后空白区域"已剥离为 [79](./79-END之后空白区域.md)）。

## 症状 / 现状（代码事实）

`pasteChartNotes`（`src/chart/editing/NoteReplacementRules.ts:566`）只把剪贴板组的包围盒左上角对齐到锚点，
**逐成员不再做末端校验** → 组尾可以越出 END。而另两条入口都有拦截：

- 放置 / 执行键：`snapChartPos` → `isPastChartEnd`（`CanvasGesture.ts:51`）、`canPlaceAtCursor`（:306）；
- 拖拽：`planDragMove` 的 `inBeat`（`NoteDragging.ts:149-152`）。

三条入口口径不一致，只有粘贴漏了。

## 定案（用户 2026-09-10 拍板）

**拒绝整组放下**（任一项越界即整组无事发生）—— 与放置同口径。
用户附理由：「如果你真想把它放下，合理的操作应该是**调整音频时长**，从而延长谱面长度。」

- 落点判据：剪贴板组按锚点平移后，**整组的最大拍位** ≤ `chartEndBeat`（沿用 `CHART_END_EPS`，不得新写一份 epsilon）；
- 越界时：无事发生（不写历史、不清选区/粘贴工具态照旧驻留），给一次 UI 反馈（状态栏/气泡提示"超出谱面长度"）。

## 实现落点

| 文件 | 改动 |
| --- | --- |
| `src/chart/editing/NoteReplacementRules.ts` | `pasteChartNotes` 增 `chartEndBeat` 入参 + `CHART_END_EPS` 组尾校验；越界返回 `{ newNotes: 原引用, written: [], rejected: 'past-end' }` |
| `src/chart/editing/ToolActionMatrix.ts` | `clickOps` 的 paste 行（:180-188）：越界 → 只清选区（与非法落点同档），不 setNotes |
| `src/chart/editing/CanvasGesture.ts` | 从 `isPastChartEnd` 导出/复用同一判据（`CHART_END_EPS` 已是唯一实现） |

## 锁测

- `tests/unit/PasteOverwrite.test.ts`：① 组尾越界 → `newNotes` 引用不变（未写谱）、`written` 为空；
  ② 组尾恰好 = `chartEndBeat + 1e-9` 以内 → 正常粘贴；③ 锚点在界内但组尾越界 → 同样拒绝（防"只校验锚点"回归）。
- `tests/unit/ToolActionMatrix.test.ts`：paste 越界 → 产出 `setSelection: []` 且**无** `setNotes`。
