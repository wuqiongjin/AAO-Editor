# 201 · 回到播放起点更名为标记点体系

Type: chore
Status: resolved
Blocked by:

**来源**：用户需求提出与 grilling 定案（2026-11-01）：
当前界面中的“回到播放起点”文案极易让用户误解为“回到谱面 0:00 最开头”，而其实际语义是跳转至画布上双击放置的临时播放标记旗标并起播（代码对应 `jumpToMarker`）。为了消除概念混淆，需全链路更名为清晰、专业的“标记点”体系。

## 范围

- 做：
  1. **快捷键系统文案**：`shortcut.fn.jumpToMarker` 重命名为 `回到标记点并播放`。
  2. **播放条徽标文案**：播放条时间码旁的标记跳转按钮 Tooltip 与无障碍标签同步更新为 `跳转到标记点并播放`；设置面板开关名称更新为 `显示标记点跳转按钮`。
  3. **画布标记交互提示**：旗标双击删除提示与无障碍说明更新为 `标记点，双击删除`。
  4. **英文本地化全量对齐**：`Jump to playback start` 同步更新为 `Jump to marker and play` / `Jump to marker`。
  5. **测试与静态断言修正**：更新项目中涉及旧文案断言的静态与单元测试。
- 不做：
  - 不变更代码底层的标识符与方法名（如 `jumpToMarker`、`PlaybackMarker`、`markerSeconds` 保持不变，避免不必要的底层破坏性重命名）；
  - 不改变“跳到标记点后立即开始播放”的核心交互行为。
