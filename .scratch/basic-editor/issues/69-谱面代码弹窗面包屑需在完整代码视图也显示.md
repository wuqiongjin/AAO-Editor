## 症状

面包屑只在**对象视图**（note 整条音符 / node 滑条结点）显示；**完整谱面代码视图**只有一个
`<h3>` 标题、无面包屑。用户从 node → 点"所属滑条" → note → 点"完整谱面代码" → chart 后，
画面上完全没有任何层级指示，**也再也回不去** note/node（这才是痛点，不只是"没有面包屑"）。

## 定案（用户 2026-09-09 拍板）

- **永远显示面包屑**（三个视图都有）；
- **顺序不变**（`完整谱面代码 › 所属滑条 › 滑条结点代码`）；
- **不加"‹ 返回"按钮** —— 切换能力由面包屑项本身承担；
- 切换层级时**能显示出当前在哪个层级**（末项加粗、不可点）；
- **用户可以随意切换这几个层级**。

## ⚠️ 一次返工：首版只改了皮，没解决"回不去"

首版（用户复报"没有任何变化"）：仅把 chart view 的 `<h3>谱面代码编辑器</h3>` 换成一行
面包屑文字 `完整谱面代码`。**实测确认改动确实生效**（旧标题出现 0 次、新面包屑出现 1 次），
但**功能上零变化** —— 没记住用户去过的深层，从 chart 依然回不到 note/node。

> 教训：**"永远显示面包屑"的落点是"回得去"**，不是"每个视图都摆一行字"。
> 面包屑天然只能向上（chart ← note ← node），要向下回深层必须记录历史。

## 定案实现：trail（记住最近进入的深层）

`ChartCodeEditorProvider` 增 `trail: NoteCodeTarget | null` = 最近一次**从画布进入**的深层对象。

| 方法 | 行为 | 调用方 |
| --- | --- | --- |
| `openNoteCode(t)` | 设 target **并记录 trail** | 外部入口：画布点击 / 音符代码工具 / Ctrl+B |
| `openChartCode()` | 设 target = chart，**清空 trail**（新会话） | 外部入口：工具栏「谱面代码」按钮 |
| `navigate(t)` | **只切 target，不动 trail** | **面包屑内部导航** |
| `close()` | target + trail 一起清 | 关闭弹窗 |

> `navigate` 与 `openNoteCode` 必须分开：若面包屑点"所属滑条"走了 `openNoteCode`，
> 会把 trail 的 `connIndex` 抹掉 → 用户再也点不回那个结点（trail 的意义正是"记住最深那次"）。

**档位由 trail 决定，而非当前视图** —— 于是从 node 一路点回 chart 后，
「所属滑条 / 滑条结点代码」两档**仍在且可点**：

| 当前视图 | 面包屑（粗体=当前层，不可点；其余可点） |
| --- | --- |
| chart（trail 空） | **完整谱面代码** |
| chart（trail=note） | **完整谱面代码** › 音符代码 |
| chart（trail=node） | **完整谱面代码** › 所属滑条 › 滑条结点代码 |
| note（trail=node） | 完整谱面代码 › **所属滑条** › 滑条结点代码 |
| node（trail=node） | 完整谱面代码 › 所属滑条 › **滑条结点代码** |

第 2 档文案：`trail.connIndex !== undefined ? '所属滑条' : '音符代码'`。

## 实现落点

| 文件 | 改动 |
| --- | --- |
| `src/chart/components/code-editor/ChartCodeEditorProvider.tsx` | 增 `trail` state + `navigate()`；`openNoteCode` 记 trail、`openChartCode`/`close` 清 trail |

## 验收（Playwright 实测，2026-09-09）

放一个单键 → 音符代码工具点开 → 面包屑导航，实测轨迹：

```
[3] note view : btn_chart='完整谱面代码'(可点)   → 第2档是当前层

[5] 点回后    : btn_chart='完整谱面代码'(可点)   → ★ 成功回到 note view
```
