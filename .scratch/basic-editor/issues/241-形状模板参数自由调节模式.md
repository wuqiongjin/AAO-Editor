# 241 形状模板参数自由调节模式

- **Type**: grilling
- **Status**: resolved（定案于 grill-with-docs 2026-11-21；已实现并锁测）
- **关联**: [ADR-0009](../../../docs/adr/0009-SP绿条与段曲线模型.md) · [CONTEXT.md](../../../CONTEXT.md) · 前置 [235](./235-曲线工具形状模板扩充与图形化选型.md) · [240](./240-形状模板阶梯端点插值与专属配置项.md)

## 来源

用户在 [240](./240-形状模板阶梯端点插值与专属配置项.md) 落地后提出进一步诉求，发起 `/grill-with-docs` 拍板：
1. 在保留当前简洁、快捷的按钮档位选择（作为默认形态）的前提下，增加可来回切换的**自由调节模式**，让连续数值型模板配置项（幅度、段密、数值型专属选项等）能够更加自由灵活地调整；
2. 自由调节模式下的可调范围允许**超出既有档位按钮边界**（例如段密可以比「稀疏 0.5×」更稀疏、比「稠密 2×」更密集；幅度同理）。

经 Q1–Q10 三轮 `grilling` 访谈与场景推演，全部边界与语义已于 2026-11-21 由用户确认拍板，frontier 为空。

---

## 现状与根因

1. **枚举白名单封死了自由数值持久化（`src/chart/editing/CurveTool.ts`）**：
   - `normalizeCurveConfig` 使用 `pickEnum(TEMPLATE_SCALES, ...)` 与 `pickEnum(TEMPLATE_DENSITIES, ...)` 校验 `templateScale` / `templateDensity`，任何非 `[0.5, 1, 1.5]` 或 `[0.5, 1, 2]` 的值都会被回落成 `1`；
   - `CurveConfig` 尚未记录模板参数模式开关（`templateParamMode`）。
2. **部分模板硬上限过紧（`src/chart/editing/ShapeTemplates.ts`）**：
   - 虽有全局分段点数预算 `TEMPLATE_SEGMENTED_MAX_POINTS = 256`，但 `pulse` 与 `step` 写死了 `Math.min(24, ...)`，`gluten-saw / chain-square / chain-alt` 写死了 `Math.min(96, ...)`；放开高段密（至 `4×`）后，常见 2–4 拍段会在远低于 256 点时被提前截停。
3. **UI 与胶囊摘要仅支持离散预设（`src/pages/workspace/CurveConfigPanel.tsx`、`curveLabels.ts`）**：
   - 面板所有参数行均硬编码为固定胶囊按钮（连底层已为 `0–100` 数值型的 `pulsePos` 也仅露出 3 按钮）；
   - `curveConfigSummary` 直接按 `SCALE_KEYS` / `DENSITY_KEYS` 查表，非预设数值会错误回退为 `中` / `标准`。

## 定案（Q1–Q10 全量汇总，用户 2026-11-21 拍板）

1. **Q5（领域术语定名，已入 `CONTEXT.md`）= A**：
   - 规范称呼：**模板参数模式**（`Template param mode`），包含 **档位模式**（Preset mode，默认）与 **自由调节**（Free-adjust mode）。界面短文案：`档位` | `自由`。避免与「自由段」「自定义模板」混称。
2. **Q1（模式切换粒度与位置）= A（2026-11-21 二次验收：上提至胶囊展开顶栏，分类改为无边框 Tab）**：
   - **模板级总开关**：不是底部配置项。展开态且当前为形状模板时，放在胶囊顶栏右侧，与 `[曲线] · 预览 · 主名 · chevron` 同一行；同屏双段常显 `档位 | 自由`（默认档位，点未选中段切换）。折叠态不显示。缓动函数页不显示。开合仍点胶囊本体任意处；模式开关独立于开合按钮，点击不折叠。
   - **分类筛选**：形状模板页改为无边框单行 Tab（选中下划线），独占一行，不再与模式开关共用胶囊样式或同一行。
   - 切到 `自由` 后，当前模板所有**连续数值项**统一切换为自由控件；离散项保持按钮不变。
3. **Q2（参与自由调节的配置项边界）= A**：
   - **参与自由调节**：**幅度**（`templateScale`）、**段密**（`templateDensity`）、所有 `kind: 'range'` 的**模板专属数值项**（当前为 `pulse.pulsePos`，未来新模板同类专属项自动继承）。
   - **保持按钮不变**：**偏向**（左偏/右偏）、`kind: 'choice'` 专属项（如 `step.stepStyle` 斜坡/直角）、以及**采样精度**（`1/16` / `1/32` / `1/64`，守住 ADR-0009 §3 不牵连画笔采样步长与谱面体积）。
4. **Q3（来回切换的数值语义与记忆策略）= 1a + 2a**：
   - **1a（只切控件、不改生效值）**：切换模式仅改变输入控件形态，绝不静默篡改当前数值；在自由调节下调出非预设值（如 `3.5×`）后切回档位模式，`3.5×` 继续生效，该行档位按钮全处于未高亮态，点击任意一档按钮时才覆盖回该档值。
   - **2a（全局持久化）**：模式开关随 `CurveConfig.templateParamMode`（`'preset' | 'free'`，出厂默认 `'preset'`）持久化于 `settings.curve`，不升 `schemaVersion`。
5. **Q4 + Q10（自由模式控件形态与复位交互，精简后）**：
   - 每个自由调节行采用 **滑块 + 可直接输入的紧凑数值框**（失焦 / 回车提交，自动按 `[min, max]` 钳制并规整小数，Esc 取消当前编辑而不误关闭整个胶囊）；
   - **复位方式（无独立重置按钮）**：双击各行标签或滑块复位该项默认值（`1×` / `50%`），或在档位模式下点击对应预设按钮。
6. **Q6（自由参数数值范围与步长）= A**：
   - 滑块与数值框共用同一合法范围（含 `normalizeCurveConfig` 持久化校验钳制）：
     - **幅度（`templateScale`）**：`0.1× – 3.0×`，滑块步长 `0.05`（数值框允许两位小数）；
     - **段密（`templateDensity`）**：`0.25× – 4.0×`，滑块步长 `0.05`（数值框允许两位小数）；
     - **尖刺位置（`pulsePos`）**：`0% – 100%`，步长 `1%`（未来新 `range` 专属项各自在 `TemplateExtraParamSpec` 中声明范围与步长）。
7. **Q7（高段密单段点数上限护栏）= A**：
   - 守住全模板单段 **`≤ 256` hidden 点**（`TEMPLATE_SEGMENTED_MAX_POINTS = 256`）总安全红线；
   - 将过紧的模板小上限按 256 点预算对齐松绑：`pulse` 上限 `24 → 80` 周期（≤240 点）、`step` 上限 `24 → 120` 级（≤240 点）、`gluten-saw / chain-square / chain-alt` 上限 `96 → 128` 循环（≤256 点）。
8. **Q8（超大振幅 SVG 缩略图预览）= A**：
   - 维持 `buildTemplateSvgPath` 当前 `1×` 固定基准比例 + 卡片边缘钳制，不动态缩放视图；`> 1.5×` 贴边削平直观反映画布 `0..6` 轨贴墙效果。
9. **Q9（胶囊摘要与档位模式非预设值表现，精简后；二次验收按开合分文案）**：
   - **1b（折叠态摘要随模式一致）**：
     - **自由调节模式**：所有连续数值项统一按数值展示（如 `震动条 · 右偏 · 1× · 1×`、`尖刺 · 右偏 · 1.25× · 3.5× · 25%`），拖动滑块零闪烁且收起态可直观辨识模式；
     - **档位模式**：命中预设值显示档位词（`小/中/大`、`稀疏/标准/稠密`），若当前生效着非预设值则直接显示数值（如 `震动条 · 右偏 · 中 · 3.5×`）。
   - **展开态顶栏**：形状模板只留模板主名（如 `面筋·斜纹`），参数已在面板内，避免与右侧 `档位 | 自由` 抢宽；缓动页仍显示 `族 · 型 · 精度`。折叠后恢复 1b 完整拼接。
   - **档位模式行内表现（无多余徽章）**：切回档位模式时，若某连续项当前值未命中任何档位按钮，仅保持该行几个档位按钮均为未选中态（不额外在按钮右侧加数值小徽章）。

## 实现落点

1. **范围常量、上限对齐与纯函数（`src/chart/editing/ShapeTemplates.ts`）**：
   - 导出自由范围与步长常量（`TEMPLATE_SCALE_RANGE = { min: 0.1, max: 3, step: 0.05 }`、`TEMPLATE_DENSITY_RANGE = { min: 0.25, max: 4, step: 0.05 }`）与统一规整/钳制工具函数；
   - 松绑 `pulse`（80）、`step`（120）、`gluten-saw / chain-square / chain-alt`（128）上限，全部严格保证单段产出 `≤ TEMPLATE_SEGMENTED_MAX_POINTS`（256）。
2. **配置模型与持久化归一化（`src/chart/editing/CurveTool.ts`）**：
   - `CurveConfig` 新增 `templateParamMode?: 'preset' | 'free'`（`DEFAULT_CURVE_CONFIG` 默认 `'preset'`）；
   - `normalizeCurveConfig` 将 `templateScale` / `templateDensity` 校验从 `pickEnum` 升级为有限数值范围钳制（保留两位小数规整，向后 100% 兼容既有 `0.5/1/1.5` 与 `0.5/1/2`），并白名单校验 `templateParamMode`。
3. **胶囊摘要格式化（`src/pages/workspace/curveLabels.ts`）**：
   - 统一数值格式化（去多余尾零，如 `1.00 → 1×`、`1.25 → 1.25×`、`3.50 → 3.5×`）；
   - `curveConfigSummary` 按 `templateParamMode` 实现 Q9=1b 规则（自由模式全数值；档位模式命中显示词、非预设显示数值）。
4. **面板 UI、控件与键盘交互（`src/pages/workspace/CurveOptionsCapsule.tsx`、`CurveConfigPanel.tsx`、`CurveConfigPanel.css`、`src/pages/workspace/useCanvasCapsule.ts`）**：
   - 展开态形状模板：胶囊顶栏右侧双段 `档位 | 自由`（`CurveOptionsCapsule`）；分类为无边框 Tab；不占参数区行、不放「参数」标题或「重置」按钮；折叠态不显示模式开关；
   - 新增通用 `FreeRangeRow`（标签 + `<input type="range">` + 可编辑紧凑数值框 + 单位后缀 `×` / `%`，支持双击标签/滑块单行复位、回车/失焦提交、Esc 撤销输入框草稿且 `stopPropagation` 不关闭整个胶囊）；
   - 档位模式下，未命中预设按钮的连续项仅保持档位按钮全不高亮（不渲染行内徽章）；
   - 自由模式下，`幅度`、`段密` 与 `kind: 'range'` 专属项（`pulsePos` 等）统一切换为 `FreeRangeRow`；`偏向`、`精度`、`kind: 'choice'` 保持按钮不变。
5. **双语词典（`src/i18n/messages/zh-CN.json`、`src/i18n/messages/en.json`）**：
   - 补齐 `档位` / `自由` 模式切换及双击复位提示等中英文词条。

1. **模板上限与数值规整单测（`tests/unit/chart/editing/ShapeTemplates.test.ts`）**：

   - `pulsePos` 任意中间整数值（如 `15%`、`25%`、`75%`）在烘焙与重投影中完整保真。
2. **配置归一化与胶囊摘要单测（`tests/unit/chart/editing/CurveTool.test.ts`、`CurveLabels.test.ts` 或对应测试）**：
   - `normalizeCurveConfig` 保留合法连续值（`0.25`、`1.35`、`3.0`、`4.0`）、钳制越界值（`< 0.1` / `> 3`、`< 0.25` / `> 4`）、非法值回落 `1`，且正确处理 `templateParamMode`（缺省回落 `'preset'`）；
   - `curveConfigSummary` 锁住 Q9=1b：自由模式下 `1` / `2` 输出 `1×` / `2×`；档位模式下 `1` / `2` 输出 `中` / `稠密`、非预设 `3.5` 输出 `3.5×`。
3. **面板 DOM 交互测试（`tests/dom/workspace/CurveOptionsCapsule.test.tsx`）**：
   - 展开且形状模板：顶栏双段 `档位 | 自由` 同屏、默认档位；点模式开关不折叠胶囊；缓动页无此开关（从模板切回缓动后消失，顶栏恢复 `族 · 型 · 精度`）；点击 `自由` 后 `幅度`、`段密`、`pulsePos` 切换为滑块 + 数值框，`偏向`、`阶跃形态`、`精度` 保持按钮，且不存在「重置」钮；展开顶栏只留模板主名，折叠恢复完整摘要；
   - 自由模式下拖动滑块或手输合法/越界数值（失焦/回车）实时更新配置与 SVG 预览；在输入框内按 `Esc` 还原草稿且不关闭整个胶囊；
   - 自由模式调出 `3.5×` 后切回 `档位` 模式：`3.5×` 继续生效、三枚按钮全不高亮且无多余行内徽章；点击「标准」按钮立即覆盖回 `1`；
   - 双击单行标签/滑块仅复位该项（其它连续项与 `偏向`/`阶跃形态` 不受影响）。
