# 88 · 持工具态下，单击「选区内的音符」应把该工具动作作用于整片选区

Type: grilling（会改 ADR-0008 §2 原则 6 与单击矩阵；细化项已在本票拍板）
Status: resolved（2026-09-11 实现 + 锁测，待你在页面验收）
Blocked by:

## 来源

用户 2026-09-11：框选一堆音符后切到其它工具（**切工具本身不清选区** = issue 83 定案），
此时新工具若点在**被框选的那些音符之一**上，应把该工具的动作作用于**整片选区**；
现状只作用于"被点的那一个"（删除 / 镜像只删 / 镜 1 个）。

## 核心原则（用户 2026-09-11）

> 「先框选，再单击选区内音符」与「先切到该工具的持工具态，再框选」是同一件事的两种先后顺序，
> **它们的表现应该要一样的**！代码理论上也可以复用的吧？

口径 accordingly：**单击路径直接复用框选矩阵**（`boxSelectOps` 的**同一行**），不另写一套 ——
框选行为怎么改，单击路径自动跟随。

## 定案

**触发条件**：命中项 ∈ 当前选区（`sameSelectionItem` 口径，含滑条结点 / 区域）。
- 点**选区外**音符 → **维持 issue 83 现状**（清空旧选区 + 只作用于被点那一个）。
- §2 原则 6「非指针态单击画布 = 清空选区」的**新例外**：这一击被选区消费 → 不清，清不清由动作自身决定。
- 不设"选区 ≥2"门槛（选区只有 1 件时两条路径结果等价；滑条则因来源 <2 自然回落）。

| 工具 | 单击「选区内音符」⇒ | 口径来源 |
| --- | --- | --- |
| 删除 | 整片删除 + 清选区 | = 删除框选（`boxSelectOps` 同一行） |
| 镜像 | 整片镜像，选区 = 镜像产物 | = 镜像框选 |
| 5 个键型（单键 / 滑键 / 技能 / 左滑 / 右滑） | 整片批量换型：`batchApplyKeyType` → ADR-0001 替换规则（滑条结点拆条 / 端点标记覆盖 / **方向键 length+1、到 3 回 1**），不可替换的跳过，选区 remap 保留 | = 键型框选（用户强调：替换规则 + 方向键延长规则） |
| 滑条 | 整片组合（`combineOps`，§4；**同拍横向照常合法**）；来源 <2 → 不组合、回落两击直放（挂锚点 / 成条） | = Slide 框选（用户 2026-09-11） |
| BPM / 粘贴 / 音符代码 | **不适用，维持现状**（栅格位放线 / 作用于位置 / 弹窗单例） | 用户 2026-09-11 同意 |
| 指针 | 不适用（选区语义本身） | — |
| **右键删除**（issue 74 通路） | 命中 ∈ 选区 → 整片删除（BPM 整线命中同理）；选区外 → 只删那一个 | 用户 2026-09-11 补充 |

**执行键不在本例外内**：`Ctrl+F/G/A/S/D` / `Ctrl+V` 是"光标处放置 / 粘贴"，与"点了哪个音符"无关。

## 根因（改前）

- `ToolActionMatrix.clickOps` **收不到选区**（`ClickInput` 无 `selectedItems`），动作族只吃命中项
  （`actionOnItemOps` 内部 `sel = [hit]`）；键型行也只作用于"被点那个音符"的栅格位。
- `CanvasGesture.resolveClickPlan` 的"需要命中"集合只有 delete / mirror / noteCode
  → 键型 / Slide 单击路径根本没有 hit，谈不上"命中 ∈ 选区"。

## 实现落点

| 文件 | 改动 |
| --- | --- |
| `src/chart/editing/ToolActionMatrix.ts` | `ClickInput` 增 `selectedItems`；命中 ∈ 选区 → 键型 / 动作族直接 `return boxSelectOps(tool, notes, selectedItems)`，Slide 行 `combineOps`；另新增 `resolveActionTargets(hit, selectedItems)` + `actionOnTargetsOps(tool, notes, targets)`（供右键删除与 BPM 删除例外复用） |
| `src/chart/editing/CanvasGesture.ts` | "需要命中"集合抽成 `NEEDS_HIT`，扩到键型 + Slide（原来只有 delete / mirror / noteCode） |
| `src/chart/components/canvas/FinalVirtualCanvas.tsx` | 四处 `clickOps(...)` 补 `selectedItems`；`rightClickDelete` 改走 `actionOnTargetsOps('delete', …, resolveActionTargets(hit, selectedItems))`（与单击删除同源） |
| `docs/adr/0008-工具交互机制.md` | §2 原则 6 增**例外⑥**（命中 ∈ 选区 → 整片执行且不清选区）；单击语义矩阵三行（键型 / Slide / 删除镜像）补注 + 表后新增整段说明（逐工具口径 / 不适用清单 / 执行键不在本例外内） |

## 锁测

`tests/unit/ToolActionMatrix.test.ts` 新增 `describe('issue 88 命中 ∈ 选区 → 整片执行')`：

- **等价性锁（本票核心）**：参数化 flick / delete / mirror / slide（**含同拍横向**），断言
  `clickOps(命中 ∈ 选区)` 与 `boxSelectOps(同一选区)` 的 op 序列**全等**，且真的有 op ——
  把"两个先后顺序恒等"钉成不变量；
- 逐条：`resolveActionTargets` 三态 / 删除整片 + 清选区 / 镜像整片且选区 = 产物 / 命中在选区外维持 issue 83 /
  **右键删除同源整片** / 键型整片换型（选区外不动 + remap 保留）/ **方向键延长规则 length+1、3→1** /
  整片无落点 → 无 op / Slide 整片组合 + 清选区 + 清锚点 / **来源 <2 回落两击直放** / 粘贴不参与整片。

`tests/unit/CanvasGesture.test.ts`：键型原断言"不吃音符命中"改写为"吃命中"，新增 Slide 吃命中、
BPM / 粘贴不吃命中。

## 明确不做

- 执行键 `Ctrl+F/G/A/S/D`、`Ctrl+V` 仍传 `hit: null`。
- 框选路径（`boxSelectOps` / `combineOps`）保持原样（同拍横向合法），不受单击路径影响。
