## 迁移三刀

1. **骨架 + snapshot 出口**：`GestureSession` 落地，五个渲染镜像 state 改由 snapshot 驱动；内核暂未接管任何 handler（行为零变化）。
2. **搬拖拽 / 框选 / 视口重算**：`begin` / `move` / `end` 接管这两类手势 + `onViewportChange`；`selectionStartRef` / `selectionMovedRef` / `marqueeCursorRef` / `dragCursorRef` / `dragFrozenRef` / `gestureCancelledRef` 迁入内核。
3. **搬画笔 + Esc ②档 + 收窄句柄**：画笔编排迁入；`cancelActiveGesture` 改为内核方法；删 `getCursorChartPos` / `setMarkerBeat`。

## 不变量

继承 issue 70「不变量」节 17 条，逐条核销；**第 13 条按 ADR-0008 §7（2026-09-16 修订）更新为五档链**（进行中手势 → 锚点 → 选区 → 工具态）。新增：
