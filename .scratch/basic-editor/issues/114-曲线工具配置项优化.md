## 定案（用户 2026-09-16，两轮拍板）

| # | 定案 |
| --- | --- |
| 1 | 曲线工具图标 = **真实 SP 带材质**（`slideBandSp` / `longNoteLine2`）画的**裸带**，**无端点**；size **28**，与六枚音符图标同视觉重量；随皮肤联动 |
| 2 | 曲线配置持久化到 **`settings.curve`**（全局一份、跨会话沿用上次值）；**不进谱面工程**；四项（族/型/精度/模板）全记 |
| 3 | 面板展开序改为 **缓动族 → 缓动型 → 采样精度 → 形状模板**；选模板时上方三项**保持 disabled**（不改隐藏、不做模式切换器） |
| 4 | 模板下拉 null 项措辞 = **「不使用模板」**（不写「自定义」，留给未来的用户自建模板） |
| 5 | 缓动族命名 = **`Sine（正弦）`**（英文 id 首字母大写 + 全角括号中文）；**不引入 i18n**；族名中英映射从 `Toolbar.tsx` 收回 `Easing.ts` 旁 |
| 6 | 默认型 **`In-Out → In`**；默认族仍 `Sine` |
| 7 | 精度**保持三档** 1/16 / 1/32 / 1/64（不加档）；「模板也吃精度」**复核否决**（模板点列即采样、密度固定；结论落 ADR-0009 §2.3 / §6） |
| 8 | **删除画笔圆滑**：`CurveConfig.smooth` / `smoothPenLanes` / `smoothedPenSamples` / 面板复选框 / 描述文字 / 对应单测，全删 |

**两处超出定案字面的实现口径（待验收，可推翻）**：

1. **缓动型也加了中文**：`In（缓入）` / `Out（缓出）` / `In-Out（缓入缓出）` / `Out-In（缓出缓入）`。定案只说了族要 `Sine（正弦）`；型原本是纯字母，加上去是为了跟族一致、也方便不懂 In/Out 的用户。**不想要的话删 `EASING_TYPE_LABELS` 的括号部分即可**。
2. **曲线图标的带宽收缩到滑条带宽的 0.62**（`CURVE_BAND_WIDTH_RATIO`）：不收缩的话带子横向吃满 28px 方框，弯了也看不出来；腾出的余量就是 S 形摆幅（28px 下摆幅 ≈ ±6.3px、带宽 ≈ 13.4px）。这是**目测调参**，你看过觉得弯得太夸张/太含蓄，直接调这个系数。

**手工验收清单**（单测拿不到像素）：
- [ ] 工具栏曲线图标：是一段**弯的绿带**、**无端点**、与其余音符图标**同大小**、换肤后跟着变
- [ ] 曲线配置：改一项 → 刷新页面 → 仍是改后的值
- [ ] 面板顺序：缓动族 → 缓动型 → 采样精度 → 形状模板；选模板后上三项置灰
- [ ] 面板里搜不到"画笔圆滑"
