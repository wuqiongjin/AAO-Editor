# 251 · 谱面画布幽灵预览不跟随节奏图示大小

Type: bug
Status: resolved（待页面验收）

## 来源与症状

用户 2026-11-24 报：调「节奏图示大小」后已放置音符跟着变，幽灵预览除滑条「段」外都不跟（单键/滑键/技能/方向键、滑条结点、拖拽/镜像/粘贴）。

## 根因

ADR-0002 §4 幽灵 = 实绘同形。实绘 `spriteScale = viewport.scale × noteSize`；幽灵 `renderSpriteGhost` / 滑键挂件 / 方向键组只乘了 `viewport.scale`。段走 `renderSpanBands`，所以只有段跟着变。

## 本轮实现口径（待验收）

幽灵图标与挂件改走 `noteSpriteScale`（与实绘同一函数）。方向键轨距仍只跟视口 scale。段带宽原本已乘，未改。

## 锁测

`tests/unit/rendering/render/GhostPreview.test.ts` `幽灵尺寸随节奏图示大小（issue 251）`：5 例，noteSize 2× 时单键/滑键挂件/方向键/滑条端点幽灵 scale 翻倍且与 `renderNotes` 同值；段 `canvasWidth` 仍随 noteSize。

## Answer

幽灵漏乘 `noteSize`。改走 `noteSpriteScale`。锁测 5 条全绿。
