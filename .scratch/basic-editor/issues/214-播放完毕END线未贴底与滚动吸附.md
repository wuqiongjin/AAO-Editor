# 214 · 播放完毕END线未贴底与滚动吸附

Type: bug
Status: resolved

## 来源

用户反馈：
谱面画布播放完毕后，END线不是完全贴合到最下面的，此时如果使用"滚轮继续滚动"或者"使用右侧的滚动条继续滚动"，会发现END线能继续移动直到贴合到最下面（距离最下面就一点点的缝隙）。

## 症状与根因

1. **播放自然终止帧未推送画布终态坐标（主因）**：
   - 在 [usePlaybackCoordinator.ts](file:///d:/Company/WorkSpace/MocaCoffee/bangdream-editor/src/playback/usePlaybackCoordinator.ts#L121) 的播放 rAF 循环中：
     ```typescript
     if (current >= durationRef.current) {
       setCurrentSeconds(current);
       stopPlayback();
       return;
     }
     ```
   - 当 `current >= durationRef.current` 命中播放结束条件时，直接调用 `stopPlayback()` 并提前 `return`，**跳过了本帧的 `canvas.setScrollY(scrollY)`**，画布未能接收到播放终点的精确坐标。
2. **`stopPlayback()` 仅同步更新了 DOM 滚动条，漏更新画布并提前冻结视口（主因）**：
   - 在 `stopPlayback()` 实现中：
     ```typescript
     canvasRef.current?.setPlaybackActive?.(false);
     ...
     const { scrollTop } = scrollModel.scrollTargetForSeconds(sec, maxScroll);
     if (Math.abs(scrollTop - container.scrollTop) > 0.5) {
       container.scrollTop = scrollTop;
     }
     ```
   - 存在两个关键断层：
     1. 首先调用了 `setPlaybackActive(false)`，该方法将当前 `scrollYRef.current`（仍停留在倒数第二帧未完成播放时的位置）直接同步回 React 视口状态 `viewport.scrollY` 并固化；
     2. 随后虽然以 `sec` 计算了 `scrollTargetForSeconds`，但解构时仅提取了 `{ scrollTop }`，**完全没有调用 `canvasRef.current?.setScrollY(scrollY)`**。
3. **坐标残留机理与触碰滚动条补齐现象**：
   - 根据 [ChartGeometry.ts](file:///d:/Company/WorkSpace/MocaCoffee/bangdream-editor/src/chart/geometry/ChartGeometry.ts#L125) 与 [render.ts](file:///d:/Company/WorkSpace/MocaCoffee/bangdream-editor/src/rendering/render.ts#L1648)，END 线的绘制位置为 `canvasY = (virtualY - scrollY) * es = surface.h - scrollY * es`。
   - 只有当 `scrollY === 0` 时，END 线才严格贴合在 `canvasY = surface.h`（画布判定线/最底部）。
   - 由于自然终止帧漏更画布，`scrollYRef.current` 停留在终点前最后一帧（例如 60Hz 下约提前 16ms，对应约 7px 的高度缝隙）。
   - 此时外部 DOM 滚动容器已被 `stopPlayback()` 写入了 `scrollTop = 0`。
   - 一旦用户移动滚轮或拖动右侧滚动条，DOM 容器的 `onScroll` 事件触发 `onScrollbarScroll`（[useChartViewSession.ts](file:///d:/Company/WorkSpace/MocaCoffee/bangdream-editor/src/playback/useChartViewSession.ts#L239)），以 `scrollTop = 0` 计算出 `canvasScrollY = 0` 并调用 `canvas.setScrollY(0)`，使得 END 线补齐最后 7px 的位移落到最底端。

## 修法

1. **保证播放结束状态的同源双写**：
   - 在 `usePlaybackCoordinator.ts` 中：
     - 当 `current >= durationRef.current` 命中时，或在 `stopPlayback()` 中，以终态秒数调用 `scrollModel.scrollTargetForSeconds`，获取 `{ scrollY, scrollTop }`；
     - **同时调用** `canvasRef.current?.setScrollY(scrollY)` 与更新 `container.scrollTop = scrollTop`（对齐 Issue 75 / 134 的同源写入不变量）；
     - 将终态坐标生效后再调用 `canvasRef.current?.setPlaybackActive?.(false)`，保证 React 视口状态 `viewport.scrollY` 固化为精确的 `0`。

## 锁测与不变量保护

1. **既有功能不变量**：
   - 严格遵守 Issue 75（seek 同步滚动条）、Issue 134（单引用同源几何）与 Issue 213（滚动条吸附无回弹）；
   - 播放中途暂停、拖拽、重新播放与跳转起点不变量保持不变。
2. **锁测**：
   - `tests/unit/playback/PlaybackEndAlignment.test.ts`：编写单测模拟播放推进至 `duration` 并调用停止，验证 `canvas.setScrollY` 与 `container.scrollTop` 均被严格同步置为终态（`scrollY === 0`，`scrollTop === 0`）。
