# 96 · 画布缩放 <100% 时音符图标逐级发糊

Type: bug
Status: open
Blocked by:

## 来源

用户 2026-09-12 第五批复报：谱面画布音符图标在不同缩放比例下清晰度不一——50% 一种糊形态、80% 略清晰、100% 完全清晰，>100% 恒定最清晰档。用户已确认指**画布缩放**（工具栏百分比，非浏览器缩放）。

## 症状 / 根因（2026-09-12 页面实测复现）

48% 下结点图标糊成小绿点、78% 明显发软、128% 清晰，与用户描述吻合。根因：音符精灵经 `CanvasSpriteIcon.drawSingle` 用单步 `drawImage` 从高分辨率源图集直接缩到目标 CSS 尺寸（`CanvasSpriteIcon.tsx:137`），画布缩放 <1 时为大幅降采样，无 mipmap/多步插值 → 发糊；≥100% 时源图远大于绘制尺寸、降采样比温和 → 恒定清晰（正对应用户「100% 以后保持不变」）。瓦片 dpr 上限 1.5（`noteLayerCache.ts:38` `TILE_DPR_CAP`，issue 36 内存权衡）与本症状正交，非主因。

## 修法

精灵降采样品质整改：候选 = 绘制前逐步减半的中间位图（mip 链）/ 按缩放档预渲染精灵位图 / `imageSmoothingQuality: 'high'` + 分级缓存，按瓦片重建成本实测择一；不得回退 issue 36 的 `TILE_DPR_CAP` 内存权衡（如需动它须另与用户确认）。

## 锁测

- Canvas 像素质量单测覆盖不到 → **Playwright 像素实测**：多档缩放（48/78/100/128%）音符特写截图对比（验证阶段脚本手法已跑通，`scripts/` 下临时脚本可整理为正式验收脚本）+ 手工验收清单。
- 若实现抽出「缩放 → 采样策略」纯函数（如 mip 档位选择）则配套单测锁行为。
