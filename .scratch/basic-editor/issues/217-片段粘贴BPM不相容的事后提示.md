# 217 · 片段粘贴 BPM 不相容的事后提示

Type: feature
Status: open
Blocked by: —

## 来源

用户 2026-11-07 报：含负 BPM 的片段（−120 → +120，跨度 0.75 拍）贴入谱面后「影响到后面的谱面」。根因实测、正 BPM 对照与性能调查见 `docs/research/negative-bpm-pattern-paste.md`。

## 症状与根因

1. BPM 是从事件起生效到下一条事件的**全谱量**，不是片段的局部属性；时间轴为带符号积分，片段内的 BPM 变化会在片段结束处留下**净偏移 Δt**，后面每个音符的响铃时刻整体平移（本例 −0.75s；正 BPM 片段 `120→180→120` 为 −0.125s，同一性质）。末尾写回 +120 只恢复斜率，不恢复积分读数。
2. 现有防线只查「末条 BPM 为负」（`BpmTail.ts` 警示 / `ChartConverter.checkBackflowBoundaries` 拒收），本例末条为正 → 不触发；`clickOps` 的 paste 行与 `applyOps` 均无事后反馈通道（`rejected: 'past-end'` 也静默）→ 破坏完全无提示。
3. 胶囊 `PatternPastePill` 是 30px 单行模式标签（`CanvasCapsule.css` `white-space:nowrap`、无省略号、外层 `overflow:hidden`），承载不了后果说明。

## 定案（用户 2026-11-07 拍板）

1. **不代偿**：粘贴不改动任何既有音符的 `beat`，不自动补偿时间、不补恢复线、不腾位。理由：BPM 与谱面不相容时，常见做法是「不带 BPM 粘贴」或「带 BPM 后谱师自己手动改兼容」，编辑器擅自改写后面所有音符大概率有害。自动补偿亦不可行（只在片段末速 = 目标原速度时数学成立，见调研 §4）。
2. **落点已有音符允许粘贴、覆盖就覆盖**，一次 Ctrl+Z 全撤（既有覆盖规则 + 整份数组快照，已核实）。
3. **不相容时事后弹 toast**，不放在胶囊、不做预览重画 / 位移影子。

## 本轮实现口径（待验收）

- 触发：`withBpm: true` 且本次确实写入了 BPM 线且粘贴成功；判据统一正负 BPM —— 净偏移 `Δt ≠ 0`，或「片段末速 ≠ 目标落点原生效 BPM」。同速不写线 / 「不含 BPM」/ 整组拒绝时不弹。
- 文案走短句 + 数字插值（如「片段 BPM 已写入：后续谱面整体提前 0.75 秒，Ctrl+Z 可撤销」），`tone: 'warn'`（5s 自动消失）；不扩展 `Toast.tsx` 的 action 按钮，撤销用文案提示 Ctrl+Z。
- 默认档不变（含 BPM 仍是默认，ADR-0023 定案），模式偏好照旧记忆。
- 可选（零额外接线，待定）：给 `rejected: 'past-end'` 也补一条 toast，结束整组拒绝的静默。

## 实现落点（路径按主仓库当前结构）

- `src/patterns/paste.ts` + `src/patterns/PasteBpmDecision.ts`：新增判定纯函数，复用 `effectiveBpmAt` / `beatToSeconds` 算 Δt 与末速差；不改写入逻辑。
- `src/chart/editing/ToolActionMatrix.ts`：`MatrixOp` 加一种纯数据 `notice` op（key + params + tone，零 UI 依赖）；paste 行在成功且不相容时随 `setNotes` 一起产出，仍只发一个 `setNotes`。
- `src/chart/components/canvas/FinalVirtualCanvas.tsx`：`applyOps` 加分支消费 `notice` → `showToast(t(op.key, op.params), op.tone)`；这是鼠标路径与 `execPaste` 快捷键路径的唯一汇聚点。
- `src/ui/Toast.tsx`（现成 `showToast`）、`src/i18n/messages/{zh-CN,en}.json`（新增 `patternPaste.*Toast`，带 `{{delta}}` 插值）：复用，不改组件。
- **不改**：`pasteChartNotes` / 覆盖规则、`AudioTiming` / `BpmTimeline` / `ChartGeometry`、撤销栈、`PatternPastePill`、`render.ts`（不进渲染帧循环，零性能风险）。

## 锁测

1. 新增 `tests/unit/patterns/PatternPasteBpmMismatch.test.ts`：负 BPM 片段 Δt = −0.75；正 BPM 片段 Δt = −0.125；同速不写线 / `withBpm:false` / 空片段不报；末速 ≠ 目标单列判据。
2. `tests/unit/chart/editing/ToolActionMatrix.test.ts` 扩：不相容且成功 → 产出 notice op 且仍只一个 `setNotes`；相容 / 不含 BPM / `past-end` 拒绝 → 不产出。
3. `tests/dom/ui/Toast.test.tsx` 同惯例新增或扩：`applyOps` 消费 notice 后渲染 warn toast 文案与插值；鼠标路径与 `execPaste` 快捷键路径各一例。
4. 静态源码断言：`clickOps` / `ToolActionMatrix` 保持零 UI 依赖（notice 只带数据）；`en.json` 与 `zh-CN.json` key 对齐。
5. toast 是 DOM 提示，无需 Canvas 像素实测；手工验收清单：贴完核对文案与音频后果一致、Ctrl+Z 一次全撤。

## ADR

不推翻任何定案：`ADR-0008 §2.1`（不腾位）不用改；只在 `ADR-0023 §2` 补「不相容只提示、不代偿」、`ADR-0010` 补记局部 BPM 的净偏移与「末条为负」错误态的区别。性质为补注，动代码前给用户过目。
