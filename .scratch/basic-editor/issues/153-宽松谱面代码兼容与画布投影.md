# 153 · 宽松谱面代码兼容与画布投影

Type: grilling
Status: resolved
Blocked by: —

## 来源

用户 2026-09-23 对第 3 条需求补充：需要最大兼容 Bestdori。未知字段、未知 `type`、已知字段的有限非法值都不能因解析或导出而丢失；非法 lane 仍应能在画布轨道外渲染，并支持有限的编辑操作。

本票是对 [02](./02-谱面代码格式对齐.md)、[59](./59-谱面代码入口与单音符视图.md)、[118](./118-谱面代码导出另存为.md) 相关边界的最新补充，不改写历史票。

## 定案

### 1. 数据模型

- 谱面代码采用“**源数据 + 画布投影**”模型。
- 合法 JSON 数组中的每个对象及其原始字段都进入源数据；未知字段、未知 `type` 和符合既有放行边界的已知字段有限非法值均保留。
- JSON 语法错误仍拒绝应用；不能安全参与几何计算的对象不因失败而从源数据消失。
- 未知 `type` 是 opaque 条目：保留、保存、导出，但不渲染、不计数、不播放、不进入画布选区；只能通过谱面代码编辑器修改或删除。
- `BPM.bpm = 0` 仍禁止；负数 BPM 规则沿用现有定案，不在本票改动。

### 2. 画布投影

- `beat < 0` **不对齐 Bestdori 编辑器的画在 0**，对齐实机：不渲染、不键音、不进画布选区，计入 combo（开播即已过线）；源数据保留负数。滑条部分结点为负 beat 时，这些结点显示上当 hidden（不铺带），但仍计 combo。
- `beat` 超过谱面结束位置时保持当前行为：按真实 beat 在 END 线之后正常渲染，END 线仍由谱面工程时长决定且位置不变。END 不是渲染裁剪线。
- `lane` 为有限越界值时按原值计算 X，在轨道外正常渲染；`connections` 的 lane 同样处理。
- 如果编辑 connection 的 beat 造成中间结点早于原前置结点，沿用现有 Slide 显示投影的重排能力，本票不重新发明排序规则。
- `Directional` 的渲染投影保留原始 `width`：
  - `width > 0` 时绘制 `ceil(width)` 个方向键本体，并把方向装饰放在原始 width 的真实位置；
  - 例如 `4.25` = 5 个本体 + 4.25 处的装饰，`0.25` = 1 个本体 + 0.25 处的装饰；
  - `width <= 0` 不绘制本体，负值使装饰按原始符号向反方向偏移；
  - `direction: "Other"` 渲染回落为 Right，源数据仍保留 `"Other"`。

### 3. 编辑与字段归属

- 一对一操作（拖拽、复制、剪切、镜像、粘贴）：
  - 未被直接编辑的字段随对象保留；
  - 拖拽改变位置时，lane 归入 `0..6`，纵向位置按正常落点规则处理；
  - 新放置和粘贴的目标 lane 必须合法；
  - 镜像不强制修正结果 lane，允许继续非法；
  - 覆盖时旧对象连同其字段一起删除，新对象只保留自己的字段。
- 会改变音符本身形态的操作（Slide 拆条、增加 connection、合并 Slide、增加方向键宽度等）对齐 Bestdori：重新生成标准对象，丢弃编辑器不理解的未知字段和非法字段；能够明确映射的标准字段按既有覆盖/滑条规则保留。
- 可编辑的越界 lane 音符/connection 支持选中、复制、剪切、删除和拖动；拖动后落入最近的合法轨道。未知 `type` 不进入这些画布编辑路径。

### 4. 源文本、工程保存与另存为

- 应用后的代码文本是当前源文本；工程保存/重载、再次打开代码和对外导出都基于它。
- 另存为只保存当前已应用源文本，不包含代码框中的未应用草稿。
- 没有画布编辑时，另存为尽量保存应用代码框的原始文本；画布编辑后允许必要的 JSON 重排，但不能丢失本票规定应保留的字段。
- `beat < 0` 的实机口径由**画布播放**直接实现（不画、不键音、计入 combo）；日后谱面预览视频沿用，本票不做视频、不另开 Auto Play 票。

## 文档落点

- 新增 [ADR-0014 宽松谱面代码源数据与画布投影](../../../docs/adr/0014-宽松谱面代码源数据与画布投影.md)，记录源数据/画布投影、宽松兼容、非法 lane 和另存为边界。
- 修订 ADR-0009 中“导出只写标准字段”的表述：内部 `spanParams` 等编辑器字段仍不导出，但用户谱面代码源数据中的未知字段和非法值按本票保真导出；形态变化后的 Bestdori 式重建例外按本票处理。
- 复核 ADR-0005、ADR-0008 与 `CONTEXT.md` 中“合法 lane / 谱面代码 / END 范围”的术语，区分“新编辑落点合法”和“外部源数据可越界渲染”。

## 锁测

- `tests/unit/ChartConverter.test.ts` / 新增源数据投影单测：未知字段、未知 type、非法 lane、`beat < 0`、超 END beat、Directional 小数/负 width、`Other` direction 的应用、重载和导出不丢源字段；JSON 语法错误仍拒绝。

- `tests/unit/chart/editing/` 与 `NotePlayheadStats` / `buildKeyEvents`：`beat < 0` 计入总数与开播过线 combo、不发键音；越界 lane 的选择/复制/剪切/删除/拖动、粘贴合法化、镜像允许非法 lane、覆盖删除旧字段，以及 Slide/Directional 形态变化时丢弃未知/非法字段；`width>=3` 同向点击结果为 1。
- `tests/unit/ChartCodeExportSaveAs.test.ts`：锁定另存为使用已应用源文本且不读取未应用草稿；源数据发生画布编辑后仍保留规定字段。
- Canvas 像素位置、轨道外音符可见性和代码弹窗/另存为时序补 Playwright 验收；无法仅靠纯单测证明的 Electron 实际写盘补手工验收。
