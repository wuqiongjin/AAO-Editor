# 205 · 画布与预览设置浮层条目重构与三端对齐

Type: grilling
Status: resolved
Blocked by:

**来源**：用户通过 `/grill-me` 提出（2026-11-01）。

## 症状

谱面画布设置、静态预览设置、动态预览设置三者之间部分配置项共通、部分独立，现有条目组织混乱：
1. 动态预览直接混入了纯 2D 二维画布专属的无效项（纵向比例、轨道颜色、轨道线透明度），生搬硬套“画布”概念；
2. 静态预览的节拍线缺乏三连音/三拍子支持；
3. 工作台画布设置在 issue 200 扩展后条目顺序杂乱，且缺少与预览弹窗对齐的音符皮肤入口；
4. 预览弹窗缺少重置恢复默认机制。

## 根因

1. 动态预览浮层早期直接复制了静态预览的设置代码，而动态仿真实际使用基于 WebGL/Canvas 的 3D 透视舞台，二维轨道的网格颜色与纵向比例在仿真渲染管线中根本未被接入；
2. 静态预览节拍线仅沿用了 2 的幂次细分常量，未扩充三连音与 12/16 分音符细分；
3. 工作台设置面板经多轮特性迭代追加后未重新梳理视觉分组与心智模型；两处预览面板具备皮肤跳转但工作台遗漏了对标入口。

## 范围

- 做：
  1. **动态预览设置重构（剔除无效项与去画布化）**：
     - 彻底移除不生效的「纵向比例、轨道颜色、轨道线透明度」3 项；
     - 剥离“画布”概念，分为「舞台与仿真」与「音符与画质」两大组；
     - 引入「打击音效音量（SE 音量）」，支持就地调节实机试听与视频导出的音效；
     - 底部新增两步防误触「恢复默认」按钮。
  2. **静态预览设置优化**：
     - 节拍线细分下拉项扩充常用三连音预设（新增 `1/3`、`1/6`、`1/12`），支持 3 拍子与三连音谱面观览；
     - 保持克制精简，不补齐「时间精度显示、线形分层、文字大小」，避免侧栏挤占与视觉冗余；
     - 底部新增两步防误触「恢复默认」按钮。
  3. **工作台画布设置条目优化与三端对标**：
     - 画布分组内条目次序顺化：音符外观（音符大小/长压透明度/双押线/色觉辅助）→ 轨道与网格（纵向比例/轨道颜色/网格透明度/线形分层）→ 读数与画质（文字大小/时间精度/图像品质）；
     - 保持「画布 / 播放与音频 / 操作偏好」三大块不变；
     - **新增「音符皮肤」独立块**（显示当前皮肤包名 +「前往更换」跳转至素材页），与静态/动态预览保持完全一致体验。
  4. **配置常量与国际化**：
     - `AppSettings.ts` 扩充 `PREVIEW_BEAT_MARK_DIVISIONS`；
     - 同步补齐中英文字典键。
- 不做：
  - 静态预览不做任意数字自定义节拍线输入（下拉预设已覆盖 99% 场景，维持轻量）；
  - 动态预览不引入横向/纵向轨道缩放（舞台投影几何模型固定）；
  - 不做全局设置页（`SettingsPage`）的画布项迁回（保持设置页扁平纯粹）。

## 交互与参数定案（用户 2026-11-01 定案）

### 1. 动态预览弹窗（`PreviewDisplayPanel` - mode='video'）

  - 镜像（`Toggle`，`preview.mirror`）；

### 2026-11-01（Code Review 发现与修复）
- **Spec 轴发现**：`PreviewDisplayPanel.tsx` 原重置实现无条件调用 `setPreview(d.preview)`，导致在静态模式下重置会意外清掉动态仿真配置（如音符速度、背景包等），在动态模式重置会意外清掉静态标注开关。
- **修复措施**：按 `mode === 'static'` 与动态模式对 `preview` 字段做分域 patch 更新，并扩充 DOM 测试锁定独立重置互不冲掉的行为。
- **单测补全**：在 `PreviewMarkerSettings.test.ts` 中补齐全白名单细分值的读取与脏值/非法值回落默认测试。
