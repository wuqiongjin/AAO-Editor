# 42 · 整包预设封面图

Type: grilling
Status: resolved
Blocked by: issue 29（音符皮肤管线 12 套已就位）

## Question

issue 29 整包预设当前缩略区是统一占位（深色背景 + 居中 Sparkles 图标）。要不要给每个整包预设做"作品集式封面"？

可选方向（待 grill）：

1. **整包预览缩略**：用一个画布按整包绘制 6 类音符样例（综合预览的缩小版），作为该整包的封面。
2. **官方 bestdori 截图**：引用 bestdori 官方的 sample 包预览图（已归档在 `directionalflickskin*sample_rip/` / `*_sample_rip` 里有 note_flick_3 / note_normal_3 等单图），但**样片图不等于整包观感**。
3. **不做封面**：保持当前占位（深色 + Sparkles），把"按条目覆盖"区的 6 列预览当作隐式封面。
4. **真实精灵缩略 + 标签**：保留当前 Sparkles 占位但加标签"含 6 类音符"，避免大改动。

## 决策依据（待 grill 拍板）

- **规格**：封面图尺寸 / 宽高比 / 边距 / 是否与下方"整包使用中/应用整包"按钮对齐
- **资源来源**：构建期从 `*sample_rip` 拉取 vs 运行时从 `noteSkinRegistry` 渲染 vs 不动（占位）
- **状态可见性**：选中态要不要换图 / 加边框 / 加 ✓ 角标
- **加载性能**：12 个整包每个一个独立画布 vs 复用 NoteSkinPreview 渲染路径 vs 单 sprite-locator
- **与下方"按条目独立覆盖"预览的关系**：避免重复——预览已经画了 6 类样例

## 边界

- 不改整包预设数据结构 / id 约定 / `pairedDir` 配对
- 不动 .sprites 解析路径
- 不动 NoteSkinPreview 列展示
- 资源若来自 Bestdori `*sample_rip`，复用 issue 29 现有的 `scripts/fetch-bestdori-skins.mjs` 拉取框架（不重写）

## 答案（结论）

- **Q1=A**（用户 2026-09-26）：做**整包预设缩略**——按该预设会写入的条目画真实精灵，表示「使用此包会长什么样」。不用 sample 成品图，不保留 Sparkles。综合预览仍只反映当前六条目组合。词不用「封面」（已被工程信息占用）。
- **Q2=A**（用户 2026-09-26）：上图下文。图下只留「使用此包 / 使用中」，不显示 Skin 0N（名称只进 aria-label / title）。
- **Q2 修订**（用户 2026-09-26 见稿后）：缩略要像缩略，不要拉满卡宽；Skin 0N **要露出来**，方便称呼「哪一套」。形态改回横排左缩略右编号+药丸。
- **Q3=A**（用户 2026-09-26）：只画该预设会写入的条目；skin05/06 四格，不留方向键空位。
- **Q4=A**（用户 2026-09-26）：运行时 registry + 与综合预览同构绘制。已知打开视觉素材页会预热全部图集（约 1.8MB 下载 / 约 76MB 解码），仍选运行时。
- **Q5=A**（用户 2026-09-26）：缩略图不换；沿用卡描边 +「使用中」状态标记。
- **Q6=A**（用户 2026-09-26）：2×3（05/06 为 2×2）；格序与综合预览六列相同；格内不写类别名。
- **Q7=A**（用户 2026-09-26）：未使用时点图与点「使用此包」同效果；「使用中」的图不可点。

### 本轮实现口径（用户 2026-09-26 确认后落地）

- 词：整包预设缩略 ≠ 封面；综合预览仍只反映当前组合。不写 ADR（可逆、不意外到需要单独决策文）。
- 卡：整包预设横排（左缩略、右编号 + 药丸）。键音素材包横条不动。综合预览列布局不动。
- 图：每卡一块画布；单格比例跟综合预览单格相同（140:88）；**固定槽 156px 宽**（原 Sparkles 占位 84×56 加宽以容 2×3），不拉满卡宽。skin05/06 的 2×2 与 2×3 **单格同尺寸、水平居中**，不把四格拉满变大。
- 绘制：抽出与综合预览同构的 `drawPreviewSprite` 路径，按该预设会写入的 selection 画（有 `pairedDir` 则六条目都指向这对包；无则只画四类）。缩略格内按综合预览单格坐标等比缩小居中（`PRESET_THUMBNAIL_SPRITE_FIT`），不把缩略格子当预览格去画，避免音符撑破格子。
- 文案：卡上显示 `pack.label`（Skin 0N），右侧药丸仍是「使用此包 / 使用中」。
- 资源：运行时预热该页用到的图集；不拉 sample_rip。

### 锁测

1. 纯函数：`presetThumbnailItems(pack)` —— 有 `pairedDir` → 六类；无 → 四类且不含 dirL/dirR。
2. 纯函数：2×3 / 2×2 格子几何（同行同高、05/06 居中且单格尺寸与六格卡相同）。
3. 纯函数：格内精灵相对综合预览单格等比缩小居中，占用小于格子。
4. 静态源码：`AssetsPage` 整包预设不再渲染 `Sparkles`；`NoteSkinPreview` 六列结构不被这张票改掉；缩略绘制走预览格坐标缩放。
5. 单测盖不到的点击/像素：进视觉素材页看 7 张卡是横排小缩略 + Skin 0N 编号；格内音符不撑破格子；点未使用卡的图会套用；使用中的卡图不可点。
