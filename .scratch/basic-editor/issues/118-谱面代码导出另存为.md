# 118 · 谱面代码导出另存为

Type: feature
Status: open
Blocked by: —

## 来源

用户原把「谱面 JSON 导出路径」算进「改保存路径」。Q9=A：导出不常用 → **每次另存为、不记目录**。故从 117 拆出，不合入 issue 04。

## 症状 / 根因

谱面代码目前只能在编辑器里看/拷，没有「存成文件」；issue 04 已 research 过 dialog+fs，未实现。

## 修法

- Electron：`dialog.showSaveDialog` + 写出 **谱面代码 JSON**（`chartCodeToJSON`），音频不附带（04 MVP）。
- **不记住**上次目录、不在设置里养默认导出路径。
- 浏览器：保持下载或暂不做（正式形态是 Electron，ADR-0011）。

## 锁测

- 序列化复用现有转换器单测，本票不改格式。
- 对话框/写盘：Electron 手工验收（另存 → 打开文件 = 当前谱面代码；再导出一次仍弹出选路径）。
- 静态断言：无「记住导出目录」的 localStorage / settings 字段。
