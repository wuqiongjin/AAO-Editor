# 161 · BPM 数值随线裁切（滚动不贴边漂移）

Type: grilling（重开 issue 51「BPM 整字钳进画布」与 issue 159 定案 2「整组平移 / 线 y 2×字号折回」；落地 = bug）
Status: resolved（2026-09-25 钉线+画布裁切+盒相交才保持展开）
Blocked by: —

## 来源

用户 2026-09-25：

1. BPM 数字过判定线后不会立刻被盖住，而是往上移一段再突然消失。
2. 在 159 展开之后，若真数字很多（占很高），滚一点整叠会突然消失。

## 症状

判定线 = 画布底边。BPM **横线**已随滚动离开，**沟槽数字**仍留在底边内侧（或展开叠被整组推进视口），与线脱开；再滚一段后整颗/整叠瞬间没了。播、停、手滚同一条绘制路径都会中招。START / END 不在本票范围。

## 根因

- 单条/摘要：`clampGutterLabelY`（issue 51「文字都在谱面范围内」）把字 y 钳进 `[half, h−half]`，线已出底边时字还钉在底边，直到 `visibleNotes` / `y > h+50` 裁掉才消失。
- 展开叠：每帧 `shiftStackIntoCanvas`（159 定案 2「贴边整组平移」）把整叠推进视口；`bpmExpansionOffscreen` 以**共用线 y** 出画布外 2×字号折回摘要。高叠时线已出缓冲、错开字仍在画布上 → 一折回整叠瞬切成（往往已在画外的）摘要。
- `renderBpmLabels` 还用 `visibleNotes` 跳过未入可见集的 BPM：展开叠的字 y 可以离线很远，可见集按线/音符 cull 时会提前整组不画。

159 产品意图（展开不要画到画布外、贴边仍要能读）与本票**不冲突**；冲突的是把「不要画到外面」做成**每帧平移 / 钳制**，而不是**裁切**。

## 定案（用户 2026-09-25）

grill：Q1=A / Q2=A / Q3=A / Q4=A / Q5=A / Q6=B。

1. **钉线**：BPM 数值 / 摘要的画布 y = 线 y（159 错开后相对线）。过画布**底边（判定线）**与**顶边**都随线走，**半截可见**（画布裁切）。不把整字/整叠推进视口。
2. **范围**：只动 BPM 沟槽（摘要 + 展开真数字）。START / END 仍可 `clampGutterLabelY`。播 / 停 / 手滚同一口径。
3. **不要画到画布外** = **裁切**，不是平移。取消展开叠的 `shiftStackIntoCanvas`（含展开当下）。
4. **折回摘要**：点组外（及既有 Esc/Enter 留展开）不变。滚动自动折 = 展开叠里**所有真数字文字盒均与画布不相交**之后才折；不是「线 y 出画外 2×字号」。
5. 绘制 / 命中 / 就地编辑框共用同一套未钳制的 y；盒与画布不相交则不可点、不画（半交则裁切可见部分，命中跟可见盒）。

不改 ADR-0010；不重画已删的判定线描边（issue 50）。实现时改 CONTEXT「BPM 数值 / BPM 展开态」；issue 159 定案 2 第 7–8 条（2×字号折回、整组平移）由本票取代。

## 实现落点

| 文件 | 改动 |
| --- | --- |
| `src/visual/gutterLabels.ts` | `layoutBpmGutter` 展开叠不再 `shiftStackIntoCanvas`；折回判据改为「任一字盒与画布相交则保持展开」；`clampGutterLabelY` 仍给 START/END |

## 锁测

- `tests/unit/visual/render/GutterLabels.test.ts`
  - **会改红**：`起始线贴底边…数值钳制在画布内（不再堆叠/裁剪）` — 改成 fillText 的 y **等于线 y**（可在底边外或贴边），不得等于 `h − fontPx/2` 的钳位。
  - **会改红**：`展开同位组：…贴底整叠仍在画布内` — 错开间距仍 ≥ 字号，**允许**字盒超出 `[half, h−half]`（不再断言整叠在画布内）。
  - **会改红 / 替换**：`整组平移不逐颗压回…滚出 2×字号才算离屏` — 断言展开 y 与 `layoutBpmLabelYs` 一致（无平移）；折回 = 所有真数字盒与 `surface` 不相交；线 y 刚出 2×字号但高叠仍有盒相交 → **不折**。
  - **保留**：issue 51 的 `clampGutterLabelY` 对 **bound**（START/END）用例；非 BPM 钳制不改。
- 单条过底边：连续两个 `scrollY`，字 y 的增量 = 线 y 的增量（钉线、不漂移）；线出画后字可半截，再出则无 fillText。
- 高展开叠：线已出画、仍有错开字盒相交 → `expandedKey` 保持；盒全部不相交 → 折回。点组外折回仍由 `CanvasGesture.test.ts` 既有用例锁。
- 单测盖不住的半截像素：不强制 Playwright；裁切用 canvas `clip` 的静态断言（`renderBpmLabels` 路径有 `save`/`rect`/`clip` 或等价）即可。

## Answer

BPM 沟槽数字/摘要钉线 y（159 错开相对线），顶底画布 `clip`，不 `clampGutterLabelY` / 不整叠平移。滚动折回摘要 = `bpmExpandedNumeralsOnCanvas`（墨迹盒与画布相交）。就地编辑框跟未钳制的 layout y。锁测 `GutterLabels.test.ts` + `BackflowRender` 换色仍按文案取色。
