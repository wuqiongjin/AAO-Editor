# 161 · BPM 数值随线裁切（滚动不贴边漂移）

Type: grilling（重开 issue 51「BPM 整字钳进画布」与 issue 159 定案 2「整组平移 / 线 y 2×字号折回」；落地 = bug）
Status: resolved（2026-09-25 钉线+画布裁切；验收复报已合入）
Blocked by: —

## 来源

用户 2026-09-25：

1. BPM 数字过判定线后不会立刻被盖住，而是往上移一段再突然消失。
2. 在 159 展开之后，若真数字很多（占很高），滚一点整叠会突然消失。

## 症状

判定线 = 画布底边。BPM **横线**已随滚动离开，**沟槽数字**仍留在底边内侧（或展开叠被整组推进视口），与线脱开；再滚一段后整颗/整叠瞬间没了。播、停、手滚同一条绘制路径都会中招。START / END 不在本票范围。

## 根因

- 单条/摘要：`clampGutterLabelY`（issue 51）把字 y 钳进 `[half, h−half]`，线已出底边时字还钉在底边。
- 展开叠：`shiftStackIntoCanvas` 每帧把整叠推进视口；折回用「线 y 出画外 2×字号」。
- `renderBpmLabels` 用 `visibleNotes` 按线 cull，展开叠的字离线很远时整组不画。

冲突的是把「不要画到外面」做成**每帧平移 / 钳制**，而不是**裁切**。

## 定案（用户 2026-09-25）

grill：Q1=A / Q2=A / Q3=A / Q4=A / Q5=A / Q6=B。

1. **钉线**：BPM 数值 / 摘要的画布 y = 线 y（159 错开后相对线）。过顶/底（底边=判定线）随线走，半截可见（画布 clip）。不把整字/整叠推进视口。
2. **范围**：只动 BPM 沟槽。START / END 仍可 `clampGutterLabelY`。播 / 停 / 手滚同一口径。
3. **出界 = 裁切**，取消 `shiftStackIntoCanvas`。
4. **折回摘要**：所有真数字文字盒均与画布不相交之后才折。
5. 绘制 / 命中 / 就地编辑框共用同一套未钳制的 y。

不改 ADR-0010。CONTEXT「BPM 数值 / BPM 展开态」已改；159 定案 2 第 7–8 条由本票取代。
