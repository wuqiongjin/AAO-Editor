# 151 · 起始线与结束线文字调整

Type: feature
Status: resolved
Blocked by: —

## 来源

用户 2026-09-23 反馈：当前 START/END 文字位置曾从线上下改成垂直居中；最新口径为移除 START 文字，保留 END 文字并放到结束线下方。关联已完成的 [52](./52-起始线结束线样式与文字整改.md)，不改写历史票。

## 定案

- 起始线继续保留，但不再显示 `START` 文字。
- 结束线继续保留，`END` 文字位于结束线下方。
- `END` 文字盒仍必须完整位于当前谱面画布可见范围内。
- 结束线仍只绘制在当前既有的左右沟槽区域，颜色、线宽和外侧文字锚定体系沿用现状。

## 修法

调整 `renderBoundLines` 的起始/结束文字绘制与边界钳制；不要修改谱面长度、起始线/结束线的几何位置，也不要把本票与 Ctrl+Space 临时起点标记混为一谈。

## 锁测

- `tests/unit/visual/render/BoundLines.test.ts`：START 文本不再输出；END 文本存在且文字基线位于结束线下方；起始线和结束线仍各自绘制。
- 增加结束线贴近画布边界时的完整文字盒钳制测试。
- 单测无法证明真实字体墨迹不被裁切，补 Playwright 像素验收：检查起始线无 START、结束线下方可见 END，且滚动/缩放后不越出画布。

## Answer

`renderBoundLines`：起始线只画沟槽虚线、不 `fillText('START')`；结束线仍画沟槽段，`END` 走 `layoutGutterLabel(..., 'below')` + `clampGutterLabelY`。线几何/配色/线宽未改。锁测：`BoundLines.test.ts` 4 例（无 START、END 在线下方、两线沟槽、贴底钳制）。仓内无 Playwright 基建（与 issue 110 同），像素验收改用开发服实机：起始线无 START、结束线下方可见完整 END，110% 缩放后仍在画布内。贴底时钳制优先于「在线下方」，文字盒完整可见。
