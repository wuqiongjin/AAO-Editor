## §1 校验规则（先做：纯函数 + 单测，可独立验收）

### 1.1 错误结构升级

- 返回 `{ valid: boolean; errors: ValidationError[] }`，`ValidationError = { noteIndex: number; connIndex?: number; field?: string; reason: string; expected?: string }`。
- **一次收集全部错误**（不首条即停）；UI 一次列完（前 N 条 + 「共 N 处」）。
- 本票**不新增 toast 组件** —— 沿用 `ChartCodeEditor` 现有展示位；「统一提示体系」单开小 issue（把现有 `alert` 一并换掉）。

### 1.2 校验加严：只接受"有意义的谱面代码"

| 规则 | 处置 |
| --- | --- |
| `type:"Slide"` / `"Long"` 的 `connections` 必须 **≥2** | 0 或 1 个 = **非法**，报错不回写，**不做自动退化为单键** |
| `type:"Single"` 必须齐备 `beat` + `lane`，且**不得残留 `connections`** | 非法 → 报错不回写 |
| `type:"LDirectional"` / `"RDirectional"` 另需 `direction` + `width`，同样不得残留 `connections` | 同上 |
| Slide / Long 的**首尾 connection 不得 `hidden: true`** | 非法 → 报错不回写 |
| 非法一律**报错 + 不回写，不静默修正** | — |

- 仍**允许**把整条 Slide 完整改写成一条合法 `Single`（删掉 `connections`、补齐 `beat`/`lane`）→ 回写后滑条变单键，这是合法编辑。
- **完整代码视图与单音符视图共用同一套规则**：外部粘来的脏代码同样被拒。
- **导入 / 应用撞错 = 整份拒**（不静默修正、不跳过单条）。

> **原则固化不归本票**：「不追求兼容 bestdori 的边界行为」这条总纲，实现时同步记入 **issue 02（谱面代码格式对齐）**，作为未来所有"要不要兼容"的判断基准。

## §2 两个入口，各司其职

| 入口 | 形态 | 行为 |
| --- | --- | --- |
| 「谱面代码」按钮 | 普通按钮，**不进工具轴** | **永远**打开完整谱面代码（**不看选区**）；选区 ≥2 时弹窗顶部加一行非阻断提示「已选 N 个音符，代码视图展示完整谱面；复制选中片段请用『复制为谱面代码』」 |
| 「音符代码」工具 | **持工具态**，tool id `noteCode` | 点某个音符 → 弹出**同一个弹窗组件**，内容 = 该音符/结点的代码；弹窗关闭后**态驻留**（连续查看） |
| `Ctrl+B` | 执行键 | 打开**光标处**音符的代码（不切工具的快捷版） |

- 工具栏两按钮并列于「编辑」分组，tooltip 写明：`B` 切换态、`Ctrl+B` 看光标处音符。
- **Q12 的"入口按钮按选区分流"作废**（两入口已各司其职）。

## §3 「音符代码」工具态语义

- **点击音符** → 打开该音符对象视图（**点击优先于选区**）。粒度完全沿用 `findItemAt`（数组序首个）。
- **点击空白** → 无效果、**不清选区**。
- **框选 = 不可框选**：按下拖拽**不启动框选**（不画框选矩形），而非"框了松手无反应"。
- **不清选区**（点音符/空白都不清）——它是唯一不改谱面的工具，ADR-0008 §2 原则 6 的动机不成立。
- 退出：Esc / 再点按钮 / 切其它工具（沿用 §2 三出口）。

## §4 对象视图（三种初值）

| 选中项 | 视图内容 |
| --- | --- |
| `note`（整条 Slide/Long） | 权威格式 `{"type":"Slide","connections":[…]}`，**不展开** |
| `slideNode` | **独立形态投影**：`{"beat","lane","type":"Single", hidden?, flick?, skill?}` —— "若它是独立音符" |
| `slideRegion` | **不支持**，回退到整条 Slide 视图 |

- **hidden 结点不可达**（56 已定 Q36=D：命中和框选都跳过 hidden），其字段在整条视图里照样可改。
- **投影规则**：如实映射 `flick`/`skill`/`hidden`，不按位置臆断；`type` 恒为 `Single`（connection 无 `direction`/`width`，端点不可能投影成 Directional）。

## §5 回写（依赖 §1）

- 单音符视图：恰好一条 + 合法 + **字段集与 type 匹配** → 替换原 `noteIndex`。
- 结点视图：**只接受 `type:"Single"`**，其它一律报错；写回该 connection 的 `beat`/`lane`/`flick`/`skill`/`hidden`。不做结构替换、不静默忽略。
- 非法 → 报错 + 不回写（§1.2）。

## §6 导航与 Esc

- **两级面包屑**（只向上返回、不下钻）：`‹ 所属滑条` → `‹ 完整谱面代码`。
- **Esc 逐档退**：结点视图 → 滑条视图 → 完整代码 → 关弹窗（与 ADR-0008 §7"先到先吃、只吃一档"一致）。
- 不做代码↔画布跟踪（Q25–28 已废）。

## 验收

**校验（§1，单测）**
- `connections: []` / `[x]` → 报错、含 `noteIndex`、不回写。
- `{"type":"Single","beat":1,"lane":0,"connections":[…]}` → 报错。
- 首尾 `hidden:true` → 报错。
- 一手脏代码含 5 处错误 → `errors.length === 5`。
- 合法把整条 Slide 改写成 Single → 通过、回写后为单键。
- 回归：`ChartConverter` 往返映射（含 skill）全绿；导入链路（issue 02 / 24）除"撞错改整份拒"外行为不变。

**入口与视图（§2–§6，手验）**
- 进态 → 连点 3 个音符各弹出对应代码 → Esc 逐档退 → 再 Esc 落回指针。
- 点滑条结点 / 段 / 整条，三种初值正确（段回退整条）。
- 该态下拖拽不出现框选矩形；点击后选区仍在。
- 「谱面代码」按钮始终完整代码；≥2 选中时有提示行。
- `B` / `Ctrl+B` / `Ctrl+Shift+B`（侧栏折叠）三者不冲突。

**遗留 / 需你知**
1. **`hasBeat0Bpm` 仍是独立 alert**（ADR-0001 保底语义，没进错误列表）：合法 JSON 但没有第 0 拍 BPM 时，仍然只弹「谱面必须包含第 0 拍的 BPM 音符，无法应用」，不在错误面板里。要不要把它也收编成一条 `ValidationError` 进面板，属"统一提示体系"范畴，我没动。
2. **`LDirectional` / `RDirectional` 同理**：代码侧方向键只有 `type:"Directional"` + `direction:"Left"/"Right"`（内部 `LDirectional`/`RDirectional` 序列化而来）。与 Long 不同，Bestdori **没有** `LDirectional`/`RDirectional` 这两个类型（vendored `convert.ts:307-312` 只有 `BPM/Single/Directional/Long/Slide/System`），所以这条我维持现状：**代码侧不接受 `LDirectional`/`RDirectional` 字面量**。若你也要收，请明示。
3. **连带影响**：画布上若存在"只有 1 个结点"的滑条 / 长条，或"端点 hidden"的滑条 / 长条，由它生成的代码现在会被判非法 → 该谱的代码**无法应用**（一贯的"整份拒"）。这是加严的预期后果，但意味着这类脏数据只能先在画布侧修好，或手工把整条改写成合法 Single。是否要在打开弹窗时先给提示，留待后续。
4. §2–§6（入口 / 工具态 / 对象视图 / 回写 / 导航）**未动**，本条只覆盖 §1。
