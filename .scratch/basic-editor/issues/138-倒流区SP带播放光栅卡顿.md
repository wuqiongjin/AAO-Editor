# 138 · 倒流区 SP 带播放光栅卡顿（默认缩放也会卡）

Blocked by: —

## 来源

用户 2026-09-21：谱面播放部分配置下严重掉帧；样例 `150030.json` 约 5s 折返带。同日确认：**默认缩放滚到这段也会卡**。修法 1–3 拍板。

## 症状

播放时钟 ~5s（布局轴已进入首段倒流折返，Y 覆盖 4.8s–12.8s）帧时很高。放大 / 纵向比例·音符大小拉高更重。

## 根因

`rasterBandRuns` 按整条带 bbox 逐设备像素扫描、不裁瓦片/视口；每个 fold run 空转联合高度。可见集按整条 pos 相交 → beat 48→290 的倒流长条在 5s 已整条入列（外加 beat 2→18 的 284 点锯齿）。瓦片 miss 时同步光栅整条（4ms 预算拦不住已开的那块）。实测默认档一视口约 64–100ms、位图高 5462px（瓦片 768px）；`verticalRatio=2`+`noteSize=2` 约 430ms。键音跳过 hidden，不是 SE。

## 修法

**定案（用户 2026-09-21）**

1. `rasterBandRuns` 裁到当前 clip/瓦片行。
2. 每个 fold run 只扫自己的 y 区间。
3. 可见集仍整条相交（防折返臂漏画）；只光栅与视口相交的 run/行。放大直渲同样裁。不退回分层 `fill`、不做 hidden LOD。

## 锁测

1. `tests/unit/visual/render/SlideBandGeometry.test.ts`：传入 clip 后 `bh` ≤ clip 高；run 不扫联合 bbox 空行。
2. `tests/perf/`：`150030` 在 5s 视口（瓦片坐标系、默认档）光栅像素 ≤ 可见瓦片面积 × 常数（修前 2.6M 红）。
3. 画质：折返叠亮 / 无暗缝既有用例不回退。页面验收 = 默认缩放播过 5s 折返不再持续掉帧。

## Answer

`rasterBandRuns` 接受 `clipCss`：位图与 clip 求交，每个 fold run 只扫自己的 y。`renderSpBandStrip` 用当前画布变换把瓦片/直渲可见矩形传进去（放大直渲同一条路）。可见集未改。
