## 来源

用户 2026-09-26（[chart-projects 01](../../chart-projects/issues/01-谱面工程管理与启动流程定案.md) 第四轮）：增加自定义配置的收藏功能，把喜欢的配置收藏起来，在任何可编辑的谱面画布里粘贴。

## 已定

- 术语：**片段**（Pattern）/ **片段收藏**。不叫「配置」——已被配置系统 / 设置对象占用；也不与滑条「形状模板」混称（见 `CONTEXT.md`）。
- 与剪贴板并存：剪贴板管一次性搬运（切换工程 / 谱面不清空），片段收藏管长期复用、跨工程可见。
- 可以粘贴进任何可编辑的谱面画布；已上传的谱面只读，不能粘（ADR-0015 §4）。
- 位置与外观由 [180 工作台侧栏重设计](./180-工作台侧栏重设计.md) 定：工作台右侧可开合的「片段库」抽屉（顶栏图标钮 + `Ctrl+Shift+B`）。本票管语义。

## 现状事实（grill 前查证 2026-10-30）

- 剪贴板 = `EditingProvider` 里的 `ChartNote[]` 内存态，**跨工程保留**（`workspaceProject.applyProjectSwitch` 只清选区）。载荷形态由 `copySelection`（`src/chart/editing/SelectionEditing.ts`）决定：整条音符 / 整条滑条 `structuredClone`；滑条区域或多结点 → 连续 `connections` 装回一条滑条；单结点 → 退化成独立音符；hidden 结点随行；`spanParams` **只在整条复制时**保留；`source`（原谱 overlay）随克隆带出。
- 粘贴 = 持工具态（`ToolActionMatrix` 的 paste 行 → `pasteChartNotes`）：beat 轴，**组的包围盒左上角对齐落点**，lane 只夹取不拒绝，整组越过谱面末端整组拒绝，覆盖按 ADR-0001；`Ctrl+V` = 光标处即时粘贴、不进态（ADR-0008 §2.1）。
- **选区里永远没有 BPM**（issue 71），所以收藏侧只能自动取 BPM。
- 设置对象 = localStorage 单键 `aao.settings.v1`，**没有任何"用户集合"**；片段库抽屉只占 `settings.layout.patternDrawer`。
- Electron 数据根只有 `projectStore` / `backgroundSkin` 两条桥，**没有通用的"数据根下任意应用文件"API**（需要为本票新增）。
- 「末条 BPM 为负」已有独立错误态：画布画**危险红 + `!`**（`src/chart/editing/BpmTail.ts`、`render.ts`，issue 142），因为导出后 Bestdori 打不开；编辑器**不拦**，只有导入侧整份拒收。
- 抽屉外壳已实现（票 183：标题 / 空状态 / 禁用占位按钮），卡片与数据全无。

## 定案（用户 2026-10-30）

### 1. 载荷：音符 + 速度语境

| 项 | 定案 |
| --- | --- |
| 音符 | 复用 `copySelection` 的形态归一产物，不为片段另写一套 |
| `source` | **剥掉**（片段是纯音符；原谱 overlay 跨工程长期携带会变成幽灵字段）。剪贴板维持现状 |
| 速度语境 | **一律存**，不是"只有特殊片段才存"：`startBpm` = 源谱面在 `minBeat` 处的生效 BPM（按 beat 稳定排序后最后一条 `beat ≤ minBeat` 的 BPM 值；谱面必有 beat 0 的 BPM，故恒有值）；`events` = 跨度内 `(minBeat, maxBeat]` 的 BPM 事件，相对 `minBeat` 记 `deltaBeat`（起拍处那条就是 `startBpm`，不重复存） |
| 跨度 | `[minBeat, maxBeat]` = 音符包围盒。**不为"回正"扩边** |
| 不存 | 尾部"恢复 BPM"事件、缩略图位图、来源工程 / 谱面名 |

理由：收藏是低频可重做动作、粘贴是高频当场动作，选择该放在生效那一刻；而"收藏时不存"等于源速度语境的**信息永久丢失**，以后想保真也没法。

### 2. 粘贴：带 / 不带 BPM 由粘贴时决定

| 项 | 定案 |
| --- | --- |
| 坐标系 | 与剪贴板 100% 同口径（beat 轴、包围盒左上角对齐落点、lane 夹取、越过末端整组拒绝、覆盖按 ADR-0001、`subBeat` 原样带过去） |
| 两种模式 | **带 BPM（默认）** / **仅音符** |
| 带 BPM | 落点写 `startBpm`——**与目标该处生效 BPM 相同则不写**（同速粘贴不长出多余 BPM 横线）；跨度内事件按同一 `deltaBeat` 平移写入，同拍已有 BPM 按既有粘贴规则原位替换 |
| 仅音符 | 只按 beat 平移音符，速度完全跟目标谱面 |
| 数值 | **绝对值照搬，不按 `目标 BPM / 片段 startBpm` 缩放**（花活就是"这个形状"；缩放还会产出 `-37.5` 这类非整数 BPM） |
| 尾部 | **不自动补"恢复 BPM"**：目标后文有 BPM 事件时负值天然被收住；没有时落成"末条 BPM 为负"，由 issue 142 既有警示（危险红 + `!`）当场暴露，用户自己收尾 |
| 结果 | 产物 = 新选区（同剪贴板）；写谱走既有 undo 与只读闸门 |

**为什么不是"收藏时选带不带"**：那会逼用户为"以后也许想不带 BPM 粘"预先存两条；而且收藏侧选"不带"是不可逆的信息丢弃。

### 3. 收藏、命名与浏览

| 项 | 定案 |
| --- | --- |
| 收藏入口 | 抽屉 footer「收藏选区」按钮 + 快捷键 `Ctrl+Shift+D`（新 `FunctionId`，进快捷键页、冲突拒绝；运行时被抢占则退 `Ctrl+Alt+C`）。无选区 = 无事发生、按钮置灰 |
| 反馈 | toast「已收藏到片段库」，**不自动打开抽屉**（别打断正在编辑的人） |
| 命名 | 「片段 N」，N = 库内最大序号 + 1，**删除不回收**；双击名字就地改名（Enter 提交 / Esc 取消，与 BPM 数字同一套就地编辑词汇） |
| 卡片必须元素 | 缩略图 + 名字 + 徽标（`含 BPM 变化 · n` / `含倒流`）+ hover 菜单（导出 / 删除）。列数、卡片高、缩略图比例、间距**留给实现票**，本票不钉像素 |
| 缩略图 | 由音符 + 速度语境**实渲染**（不存位图），按**布局轴**取景（倒流折返才画得对）；无 BPM 变化时用 `startBpm` 铺 |
| 浏览 | 收藏时间倒序；顶部常驻搜索框按名字子串过滤（不区分大小写），无匹配给空态；不做按徽标 / 音符数筛选 |
| 粘贴开关 | **画布左上角选项胶囊**（照 180 Q15 曲线胶囊）：进粘贴态才出现、切走即消失、记住上次选择；内容 = `含 BPM 变化 · n` / `仅音符` |
| 只读谱面 | **卡片置灰** + tooltip 说明（与工具轨粘贴钮同语言）；但「收藏选区」照常可用——收藏读的是选区、不写谱面，与"已上传谱面允许选中 / 复制"同口径 |

### 4. 存储与分享

| 项 | 定案 |
| --- | --- |
| 存储 | **不进设置对象**（设置是"我的习惯"，片段是"我的素材"；混进去会让"导入别人的设置"顺手覆盖片段库）。Electron：数据根下独立文件；浏览器：IndexedDB 独立库 |
| 容量 | **不设硬上限**；v1 单文件全量载入（真实规模几百条 × 每条几十~几百音符在 10MB 内）；体量超阈值时提示导出备份。将来要分片属存储层改动，不动语义 |
| 导出 | 统一信封 `{ schemaVersion, exportedAt, patterns: [...] }`，**单条也用同一信封**（解析只有一条路）；含名字 / 音符 / 速度语境 / `spanParams`，**不含缩略图**；整库从抽屉头 ⋯ 菜单、单条从卡片 hover 菜单 |
| 导入 | **只合并、不做整库替换**（替换是危险键且误操作毁掉别人的积累）；每条生成**新 id**；**允许重名**（名字是标签，不改写别人起的名字——与"副本命名"那条**对象复制**规则区分）；坏条目 / 版本不认识 → 跳过并报数，不整包失败 |
| 删除 | 卡片 hover 删除钮 → 既有弹窗壳 `sm` 确认 → 立即删（不建撤销栈） |

### 5. 与既有模型的关系

- **剪贴板**：并行。点卡片**不写剪贴板**——粘贴态负载来源 = 该片段，退出后剪贴板仍是原来那份；复制 / 剪切行为不变。
- **ADR-0008**：片段粘贴复用同一持工具态（驻留 / 幽灵预览 / 单击即贴 / Esc 退出 / 走 paste 行），只是负载来源多一个；此态下再点工具轨「粘贴」= 切回剪贴板来源。
- **ADR-0010 / issue 142**：倒流区片段照常允许；不拦、不补线，末条负值靠既有警示色。
- **ADR-0002**：新增 `execSavePattern` 一个 FunctionId。

## 实现落点（已拆 184–187，见 Answer）

- 数据层：`src/chart/patterns/`（类型 / 拷贝与剥 `source` / 摘速度语境 / 存储后端接口 + 两个实现）
- Electron：`electron/dataRoot.cjs` 增数据根下片段文件 + `electron/preload.js` 新桥（照 `backgroundSkin` 先例）；浏览器：IndexedDB 独立库
- UI：`src/pages/workspace/PatternLibraryDrawer.tsx` 内容（卡片 / 搜索 / 空态 / 页脚按钮 / ⋯ 菜单）、粘贴态胶囊
- 交互：`ToolActionMatrix` paste 行接片段负载、`WorkspacePage` 收藏执行键、`ShortcutConfig` 加 `execSavePattern`、i18n 两语言

## 锁测

- 载荷：收藏剥 `source`；`startBpm` 取最后一条 `≤ minBeat`；事件区间是 `(minBeat, maxBeat]` 且 `deltaBeat` 归一
- 粘贴：同值跳过 / 异值写入 / 同拍替换 / 仅音符不写任何 BPM / 包围盒锚点与剪贴板一致 / 只读闸门拦截
- 存取与分享：信封 round-trip、坏条目跳过并报数、导入生成新 id 且允许重名
- 单测覆盖不到的（拖拽幽灵预览、胶囊开合态）走 Playwright 手工验收清单
