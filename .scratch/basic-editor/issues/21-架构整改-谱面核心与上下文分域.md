## Question

按 improve-codebase-architecture 架构评审（候选 A/B/C/D）推进代码重构整改，为 issue 10（密集音符性能）与 ADR-0003（工作台 UI 与配置）打地基。这些是对**既有决策的实现**（非新决策），不新增 ADR。

## Answer（已执行，2026-08-10）

分 4 个 Phase 落地，每笔独立提交、tsc + vitest 全绿：

### Phase 1 · 谱面核心（候选 B+C，commit `1d1802c`）
- 统一 BPM 换算：新增 `BpmTimeline`（单一 BPM 段遍历器 + 段缓存），`ChartGeometry` 的 beat↔virtualY 与 `AudioTiming` 的 beat↔秒共享同一事件表，消除两份平行累加的时间轴漂移风险。
- 坐标几何收敛到 `ChartGeometry`（trackGeometry/beatToVirtualY/virtualYToBeat/noteVirtualY/visibleNotes/laneBeatFromCanvas），全部 O(log BPM) 缓存查询。

### Phase 2 · 上下文分域（候选 A，commit `ca9c5b6` + `3588d52`）
- 按 ADR-0003 §7 拆 `EditingContext`（音符/历史/选择/剪贴板）、`UIContext`（面板/缩放/工具态）、`ConfigContext`（settings），并新增 `PlaybackContext`；`Editor` 收为组装层，子组件经 hooks 直读各域，消除 13 个逐层透传 props。

### Phase 3 · FinalVirtualCanvas 拆薄（候选 B 收尾，commit `c55a703`）
- 新增 `src/renderer/` 纯模块：`render.ts`（15 个 render* 纯绘制）、`hitTest.ts`（findItemAt/computeItemsInBox/pointInQuad）、`coords.ts`（makeCoords 坐标封装）、`types.ts`（RenderCtx 依赖注入）。
- `FinalVirtualCanvas` 从 1600+ 行收为薄层：只保留挂载/生命周期/事件/RAF，每次组装 RenderCtx 调 renderChart。
- 新增渲染/命中/坐标单测 10 用例（`tests/unit/RendererHitTest.test.ts`）。

### Phase 4 · 历史轻量化（候选 D，commit `7b71fd4`）
- 新增纯模块 `src/utils/History.ts`（createHistory/pushHistory/undoHistory/redoHistory，可单测）。
- **结构共享快照**：所有编辑函数均不可变（未改动音符复用原引用），快照直接存引用，不再每次全量 `structuredClone` —— 密集谱面击键从 O(n) 深拷贝降为 O(1) 数组存储，**正面回应 issue 10 第三问**。
- `notes` 改以历史栈为单一真相源；修复原 undo/redo 在 `setHistoryState` updater 内调用 `setNotes` 的 impure updater（React StrictMode 双调用副作用）。
- 新增 History 单测 6 用例（含结构共享语义验证）。

## 收益

- 编辑状态与 UI/配置解耦，ADR-0003 的主题/布局/配置改动不再牵动整棵树。
