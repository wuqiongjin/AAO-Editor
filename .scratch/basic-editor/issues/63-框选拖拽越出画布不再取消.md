# 63 · 框选 / 拖拽手势越出画布不再被取消

Type: task
Status: resolved（2026-09-09 实现落地，**方案选择待用户验收确认**）
Blocked by:

## 来源

issue 55/56 验收后用户复报的遗留问题 #4（2026-09-09）。用户问：这是 bug 还是设计？哪种逻辑更合适？

## 现状

`FinalVirtualCanvas` 的 `<canvas onMouseLeave>` 无条件清空整套按下态：

```
selectionStartRef = null; selectionMovedRef = false; dragRef = null;
setSelectionBox(null); setDragGhost(null);
```

→ 框选矩形拉到画布外瞬间消失、手势作废；音符拖拽同理（拖出画布 = 静默取消）。

## 本轮采纳 = 方案 a（**待用户验收确认**，非用户预先定案）

用户在本轮只提出"这算不算问题、哪种逻辑更合适"，未预先拍板。经比较后本轮按方案 a 实现，验收时若用户选择另一种语义，回滚点在 `handleMouseDown` 的 window 监听与 `clampToSurface` 两处。

**推荐理由**：业界编辑器与文件管理器的框选都是「越出继续、在框外松手照常结算」；画布还额外有"谱面比可视区大"的事实——**框一条跨屏长滑条、把选区拉到底部再往下扩**是本编辑器的常规操作，现状直接禁掉了它。

改为**隐式指针捕获**语义：

- `mousedown` 后在 `window` 上挂 `mousemove` / `mouseup`（抬手或组件卸载即摘），画布自身的 `mouseleave` **不再清按下态**。
- **框选矩形钳在画布内**：越界坐标钳到 `[0, surf.w] × [0, surf.h]`（视觉上框不会跑到工具栏上），结算用钳后的框。
- **拖拽幽灵在画布外消失**：`snapPos` 出轨/出谱面 = 非法落点（ADR-0008 §1），照旧"幽灵不见、松手回弹"——这是既有语义，不因本票改变。
- **hover 类反馈在画布外一律关闭**：`hoverPos` / `mousePosition` 出界即置 null（实时显示线、放置幽灵、hover 描边都不画），回到画布内自动恢复。
- 画布外松开**框选** = 用钳后的框正常结算；画布外松开**拖拽** = 落点非法 → 回弹。

## 实现落点

| 文件 | 改动 |
| --- | --- |
| `src/chart/components/canvas/FinalVirtualCanvas.tsx` | `handleMouseDown` 里 `window.addEventListener('mousemove'/'mouseup', …)`（经 ref 转发到最新闭包，避免每渲染重挂）；新增 `clampToSurface(cx, cy)`；`onMouseLeave` 收窄为"只清 hover 态"；卸载兜底摘监听 |

纯逻辑部分（钳制 + 出界判定的坐标换算）若有必要抽到 `src/visual/coords.ts` 或就地小函数并补测。

## 验收

- 框选起点在画布内，拖到画布外（上/下/左/右四个方向都试）：矩形保持存在并被钳在边缘，画布外松手 → 选区按钳后的框建立。
- 持键型工具 / Slide 工具态下同样可以越出框选（批量替换 / 组合）。
- 拖一个音符出画布：幽灵消失、松手回弹、谱面不变；拖回画布内松手 → 正常落位。
- 光标出画布时实时显示线 / 放置幽灵 / hover 描边都不残留。
- 回归：右键删除、BPM 就地编辑、左沟槽双击起点标记不受影响。

## Comments

- 2026-09-09 实现：`handleMouseDown` 里 `attachWindowGesture()`（window 上只挂一次稳定壳，经
  `gestureHandlersRef` 转发到最新一帧处理器），`handlePointerUp` / 组件卸载 `detachWindowGesture()`；
  `onMouseLeave` 收窄为只清 `hoverPos` / `mousePosition`（实时显示线、放置幽灵、hover 描边、状态栏读数出界即关）。
- 框选矩形的光标端经 `clampToSurface` 钳进渲染面（起点仍锚在虚拟坐标，bug 32 语义不变），画布外松手用钳后的框照常结算。
- 拖拽出画布**不钳**：`snapPos` 出界 = 非法落点 → 幽灵消失、松手回弹（ADR-0008 §1 既有语义，本票不改动）。
- 失焦（`window blur`）走 `up(null)`：只收手势态，不触发任何动作，避免"焦点回来时以为还按着"。
- 验收：纯手势逻辑在 React 组件内，无单测接缝，靠浏览器实测（四方向越出 + 画布外松手 + 拖拽回弹）。
