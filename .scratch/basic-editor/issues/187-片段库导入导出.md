# 187 · 片段库：导入导出

Type: feature
Status: resolved
Blocked by: 184, 185

**来源**：[164 片段收藏](./164-片段收藏.md) 定案 §4；权威 = [ADR-0023](../../../docs/adr/0023-片段收藏的载荷与存储边界.md)。第 4 刀 —— 让片段库能分享（用户原话："便于把自己的片段库分享给其他人"）。

**现状**：184 只做信封的序列化 / 解析，没有文件读写与入口。

**修法**：

- **入口**：抽屉头 ⋯ 菜单 = 「导出片段库」/「导入片段库」；卡片 hover 菜单的「导出」= 单条。
- **写文件**：照既有先例（`chartCodeExport.saveAs` / `preview.saveBinary`）——Electron 走桥，浏览器走 Blob 下载；用户取消保存 = 什么都不发生。
- **读文件**：`<input type="file">`（两环境同一路），`accept=".json,application/json"`。
- **文件名**：整库 `aao-patterns-YYYYMMDD.json`；单条 `<片段名>.aao-pattern.json`（名字里的非法文件名字符替换为 `_`，不改库里存的名字）。
- **导入语义**（数据层已在 184）：**只合并、不替换**；每条新 id；允许重名；反馈按实际结果报数 —— 成功「导入 N 条」、部分「导入 N 条，跳过 M 条」、整包拒绝（版本不认识 / 不是片段文件）单独文案。
- i18n：zh-CN + en。

**锁测**：

- `tests/dom/workspace/PatternShareMenu.test.tsx`（新增）：⋯ 菜单两项、卡片「导出」导出的是该条、取消保存不写盘。
- `tests/dom/workspace/PatternImport.test.tsx`（新增）：合法文件 → 合并且条数正确、含坏条目 → 报「N 条 / 跳过 M 条」、版本不认识 → 整包拒绝且不动现有库。
- `tests/unit/chart/patterns/PatternFileName.test.ts`（新增）：文件名清洗与日期格式。
- 文件选择与下载在浏览器里的真实行为 → 手工验收（Electron 与网页各一次）。

## Answer

2026-10-31 实现：

- **文件层** `src/chart/patterns/shareFile.ts`：整库文件名按**本地日期** `aao-patterns-YYYYMMDD.json`；单条 `<片段名>.aao-pattern.json`（非法字符与控制字符换 `_`、尾点 / 尾空格去掉、清洗后为空回落 `pattern`；**信封里的名字原样不动**）。另存照 `chartCodeExport` / `saveBinary` 先例：Electron 走 `electronAPI.patternLibrary.saveAs`（系统对话框，取消 → `{ cancelled: true }` 且静默），浏览器降级 Blob 下载。读文件两环境同一路动态 `<input type="file">`，`accept=".json,application/json"`，FileReader 读文本。
- **导入** `usePatternLibrary.importFromText`：等首次载入 → 184 的 `parsePatternsFile` 逐条校验（id 已重发）→ 合并进现有库 → **一次整库落盘**；只合并不替换、允许重名，排序沿用 `createdAt` 倒序。坏条目只计价不阻断；读失败 / 整包解析失败 / 落盘失败分别返回，读失败时**一条都不写**（沿用 185 的「读不出来禁止写」）。
- **入口**：抽屉头 ⋯ = 「导出片段库」/「导入片段库」（空库 / 未载入完成时导出置灰）；卡片 ⋯ = 单条「导出片段」。两个菜单共用 `useAnchoredMenu`（定位 / Esc / 回焦只留一份）。导入反馈：成功「导入 N 条」、部分「导入 N 条，跳过 M 条」、空文件、整包拒绝（版本不认识 / 无法解析 / 读失败）各自文案。
- **Electron**：`main.cjs` 注册 `patternLibrary:saveAs`（dialog + basename + JSON 过滤器）；`preload.js` 暴露 `patternLibrary.saveAs`。i18n zh-CN + en 新增全部文案，删掉 185 的 `exportSoon` 占位。
- **评审修订**：主进程 JSON 另存处理与 `chartCode:saveAs` 共用 `saveJsonWithDialog`；导出失败文案改通用「导出失败」；导出置灰提示按载入中 / 读失败 / 空库分档；移除未被消费的保存结果类型；导入锁测改条件等待，并补「单条导出失败」用例。
- **锁测**：`PatternFileName.test.ts`（5 例）、`PatternShareMenu.test.tsx`（5 例）、`PatternImport.test.tsx`（5 例）、`PatternLibraryHook.test.tsx` 增「读失败导入拒绝」、`PatternBackendWiring.test.ts` 增跨进程另存桥静态锁；`PatternLibraryDrawer.test.tsx` 的导出占位置灰断言改为可用。
- **验证**：`tsc -b` 0；eslint 改动文件无新增；全量 vitest 368 文件 / 4034 例全绿；`npm run build` 通过。
- **待手工验收**：Electron 与网页各一次真实文件选择 / 保存对话框 / 浏览器下载（jsdom 只能锁到 `<input type="file">` 与桥上发出的 JSON / 建议文件名）。

## Comments

- **2026-10-31 验收修订（用户）**：整库导出文件名从 `aao-patterns-YYYYMMDD.json` 改为 `aao-patterns-YYYYMMDD-HHmmss.json`（本地时间），避免同一天多次导出重名；单条 `<片段名>.aao-pattern.json` 不变。
- **2026-10-31 验收修订（用户）**：导入信封的 `schemaVersion` 缺失 / 不是数字时归为「片段文件无法解析」（不再出现「不支持的片段文件版本：undefined」）；只有数字版本不认识才报版本不支持。
