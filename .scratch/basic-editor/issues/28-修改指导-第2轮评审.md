## A. P1+P2+P8 — 工作台左右面板：浮层 + 窄轨 + 左侧默认 380

**目标行为**
- 左右面板**不再作为独立列**占位（不再压缩中间画布）：画布区始终占满工作台剩余宽度。
- 面板展开时**悬浮在画布之上**（绝对定位覆盖画布左侧 / 右侧），带阴影、可拖拽调宽（上限如 30vw），点画布空白或 Esc 可收起。
- 面板折叠时在**原边缘渲染 34px 窄轨**（参考 prototype `.workspace-rail`）+ 展开按钮，而非现在的「折叠后按钮藏在拖拽条上」。

**现状（改动点）**
- [Editor.tsx](file:///workspace/src/pages/Editor.tsx#L489-L515)：左侧面板是 flex 流内独立列 `width: leftCollapsed ? 0 : min(...)`，折叠时宽度归 0，展开按钮挂在 4px 拖拽条上（[L528-L545](file:///workspace/src/pages/Editor.tsx#L528-L545)）。
- 右侧面板同理（[L616-L704](file:///workspace/src/pages/Editor.tsx#L616-L704)）。
- 布局根是 `display:flex`（[L490](file:///workspace/src/pages/Editor.tsx#L490)）。

**技术方向**
1. 把编辑根容器设为 `position: relative`；中间画布列保持 `flex:1`（全宽）。
2. 左右面板改为**绝对定位覆盖层**：展开态 `position:absolute; top:0; bottom:0; left/right:0`，宽度 `min(左380px / 右300px, 30vw/24vw)`，`zIndex` 高于画布，加 `box-shadow` 与边框；折叠态渲染 34px 窄轨（绝对定位在边缘，垂直居中一个展开按钮）。
3. 拖拽调宽：保留 `startDrag('left'|'right')`，改为拖面板边缘（窄轨也可当手柄）。
4. 收起时机：点画布空白 / Esc 触发 `toggleLeftPanel/toggleRightPanel`（画布空白点击已由 `onMouseDown` 处理，注意别与放音符冲突——用「未命中音符/轨道」区域或空点击判定，避免误收）。
5. **默认宽度**：`AppSettings.defaultSettings().layout.leftPanel.width` 470 → 380（[AppSettings.ts](file:///workspace/src/utils/AppSettings.ts#L28-L31)）；右侧 300 不动。注意 `settings.layout.leftPanel` 已有持久化值会覆盖默认，可在开发期清 localStorage 验证，或按「读取时兜底 380」处理。
6. 窄轨样式复用 prototype：`.workspace-rail`（34px、`.left-rail/.right-rail`、展开按钮 `PanelLeftOpen/PanelRightOpen`）——从 `PageShellPrototype.css` 复制到 `Editor` 所在样式域即可。

**验收**：画布宽度不再随面板开合变化；折叠后边缘有可见窄轨+按钮；展开浮层有阴影、可拖拽、可点画布空白收起。

**改动**

## D. P5 — 双击快捷键行打开编辑弹窗

**现状**
- 只有点击键位按钮（`.key-binding`，`onClick={() => setEditingId(f.id)}`）才打开编辑。

**改动**
1. 给 `.shortcut-row` 加 `onDoubleClick`，打开该行编辑：`onDoubleClick={() => setEditingId(f.id)}`。
2. 防误触：`onDoubleClick` 内先判断 `if ((e.target as HTMLElement).closest('button')) return;`——这样双击「启用」开关或「键位按钮」不会重复触发（键位按钮单击已可编辑）。

**验收**：双击行（非按钮区域）弹出键位录制弹窗；双击开关/键位按钮不冲突。

## E. P6 — 谱面时长上限 30 分钟（1800s）

**现状**
- `PlayBar.tsx` 时长输入 `type="number" min={1}` 无 `max`（[PlayBar.tsx L74-L88](file:///workspace/src/components/PlayBar.tsx#L74-L88)）。
- `AudioPage.tsx` 时长输入同样无上限。
- `Editor.tsx` 的 `handleDurationChange` 只校验 `sec > 0`。

**改动**
1. 定义常量 `MAX_DURATION = 1800`（可放 `src/utils/` 或组件内）。
2. 两处输入 `max={1800}`；`onChange` 解析后夹紧到 `[1, 1800]`。
3. `Editor.handleDurationChange` 内同样 `if (!(sec > 0)) return; sec = Math.min(sec, 1800);` 兜底（音频锁定模式不经过此路径）。

**验收**：输入 >1800 被钳制；滑块/输入无法设超 30 分钟。

## F. P9 — 代码编辑器：修闪烁 + 按钮压文本

**现状（根因）**
- 闪烁：外层卡片 `transition: 'flex var(--dur) var(--ease)'`（[NoteInfoPanel.tsx L439](file:///workspace/src/components/NoteInfoPanel.tsx#L439)）——每次展开/折叠动画 `flex` 触发整块回流，表现为闪烁。
- 覆盖：`textarea` 设 `minHeight: 260`（[L497](file:///workspace/src/components/NoteInfoPanel.tsx#L497)），而其父容器是 `flex:1; minHeight:0`（[L488](file:///workspace/src/components/NoteInfoPanel.tsx#L488)）。当可用高度 <260 时，textarea 向下溢出到其下「工具栏」（应用更改/重置/复制）区域，按钮压住代码文本。

**改动**
1. **移除** `transition: 'flex ...'`（L439）——折叠/展开改为瞬切（snap），不闪。若想要平滑：把内容包一层 `height` 动画的占位容器，而非动画 `flex`。
2. `textarea` 的 `minHeight: 260` → `minHeight: 0`（保留 `height:100%`），让 flex 父容器（`flex:1; minHeight:0`）真正约束高度，工具栏固定在下沿、互不覆盖。
3. 复核：外层卡片 `overflow:hidden` 保持；确认工具栏 `flex-shrink:0`（当前是普通 div，靠 `borderTop` 分隔，无碍）。

**验收**：展开无闪烁；代码区与「应用更改/重置/复制」按钮不重叠，按钮始终在文本下方。
