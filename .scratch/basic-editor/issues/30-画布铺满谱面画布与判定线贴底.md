## Question

编辑器画布当前为固定缓冲 750×900 + `object-fit: contain` 显示在"谱面画布"sticky 容器内，导致：
1. 窗口比例与 750:900 不符时画布四周留黑边/留白，与谱面画布区域不贴合；
2. 判定线绘制在画布底部上方 60px（`JUDGE_LINE_Y = CANVAS_HEIGHT - 60`），下方留空轨道，与画布底边割裂；
3. 画布尺寸固定，无法真正铺满谱面画布区域。

目标（ADR-0006 定案）：画布铺满谱面画布、任意窗口比例贴合；判定线以画布下边边缘为准；轨道不变形、性能不劣化。

## 复现

- 拉宽/拉高窗口使比例偏离 750:900，观察画布四周黑边；
- 观察判定线位于画布底边上方 60px、下方有网格空轨。

## 期望

- canvas 铺满谱面画布区域（任意窗口比例无黑边/留白）；
- 判定线 = 画布下边边缘 = PlayBar 正上方；
- 轨道水平居中、不变形、7 轨始终完整可见（过窄自动收缩）；
- 缩放/resize 后判定线处秒数稳定（复用 issue 24 按秒重锚）；
- 缓冲 = surface × min(dpr,2)，绘制/命中用 CSS 像素，性能不劣化。

## 方案（ADR-0006 映射）

1. **ChartGeometry.ts**：构造器加 `surface:{w,h}`（默认 {750,900}）；`JUDGE_LINE_Y` → surface.h（贴底）；新增 `effectiveScale(scale)=min(scale, fitWidth(surface.w))`；所有常量引用改由 surface + effectiveScale 推导。
2. **render.ts / types.ts**：`canvas.width/height = surface×dpr`，`setTransform(dpr)`；`RenderCtx` 注入 surface/dpr；清屏/背景/网格/判定线/边界线按 surface 尺寸；判定线 y=surface.h。
3. **Editor.tsx**：`chartAreaRef` 挂 ResizeObserver 算 `surface` 传给 canvas；sticky 容器去掉 `padding: var(--space-5)`；surface 并入 issue-24 重锚 key，resize 按秒重锚。
4. **FinalVirtualCanvas.tsx**：接收 `surface` prop；`geometry` 依赖加 surface；canvas 样式 `width/height:100%`（去 contain）；`cssToCanvas` 返回 CSS 像素；scroll 相关改用 `surface.h/effectiveScale`。
5. **测试**：更新 ChartGeometry.test.ts / RendererHitTest.test.ts；新增动态 surface、判定线贴底、effectiveScale 钳制用例。

## 验证

- `tsc -b` 通过；vitest 全绿。
- 浏览器实测：任意窗口比例下画布铺满谱面画布、无黑边；判定线在画布最底、PlayBar 正上方；7 轨完整可见不变形；resize 后判定线处秒数不变。
