# 137 · 曲线工具点选区内应组合并刷缓动

Type: bug
Status: resolved
Blocked by: —

## 来源

用户 2026-09-21：框选后曲线工具点选区内音符，应对齐 Slide 的整片组合，并额外刷当前缓动（= 曲线 Shift+框选同一行）。现状是挂两击锚点。

## 症状

有选区时点选区内音符 → 画笔起手清选区 → 松手走两击第一击。矩阵「命中 ∈ 选区」分支到不了。

## 修法

1. `resolvePressIntent`：无 Shift、命中 ∈ 选区 → 不启画笔（退回框选仲裁）；松手未拖 = 单击。
2. `curveToolClickOps`：命中 ∈ 选区 → 复用 `curveBoxOps`（issue 88：单击 = 框选行）。
3. ADR-0008 issue 88 补曲线行；ADR-0009 §3 记选区内单击例外。

## 锁测

- `ToolActionMatrix.test.ts`：曲线「先框选再点选区内 ≡ Shift+框选」。
- `CurveTool.test.ts`：选区内按下 ≠ 画笔。
- `GestureSession.test.ts`：选区 ≥2 单击选区内 → `setNotes` 成条且带缓动，无 `setCurveBuffer`。

## Answer

按下命中选区内不启画笔。单击复用 `curveBoxOps`。ADR-0008 issue 88 与 ADR-0009 §3 已记。
