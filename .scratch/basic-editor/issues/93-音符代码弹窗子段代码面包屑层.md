## 来源

用户 2026-09-12：音符代码工具选中 slide 的**段**或**中间结点**时，希望额外增加一层面包屑，专门显示**该子段**的音符代码（仅当滑条有中间结点时出现；无中间结点的滑条没必要显示）。

## 现状

弹窗只有 note（整条）/ node（单结点）两档（`NoteCodeOps.ts:20-24, 42-60`）；noteCode 工具点中**段**（slideRegion）时 connIndex 被丢弃、回退整条滑条视图（`ToolActionMatrix.ts:213-225`）；无任何"子段"展示。面包屑为 trail 机制三层（`ChartCodeEditorProvider.tsx` / `ChartCodeEditorModal.tsx:346-383`，issue 69 定案）。

## 定案（用户 2026-09-12）

- 新增**子段代码**层：进入目标 = 滑条**段**（slideRegion）或**中间结点**（slideNode 且非端点）时出现。
- **整条滑条只有一个逻辑段时（如 `A—B`、`A—H—B`）→ 隐藏子段层**（用户 2026-09-12 拍板）：单段的段视图与「所属滑条」层内容完全相同，属冗余。即段层出现条件 = **逻辑段 ≥2**（可见结点 ≥3）。
- 段 = `SlideSegments` 逻辑段口径（跨 hidden）；段代码 = 该段序列化为独立 Slide JSON（**含段内 hidden**，与复制/剪贴板同口径，`SelectionEditing.ts:241`）。
- **可编辑回写**：应用时把该段 connections 整体替换回宿主滑条（`splice(start, end−start+1, 新段)`），替换后按 `validateChartCode` 同口径校验（首/尾 hidden 非法等），非法整单拒绝。
- 面包屑扩为四档：完整谱面代码 › 所属滑条 › **子段代码** › 滑条结点代码（实现口径，待验收）；trail 扩展记录段区间。

## 修法（落点细化）

1. **`NoteCodeTarget` 扩展**（`NoteCodeOps.ts:20-24`）：加段区间字段 `span?: { start: number; end: number }`（宿主滑条 connections 的实下标闭区间，含段内 hidden）。
2. **入口不再丢段**（`ToolActionMatrix.ts:213-225`）：noteCode 工具命中 `slideRegion` → target 带该逻辑段的 span（现状是把 connIndex 丢掉、回退整条视图）；命中**中间结点**（slideNode 非端点）→ 同样算出所属逻辑段的 span 附上；命中端点 → 维持现状（结点视图，无段层）。**仅当宿主滑条逻辑段 ≥2 才附 span**；单段滑条维持现状（slideRegion 回退整条、slideNode 走结点视图）。
3. **`NoteCodeOps` 新增两个纯函数**：
   - `buildSegmentCode(notes, target)`：`spanConnIndices` 取段内全部实下标（含 hidden）→ 材质化为独立 Slide（同 `copySelection` 口径，`SelectionEditing.ts:241`）→ 走 `convertNotesToChartCode` 包成单元素数组（与整条音符视图同形态）。
   - `applySegmentCode(notes, target, code)`：解析 → 恰好 1 条 Slide → `splice(start, end−start+1, 新段)` 整体替换回宿主滑条 → `validateChartCode` 同口径校验 + 宿主级收口（替换后整条仍须 ≥2 结点、首/尾不得 hidden），非法整单拒绝不回写。subBeat 代码侧无从表达：新段结点数与原段一致时逐结点保留原 subBeat（同结点视图口径，`NoteCodeOps.ts:124`），结点数变化（在段里加/删结点）则新增结点取缺省值。
4. **`ChartCodeEditorModal`**：视图判定加 segment 档；逻辑段 ≥2 时面包屑四档 `完整谱面代码 › 所属滑条 › 子段代码 › 滑条结点代码`，**单段滑条维持 issue 69 三层口径**；trail 记 span。默认视图口径：点**段**进入 → 默认段视图；点**中间结点**进入 → 维持默认结点视图（现状），面包屑多出"子段代码"层可点。
5. 与 issue 60 划界：60 的"导出选中"维持"触碰即整条"，段级查看/编辑只在本弹窗入口。

## 段代码示例（待用户核实）

展示形态与「整条音符视图」**完全同构**：单元素 JSON 数组，元素是 `{"type":"Slide","connections":[…]}`；
字段规则同 `convertSlideNote`（`ChartConverter.ts:181-200`）：beat/lane 恒有，hidden/flick/skill 仅 true 时输出；
**绝对 beat**（不相对段首）；段内 hidden 结点如实保留。

例：滑条 connections = `[A(beat 8, lane 2) / H(beat 10, lane 3, hidden) / B(beat 12, lane 4) / C(beat 16, lane 4, flick)]`
（两个逻辑段：A→H→B、B→C），4 空格缩进（`chartCodeToJSON`，`ChartConverter.ts:213-215`）：

点**段1**（A→B，跨过 hidden H）→ 子段视图显示：

```json
[
    {
        "type": "Slide",
        "connections": [
            { "beat": 8, "lane": 2 },
            { "beat": 10, "lane": 3, "hidden": true },
            { "beat": 12, "lane": 4 }
        ]
    }
]
```

点**段2**（B→C）→ 显示：

```json
[
    {
        "type": "Slide",
        "connections": [
            { "beat": 12, "lane": 4 },
            { "beat": 16, "lane": 4, "flick": true }
        ]
    }
]
```

应用（回写）= 把编辑后的 JSON 的 connections 整体替换回宿主滑条对应段区间；段外结点不动；段两端结点
（与相邻段的衔接点）被改 beat/lane 时相邻段自然跟随（同一条滑条）。把整段编辑成只剩 1 个结点也允许，
只要替换后整条滑条仍合法（≥2 结点、首/尾非 hidden）。

**单逻辑段滑条（如 `A—B`、`A—H—B`）→ 不出现子段层**（用户 2026-09-12 拍板）：此时段视图与「所属滑条」层
内容完全相同（冗余）；点段维持现状回退整条视图，点结点维持结点视图，面包屑三层不变。

## 锁测

- `NoteCodeOps.test.ts`：段 → 独立 Slide JSON 逐字段断言（含 hidden）；`applySegmentCode` 替换回宿主、段外结点不动、越界/段首尾 hidden 拒绝；产物过 `validateChartCode`。
- 面包屑四档与层级切换：组件单测或静态断言；**单段滑条（`A—B` / `A—H—B`）点段/点结点 → 无子段层、面包屑维持三层（issue 69 口径）**，`A—B—C`（两段）→ 段层出现；Playwright/手工验收：点段进入默认子段视图、可切层、应用后画布更新、undo 一步回退。
