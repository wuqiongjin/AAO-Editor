# 206 · 显示面板切语言选项文案残留与选项窄收敛

Type: bug
Status: resolved

## 来源

代码健康审查（`CODE_HEALTH_REVIEW_REBUTTAL.md` 问题二与问题七）：
页面保活挂载时，运行时切换语言（zh-CN ↔ en-US），显示面板内的部分下拉选项文案未跟随刷新。

## 症状与根因

- **症状**：切换界面语言后，[PreviewDisplayPanel.tsx](file:///d:/Company/WorkSpace/MocaCoffee/bangdream-editor/src/pages/preview/PreviewDisplayPanel.tsx)（时间标记、节拍标记、画质、网格选项），以及 [WorkspaceDisplayPanel.tsx](file:///d:/Company/WorkSpace/MocaCoffee/bangdream-editor/src/pages/workspace/WorkspaceDisplayPanel.tsx)（画质、网格、时间精度、变形风格选项）仍显示切换前的旧语言标签。
- **根因**：上述选项数组使用空依赖 `useMemo(..., [])` 缓存了 `t(labelKey)`，而 `t()` 读取的是模块内部响应状态，空依赖数组阻断了重新计算。

## 修法

1. **清除空依赖缓存**：直接移除这些仅有 2~8 项元素的小数组的 `useMemo`，直接在渲染期求值（开销微秒级完全可忽略），避免空依赖阻断或不必要的 hooks 依赖心智负担；同时消除 `skinName` 的 eslint warning。
2. **窄收敛共享常量**：新建 [src/pages/displayPanelOptions.ts](file:///d:/Company/WorkSpace/MocaCoffee/bangdream-editor/src/pages/displayPanelOptions.ts)，提取工作台与预览页完全同质的画质档（`QUALITY_OPTIONS`）与网格颜色（`GRID_OPTIONS`）选项配置及 `buildQualityOptions` / `buildGridOptions` 构造函数，严格限制于显示面板内部（WorkspaceDisplayPanel & PreviewDisplayPanel），不扩散至选曲等业务面板。

## 锁测

1. **DOM 行为测试**：
   - `tests/dom/workspace/WorkspaceDisplayPanel.test.tsx` 新增「运行中切界面语言，下拉选项文案（画质 / 轨道颜色 / 时间精度 / 变形风格）立即更新为对应语言」用例。
   - `tests/dom/preview/PreviewDisplayPanel.test.tsx` 新增「运行中切界面语言，下拉选项文案（时间标记 / 节拍线 / 画质 / 轨道颜色）立即更新为对应语言」用例。
2. **已有测试保护**：全量 380 个测试文件（4,270 个单测）与 92 个静态锁测全部通过。
