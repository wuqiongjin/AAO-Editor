# 97 · 左侧工具栏默认宽度对齐右侧面板

Type: feature
Status: resolved（2026-09-12 实现 + 锁测，待你在页面验收）
Blocked by:

## 来源

用户 2026-09-12 第五批复报：工作台页面左侧工具栏默认宽度偏大，最好减少到与右侧面板默认宽度一致。

## 症状 / 根因

默认宽度两套公式（`UIProvider.tsx:52-53`）：左 = `min(380, 30vw)`、右 = `min(300, 20vw)`；1280 视口实测左 380 / 右 300（差 80px）。CSS 兜底值也不一致（`AppShell.css` `.ws-panel-left` 兜底 240 / `.ws-panel-right` 280，仅 JS 未注入时可见）。

## 修法

左面板默认宽度改用与右面板**同一公式**（`min(300, 20vw)`），两处共享常量/纯函数防再分叉；CSS 兜底值顺手对齐。注意：面板宽度有持久化（`useLayoutPersistence` → IndexedDB），本票只影响**未持久化的新会话**，老用户已保存的宽度不变（符合「默认宽度」语义）。

## 锁测

- 默认宽度抽纯函数（如 `defaultPanelWidth(innerWidth)`）后单测：左右同源同值；或静态断言两处公式一致。
- **Playwright 实测**：首屏 `.ws-panel-left` 与 `.ws-panel-right` offsetWidth 相等（验证阶段已用量宽脚本手法）+ 手工验收拖拽改宽后仍各自持久化、互不影响。

## Comments

    UIProvider useState 初值），故两处都要改——只改 UIProvider 的话用户看到的仍是 380/300。
  - `AppSettings`：新增 `DEFAULT_PANEL_WIDTH`(300) 与 `defaultPanelWidth(innerWidth)`（min(300, 20vw)）；
    出厂默认左右面板同宽 300（normalize 缺省分支自动跟随）。
  - `UIProvider`：左右两个 useState 初值都走 `defaultPanelWidth(window.innerWidth)`（hydrate 前首帧也同宽）。
  - `AppShell.css`：`.ws-panel-left` 兜底 240→300、`.ws-panel-right` 280→300（JS 注入后失效，仅对齐口径）；
    max-width 视口夹取（30vw/24vw，issue 87）不动。
  - 锁测：新 `tests/unit/PanelWidth.test.ts`（公式 1 / 出厂默认 1 / UIProvider 接线静态断言 1 / CSS 兜底 1）。
