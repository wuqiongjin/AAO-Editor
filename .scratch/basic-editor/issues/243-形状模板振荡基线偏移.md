# 243 形状模板振荡基线偏移

- **Type**: grilling
- **Status**: resolved（定案于 grill-with-docs 2026-11-21；已实现）
- **关联**: [ADR-0009](../../../docs/adr/0009-SP绿条与段曲线模型.md) · [CONTEXT.md](../../../CONTEXT.md) · 前置 [235](./235-曲线工具形状模板扩充与图形化选型.md) · [240](./240-形状模板阶梯端点插值与专属配置项.md) · [241](./241-形状模板参数自由调节模式.md)

## 来源

用户针对震动条、余震等形状模板提出：当前振荡绕起终点弦正中对称，希望增加一项**模板专属选项**，让振荡基线可以横向偏移。经 Q1–Q9 三轮 `grilling`，2026-11-21 用户确认拍板，frontier 为空。词汇 **振荡基线偏移** 已写入 `CONTEXT.md`。

---

## 现状与根因

1. **相对弦偏移型一律绕弦均值 0 摆动**（`bakeTemplatePoints`：`lane = lerp(from, to, t) + sign × off × TEMPLATE_AMPLITUDE × amplitudeScale`）。震动条 `off = ±0.45`、余震条带包络仍关于 0 对称；「偏向」只翻 `sign`，不平移均值。
2. **带体「中心线」已被占用**（ADR-0009 §5 / `slideBandGeometry` = hidden 采样折线），不能拿来命名这项参数。
3. **尖刺档位按钮把百分数焊进文案**（`起拍 0%` / `居中 50%` / `尾拍 100%`），与幅度「小/中/大」、即将落地的基线「贴左/居中/贴右」不一致；`curveConfigSummary` 对 `range` 专属项一律输出数值，档位模式未命中词。

---

## 定案（Q1–Q9 全量汇总，用户 2026-11-21 拍板）

1. **Q1 = A（平移，峰峰值不变）**：`off` 振荡宽度不变，整串相对弦平移。端点仍钉在弦上。余震尾部振幅 → 0 时 hidden 点收敛到**偏移后的基线**，再拉回终点可见结点——接受。
2. **Q2 = B（六款双侧摆动模板）**：`zigzag`（震动条）、`damped`（余震条）、`gluten-spindle`（面筋·螺旋）、`gluten-saw`（面筋·斜纹）、`chain-square`（锁链·方波）、`chain-alt`（锁链·拉链）。不做：尖刺 / 阶梯 / 平滑弧弯 / 梳齿 / 竹节。
3. **Q3 = A（相对该模板半幅的百分比）**：`0` = 弦上对称；`±100%` = 峰峰值不变且一侧贴弦（半幅 = 该模板特征 `|off|` 峰值：zigzag `0.45`、damped `0.75`、spiral `0.85`、saw `0.75`、square `0.55`、alt `0.6`）；缺省 `0`，旧谱无字段行为不变。
4. **Q4 = A**：模板专属 `extraParams` `kind: 'range'`，键 **`baseline`**；按模板 ID 记 `settings.curve.templateExtras`，段上 `SpanTemplateParam.extra`；不升 `schemaVersion`。
5. **Q5 + Q6 = A（与偏向正交，落实真镜像）**：  
   `lane = 弦插值 + AMP × ampScale × (sign × off + (baseline/100) × half)`。  
   「贴右」= 往 **lane 增大**；「偏向」只改齿序。`H` = 结点真镜像 + 翻转 `mirrored` + **`baseline` 取反**（`mirrorValue: v → -v`）。基线加在 `sign` **外侧**，避免双翻。
6. **Q7 = A**：档位快捷点 `-100 / 0 / +100`；自由调节 `-200% … +200%`，步长 `5%`。
7. **Q8 = A**：沿用 241 **模板参数模式**，无第二套开关。面板标签 **基线**（英 `Baseline`）。档位三键 `贴左` / `居中` / `贴右`；自由 = 滑块 + 数值 + `%`，双击行标签或滑块复位 `0`。
8. **Q9 = A（`range` 专属项档位用词）**：档位按钮不焊百分数。尖刺改为 `起拍` / `居中` / `尾拍`（英 `Start` / `Mid` / `End`）；几何与 `0/50/100` 极值同拍起跳/收口不变。折叠胶囊：档位命中写词、**默认专属值不占摘要**（基线 `0`、尖刺 `50`）、自由或非预设写 `25%` / `-200%`。

> **2026-11-22 起，Q9 的后半段（摘要口径与尖刺中文用词）已被 [245](./245-胶囊摘要默认值占位与居中撞词.md) 修订**：默认值也占摘要；尖刺档位词由 `居中` 改为 `中段`。本文其余定案（几何、六款名单、档位词本身、自由范围）不变；下文「实现落点 2」「锁测 3」里的对应句子同此失效。

## 实现落点

1. **内核（`ShapeTemplates.ts`、`SpanCurve.ts`）**：六款声明同一 `baseline` schema（`range` −200…200 step 5，unit `%`，presets −100/0/100，`mirrorValue` 取反）；`bakeTemplatePoints` 对声明了 `baseline` 的相对弦偏移型按上式叠加；`resolveTemplateExtra` / `stripDefaultTemplateExtra` 沿用。
2. **配置与摘要（`CurveTool.ts`、`curveLabels.ts`）**：`normalizeCurveConfig` 钳制 `baseline`；`spanParamFromCurveConfig` 仅非默认写入 `extra.baseline`；`curveConfigSummary` 对所有 `range` 专属项走 241 Q9=1b + 本票 Q9（档位命中 `labelKey` 词、默认跳过、否则 `formatTemplateNumber` + `%`）。
3. **面板 / SVG / i18n**：`extraParams` 声明即渲染，无需特判行；网格与胶囊迷你图透传 `extra`；`zh-CN` / `en` 补 `curve.extra.baseline*`，并改 `curve.extra.pulsePos.start|center|end` 去掉百分数。
4. **ADR-0009**：十七轮之后追加一轮，写入振荡基线偏移几何、正交公式、六款名单与尖刺档位用词修订。

---

## 锁测清单

1. **几何与镜像（`ShapeTemplates.test.ts`、`SpanCurve.test.ts`）**：同轨震动条 `baseline = 100` 一侧贴弦（一侧 `off` 等效 0）、峰峰值仍为 `2 × 0.45 × AMP × ampScale`；`baseline = 200` 整串离弦；余震尾部 hidden 靠近偏移基线而非弦；`H` 后 `baseline` 反号且与真镜像逐点吻合；`mirrored` 只翻齿序不翻「贴右」的 lane 方向；旧谱无 `extra` 回落 0 且不抛错。未列入的模板（尖刺/阶梯/大弧等）无 `baseline` 行、烘焙不含该键。
2. **配置（`CurveTool.test.ts`）**：越界钳进 ±200、步长 5；六款模板 ID 独立记忆；默认不写盘。
3. **DOM / 摘要（`CurveOptionsCapsule.test.tsx`）**：震动条档位出现 `贴左|居中|贴右`，尖刺档位为 `起拍|居中|尾拍`（无 `0%` 焊在钮上）；自由模式基线滑块可到 ±200；折叠摘要默认不写基线/50%、档位命中写 `贴左`/`起拍`、自由写 `-200%`/`25%`；中英文无漏译。
