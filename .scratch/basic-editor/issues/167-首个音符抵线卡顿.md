# 167 · 首个音符抵线（键音发声）时卡顿一下（首次打开 / 换未用过的皮肤）

Type: bug
Status: resolved（2026-10-10 已定位根因并由用户决策 Q1=C, Q2=A, Q3=A 闭环修复与复测验证；2026-10-29 冷机真实音频与动态预览残余症状跟进见 [179](./179-冷启动首次播放首音符与BGM出声同刻卡顿.md) 与 [chart-preview/57](../../chart-preview/issues/57-动态预览首次播放首音符入场与抵线卡顿.md)）
Related: [101](./101-播放起始卡顿.md), [165](./165-首次播放卡顿.md), [179](./179-冷启动首次播放首音符与BGM出声同刻卡顿.md), [chart-preview/57](../../chart-preview/issues/57-动态预览首次播放首音符入场与抵线卡顿.md)

## 来源

用户 2026-10-10 反馈：首次打开程序、或换一个之前没用过的皮肤后，在谱面画布播放，当第一个音符到达判定线被播放时会卡顿一下。与 #101 / #165 同族，怀疑一直未真正解决，至今可复现。

## 症状

- 触发 = 会话内"冷"态：首次打开程序，或换未用过的音符皮肤；同皮肤第二次播放不复现。
- 时刻 = 不是点播放瞬间，而是第一个音符抵线（键音发声）前后的一帧长停顿。

## 根因与定量分析（用户机真实谱面 + 音频实测确认）

测试环境与素材：
- 谱面：`150030.json`（BPM 225，1754 音符，首个实体音符在 beat 20 / 5.333s，前 5.3s 纯空白）
- 音频：`Henceforth (covered by 燈) [short ver.].mp3`
- 仪器：自动化 CDP CPU Profiler + 浏览器真机探针

**根因坐实：**
1. **空白瓦片掩盖了补建成本**：开播前 0~4.7 秒由于没有音符，所有瓦片均为秒建（耗时 0.01ms），用户感知不到卡顿；
2. **首块实体非空瓦片突发命中**：当播放推进到 4.7s（时间码 00:04.7，首音符抵线前约 0.6s）时，预取队列首次触及全谱第一块非空瓦片（瓦片 8）；
3. **冷计算集中爆发**：瓦片 8 在单个宏任务内同步执行 `drainOnePlayingTile`（6.9ms）+ `rasterBandRuns` 滑条光栅（6.3ms）+ 皮肤图集冷启动解码与整张 mip-chain 构建（≈2× 图集像素一次性成本）；
4. **单帧打穿**：宏任务补建与 rAF 绘制同帧叠加，导致该帧耗时飙升至 **91.7ms**（严重掉帧 5~6 帧），给用户带来强烈的“抵线卡顿一下”感；
5. **排除项**：音频调度 `bufferSource.start` 耗时 <0.1ms，非瓶颈。

## 方案定案（用户决策：Q1=C, Q2=A, Q3=A）

1. **组合拳策略（Q1=C）**：
   - 静止期靶向预热：开播前在静止状态主动把全谱首个实体非空瓦片加入预热队列，在静止空闲帧完成图集解码与 mip-chain 构建；
   - 播放期单帧节流：`schedulePlayTileDrain()` 在 `rc.playing === true` 时将补建间隔设为 16ms（~1 帧），保证单帧至多补建 1 块瓦片，避免连环宏任务挤压渲染帧预算；静止期维持 0ms 快速排空。
2. **首个非空瓦片定位（Q2=A）**：
   - 在 `ChartGeometry` 增加 `firstNotePosition(notes, beatDisplay)`，利用既有 `ensureNoteIndex` 缓存查找首个非 BPM 音符的最小 `pos`；
   - `noteLayerCache.ts` 导出 `firstNonEmptyTileIdOf(rc)`，静止期直接将该瓦片 append 到 prefetch 队列。
3. **冷启动与换肤图集成本自然消化（Q3=A）**：
   - 换肤或冷加载后的首块非空瓦片在静止帧预热绘制时，自然触发 `CanvasSpriteIcon.getMipLevelSource` 完成图集构建与缓存，无需额外的 dry-run 机制。

## 验证与锁测结果

1. **真机自动化探针复测**：
   - 在相同谱面（`150030.json`）与音频下，监测 4.0s ~ 5.5s 首音符抵线全窗口：
   - 掉帧统计：`gapsOver25 = 0`，`gapsOver50 = 0`；
   - 帧率表现：帧间隔稳定恒定在 16.6ms 满帧平滑运行，原 **91.7ms** 的卡顿彻底消除。
2. **测试覆盖**：
   - `tests/unit/chart/geometry/ChartGeometry.test.ts`：新增 3 项 `firstNotePosition` 逻辑与边界单测；
   - `tests/perf/RendererPerf.test.ts`：新增 2 项 issue 167 锁测（验证静止期首实体瓦片纳入预热、验证播放期 16ms 节流与静止期 0ms 排空）；
   - 全仓回归：222 个测试文件（2436 条测试）全部 PASS，`npx tsc -b` 0 错误。
