# 218 · 判定线向上偏移（作为设置项）

Type: grilling
Status: resolved
Blocked by: —

## 来源

用户 2026-11-07 第 2 问：谱面画布支持调节最下面判定线的偏移，即**判定线向上偏移**，可作为一个设置项。
同日 grill Q1/Q2 均回「OK」，Q8 回「OK」⇒ 语义与控件口径定案见下。

## 症状

判定线固定贴画布底边，没有任何可调项；`src/pages/workspace/WorkspaceDisplayPanel.tsx` 的
「画布 / 播放与音频 / 操作偏好」三组里没有这一行。

## 根因（已核实，不是「少一个 y 变量」）

现行代码**没有一条被绘制的判定线**，也没有 `JUDGE_LINE_Y` 之类的可配常量。判定线是
**纯几何语义 = 渲染面底边 `surface.h`**，且是整个画布坐标系的基线原点：
`src/chart/geometry/ChartGeometry.ts:135-138` `baseline = chartEndVirtualY + surface.h / es`，
`src/playback/PlaybackScrollModel.ts:83-95` 的时间→滚动映射、`src/rendering/render.ts` 的 clip / cull /
起止线 / 时间刻度、`src/rendering/gutterLabels.ts:171-189` 的 BPM 钉线裁切、`hitTest` / `CanvasGesture`
的命中盒、静态预览 `src/preview/static/panelLayout.ts:152-158` 与宽图导出，全部从这一条式子派生。

两次 Accepted 定案把「可偏移」这件事拆掉了：

- `docs/adr/0006-画布动态渲染面与判定线贴底.md:21,43`：把 `JUDGE_LINE_Y = CANVAS_HEIGHT - 60` 的
  60px 偏移**取消**，改为 `surface.h`；
- `.scratch/basic-editor/issues/50-画布贴合回归与判定线视觉冗余清理.md:20-26,37-38`：把判定线
  **绘制本身删除**，语义改成「音符越过 `chartArea` 底边即被判定」。
- `CONTEXT.md:187`「判定线固定在画布底部」、`:238`「底边 = 判定线」；`docs/adr/0004:5` 与 `0006:5`
  都写明：**涉及该行为的变更须先更新 ADR 并经用户确认**。

⇒ 根因 = 需求与两次定案正面冲突，且「底边」同时承担**判定时刻 / 裁切边 / 滚动基线 / 读数界线**
四种语义；上移不是加个字段，而是要把这四种语义拆开重定。

## Answer（用户 2026-11-07 拍板 Q1 / Q2 / Q8 = OK）

**定案（用户 2026-11-07 拍板 Q1/Q2/Q8 + 2026-11-08 原型评审与实现确认）**

1. **判定线呈现**：偏移 > 0 时恢复可见判定线（街机光刃 + 7 轨精密卡榫 + 香槟金色系）；**偏移为 0 时完全隐匿**（贴底时由底栏天然充当判定基线，不重复绘制视觉冗余线条）。
2. 线下方**继续绘制已过线的音符**并覆盖 50% 半透明深色遮罩（给作者一段「刚过去」的可视余量并压暗聚焦）；画布裁切边仍是 `surface.h`，**播放 / 判定时刻锚在新线 y**。与仿真场「场地判定线」不是同一物（`CONTEXT.md:213`）。
3. 作用域 **只工作台画布**；静态预览面板 / 谱面图导出 / 仿真场明确**豁免**，并在 `src/rendering/displayOptions.ts` 写明例外（保持统一映射架构锁）。
4. 归属 = 全局设置 `settings.display.judgeLineOffsetRatio` 新字段，**默认 0 = 现行贴底**，范围 `[0, 0.4]`（步进 1% 滑杆），不随谱面工程走。
5. 设置项命名为「判定线偏移」（`Judge line offset`），放工作台显示面板**「画布」组**，排布在「纵向比例」之后，带向下展开的帮助气泡。
6. 实现顺序 = 先做 throwaway prototype → 再修订 ADR → 最后动产品代码。

**本轮实现口径（待验收，不是用户定案）**

- 播放 / 暂停 / 手滚三态同一位置（照 `CONTEXT.md:187` 常显口径）；
- BPM 数值 / END / 已过音符数 / 实时读数 / 标记点 / 命中盒的界线跟新线走，否则「判定线处秒数」
  与读数不一致。
