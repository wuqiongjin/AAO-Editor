## Question

应用 5 个页面（工作台 / 音频 / 素材 / 快捷键 / 设置）中，**4 个非工作台页面**的布局壳当前不一致：
- **音频**用"侧边次级索引（独立于正文外，3 tab） + 右侧 detail"
- **素材**用"页内类别子 tab（顶部 2 个）+ 单列内容"
- **设置**用"侧边次级索引（**在正文内**，分组） + 右侧 detail"
- **快捷键**用"页顶只读区 + 搜索 + 大表格，整页不动表格自身滚"

4 页在"页面头（`.page-intro`）"已共用，但页面头之后的内容布局形态各异：是否有次级索引、次级索引是顶部还是侧边、侧边是在正文外还是正文内、整页滚还是内嵌滚、容器宽度等 5 个维度都有差异。本轮目标：将这 5 个维度的差异收敛为一个**可复用模板** `<AppPageShell>`，4 页一次性迁移到模板上，并沉淀"未来加新页"用的决策清单。

## 期望

- 新建 `src/components/layout/AppPageShell.tsx`，以 compound component 形式暴露：
  - `<AppPageShell.Header eyebrow title description />`（沿用现有 `.page-intro` class，CSS 不动）
  - `<AppPageShell.Sidebar>` / `<AppPageShell.SidebarGroup title>` / `<AppPageShell.SidebarItem icon label>`（侧边索引；可空、可分组；激活态统一为"主色软底 + 主色文字 + 弱描边"）
  - `<AppPageShell.Body mode="default" | "fill" width="default" | "wide">`（内容模式与宽度档）
- 4 个页面（音频 / 素材 / 快捷键 / 设置）改写为调用上述模板：
  - **设置页**侧边索引从"正文内 168px"搬到"正文外 200px"（detail 区变宽是统一化产物，允许）；
  - **素材页**"页内顶部 2 个类别 tab"改为"侧边索引 2 项"（顶部 tab 本轮废止）；
  - **音频页**沿用"侧边索引"现状；
  - **快捷键页**不写 Sidebar，沿用 `mode="fill"` 整页不动、表格自身滚。
- 模板默认硬约束 4 处：Header 下间距 / Sidebar-Body 横向 gap / Sidebar 内 padding / Body 居中与 max-width；其它由 design tokens + 页面作者自管。
- 侧边宽度定 1 档 **200px**（以音频为准，4 页统一）。
- 切子类别保持 `useState`，**不写 URL/hash**（与"切页不写 URL"心智对称）。
- 视觉零变化（除设置页 detail 变宽这一处统一化产物）。
- 沉淀决策清单到 ADR-0007。
- CONTEXT.md 新增"应用页面壳"通用语言段。

## 实施步骤（Q19 顺序）

1. **基线截图**：迁移前用 Playwright 截 4 页 × {浅色 + 深色} = 8 张图存档（`/tmp/page-shell-baseline/*.png`），作为 Q10"视觉零变化"的对比基线。
2. **抽模板**：新建 `src/components/layout/AppPageShell.tsx`（含 5 个 namespace 子组件）；新增对应 CSS（BEM 化：`app-page-shell__sidebar` 等，**Header 沿用 `.page-intro`**）。模板写完先单独走 tsc + 1 个示例页（建议用 SettingsPage 的 JSX 草稿）验证 props 形状对。
3. **迁移设置页**（最复杂：分组侧边 + 详情区）：把 `.settings-index` 从 `.page-content` 内部搬到外部（独立侧栏），搬到 `<AppPageShell.Sidebar>` 下、用 `<AppPageShell.SidebarGroup title="应用设置">` / `<AppPageShell.SidebarGroup title="功能设置">` 分组。Body 仍走 `mode="fill" width="default"`（沿用现状，detail 高度由内容决定）。激活态走模板统一视觉（这一处视觉会变，**Q23 统一化产物**）。
4. **迁移音频页**（多 section 堆叠 + 平铺侧边）：把现状的 `.page-sidebar` 内容包到 `<AppPageShell.Sidebar>` 下，删 `AUDIO_SECTIONS` 与侧边 nav 的手写实现。Body 走 `mode="fill" width="default"`（**改动**：现状是默认整页滚；如需保留"切换到本页自动暂停播放并保留位置"提示，调整至 page-intro 描述句）。3 个 section（音频素材 / 键音素材包 / SE 音量）继续在 Body 内自管。
5. **迁移素材页**（2 类别平铺侧边）：**Q3.1 决定**——把页内 `.assets-tabs`（顶部 2 tab）改为 `<AppPageShell.Sidebar>` 下 2 个 `<AppPageShell.SidebarItem>`（`音符皮肤` / `背景皮肤`）。Body 内容保持现有 `NoteSkinPanel` / `BackgroundPanel` 各自实现。`width="wide"`（沿用现状的 `.is-wide` 1040px）。
6. **迁移快捷键页**（无侧边 + fill）：不写 Sidebar；Body 走 `mode="fill" width="default"`（沿用现状，表格自身滚）。Header 的页顶只读区"应用级快捷键"从 `APP_SHORTCUTS` 数组保留（与 `<AppPageShell.Header>` 三字符串不冲突）。
7. **基线对比**：用 Playwright 同样条件截 8 张图，与第 1 步基线**像素 diff**或**人工逐页对比**。视觉差异仅允许：①设置页 detail 变宽；②4 页侧边激活态统一化；③素材页"页顶 2 tab → 侧边 2 项"的位置变化（同一视觉、容器换了）。其它差异 = bug。
8. **tsc / test / build / eslint** 全部绿。
9. **issue 收口**：本文件 `## Answer` 段填实施记录、`Status: resolved`；CONTEXT.md 新增段已就位；ADR-0007 已就位。
