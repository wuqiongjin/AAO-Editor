# 168 · 工作台播放条支持双击时间输入秒数跳转

Type: bug
Status: resolved
Blocked by: none

## 来源与症状

用户反馈：工作台页面的 playbar 当前不支持输入自定义秒数（无法双击时间码编辑跳转），期望与动态预览的 playbar 行为完全一致。

## 根因

在 `src/pages/workspace/WorkspacePage.tsx:551` 中，向 `PlayBar` 传递属性 `canEditTime={!canPlay}`。
当工程加载了音频后，`canPlay` 为 `true`，导致 `canEditTime` 被计算为 `false`，从而禁用了时间码双击编辑。
而动态预览 `PreviewVideoStage.tsx:444` 中则是无条件传递 `canEditTime={true}`。

## 修法

在 `src/pages/workspace/WorkspacePage.tsx` 中移除 `!canPlay` 门禁，直接传递 `canEditTime={true}`（或 `canEditTime`），使工作台有音频时同样支持双击时间码输入秒数精准跳转，行为与动态预览对齐。

## 锁测

- `tests/dom/workspace/` 或工作台播放条测试中增加断言：在音频已加载（`canPlay = true`）状态下，工作台 `PlayBar` 的当前时间码依然具备 `is-editable` 类名且支持双击进入编辑态。
