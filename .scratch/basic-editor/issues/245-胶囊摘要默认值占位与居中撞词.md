# 245 胶囊摘要默认值占位与「居中」撞词

- **Type**: grilling
- **Status**: open（定案于 2026-11-21 复核；待实现）
- **关联**: 修订 [243](./243-形状模板振荡基线偏移.md) Q9 · [241](./241-形状模板参数自由调节模式.md) Q9 · 前置 [244](./244-基线提为跨模板通用配置.md)

---

## 来源

用户复核曲线胶囊面板（问题 2）：部分配置项处于默认档位时，折叠摘要里就不出现了——看不到它存在，也就不知道自己现在是不是默认。同批 1b 把基线提为通用单值后，这个问题会更显眼（震动条默认态永远看不到「居中」）。

---

## 现状与根因

1. **两条规则打架**（`src/pages/workspace/curveLabels.ts:75`）：`range` 专属项 `if (val === spec.defaultValue) continue`（243 Q9），而 `choice` 专属项（如阶梯「斜坡」）、幅度 / 段密（`1×`）照常输出（241 Q9-1b「自由模式所有连续项统一按数值展示」）。实测折叠摘要：尖刺 `尖刺 · 右偏 · 中 · 标准`（位置 50% 消失）、震动条 `震动条 · 右偏 · 中 · 标准`（基线 0 消失）、阶梯 `阶梯 · 标准 · 斜坡`。
2. **默认值被当成「零操作」**：基线的零操作值是 `0`，尖刺位置是 `50`；同一条跳过规则把两者一起吞掉，语义上并不等价（前者是「不偏移」，后者是「正中」）。
3. **潜在撞词**：一旦默认也显示，基线「居中」（`curve.extra.baseline.center`）与尖刺位置「居中」（`curve.extra.pulsePos.center`）在中文里同词，若同模板共存会出现 `… · 居中 · 居中`（英文 `Center` / `Mid` 本来不撞）。

---

## 定案（用户 2026-11-21 拍板）

1. **默认值也占摘要**：删掉 `range` 专属项的默认值跳过；档位命中写档位词，否则写数值 + 单位。
2. **摘要顺序固定**：模板主名 → 偏向 → 幅度 → 段密 → 专属项（按声明序），自由模式同样。
3. **撞词改名**：`curve.extra.pulsePos.center` 中文由「居中」改为「**中段**」；英文 `Mid` 不变。基线保留「居中」。
4. **本期不改**：自由模式下幅度 / 段密都为默认时仍会显示 `1× · 1×`；是否合并为一项另议。
5. 本票**修订 243 Q9** 的「默认专属值不占摘要」；243 其余定案（档位按钮去百分数、几何）不变，ADR-0009 需追加一轮记录本次反转。

---

## 实现落点

1. **摘要**（`curveLabels.ts:67-86`）：去掉默认值 `continue`；`range` 项统一走「档位词 / `formatTemplateNumber` + 单位」。
2. **i18n**（`src/i18n/messages/zh-CN.json:1028`）：`curve.extra.pulsePos.center` → `中段`；同文件 `curve.extra.pulsePosHint` 的「峰值位置」措辞顺带核对，避免仍暗示「居中」。`en.json` 不动。
3. **顺序**：确认现有 push 顺序即定案 2；若 244 把基线改为单值读取，先取到值再 push，保持位置在专属项段。

---

## 锁测

1. **摘要（`CurveOptionsCapsule.test.tsx`）**：尖刺档位默认 → `尖刺 · 右偏 · 中 · 标准 · 中段`；震动条档位默认 → `震动条 · 右偏 · 中 · 标准 · 居中`；阶梯 → `阶梯 · 标准 · 斜坡`；自由模式非预设值仍写 `25%` / `-200%`。
2. **i18n**：`zh-CN` 与 `en` 键集合一致、无漏译；中文摘要中不再出现连续两个「居中」。
3. **回归**：243 已锁的「档位命中写词、自由写数值」用例保持绿（只改默认是否占位）。
