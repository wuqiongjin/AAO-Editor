# 204 · 滑条捏形默认风格配置与帮助气泡

Type: feature
Status: resolved
Blocked by: —

## 来源

2026-11-01 用户在 issue 203（圆滑捏形）完成后提出：
普通用户可能很难察觉到可以通过「Alt+拖拽」保留/切换旧版三角拉弓行为，且部分老用户可能偏好将经典三角拉弓设为默认模式。因此需要在界面中提供默认模式配置与交互帮助指引。

---

## 需求与定案（用户 2026-11-01）

1. **配置项位置**：
   - 放置于工作台顶栏的【画布显示与操作偏好面板】（`WorkspaceDisplayPanel.tsx`）中的【操作偏好】（`preferences`）组；
   - 与既有的「滚轮反转（`invertWheel`）」并列，离画布操作最近、易达且不干扰作谱流。
2. **配置项定义与术语**：
   - 配置字段：`settings.display.pinchMode?: 'smooth' | 'triangle'`，默认 `'smooth'`；
   - 界面标题：`滑条拖拽变形风格`（Slide Pinch Mode）；
   - 选项：
     - `smooth`：`圆滑曲线（默认）`
     - `triangle`：`三角拉弓（经典）`
3. **帮助气泡（HelpHint）**：
   - 配置项标题旁边放置 `?` 帮助气泡（复用 `src/ui/HelpHint.tsx`）；
   - 采用默认的 `placement="up"`（向上展开），避免在底栏向下展开撑破面板产生纵向滚动条；
   - 气泡内容详细解释两种模式的形变差异，并明确告知快捷键：
     > 设置在画布上直接拖拽滑条连接段时的默认形态。  
     > • **圆滑曲线**：贝塞尔平滑鼓包，峰值随光标丝滑走位，贴边时整体等比收缩；  
     > • **三角拉弓**：传统折线拉弓，峰值尖角分明，贴边时单点截断。  
     > 💡 *拖拽过程中按住 **Alt** 键可实时临时切换为另一种形态。*
4. **Alt 快捷键双向反转**：
   - 当默认为 `smooth` 时：拖拽中按住 Alt 临时切换为 `triangle`（三角拉弓）；
   - 当默认为 `triangle` 时：拖拽中按住 Alt 临时切换为 `smooth`（圆滑曲线）；
   - 松开 Alt 均即时恢复为默认模式。
5. **不增加碰壁视觉反馈**：
   - 用户明确：不需要触壁发光或碰壁浮动气泡，避免任何多余的视觉干扰，保持操作界面干净克制。

---

## 实现落点

1. **`src/chart/config/AppSettings.ts`**：
   - `AppSettings['display']` 新增 `pinchMode: 'smooth' | 'triangle'`；
   - 在 `defaultSettings` 中提供默认值 `'smooth'`；
   - 在 `normalizeSettings` 中做白名单校验，脏值或老版本缺失时安全回退 `'smooth'`。
2. **`src/pages/workspace/WorkspaceDisplayPanel.tsx`**：
   - 拓展内部辅助组件 `Row`，支持 `label` 传入 `ReactNode`（或增加 `hint?: ReactNode` 属性）；
   - 在【操作偏好】分组中增加该行配置，渲染 `Select` 下拉框；
   - 标题后挂载 `HelpHint` 组件（`placement="up"`）。
3. **`src/chart/components/canvas/FinalVirtualCanvas.tsx`**：
   - 在 `session.bindWorld({ ... })` 中，将 `pinchMode: display.pinchMode` 传入内核，串联 React 配置与会话内核。
4. **`src/chart/editing/GestureSession.ts`**：
   - `GestureWorld` 接口增加 `pinchMode?: 'smooth' | 'triangle'`；
   - 在 `dragDelta` 中根据默认模式与当前 `altKey` 动态计算生效模式：
     `const defaultMode = w.pinchMode ?? 'smooth';`
     `const pinchMode = defaultMode === 'smooth' ? (altKey ? 'triangle' : 'smooth') : (altKey ? 'smooth' : 'triangle');`
5. **`src/i18n/messages/zh-CN.json` 与 `src/i18n/messages/en.json`**：
   - 补充 `settings.pinchMode`、`settings.pinchMode.smooth`、`settings.pinchMode.triangle` 与 `settings.pinchMode.hint` 文本。
