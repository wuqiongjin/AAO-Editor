## Question

实施 [ADR-0003 §2](../../../docs/adr/0003-工作台UI与配置系统.md) 的入口直达（取消独立上传页），并把"加载音频"的入口形态从"顶部控制栏按钮"**升级为独立音频面板/页面**（工作台内以页面/Tab 切换访问），同时引入**最简页面切换底层**为后续多页面管理铺路。删除前置选歌页与 App 层入口状态机。

## 决策（grill-with-docs 已定案，2026-08-11）

- **删除前置页**：`App → SongUploader → Editor` 改为 `App → Editor` 直达工作台；删除 `SongUploader` 组件与 `inEditor`/`onBack` 入口状态机（`onBack` 一并移除）。
- **独立音频面板**：工作台内以页面/Tab 访问，承载 **导入 / 换 / 清除** 音频与**无音频时长编辑**；无音频可正常编辑，无音频时播放相关控件禁用或隐藏；保留"无歌曲模式"为常态。
- **时长语义（沿用 ADR-0005 §4 单一字段）**：有音频＝音频时长（锁定、不可调）；**清除音频 → 回到无音频模式，时长保留当前（音频长度）值、重新可编辑**；再次加载音频 → 音频时长再次覆盖。
- **最简页面 Tab 底层**：本期引入最小可用的"工作台 ↔ 音频面板"页面切换（仅支撑两个页面即可），为独立 issue（多页面管理）铺路，不做完整 Tab UX。
