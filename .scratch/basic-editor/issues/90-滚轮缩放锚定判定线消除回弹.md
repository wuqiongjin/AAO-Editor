# 90 · 画布内滚轮缩放锚定判定线（消除上部缩放回弹）

Type: bug
Status: resolved（2026-09-12 实现 + 锁测，待你在页面验收）
Blocked by:

## 来源

用户 2026-09-12 报：光标在画布上部（非判定线处）时 Ctrl+滚轮缩放，谱面音符会轻微上下回弹；光标在底部判定线处则没有。用户自行推测"缩放以光标为锚"并提议改为以判定线为锚。

## 症状

缩放时音符上下回弹（幅度不大）；仅当光标不在判定线附近时出现。

## 根因（代码已证实）

滚轮缩放以**光标为锚**：`FinalVirtualCanvas.tsx:760-788` → `zoomAnchorScrollY`（`ChartGeometry.ts:171-179`），
每 tick `ΔscrollY = (1/es1 − 1/es2)·(mouseY − surf.h)` —— 判定线（= 画布底边，issue 50 之后无视觉判定线）处恒为 0、越往上越大，与"底部没事、上部回弹"完全吻合。
回弹本体 = scrollY 的第二写入者（滚动条 onScroll 回写 `Editor.tsx:253-265`）在缩放的三段式提交窗口（scale+scrollY → virtualHeight → 写 DOM 高度/scrollTop，`FinalVirtualCanvas.tsx:715-725` + `Editor.tsx:212-234`）内用陈旧 scrollTop/maxScroll 反算覆写锚点 → 先跳回再追平，观感即"回弹"。ΔscrollY 越大的位置竞态越可见。

## 定案（用户 2026-09-12）

滚轮缩放锚点改为**判定线（画布底边）**，不再与光标位置挂钩 —— 与工具栏 ±/百分比缩放（`Editor.tsx:428-438` 只 setScale、scrollY 不动）口径完全统一。产品未发布，接受交互语义变更。

## 修法

- 滚轮 handler 不再调 `zoomAnchorScrollY`：setViewport 的 scrollY 分量保持原值（只改 scale，等价工具栏路径）；zoom 手势期瓦片 blit 窗口（240ms/250ms，`noteLayerCache`）照旧不受影响。
- `zoomAnchorScrollY` 失去唯一调用方 → 删除函数；`ChartGeometry.test.ts:206-256` 的锚定不变量用例同步删除（其中 m=h 底边退化本就是"scrollY 不变"）。
- 播放中 RAF 覆写 scrollY（`usePlaybackCoordinator.ts:87-108`）不在本票范围（播放中滚动本就由播放接管）。

## 锁测

1. 静态源码断言（照 `EditorAudioSessionRefactor.test.ts` 惯例）：wheel handler 不再引用 `zoomAnchorScrollY`、缩放提交的 scrollY 与缩放前相等；`zoomAnchorScrollY` 全库零引用。
2. 滚动条回写竞态是真实浏览器 DOM 时序，单测覆盖不到 → **Playwright/手工验收**：光标停画布上部连滚缩放，逐帧采样 scrollY 恒定、音符无上下位移（照 `scripts/measure-browser-zoom.mjs` 口径，脚本不入库）。
