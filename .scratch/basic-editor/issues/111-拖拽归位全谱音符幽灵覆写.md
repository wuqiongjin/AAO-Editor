Type: bug
Status: resolved

## 来源

用户 2026-09-16 验收问题 1：拖拽 SP 滑条中途（鼠标保持按下）移回原位时，全谱所有 SP 滑条材质高亮发荧光。

## 症状

在拖拽音符或 SP 滑条（捏形）过程中，鼠标移回原位（位移分量为 0）时，画布上**全谱所有 SP 滑条**的绿色材质明显加深、变亮（荧光高亮）。

## 根因

1. `FinalVirtualCanvas.tsx` 中 `setDragGhost(r.ghost ?? notes)`：当拖动 SP 带回到原轨道（`delta.dLane === 0`）或常规位移归零时，`planDragMove` 返回的 `r.ghost` 为 `undefined`，`?? notes` 导致 `dragGhost` 被误赋值为全谱所有音符数组。
2. `render.ts` 的 `renderSpBandStrip` 不受幽灵透明度约束（硬编码 `globalAlpha = 1` 贴回离屏缓冲），以 `source-over` 在原位置重叠绘制了一遍全谱所有 SP 滑条，导致半透明绿色二次叠加变亮。

## 修法

1. `FinalVirtualCanvas.tsx`：清除 `r.ghost ?? notes` 回退，位移为 0 或 `r.ghost` 为空/未产生位移时调用 `setDragGhost(null)`，仅在有实际有效位移且合法的音符集合上设置幽灵。
2. `NoteDragging.ts`：显式规定 `dBeat === 0 && dLane === 0` 或 `dLane === 0`（捏形）时返回 `ghost: undefined` 并在消费侧统一置空幽灵。

## 锁测

- 单元测试：`NoteDragging.test.ts` 断言位移为 0 时 `planDragMove` 的 `ghost` 为空或不包含未移动音符；
- 组件交互锁测：断言位移为 0 时 `dragGhost` 恒为 `null`，严禁包含 `notes` 全集。
