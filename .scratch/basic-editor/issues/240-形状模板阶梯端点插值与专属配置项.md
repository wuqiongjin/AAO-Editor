## 来源

用户针对 [235](./235-曲线工具形状模板扩充与图形化选型.md) 落地后的形状模板提出两项优化诉求，发起 `/grill-with-docs` 拍板语义与架构：
1. **阶梯（`step`）尾端折回问题**：放置斜向阶梯滑条时，阶梯尾端不应该折回终点，整体走向与跨度应由起终点统一决定；由此重新审视「偏向」等通用配置项对阶梯的适用性。
2. **可扩展的模板专属自定义配置项**：部分模板需要独立于通用项（偏向/幅度/段密/精度）的专属参数——例如尖刺（`pulse`）希望设置尖刺位置，支持拉到贴近起点处精准对齐鼓点；且架构需面向未来更多带专属参数的模板可扩展。

经 Q1–Q8 两轮 `grilling` 访谈与镜像口径澄清，全部设计边界已于 2026-11-21 由用户确认拍板，frontier 为空。

---

## 现状与根因

1. **所有模板强绑定「相对弦偏移」公式（`src/chart/editing/ShapeTemplates.ts`）**：
   - `bakeTemplatePoints` 统一计算 `lane = lerp(from.lane, to.lane, t) + sign * off * TEMPLATE_AMPLITUDE * ampScale`。
   - `step` 模板将 `off` 逐级抬升至 `1.0`（`t = 0.995`），而终点强制位于 `off = 0`，导致尾端猛然横折 `±2 × ampScale` 轨回拉到终点；同时每级踏板因叠加了斜弦 `lerp(from, to, t)` 而非严格竖直。
   - `buildTemplateSvgPath` 固定以垂直弦（`x = cx`）绘制所有模板预览，无法正确呈现端点插值型模板。
2. **模板缺少能力声明与专属参数模型（`src/chart/types.ts`、`src/chart/editing/CurveTool.ts`、`src/pages/workspace/CurveConfigPanel.tsx`）**：
   - 面板固定渲染「偏向 + 幅度 +（段密/精度）」三行，无法按模板实际能力隐藏无效通用项；
   - `SpanTemplateParam` 与 `CurveConfig` 无可扩展的模板专属参数槽位，无法承载如 `pulse` 周期内位置或 `step` 阶跃形态等差异化调节需求。

## 定案（Q1–Q8 全量汇总，用户 2026-11-21 拍板）

1. **Q1（双映射模型与通用参数能力声明）= A**：
   - `ShapeTemplate` 显式区分两种映射模型（`mappingMode`）：
     - **`'chord-offset'`（相对弦偏移型，默认，其余 17 款）**：相对起终点连线叠加横向偏移，支持 `偏向` 与 `幅度`；
     - **`'endpoint-interp'`（端点插值型，`step` 及未来同源模板）**：`lane(t) = from.lane + (to.lane - from.lane) × progress(t)`，整体走向与跨度完全由起终点决定，**起终点同轨（`from.lane === to.lane`）时自然退化为直线**（与缓动函数同口径）；声明 `supportsMirror: false`、`supportsAmplitude: false`，保持 `偏向` 语义纯洁。
2. **Q2 + Q6（阶梯 `step` 几何重构与专属选项）= C + 默认 `斜坡` + 旧工程按新模型重烘焙**：
   - 改为 `endpoint-interp`：`levels = clamp(round(span × 3 × densityScale), 2, 24)`，每级踏板均匀分布在 `0..1`（`k / (levels - 1)`），共 `levels` 级严格竖直踏板、`levels - 1` 次跃阶；首级贴 `from.lane` 竖直起跑、末级贴 `to.lane` 竖直进终点，彻底消除尾端折回与踏板倾斜。
   - 新增专属选项 **`stepStyle`（阶跃形态，`choice`）**：
     - **`sloped`（斜坡，默认）**：级间占单级拍宽 20% 短斜坡过渡；
     - **`sharp`（直角）**：级间使用 `Δbeat = 0` 同拍零高跃阶。
   - 旧工程里已保存的 `templateId: 'step'` 滑条在拖端点重投影时，直接按新模型 + 默认 `sloped` 重烘焙。
3. **Q3 + Q8（模板专属配置项架构与控件形态）= A+1 + Q8=B**：
   - **不支持的通用行直接隐藏**：面板仅渲染当前模板实际生效的通用项（如 `step` 隐藏 `偏向` 与 `幅度`，仅留 `段密` + `阶跃形态`）。
   - **声明式 Schema（`ShapeTemplate.extraParams`）**：本期支持两类通用控件：
     - **`choice`**：紧凑胶囊档位按钮；
     - **`range`**：紧凑滑块行（标签 + `<input type="range">` + 百分比读数，双击标签/滑块复位默认）+ 下方一排**紧凑快捷点胶囊**（如 `起拍 0%` / `居中 50%` / `尾拍 100%`）。
4. **Q4 + Q5（尖刺 `pulse` 专属「位置」语义与本期范围）= A+1 + Q5=A**：
   - 本期仅对 `step` 与 `pulse` 落地专属选项，其余模板保持现状，架构面向未来新模板即插即用。
   - `pulse` 新增专属选项 **`pulsePos`（位置，`range`，`0–100`%，默认 `50`%，快捷点 `起拍 0%` / `居中 50%` / `尾拍 100%`）**：
     - 沿用 `count = clamp(round(span × 2 × densityScale), 1, 24)`，控制**每个周期 `[a, a + w]` 内的尖刺峰位** `tPeak = a + w × pos`（半宽 `hw = 0.2`）；
     - `pos = 50%` 时与旧实现 `[a + 0.3w, a + 0.5w, a + 0.7w]` 逐点一致，100% 兼容历史谱面；
     - 中间值保留 `0.2w` 翼宽并将左右翼裁切进 `[a, a + w]`；
     - **极值 `0%` / `100%` 走 `Δbeat = 0` 同拍起跳 / 收口**（`pos = 0%` 时在每周期起拍 `a` 处零延迟瞬间扎出尖刺并斜回弦线，首周期 `k = 0` 与起始可见结点同拍起跳，精准踩鼓点；`pos = 100%` 在周期末段斜升后同拍收口），由 `displayConnections` 稳定排序保持数组序。
5. **Q7（持久化、缩略图联动、胶囊摘要与 `H` 水平镜像）= A+2 + 确认**：
   - **按模板 ID 独立记忆**：`CurveConfig` 增量追加 `templateExtras?: Record<string, Record<string, number | string>>`，存入 `settings.curve`，**不提升 `schemaVersion`**；`SpanTemplateParam` 追加可选 `extra?: Record<string, number | string>`（仅存非默认或全量规范化存储，老工程/老设置缺省回落各模板默认值）；拖端点重投影与整条复制完整保留。
   - **SVG 缩略图联动**：网格卡片与收起态胶囊迷你图实时随当前专属选项重绘；`endpoint-interp` 模板在 SVG 预览中改按**左下 → 右上斜弦**绘制（同缓动预览），避免同轨预览退化为直线。
   - **收起胶囊摘要（`curveConfigSummary`）**：同步跳过当前模板不支持的通用项（如 `step` 不再输出 `右偏 · 中`）；专属项**仅非默认时附加短值**（如 `step` 默认 `阶梯 · 标准`、切直角时 `阶梯 · 标准 · 直角`；`pulse` 默认 `尖刺 · 右偏 · 中 · 标准`、调至 `0%` 时 `尖刺 · 右偏 · 中 · 标准 · 0%`）。
   - **`H` 水平镜像**：所有可见与隐藏结点正常执行 `lane → 6 - lane` 真镜像；`chord-offset` 模板按既有口径翻转 `param.mirrored`，`endpoint-interp` 模板因起终点镜像后 `(to.lane - from.lane)` 自动反号，**无需写入/翻转 `mirrored`**；`stepStyle` 与 `pulsePos` 属时间/过渡属性镜像不变，参数 schema 预留可选 `mirrorValue` 钩子服务未来横向不对称专属项。

## 实现落点

1. **模板内核与类型（`src/chart/types.ts`、`src/chart/editing/ShapeTemplates.ts`、`src/chart/editing/SpanCurve.ts`）**：
   - `SpanTemplateParam` 新增可选 `extra?: Record<string, number | string>`；
   - `ShapeTemplate` 新增 `mappingMode?: 'chord-offset' | 'endpoint-interp'`、`supportsMirror?: boolean`、`supportsAmplitude?: boolean`、`extraParams?: readonly TemplateExtraParamSpec[]`（支持 `'choice'` 与 `'range'` 两种规格，含 `presets` 与可选 `mirrorValue`），并提供 `resolveTemplateExtra(tp, raw)` / `normalizeTemplateExtra(tp, raw)` 纯函数；
   - 重写 `step`（`endpoint-interp` + `stepStyle: 'sloped' | 'sharp'`）与 `pulse`（`pulsePos: 0..100` + 极值同拍起跳/收口）；
   - `bakeTemplatePoints` / `bakeTemplateParam` 支持 `endpoint-interp`（同轨返回 `[]`）与 `extra` 透传；
   - `mirrorSpanParam` 按模板能力判断是否翻转 `mirrored`，并对带 `mirrorValue` 钩子的专属参数做变换。
2. **曲线配置持久化与摘要（`src/chart/editing/CurveTool.ts`、`src/pages/workspace/curveLabels.ts`）**：
   - `CurveConfig` 新增 `templateExtras?: Record<string, Record<string, number | string>>`；`normalizeCurveConfig` 逐模板白名单校验合法值与范围钳制；
   - `spanParamFromCurveConfig` 按模板能力裁剪无效通用字段（如 `step` 不带 `mirrored` / `amplitudeScale`）并写入非默认 `extra`；
   - `curveConfigSummary` 跳过不支持的通用项，仅在专属项偏离默认值时追加短文案。
3. **预览 SVG 与配置面板 UI（`src/pages/workspace/curveSvg.ts`、`CurveMiniSvg.tsx`、`CurveConfigPanel.tsx`、`CurveConfigPanel.css`、`CurveOptionsCapsule.tsx`）**：
   - `buildTemplateSvgPath` 支持 `endpoint-interp` 斜弦预览与 `extra` 透传；
   - `CurveConfigPanel` 隐藏模板不支持的通用行，按 `currentTemplate.extraParams` 声明式渲染 `choice` 胶囊与 `range` 滑块 + 快捷点胶囊；网格卡片与胶囊迷你图传入对应模板的当前 `extra` 实时重绘。
4. **双语词典（`src/i18n/messages/zh-CN.json`、`src/i18n/messages/en.json`）**：
   - 补齐 `stepStyle`（`阶跃形态` / `斜坡` / `直角`）与 `pulsePos`（`位置` / `起拍` / `居中` / `尾拍`）等中英文词条及提示。

## 锁测清单

1. **模板几何与镜像单测（`tests/unit/chart/editing/ShapeTemplates.test.ts`、`SpanCurve.test.ts`）**：
   - `step` 在异轨（如 `1 → 5` 与 `5 → 1`）下每级严格竖直、单调朝向终点、尾端绝不折回；`sloped` 含短暂斜坡过渡、`sharp` 含 `Δbeat = 0` 同拍跃阶；同轨（`3 → 3`）退化为直线；
   - `step` 经 `H` 水平镜像（`1 → 5` → `5 → 1`）后 `mirrorSpanParam` 不设置 `mirrored`，且拖端点重投影后轨迹仍与真镜像逐点吻合；
   - `pulse` 在 `pulsePos = 50` 时与旧 `[0.3, 0.5, 0.7]` 逐点一致；`pulsePos = 0` 在 `k = 0` 与后续周期起拍处产生 `Δbeat = 0` 同拍起跳且经 `displayConnections` 稳定保序不裁切；`pulsePos = 100` 在周期末同拍收口；中间值如 `5%` 保持连续折线且时间弱单调；
   - 历史旧工程 `step` / `pulse`（无 `extra`）加载与重投影自动回落默认值且不抛错。
2. **配置持久化与归一化单测（`tests/unit/chart/editing/CurveTool.test.ts`）**：
   - `normalizeCurveConfig` 兼容缺失 `templateExtras` 的旧配置，剔除未知模板/非法键、钳制越界数值；
   - `spanParamFromCurveConfig` 对 `step` 不写入 `mirrored`/`amplitudeScale`，正确携带非默认 `extra` 并支持按模板 ID 独立记忆。
3. **面板与胶囊 DOM 交互测试（`tests/dom/workspace/CurveOptionsCapsule.test.tsx`）**：
   - 选中 `step` 时隐藏 `偏向` 与 `幅度` 行，展示 `段密` 与 `阶跃形态（斜坡 | 直角）`，切换后回调更新 `templateExtras.step` 且卡片与胶囊 SVG 实时变化；
   - 选中 `pulse` 时展示 `位置` 滑块与 `起拍 / 居中 / 尾拍` 快捷点，点击 `起拍` 立即写入 `0`、双击复位回 `50`；
   - `curveConfigSummary` 跳过不支持的通用项，默认态不追加专属短值、非默认态正确追加；中英文无漏译。
