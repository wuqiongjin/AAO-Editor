# 209 · 工作台顶栏谱面工程与谱面切换器样式与自适应优化

Type: grilling
Status: resolved
Blocked by: —

## 来源

用户 2026-11-02 附图反馈并通过 `/grill-me` 对齐工作台顶栏左侧工程名与谱面切换器的视觉与交互缺陷：
1. 谱面工程名字在超出宽度时直接被硬切断（如 `Redemptio` 末尾字符生硬切掉），未正常绘制省略号 `...`，且鼠标悬停 `title` 仅为「回工程管理页」，无法感知完整原名；
2. 谱面切换器（ChartSwitcher）中的下拉箭头在点击展开下拉菜单时没有任何交互反馈或朝向变化；
3. 工程名写死 `max-width: 200px`，宽屏下中间留白巨大但曲名依然被截断；且需要保证未来顶栏右侧新增组件时能自动优雅让宽收缩。

## 根因

1. `.chart-switcher__crumb` 在 CSS 声明中虽然写了 `overflow: hidden; text-overflow: ellipsis;`，但按钮本身为 `display: inline-flex`，其直接子节点为纯文本节点，部分排版引擎在 flex container 直接裁切文本时仅做 clip 处理而未生成省略号字符；且 `title` 属性仅绑定了固定的 `t('workspace.switcher.crumbTitle')`。
2. `<ChevronDown size={14} />` 为裸组件，未绑定展开状态类，亦缺少类似 `ScopePicker` 和 `PreviewChartSwitcher` 中的平滑旋转动画规则；且缺少 `aria-hidden` 无障碍属性。
3. Crumb 上限硬编码为 `max-width: 200px`，缺少响应式视口断言；未利用弹性布局的天花板规则（`min(360px, 28vw)` / `min(440px, 34vw)`）。

## 定案（用户 2026-11-02 拍板）

1. **工程名省略号与 Tooltip 规范（Q1=A）**：
   - 将工程名文字包入专用 `<span className="chart-switcher__crumb-name">`，并设置标准 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`，彻底根治 `inline-flex` 容器内直放纯文本节点导致排版引擎 clip 而不画省略号的 bug；
   - 悬停 `title` 采用全站一致的 ` · ` 拼接规范：`${displayProjectName(project)} · ${t('workspace.switcher.crumbTitle')}`（如 `Retribution ~ Cycle of Redemption · 回工程管理页`）。
2. **下拉箭头交互动效（Q2=A）**：
   - 对齐全站 `ScopePicker` 与 `PreviewChartSwitcher` 规范，为 Chevron 图标添加 `.chart-switcher__caret` 与 `.chart-switcher__caret.is-open`，并带 `aria-hidden`；
   - CSS 实现 180° 平滑翻转（`transform: rotate(180deg)` + `var(--dur-fast) var(--ease)` 过渡），并带 `prefers-reduced-motion: reduce` 保护；外层按钮本体保持默认样式。
3. **响应式自适应宽度与弹性让宽（Q3=A）**：
   - 工程名 Crumb 从固定 `max-width: 200px` 放宽为响应式天花板 `max-width: min(360px, 28vw); min-width: 0; flex-shrink: 1;`；
   - 当前谱面 Switcher 协同设置 `max-width: min(440px, 34vw); min-width: 0; flex-shrink: 1;`；
   - 在 1440/1920 宽屏下长歌名舒展展开；在小窗、窄屏或未来右侧新增组件占据空间时，依靠 `flex-shrink: 1` 自动让宽并收敛至省略号，绝不挤爆右侧控制簇（兼容既有 issue 174 守卫）。
4. **顶栏结构布局（Q4=A）**：
   - 保持现有顶栏整体 flex 排版与撤销/重做位置不变，改动严格闭环在 `ChartSwitcher` 内部。

## 实现落点

- `src/pages/workspace/ChartSwitcher.css`：crumb 响应式上限 `min(360px, 28vw)`，current 响应式上限 `min(440px, 34vw)`，`crumb-name` 的 ellipsis，`.chart-switcher__caret` 的 180° 翻转与 reduced-motion 兜底。
