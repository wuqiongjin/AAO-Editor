# 162 · 无音频恢复后音频页谱面时长仍为默认 30s

Type: bug
Status: claimed
Blocked by: —

## 来源

用户 2026-09-26 #1。grill Q1=OK。

## 症状

无音频调过谱面时长后刷新/重开：工作台仍是上次的值，音频页回到 30s。

## 根因

`AudioSession` 才是谱面时长真相源（issue 145 #2）。会话创建写死 30；恢复只灌 PlaybackContext。音频页读 session。

## 修法

无音频恢复：`session.setChartDuration`（可同拍 `setCtxDuration` 以免落盘抢 30）。`changeDuration` 只走 session。不改 ADR-0005。

## 锁测

- `ChartCodeDurationSync.test.ts`：恢复必须 `audioSession.setChartDuration(project.durationSeconds)`；`changeDuration` 不直接 `setCtxDuration`。
- `AudioSession.test.ts` clamp 保持绿。手工：无音频改非 30 → 刷新 → 两页同值。
