## Question

子拍线现状（`src/visual/render.ts` `renderGrid`）：所有子拍线同为 `#666666` 虚线 + 0.8 透明度，仅靠间距抽稀（<5px 不逐条画）区分远缩放观感；无层级、无样式可切换（用户要求美化且可切换预设）。

grill 定案（2026-09-06，Q3/Q9/Q10）：

- **分母分层制**：按细分分母逐级区分——整拍(1) > 1/2 > 1/4、3/4 > 1/8 类 > 1/16 类；任意 beatDisplay（2/4/8/16）下自动成立。
- **层级靠样式区分而非仅变淡**（用户明确："其实不是变淡，而是样式不同"），形态阶梯（音乐记谱惯例，跨预设共享）：

  | 层级 | 形态 |
  | --- | --- |
  | 整拍 | 实线（各级中最粗） |
  | 1/2 | 长虚线 |
  | 1/4、3/4 | 短虚线 |
  | 1/8 类 | 点线 |
  | 1/16 类 | 细点线（更小点） |

- 形态为主 + **同色系亮度逐级微调**为辅；设**对比度下限**：最淡层级在 1px 线宽下依然清晰可辨（"不能影响视觉判断"，写进验收）。
- **轨道样式预设**（共享形态阶梯，改变配色基调与线宽/亮度基线）：
  - `经典`：灰系基线（现有基底按形态阶梯改良）——日常作谱；
  - `高对比`：亮白系、线宽加大、层级差拉满——演示/录屏；
  - `柔和`：暗灰细线、整拍线独醒——干扰最小。
  - （"琥珀主题"预设本轮未选入，留作后续扩展。）
- **设置**：`settings.display.gridStyle: 'classic' | 'highContrast' | 'soft'`（默认 `classic`），设置页 → 画布显示 → "轨道样式"下拉；全局生效、随设置持久化（additive 合并，缺省回退 classic）。
- 整拍线纳入预设作用范围（层级是相对的）；与远缩放间距抽稀叠加时，抽稀按层级从高到低优先保留高层级线。

## 第二轮修订（2026-09-06 grill，用户反馈"子拍线效果非常差"）

- **形态阶梯改为可选开关**（Q3=A）：新增 `display.lineShapeTiers`（默认**关**）——关闭时全部
  实线、仅靠颜色分层；开启后叠加线形阶梯（实线→长虚线→短虚线→点线→细点线）。与颜色主题正交组合。
- **删除 经典/高对比/柔和 三预设**，改为 **4 个轨道颜色主题**（Q4=OK）：`mono` 灰阶 /
  `amber` 琥珀 / `cyan` 青蓝 / `vivid` 多彩（层级靠色相辨识 + 亮度排序）。层级区分靠颜色：
  等级越高越亮眼、越低越暗；**luma 下限 ≥ 90**（用户明确"不要出现与黑色相关的颜色"），
  透明度恒 1（避免暗上加暗）。旧设置值（classic 等）归一化回退 mono。
- **BPM 标线跟随主题主色**（Q5=B，落在 issue 51）：`gridThemeBpmColor` = 主题 beat 层色。
- 抽稀×层级叠加维持（阈值 拍线 2px / 子拍 5px）。

## 第三轮补修订（2026-09-06，用户反馈）

- **默认主题 = 多彩（vivid）**（同日用户定案）：非法/缺省回退 vivid（原 mono）。
