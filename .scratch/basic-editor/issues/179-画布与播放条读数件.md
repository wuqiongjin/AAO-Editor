# 179 · 画布与播放条读数件

Type: feature
Status: resolved
Blocked by: 178

**来源**：[177](./177-工作台侧栏重设计.md) 实现拆分第 2 刀（Q13 / Q15 / Q23 / Q25 / Q26）。

**症状**：曲线配置、播放起点卡片挂在旧左右栏里，换壳前得先有新家；画布左下角的时间与播放条时间码重复。

**修法**：

- **曲线选项胶囊**（Q15）：`CurveOptionsCapsule` 挂在画布区左上角，只在曲线持工具态出现；胶囊显示「曲线 Sine · In · 1/16」（选了模板显示模板名），点开 = `CurveConfigPanel` 四行带标签表单（选了模板时前三项置灰），点外面 / Esc 收回，无关闭钮。`CurveConfigPanel` 改成带标签的行，旧左栏暂时照挂。
- **播放起点按钮**（Q13 / Q25）：`PlaybackMarkerButton` 经 `PlayBar.timeSlot` 放在时间码右侧；设了起点才出现，点 = 跳回并播放；从「无」变「有」时弹入 + 一圈光晕（约 0.9s）。显隐开关 `settings.playbar.markerButton`（默认开），开关在工作台显示设置面板最下方「播放条」组。旧右栏卡片本刀先留。
- **画布底部读数**（Q23 / Q26）：左下改为判定线处 `BPM N`（删时间），右下改为 `♪ 已过 / 总数`。判定线 BPM 抽成 `ChartGeometry.bpmAtSeconds`，顶栏 BPM 与画布读数共用。

**锁测**：

- `tests/unit/chart/config/PlaybarSettings.test.ts`（新增）：`playbar.markerButton` 默认开、缺字段回落、脏值回落、往返保真。
- `tests/dom/playback/PlaybackMarkerButton.test.tsx`（新增）：无起点不渲染、显示时间、点击跳回、仅「无 → 有」带出现动效（挪动起点不重播）。
- `tests/dom/workspace/WorkspaceDisplayPanel.test.tsx`（追加）：「播放条」组在画布组之后，开关写盘；「恢复默认」不动它。
- `tests/dom/workspace/CurveOptionsCapsule.test.tsx`（新增）：非曲线工具不出现、摘要文案、展开四行、模板置灰、点外面收回。
- `tests/unit/chart/geometry/ChartGeometry.test.ts`（追加）：`bpmAtSeconds` 取判定线所在段的 BPM。
- 画布底部读数在 `FinalVirtualCanvas` 里，jsdom 跑不动画布 → 静态源码断言（`tests/static/CanvasReadout.test.ts`）锁"左下不再是时间、右下带总数"；动效与胶囊位置 → 浏览器手工验收截图。

## Answer

2026-10-26 实现：曲线选项胶囊挂画布左上角（切走工具复位收起态）；播放起点钮进播放条（0.9s 一圈 + `settings.playbar.markerButton` 默认开）；画布左下 BPM、右下 `♪ 已过 / 总数`，删左下时间。commit `1c68c0f`。
