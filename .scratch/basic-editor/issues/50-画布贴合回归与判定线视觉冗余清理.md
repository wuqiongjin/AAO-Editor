## Question

issue 30（"画布铺满谱面画布与判定线贴底"）实施后仍残留两个回归：

1. **画布与 background 不贴合**——实测 1920×1080 窗口 + 浏览器 100% 缩放下：
   - `chartArea` = 810×672
   - sticky / FinalVC outer / background div = 800×672
   - `<canvas>` = 750×900
   画布宽度 750 < 父级 800（左右各露 25px 灰底），画布高度 900 > 父级 672（上下各被 `overflow: hidden` 裁 114px）。
   根本原因：`useSurfaceSize(chartAreaRef)` 在某些窗口比例下未把真实尺寸喂给 React，画布仍走 `DEFAULT_SURFACE = {w:750, h:900}`。

2. **判定线在画布内 y=900（最底），实际被画布的 `overflow: hidden` 裁掉**——视觉上"判定线在中间"实为画布外的几何"占位 y"，音符越过 chartArea 底部 ~114px 区间才被判定，**视觉上"音符被拖延了 ~114px 才被判定"**。

用户决定（grill 5 轮结论）：
- 画布必须**始终**贴父级（任意窗口比例、任意缩放），无黑边、无溢出裁切。
- 判定线视觉不必要（用户原话："其实判定线可以没有。即便没有，用户也能懂音符什么时候被判定播放"）。
- "拖延"完全是画布没贴 background 导致的视觉错觉，**判定线本身不渲染，音符越过 chartArea 底边就判**——不再有"黑边吞掉判定线"问题。

## 期望

- 画布在任意窗口比例下铺满 `chartArea` 可视区，无 letterbox、无被裁（min 维度算法 + 0.1 ≤ scale ≤ 3.0 自动钳制）。
- 判定线 DOM 与绘制**全部移除**（Q7 a）；音符越过 chartArea 底边 = 视觉上"过线"= 判定。
- PlayBar 顶 `borderTop` 一并移除（Q11 d）—— `--canvas-bg` 与 `--bg-elevated` 色差兜住分隔。
- `DEFAULT_SURFACE` / `CANVAS_WIDTH` / `CANVAS_HEIGHT` 删除（grep 确认外部无引用）——`ChartGeometry` 构造器 `surface` 改 required。
- 极小窗口（chartArea < 200×240）时画布不消失——`SurfaceSizeMerger.feed` 钳到 min(200, w) / min(240, h)。

## 方案（9 文件 / 一次提交）

1. **`src/chart/geometry/ChartGeometry.ts`**：删 `DEFAULT_SURFACE` / `CANVAS_WIDTH` / `CANVAS_HEIGHT`；新增 `export const CANVAS_ASPECT = 5 / 6`；`ChartGeometry` 构造器第 3 参 `surface` 改 required（去 `= DEFAULT_SURFACE`）。
2. **`src/chart/layout/useSurfaceSize.ts`**：删 `DEFAULT_SURFACE` import；返回类型改 `SurfaceSize | null`；`useState` initial 改 `null`。
3. **`src/chart/layout/SurfaceSizeMerger.ts`**：删 `DEFAULT_SURFACE` import；`lastCommitted: SurfaceSize | null = null`；`getCommitted` 返回 nullable；`feed` 加 `Math.max(200, round(w))` / `Math.max(240, round(h))` 钳制。
4. **`src/chart/components/canvas/FinalVirtualCanvas.tsx`**：import 改 `CANVAS_ASPECT`（删 `DEFAULT_SURFACE`）；`props.surface: SurfaceSize | null`；组件顶端 `if (!surface) return null;`；删除 `surf` 三元 fallback；新增 min 维度算法 `aspectW = floor(surface.h × CANVAS_ASPECT); canvasW = min(surface.w, aspectW); canvasH = round(canvasW / CANVAS_ASPECT);`。
5. **`src/visual/render.ts`**：删除 `renderJudgeLine` 函数定义 + `renderChart` 内调用；`renderChart` 顶端 `if (!rc.surface) return;`。
6. **`src/visual/index.ts`**：`renderJudgeLine` 从 re-export 列表移除。
7. **`src/playback/PlayBar.tsx`**：根 `<div>` 删 `borderTop: '1px solid var(--border)'`。
8. **`src/chart/Editor.tsx`**：无源码改动（`surface` 透传，类型已 nullable）。
9. **`src/playback/useScrollModel.ts`**：`UseScrollModelOptions.surface: SurfaceSize | null`；`new ChartGeometry(..., surface ?? { w: 200, h: 240 }, ...)`；`chartEndKey` 中 surface 占位 `'?x?'`。

## 设计不变量（保留）

- 判定线位置：删除后语义改为"音符越过 `chartArea` 底边即被判定"——这是 issue 24 按秒重锚 + issue 30 ADR-0006 §1 "判定线 = 渲染面底边"的自然延伸。
- 缓冲：仍为 `surface × dpr`（`renderChart` 内部 `canvas.width/height` 设置），`useLayoutEffect` 内 `renderChart` 早 return 保护。
- 缩放：Q4=A 不变（`viewport.scale` 恒等于 `effectiveScale`，Q4=a 沿用 issue 30 定案）。
- 7 轨完整可见：`effectiveScale` 钳制不变。
- 性能：min 200×240 钳制防止极小窗口下 buffer 频繁重设；无 rAF 节流、无 RO debounce（Q13/Q14 沿用现状）。
