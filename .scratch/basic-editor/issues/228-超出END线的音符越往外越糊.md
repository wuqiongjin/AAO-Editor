# 228 · 超出 END 线的音符发糊、越往外越糊（根因待调研）

Type: research
Status: open
Blocked by: —

## 来源

用户 2026-11-10 验收反馈 #2：END 线以外（END 之后时间域）的音符非常糊，且离 END 越远越糊。

## 症状

- 出现在工作台画布（是否也见「谱面图」静态预览 / 仿真场预览待确认）。
- 音符位于「END 之后空白区」（issue 79 几何事实：上 = 更晚时间；`scrollY = 0` 时可见窗口整屏都是 END 之后时间域）。
- 糊的程度随离 END 距离单调增加（「越往外越糊」）。

## 补充复现线索（用户 2026-11-11）

- **音符来源**：谱面长度（谱面时长）被缩短，原谱面里 `beat > chartEndBeat` 的音符被留在 END 线之外（缩短时长并不清理越界音符）；这些「残留音符」看着就发糊。
- **间歇性**：偶然遇到 1-2 次，目前无法稳定复现，也不确定触发操作（缩放 / 滚动 / 播放 / 缩短时长 的先后）。
- ⇒ 现象与「越界音符 + 某个瞬态」绑定，不是稳定必现；定根因需截图 + 当时的缩放 / 播放 / 判定线偏移设置。

## 现状盘点（已核实的代码事实）

1. 编辑器自身渲染**没有**针对 `beat > chartEndBeat` 音符的渐糊 / 渐隐 / 模糊滤镜：`renderGridBeatLines` 只用 `isPastChartEnd` 跳过 END 之后的**横网格线**（`render.ts:204,211`）；`visibleNotes` 不按 END 裁音符（`ChartGeometry.ts:441`）；`renderNotes` 无 per-note alpha（`render.ts:675`）；全 src 无 `ctx.filter = blur(...)`。故糊不是一处「故意的渐糊」直接产生的。
2. **收窄后的首要候选 = 音符层瓦片 stale 拉伸（被 issue 222 的「自适应平滑」放大成「糊」而非「马赛克」）**：`tileBlitRect` 按 `k = es/refScale` 拉伸（`noteLayerCache.ts:332`），而 `shouldEnableTileBlitSmoothing` 在 `es !== refScale` 时强制 `imageSmoothingEnabled = true` + `high`（:187）——拉伸瓦片呈**平滑模糊**（旧版最近邻是块状马赛克）。END 之外音符落**高 pos / 高 tileId** 瓦片，`planPrefetchTiles` 预算（64MiB / 64 块）优先视口块与 `hi+1/hi+2` / 首音符窗口，远处高 id 瓦片易保留旧 `refScale`；`k` 越大越糊 ⇒ 与「越往外越糊」同向。谱面时长缩短会改 `chartEndVirtualY` → `tiles.clear()` 全量失效（`draw` :717/728）；若此刻叠加缩放手势 / 播放态的异步重建，未轮到的高 id 瓦片会以旧 `refScale` 被拉伸 → 间歇性发糊。
3. 反向排除：判定线蒙版 `renderPassedNotesScrim`（`render.ts:1859`，issue 218）的渐变 `0 → 0.35 → 0.55` 虽「随距离单调加深」，但只在**画布底部条带**、且仅 `judgeLineOffsetRatio > 0`（默认 0，`AppSettings.ts:515`）时生效，作用对象是「已过线音符」，不在 END 之后（上方）区域 ⇒ 不是蒙版。
4. 注意：静止帧 `draw` 对**视口覆盖块**会同步重建（`pending`），理论上进视口即清晰；故候选要成立，需落在「播放态跳过同步重建（:756 `if (!rc.playing)`）/ 缩放手势预算内未轮到」这类**瞬态**上——这也解释了间歇性。
5. 上述均为静态推断，**间歇性使根因无法坐实** ⇒ 需视觉复现（截图 + 当时的缩放 / 播放 / 设置）才能定案。

## 待澄清 / 复现清单（grill，其余已收敛）

1. 界面已默认是工作台画布（若其实在谱面图 / 仿真场请指出）。
2. 形态：更像**平滑模糊 / 发虚**（贴图被拉伸 + 双线性平滑）还是**块状马赛克 / 重影**？前者支持瓦片 stale 拉伸候选。
3. 下次复现时记录：缩放百分比、播放中还是暂停、`判定线偏移` 是否为 0、能否通过「放大 / 缩小 / 暂停 / 等 1 秒」恢复清晰；**最好截一张图**。
4. 复现尝试：缩短谱面时长 → 滚到 END 之外看残留音符 → 再做一次缩放手势，观察是否发糊。
5. 另：缩短谱面时长后 END 外残留音符本身是否要处理（钳 / 清理 / 提示）属另一类问题，**不并入本票**；需另开请告知。
