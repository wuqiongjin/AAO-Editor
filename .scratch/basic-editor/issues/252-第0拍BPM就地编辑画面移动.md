# 252 · 第 0 拍 BPM 原地编辑时整画面移动

Type: bug
Status: resolved

## 来源与症状

用户 2026-11-24 报：单击第 0 拍沟槽 BPM 数字进入就地编辑时，**整个谱面画面会移动**。其它拍位不明显。

## 根因

第 0 拍 BPM 钉在判定线（画布底）。`bpmLabelAnchorY(0)` 把数字中心上移半个字高，画布文字刚好在盒内。HTML 输入框却多了 ±3px 内边距：`top = lineY - fontPx/2 - 3`、`height = fontPx + 6` → 底边 = 线 y + 3，在 `lineY ≈ surface.h` 时溢出画布 3px。

挂载时 `attachBpmInput` 调 `el.focus()` **没有** `preventScroll`。`.ws-chart-area` 是 `overflow: auto` 滚动宿主，画布 `position: sticky`。焦点把溢出的输入滚进视口 → `onScrollbarScroll` 改 `scrollY`，整谱相对判定线平移。第 0 拍默认就在底边，所以只有它稳定复现。

## 修法

1. `focus({ preventScroll: true })`，禁止焦点改滚动宿主。
2. 输入盒纵向钳进 `[0, surface.h]`（抽出纯函数），beat 0 不再溢出。

## 锁测

- `gutterLabels.ts`：`bpmInlineInputBox(beat=0, y=h)` 整盒在画布内；中段 BPM 位置与修前一致。
- `tests/static/BpmInlineEdit.test.ts`：`attachBpmInput` 必须 `preventScroll: true`。

## Answer

输入盒底边在 beat 0 溢出 3px，默认 `focus()` 滚动 `.ws-chart-area`。改为 `focus({ preventScroll: true })` + `bpmInlineInputBox` 纵向钳进画布。锁测全绿。
