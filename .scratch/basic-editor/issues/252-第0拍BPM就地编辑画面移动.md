# 252 · 第 0 拍 BPM 就地编辑时整画面移动

Type: bug
Status: resolved（待页面验收）

## 来源与症状

用户 2026-11-24 报：单击第 0 拍沟槽 BPM 数字进入就地编辑时整谱会移动。其它拍不明显。

## 根因

beat 0 钉判定线（画布底）。输入盒 ±3px 内边距使底边溢出 3px；`focus()` 无 `preventScroll`，把 `.ws-chart-area` 滚一下 → sticky 画布 `scrollY` 变。

## 本轮实现口径（待验收）

1. `focus({ preventScroll: true })`。
2. `bpmInlineInputBox` 把输入盒纵向钳进 `[0, surface.h]`；中段 BPM 公式不变。

## 锁测

`tests/unit/rendering/render/GutterLabels.test.ts` `bpmInlineInputBox：就地编辑输入盒（issue 252）`：beat 0 整盒在画布内、中段位置与修前一致。`tests/static/BpmInlineEdit.test.ts` 锁 `preventScroll: true`（焦点滚动是 DOM 时序，单测碰不到 `focus()`）。

## Answer

溢出 3px + 默认 `focus()` 带动滚动宿主。`preventScroll` + 纵向钳盒。
