# 189 · 片段导入冲突：跳过 / 覆盖 / 保留两者

Type: feature
Status: resolved
Blocked by:

**来源**：[187 片段库：导入导出](./187-片段库导入导出.md) + 2026-10-31 用户追加讨论（184–187 已 resolved，本票不改写旧票）。权威基线 = [ADR-0023](../../../docs/adr/0023-片段收藏的载荷与存储边界.md) §3。

**现状**：`parsePatternsFile` 对每条都重发 id，`usePatternLibrary.importFromText` 直接 `[...现有, ...parsed]`；没有内容比较。于是「导出 → 再导入」必然多一份，分享文件重复导入也会反复加；导入还保留源文件的 `createdAt`。

**定案（用户 2026-10-31）**：导入遇到重复条目，提供「跳过 / 覆盖 / 保留两者」；默认跳过。判重按内容，不按名字 / id。

## 判重口径

- **冲突键 = 内容指纹**：`notes + bpmContext` 的规范化 JSON（递归键排序；不含 `id / name / createdAt`，也不含置顶等本地字段）。
- **同名不同内容不是冲突**：默认两条都保留（继续允许重名）；预览里可以标一句「同名但内容不同」。
- 文件内同内容多条、以及同一次导入刚加入的条目，按**文件顺序**参与后续冲突判定：
  - 跳过：保留先出现 / 本地已存在的那条；
  - 覆盖：后出现的导入条目覆盖同内容条目的名字；
  - 保留两者：全部加入（各自新 id）。
- 库里已有同内容多条时，覆盖只作用于当前排序下最靠前的一条，并在冲突清单里标明目标；**不批量改名**。

## 动作语义

| 动作 | 结果 |
| --- | --- |
| 跳过 | 本地完全不变，导入条目不写入 |
| 覆盖 | 保留本地 `id / createdAt`（以及 191 落地的置顶字段）；`name` 换成导入名；因为内容相同，`notes / bpmContext` 不变 |
| 保留两者 | 新 `uuid` 追加；名字 / `createdAt` 沿用导入文件（现行导入语义） |

> **不按名字覆盖**：名字不是唯一键；按名字覆盖会拿别人同名片段的内容替换本地，误操作代价高。若将来要支持「同一片段的新版本覆盖旧版本」，需要独立的内容版本身份，不在本票。

## 入口与反馈

- 整库导入在解析成功后、落盘前显示确认 / 冲突清单；单条导入也走同一路，不再造第二套。
- 弹层内容：文件总条数 / 新增 / 重复 / 坏条目；重复清单（导入名 ↔ 本地名）；全局三选一（跳过默认 / 覆盖 / 保留两者）；确认 / 取消。
- 取消 / 关闭 = 不写盘。
- 成功反馈分开报数：`导入 N 条，跳过 M 条（K 条已存在）`；全部被跳过时**不产生无意义的整库落盘**。
- 读失败状态（`status === 'error'`）继续禁止写；载入中先等首次载入完成。

## 实现落点

- `src/chart/patterns/`：新增内容指纹纯函数与导入合并策略纯函数（输入现有库 + 解析结果 + 策略 → `{ patterns, imported, skippedExisting, targets }`）。
- `parsePatternsFile` 保持「逐条校验 + 新 id」；冲突判定与动作放库层，不把 UI 策略塞进分享解析。
- `usePatternLibrary.importFromText` 拆成「先解析 / 规划 → 弹层确认 → 再落盘」，返回冲突明细；新增 DOM 弹层（建议 `PatternImportDialog`）。
- `record.ts` / `types.ts` 不加字段；本票不改片段载荷。
- ADR-0023 §3「分享」补：内容相同默认跳过；覆盖保留本地身份与收藏时间，只同步展示名；同样允许「保留两者」。
- i18n：zh-CN + en。

## Answer

2026-10-31 实现：

- **内容指纹** `src/chart/patterns/importConflict.ts`：`patternContentFingerprint` 对 `notes + bpmContext` 做递归键排序后 JSON 化；`id / name / createdAt / pinnedAt` 等都不参与。
- **合并策略** `planPatternImport`：**只和传入的本地库**按内容指纹判重，库内同内容多条取**最靠前**一条；`skip` 跳过导入条目，`overwrite` 保留本地 `id / createdAt` 与本地字段、只换名字，`keep-both` 各自新 id 追加。同名不同内容不判冲突，仍两条都保留。**文件内部的同内容条目不做去重**（2026-10-31 用户验收修订）：空库导入含多条同内容片段的文件时全部新增，冲突仅指「导入条目 ↔ 本地已有片段」。`previewPatternImport` 汇总总数 / 新增 / 与本地库重复 / 坏条目与冲突清单。
- **库层** `usePatternLibrary`：`importFromText` 拆成 `prepareImport`（等首次载入 → 解析 + 预览，不写盘）与 `applyImport`（按策略合并 → 一次整库落盘）。读失败仍禁止写；全部被跳过（`imported === 0`）不产生整库落盘；覆盖只改名字，排序沿用 `createdAt`。
- **入口** `PatternLibraryDrawer` + 新增 `PatternImportDialog`：解析成功后、落盘前弹层展示计数 + 重复清单（导入名 ↔ 本地名）+ 同名不同内容提示；全局三选一默认跳过；**没有重复条目时整块隐藏策略区**；取消 / 关闭 / Esc / 点遮罩都不写盘，说明收进标题右侧的「?」气泡。计数分色：新增绿 / 重复琥珀 / 坏条目红，为 0 时退回中性灰。反馈分开报数：全新增「导入 N 条」、有坏条目「导入 N 条，跳过 M 条」、有已存在「导入 N 条，跳过 M 条（K 条已存在）」。
