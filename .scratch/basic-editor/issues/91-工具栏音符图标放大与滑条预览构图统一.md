# 91 · 工具栏音符图标放大到 24px + 滑条预览/工具栏构图统一

Type: bug
Status: resolved（2026-09-12 实现 + 锁测，待你在页面验收）
Blocked by:

## 来源

用户 2026-09-12（issue 86 验收反馈 + 新增素材页问题）：
1. 工具栏六个音符图标"非常小，看不清"（86 实现口径 = 18px 方框）。
2. 素材页 → 音符皮肤 → 滑条：中间结点超出滑条（连接带）本身宽度，效果不好；并要求素材页的修复**同步**到工具栏的滑条图标。

## 症状 / 根因

1. **工具栏过小**：`Toolbar.tsx:81-86` `size={18}`，音符素材位图在 18px 下细节挤成一点。
2. **素材页滑条预览比例失衡**：`NoteSkinPreview.tsx` —— band 宽写死 22（`:62`），端点/中间结点画 36×1.1 = 39.6px（`:116-138`）→ 结点/带 = **1.8×**。真实画布是 band 30（`render.ts:760`，LANE_WIDTH×noteSize）: 结点 36（`SLIDE_ICON_SIZE`）= **1.2×**。
3. **三处各画各的**：工具栏滑条图标又一套常数 band 7 / 端点 14（`noteGlyph.ts:23-25, 83-102`）= 2×，且 18px 下省略中间结点；与素材页、画布素材同源但几何不共用。

## 定案（用户 2026-09-12）

- 工具栏音符图标 18px → **24px**。
- 素材页滑条预览与工具栏滑条图标**构图统一**，band:结点比例锁真实画布口径 **30:36**（实现口径，待验收：结点仍略宽于带、与游戏内渲染一致，不再是 1.8× 悬殊；绝对尺寸以预览格子构图美观为准）。

## 修法

- `Toolbar.tsx` 六处 `size={18}` → 24；确认按钮/行高容纳、DPR 渲染不糊。
- `NoteSkinPreview.tsx` 的 bandW 不再写死 22，由结点宽 × 30/36 推导。
- band:结点比例抽成共享常量（如 `noteMetrics`/`noteGlyph` 导出），素材页与工具栏同源引用，防再次分叉；24px 下滑条中间结点仍省略（三条竖向塞不进方框，维持 86 口径）。

## 锁测

- `tests/unit/ToolbarNoteSkin.test.ts`："落在 18px 方框内"断言改 24px（该测试已参数化 24px 约束，改参数即可）。
- 新增纯函数/静态断言：滑条构图 band = 结点 × 30/36，且共享常量被素材页与工具栏两处引用（防再写一套）。
- 预览像素单测覆盖不到 → 手工/Playwright 验收：素材页滑条预览与画布真实渲染并排对照；工具栏 24px 不糊、与素材页一致。
