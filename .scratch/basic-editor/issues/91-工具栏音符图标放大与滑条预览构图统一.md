# 91 · 工具栏音符图标放大到 24px + 滑条预览/工具栏构图统一

Type: bug
Status: resolved（2026-09-12 实现 + 锁测，待你在页面验收）
Blocked by:

## 来源

用户 2026-09-12（issue 86 验收反馈 + 新增素材页问题）：
1. 工具栏六个音符图标"非常小，看不清"（86 实现口径 = 18px 方框）。
2. 素材页 → 音符皮肤 → 滑条：中间结点超出滑条（连接带）本身宽度，效果不好；并要求素材页的修复**同步**到工具栏的滑条图标。

## 症状 / 根因

1. **工具栏过小**：`Toolbar.tsx:81-86` `size={18}`，音符素材位图在 18px 下细节挤成一点。
2. **素材页滑条预览比例失衡**：`NoteSkinPreview.tsx` —— band 宽写死 22（`:62`），端点/中间结点画 36×1.1 = 39.6px（`:116-138`）→ 结点/带 = **1.8×**。真实画布是 band 30（`render.ts:760`，LANE_WIDTH×noteSize）: 结点 36（`SLIDE_ICON_SIZE`）= **1.2×**。
3. **三处各画各的**：工具栏滑条图标又一套常数 band 7 / 端点 14（`noteGlyph.ts:23-25, 83-102`）= 2×，且 18px 下省略中间结点；与素材页、画布素材同源但几何不共用。

## 定案（用户 2026-09-12，同日页面验收定稿）

- 工具栏音符图标 **28px**（六项统一）；方向键本体 = 键型本体 × **`DIR_BODY_BOOST`(1.1)**，比其它音符显大一点。
- 方向键按**整组墨迹中心**居中（补偿系数 **`DIR_INK_BALANCE`(0.9)**：本体居中时墨迹偏箭头侧，与上方单键的对称构图不齐）。
- 工具栏滑条图标**只画"段"（连接带）**，不画起止端点音符。
- 素材页滑条预览与工具栏滑条图标**构图统一**：band:结点比例锁真实画布口径 **30:36**（共享 `SLIDE_BAND_TO_NODE_RATIO`；结点略宽于带、与游戏内渲染一致）。
- 字形画布内部分辨率固定 **3× 超采样**（与运行时 dpr 解耦，浏览器缩放不发糊）。

## 修法

- `Toolbar.tsx` 六处 `size={28}`；`NoteIconGlyph` 画布 backing 固定 3× 超采样 + `imageSmoothingQuality: high`。
- `NoteSkinPreview.tsx` 的 bandW 不再写死 22，由结点宽 × 30/36 推导；布局几何抽 `noteSkinPreviewLayout.ts` 纯模块（react-refresh 规则）。
- band:结点比例抽成共享常量（`noteMetrics` 导出），素材页与工具栏同源引用，防再次分叉；工具栏滑条只画连接带（band-only，随 size 缩放）。

## 锁测

- `tests/unit/ToolbarNoteSkin.test.ts`：静态源断言（皮肤域接入 / legacy 零残留 / 六项 `size={28}` / 共享常量两处引用 / backing 不依赖 `devicePixelRatio`）+ 假精灵构图断言（不空绘、不越字形盒、方向键本体 = 单键 × `DIR_BODY_BOOST`、墨迹居中方向 L 右 R 左、滑条单枚 band-only、band 几何 30:36）。
- 预览像素单测覆盖不到 → 用户页面验收（2026-09-12 通过）。
