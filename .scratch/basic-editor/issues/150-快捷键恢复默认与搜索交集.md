# 150 · 快捷键「恢复默认」是否跟搜索交集

Type: grilling
Status: resolved
Blocked by: —

## 来源

用户 2026-09-22：搜索筛到 1 条时，「恢复默认」是否应只恢复这 1 条？

## 现状（代码与定案）

- Issue **121** + ADR-0002：**恢复默认跟当前索引桶**（全部 = 整表；其它桶 = 该桶全部可改 `FunctionId`）。**未**纳入搜索词 `query`。
- `ShortcutsPage`：`onClick` 调用 `restoreDefaultsInFilter(config, indexFilter)`，不传 `visible` / `query`。
- `restorableCount` 同样只按桶计数，搜索不缩小。

## 症状（若按用户期望）

搜索「复制」只剩一行时，点恢复默认仍会重置**整个编辑工具桶**（或当前桶内全部项），与「眼前只有一行」心智不符。

## 待拍板

| 选项 | 行为 |
| --- | --- |
| A | 维持 121：恢复只跟桶，搜索纯展示 |
| B | 有非空 `query` 时，恢复默认 = 仅当前表内可见可改行（`visible` 的 FunctionId）；桶内只读切页行仍不参与 |
| C | 混合：桶 + 搜索交集，但按钮文案/tooltip 要区分「恢复本桶」vs「恢复筛选结果」 |

## 实现落点（拍板后）

- 扩展 `shortcutIndexFilter.ts`（如 `restoreDefaultsInFilter` 增加可选 `scopeIds` 或 `query` 参数）。
- `ShortcutsPage` 传 `visible` 的 id 集合；`restorableCount` / `title` 与行为一致。
- 更新 ADR-0002 索引筛选 bullet + `ShortcutIndexFilter.test.ts`。

## 定案（用户 2026-09-22）

**B**：有非空搜索词时，「恢复默认」= 仅当前表内可见可改行（`visible` FunctionId）；无搜索时仍跟桶（121）。

## Answer

`restoreDefaultsInFilter` 第 5 参 `onlyIds`；`ShortcutsPage` 在 `searchActive` 时传入 `visible.map(f => f.id)`，`restorableCount` / `title` 同步。ADR-0002 已补一句。
