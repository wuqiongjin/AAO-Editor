## Answer（结论）

**定案（用户 2026-09-14，四轮 grill）：放行负数 BPM，承认「倒流区」为一等语义。** 权威落点 = 新增 [ADR-0010 负数 BPM 与倒流区](../../../docs/adr/0010-负数BPM与倒流区.md)，并修订 ADR-0005 §7、回填 ADR-0009 范围切片句；术语入 `CONTEXT.md`。

### 1. Bestdori 口径（实测，非推测）

- **时间轴 = 带符号累加**（负 BPM 段的秒倒扣）。硬证据：社区谱 150030「Retribution ~ Cycle of Redemption ~」自带音频 **173.376s**，其末音符（beat 1160）在带符号累加下 = **172.80s**（恰在歌曲结尾前 0.58s），按 `|bpm|` 累加 = 309.33s（不可能）。
- **播放时钟单调**：判定线不动、谱面正向播放、**无倒流演出**。
- **所有音符一视同仁**（实机复核，收回先前"非 Slide 不受影响"的观测）：倒流区内所有元素在画布上都会折返。
- **倒流区内可击打元素实机 100% MISS**；Bestdori 不拦（可存可渲染），我们也不拦。
- `bpm = 0` 无意义（预览无限加载 / 游戏内空白）；**谱面以负 BPM 收尾会让 Bestdori OUT_OF_MEMORY 崩溃**。

### 2. 语义结论（11 条，全文见 ADR-0010）

放行 `bpm < 0`；倒流区 = 从 `bpm < 0` 事件起到**下一条 `bpm > 0`** 事件为止；时间轴带符号、播放时钟单调；**画布布局轴 = 时间轴，画布高度由秒直接得出不经拍反查**；**「秒 → 拍」在倒流区内多值，须显式取值，几何/滚动/命中一律走正向**；段内可击打元素不拦但不承诺可完成；校验边界（`0`/非有限数/beat 0 负值/末条 BPM 负值 → 拒）；编辑器内可创建负 BPM；往返保真 + 稳定排序；谱面长度不被倒流区改变；负值 BPM 数值换色。

### 3. 影响范围（实现落点）

- **正向链路本来就正确**：`perBeatValue` 与 `60/bpm` 都带符号，与 Bestdori「`pixel = 时间 × pps`」同构 → 渲染的正向映射不需重写。
- **要处理的是反查与单调假设**：`BpmTimeline.beatOfPosition`（L77-95 二分假设 offsets 单调）、`AudioTiming.secondsToBeat` / `chartLengthToEndBeat` / `maxNoteEndSeconds`、`ChartGeometry.chartEndVirtualY`（L97）与 `virtualYToBeat`（L141-143）、`render.ts visibleBeatRange`（L112-117）与 hover 秒读数（L1306-1307）、`noteLayerCache.invalidateTilesForBeatRange`（L169-177，L163 注释明写「pos 随 beat 递增」）、`PlaybackScrollModel`（L72-85）、`Editor.currentRegionBpm`、`FinalVirtualCanvas.playheadBeat`。
- **校验与编辑入口**：`ChartConverter.ts` L403-404、`FinalVirtualCanvas.tsx` L404。

### 4. 锁测

- **会变红（须改写）**：`tests/unit/ChartConverter.test.ts` L210-222（现断言 `bpm: -1` invalid）。
- **新增单测**：负值通过 / `0`、`-0`、`NaN`、`Infinity` 拒 / beat 0 负值拒 / 末条 BPM 负值拒 / 负值往返逐元素相等（含同拍多条 + 稳定排序）；`BpmTimeline` 折返与多值反查口径；`AudioTiming` 带符号回退 + `maxNoteEndSeconds` 取最大秒；`ChartGeometry` 画布高度 = 秒 × 像素密度。
- **新 fixture**：`docs/resource/SampleChartCode/Community/150030.json`（**须固定版本**——仓内样本与线上 API 当前版 1242 条中 1228 条逐元素不同、BPM 事件序列一致），断言末音符 = 172.80s。
- **单测覆盖不到的**：画布折返渲染、hover 秒读数、播放滚动 → **Playwright 像素实测** + 手工验收清单（滑条带折返、负值换色、hover 秒读数不跳变）。
