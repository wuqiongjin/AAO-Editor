## Question

## Answer（结论）

已实现（2026-08-17）：

- **导航**：`AppNav` 的 `PageId` 扩展 `'assets'`，NAV_ITEMS 追加「素材」（`Layers` 图标）；`AppShell` 注册保活页 + 切页快捷键；快捷键页 `APP_SHORTCUTS` 追加「切换到素材」只读行。最终顺序（第 2 轮定稿）：工作台 `⇧⌘1` / 音频 `⇧⌘2` / 素材 `⇧⌘3` / 快捷键 `⇧⌘4` / 设置 `⇧⌘5`。
- **素材页**（`src/pages/AssetsPage.tsx`）：左栏键音素材包列表——遍历 `KEY_SOUND_SETS` 注册表，每包展示名称 + 五类击打样式明细（标签/说明/采样类型：真实音频/振荡器占位/方向键 1~3 档），激活包高亮 + 「使用中」徽标、隐藏切换按钮，非激活包点「切换」写 `settings.audio.keySet`（与播放条素材下拉同字段，立即生效并持久化）；右栏「皮肤」占位卡片（虚线「即将支持」徽标 + 说明），本轮不实现数据模型。
- **展示元数据**：新增 `src/utils/KeySoundMeta.ts`（五类击打样式的中文标签/说明）——与 `KeySound.ts` 的音频资源分离，测试环境不触碰 `?inline` 导入。

## 素材 tab 范围定案（grill 2026-08-17，第 3 轮信息架构）

本 issue 覆盖**完整的素材 tab**（不止键音）。以下为本轮 grill 定案：

- **准入标准**：素材 tab 只放**可选择的成组内容资产（素材包）**——选一套、整体或按条目生效。显示参数/开关（大小、亮度、线条、色觉辅助、比例、品质等）**不进**素材 tab，归设置页「功能设置」组（issue 39）。
- **三类别**：
  1. **键音素材包**（音频类）——✅ 已实现（见 Answer）；选择粒度 = **整包切换**（`settings.audio.keySet`）。
  2. **音符皮肤**（视觉类）——待实现；选择粒度 = **条目级选择**（对标 bestdori，各击打样式可独立选皮肤，而非整包）。
  3. **谱面背景皮肤**（视觉类）——待实现；未来支持给谱面画布背景设置图片（画布本身固定深色的主题边界不变，背景图是其上的可选层）；选择粒度待定。
- **皮肤与音符类型的对应关系（不自行决定，留待拿到皮肤资源后深入 grill）**：已知信息仅——左滑键/右滑键属同一种音符皮肤类型但皮肤有区别；单键有自己的皮肤；滑条本体不区分皮肤、但其起点/终点是单键故使用单键皮肤。**完整映射（含方向键/技能键/滑条各形态）等用户找到对应皮肤资源后单独 grill 定案。**
- **页面结构（类别 ≥3 后）**：页内**类别子 tab**（键音 | 音符皮肤 | 背景皮肤），一次看一个类别；类别可扩展（用户明确"未来可能还有"）。当前实现的双栏布局（左键音 + 右皮肤占位卡）随类别实装改为此结构。
- **统一操作原语**：切换/选择写 settings、立即生效并自动持久化；音频类与播放引擎即效关联，视觉类与画布渲染即效关联。
- **未做**（登记）：素材包导入（文件格式与校验待 grill）；音符皮肤/背景皮肤的数据模型、包结构、资源来源（用户侧找资源）待后续 grill。
- **导航顺序定稿**（第 2 轮）：工作台 `⇧⌘1` / 音频 `⇧⌘2` / 素材 `⇧⌘3` / 快捷键 `⇧⌘4` / 设置 `⇧⌘5`。
- **边界**：设置页自身的两组结构（应用设置/功能设置）与 bestdori 显示参数归位由 **issue 39** 跟踪，不在本 issue 范围。
