# 192 · 片段排序

Type: feature
Status: resolved
Blocked by: 190, 191

**来源**：2026-10-31 用户追加需求「是否支持片段排序」；同轮讨论确认排序键与方向。依赖 190（音符数 / 拍数派生）与 191（置顶优先）。

## 现状

`library.ts` 只有 `sortPatternsNewestFirst`（`createdAt` 倒序、同毫秒按 id）；抽屉没有可切换的排序 UI。本票把排序变成**视图偏好**，不改变库里的落盘顺序。

## 排序键与方向

| 键 | 升序 | 降序 |
| --- | --- | --- |
| `createdAt`（默认） | 最早收藏在前 | 最新收藏在前（默认） |
| `name` | A→Z / 名称升序 | Z→A / 名称降序 |
| `noteCount` | 音符数少→多 | 音符数多→少 |
| `beatSpan` | 拍数少→多 | 拍数多→少 |

- 名称排序用 `Intl.Collator`：按当前界面语言、`numeric: true`（「片段 2」排在「片段 10」前）、`sensitivity: 'base'`（大小写不敏感）。
- 所有排序必须是**全序**：主键相同按 id 兜底，避免每次渲染换位。
- `noteCount` / `beatSpan` 直接用 190 的派生函数，不在这里再算一套。

## 组合规则

- **置顶组永远在最前**，组内按当前排序键 / 方向排；非置顶组同样按当前排序键 / 方向排。这样按名称排序时置顶不会失去意义。
- 先按搜索词过滤，再排序；搜索不改变排序偏好。
- 排序只影响显示；`PatternStore.saveAll` 的数组顺序不是语义，不因排序触发写盘。
- 默认 `{ key: 'createdAt', direction: 'desc' }`。

## 偏好持久化

- 新增 `settings.patternLibrary.sort`（additive，不 bump `schemaVersion`，照 `settings.patternPaste.withBpm` 先例）：
  - 形状建议 `{ key: 'createdAt' | 'name' | 'noteCount' | 'beatSpan'; direction: 'asc' | 'desc' }`。
  - 缺字段 / 未知 key / 非法 direction → 回落默认，不报错、不阻止抽屉打开。
- 这是「我的习惯」，不是片段数据；不进入片段库文件、不随片段分享导出。

## UI

- 在抽屉搜索行右侧加一个小的排序按钮（`ArrowUpDown` 图标），点开浮层菜单（复用 `useAnchoredMenu`，portal + fixed）；当前项打勾。
- 菜单项按「键 + 方向」列出，例如：最新收藏 / 最早收藏 / 名称 A→Z / 名称 Z→A / 音符数多→少 / 音符数少→多 / 拍数多→少 / 拍数少→多。
- 不往卡片右上角加按钮；不改卡片布局。
- 排序键切换后，当前搜索过滤、置顶状态、片段的粘贴来源高亮都保持。

## 非目标（本票明确不做）

- **最近使用排序**：需要记录「真正写入成功的粘贴」并处理高频落盘，另票。
- **手动拖拽排序**：会与「点卡片即粘贴」、多选模式抢交互，且需要顺序字段；置顶已覆盖「常用在前」。
- **最近导入排序**：当前导入保留源 `createdAt`，不引入 `importedAt`。

## 实现落点

- `src/chart/patterns/library.ts`：新增排序纯函数（如 `sortPatterns(patterns, sort)`），把置顶优先与键 / 方向收在一处；`sortPatternsNewestFirst` 保留或改为默认委托，避免两套口径。

- 190 的 `stats.ts` 提供 `noteCount` / `beatSpan`；191 的 `pinnedAt` 参与置顶优先。

## Answer

### 1. 纯函数排序引擎 (`src/chart/patterns/library.ts`)
- 定义类型 `PatternSortKey` (`'createdAt' | 'name' | 'noteCount' | 'beatSpan'`) 与 `PatternSortDirection` (`'asc' | 'desc'`)、配置对象 `PatternSortPreference`。
- 实现归一化函数 `normalizePatternSortKey`、`normalizePatternSortDirection`、`normalizePatternSort`，缺省或非法值优雅回落默认 `{ key: 'createdAt', direction: 'desc' }`。
- 实现纯函数 `sortPatterns(patterns, sort, locale)`：
  - 置顶优先：置顶项永远排在非置顶项之前；置顶组与非置顶组内部均严格遵从当前排序键与方向。
  - 名称使用 `Intl.Collator(locale, { numeric: true, sensitivity: 'base' })`。
  - 音符数与拍数排序利用 `Map` 预先缓存计算结果，避免 `O(N log N)` 重复解析音符。
  - 所有排序均以 `a.id.localeCompare(b.id)` 作为 tie-breaker 保证严格全序。
  - 原有 `sortPatternsNewestFirst` 保留并委托至 `sortPatterns(patterns, DEFAULT_PATTERN_SORT)`，消除重复逻辑。

### 2. 设置持久化 (`src/chart/config/AppSettings.ts`, `src/app/providers/ConfigProvider.tsx`)
- 在 `AppSettings` 中新增 `patternLibrary: { sort: PatternSortPreference }`（additive，保持 `schemaVersion: 1`）。
- 并在 `mergeSettings`、`updateSettings` 及 `ConfigProvider` 中暴露 `setPatternLibrarySort(sort)`，仅通知 `['patternLibrary']` 变动。
- ADR-0023 §3 补充说明：片段库排序是工作区偏好视图设置，存储于 `settings` 中，不写入 `patterns.json` 文件。

### 3. UI 交互 (`PatternLibraryDrawer.tsx`, `PatternLibrarySortMenu.tsx`, `PatternLibraryDrawer.css`)
- 抽屉顶部搜索栏提取为 `.pld__search-row` flex 布局，左侧为可自适应拉伸的搜索框，右侧为独立 28×28px 排序按钮（`ArrowUpDown` 图标）。
- 菜单使用 `useAnchoredMenu`（portal + fixed 浮层），包含 8 个单选式选项（最新收藏、最早收藏、名称 A→Z、名称 Z→A、音符 多→少、音符 少→多、拍数 多→少、拍数 少→多），选中项带有 Check 图标与 `aria-checked="true"`。
- 在多选模式下排序按钮依然保持可用，重新排序不会丢弃已选中的 `selectedIds` 集合。
- 搜索与排序严格正交：先按搜索词过滤得到 `filtered`，再经 `sortPatterns` 渲染为 `visible`。

### 4. 国际化与样式
- `zh-CN.json` 与 `en.json` 补充 `patternLibrary.sort` 及 8 组排序选项对应翻译文本。
- CSS 严格遵循 design token，无非法 `--border-hover` 引用。
