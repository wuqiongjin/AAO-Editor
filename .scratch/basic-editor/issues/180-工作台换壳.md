# 180 · 工作台换壳：窄工具轨 + 岛屿外壳 + 片段库抽屉

Type: feature
Status: claimed
Blocked by: 178, 179

**来源**：[177](./177-工作台侧栏重设计.md) 实现拆分第 3 刀（Q1–Q3 / Q8 / Q10–Q12 / Q14 / Q18–Q22 / Q26）。

**症状**：左栏被工具栏占满、右栏只有没人看的音符信息；178 / 179 已把吸附、曲线配置、播放起点搬进新家，旧左右栏可以整体撤掉。

**修法**：

- **岛屿外壳**（Q3 / Q18）：页面 8px 内边距 + 8px 间隔，工具轨 / 画布列 / 抽屉各是圆角 + 轻阴影的岛，并排占布局、不压画布。
- **窄工具轨** `WorkspaceToolRail`（Q2 / Q10 / Q11）：52px 固定宽、不折叠不拖宽；15 键 5 组「指针｜单键 滑键 技能 左滑 右滑 滑条 曲线｜BPM｜复制 剪切 粘贴｜删除 镜像 音符代码」；tooltip = 名称 + 快捷键；复制 / 剪切是即时动作，无选区置灰并提示；粘贴空剪贴板置灰。
- **顶栏** `WorkspaceTopBar`（Q10 / Q21 / Q22 / Q26）：项目名后撤销 / 重做；右簇 = 吸附｜缩放｜显示设置｜谱面代码｜片段库，撤 BPM 标签（已进画布左下）与音符数；删「当前工具」pill。
- **片段库抽屉** `PatternLibraryDrawer`（Q1 / Q8 / Q14）：只做外壳——标题、空状态、「收藏选区」占位（内容归 164）；展开占布局、左缘可拖宽（220px–32vw），收起完全消失；开合态与宽度存 `settings.layout.patternDrawer`（默认收起），入口 = 顶栏最右图标钮 + `Ctrl+Shift+B`（`toggleSidebar` 改为只开合抽屉）。
- **删旧**：`Toolbar` / `ToolbarSection` / 旧谱面代码按钮 `ChartCodeEditor` / `NoteInfoPanel` / `PlaybackMarkerCard` / `useLayoutPersistence`；`UIProvider` 的左右面板宽度、折叠、拖拽状态；`settings.layout.leftPanel` / `rightPanel`；`.ws-panel*` 与 `.playback-marker-card*` CSS。

**锁测**：

- `tests/unit/chart/config/PatternDrawerSettings.test.ts`（新增）：默认收起 / 300px、老设置的 leftPanel / rightPanel 不再带出、脏值与越界宽度回落、往返保真。
- `tests/dom/workspace/WorkspaceToolRail.test.tsx`（新增）：15 键 5 组顺序、点选持工具态 / 再点落回指针、复制剪切无选区置灰、粘贴空剪贴板置灰。
- `tests/dom/workspace/PatternLibraryDrawer.test.tsx`（新增）：空状态、收藏选区占位置灰、关闭钮、拖左缘改宽并在松手时落盘。
- `tests/dom/workspace/WorkspaceTopBarCluster.test.tsx`（改）：撤销 / 重做在项目切换器之后、右簇无 BPM 标签、谱面代码钮打开弹窗、片段库钮与 `Ctrl+Shift+B` 开合抽屉并落盘。
- 静态锁改写：`ToolbarNoteSkin`（字形改看工具轨，工具轨字形 26px）、`CurveConfigSettings`（工具轨不内联曲线配置）、`PlaybackMarkerWiring`（卡片 → 播放条按钮）、`PagesConvergence`（工作台件清单）、`PanelWidth`（issue 97 左右同宽作废 → 删）、`ProjectListWidth`（不再提左右面板）、`BrowserZoomLive`（视口夹取改看抽屉的 `max-width: 32vw`）。
