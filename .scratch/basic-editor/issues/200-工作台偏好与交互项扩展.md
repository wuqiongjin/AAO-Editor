# 200 · 工作台偏好与交互项扩展

Type: feature
Status: open
Blocked by:

**来源**：用户需求提出与 grilling 定案（2026-11-01）：
1. 滚轮反转功能（Mac 与 Win 滚轮操作习惯及自然滚动差异）；
2. 时间精度支持更高位数（对齐节拍与 Offset 需 3 位毫秒精度）；
3. 工作台顶栏设置面板收纳节奏图示 SE 音量，提升调音便捷度。
（注：前期讨论提及的“轨道背景不透明度”经评估确认无实际效用且易与背景皮肤透明度混淆，已从本票范围排除。）

## 范围

- 做：
  1. **滚轮反转**：增加反转滚轮方向开关，仅反转时间轴纵向滚动，包含 Shift+滚轮滚动同频反转；Ctrl+滚轮缩放保持原逻辑。
  2. **时间显示精度**：增加时间精度选项（标准 `0.1s` / 毫秒 `0.001s`），全局联动底部 PlayBar 与画布光标悬停实时预览线。
  3. **工作台顶栏设置浮层（`WorkspaceDisplayPanel`）结构重构**：按「画布 / 播放与音频 / 操作偏好」三组排布，接入上述新项与节奏图示 SE 音量调节（读写 `settings.audio.seVolume`）。
  4. **配置归一化与持久化**：新增字段均属于 additive 扩展，不 bump schemaVersion。
- 不做：
  - 不反转 Ctrl+滚轮缩放方向（保持放大/缩小通用操作心智）；
  - 不拆分 PlayBar 与预览线各自独立的精度开关（保持单一时间源精度，避免心智割裂与界面臃肿）；
  - 不做横向时间轴滚动；
  - 不做“轨道背景不透明度”（保持现状 `outsideTrack` 与全屏 45% 遮罩的舒适平衡，避免概念混淆）。

## 交互与参数定案

### 1. 滚轮反转（`invertWheel`）
- **配置位**：`AppSettings.display.invertWheel: boolean`，默认 `false`。
- **交互行为**：
  - 未开启（默认）：滚轮向下为倒退时间（靠近 beat0），滚轮向上为前进时间；
  - 开启时：时间轴纵向滚动方向取反；
  - **Shift 协同**：按住 Shift 时触发的纵向滚动与普通滚动方向完全一致同步反转，防止多选/拖拽音符时滚轮方向发生跳变；
  - Ctrl+滚轮缩放不受此开关影响。

### 2. 时间显示精度（`timePrecision`）
- **配置位**：`AppSettings.display.timePrecision: 'standard' | 'millisecond'`，默认 `'standard'`。
- **界面联动**：
  - `'standard'`（默认）：
    - PlayBar 当前时间显示 `mm:ss.s`（1 位小数，例如 `01:23.4`）；
    - 画布光标悬停实时预览线左沟槽显示分内秒 `SS.ss`（2 位小数，例如 `23.45`）。
  - `'millisecond'`（高精度）：
    - PlayBar 当前时间显示 `mm:ss.sss`（3 位毫秒，例如 `01:23.456`）；
    - 画布光标悬停实时预览线左沟槽显示分内秒 `SS.sss`（3 位毫秒，例如 `23.456`），左沟槽宽度与字号自适应适配 6 字符；
    - PlayBar 双击编辑输入框已有正则（支持 1~3 位小数）保持不变。

### 3. 浮层面板分组排布（`WorkspaceDisplayPanel`）
- **画布（Canvas）**：
  - 音符大小、长压透明度、同时点击线、色觉辅助、纵向比例、画质、轨道主题、线形分层、网格透明度、文字大小；
  - **[新增]** 时间显示精度（下拉选择：标准 0.1s / 毫秒 0.001s）。
- **播放与音频（Playback & Audio）**：
  - 显示标记点跳转按钮（Toggle）；
  - **[新增]** 节奏图示 SE 音量（百分比滑块 0%~100%，步长 5%，双向同步 `settings.audio.seVolume`）。
- **操作偏好（Preferences）**：
  - **[新增]** 反转滚轮滚动（Toggle，默认关）。

## 实现落点

- `src/chart/config/AppSettings.ts`：
  - 在 `AppSettings.display` 中增加 `timePrecision?: 'standard' | 'millisecond'`、`invertWheel?: boolean`；
  - `defaultSettings()` 填充默认值；
  - `loadSettings()` 与归一化函数加入边界与合法性兜底。
- `src/app/providers/ConfigProvider.tsx`：`setDisplay` 透传并持久化新增显示/偏好字段。
- `src/chart/geometry/TimeFormat.ts`：
  - 扩展 `formatTimePrecise(seconds, precision?)` 支持 3 位格式化；
  - 扩展 `formatInMinuteTime(seconds, precision?)` 支持 3 位格式化。
- `src/rendering/render.ts`：
  - `renderHoverInfo` 根据 `timePrecision` 格式化时间并微调绘制宽度。
- `src/playback/PlayBar.tsx`：读取 `timePrecision` 切换时间码显示位数。
- `src/chart/components/canvas/FinalVirtualCanvas.tsx`：
  - `handleWheel` 读取 `display.invertWheel`，按配置取反滚动步长。
- `src/pages/workspace/WorkspaceDisplayPanel.tsx`：重构三个配置分组，添加对应 UI 组件与 `setSeVolume` 接入。
- `src/i18n/messages/zh-CN.json` & `en.json`：补充各项文案、提示与下拉标签。
