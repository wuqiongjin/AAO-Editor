# 86 · 工作台工具栏音符图标向素材页看齐（+ 镜像图标语义）

Type: bug
Status: resolved（2026-09-11 实现 + 锁测，待你在页面验收）
Blocked by:

## 来源

用户 2026-09-11 同批复报两条工具栏图标问题，同属"工具栏图标"一类 → 合并本票。

## 症状

1. 键型/方向/滑条图标**糊、大小与朝向不对**；在素材页切换音符皮肤时这边**毫无变化**（期望：向素材页看齐）。
2. 「镜像」用 `RotateCcw`（逆时针旋转）表达"重置/撤销"，语义不符。

## 根因

工具栏写的是 **legacy 那一套**：`Toolbar.tsx:74-79` → `src/ui/SpriteIcon.tsx` 的 `NoteIcons`
（`./assets/skins/legacy/*.png` + 负百分比偏移 + `imageRendering:'pixelated'` + 尺寸写死 18px）。

素材页与画布走 **另一套**（issue 29 音符皮肤域）：`noteSkinRegistry.gen` → `buildActiveNoteIcons(settings.visual.noteSkin)`
→ `CanvasSpriteIcon`（参考实现 `NoteSkinPreview.tsx:68`；画布消费 `FinalVirtualCanvas.tsx:135-136`）。

两套素材 + 两套渲染路径 + 两套几何（legacy 百分比缩放 vs 像素矩形 + 墨迹/箭头组合 + 扁平化轨道）
⇒ 糊 / 尺寸 / 朝向不可能对齐，换肤也不可能联动。根因不是"图标没画好"，而是**工具栏从未接入音符皮肤域**。

## 修法

- `Toolbar.tsx` 去掉 legacy `NoteIcons` / `ui/SpriteIcon`，新增一个画布小件（如 `src/chart/rendering/NoteIconGlyph.tsx`）
  复用素材页绘制路径：`buildActiveNoteIcons(normalizeNoteSkinSelection(settings.visual.noteSkin))` + `CanvasSpriteIcon`。
  六个图标（单键 / 滑键 / 技能 / 左方向 / 右方向 / 滑条）与素材页**同素材、同朝向、同扁平化**，换肤即时重绘。
- 尺寸走工具栏既定逻辑尺寸（18px），DPR 上限与画布一致，不再 pixelated 放大。
- `Toolbar.tsx:171` `RotateCcw` → `FlipHorizontal2`（左右镜像；用户 2026-09-11 拍板）。

## 锁测

图标是 canvas 位图、且要验的是"是否接入皮肤域"，单测拿不到像素 → 照 `EditorAudioSessionRefactor.test.ts` 惯例用**静态源码断言**，
Playwright 像素（照 issue 67 口径）可作补充：

1. 新增 `tests/unit/ToolbarNoteSkin.test.ts`：`Toolbar.tsx` 不出现 `NoteIcons` 与 `ui/SpriteIcon`；
   出现 `buildActiveNoteIcons` 与 `settings.visual`（皮肤联动）；镜像行 icon 为 `FlipHorizontal2`（该行不再有 `RotateCcw`）。
2. 手工验收：素材页逐条目 / 整包换肤 → 回工作台，六图标即时变化且与素材页预览一致；浏览器 125% 缩放下不糊。
