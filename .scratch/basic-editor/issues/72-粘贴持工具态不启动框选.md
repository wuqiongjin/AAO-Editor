# 72 · 粘贴持工具态不启动框选（与「音符代码」同口径）

Type: bug
Status: open
Blocked by:

## 来源

用户 2026-09-10 清单 #2。

## 症状

粘贴态下在画布按下并拖动，会画出框选矩形（还带 issue 67 的实时预览高亮），松手却**什么也没发生** ——
与「音符代码」工具（压根画不出框）行为不一致。

## 根因

`canStartMarquee`（`src/chart/editing/CanvasGesture.ts:288`）只排除了 `noteCode`；
paste 仍启动 marquee 手势，松手后 `boxSelectOps` 的 paste 行返回 `[]`
（`src/chart/editing/ToolActionMatrix.ts:223`：「粘贴作用于位置，非选区」）→ 画了框、无结果。

## 修法

`canStartMarquee` 增加 `paste`（与 `noteCode` 同一理由：框选对它毫无作用）。
Shift+按住音符拖拽这条全局逃生口不受影响（拖拽侧先行返回）。

## 实现落点

| 文件 | 改动 |
| --- | --- |
| `src/chart/editing/CanvasGesture.ts` | `canStartMarquee`：`armedTool !== 'noteCode' && armedTool !== 'paste'` + 注释理由 |
| `docs/adr/0008-工具交互机制.md` §3 | 「不可框选」清单补 paste（与 noteCode 并列） |

## 锁测

`tests/unit/CanvasGesture.test.ts`：`canStartMarquee('paste') === false`（与既有 noteCode 例同形）。
