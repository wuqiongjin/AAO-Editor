# 185 · 片段库：浏览与收藏

Type: feature
Status: resolved
Blocked by: 184

**来源**：[164 片段收藏](./164-片段收藏.md) 定案 §3；权威 = [ADR-0023](../../../docs/adr/0023-片段收藏的载荷与存储边界.md)。第 2 刀，把 [183](./183-工作台换壳.md) 留下的抽屉空壳填成能用的库。

**现状**：`PatternLibraryDrawer` 只有标题、空状态与一颗 `disabled` 的「收藏选区」；`map.md` 里 164 的数据还没有。

**修法**：

- **卡片**：缩略图 + 名字 + 徽标（`含 BPM 变化 · n` / `含倒流`）+ hover 菜单（导出——**动作落 187** / 删除）。列数、卡片高、缩略图比例、间距由实现定（164 明确不钉像素）。
- **缩略图**：由 `notes` + `bpmContext` **实渲染**（不存位图），**按布局轴取景**——倒流片段会折返，按 beat 跨度归一化会把折返压平（ADR-0023 Consequences）。复用画布渲染（`FrameView` / `ChartGeometry`）离屏画一张静态图。
- **搜索**：抽屉顶部常驻输入框，按名字子串过滤（不区分大小写）；「库里没有片段」与「搜索无匹配」是两套空态。
- **收藏**：启用 footer「收藏选区」按钮；新增 `execSavePattern`（`ShortcutConfig`，默认 `Ctrl+Shift+D`，进快捷键页、冲突拒绝）→ `WorkspacePage` 分发 → `capturePattern` → 落库 → toast「已收藏到片段库」。**无选区 = 无事发生 + 按钮置灰**；**不自动打开抽屉**。
- **只读谱面**：**卡片置灰**（贴入被拦，186），但「收藏选区」**照常可用**——已上传谱面允许选中 / 复制，收藏读的是选区、不写谱面，两者不能一起灰。
- **改名**：双击卡片名字就地编辑，Enter 提交 / Esc 取消（与 BPM 数字同一套就地编辑词汇）；空名拒绝、超长截断显示但存原文。
- **删除**：hover 出删除钮 → 既有弹窗壳 `sm` 确认（`src/ui/Dialog`）→ 立即删；不建撤销栈。
- **排序**：收藏时间倒序（最新在最上）。
- i18n：zh-CN + en 两套文案。

**锁测**：

- `tests/dom/workspace/PatternLibraryDrawer.test.tsx`（改）：两套空态、卡片三元素齐、搜索过滤与清空复原、改名 Enter 提交 / Esc 取消 / 空名拒绝、删除走确认弹窗、只读谱面**卡片置灰但「收藏选区」仍可点**（用已上传谱面收片段）。
- `tests/dom/workspace/PatternSaveShortcut.test.tsx`（新增）：`Ctrl+Shift+D` 有选区调 capture 并 toast、无选区无事发生、抽屉开合态不被改动。
- `tests/unit/chart/config/ShortcutConfig.test.ts`（改）：`execSavePattern` 默认键与冲突表。
- 静态锁：`execSavePattern` **不在** `CHART_EDIT_FUNCTIONS`（收藏读的是选区、不写谱面，只读谱面也允许）。
- 缩略图（Canvas 像素）单测拿不到 → **Playwright 截图**：普通片段、倒流折返片段各一张，断言折返处被画出来。
- 卡片 hover 菜单与拖宽手感 → 浏览器手工验收。

## Answer

2026-10-31 实现（第 2 刀，抽屉从空壳变成能用的库）：

- **库状态**：`src/chart/patterns/usePatternLibrary.ts` —— 一次载入、每次变更整库落盘的**唯一写入口**；活在 `WorkspacePage`（抽屉可没开，快捷键照样要收藏）；落盘失败回滚到上一次好状态并 toast，不留"界面存了、磁盘没有"的分裂。视图操作（排序 / 搜索 / 改名 / 删除 / 徽标口径）在 `library.ts`，纯函数。
- **卡片**：缩略图 + 名字 + 徽标（`含 BPM 变化 · n` / `含倒流`）+ hover 动作（导出**置灰占位**，动作落 187；删除）。列数 = 单列，缩略图 88×56（实现定）。
- **缩略图** `PatternThumbnail` + `thumbnail.ts`：由 `notes` + `bpmContext` **实渲染**、不存位图；取景走 `ChartGeometry` 的 `BpmTimeline`（与画布同一份正向映射）拿**布局坐标 pos 的极值**，倒流折返原样折回来。**实现口径偏离**：没有复用 `renderChart` / `FrameView` —— 它只支持等比缩放，一条 8 拍片段在布局轴上是 7 车道 × 数千虚拟 px 的细条，塞进卡片只剩 ~20px 宽的窄带、音符糊成一团；改为「同一份 `ChartGeometry` + 非等比取景 + 形状速写」的画法（横向按车道铺满、纵向由布局轴定）。折返的正确性由场景单测（首尾同高、中段在更高处）+ 记录型 ctx 的折线锁看守。
- **搜索**：顶部常驻输入框，按名字子串（不区分大小写、trim）；「库里没有片段」与「搜索无匹配」两套空态；载入中不显示空态（loading ≠ 空库）。
- **收藏**：`execSavePattern`（`ShortcutConfig`，默认 `Ctrl+Shift+D`，类别「片段」、索引桶「编辑工具」、进快捷键页、冲突拒绝）→ `WorkspacePage` 分发 → `useSaveSelectionPattern`（选区 → `capturePattern` → 落库 → toast「已收藏到片段库」）。**无选区 = 无事发生 + 按钮置灰**；**不自动打开/关闭抽屉**。**故意不进 `CHART_EDIT_FUNCTIONS`**：收藏读选区、不写谱面，已上传谱面照常可用。
- **只读谱面**：卡片置灰 + tooltip 说明；「收藏选区」不禁用（静态锁禁掉 `disabled={…readOnly…}` 这种写法）。
- **改名 / 删除**：双击名字就地编辑（Enter 提交 / Esc 取消 / 失焦提交，Esc 后补发的 blur 被吞掉）；空名拒绝、超长存原文只做 CSS 省略。删除走 `ConfirmDialog`（`Dialog` 的 `sm` 档）→ 立即删、不建撤销栈。
- **排序**：`createdAt` 倒序（同毫秒按 id 全序，避免抖动）；新收藏进列表头。
- i18n：zh-CN + en 全套新文案，删掉 183 的 `patternLibrary.saveSoon` 占位。
