# 185 · 片段库：浏览与收藏

Type: feature
Status: resolved
Blocked by: 184

**来源**：[164 片段收藏](./164-片段收藏.md) 定案 §3；权威 = [ADR-0023](../../../docs/adr/0023-片段收藏的载荷与存储边界.md)。第 2 刀，把 [183](./183-工作台换壳.md) 留下的抽屉空壳填成能用的库。

**现状**：`PatternLibraryDrawer` 只有标题、空状态与一颗 `disabled` 的「收藏选区」；`map.md` 里 164 的数据还没有。

**修法**：

- **卡片**：缩略图 + 名字 + 徽标（速度跨度 `120 → 180`，负值数字危险色 —— 186 二轮替换了原来的「含 BPM 变化 · n / 含倒流」）+ 常驻 ⋯ 菜单（导出——**动作落 187** / 删除）。列数、卡片高、缩略图比例、间距由实现定（164 明确不钉像素）。
- **缩略图**：由 `notes` + `bpmContext` **实渲染**（不存位图），**按布局轴取景**——倒流片段会折返，按 beat 跨度归一化会把折返压平（ADR-0023 Consequences）。复用画布渲染（`FrameView` / `ChartGeometry`）离屏画一张静态图。
- **搜索**：抽屉顶部常驻输入框，按名字子串过滤（不区分大小写）；「库里没有片段」与「搜索无匹配」是两套空态。
- **收藏**：启用 footer「收藏选区」按钮；新增 `execSavePattern`（`ShortcutConfig`，默认 `Ctrl+Shift+D`，进快捷键页、冲突拒绝）→ `WorkspacePage` 分发 → `capturePattern` → 落库 → toast「已收藏到片段库」。**无选区 = 无事发生 + 按钮置灰**；**不自动打开抽屉**。
- **只读谱面**：**卡片置灰**（贴入被拦，186），但「收藏选区」**照常可用**——已上传谱面允许选中 / 复制，收藏读的是选区、不写谱面，两者不能一起灰。
- **改名**：双击卡片名字就地编辑，Enter 提交 / Esc 取消（与 BPM 数字同一套就地编辑词汇）；空名拒绝、超长截断显示但存原文。
- **删除**：hover 出删除钮 → 既有弹窗壳 `sm` 确认（`src/ui/Dialog`）→ 立即删；不建撤销栈。
- **排序**：收藏时间倒序（最新在最上）。
- i18n：zh-CN + en 两套文案。

**锁测**：

- `tests/dom/workspace/PatternSaveShortcut.test.tsx`（新增）：`Ctrl+Shift+D` 有选区调 capture 并 toast、无选区无事发生、抽屉开合态不被改动。
- `tests/unit/chart/config/ShortcutConfig.test.ts`（改）：`execSavePattern` 默认键与冲突表。
- 静态锁：`execSavePattern` **不在** `CHART_EDIT_FUNCTIONS`（收藏读的是选区、不写谱面，只读谱面也允许）。

## Answer

2026-10-31 实现（第 2 刀，抽屉从空壳变成能用的库）：

- **库状态**：`src/chart/patterns/usePatternLibrary.ts` —— 一次载入、每次变更整库落盘的**唯一写入口**；活在 `WorkspacePage`（抽屉可没开，快捷键照样要收藏）；落盘失败回滚到上一次好状态并 toast，不留"界面存了、磁盘没有"的分裂。视图操作（排序 / 搜索 / 改名 / 删除 / 徽标口径 / 新片段追加）在 `library.ts`，纯函数；新片段追加口径与 `PatternStore.add` 共用 `appendNewPattern`，不各写一遍。
- **读失败一律不许写**（评审补的第 3 套态）：整库落盘的前提是手里这份是对的；`load()` 失败时手里是空库，此时写一次就把用户已有片段整份抹掉。故 `status = 'loading' | 'ready' | 'error'`，`error` 下 `add / rename / remove` 全部拒绝，抽屉显示「片段库读不出来」而不是冒充空库。
- **卡片**：缩略图 + 名字 + 徽标（速度跨度，186 二轮改口径）+ **常驻 ⋯ 菜单**（导出**置灰占位**，动作落 187；删除）。列数 = 单列，缩略图 88×56（实现定）。
- **卡片动作入口（2026-10-31 验收改向）**：原实现是 hover 才浮现的两个图标，用户指出「入口不可见」且未来要支持多选 / 整库导出。定为：卡片右上角**常驻低对比度 ⋯**（一直可见）→ portal 浮层菜单（Esc / 点遮罩关闭、焦点回触发钮）。分工写死：**整库导入导出 = 抽屉头 ⋯（187）**、**单条 = 卡片 ⋯ 菜单**、**多选 = 将来单独做「选择模式 + 抽屉底部选区工具条」**，不往卡片右上角继续堆按钮。这也让 186 的"点击卡片即粘贴"不必与不可见热区抢命中。
- **缩略图** `PatternThumbnail` + `thumbnail.ts`（几何）+ `thumbnailPaint.ts`（画法）：由 `notes` + `bpmContext` **实渲染**、不存位图；取景走 `ChartGeometry` 的 `BpmTimeline`（与画布同一份正向映射）拿**布局坐标 pos 的极值**，倒流折返原样折回来。
  - **音符本体贴真实皮肤精灵**（2026-10-31 验收改向：自绘方块/横条把单键、滑键、技能键画成了一个样）。选款复用画布的 `singleIconConfig` / `slideNodeIconConfig`（含「flick 胜 skill」issue 147 的优先级），滑条端点/中间结点分款；hidden 结点不出图标、带体仍穿过。精灵按固定 9–13px（跟车道宽）贴，不随纵向压缩变形；皮肤图异步就绪后补画一次。
  - **第二处验收返工（同日）——三件事都改成复用画布既有实现，不自己近似**：
    1. **滑条段**：先是 `splitBandAtFolds` + `bandPolygonAt` 的真多边形（不是细线）；同日第三轮再改 —— 实心多边形"死绿、硬边"且**普通带与 SP 带长得一样**，于是导出画布的 `renderBandStrip`（原 `renderSpBandStrip`）直接复用：材质剖面来自**皮肤贴图采样**（中心暗 / 亮缘 / 软边），`slideBand` 与 `slideBandSp` 各取自己的剖面，回折处逐行合成 = 自叠更亮。光栅化拿不到（无 DOM / 画布不可用）时退多边形，不会空白。
    2. **方向键组合**：`renderDirGroup` 抽成导出（只吃 `spriteIcon` + 缩放，画布两处调用点改传 `rc.spriteIcon`），缩略图**整组一次画**（N 条覆盖轨本体 + 最外侧箭头），不再按轨摆互不相连的散点；组内偏移用缩略图的"每虚拟 px 的屏幕 px"换算，所以组是连着的。
    3. **flick 顶部箭头**：`renderDecorator` + `flickTopDecorator`。第三轮修了**距离**：装饰器的尺寸与偏移都是「主精灵设计尺寸 × spriteScale」，第一版把设计 px 的偏移当成缩略图 px → 箭头被甩到离音符很远；现在锚点传设计尺寸（36×21.6）、`spriteScale = sizePx / 36`。单键与滑条**端点**各补一次，方向键不补（画布的箭头是它的组合件）、滑条中间结点不补（issue 145 #3）。
  - **仍不复用 `renderChart` / `FrameView`**：它只支持等比缩放 —— 1 拍 = 220 虚拟 px、7 轨只有 210 虚拟 px 宽，88×56 的卡片装 8 拍片段，等比缩完轨道只剩 6.7px（哪怕 1 拍，图标也只有 9px）。故保留「非等比取景 + 单点贴图」；带体不贴纹理（10px 宽上只剩噪声），用体色多边形。
  - **密集片段精灵会叠**：这是卡片尺寸的固有限制 —— 8 拍装进 56px，每拍只有 7px，任何画法（含自绘点）都会叠；用户 2026-10-31 确认接受。
  - 悬停大预览**不做**：186 之后「点卡片即贴」本身就是最快的真实预览（画布上的粘贴幽灵就是真渲染），再在 300px 抽屉里弹一块盖住画布的大图，收益不抵成本。若 186 落地后仍看不清细节，从"粘贴态幽灵放大"入手，不要另造预览。
- **搜索**：顶部常驻输入框，按名字子串（不区分大小写、trim）；「库里没有片段」/「搜索无匹配」/「读不出来」三套空态；载入中不显示空态（loading ≠ 空库）。
- **收藏**：`execSavePattern`（`ShortcutConfig`，默认 `Ctrl+Shift+D`，类别「片段」、索引桶「编辑工具」、进快捷键页、冲突拒绝）→ `WorkspacePage` 分发 → `useSaveSelectionPattern`（选区 → `capturePattern` → 落库 → toast「已收藏到片段库」）。**无选区 = 无事发生 + 按钮置灰**；**不自动打开/关闭抽屉**。**故意不进 `CHART_EDIT_FUNCTIONS`**：收藏读选区、不写谱面，已上传谱面照常可用。置灰判据与快捷键同源（`useSaveSelectionPattern` 同时给出 `canSave` 与 `save`，抽屉只收布尔，不各自读一次选区）。
- **只读谱面**：卡片置灰 + tooltip 说明；「收藏选区」不禁用（静态锁禁掉 `disabled={…readOnly…}` 这种写法）。
- **改名 / 删除**：双击名字就地编辑（Enter 提交 / Esc 取消 / 失焦提交，Esc 后补发的 blur 被吞掉）；空名拒绝、超长存原文只做 CSS 省略。删除走 `ConfirmDialog`（`Dialog` 的 `sm` 档）→ 立即删、不建撤销栈。
- **排序**：`createdAt` 倒序（同毫秒按 id 全序，避免抖动）；新收藏进列表头。
- i18n：zh-CN + en 全套新文案，删掉 183 的 `patternLibrary.saveSoon` 占位。
