# 235 曲线工具形状模板扩充与图形化选型

- **Type**: grilling
- **Status**: resolved（定案于 grill-with-docs 2026-11-14 + 原型两轮增补 2026-11-15；2026-11-15 已实现并全量通过单测/DOM 测试/代码审查）

## 来源

用户发起 `/grill-with-docs` 指出曲线工具当前内置「形状模板」（原面板入口下拉项，俗称自定义模板）存在三点痛点：
1. **样式过少**：仅有 5 款（`arc` / `s-curve` / `wave` / `heart` / `zigzag`），缺少谱面高频使用的面筋条、锁链条、多拱/起尾钩/衰减震动等实用样式；
2. **部分不实用**：如 `zigzag` 固定 25 点且固定套用 ±1.8～2 轨过宽振幅，长段稀疏、短段扎堆，实战极难直接复用；
3. **不够直观**：下拉文字列表完全无法一眼看出形状，必须先试画到画布上才能确认形态与凸向。

经 Q1–Q10 十轮 `grilling` 访谈并搭配可交互原型（`?variant=A`）视觉评审与实谱（`150030.json`、`689_SP.json` 等官方 SP 谱面样本）考证，全部设计边界已拍板收敛，frontier 为空。

---

## 现状与根因

1. **目录与几何生成（`src/chart/editing/ShapeTemplates.ts`）**：
   - 仅定义 5 款模板；全局固定 `TEMPLATE_AMPLITUDE = 2`（车道单位），对 `arc`/`heart` 合适但对震动条/面筋/锁链严重过宽；
   - `zigzag` 采用固定 25 点采样，未随段拍长自适应分配周期齿数；
   - 缺少利用 `Δbeat = 0` 同拍隐藏跃迁点构建斜切面筋（`gluten-saw`）与交替锁链（`chain-alt`）的内建能力。
2. **参数模型与持久化（`src/chart/types.ts`、`src/chart/editing/CurveTool.ts`、`src/chart/editing/SpanCurve.ts`）**：
   - `SpanTemplateParam` 已有 `precision?: CurvePrecision` 与 `mirrored?: boolean`，缺少 `amplitudeScale?: number`；
   - `CurveConfig` 仅持久化 `mode / easingFamily / easingType / precision / templateId`，未持久化用户惯用的偏向与幅度倍率。
3. **选型 UI（`src/pages/workspace/CurveConfigPanel.tsx`、`CurveOptionsCapsule.tsx`、`src/i18n/messages/*.json`）**：
   - `CurveConfigPanel` 使用纯文字 `<select>`（`模板`、`缓动族`、`缓动型`、`精度`），选中某项后另一侧仅做灰态禁用；既不直观、空间利用差，也不暴露 `mirrored` 与幅度控制。

---

## 定案（Q1–Q10 全量汇总）

1. **Q1（范围边界）= A**：本期仅重构并扩充**内置形状模板库**与选型交互，**不实现**"将选中滑条存为用户自定义模板"（保持与 `片段` 边界清晰，避免额外本地模板序列化负担）。
2. **Q2 + Q3 + Q7（模板目录与老 ID 兼容）= 18 款三分组目录（未来可扩展）**：
   - 完整保留旧 5 个 ID（`arc` / `s-curve` / `wave` / `heart` / `zigzag`），其中改进 `zigzag` 为随拍跨度与 `densityScale` 自适应周期并收窄基准幅度（`baseAmplitude = 0.45`）；
   - 按三类分组共 **18 款**：
     - **平滑弧弯（smooth，8 款）**：`arc`（大弧）、`s-curve`（S 形）、`wave`（双波浪）、`double-arc`（双峰弧）、`soft-elastic`（柔弹弧）、`hook-tail`（甩尾钩）、`hook-head`（起手钩）、`heart`（半心弧）；
     - **节奏 / 震动（rhythm，4 款）**：`zigzag`（震动条）、`damped`（余震条）、`pulse`（尖刺脉冲）、`step`（阶梯折线）；
     - **面筋 / 锁链（special，6 款）**：`gluten-spindle`（面筋·螺旋）、`gluten-saw`（面筋·斜纹，含 `Δbeat = 0` 同拍跃迁）、`gluten-comb`（面筋·梳齿，1/16 × 1/12 错拍同拍跃迁）、`chain-square`（锁链·方波）、`chain-bead`（锁链·竹节）、`chain-alt`（锁链·拉链，含 `Δbeat = 0` 同拍跃迁）。
   - 短时间内保留全部 18 款，预留扩展位以备后续增补。
3. **Q4 + Q8 + Q9 + 原型反馈（偏向、幅度与段密）= 三维正交调节参数**：
   - **偏向（`mirrored: boolean`）**：`↰ 左偏` / `右偏 ↱`——绕弦线（起终点连线）将横向偏移取反（与工作台对称镜像 `H` 区分：不移动两端可见结点，只切换凸向；`H` 镜像既有模板段时同步对 `mirrored` 取反）；
   - **幅度（`amplitudeScale: number`）**：每款模板拥有专属合理 `baseAmplitude`（平滑类 `0.75~1.0`、窄振/面筋/锁链 `0.45~0.85`），面板提供 **小（0.5×） / 中（1×） / 大（1.5×）** 三档倍率（标签简洁为 `小` / `中` / `大`，悬停 `title` 提示倍率）；
   - **段密（`densityScale: number`）**：面向 `rhythm` 与 `special` 共 10 款分段/周期模板，面板第 3 排由 `精度` 上下文切换为 **`段密`：稀疏（0.5×） / 标准（1×） / 稠密（2×）**（3 档收敛，不设极密），直接调节震动齿数、锁链段数或面筋肋数。
4. **Q5 + Q6 + Q9（UI 选型交互定案：精简版原型 A）**：
   - 顶部两段切换开关：**`缓动函数` | `形状模板`**（去除 `(40种)`、`(18款...)` 等多余括号说明）；
   - **形状模板视图**：
     - 顶部分类筛选胶囊：`全部` / `平滑弧弯` / `节奏/震动` / `面筋/锁链`；
     - 4 列可视化 SVG 预览网格（按 1 拍基准采样，缩略图与画布实际 1 拍滑条 1:1 匹配；随当前 `mirrored`、`amplitudeScale`、`densityScale` 实时重绘；卡片保留简洁名与轻量 `title` 提示，去掉网格下方多余的选中详情条与 `?` 帮助弹窗）；
     - 底部三行紧凑胶囊按钮：`偏向`（`↰ 左偏` / `右偏 ↱`）、`幅度`（`小` / `中` / `大`）、上下文第 3 行（`adjustableDensity` 模板显示 **`段密`**：`稀疏` | `标准` | `稠密`；连续平滑模板显示 **`精度`**：`1/16` | `1/32` | `1/64`）；
   - **缓动函数视图**：实时 SVG 曲线预览 + `缓动族` `<select>` + `缓动型` `<select>` + **`精度` 同源改用 `1/16` | `1/32` | `1/64` 胶囊按钮**；
   - **收起状态胶囊（`CurveOptionsCapsule`）**：工具徽标旁显示当前曲线/模板的**实时迷你 SVG 图标**与简洁摘要文案。
5. **Q10（持久化、编辑交互、i18n 与文档）**：
   - `CurveConfig` 增量追加 `templateMirrored?: boolean`（默认 `false`）、`templateScale?: number`（默认 `1`）与 `templateDensity?: number`（默认 `1`），由 `normalizeCurveConfig` 补齐并与 `settings.curve` 持久化（**不提升 `schemaVersion`**）；
   - `SpanTemplateParam` 追加 `amplitudeScale?: number` 与 `densityScale?: number`（缺省兼容历史工程回退为 `1`）；
   - 已有段编辑一致性：曲线工具单击既有段 / 框选重刷时写入当前 `mirrored`、`amplitudeScale` 与 `densityScale` 重烘焙；拖端点重投影保留上述参数；`H` 水平镜像仅翻转 `mirrored`、幅度与段密不变；
   - 中/英双语词典（`zh-CN.json` / `en.json`）补齐 18 款模板、3 个分组与偏向/幅度/段密/精度控件文案。

## 实现落点

1. **清理原型（开工首步）**：按 `prototype` 技能约定，移除 `AppShell.tsx` / `WorkspacePage.tsx` 中的 `?variant=` / `ProtoCurveCapsule` 临时挂点及 `src/pages/workspace/prototype-curve-templates/`、`src/ui/PrototypeSwitcher.*` 丢弃代码（或在归档分支留档后从工作区移除）。
2. **模板内核（`src/chart/editing/ShapeTemplates.ts`、`src/chart/types.ts`、`src/chart/editing/SpanCurve.ts`）**：
   - 定义 `TemplateCategory`（`'smooth' | 'rhythm' | 'special'`）、18 款 `ShapeTemplate`（含 `category`、`adjustableDensity`、`hasZeroBeatJump`、`sample(spanBeats, precision, densityScale)`）；
   - 扩展 `SpanTemplateParam.amplitudeScale?: number` 与 `densityScale?: number`，并在 `bakeTemplatePoints` / `bakeTemplateParam` 应用 `scale * (mirrored ? -1 : 1)`；
   - 对含同拍跃迁点（`gluten-saw` / `gluten-comb` / `chain-alt`）确保生成时间满足 `t[i] >= t[i-1]` 弱单调且隐藏点不超限（平滑类 `TEMPLATE_MAX_POINTS = 128`、高密分段 `256`）。
3. **曲线配置与编辑器接线（`src/chart/editing/CurveTool.ts`、`src/pages/workspace/curveLabels.ts`、`WorkspacePage.tsx`）**：
   - 扩展 `CurveConfig`（`templateMirrored`、`templateScale`、`templateDensity`）、`DEFAULT_CURVE_CONFIG`、`normalizeCurveConfig`、`spanParamFromCurveConfig`；
   - 确保 `mirrorSpanParam` 仅翻转 `mirrored`、保留 `amplitudeScale`、`densityScale` 与 `precision`。
4. **图形化胶囊 UI 与样式（`src/pages/workspace/CurveConfigPanel.tsx`、`CurveConfigPanel.css`、`CurveOptionsCapsule.tsx`、`CurveOptionsCapsule.css`、`curveSvg.ts`、`CurveMiniSvg.tsx`）**：
   - 实现精简版原型 A 的两段模式切换、4 列 SVG 模板网格、3 类筛选、偏向/幅度/上下文第 3 排（段密或精度）、缓动 SVG 预览与精度胶囊按钮、收起态迷你 SVG 图标。
5. **国际化文案（`src/i18n/messages/zh-CN.json`、`src/i18n/messages/en.json`）**：
   - 补齐 `curve.*` 与 `shape.*` 全量词条（18 款名称/提示、3 分组、偏向/幅度/段密/精度提示）。

1. **模板几何与兼容单测（`tests/unit/chart/editing/ShapeTemplates.test.ts`）**：
