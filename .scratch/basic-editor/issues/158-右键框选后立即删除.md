# 158 · 右键框选完成后立即删除

Type: grilling（改 ADR-0008 右键通路；落地 = feature）
Status: resolved（2026-09-25 实现）
Blocked by: —

## 来源

用户 2026-09-25：「右键支持框选，框选完成后立即删除（等价于区域选择后，执行删除功能）。」

## 症状

现状右键 **不是** 框选：`GestureSession.begin` 对 `button !== 0` 只置 `rightButtonHeld`，松手走 `commitRightUp`（`findItemAt` ?? `findBpmLineAt`，issue 88：命中 ∈ 选区 → 整片删）。左键框选才有矩形；删除工具左键框选才「松手即删」。

## 根因

issue 74 / ADR-0008 把右键定成「点删 + 按住预览」，没有右键拖框这条手势。

## 定案（用户 2026-09-25）

grill 两轮：Q1=A / Q4=A / Q5=A / Q6=A。

1. **双模态**：未过框选阈值（**8px**，issue 141）→ **现状点删**（含 issue 88 整区、含 BPM 点删、beat 0 重置为 120）；过阈值 → 右键框选手势，松手按 **删除工具框选** 同一套目标立刻删除。
2. **目标集** = `computeItemsInBox` + `computeBpmLinesInBox`（框须横向盖住整条轨道才带上 BPM）。空框 = 无事发生。提交后 **清选区**（与 `boxSelectOps('delete')` 相同）。
3. **任意持工具态**都可右键框删（含粘贴 / 音符代码：它们只禁 **左键** 框选）。
4. **预览**：未过阈值仍只红光标下对象（issue 74/89）；过阈值后走删除工具框选预览（框内全红，含 BPM）。Esc 取消进行中手势，松手不删。画布外松手不删。
5. 右键 **不** 启动拖拽移动。过阈值后不再走 issue 88 点删。

实现时修订 ADR-0008：右键通路补「拖过 8px = 删除工具框选行」；`canStartMarquee` 的粘贴/音符代码例外 **不** 套到右键。

## 实现落点

| 文件 | 改动 |

## 锁测

- `tests/unit/chart/editing/GestureSession.test.ts`：右键位移 7px 松手 → 点删（`actionOnTargetsOps('delete')`）；8px → `setNotes` 删框内且 `setSelection []`；框住 BPM 横线（整轨覆盖）→ BPM 进删除集；粘贴态同样能右键框删。
- `tests/unit/visual/render/SelectionVisual.test.ts`：`rightButtonHeld` + `selectionBox` → 框内 danger（含 BPM）；仅 `rightButtonHeld` 无框 → 仍只红 hover。
- DOM 时序（contextmenu / window mouseup）单测盖不到 → 手工：① 右键点删仍在；② 拖框松手即删且预览红；③ Esc / 画布外松手不删。

## Answer

右键 down 记按下点并 `attachWindow`（不再另挂 mouseup effect）。未过 8px 仍 `commitRightUp` 点删；过阈值起框，松手 `boxSelectOps('delete')`（含 BPM、不走 `canStartMarquee`）。预览：`rightButtonHeld` ∧ 框 → BPM 进 `buildPreviewSets`。ADR-0008 已补双模态。锁测 GestureSession + SelectionVisual 已绿。DOM 时序仍按票内手工清单验收。
