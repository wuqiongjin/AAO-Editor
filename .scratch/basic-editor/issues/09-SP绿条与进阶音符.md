## Question

进阶音符：SP 绿条（SP 滑条，含过渡结点缓动函数，见谱面代码规则文档"SP滑条"）、负数 BPM、更多音符样式。决定本 effort 是否纳入、纳入哪些、优先级：
- SP 绿条生成算法（正弦/缓动）是否纳入 MVP？
- 负数 BPM 语义。

产出：进阶音符纳入范围决策。

## Answer（结论）

**进阶音符纳入范围决策（2026-09-12 grill 定案，权威 = ADR-0009）**：

- **SP 绿条：全纳入**，切四片独立交付：S1 材质接线（含 hidden 段用 longNoteLine2，段级判定）→ S2 缓动生成 + 曲线工具直接放置（10 族 × 4 型全量，精度三档 1/16、1/32、1/64；单击链式 + 拖动画笔）→ S3 拖带弯曲（slideRegion 可拖 = 拉弓变形，拨弯即转化，一动就自由化）→ S4 形状模板（三来源统一：缓动/自由点集/模板）。
- **数据模型 = 参数随行**：缓动/曲线参数挂段上、随谱面工程保存；hidden 采样点 = 渲染/命中/导出唯一真相；导出必然烘焙（Bestdori 可直接导入），导入 = 自由点集段（不做拟合）。
- **负数 BPM：不纳入本票**，拆 [issue 100](./100-负数BPM语义.md) 单独 grill。
- 交互槽位沿用 ADR-0008（框选组合 / 就地编辑 / 指针态拖拽），修订三处见 ADR-0008 头部 2026-09-12 修订条目。
