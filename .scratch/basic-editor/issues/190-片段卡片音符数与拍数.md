# 190 · 片段卡片显示 N 音符 / N 拍

Type: feature
Status: resolved
Blocked by:

**来源**：2026-10-31 用户追加讨论（N 音符、N 拍都要）。184–187 已 resolved，本票只加卡片展示，不改片段载荷 / 存储 / 分享。

## 目标

卡片上能直接扫到片段的规模，不用打开详情；两个值都是**派生值**，不进 `Pattern` 字段、不进导入导出。

## 口径

- **音符数**：复用 `countChartNotes`（`src/chart/editing/NoteEditing.ts`）——
  - 单键 / 左方向 / 右方向各 1；
  - 滑条 / 长条按**非 hidden 连接点**逐点计；
  - BPM / System / Opaque 不计。
  - 与画布音符计数 / combo 同口径，**不另写第二个音符数定义**。
- **拍数**：片段音符（含滑条 / 长条的全部连接点，**含 hidden**）的 `maxBeat − minBeat`；与 `capture` 对有效音符 / 连接点的包围盒口径一致，BPM / System / Opaque 不参与。没有可投影音符时记 0。
- 显示格式：整数显示 `10 拍`；非整数保留一位小数并去掉无意义的 `.0`（如 `10.5 拍`）。
- 两个函数做成纯函数（建议 `src/chart/patterns/stats.ts`），供卡片与后续排序票复用；不要在抽屉里各算一份。

## 卡片

- 现有卡片保持：缩略图 + 名字 + `BPM 120 → 180` 徽标 + 常驻 ⋯。
- 在徽标下方加一行小字：`12 音符 · 10 拍`（`--text-2xs` / 弱化色）；名字超长仍只省略名字。
- 卡片高度会相应增加；就地改名输入框只替换名字行，统计行保持。
- 读屏名仍以「把『X』贴到画布」为主，不把统计塞进 aria-label（避免读屏过长）。
- 空片段 / 只有 BPM、System 的异常数据：显示 `0 音符 · 0 拍`，不抛错。

## 实现落点

- `src/chart/patterns/stats.ts`（新增）：`patternNoteCount` / `patternBeatSpan`（或一个 `patternStats` 返回两者）。
- `PatternLibraryDrawer.tsx`：卡片徽标区加统计行；i18n 两条（zh-CN + en）。
- 不改 `types.ts` / `record.ts` / `share.ts` / `PatternStore.ts`。
- 不建议把统计写进缩略图位图或缓存；渲染时派生即可；若列表规模暴露性能问题，再在载入时算一次缓存。

## 锁测

- `tests/unit/chart/patterns/PatternStats.test.ts`（新增）：单键 / 方向键 / 滑条；滑条 hidden 结点**不计音符数但计拍数**；BPM / System / Opaque 不计；非整数拍；空片段 / 只有 BPM 的脏数据。
- `tests/dom/workspace/PatternLibraryDrawer.test.tsx`（改）：卡片同时显示 `N 音符 · N 拍`；改名 / 删除 / 搜索 / 只读态 / 当前粘贴来源高亮不受影响；统计行不抢 ⋯ 菜单。
- 静态锁：`types.ts` / `record.ts` / `share.ts` 没有新增字段（防止把派生值误写进载荷）。

## Answer

2026-10-31 实现：

- **派生纯函数** `src/chart/patterns/stats.ts`：`patternNoteCount` 直接复用 `countChartNotes`；`patternBeatSpan` 按存储 `beat` 的 `maxBeat − minBeat`，滑条 / 长条含全部连接点（含 hidden、含负 beat），BPM / System / Opaque 不参与，无可投影音符 → 0；`patternStats` 一次返回两者；`formatPatternBeatSpan` 整数不带小数、非整数四舍五入到一位并去掉无意义的 `.0`。
- **卡片** `PatternLibraryDrawer.tsx`：徽标下新增 `.pld-card__stats` 统计行（`N 音符 · N 拍`），样式 `--text-2xs` + `--text-muted` + `tabular-nums`；名字仍只省略名字，就地改名只替换名字行，统计行与 ⋯ 菜单不受影响；读屏 aria-label 仍只讲「把『X』贴到画布」。
- **i18n**：zh-CN / en 各新增一条 `patternLibrary.cardStats`。
- **载荷边界**：`types.ts` / `record.ts` / `share.ts` / `PatternStore.ts` 未改，统计只在渲染时派生、不落库、不进分享。
- **锁测**：`tests/unit/chart/patterns/PatternStats.test.ts` 19 例（单键 / 方向键 / 滑条 / 长条；hidden 不计音符数但计拍数；负 beat hidden；BPM / System / Opaque 不计；非整数与 subBeat 不折算；空片段 / 只有 BPM / 空滑条；显示格式；CSS 字号与弱化色；载荷静态锁）；`tests/dom/workspace/PatternLibraryDrawer.test.tsx` 增 4 例（统计行 / 改名保持 / ⋯ 菜单 / 空数据），既有改名、删除、搜索、只读态、当前来源高亮用例全绿。
- **验证**：`npx tsc -b` 0；`npm run test:types` 报错均落在本票未触碰的文件，改动文件无类型错误；eslint 改动文件无新增；全量 vitest 371 文件 / 4100 例全绿。
- **待手工验收**：真实抽屉里长名字 / 窄宽度下统计行省略与卡片实际高度。

## Comments

- **2026-10-31 验收样式微调（用户）**：统计行保持单行小字、不升级成 BPM 式胶囊；颜色由 `--text-subtle` 提到 `--text-muted`（11px 下 subtle 对比度不足），并加 `font-variant-numeric: tabular-nums` 让多张卡的数字纵向对齐。单位维持「拍」——秒依赖 BPM，倒流区下带符号累加会回退，不能作为稳定的规模口径。
