# 106 · SP 画笔点序回折废止（折返只能来自倒流区）

Type: bug
Status: open
Blocked by: 104

## 来源

issue 100 定案后的 Round 5 追问（2026-09-14，用户拍板 **Q13=A**）；连带修订 [ADR-0009](../../../docs/adr/0009-SP绿条与段曲线模型.md) §2.2 / §5。

## 症状

ADR-0009 §2.2 允许「画笔方向锁定后中途折返 → 采样序列拍位回折」，并据此在 §5 做了回折自叠渲染（`splitBandAtFolds`）。但 **Bestdori 会忽略掉这些不单调的中间结点**，以「起点 → 单调的中间结点 → 终点」重建一条合法 Slide —— 即：我们编辑器里画出的这个折返**在实机根本不存在**。用例照着编辑器做，实机拿到的是一条被削平/少点的滑条。

数据佐证：仓内 11 份样本（社区 3 + 官方 8，合计 ≈**1943** 条 Slide/Long）**非单调点序 0 例**；`150030` 的 232 条滑条全部单调，折返纯粹来自负 BPM。

## 根因

ADR-0009 §2.2 的实测只验证了「Bestdori 能导入这类代码」，未验证「Bestdori 会把这个折返渲染出来」——把一个**导入容错**误当成了**渲染能力**。

## 修法

1. **画笔方向锁定后回头 → 只停止追加，不产生 beat 倒退**（`src/chart/editing/SpanCurve.ts` `penAppendSamples` / `FinalVirtualCanvas.tsx` L655-680 画笔分支）。
2. **折返一律由倒流区产生**（[ADR-0010](../../../docs/adr/0010-负数BPM与倒流区.md)）：画笔保持单调绘制；要折返就走修法 5 的「**先画后折**」（先画平铺滑条，再插一对 BPM 事件把它折回去）——这正是社区"负 BPM 画爱心"的做法。
3. **曲线工具的两击直放预览必须实时按折返几何显示**（跨区段烘焙点显示折返，不得用单调布局预览、落子才跳）——见 [issue 104](./104-倒流区时间轴与几何.md) 修法 9。画笔不再有"带内预览"（见修法 6）。
4. **ADR-0009 修订**：§2.2 删去「段内中间点 beat 可倒退」作为合法形状来源的表述；§5「回折自叠」保留但**依据改写**为「倒流区造成的布局折返（点序单调、布局 y 非单调）」，并顺带处理 §5 末句「叠亮口径未经用户确认」。
5. **折返的产图通道**（Q18.1 + 2026-09-15 收敛）：
   - **主通道 = 先画后折**：在**没有**倒流区时先画一条跨过目标拍的**普通**滑条（画笔正常等步长采样、beat 单调），**然后**插一对 BPM 事件（中间那条为负、末条必须为正）→ 已画的点被折回去，回头弯出现。**画笔不需要任何新规则**；这也是"倒流区生效那一刻区内音符反转"的同一件事。
   - **补充通道 = 跨区段 + 烘焙/模板**（倒流区**已存在**时往区里补点/改点）：一条跨过倒流区的段，其烘焙点（缓动或模板）按拍细分后天然呈现「正向 → 折返 → 正向」，beat 严格单调、实机保真。据此：烘焙/模板采样点**允许落在倒流区内**（beat 单调，天然满足，只需不被校验拦掉）；段的**跨度允许跨倒流区**（`bakeEasingPoints` 本就只要求 `toBeat > fromBeat`）。
   - **"一键画心形"的落点** = `ShapeTemplates` 的「爱心」预设套在跨区段上（模板天然跨折返——模板点按拍映射，折返由时间轴产生）。**我们比 Bestdori 方便的地方在这里，不在画笔**（Bestdori 没有形状模板，画心形得靠多段拼 + 手改代码）。
6. **画笔跨层 = 直接接续，不补点**（Q18.2 / Q19 / Q21 收敛，2026-09-15；用户实测：Bestdori 可正常跨层绘制）：跨层那一帧光标拍号会跳 2~4 拍，但这**两个拍在画布上几乎落在同一个 y**（同一个纵向位置的多解）——**几何本来就是连续的**，所以既不需要"终止笔画"（那才会真的断开），也不需要任何"选层"。
   - **错的处置 = 按 `n = |Δbeat| / step` 补中间点**（`SpanCurve.penAppendSamples` L326-331；其前提是"两帧之间光标只挪了一点点"，跨层那一步违反前提）：会补出 48 个（精度 1/64 时近 200 个）**手没画过**的点，它们在画布上是一段"上到带顶再回带底"的**尖峰**（beat 3.5→5 向上、5→6.5 向下）。
   - **对的处置 = 跳变步只把当前光标接为下一个采样点、跳过补点**（并保证新点 beat **严格大于**上一个采样点，抖动去重）。采样序列 `3.49 → 6.5` 仍然 beat 单调 ✓（手向上 = L1→L3 = +3 拍；手向下 = L3→L1 = −3 拍，都顺着手的方向），两端画布位置几乎重合 → **所见即所得，与 Bestdori 一致**。几何示例（三事件最小谱 + 三层解）见 [ADR-0010 附录 B](../../../docs/adr/0010-负数BPM与倒流区.md)。
   - 「是不是跨层」的**判据**留实现票定：**不能纯用 `|Δbeat|` 阈值**——快速甩笔同样会造成大 Δbeat，而那种情况下的插值补点是**合法且必要**的；应结合"上一帧所在段/层"判断。
   - **不做**「跟手方向」的层面选择机制——它服务的是"往折返带里手绘折返"，而折返靠「先画后折」（见修法 5），本就不需要。

## 锁测

- 单测：画笔折返时采样序列**不再**出现 beat 倒退（回头只停止追加）。
- 单测：`slideBandGeometry.splitBandAtFolds` 在「点序单调 + 布局 y 折返」输入下拆分仍正确（沿用 ADR-0009 §5 验收口径）。
- 单测：**跨倒流区的段烘焙**——采样点落点位于倒流区内、beat 严格单调、`previewSpanConnections` 与落子结果逐点一致。
- 单测：**光标拍号跳变时不补点**——跨层前后 `pen.samples` 不出现"一帧追加多点"。
- 单测（**先画后折主通道**）：画一条跨过目标拍的普通滑条 → 再插一对 BPM 事件（中间为负）→ **点的 beat 序列逐元素不变**，只有布局 y 折返（折返由时间轴产生，与点序无关）。
- **Playwright 像素实测**：倒流区**已存在**时，画笔在折返带里的落子位置 = 手绘位置（逐顶点一致），且带体**不出现回头弯**（区外两层 y 随拍单调）。
- 手工验收：正 BPM 下画笔回头不再产出折返形状。
