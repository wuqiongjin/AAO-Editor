## Question

基本编辑操作的范围与 UX 到底怎么定，才能让"基本功能"可用？基于 01 盘点的现状（复制/剪切/删除可、粘贴只追加、镜像空桩、无快捷键、无区域选择），逐项锁定 MVP 行为：
1. 粘贴语义：粘贴到鼠标光标位置（需要"粘贴入点"概念）还是维持追加？
2. 镜像语义：按什么轴镜像（左右 lane 镜像？）选中区域如何定义？
3. 区域选择是否纳入 MVP（TODO 提到"区域选择是复制/剪切/删除/镜像可用性的前提"）。
4. 键盘快捷键：需要绑定哪些（Ctrl+C/X/V/Z/Y、Delete、全选、镜像）？
5. 撤销/重做对滑条、方向键形态的覆盖范围。

产出：一份可执行的"基本编辑操作 MVP 规格"决策。

## Answer（结论）

经 /grilling 多轮与用户对齐，MVP 规格已锁定（2026-08-08）：

**多选与选区**
- 选择工具下随时拖拽圈选（矩形，画布坐标）；点击单选；Shift/点击加选。
- Ctrl+A 全选（仅画布内音符）；选区状态同步右侧 NoteInfoPanel。
- 组合状态开关仅保留"将选中音符连接成滑条"语义，不再控制圈选（Q6=A）。

**编辑操作**
- 复制/剪切/删除：作用于选中音符；删除后清空选区。
- 粘贴：粘贴到鼠标所在 beat/lane 为锚点，保持剪贴板内音符相对位移；粘贴后新音符成为选中项；鼠标不在画布时粘贴禁用（Q1=A）。
- 镜像：左右 lane 镜像（lane → 总道数-1-lane，beat 不变，以画布中线为轴），方向键 L↔R 翻转，滑条起/终点 lane 与端点方向同步，BPM 线不参与；作为一次编辑操作写入历史（Q2）。

**快捷键（画布内）**
- Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+Z / Ctrl+Y / Delete / Backspace / Ctrl+A / Ctrl+M(镜像)。
- 上下文分发：焦点在输入元素/代码编辑器时放行原生行为，不触发画布操作（Q4；Ctrl+A 作用域仅限画布）。

**撤销/重做**
- 统一历史快照：音符增删/位置、方向键组合形态、滑条端点变化全部入历史，Ctrl+Z/Y 全覆盖（Q5=A）。
