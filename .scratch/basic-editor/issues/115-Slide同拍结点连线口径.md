# 115 · Slide 带体「同拍结点」连线口径（与 Bestdori 的阶梯/锯齿差异）

## 来源

社区谱 150030 那条 284 点滑条（beat 2→18，仅首尾两个可见结点）在两处与本编辑器形状不同：
beat 10-11、beat 16-18（beat 8-10 同族）。

## 症状

带体是**逐相邻对铺带**：同拍组（`beat` 全等的一串结点 = 同一时刻占多条轨）之间的段 Δbeat = 0 →
面积退化、不画，它只是"拍线上的瞬时横跳"。于是**组内走序**直接决定带体形状：

- 横移压在拍边界 → 段内恒在同一轨（**竖条 / 阶梯**）；
- 横移发生在段内 → **斜穿**（锯齿 / 上斜坡）。

同一种"两轨来回"的数据，两种走序画出两种形状；本谱上两种都出现过（beat 8-10 是上斜坡、
beat 16-18 是竖条交替），所以**不可能有一条通用的"重建走序"规则**。

## 根因（实机口径）

实机 `repair()`（vendored `docs/plans/external/sonolus-bandori-engine/lib/src/bestdori/convert.ts`
L315-356）只做两步：

1. `connections.sort((a, b) => a.beat - b.beat)`（**稳定**排序）；
2. 掐掉首尾 hidden（可见 0 → 删对象；可见 1 → 降级为 Single）。

**没有任何同拍组重排**；稳定排序在同拍内不换位 ⇒ **同拍组的数组序 = 作者点序 = 带体走序**。
走序是数据本身的一部分，**不可从代码重建**。

## 取证（真实模块 `displayConnections`：投影 `identity=true`、零换位）

| 段 | 投影后的可见腿 | 与 Bestdori 对照 |

| beat 8→10.5 | 每步 `(b,4) → (b+0.125,6)`（Δlane +2）；同拍跳 `6→4` 零高度不画 | **上斜坡** = Bestdori 的斜杠 ✓ |
| beat 16→18 | `(b,3)→(b+0.25,3)` 与 `(b,5)→(b+0.25,5)` 交替；同拍跳在拍线上不可见 | **两列竖条交替** = 与 Bestdori 截图逐像素量得的 `[2.49..3.48]` / `[4.50..5.44]` 两列、每根 0.25 拍吻合 ✓ |
| beat 10→11.6 | 走序 = 数组序（含 `(10.375,6)→(10.375,1)` 的零高横跳） | 与原谱一致 ✓ |

## 定案（用户 2026-09-18 拍板）

- **显示投影 = 两步**：按 beat **稳定排序** + 掐首尾 hidden（= 实机 `repair()`）。
  **同拍组一律原样保持数组序**，不做任何重建。
- 数据侧一字不动：代码弹窗 / 导出 / 段与参数 / 拖带 / 删结点 / `planDragMove` 仍按数组序。
- 取样自检（通用）：一份谱的**所有**多点同拍组若都是 lane 升序，说明它不是接口原样（被规范化过），
  不可作取证基准。
