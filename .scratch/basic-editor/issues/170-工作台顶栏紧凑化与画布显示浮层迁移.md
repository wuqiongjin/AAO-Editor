# 170 · 工作台顶栏紧凑化与画布显示浮层迁移

Type: feature
Status: open
Blocked by: —

**来源**：用户 2026-10-14 反馈 #2 —— 设置页中的“画布显示”更适合放到“谱面画布”（工作台）中，方便编辑时直观调节与即时所见即所得。针对工作台顶栏中间空间有限（长歌名 + 左右侧栏均展开时仅 ~600px）的问题，确定将入口精简为单图标，并对顶栏右簇进行紧凑化瘦身。

## 定案（用户 2026-10-14 拍板）

1. **入口形态**：工作台顶栏右侧新增单图标按钮 `[ ⊶ ]`（使用 `SlidersHorizontal`，尺寸 26×26px，带 Tooltip “画布显示设置”），不放置“画布显示”等完整文字或下拉箭头，避免侵占水平空间。
2. **浮层面板**：点击弹出半透明浮层面板（复用类似 `PreviewDisplayPanel` 的交互样式与 `settings.display` 写回逻辑），包含节奏图示大小、长压线不透明度、同时点击线、色觉辅助、纵向比例、图像品质、轨道样式、线形分层、轨道线透明度、文字大小等画布呈现项，并提供“恢复出厂默认”。
3. **顶栏右簇紧凑化瘦身**：
   - **缩放组件**：将原分散的 `[-]` 按钮 + `100%` 文本 + `[+]` 按钮整合为 24px 高度的一体化微型胶囊 `[ – | 100% | + ]`，宽度由 92px 压缩至约 68px；双击居中 100% 与滚轮缩放能力完整保留。
   - **BPM 读数**：调整为紧凑的 Meta 标签展示（`BPM 152`，高度 24px 对齐），宽度压缩至约 45px。
   - **整体宽度收益**：改造后右簇（BPM + 缩放胶囊 + 画布显示图标）总宽度控制在 ~145px，比现状（~160px）更省空间，给左侧工程歌曲名留出更多展现余量。

## 锁测

1. 工作台顶栏渲染：验证 BPM、缩放微型胶囊及 `SlidersHorizontal` 触发按钮均正常渲染且高度对齐。
2. 浮层展开与写回：点击触发按钮弹出设置面板，修改参数即时触发 `setDisplay` 并在画布渲染中生效。
3. 交互行为保持：缩放增减、双击 100%、外部点击收起浮层等行为单测覆盖。
