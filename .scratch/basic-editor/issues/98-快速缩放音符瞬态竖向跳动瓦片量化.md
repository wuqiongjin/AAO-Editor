# 98 · 快速缩放时音符相对网格瞬态竖向跳动（三个独立分量，均已修复）

Type: bug
Status: resolved（2026-09-12 三分量全部修复 + 看守测试 + 像素实测，用户页面验收通过）
Blocked by:

## 来源/症状

用户 2026-09-12 复报（issue 90 修复后残余）：快速缩放时谱面音符轻微上下回弹，不易察觉、偶尔可观测，与光标/缩放位置无关。二轮验收补充症状：缩放时**左下角时间读数与弹跳同步闪烁**；**纯缩放（不碰进度条）会意外拨动进度条**。

## 根因：三个独立、可叠加的分量（同量级，各 ≤±1px；单修其一症状只减半）

| # | 分量 | 机制 | 修法 |
| --- | --- | --- | --- |
| ① | 瓦片位图量化 | `renderTile` 位图高 `bh = round(TILE_PX·es·tileDpr)` 为整数、内容按恒 `tileDpr` 绘制、blit 目标高 `TILE_PX·es` 为浮点 → 内容被「距瓦片顶边线性增长」的非均匀压缩（≤±0.5/tileDpr px），每个 es 重掷 | 内部 transform 改按位图实际尺寸/css 尺寸（`bw/cssW, bh/cssH`），内容恰填满整数位图；blit/接缝数学不动 |
| ② | 精灵整像素对齐 | `CanvasSpriteIcon.drawSingle` 的 `dx/dy = Math.round(canvas ± dW/2)`（画布框架初版遗留）→ 音符锚点为浮点且随 es 连续变化，取整逐帧重掷 ±0.5px | 去掉取整，绘制位置走浮点（亚像素 AA；静止帧渲染恒定不闪烁；经验收不可辨） |
| ③ | 滚动条自回声反算 | 程序化 scrollTop 回写（缩放的比例位保持）被浏览器按设备像素取整，回声 scroll 事件把取整值按比例反算回 scrollY → 缩放期 scrollY 每档重掷 ±0.5 virtual px，破坏 issue 90「缩放期 scrollY 恒定」不变量 → 判定线秒数跳变（时间读数闪烁）+ 进度条比例位微动 | 程序化写入登记期望值（`programmaticScrollTopRef`）；回声事件（\|st − 期望\| ≤ 1px）经 `isProgrammaticScrollEcho` 吞掉；真实用户滚动照常处理 |

> 定位经验：分量 ③ 最初由用户观察「时间读数与弹跳同步闪烁」锁定——左下角时间 = f(scrollY)，渲染层分量（①②）不可能影响它。此类「哪个量在跳」的联动观察是区分分量的最快途径。另：逐帧像素指标必须区分族（渲染残差用「音符−基准线」差分；scroll 残差只看 scrollY 自身序列），差分指标对共模位移天然盲。

## 锁测

1. 分量 ①：`RendererPerf.test.ts`「issue 98」用例（stub ctx 记录 `setTransform`，es=0.8：css 高 409.6 / 位图 410，修复前红）+ dpr=1.5 非整宽用例锁 X 轴。
2. 分量 ②③：`ScrollbarEchoSuppression.test.ts` —— `isProgrammaticScrollEcho` 行为用例（容差内吞掉 / 超容差与 null 照常处理）+ 静态断言（回声检查先于 scrollHeight 反算；两处程序化写入都登记期望值；`CanvasSpriteIcon` 无 `Math.round` 复活）。
3. 像素实测（脚本不入库）：`measure-note-bounce.mjs`（稳态 A/B：偶数拍 BPM 线 = 零量化基准，rel 残差判定阈 = max(0.25, 线自检噪声+0.1)）→ PASS；`watch-scroll-family.mjs`（缩放爆发期 scrollY 违例监视，阈值 0.02 virtual px，排除脚本自设滚动）→ 0 次。单分量二分对照：`git checkout HEAD~1 -- <对应文件>`。

## 验收口径（页面）

快速缩放时：① 音符与拍线/BPM 线无相对窜动；② 左下角时间读数完全静止；③ 进度条滑条位置不被缩放拨动（滑条尺寸随内容长度变化属设计内）。静止观感：分量 ② 修复后的亚像素软化经 A/B 对比（public/ab/index.html，临时产物不入库）不可辨。
