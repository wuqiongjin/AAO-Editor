# 105 · 倒流区渲染与视觉

Type: feature
Status: resolved（2026-09-17 实现 + 锁测，tsc 0 / 1185 测全绿 + 页面手工验收通过）
Blocked by: 104

## 来源

[issue 100 负数 BPM 语义](./100-负数BPM语义.md) 定案（2026-09-14），权威 = [ADR-0010](../../../docs/adr/0010-负数BPM与倒流区.md) 结论 11。

## 症状

含倒流区的谱面在画布上会出现"同一纵向区间被走过多次"的折返：滑条带与网格线自叠、BPM 线逆序排列。用户在编辑器里看到折返时无法判断这是**正确保真**还是渲染 bug；负值 BPM 的数值标签目前与正值同色（`render.ts` L1214-1227 直接 `String(note.bpm)`），看不出区间性质。

## 根因

渲染层从未面对非单调布局；折返自叠的健壮性此前只在 ADR-0009 §5「回折自叠」做过（`splitBandAtFolds`），而其**触发条件**已由 §2.2 修订后的「**布局折返**（点序单调、布局 y 非单调）」给出。

## 修法

1. **负值 BPM 的数值换一种颜色**（`renderBpmLabels` / `gutterLabels.ts` 的标注文字色）：这是「倒流区」唯一的视觉标识，**不做**区域底纹。
2. **网格线 / 子节拍线 / BPM 线 / START·END 线**按各自布局坐标绘制，**允许折返重叠**；确认 `render.ts` L159-168 的按 beat 枚举不隐含单调假定（每个拍点独立求 y）。
3. **折返自叠的绘制健壮性**沿用 ADR-0009 §5（触发条件 =「布局折返」）：滑条带在时间轴折返处的自叠按既有 `splitBandAtFolds` 口径处理。
4. 段内可击打元素（实机必 MISS）**不加拦截、不加额外警示**——负值换色已足够溯源（用户口径）。

## 锁测

- 单测：`gutterLabels` / BPM 数值标签取色（负值分支）。
- **Playwright 像素实测**：用 [ADR-0010 附录 A](../../../docs/adr/0010-负数BPM与倒流区.md) 的 BPM 事件编码 + 附录 B 的最小谱构造折返场景，截图比对（滑条带折返形状、BPM 数值换色）；折返自叠处无黑线洞/无贴图拼接缝（与 ADR-0009 §5「回折自叠」同一验收口径）。谱面文件不入库。
- 手工验收：网格线折返重叠符合预期、不误判为渲染故障。

2. **换色作用域 = 只作用于数值文字**（票面修法 1 字面口径）：BPM 横线仍走 `gridThemeBpmColor`。
3. **锁测方式照 issue 104 先例**：票面「Playwright 像素实测」三条转为**手工验收清单**（见下），本轮只交单测 + 静态断言，不引入 Playwright 依赖。

**实现口径**

- `gridStyle.ts`：新增 `GRID_BPM_NEGATIVE_COLORS`（四主题各一色）+ `gridBpmNegativeColor(preset)`（负值分支的唯一实现）。**不塞进 `GridStyleDef`**——那是 `Record<GridTier, GridTierStyle>`，加字段会污染按层级枚举的绘制路径。
- `render.ts renderBpmLabels`：`bpm < 0` 取倒流色、否则取主题主色；文字仍是 `String(bpm)`（**负号原样保留**，不取绝对值）。动机直白：折返带上正/负事件在画布上常**同位**（同一 y 逆序排列），数值色是区分两者的唯一线索。
- **修法 2 核对为「无需改码」**（已由 104 落地）：`renderGrid` 走 `visibleBeatRanges`（布局坐标正向派生的**多段**拍区间），每个候选拍点独立 `c.beatToVirtualY(beat)` 求 y，没有任何"pos 随 beat 递增"假设；`renderBpmLines` / `renderBpmLabels` / `renderBoundLines`（START·END）各自按元素自己的 beat 求 y。本票补断言锁住。
- **修法 3 核对为「无需改码」**：`renderSpBandStrip` 已按 ADR-0009 §5 用 `splitBandAtFolds`（触发条件 =「布局折返」）切 y 单调 run + `rasterBandRuns` 逐行光栅——像素内 screen 合成 = 叠亮，非零填充**不会相消成洞**。
- **修法 4 无工作项**：段内可击打元素不加拦截、不加额外警示（用户口径）。

**锁测落点**

- `tests/unit/GridStyle.test.ts`：**新增 1 组 3 例**，覆盖四条断言——四主题负值色存在且 ≠ 同主题正值（beat 层）色；黑底 luma ≥ 170；四主题取值互异；不侵占 START/END/选中/危险四色。
- **新增 `tests/unit/BackflowRender.test.ts`（11 例）**：

  - **修法 2（行为，3 例）**：折返带内三个整拍线（beat 5 顶 / 6 回程 / 7 再向上）**三条都画出来**（旧实现按 beat 窗口反推只会剩最后一层），`yOf(6) > yOf(7)` 明确锁住"拍序 6→7 而画布 y 变小"；**子节拍线**同样逐点独立求 y（回程层的 5.25 落在顶层与 beat6 之间）；**START·END** 按各自布局坐标画（END 落在折返带顶、与 beat5 同位 = 折返重叠是保真）。

**手工验收清单（替代 Playwright 像素实测；请你在页面验收）**
