# 105 · 倒流区渲染与视觉

Type: feature
Status: open
Blocked by: 104

## 来源

[issue 100 负数 BPM 语义](./100-负数BPM语义.md) 定案（2026-09-14），权威 = [ADR-0010](../../../docs/adr/0010-负数BPM与倒流区.md) 结论 11。

## 症状

含倒流区的谱面在画布上会出现"同一纵向区间被走过多次"的折返：滑条带与网格线自叠、BPM 线逆序排列。用户在编辑器里看到折返时无法判断这是**正确保真**还是渲染 bug；负值 BPM 的数值标签目前与正值同色（`render.ts` L1214-1227 直接 `String(note.bpm)`），看不出区间性质。

## 根因

渲染层从未面对非单调布局；折返自叠的健壮性此前只在 ADR-0009 §5「回折自叠」做过（`splitBandAtFolds`），而其**触发条件**已由 §2.2 修订后的「**布局折返**（点序单调、布局 y 非单调）」给出。

## 修法

1. **负值 BPM 的数值换一种颜色**（`renderBpmLabels` / `gutterLabels.ts` 的标注文字色）：这是「倒流区」唯一的视觉标识，**不做**区域底纹。
2. **网格线 / 子节拍线 / BPM 线 / START·END 线**按各自布局坐标绘制，**允许折返重叠**；确认 `render.ts` L159-168 的按 beat 枚举不隐含单调假定（每个拍点独立求 y）。
3. **折返自叠的绘制健壮性**沿用 ADR-0009 §5（触发条件 =「布局折返」）：滑条带在时间轴折返处的自叠按既有 `splitBandAtFolds` 口径处理。
4. 段内可击打元素（实机必 MISS）**不加拦截、不加额外警示**——负值换色已足够溯源（用户口径）。

## 锁测

- 单测：`gutterLabels` / BPM 数值标签取色（负值分支）。
- **Playwright 像素实测**：用 [ADR-0010 附录 A](../../../docs/adr/0010-负数BPM与倒流区.md) 的 BPM 事件编码 + 附录 B 的最小谱构造折返场景，截图比对（滑条带折返形状、BPM 数值换色）；折返自叠处无黑线洞/无贴图拼接缝（与 ADR-0009 §5「回折自叠」同一验收口径）。谱面文件不入库。
- 手工验收：网格线折返重叠符合预期、不误判为渲染故障。
