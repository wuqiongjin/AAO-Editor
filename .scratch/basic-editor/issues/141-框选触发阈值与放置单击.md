# 141 · 框选触发阈值：4px 太灵敏，吃掉「放置音符」那一击

Type: grilling（要拍板阈值口径；拍板结论追加进本票，不另开）
Status: resolved（2026-09-21 实现 + 锁测，待你在页面验收手感）
Blocked by: —

## 来源

用户 2026-09-21：「框选触发的范围，鼠标按下后移动多少距离触发框选？当前感觉框选触发的非常容易，这导致有时候放置音符时，鼠标不小心略微移动了一下，就无法放置了（因为触发了框选）。」

## 现状（代码实测，非推测）

- 阈值常量：`src/chart/editing/GestureSession.ts:46` `DRAG_THRESHOLD_PX = 4`。
- 判定：`hasMovedBeyondThreshold`（`src/chart/editing/CanvasGesture.ts:524-530`）= `|dx| >= 4 || |dy| >= 4` —— **单轴 4px 即触发**，不是欧氏距离，对角起手更松。
- 持工具态（键型 / Slide / BPM / 删除 / 镜像）在空白处按下 → `resolvePressIntent` 一律返回 `marquee`（`CanvasGesture.ts:174`，防误拖）；松手时 `resolveReleaseIntent` 见 `moved === true` → `commitBox`（`:226-231`）。
- 于是：按下后手抖 ≥4px → 走框选 → 框内没音符时只是清选区、**本次放置彻底丢失**；框内有音符时更糟，变成「批量换型」（issue 88 的框选行，会改到别的音符）。
- 反讽点：单击的落点取的是**按下点** `start.vx/vy`（`GestureSession.ts:307`），本意是宽容「移一点再松手」，结果被阈值先判成框选，宽容没生效。

## 待拍板

- **Q1（主）** 选哪条：
  - A 抬高统一阈值（4 → 8 或 10px）—— 最省事，代价是**拖拽移动也变迟钝**（拖音符要跟手）。
  - B **分意图阈值**：拖拽移动仍 4px（跟手），**框选 8~10px**（防误触）—— 手感最合理，代价是阈值从一个变两个。
  - C 阈值不动，加**兜底**：越过阈值、但松手时框内没命中任何音符 → 回落成单击（按按下点放置）。
  - D B + C 一起。
- **Q2** 阈值要不要做成设置项（设置页 · 编辑/画布）？还是硬编码常量？
- **Q3** 曲线工具态的**画笔**（按下即起笔）与 **Shift+拖**（强制框选）是否跟同一阈值？画笔现在是无视阈值起手的（`PEN_HOLD_MS` 另算），别顺手改坏。

## 定案（用户 2026-09-21）

**Q1 = B 分意图阈值**：拖拽移动仍 **4px**（跟手），**框选 8px**（防误触）。
范围选项里取 **8px**（偏小那一档，够挡手抖又不让框选迟钝；若验收仍嫌灵敏再提到 10）。

- **Q2 = 硬编码常量**（默认）：不进设置页，做成 `GestureSession` 顶部两个具名常量。
- **Q3 = 画笔不受影响**：曲线工具态起笔保持 4px（起笔灵敏度是画笔手感的一部分）；Shift+拖 = 框选 → 走 8px；Shift+按住音符 = 移动 → 4px。

## 实现落点（定案后填实）

| 文件 | 改动 |
| --- | --- |
| `src/chart/editing/GestureSession.ts` | `DRAG_THRESHOLD_PX = 4` 保留；新增 `MARQUEE_THRESHOLD_PX = 8`；`move()` 的阈值按意图取：`this.drag \|\| this.pen ? 4 : 8`（**须确认 pen 起手即刻置位**，否则画笔会被误当框选） |
| `src/chart/editing/CanvasGesture.ts` | `hasMovedBeyondThreshold` 不动（纯函数、已单测），只由调用方传不同阈值 |
| 文档 | ADR-0008 §2 原则 1 的「阈值沿用 4px」补注：框选 8px |

## 锁测（定案后按 Q1 结论填实）

- `tests/unit/chart/editing/GestureSession.test.ts`「4px 阈值（不变量 6）」那一组：**拆成两组** —— 拖拽（4px，断言不变）与框选（8px，新增）；
  新增：持键型工具、位移 5px 松手 → 仍走 `click`（落点 = 按下点，**这就是用户报的那一下**）；位移 8px → `commitBox`。
- `tests/unit/chart/editing/CanvasGesture.test.ts`：`hasMovedBeyondThreshold` 的 `threshold-1` / `threshold` 边界（8px 那档补一条）。
- 单测锁不住「手感」→ 页面验收清单：持单键工具连续放 20 个音符，允许手抖，不得出现「放不出音符」或「误批量换型」。
