# 236 · 拖动滑条结点直接拉伸曲线（不受缓动函数/形状模板重烘焙）

Blocked by: —

## 来源

用户需求：谱面画布增加配置项（默认关闭），在拖动滑条端点/可见结点时不受缓动函数（或形状模板）重新生成的影响，改为在既有采样曲线基础上直接按起终点拉伸，并与用户经 `grill-me`（Q1–Q6）对齐确认后落地。

## 需求定案（Q1–Q6）

- **Q1（适用曲线类型）= A**：同时涵盖 `easing` 缓动函数段与 `template` 形状模板段——开启后均不再按参数重烘焙，而是走与自由段同款的起终点仿射映射。
- **Q2（触发交互与结点范围）= A**：覆盖所有可见结点的拖动——两端端点与中间可见结点均适用；拖段本身捏形等既有路径不变。
- **Q3（拖拽后 `spanParams` 处理）= A**：一动就自由化——仅清除受此次拖动影响的相邻段参数（`spanParams`），同条上未受波及的其它段参数保留。
- **Q4（配置归属与默认态）= A**：归入 `settings.display.stretchCurveOnNodeDrag`（默认 `false`），不升 settings 版本号，通过显示设置浮层「操作偏好」组开关控制并跨会话持久化。
- **Q5（整条刚体平移边界）= A**：组选 / 整条滑条刚体平移不拉伸、也不自由化，继续保持既有几何与 `spanParams`。
- **Q6（UI 文案）**：名称 `拖动滑条结点直接拉伸曲线`，hint `开启后，拖动滑条中的可见结点时（含端点），不再按缓动函数或形状模板重新生成曲线。`

## 实现与顺带修复

1. **配置与持久化**：`src/settings/AppSettings.ts`（`display.stretchCurveOnNodeDrag: boolean`，默认 `false` 与布尔归一化）；`src/i18n/messages/zh-CN.json`、`en.json` 补齐词条与 hint。
2. **显示浮层入口**：`src/pages/workspace/WorkspaceDisplayPanel.tsx` 在「操作偏好」组新增开关与 `<HelpHint placement="up" />`。
3. **拖拽规划贯通**：`src/chart/editing/NoteDragging.ts`（`planDragMove`）、`src/chart/editing/GestureSession.ts`、`src/chart/components/canvas/FinalVirtualCanvas.tsx` 透传 `stretchCurveOnNodeDrag`，开启时跳过缓动/模板重烘焙，按自由段仿射重映射既有采样点并清除受波及段的 `spanParams`。
4. **文档同步**：更新 `docs/adr/0009-SP绿条与段曲线模型.md` §4。
5. **验收反馈顺带修复（`HelpHint` 气泡被窄面板裁剪）**：长文案「拖动滑条结点直接拉伸曲线」把 `?` 推至 `.wdp__panel`（`width: 320px; overflow-y: auto; overflow-x: hidden;`）偏右，内联 `.dialog-field__popover` 右侧被截断。将 `src/ui/HelpHint.tsx` 改用 `createPortal(..., document.body)` + `position: fixed` 动态夹紧视口与箭头对齐（`src/ui/ui.css` 增加 `.is-portaled` 与 `--help-hint-arrow-left` 变量、`z-index: 10010`），移除 `src/pages/workspace/WorkspaceDisplayPanel.css` 失效窄宽补丁。
