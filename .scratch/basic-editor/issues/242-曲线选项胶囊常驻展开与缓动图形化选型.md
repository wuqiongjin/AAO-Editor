## 来源

用户提出优化**曲线选项胶囊**使用体验的三项核心诉求，经 `/grill-with-docs` 两轮访谈（Q1–Q8）于 2026-11-21 全部拍板定案，frontier 为空：
1. 曲线选项胶囊展开后点击外部不再自动收缩，且记忆折叠/展开状态；
2. 缓动函数页中「缓动族」「缓动型」的两个原生 `<select>` 下拉框使用体验差，需要升级；
3. 形状模板页中无法记忆上次选择的分类（`全部 / 平滑弧弯 / 节奏·震动 / 面筋·锁链`）。

---

## 现状与根因

1. **曲线选项胶囊共用临时弹层 Hook（`src/pages/workspace/CurveOptionsCapsule.tsx`、`useCanvasCapsule.ts`）**：
   - `CurveOptionsCapsule` 与 `PatternPastePill`（片段粘贴胶囊）共用 `useCanvasCapsule`：`open` 为局部非持久化状态，点外部 `mousedown` 自动收回、按 `Escape` 拦截收回、切走工具（`visible = false`）强制重置为折叠。
2. **缓动函数页仍为旧版原生下拉框（`src/pages/workspace/CurveConfigPanel.tsx`）**：
   - 形状模板页已于 issue 235 升级为图形化 SVG 卡片网格 + 胶囊按钮，而缓动函数页仍保留「左侧单张 `MiniEasingSvg` 预览 + 右侧 2 个原生 `<select>`（10 族 × 4 型）」，视觉割裂、切换需两步且无横向对比。
3. **模板分类与上次模板 ID 仅为组件局部状态（`src/pages/workspace/CurveConfigPanel.tsx`）**：
   - `catFilter` 为组件内 `useState('all')`、`lastTemplateIdRef` 为组件内 `useRef('s-curve')`；胶囊收起或切走工具导致组件卸载后二者同步丢失。

---

## 定案（Q1–Q8 全量汇总，用户 2026-11-21 拍板）

1. **Q1（影响范围与持久化层级）= A + 1**：
   - **仅改曲线选项胶囊**：**片段粘贴胶囊**（`PatternPastePill`）继续保持临时弹层（点外部 / `Esc` / 选完即收起，切走工具重置），与曲线选项胶囊正式分道。
   - **跨工具切换 + 跨会话持久化**：曲线选项胶囊不再因点击外部自动折叠，仅由点击胶囊顶栏切换展开/折叠；切走曲线工具或退回指针态时整枚胶囊整体隐藏消失，但展开/折叠偏好持久化于设置对象（出厂默认折叠 `false`，additive 不升 `schemaVersion`），下次切回曲线工具或重启应用后自动恢复。
2. **Q2（展开态下按 `Esc` 的行为）= A**：
   - **`Esc` 不再折叠曲线选项胶囊**：展开态下不拦截 `Esc`，将其完整交还画布 Esc 五档链（取消进行中手势 → 清锚点 → 清选区 → 退回指针态并随工具退出隐藏整枚胶囊）；在曲线工具态下想只收起面板则点击胶囊顶栏。
3. **Q3（折叠/展开快捷键）= A**：
   - **不新增快捷键**（不注册 `FunctionId`，避免快捷键表膨胀与误触），仅靠点击胶囊顶栏开合。
4. **Q4 + Q6 + Q7（缓动函数页图形化选型、排布与文案）= A + 1+上 + C**：
   - 彻底移除原生 `<select>`（缓动族、缓动型）与旧的左侧单独大图预览框，与形状模板页视觉统一；
   - **自上而下排布**：
     1. 顶部模式切换：`缓动函数` | `形状模板`；
     2. **缓动型（上排）**：4 枚单行胶囊按钮，显示英文短名 `In` / `Out` / `In-Out` / `Out-In`（悬停 tooltip 显示完整双语如 `In-Out（缓入缓出）`）；切换时下方 10 张缓动族卡片的 SVG 曲线实时联动重绘；
     3. **缓动族（中部）**：**5 列 × 2 行** 10 张实时 `MiniEasingSvg` 缩略图卡片网格（铺满两行、无尾行空位、免滚动条）；英文界面显示英文名（`Sine`…），中文界面显示**两行双语**（主字英文 `Sine` + 副字中文 `正弦`，悬停 tooltip 显示完整 `Sine（正弦）`）；
     4. **精度（底部）**：保持 `1/16` / `1/32` / `1/64` 胶囊按钮行。
5. **Q5 + Q8（形状模板分类筛选与上次模板记忆）= A+是 + A**：
   - **分类筛选**（`all | smooth | rhythm | special`）与**上次选用的模板 ID**（供从缓动页切回模板页时恢复，而非退回默认 `s-curve`）一并跨会话持久化于 `settings.curve`（additive，不升 `schemaVersion`）；
   - **忠实恢复（Q8=A）**：重新打开模板页时忠实停留在上次点击的分类标签，即使当前生效模板不在该分类内也不自动切回或改写当前生效模板（顶部胶囊摘要与迷你图标始终标示当前生效模板）。

## 实现落点

1. **设置模型与归一化（`src/chart/editing/CurveTool.ts`、`src/settings/AppSettings.ts`、`src/app/providers/ConfigProvider.tsx`、`UIProvider.tsx`）**：
   - `CurveConfig` 增量追加可选持久化字段（不升 `schemaVersion`，`normalizeCurveConfig` 做白名单归一化）：
     - `templateCategory?: 'all' | TemplateCategory`（默认 `'all'`）
     - `lastTemplateId?: string`（有效内置模板 ID，缺省/无效回落 `'s-curve'`；选中任一模板时同步更新）
   - 曲线选项胶囊展开态偏好（如 `settings.layout.curveCapsuleOpen` 或 `settings.curve.panelOpen`，出厂默认 `false`，布尔归一化，跨会话持久化，走 `ConfigContext` / `UIContext` 单一真相，支持设置导入导出同步刷新）。
2. **胶囊开合与事件解耦（`src/pages/workspace/CurveOptionsCapsule.tsx`、`useCanvasCapsule.ts`）**：
   - `CurveOptionsCapsule` 不再绑定 `useCanvasCapsule` 的外部点击收回与 `Esc` 拦截，改为读写持久化的展开态布尔值 + 点击胶囊顶栏（`.ccap__pill`）切换；`armedTool !== 'curve'` 时直接不渲染，不覆写持久化展开态；
   - `useCanvasCapsule` 仍由 `PatternPastePill` 使用，行为保持不变。
3. **缓动函数图形化选型与模板记忆接入（`src/pages/workspace/CurveConfigPanel.tsx`、`CurveConfigPanel.css`、`curveLabels.ts`、`src/i18n/messages/zh-CN.json`、`en.json`）**：
   - 缓动页改为：上排 4 枚缓动型胶囊按钮（英文短名 + 完整双语 `title`）→ 中部 5 列 × 2 行 `MiniEasingSvg` 卡片网格（中文两行双语 / 英文单行，悬停 `title` 为完整双语，激活态配色与蓝色曲线呼应）→ 底部 `精度` 胶囊行；移除旧 `.ccp__easing-box` / `.ccp__select`；
   - 模板页分类筛选读写 `config.templateCategory`（忠实恢复），切换「缓动 ↔ 模板」恢复 `config.lastTemplateId`。
   - 注：若与 [241](./241-形状模板参数自由调节模式.md) 合并/先后落地，注意 `CurveConfigPanel.tsx` 中自由模式数值框的 `Esc` 处理（241 仅需阻止输入框草稿取消误触画布五档链，无需再防关闭胶囊）。

## 锁测清单

1. **配置归一化单测（`tests/unit/chart/editing/CurveTool.test.ts`、`AppSettings.test.ts`）**：
   - `normalizeCurveConfig` 保留合法 `templateCategory`（`all/smooth/rhythm/special`）与有效 `lastTemplateId`，非法/缺失值分别回落 `'all'` 与 `'s-curve'`；
   - 设置持久化加载与导入导出正确读写曲线胶囊展开态（默认 `false`，脏值回落 `false`）。
2. **曲线胶囊常驻展开与 Esc 不拦截 DOM 测试（`tests/dom/workspace/CurveOptionsCapsule.test.tsx`）**：
   - 首次进入曲线工具默认折叠；点击顶栏展开后写盘；
   - 展开状态下点击 `document.body` 不折叠；按 `Escape` 不折叠且不 `stopPropagation`（验证事件可冒泡到达外层监听器）；
   - 切走工具（`curve → single`）整枚胶囊隐藏，切回 `curve` 自动恢复展开态；重新挂载（模拟重启）仍按持久化展开态恢复；
   - 点击顶栏手动折叠后写盘，切工具再切回保持折叠；
   - **对照回归**：验证 `PatternPastePill` 仍维持点外部 / `Esc` / 选完即收起且切工具重置。
3. **缓动图形化选型与分类/上次模板记忆 DOM 测试（`tests/dom/workspace/CurveOptionsCapsule.test.tsx`）**：
   - 缓动页不再存在 `<select>`（`queryAllByRole('combobox')` 为空）；展示 4 枚缓动型按钮（`In/Out/In-Out/Out-In`）与 10 张带 `<svg>` 的缓动族卡片；
   - 切换缓动型时 10 张卡片的 SVG `path` 实时重绘并写盘；点选缓动族立即更新摘要与持久化；
   - 中文界面缓动族卡片同时渲染英文主名与中文副名，英文界面仅渲染英文名且无缺词回退；
   - 形状模板页选中「面筋/锁链」分类并选用「面筋·梳齿」后：折叠再展开、切工具再切回、或模拟重启均保留「面筋/锁链」分类；
   - 切到「缓动函数」后折叠/重启再切回「形状模板」自动恢复「面筋·梳齿」而非回退 `S 形`；
   - 当前生效为「大弧」（平滑弧弯）但上次停在「面筋/锁链」分类浏览后重开，仍忠实停留在「面筋/锁链」分类且生效模板仍为「大弧」。
