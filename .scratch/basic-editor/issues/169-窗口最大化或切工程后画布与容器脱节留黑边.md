# 169 · 窗口最大化或切工程后画布与容器脱节留黑边

Type: bug
Status: resolved（2026-10-13）
Blocked by:

## 来源

用户 2026-10-13 反馈：
> 每天我首次打开程序时(不是最大化打开)，后续过程中可能点了最大化，后面再打开工作台后，发现谱面画布距离四周边缘有很大间隙(这个间隙整好就是我最大化时所欠缺的，也就是我调整至非最大化时，整好可以填补这个间隙。)。

## 症状

窗口以非最大化启动，用户在后续最大化窗口或切换工程进入工作台后，谱面画布盒（CSS 尺寸 = `surf.w × surf.h`）被锁死在首次启动时的非最大化尺寸，居中显示在全屏容器中央，上下左右四周露出大面积空白黑边。当窗口手动还原为非最大化尺寸时，容器正好贴合旧画布。

## 根因

### ① `ChartCodeEditorProvider` 的 key 导致整个工作台 DOM 树重建，Observer 监听脱钩
- `WorkspacePage.tsx` 中 `<ChartCodeEditorProvider key={projectId ?? 'none'} ...>`。
- 应用启动默认落点在工程页，工作台在后台保活挂载（`projectId = null`，`key="none"`），容器节点 A 被 `useSurfaceSize` 挂上 `ResizeObserver` 并记录了启动时的非最大化尺寸。
- 用户选择工程进入工作台时，`projectId` 变为工程 ID，导致 `ChartCodeEditorProvider` 连同其内部整个工作台 DOM 树全部销毁重建，生成了新容器节点 B。
- `useSurfaceSize.ts` 内部 `useEffect` 依赖为 `[ref]`（React `useRef` 对象引用恒定），节点更替时不重新执行，`ResizeObserver` 依然绑定在已被销毁的节点 A 上，新节点 B 从未被监听。

### ② `useSurfaceSize` 缺乏后台页面激活与 `window.resize` 的兜底测量
- `useSurfaceSize` 仅在初次挂载时依赖 RO 回调，若页面处于后台失活状态（`active = false`，`opacity: 0`）时发生窗口变化，浏览器对不可见节点的 RO 事件可能被延迟/节流；切回工作台时（`active: false -> true`）未进行主动尺寸校准。
- `window.addEventListener('resize')` 仅用于跟踪 `devicePixelRatio`，未对容器实际尺寸进行兜底同步。

## 修法

1. **加固 `useSurfaceSize` 节点跟踪与激活/窗口同步**（`src/chart/layout/useSurfaceSize.ts`）：
   - 增加 `observedElRef` 动态侦测 `ref.current` 节点变更，当节点更替时自动解绑旧节点并重新绑定 `ResizeObserver`，主动测量最新尺寸；
   - 增加 `window.addEventListener('resize')`，在窗口尺寸改变时主动触发同步测量；
   - 增加 `active: false -> true`（后台切回前台激活）主动校准测量；
   - 引入 `isSyncMeasuringRef` 区分同步校准测量与 RO 异步回调，消除 React 19 在 effect 中调用 `flushSync` 的告警，同时保持 issue 87 要求同帧对齐的不变量。
2. **状态与属性透传**：
   - `src/playback/useChartViewSession.ts` 与 `src/pages/workspace/WorkspacePage.tsx`：扩充 `active` prop 透传至 `useSurfaceSize`；
   - `src/chart/components/code-editor/ChartCodeEditorProvider.tsx`：接收 `projectId` 并在工程切换时重置 `target` 与 `trail` 状态；`WorkspacePage.tsx` 保留 `key={projectId ?? 'none'}` 以满足 `tests/unit/project/workspaceProject.test.ts` 契约断言，由于 `useSurfaceSize` 具备了完整的节点更替重绑机制，即便外层 remount 亦能平稳追踪尺寸。

## 锁测

1. `tests/dom/workspace/SurfaceSizeTracking.test.tsx`（新增，4 项全部通过）：
   - `projectId` 变化时重置 `target`/`trail` 状态；
   - 当外部 remount / `ref.current` 变更时，`ResizeObserver` 自动重绑并同步测量；
   - 当 `window` 发生 resize 时，自动同步测量最新容器尺寸；
   - 当 `active` 从 false 变为 true 时，主动校准并测量最新尺寸。
2. 回归既有测试：
   - `tests/platform/browser/BrowserZoomLive.test.ts`
   - `tests/unit/chart/layout/SurfaceSizeMerger.test.ts`
   - `tests/static/ChartViewSessionWiring.test.ts`
   - `tests/unit/project/workspaceProject.test.ts`
   - 全量回归与构建：`npm run test`、`npm run build` 全部绿通。
