# 177 · 工作台侧栏重设计

Type: grilling
Status: resolved
Blocked by:

## 来源

用户 2026-10-25：工作台左右两栏"保守、传统、不高级"。

- 左栏被工具栏占满；「节拍吸附」是一只原生下拉框，只有 1/1–1/16 八档，不支持更细或自定义。
- 未来要加「片段收藏」（见 [164](./164-片段收藏.md)），需要一块浏览区。
- 右栏只显示音符信息，用户自己都不看；删除 / 镜像工具栏也能做；下半部分全空。

要求：大胆重设计成更现代、简洁的编辑界面，可删组件（理由合理即可），先做原型再改代码。

## 现状事实（grill 前查证）

- `beatDisplay` 是 `UIProvider` 里的 `useState(4)`：不持久化（每次回 1/4），无快捷键；画布网格支持任意整数细分，≥1/16 全落同一样式层。
- 右栏除音符信息外还承载**播放起点卡片**（`PlaybackMarkerCard`）。
- 曲线配置（`CurveConfigPanel`）在曲线持工具态时塞进左栏。
- 画布左沟槽可交互（双击放播放起点）⇒ 面板不能压在画布上。

## 原型

- 分支：`prototype/workspace-layout`（一次性分支，不进 main）。
- 启动：`bash scripts/dev.sh`（Windows 用 Git Bash），打开 `http://localhost:5173/?variant=A`，进工作台。
- 切换：页面左下角黑色胶囊的左右箭头，或 `Alt+←` / `Alt+→`；`0` = 现状对照。
- 代码：`src/pages/workspace/prototype-layout/`（变体件）+ `src/ui/PrototypeSwitcher.tsx`（切换条，仅开发构建出现）；`WorkspacePage.tsx` 只加了按 `proto` 分支的条件渲染，`PlayBar` 加了一个原型用 `timeSlot`。
- 片段库数据全是假的（5 条示例 + 「看空状态」开关）；「收藏选区」与卡片点击都不生效。
- 吸附值在原型里**不持久化**（Q6 的持久化留到实现）。

## 实现拆分（2026-10-26 用户认可全部原型；按 Q9 开工时各拆一张实现票）

顺序有讲究：旧左栏 `Toolbar` 里装着节拍吸附与曲线配置、旧右栏装着播放起点卡片，**先把这三样的新家做好（与旧布局并存），最后一刀换壳删旧**，每一步合进去都不丢功能。

1. **节拍吸附胶囊**（顶栏右簇）：12 档网格 4×3 弹出面板 + 自定义 1–192 + 滚轮步进 + `settings` 持久化（照 `settings.curve` 的做法）。此步旧左栏的吸附下拉可先留着，两处读写同一份状态。
2. **画布 / 播放条读数件**：曲线选项胶囊（画布左上角）；播放起点按钮进播放条时间码旁（出现动效一圈 + `settings` 显隐开关，默认开，放显示设置面板最下方「播放条」组）；画布底部读数改为左下 `BPM N`、右下 `♪ 已过 / 总数`。
3. **换壳**：窄工具轨（15 键 5 组）+ 岛屿外壳 + 顶栏重排（项目名后撤销 / 重做；右簇去 BPM / 音符数，加谱面代码钮与片段库钮）+ 片段库抽屉外壳（只有空状态，内容待 164）+ `Ctrl+Shift+B` 改为只开合抽屉；删旧 `Toolbar`、`NoteInfoPanel`、`PlaybackMarkerCard`、`CurveConfigPanel` 在左栏的挂载、`leftPanelWidth` 及 `settings.layout.leftPanel`。
