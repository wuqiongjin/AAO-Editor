## 来源

issue 09 验收收口后追加需求 #1（2026-09-15 用户提出）："拖拽 SP 滑条时，不再只是针对'滑条中间节点'，而是以'拖拽点'最近的 hidden 节点进行拖拽。" 本票承接 SP 整形语义，**取代** ADR-0009 §4 的"拉弓变形"。自 09 拆出（09 已 resolved，按 issue-tracker 约定不改写旧票）。

## 症状

- 拖 SP 带（`slideRegion`）只有**整段拉弓**一种：位移场 `bowWeight(t)=1-|2t-1|` 峰值**恒在段中点**（`SpanCurve.ts:227/237`），两端可见结点锚定、只改 lane。
- 拖可见结点 = **移动该结点**（`planDragMove` 的 `nodes` 分支），不是"改形"。
- hidden 结点不可命中（`hitTest.ts:132`，issue 56 Q36=D）→ SP 的形状控制点几乎全是 hidden，**谱师捏不到细节**：想让某一小段鼓起来，只能整体拉弓或去动画笔。
- 全仓无任何"按拖拽点取最近采样点做局部位移场"的代码（唯一 `nearestVisible` 是沿数组序找邻居、刻意跳过 hidden）。

## 定案（用户 2026-09-16，两轮逐条拍板）

| # | 决策 | 结论 |
| --- | --- | --- |
| A1 | 位移场 | **分段线性三角，峰值在抓取点**：左 `w = t/t_grab`、右 `w = (1−t)/(1−t_grab)`；两端可见结点严格 `w=0`（锚定不变），全段都动，无新参数。**抓段中点时与现 `bowWeight` 逐点相同** |
| A2 | 抓取点锁定 | **按下瞬间锁定**（与 `DragAnchor.rawPressBeat` 快照同口径），整个拖拽期间峰值位置不变 |
| A3 | 度量 | `t_grab` = 按下时**最近采样点的拍位**（离散吸附，1/16~1/64 拍，肉眼不可辨）；权重参数 `t` 按**拍**归一化（与现 `bowWeight` 同源） |
| A4 | 普通段 | **同口径**：无 hidden 的直线段被拖带 = 先按 **1/16** 补采样点（Q10=B 拨弯即转化），再用同一位移场捏形 |
| A5 | 视觉反馈 | **不新增**（光标即反馈；不画 hidden 结点、不加抓取点标记——守 issue 56 Q36=D） |
| Q3 | 与拉弓关系 | **取代**，不并存（ADR-0009 §4 改写）。拉弓 = 峰值钉在中点的特例，能力零损失、无模式记忆负担 |
| Q4 | 纵向 | **beat 不动**（与拉弓同）。106 已定产不出非单调点序；纵向会让数据点与显示投影分叉 |
| Q6 | 边界 | 抓取点 = 画布几何最近的**段内**采样点（段内无可见结点，故即 hidden）；**"一动就自由化"照旧**（清该段参数 → 自由段）；**不跨段**（段 = 变形单元） |
| — | 沿用现状 | lane `clamp(0,6)`；单 `slideRegion` 才捏形（多选/混合选区不捏）；Long 与 Slide 同款；一次拖拽 = 一步 undo |

## 实现落点

1. `src/chart/editing/SpanCurve.ts`：
   - 新增 `pinchWeight(t, grabT)`（分段线性；`grabT` 落在 0/1 边界时兜底，避免除零），`bowWeight` 保留为 `grabT=0.5` 的特例（现有锁测 `SpanCurve.test.ts:201+` 直接复用）。
   - `bendSpan(slide, connIndex, dLane, grabT, beatDisplay, precision=16)`：权重换 `pinchWeight`，其余（两端锚定切片、`clamp`、参数清除）不动。普通段补采样点逻辑不变（保持 1/16）。
2. `src/chart/editing/NoteDragging.ts`：`planDragMove` 的 region 分支（`:171-180`）计算 `grabT` —— 由 `DragAnchor.rawPressBeat`（已有，无需新字段）在该段内取 `|beat − grabBeat|` 最小的采样点，再归一化 `(beat_grab − fromBeat)/(toBeat − fromBeat)`；段内 beat 单调（106），取最近点可用线性扫描或二分。
3. `src/chart/editing/CanvasGesture.ts` / `FinalVirtualCanvas.tsx`：**不改**（`rawPressBeat` 已足够；不要为抓取点新增坐标字段）。
4. 文档：ADR-0009 §4 改写（含"取代拉弓"与被否决备选）、`CONTEXT.md`（`拉弓变形` → `捏形`，新增 `抓取点`）——**均已改**。
5. **代码注释同步**（实现时一并改，避免注释与新语义打架）：`SpanCurve.ts:226/230`（"拉弓变形的位移分配"）、`NoteDragging.ts:56/168/466`（"区域可拖 = 拉弓变形"）；测试**用例名**里的"拉弓变形"措辞（`SpanCurve.test.ts:197/209`、`NoteDragging.test.ts:102/437/453`、`CanvasGesture.test.ts:249`）可保留（描述的是被覆盖行为）或一并改为"捏形"，**不要**改动它们的断言（抓中点 = 旧行为，必须继续绿）。

## 锁测

- **单测 `SpanCurve.test.ts`**：`pinchWeight` —— `grabT=0.5` 时与 `bowWeight` **逐点相等**（回归）；`grabT=0.25` 时左半斜率 > 右半斜率、`w(0)=0`、`w(1)=0`、`w(grabT)=1`；`grabT→0` / `→1` 不除零、不产生 NaN。
- **单测 `bendSpan`（带 grabT）**：抓中点 = 旧行为（与现有 4 条用例同结果）；抓 1/4 处 —— 该点 lane 增量 = `dLane`（clamp 前）、两端可见结点 lane **不变**、**所有 beat 不变**；`dLane=0` 仍无变化；lane 越界被 clamp 到 `0..6`。
- **单测 `NoteDragging.test.ts`**：抓取点**按下锁定**（同一 `DragAnchor` 下换 delta，grabT 不变、落子结果只随 `dLane` 变）；段内取最近采样点（拍位距离，非数组序）；普通段（无 hidden）→ 补 1/16 点且转自由段（参数清除）；解析段被捏 → `spanParams` 中该段被删（一动就自由化）；多选/混合选区 → 不捏形（沿用现状）。
- **页面实测（Playwright，`scripts/` 脚手架）**：同一条 SP 绿条抓中点拖 = 现状手感；抓偏左拖 → 左侧陡、右侧缓，端点不动；拖完 undo 一步完全回退。
- **手工验收**：曲线工具画一条 C 形 SP → 在曲率最大处前后各捏一次，形状响应符合"峰值跟手"。
