## 范围与落点（2026-10-19）

- **事件清单（模块级、粗粒度，Q7=A）**：页面切换（`PageId`：`projects` / `workspace` / `audio` / `assets` / `settings` / `shortcuts` / `preview`）、工程打开 / 保存、导入导出起止（含成功 / 失败）、设置变更、Bestdori 登录 / 浏览 / 上传起止、应用更新检查起止。
- **载体**：内存 ring buffer 500 条；崩溃（票 03 边界触发）或导出诊断包（票 04）时落盘到 `trail-YYYYMMDD.jsonl`（票 01 已建的那条轨）。
- **事件结构**：`{ ts, module, action, result?, durationMs?, meta? }`——meta 只放定位必要信息，不放用户内容（谱面 JSON、密码、Cookie、帖子正文都不进）。
- _Avoid_（CONTEXT.md）：逐键编辑流水、审计日志。

## 锁测

- 单测：ring buffer 容量 500（溢出丢最旧、保序）；事件结构序列化形状；关键动作各至少一条埋点（页面切换 / 工程保存 / 导出起止）。
- 手工验收：走一遍「打开工程 → 编辑 → 导出视频 → 改设置」，导出 trail 验证序列完整、粒度正确——**不应**出现逐键 / 逐音符记录。
