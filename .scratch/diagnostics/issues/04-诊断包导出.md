## 来源

ADR-0019 §4（Q8=A）。诊断包是产品**唯一**的现场来源（无远程遥测），也是文档站「排障」章节指引用户附 Issue 的对象。README 已写「排障依靠应用内导出的诊断包」，代码尚未实现。

## 实现时序

**不挡在票 02 后面。** 轨迹文件没有时包内省略或放空文件即可；票 02 完成后再自然带上最近一次操作轨迹。

## 范围与落点（2026-10-19）

- **默认包含（脱敏全量）**：应用 / Electron / OS 版本、数据根路径、最近 7 天错误日志、当前 `PageId` / 模块、设置快照。
- **凭据红线**（ADR-0011 §3，照 `tests/static/CommunityCredentialBoundary.test.ts`）：设置对象本身不含会话；组装代码**不得**读取 `community-session.bin`、Cookie jar、`safeStorage` 明文。诊断包组装不得 import 凭据模块。若将来设置里出现 token 类字段，脱敏函数一律剔除。
- **「附带当前谱面数据」勾选框，默认不勾**——谱面是用户创作内容、可能含未发布作品，默认不附、让用户主动勾。
- **导出**：zip、文件名带时间戳；经主进程完成（fs + 保存对话框）。形态对齐已有 `preview:saveBinary` / `chartCode:saveAs`（每次弹系统对话框，不记路径）。zip 库建议 `jszip`（实现期可换）。IPC 走 `registerXxxIpc`，preload 白名单新通道。
- **入口**：设置页「关于」段（`SettingsPage` 现有 `appearance | data | about`）。崩溃弹窗入口等票 03 错误态落地后补，可本票先导出函数、03 再接线。

## 锁测

- 单测：脱敏函数——构造含 token / cookie / 会话字段的设置对象，断言产出一律剔除；zip 内容清单与文件名格式（时间戳）；无轨迹文件时导出仍成功。
- 静态源码断言：诊断包组装代码不引用凭据存储键 / 不读 `community-session.bin`（照 CommunityCredentialBoundary 惯例）。
- 手工验收：设置页导出 → 解压检查版本 / 环境 / 错误日志 / 设置齐全且无凭据；勾选谱面数据后包内出现谱面、不勾则没有。
