## 来源

ADR-0019 §5（Q9=A）。现状核查（2026-10-13 与 2026-10-19 相同）：`ErrorBoundary|componentDidCatch` 全仓 0 命中，`window.onerror` / `unhandledrejection` 0 命中——一个渲染错误即白屏，且无任何记录。

## 范围与落点（2026-10-19）

无 react-router。页面是 `PageSlot` 保活挂载的 `PageId`（`src/pages/PageRegistry.tsx`）：`projects` / `workspace` / `audio` / `assets` / `settings` / `shortcuts` / `preview`。Bestdori 浏览 / 登录 / 上传都在 `projects` 页内，不另开 boundary。

实现顺序（同一张票，可分提交）：

1. **全局兜底**：`window.onerror` / `unhandledrejection` 接入 logger（错误日志轨）。
2. **App 顶层 boundary**（`src/main.tsx` / `ProviderTree` / `AppShell` 择一最外层）：错误态 + 「重试」；有票 04 之后在错误态放「导出诊断包」，本票先留入口位或完成后补。
3. **每页 boundary**：包在 `PageSlot` 里，一页崩了其它页还能切。
4. **canvas 渲染区单独 boundary**：`FinalVirtualCanvas` 所在工作台画布（高危区，ADR-0017 不变量就崩在画布上）。

- **联动**：boundary 触发时若票 02 已存在则 flush ring buffer；未做 02 则只写错误日志。
- 用户可见文案口径不变：原始技术错误不拼进界面（沿用 `useVideoExport` / `CommunityError` 既有政策：界面走 i18n，`message` 只进 logger）。

## 锁测

- 组件测试：抛错的子组件被 boundary 接住 → 显示错误态而非白屏；点「重试」后重置。canvas boundary 同例。
- jsdom 可派发 `error` / `unhandledrejection` 事件 → 断言 logger 各收到一条 error 记录。
- 手工验收：dev 态临时注入 throw，验证顶层 / 单页 / 画布各自的兜底与日志落盘。
