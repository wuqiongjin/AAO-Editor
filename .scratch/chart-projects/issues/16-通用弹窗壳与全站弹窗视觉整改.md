# 16 · 通用 Dialog 壳与全站弹窗视觉整改

Type: feature
Status: resolved
Blocked by: 13

**来源**：用户 2026-09-27 反馈「弹窗设计好单调、好丑陋」（13 票落地后），同日 grill 定案
（Q1=①层级扁 + ③规格分叉为主、②④顺带；Q2=收编成通用壳；Q3=不引 shadcn；Q4=危险分寸）。

**症状**
1. **层级扁**：图标 / 标题 / 正文 / 按钮全是一个灰调，扫一眼看不出这是不可逆操作。
2. **两个壳规格分叉**：`.pp-dialog`（新建 / 编辑工程 / 谱面信息）是 560px / padding 22 / radius-lg / 标题 16px、
   遮罩走 `--overlay-bg`；`ConfirmDialog` 是 420 / 16 / radius-md / 14px / 遮罩硬编码 `rgba(0,0,0,0.45)`。
   后者还违反了 ADR-0003「tokens.css 是全站唯一色值出处」。
3. **无动效**：全站有 `app-page-fade-in 130ms` / `app-stagger-enter 170ms`，弹窗是硬切出现。
4. `ChartCodeEditorModal` 第三套自绘弹窗（内联 style），连 class 都没有。

**根因**：13 票只补了**行为**（Esc / 焦点 / aria），没补视觉；本仓从来没有一个共同的弹窗壳，
于是每加一处就多一套 CSS。

**范围**
- 定一个通用 Dialog 壳：scrim / panel / header / body / footer + 动效 + 焦点与 aria 语义。
  先落 `ConfirmDialog`（第一步，已完成），再迁 `.pp-dialog`（新建工程 / 编辑工程信息 / 谱面信息）
  与 `ChartCodeEditorModal` 的自绘弹窗（第二步，本票主体）。
- 视觉定案 = **D 方向**（无图标、大标题问句、正文注意行、分隔线 + 底栏、120ms 渐入上浮）+ **B 的危险键**（实底红）。
- **不引 shadcn / Tailwind / Radix**（理由写进 Comments）。
- 文案结构定案：标题 = 问句（含对象名），正文 = 「注意：…」后果行。
- `window.alert` 的替换不在本票（全局提示体系另开票）。

**定案（2026-09-27 grill）**

视觉（D 方向）：
- 面板：`min(440px, 92vw)`、padding 20、radius-lg 14px、shadow-lg、gap 12 —— 与 `.pp-dialog` 对齐。
- 标题：`--text-lg`（16px，与 `.pp-dialog h3` 同档），不加图标。
- 正文：`--text-sm` 13px、line-height 1.75、`--text-muted`、`white-space: pre-line`（多行后果）。
- 底栏：上方 `--border-faint` 分隔线、padding-top 14、按钮右对齐、gap 8。
- 遮罩：`var(--overlay-bg)`（不再硬编码）。
- 动效：面板 `120ms` 渐入 + 6px 上浮，遮罩 `120ms` 渐显；`prefers-reduced-motion: reduce` 下关掉。

危险键（B 的按钮）：实底红。为此新增一对 token（与 `--accent-btn` 对称，保证白字过 WCAG AA）：
`--danger-btn / --danger-btn-hover / --danger-btn-active / --danger-btn-text`。
**分寸规则（化解 Q4-a 与「换成 B 的」的冲突）**：
> **不可逆动作（删除 / 覆盖 / 丢弃）= 实底红；可逆动作（清除封面等）= 红字点到为止。**
issue 12 定的「危险动作红字点到为止、不要红底常驻」是给**可逆**动作的分寸，不动；
本规则补上不可逆那一半，写进 CONTEXT.md 的 UI 分寸一节。

文案结构：
- 标题 = 一句问句，带对象名（`删除工程「测试」？` / `删除这张谱面？` / `丢弃未应用的更改？` / `覆盖画布上的 3 个音符改动？`）
- 正文 = `注意：…` 后果行（删除工程再多带一行已上传提示）
- 不写「确认是否要…」：弹窗本身就是确认，按钮上已经写着动作，再说一遍是冗余。

**锁测**
- `tests/dom/ui/ConfirmDialog.test.tsx`：标题 / 正文的文案与角色、动效 class 挂上了（动效本身 jsdom 测不了）。
- `tests/static/DialogTokenWiring.test.ts`（新）：弹窗 CSS 与弹窗组件里不许出现硬编码色值（hex / rgba），
  一律走 token —— 防第二个壳再犯同样的错（ADR-0003 的机器可执行版本）。
- 视觉（尺寸 / 留白 / 动效 / 暗色下的红）jsdom 无布局引擎 → **headless Edge 出图门票**。
