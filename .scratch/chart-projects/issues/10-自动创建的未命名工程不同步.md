# 10 · 工作台自动创建的未命名工程不出现在工程管理页

Type: bug
Status: resolved
Blocked by: —

**来源**：用户 2026-09-26 #2；2026-09-27 Q9（同时把「下次再打开就是这个未命名工程」定为不变量）。

**症状**：一个工程都没有时直接进工作台 → 工作台面包屑显示「未命名工程」，但切回工程管理页列表里没有它。

**根因**：`CurrentProjectProvider.ensure()`（`src/app/providers/CurrentProjectProvider.tsx` L55-60）只 `setProjectId/setChartId`，**不调 `notifyCatalogChanged()`**；而 `createBlank` / `copyProject` / `mutate` 三条路径都显式调了。`ProjectsPage` 是保活挂载，只在 `catalogEpoch` 变化时 `reload()`。工程其实已 `store.save` 落盘，只是 UI 目录没被通知。

**修法**：`ensure()` 在**确实新建了工程**（`result.created === true`）时调 `notifyCatalogChanged()`；单纯 `open` 已有工程不触发（避免每次进工作台都重拉列表）。

**定案（用户 2026-09-27 Q9，规则现状如此，本次只补锁）**：进工作台 = 打开**最近打开且有未完成谱面**的工程；没有未完成工程时新建未命名工程；新建的未命名工程自带一张空谱面（未完成）→ 下次再进工作台就是它，直到它也完成且无其他未完成工程才建下一个。`decideWorkspaceProject` 已是这套语义，不动逻辑。

**锁测**：
- `tests/unit/chart/project/WorkspaceProjectDecision.test.ts`（新增，**不依赖 08**）：多工程时挑 `lastOpened` 最大且未完成的；全已完成 → 返回 create；把 `createUnnamedProject` 的产物喂回 `decideWorkspaceProject` → 断言命中 open（用户 Q9 那条不变量）。
- `tests/dom/app/CurrentProjectProvider.test.tsx`（依赖 08）：无工程 + 调 `ensure()` → `catalogEpoch` 递增。
- `tests/static/ProjectCatalogNotify.test.ts`：静态断言 `ensure` 分支内出现 `notifyCatalogChanged`，照 `tests/static/ChartProjectPersistence.test.ts` 惯例。
