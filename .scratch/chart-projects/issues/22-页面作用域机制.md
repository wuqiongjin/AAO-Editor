# 22 · 页面作用域机制（页面可临时作用于非当前工程）

Type: grilling
Status: open
Blocked by: —

**来源**：用户 2026-09-28 第二轮（票 15 的后续）。诉求：工程管理页的音频行要能**跳转**到音频页去改；但跳过去后**不能切走当前工程**，同时用户必须能看出「我现在操作的音频属于哪个工程」。用户提出的解法是给音频页加一个「类似 Switcher 的标识」承载这件事，并预见**预览类页面**（完整谱面预览 / 谱面视频预览）会复用同一套机制——它们从工程管理页分离出去、但要与谱面工程绑上关系。

2026-09-28 两轮 grill 拍板（第一轮 Q1–Q7、第二轮 Q1–Q4）。逐问对话存档与被否决方案见文末。

**症状**

- b) 音频与谱面工程之间**看不出绑定关系**（音频页只显示"当前工程"这一层，页面与工程的指向不显式）——票 15 症状 b。
- d) 工程详情音频行**只能看不能改**：改要绕道「先进工作台把它设为当前工程 → 再走音频页」，低频动作却路径最长。
- e) 若为「详情能改」而把当前工程切走，用户会**丢掉工作台原来的编辑上下文**（正是 d 的两难）。

**根因**：「页面作用于哪个工程」此前**隐含等于当前工程**（靠接线唯一性保证），没有独立概念。要既作用于非当前工程、又不切当前工程，就必须把这个指向显式化为一等概念。

**定案（用户 2026-09-28）**

1. **作用域（scope）= 页面此刻作用于哪一个工程的临时指向**（数据上 `projectId`，将来可扩第二级 `chartId`）。与「当前工程」**彻底分两个词**，不得用「当前」表示作用域。
2. **scope 不持久化，由「进入动作」决定**（不"粘住上次"）：应用壳左栏的页面入口（如「音频」，含 `⇧⌘2`）永远**先清 scope 再激活**（语义 = 去当前工程的音频；在音频页再点一次左栏「音频」= 回到当前工程）；带 scope 的跳转则**先写 scope 再激活**。页面是保活挂载的，这样比"进入时检测是不是跳转来的"可靠。
3. **可读不缩水，可写要参数化**：scope 指向任何工程都可读（工程名 / 音频名 / 时长 / 锁状态）；「更换 / 清除 / 改时长」按 `projectId` 参数化，锁判定在接缝里**再挡一次**（纵深防御）。
4. **锁定的工程可以被选为 scope**：进去只读看（**将来也能播**）。锁锁的是「改变共享资源的动作」，不是「看和听」。
5. **形态（三变体选 A）**：作用域住在**区块头右侧**（音频页 = 「音频素材」那行），**不做页级独立横条**。横条形态是两端对齐 + 中间 `flex:1`，只有两个元素时中间必然空一大片。
6. **作用域条显式区分「当前 / 非当前」**：
   - scope == 当前 → 「当前」徽标（`--accent-soft` / `--accent-text`，与工程管理页 `.pp-current-tag` 同语言），容器**无框**；
   - scope ≠ 当前 → 「非当前工程」标识，**中性色**（`--bg-inset` 底 + `--border-strong` 实描边；不用红黄——这不是错误态），**整条容器换底色**，让"你正待在临时作用域里"由容器说而不是靠一枚小标签喊。
   - 两个候选都不能碰的既有分工：`accent-soft/accent-text` = 当前 / 已上传，`warning-text` = 锁定。
7. **切换器（ScopePicker）= 下拉 + 常驻搜索**：
   - 匹配**显示名 + 歌手**，**不匹配谱面名**（作用域是工程级，搜到谱面名会让人以为能选谱面）；
   - 匹配源必须用**显示名**（`name === null` → 「未命名工程」），否则自动新建的未命名工程全部搜不到；
   - **不做拼音 / 首字母**（本仓无拼音索引基建，工程名多是日文/英文曲名），大小写不敏感 + trim 够用；
   - 条目 = `名称 + 音频名 / 「无音频」+ 锁图标 + 「当前」徽标`，**不放封面**（这条是"选一个作用域"，不是"挑作品"）；
   - **当前工程置顶 + 分隔线分组**（推翻 09-28 早间"不置顶"——代价：面板顺序不再等于工程管理页顺序，见被否决方案）；
   - **打开即聚焦搜索框**（显式 focus，不用挂载期隐式抢焦点）；点面板外 / Esc 关闭（Esc 还把焦点还给触发钮）；chevron 展开转 180°（150ms）；无结果给一行灰字；列表内部滚动（约 8 条以上），不做虚拟化 / 虚拟滚动。
8. **不给「回到当前工程」按钮**：出口 = 在音频页再点一次左栏「音频」（定案 2）。有它就把作用域从"身份显示"（我在改谁）变成"需要学的状态机"（当前/非当前之间有转换动作）。
9. **失效回落**：scope 指向的工程被删 → **回落当前工程 + 一条提示**（这是"状态被动失效"，不是"被禁止的操作"）；当前工程也没有 → 走该页既有空态（票 15 定案 4）。收敛到"无 scope"与"scope 失效"同态，页面里不多一个"工程不存在"中间态。
10. **本票只做工程一级**：二级（工程 + 谱面）只在 API 形状上留位，没有第二个真实消费者时不把形状做出来。
11. **播放口径（约束，本票不实现播放）**：scope 的读能力**不因"不是当前工程"而缩水**——将来音频页播放**按需解码、用完释放**，绝不常驻第二份解码音频（那是工作台共享 `AudioEngine` 的位置，借它会顶掉工作台那份）。为此票 15 的时长探针接缝要留出"解码结果"的扩展位。
12. **ADR 落点**：机制写进 **ADR-0015 新增 §6「页面作用域」**（不搬 ADR-0007，理由见被否决方案）。

**复用边界（为什么值得抽成机制）**

第一个消费者是音频页，第二个是完整谱面预览 / 谱面视频预览。共性 = **从工程管理页分离出去、但仍要与某个谱面工程绑定**。本票只抽 **scope 状态 + 作用域条组件**；数据加载各页自理（组件是受控的，不自管 store 读取）。

**被否决方案（记录理由，防回潮）**

- **落 ADR-0007（应用页面壳）**：0007 的规范对象是内容壳的**形态**——API（compound component）、几何自适应（§5）、3 条硬约束（§4）、新页 4 题决策清单（§6）；其 §10 边界明确把"**每个页面内部的内容**"划在范围外。作用域与布局无关，它是「**页面与谱面工程**的关系」，属 ADR-0015 §3「工作台与当前工程的关系」的同族推广（从"工作台"推广到"任意页面"）。放 0007 会逼它装进一个自己声明不属于自己的领域概念，且 §10 要为此破例。
- **作用域只读 + 显式"以此工程为当前工程并编辑"按钮**：多一次点击换零新写路径，语义最干净，但直接违背用户诉求（不切当前也要能改）。
- **「详情管理 → 跳音频页」整体不成立**（09-28 早间的否决）：那条否决针对的是**旧形态**（跳过去就切当前工程 / 或详情直接双写），本票用 scope 把这个矛盾解掉了——入口不必换家。
- **scope 粘住上次访问**（不随入口复位）：会让"音频"这个全局入口的含义随上次访问漂移，且"我在改谁的音频"这个困惑反而被静默放大。
- **播放只在 scope == 当前工程时可用**：省内存，但会出现"能改 B 的音频却不能试听 B 的音频"的别扭不对称。
- **「回到当前工程」按钮**：见定案 8。
- **作用域做成页级全宽横条**：见定案 5（中间空一大片的必然性）。
- **非当前标识用警示色（红/黄）**：不是错误态；且 `warning-text` 已被"锁定"占用，撞脸。
- **二级（工程 + 谱面）scope 本票一并做**：没有第二个消费者，只能靠猜。
