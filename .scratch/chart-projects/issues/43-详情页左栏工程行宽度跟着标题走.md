# 43 · 详情页左栏工程行宽度跟着标题走

Type: bug
Status: resolved
Blocked by: —

**来源**：用户 2026-10-26 图1。选中态宽度 + 进度条宽度两条观感，同一根因，不拆票。

**症状**：`.pc-item` 盒子按标题内容收缩。短名（如 `Test (Copy)`）选中浅底只铺到文字右缘；长名铺满甚至溢出左栏。`.pc-item__bar`（`left:60px; right:14px`）相对的也是这个内容宽盒子，条子跟着条目长短走。顺带：长标题被左栏 `overflow` 硬切，写在 `b` 上的 ellipsis 实际不生效；hover 底同病。

**根因**：行是 `<button class="pc-item">`。`display:flex` 改不了按钮 UA 的 `width:auto` = fit-content。选中底画在 button 上，进度条 `position:absolute` 相对的也是它。账号行踩过同一坑，给 `.pc-account__row` 加了 `width:100%`，注释却误写「与 `.pc-item` 一致」——`.pc-item` 从来没满宽。与 issue 23 #4 / 25 同源：布局判据不许依赖文字内容（Q35 已定列表行满宽）。

**本轮实现口径（待验收）**：`.pc-item` 钉 `width:100%`（照账号行；按钮 UA 已是 `border-box`，不会把 padding 再加一遍）。进度条声明不用改——包含块一满，`left/right` 就对了。

**锁测**：
- 静态：`.pc-item` 规则含 `width:\s*100%`（可挂 `AccountBarLayout.test.ts` 或 `ProjectDetailHeadLayout.test.ts`）。jsdom 无布局引擎，量不出像素。
- 手工：短名 / 长名两行，选中底与进度条右缘对齐左栏；长名出省略号而不是硬切。

## Answer

`.pc-item` 钉 `width: 100%`。选中底 / hover / 进度条的包含块铺满左栏内容宽；长标题 ellipsis 生效。
