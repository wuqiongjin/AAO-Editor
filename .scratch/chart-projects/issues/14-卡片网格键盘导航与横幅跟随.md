# 14 · 全部工程卡片网格的方向键导航 + 横幅跟随

Type: feature
Status: open
Blocked by: 08, 09

**来源**：用户 2026-09-26 #7（「希望增加左右切换…下面选中状态也跟随切换，←→↑↓ 也可生效」）；2026-09-27 Q7（不要自动轮播，只手动切换）、Q10（方向键操控的是 **下方卡片网格**，横幅跟随更新）、Q11（默认选中第一个 = 最近打开的工程）、Q15（排序沿用 `lastOpened`，不新增字段）、Q16（同意 6 条口径）。

**症状**：工程管理页没有任何键盘处理；横幅只展示「第一个未完成工程」，既不能切换，也在工程全部完成时消失（与 09 是同一根的一片）。

**定案（用户 2026-09-27）**：
1. 触发范围：**仅工程管理页为当前页** 且 **焦点不在输入框 / 弹窗内** 时才监听（避免与画布、编辑器快捷键冲突）；
2. 导航对象是**「全部工程」卡片网格**（多行多列）：←/→ 同一视觉行内 ±1 列，↑/↓ 跨行同列上下；**到边界停在原地**，不循环、不跨行绕接；
3. 顺序 = `sortProjectsByLastOpened`（沿用现状，**不新增 `updatedAt`**）；默认选中第一个卡片；
4. 选中态 = **浏览焦点**，**不等于「当前工程」**；当前工程继续由 `is-current` 角标单独标识（现有视觉）；
5. 横幅内容是**选中卡片的投影**（封面 / 名称 / 状态 / 主按钮随状态变化：未完成「继续创作」、已完成「查看工程」）；选中卡片自动滚入视口；
6. Enter / 双击打开该工程详情；鼠标点击行为保持现状；0 个工程时方向键无事可做，1 个工程时不移动。

**修法**：
- 抽出纯函数 `moveGridSelection(ordered, currentId, key, columns)` 放在 `src/pages/` 附近（可单测），二维算法不再藏在组件里；
- `ProjectStartView` 引入 `selectedId` state + `useEffect` 注册 window keydown（带页面激活守卫）；hero 改为从 `selectedId` 取值，`resume` 只作默认初值；
- 抽 lifelong 列数按容器实际折行计算（`offsetTop` 分组），随窗口 resize 重算。

**锁测**：
- `tests/unit/pages/ProjectGridSelection.test.ts`（**不依赖 08**）：←/→/↑/↓ 的位移与边界停住；首末元素；单元素 / 空列表；越界 `currentId` 回退到第一个。
- `tests/dom/pages/ProjectGridKeyboard.test.tsx`（依赖 08）：按 → 后框定卡片高亮转移 + hero 内容同步更新；弹窗打开时不响应方向键；Esc 无副作用。
- `tests/static/ProjectsKeyboardGuard.test.ts`：静态断言 keydown 监听被「当前页 + 非输入焦点」守卫包住，防止未来污染全局快捷键。
- 自动滚入视口 / 卡片滚动动画属布局行为 → jsdom 测不了，走人工验收清单。
