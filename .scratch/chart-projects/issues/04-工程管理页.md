# 04 · 工程管理页

Type: feature
Status: open
Blocked by: 02, 03

## 来源

[01](./01-谱面工程管理与启动流程定案.md) 定案 7 / 11 / 12。

## 要做

- 接入内容壳（ADR-0007）的应用页面；列表按最近打开排序，每行显示工程名称（空则「未命名工程」）、封面缩略、每张谱面的状态标签。
- 操作：打开为当前工程；新建（空白 / 从谱面代码 / 复制工程；「从 Bestdori」入口留给 07，本票不显示）；编辑工程信息；删除（二次确认，文案说明不影响 Bestdori 上已发的帖）。
- 新建对话框只露工程名称、歌手、音频、难度，全部可不填；其余在编辑工程信息里补。
- 从谱面代码新建：走现有 Apply 闸门（ADR-0014），硬拒绝时报错不建工程。
- 复制工程：工程信息、音频、封面、全部谱面照搬；**谱面状态不带**（用户 2026-09-26，与复制谱面同口径）。这也是「想换已上传工程的音频」的出路（见 06）。
- 上传记录只展示（帖子链接、时间）；上传按钮等 bestdori-integration。
- 不做搜索 / 筛选 / 分组。

## 锁测

- 列表排序与「未命名工程」显示：组件单测或 Playwright。
- 从谱面代码新建：合法代码建出一张谱面且源数据保真；硬拒绝的代码不产生工程记录。
- 删除后记录与音频、封面字节都不在存储里。
