# 04 · 工程管理页

Type: feature
Status: open
Blocked by: 02, 03

## 来源

[01](./01-谱面工程管理与启动流程定案.md) 定案 7 / 11 / 12。

## 要做

- 一个应用页面、两个视图（用户 2026-09-26 prototype 选定，见变体 D）：
  - **工程启动台**（B）：启动默认落点。继续创作 + 三种新建入口（空白 / 复制工程 / 从 Bestdori，07 落地前不显示后者）+ 封面墙。
  - **工程详情**（C）：点封面下钻。左侧工程列表（可快速切工程）+ 右侧该工程的谱面、状态、上传记录与操作。顶部「← 主页」回启动台。
- 点击口径（本轮实现默认，见 Comments）：封面 / 「详情 ›」→ 工程详情；「进入工作台」与卡片悬停 ▶、继续创作上的难度标签 → 工作台。从工作台按 `⇧⌘0` 回来时，保活页停在离开前那一层。
- 操作：打开为当前工程；新建（空白 / 复制工程；「从 Bestdori」入口留给 07）；编辑工程信息（含封面）；删除（二次确认，文案说明不影响 Bestdori 上已发的帖）。
- 新建对话框只露工程名称、歌手、第一张谱面难度，全部可不填。音频去音频页；封面、曲目来源在编辑工程信息里补。
- **不提供「从谱面代码新建工程」**（Q25）。贴 JSON 走工程内「新增谱面」或工作台谱面代码编辑器。
- 复制工程：工程信息、音频、封面、全部谱面照搬；**谱面状态不带**（用户 2026-09-26，与复制谱面同口径）。这也是「想换已上传工程的音频」的出路（见 06）。
- 上传记录只展示（帖子链接、时间）；上传按钮等 bestdori-integration。封面 / 歌手 / 曲目来源不推迟到上传才设。
- 不做搜索 / 筛选 / 分组。
- 工程详情谱面列表：每行显示难度、谱面名称（空则显示当前工程名称）、音符数、**上次修改时间**、状态。不显示创建时间；不显示「跟随工程名称 / 自定谱面名称」这类元信息。「新增谱面」与列表拉开间距。

## 锁测

- 列表排序与「未命名工程」显示：组件单测或 Playwright。
- 工程内「新增谱面」贴合法代码：建出一张谱面且源数据保真；硬拒绝的代码不产生新谱面。
- 删除后记录与音频、封面字节都不在存储里。
