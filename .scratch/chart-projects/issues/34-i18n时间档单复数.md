# 34 · i18n 时间档英文单复数（顺带为日语铺路）

Type: bug
Status: resolved
Blocked by: —

## 来源

issue 31 code-review 双轴共同备注 + 用户 2026-10-14 拍板「可以改」：`en` 的 `{{n}} minutes ago` 在 n=1 时输出 "1 minutes ago"；且未来计划加日语，复数处理须先就绪。

## 症状与根因

`relTime` 四个计数档全走扁平 `t()` 键，无单复数；`tPlural`（CLDR one/other）已存在但时间档一个没用。且 `tPlural` 的 locale→Intl tag 映射硬编码二分（`src/i18n/t.ts:63`：`locale === 'zh-CN' ? 'zh-CN' : 'en'`）——日语上线后会误用 en 规则去要 `.one` 键（日语 CLDR 只有 other），回落 + warn。

## 修法

1. `tPlural` 的 tag 映射改 `Record<UiLanguage, string>` 数据驱动（加语言不进 if 链，漏加映射直接编译红）。
2. 四个计数键各拆 `.one`/`.other`：en 补 one+other；zh 只需 other；模板变量 `{{n}}`→`{{count}}`（`tPlural` 注入的是 count）；`justNow` 保持扁平。
3. `relTime` 四档改走 `tPlural('projects.time.*Ago', n)`，旧扁平键删除；日语上线属另票，本票只保证映射可扩展 + 缺键有锁。

## 锁测

1. 扩 `tests/unit/project/projectFormat.test.ts`：`setActiveUiLanguage('en')` 下 60s→"1 minute ago"、59min→"59 minutes ago"（撤 `.one` 键或改错 tag 映射应立刻红）；zh 期望串不变。
2. 新增 `tests/unit/i18n/PluralKeyParity.test.ts`：从消息表收集全部复数键基，遍历 `UI_LANGUAGES`，用**该语言自己的** `Intl.PluralRules(tag)` 采样类别，断言键存在——将来日语缺 `.other` 即红。
3. 纯函数 + 消息表，无 DOM / 像素 / 跨平台因素，单测全覆盖。
