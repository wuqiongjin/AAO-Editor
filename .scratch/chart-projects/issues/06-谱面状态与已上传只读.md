# 06 · 谱面状态与已上传只读

Type: feature
Status: open
Blocked by: 02, 05

## 来源

[01](./01-谱面工程管理与启动流程定案.md) 定案 9；[ADR-0015 §4](../../../docs/adr/0015-歌曲级谱面工程与工程管理页入口.md)。

## 要做

- 完成标记：工作台与工程管理页都能手动标 / 撤。
- 状态派生：有上传记录→已上传；否则标了完成→已完成；否则未完成。工程未完成 = 至少一张谱面未完成（03 的选工程规则用它）。
- 已上传谱面只读：可选中、复制、播放；任何编辑入口（放置、拖动、删除、粘贴、谱面代码 Apply）都拒绝，并提示「已上传的谱面不能修改，复制这张谱面来改？」附复制按钮。
- 工程里只要有一张已上传谱面，**共享的音频与谱面时长锁定**：音频页不能换 / 清除音频，播放条不能改时长；提示「复制这个工程或新建工程后再换音频」（用户 2026-09-26）。同工程的其它未上传谱面照常编辑。
- 上传记录由 bestdori-integration 写入；本票只需能读、能显示、能据此锁定。测试时可手工注入记录。

## 锁测

- 状态派生纯函数单测：三态 + 工程聚合。
- 只读闸门单测：注入上传记录后，编辑类操作返回拒绝、谱面源数据不变；选中与复制仍可用。
- 提示与复制按钮：Playwright。

- 音频 / 时长锁：注入上传记录后，换音频、清除音频、改时长均被拒、工程记录不变；去掉上传记录（换一张未上传谱面的工程）则放行。

## Comments

- 2026-09-26：原「待确认：已上传谱面所在工程能否换音频」用户拍板 = 不能，换音频走复制工程 / 新建工程。谱面时长随音频一起锁是按同一理由推出的（时长由音频决定、全工程共享），用户未单独拍板。
