# 21 · 编辑操作后所有封面闪一下（#19-3 修复被 reload 换 Blob 身份打穿）

Type: bug
Status: resolved

**来源**：用户 2026-09-28 验收（票 19 #3 落地后复报）。

**症状**：主页 → 详情不再闪（#3 生效）；但任何编辑操作（改谱面信息、改难度 …）会让**所有**封面闪一下。

**根因**：编辑走 `mutate` → `save` → `reload()` → `store.list()`，而两个后端每次读回都给**新 Blob 对象**（IndexedDB `getAll()` 反序列化 / Electron `blobFromBytes`）。#3 的封面 URL 缓存按 **Blob 身份** 命中 → 身份一换全部未命中：每个封面重新 `createObjectURL` + 重新解码 = 全封面闪。

**修法**：`ChartProjectStore` 记住本会话内每个工程"当前生效"的封面 Blob 实例，读 / 写路径统一过 `stabilizeCover()`：尺寸相同 → 顶回同一实例；尺寸变了（用户换封面）→ 用新读到的并更新记忆；无封面 → 清记忆。已知盲区：别的窗口换成"同名同尺寸的另一张图"本会话察觉不到（本应用自己换封面走 `save()`，即时更新）。

**锁测**：
- `tests/unit/chart/project/ChartProjectStore.test.ts`（新，5 条；假后端每次读回新建 Blob，复现真实反序列化语义）：两次 `list()` 同实例 / 编辑流全链同实例 / 换封面以新实例为准 / 无封面不长出 / 删除不残留。
- `tests/dom/pages/ProjectCoverFallback.test.tsx` 新增 1 条：改动难度后所有封面 `background-image` URL 不变、`createObjectURL` 不增不 revoke（**撤下修复即红**，已验）。
- `tests/support/providers.tsx` 补 `makeMemoryProjectBackend(projects, { cloneBlobsOnRead })`（近似真后端的读回语义）。
