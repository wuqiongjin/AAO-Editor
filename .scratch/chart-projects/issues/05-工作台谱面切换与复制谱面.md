# 05 · 工作台谱面切换与复制谱面

Type: feature
Status: open
Blocked by: 02, 03

## 来源

[01](./01-谱面工程管理与启动流程定案.md) 定案 5 / 8 / 9 / 10。

## 要做

- 画布顶栏谱面切换器：每张谱面显示「难度 · 谱面名称」，谱面名称为空或等于工程名称时只显示难度；旁边「+」新增谱面（选难度）。
- 删除谱面（二次确认；最后一张不可删）、编辑谱面信息（谱面名称、难度、等级），工作台与工程管理页都能做。
- 复制谱面：同工程内复制出新谱面，谱面代码 / 名称 / 难度 / 等级照搬，完成标记清空、无上传记录。
- 切换谱面时剪贴板不清空；各谱面的撤销历史互不串。
- 谱面名称为空时，显示与上传一律取当前工程名称（改工程名跟着变）。

## 锁测

- 切换器标签文案纯函数单测：名称为空 / 等于工程名 / 不同；同难度两张。
- 复制谱面单测：源数据逐字段相等、状态字段清空、新 id。
- 删最后一张被拒：单测。
- 跨谱面复制粘贴：Playwright 在 Expert 选中 Ctrl+C，切到 Hard Ctrl+V 成功。
