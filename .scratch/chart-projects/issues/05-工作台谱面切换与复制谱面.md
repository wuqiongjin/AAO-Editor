# 05 · 工作台谱面切换与复制谱面

Type: feature
Status: open
Blocked by: 02, 03

## 来源

[01](./01-谱面工程管理与启动流程定案.md) 定案 5 / 8 / 9 / 10。

## 要做

- 画布顶栏谱面切换器采用 **面包屑下拉**（prototype B，用户 2026-09-26 选定）：「工程名称 / 当前谱面 ▾」。下拉里列全部谱面（难度、谱面名称、等级、音符数、状态）与操作（复制当前谱面、标完成、新增谱面、回工程管理页）。谱面名称为空或等于工程名称时，当前谱面那段只显示难度。已上传时旁边显示「已上传 · 只读｜复制这张谱面来改」。
- 新增谱面对话框含可选「谱面代码」：走 Apply 闸门（ADR-0014）；硬拒绝则不建这张谱面。已有工程贴别人的 JSON 走这条，不走「新建工程」。
- 复制谱面：同工程内复制出新谱面，谱面代码 / 难度 / 等级照搬，完成标记清空、无上传记录。**谱面名称默认「原显示名（副本）」**（已有同名则（副本 2）…），不跟源谱面同名（用户 2026-09-26）。
- 切换谱面时剪贴板不清空；各谱面的撤销历史互不串。
- 谱面名称为空时，显示与上传一律取当前工程名称（改工程名跟着变）。

## 锁测

- 切换器标签文案纯函数单测：名称为空 / 等于工程名 / 不同；同难度两张。
- 复制谱面单测：源数据逐字段相等（名称除外）、状态字段清空、新 id、名称 = 原显示名 + 「（副本）」。
- 删最后一张被拒：单测。
- 工程内新增谱面贴合法代码：源数据保真；硬拒绝不新增。
- 跨谱面复制粘贴：Playwright 在 Expert 选中 Ctrl+C，切到 Hard Ctrl+V 成功。
