# 01 · 谱面工程管理与启动流程定案

Type: grilling
Status: resolved
Blocked by:

## 来源

用户 2026-09-26：「软件一打开直接是工作台，这合适吗？」想改成先进谱面工程管理页，看最近的工程、新建工程；一个工程默认一张谱面、以后可加多张；管理页能看到各谱面状态；以及工程管理是否要涵盖未来的 Bestdori 上传。取代 [basic-editor issue 26 多谱面工作区](../../basic-editor/issues/26-多谱面工作区.md)（原票只登记「多谱面列表 / 切换 / 隔离」，未 grill）。

## 问题

- 启动落点：工作台还是工程管理页？管理页在应用壳里还是外？
- 谱面工程是什么单位？「一个工程多张谱面」的多张指什么？
- 工作台能否同时开多个工程（issue 26 原想法：打开别人的谱面「抄」配置）？
- 不经管理页直接进工作台时加载哪个工程？
- 建工程填哪些信息？谱面状态怎么记？已上传的谱面还能不能改？
- 与 Bestdori 上传、从 Bestdori 建工程的边界。

## 定案（用户 2026-09-26）

权威 = [ADR-0015](../../../docs/adr/0015-歌曲级谱面工程与工程管理页入口.md)；术语见 `CONTEXT.md`「工作台与配置系统」「谱面长度与谱面工程」两节。

1. **票务**：新开本 effort；issue 26 追加 Answer 指向本票后 resolved。
2. **谱面工程 = 一首歌的容器**：工程信息 + 音频 + 封面 + 谱面时长 + 1..n 张谱面；音频不同就是两个工程。
3. **工程管理页**是应用壳导航第一项、启动默认落点，快捷键 `⇧⌘0`，其余页面快捷键不变。
4. **工作台只有一个当前工程**，切工程回管理页；废弃「工程文档标签」。
5. **「抄」**：剪贴板在切换工程 / 谱面时不清空（不做成功能，只是不清）；只读参考画布不做（看别人的谱不如直接上 Bestdori）；长期复用走片段收藏（[basic-editor issue 164](../../basic-editor/issues/164-片段收藏.md)，另行 grill）。
6. **直接进工作台**：打开最近打开过的未完成工程；一个都没有才自动新建「未命名工程」并立即落盘。工程未完成 = 至少一张谱面未完成。
7. **工程信息全部可选**：工程名称、歌手、曲目来源（自定义 / BanG Dream 官方曲 id / LLSIF 曲 id）、音频、封面。没有独立「歌名」字段。新建对话框只露工程名称、歌手、音频、难度。
8. **谱面**：谱面名称（Bestdori `title`；未填时动态跟随工程名称）、难度（工程内可重复）、等级、完成标记、上传记录。
9. **谱面状态**：有上传记录→已上传；否则标了完成（手动标 / 撤）→已完成；否则未完成。**已上传的谱面只读**（可选中、复制、播放），**每张谱面至多上传一次**。要改或再传 = 同工程内复制谱面，副本不带状态。
10. **工作台谱面切换器**：画布顶栏显示「难度 · 谱面名称」，谱面名称等于工程名称时省略；旁边「+」新增谱面。删谱面、改谱面信息在工作台与管理页都能做。一个工程至少一张谱面。
11. **工程管理页首版**：按最近打开排序的列表（工程名称、封面缩略、每张谱面的状态标签）；打开 / 新建（空白、从谱面代码、复制工程、从 Bestdori）/ 编辑工程信息 / 删除（二次确认，不影响 Bestdori 上已发的帖）。不做搜索、筛选、分组。
12. **上传边界**：管理页展示上传记录、作为上传入口；登录、清洗、发帖归 bestdori-integration（ADR-0011 §3）。
13. **从 Bestdori 新建**：来源 BanG Dream / LLSIF / Community（Custom 与空白新建相同，不单列）；拆 [07](./07-从Bestdori新建工程.md)，受 Electron 网络层阻塞；静态演示版隐藏。
14. **不写迁移**：新结构不读、不删旧 `default` 工程；issue 25 的 IndexedDB → 文件后端迁移代码一并移除。
15. **默认口径**（用户确认）：音频页作用于当前工程的共享音频；谱面代码弹窗与导出作用于当前谱面。

## Comments

对话存档（2026-09-26，grill-with-docs）：

- 第一轮：Q1 票务=新开 effort；Q2 工程=一首歌的容器；Q3 管理页=应用壳内第一项；Q4 单一当前工程——用户追问 26 的「抄」需求与标签页性能。回复：标签页主要代价是单例架构重写与每工程约 60–85 MB 解码音频，不是 CPU；「抄」只需读与复制。Q5 用户选「上一个完成了就新建」并反驳「会堆空工程」的担心——用户对：空工程本身未完成，下次复用，最多一个。Q6 上传边界=管理页只展示与入口。
- 第二轮：Q7 选剪贴板跨切换保留，只读参考画布无意义；Q8 最近打开的未完成工程；Q9 状态按谱面记；Q10 字段全部可选；Q11 用户改选「难度可重复」，并指出谱面名称才是上传的名称、默认等于工程名称；Q12 四种新建来源全纳入，Bestdori 来源再加 Community，建议拆出；Q13 用户指出产品未发布、不需要迁移。
- 第三轮：Q14 工程名称即项目名称，Bestdori Custom 的 Title = 谱面名称，丢掉「歌名」；Q15 谱面名称动态跟随；Q16–Q20 通过（Q19 管理页用 `⇧⌘0`；Q18 不写迁移并删 issue 25 迁移代码）。
- 第四轮：用户调整状态——已上传帖子改不了，去掉「已上传 · 有改动」，改为复制谱面后改副本、副本不带状态；提出片段收藏新需求，问是否还需剪贴板保留。回复：剪贴板保留零成本且承担一次性搬运，与片段收藏并存；「配置」与配置系统撞词，改叫「片段」。Q21 已上传只读；Q22 每张谱面至多上传一次；Q23 叫「片段收藏」；Q24 片段收藏开在 basic-editor。
