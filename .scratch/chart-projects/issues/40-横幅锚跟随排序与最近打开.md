# 40 · 横幅锚：跟随排序键 + 打开工程后不滞留老工程

Type: grilling
Status: resolved（2026-10-18 实现落地；真机验收待补）
Blocked by: —

## 来源

用户 2026-10-18 报（工程管理页面主页横幅）：

- a) 「我打开新的工程后，回到工程管理页面主页，唯独横幅展示的还是老工程」；
- b) 「横幅上的『上次打开』我希望跟随排序的『最近打开』、『最近修改』变动。如果是最近修改的话，也需要同步展示最近修改的那个工程」。

## 症状

两条症状同根：横幅（hero）展示哪个工程，与「眼睛看到的排序」脱钩。

- a) 打开序的口径没有 live 化：打开另一个工程后，卡片列表已重排（新打开工程到头），横幅仍停留在挂载时快照的老工程。
- b) 排序键只驱动了**标签**（issue 37：hero 标签切「上次打开 / 上次修改」），没有驱动**展示的工程**：「最近修改」下卡片顺序按 `max(charts.lastModified)` 排，横幅却还是「最近打开」的那个——与 37 修掉的时间戳错位同型，错位从「时间」上升到「工程」。

## 根因

`src/pages/projects/components/ProjectHub.tsx` 的选中锚：

```tsx
const defaultSelectedId = mostRecentlyOpenedId(list);          // 恒为「最近打开」，与 sort 无关
const effectiveSelectedId = selectedId !== null && list.some((p) => p.id === selectedId)
  ? selectedId
  : defaultSelectedId;
useEffect(() => {
  if (effectiveSelectedId !== selectedId) setSelectedId(effectiveSelectedId);
}, [effectiveSelectedId, selectedId]);
```

1. **快照化**：`mostRecentlyOpenedId(list)` 本是活派生，被这个 effect 在挂载时（及选中失效时）固化成 `selectedId` state。之后只要 `selectedId` 仍有效，就以它为准——打开工程改了 `lastOpened`（`CurrentProjectSession.open` → `mutateProject`）且列表重排，锚不重新派生。
2. **保活放大了它**：页面保活挂载（`AppShell.tsx`：所有 page 常驻、切可见性），从主页点卡片播放角标进工作台全程不卸载 `ProjectStartView`，`selectedId` 原样活到回来那一刻。（「新建 → 详情页 → 返回」不复现：详情视图会把 hub 子树卸载，回来重挂载、重新派生——所以用户报的路径是「主页直接进工作台」那类。）
3. **锚与排序键无关是定案**：issue 14 Q11（默认选中 = 最近打开）+ issue 19 #4（hero 默认选中恒为最近打开、不随排序走）+ issue 37 定案复述「hero 默认选中锚不动（仍 = 最近打开）」——b) 要的就是推翻这一条，故本票是 grilling。

**复现实证**（分析期红测，`tests/dom/pages/ProjectHeroAnchorRepro.test.tsx`，3/3 红）：

- a) 种子 p1「Old」= 最近打开、p2「Other」更早；点 p2 播放角标 → `cardOrder` 重排为 `['p2','p1']`（列表已对），hero 仍 `Old详情 ›`（应 `Other`）；
- b) seed「最近修改」+ issue 37 错档种子：`cardOrder = ['p3','p1','p2']`，hero 是 `Alpha`（p2，打开序的头），应 `Mike`（p3，修改序的头）；
- b2) 运行中切「最近修改」：列表重排后 hero 不动，仍 `Alpha`。

## 定案（用户 2026-10-18，「按照你的推荐开始实现」= 采纳下列推荐口径）

1. **b) 的跟随范围 → 推荐 A**：`lastOpened` → 最近打开、`lastModified` → 最近修改；`chartCount` / `name` 下仍显示「最近打开」。与 `projectTimeAt` 的回落规则同源，非时间维度不换 resume 语义。
2. **手动浏览焦点 → 推荐「临时化」**：方向键的手动选中是临时浏览焦点；**排序切换 / 打开工程都清空**、回落排序头；编辑、切页回来不动它。issue 14 Q10「横幅 = 选中卡片投影」在手动浏览期间保持。
3. **眉题 → 推荐「不动**：「继续创作」是角色声明不是时间口径，标签已在 37 随排序切，眉题不变。

## 实现落点（2026-10-18 落地）

- `src/project/projectSort.ts`：新增纯函数 `sortAnchorId(projects, key)`——锚度量走 `projectTimeAt`（时间键取该键、其余回落 lastOpened），并列回退与 `sortProjects` 逐条同构（该键 → lastOpened → id），时间键下锚恒等于展示序的头。
- `src/pages/projects/components/ProjectHub.tsx`：
  - 锚改**活派生** `sortAnchorId(list, sort)`，撤掉「useEffect 把默认锚固化进 `selectedId`」的快照 effect（a 的根因）；选中失效不写 state，渲染期投影回落锚。
  - 两个让位点（定案 Q2）：排序切换走 render 期 state 校正（`prevSort` 比对，照 `useApplyUiLanguage` 的 render 期同步写先例）；打开工程走 `openProject` 包装（hero 主按钮 / hero 谱面按钮 / 卡片播放角标三处出口都经它）。
- `src/pages/projects/ProjectsPage.tsx`：展示序注释同步为 issue 40 口径。
- 既有锁测更新：`tests/dom/pages/ProjectsPageSort.test.tsx`——seed「最近修改」与运行中切换两例的 hero 断言由 Alpha（旧定案「锚不动」）改 Mike（锚跟随）；chartCount 例改为断言回落最近打开。

## 锁测（落地结果）

1. `tests/dom/pages/ProjectHeroAnchor.test.tsx`（新建，8 条）：a 打开后不滞留 / b seed 最近修改 / b2 运行中切换 / c 浏览后打开让位 / d 浏览后切排序让位 / e 数量排序回落最近打开 / e2 编辑工程信息后手动焦点不动（定案 Q2「编辑不动它」）/ f 最近修改下打开不动锚。

3. `tests/static/ProjectHeroAnchor.test.ts`（新建，4 条）：锚是 projectSort 纯函数且经 `projectTimeAt`；hub 调 `sortAnchorId(list, sort)` 且不再出现 `mostRecentlyOpenedId`；不把锚固化回 state；两个让位点在（`setSelectedId(null)` ≥ 2 + `openProject` 包装 + 按钮不直调 `onOpen`）。
4. `tests/dom/pages/ProjectGridKeyboard.test.tsx`（issue 14）：9 条保持绿——方向键浏览期间横幅仍跟手动选中。
- 变异检测：锚撤回落款（`'lastOpened'` 写死）→ b/b2/d/f 红；撤 `openProject` 清空 → c 红 + 静态计数红；撤排序切换让位 → d 红；「catalog 变化即清手动焦点」→ 仅 e2 红（e2 是该行为的唯一看守）。均已恢复。
