# 27 · 工程主页启动时自动滚到中间

Type: bug
Status: resolved
Blocked by: —

## 来源

用户 2026-10-10 真机反馈 #1：每次打开程序（Electron），工程管理页主页显示时右侧滚动条不在最顶部，而在中间。

## 症状

启动 → 工程主页 → `.pb-page` 滚动容器的 `scrollTop` 已非零（平滑动画滚到中间位置）；用户没有做任何输入。

## 根因

`ProjectHub.tsx:116-121` 的「选中卡片自动滚入视口」effect 只依赖 `effectiveSelectedId`，**没有排除首次挂载**：

1. 工程列表异步到达（`ProjectsPage.tsx:73-80` 的 `store.list()`）后，`effectiveSelectedId` 被自动投影为「最近打开的工程」（`ProjectHub.tsx:55-61` + `mostRecentlyOpenedId`）；
2. 该 effect 随即对这张卡片 `scrollIntoView({ block: 'nearest', behavior: 'smooth' })`；
3. 卡片位于 hero 与新建区**下方**的「全部工程」网格中，在首屏之外 → 页面被滚下去。

这个 effect 的本意是服务方向键导航（`ProjectHub.tsx:82-113`），但触发条件远宽于实际需求。与 Electron 窗口恢复、虚拟列表、图片异步撑高无关（都已排除）。

## 定案（用户 2026-10-10）

**只在键盘导航真正移动选中项时才滚**，启动 / 首次挂载不滚。

## 修法

- 把滚动从 effect 挪出去：只在键盘导航 `setSelectedId(next)` 处触发（或加「本帧来自键盘」标记）；
- `ProjectHub.tsx:59-61` 的固化 effect（把默认投影值写回 state）不得触发滚动；
- `behavior: 'smooth'` 保留与否随实现定。

## 锁测

1. `tests/dom/pages/ProjectGridKeyboard.test.tsx`（修正票面笔误为对应的主页卡片网格测试文件）：方向键移动仍滚入视口（既有行为不变）+ 新增「挂载后未按键则不发生滚动」—— jsdom 里 stub `scrollIntoView` 记调用次数断言 0 次。
2. jsdom 无布局、测不到真实 `scrollTop` → **真机验收**：冷启动进工程主页，滚动条在最顶部；按方向键仍能跟随高亮。
