# 32 · 工程详情页撤「复制工程」常驻钮

Type: chore
Status: resolved (2026-10-14)
Blocked by: —

## 来源

用户 2026-10-14：「工程管理详情页面『复制工程』这个按钮，是否有必要存在？它算是一个频繁到需要单独放出来的按钮吗？」

## 症状与根因

复制工程有三处入口、最终都调同一 `copyProject(id)`：详情页头部动作行常驻钮（`ProjectDetail.tsx:119`）、hub 卡片 ⋯ 菜单（`ProjectsPage.tsx:418`）、hub 新建四联 tile / 分裂按钮菜单（弹窗选「复制哪个工程」）。详情页这枚是唯一常驻可见的，但复制工程是低频「以旧工程为模板新建」动作，归属地是 hub；且点完视图**瞬移到副本**并把它设为当前工程（issue 23 定案），常驻钮的误点成本高。

## 定案（用户 2026-10-14）

撤掉详情页常驻钮；复制保留 hub 两处（卡片 ⋯ 菜单 = 一步复制该工程；新建弹窗 = 选源新建）。详情页动作行收缩为 打开(primary)/编辑/删除。撤后无场景走不通：回 hub → 卡片 ⋯ → 复制，两次点击。

## 修法

1. `ProjectDetail.tsx`：删头部动作行复制钮；`onCopy` prop 链（`ProjectsPage.tsx:454` 传参）一并清；`Copy` import 无其他用途同清。
2. `.pc-detail__actions` 的 CSS 不变量（`height:96px` / `flex:0 0 auto` / 不折行，见 `tests/static/ProjectDetailHeadLayout.test.ts`）不受影响——四钮变三钮即可，不动样式。
3. hub 两处入口与 `projects.duplicate` 文案键不动（hub 卡片菜单仍在用）。

## 锁测

1. **`tests/dom/pages/ProjectCreateCopyLanding.test.tsx` 两条复制用例（:120、:142）现经详情页按钮触发**，改走 hub 卡片 ⋯ 菜单的「复制工程」项；三条落点断言（不跳工作台 / 详情视图切副本 / 副本成为当前工程）与"不重放滑入动画"断言不变。
2. 防回潮 DOM 断言（可并进上文件）：详情页头部不存在「复制工程」钮，hub 卡片菜单仍存在。
3. `ProjectListKeyboardNav.test.tsx` 只用 `.pc-detail__actions` 定位「编辑工程信息」，不受影响；实现时 grep `projects.duplicate` 全 `tests/` 确认无其他引用。
