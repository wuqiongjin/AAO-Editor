# 11 · 无封面工程的封面背景色丢失（浏览器 / IndexedDB）

Type: bug
Status: open
Blocked by: 08

**来源**：用户 2026-09-26 #3（截图：主页面与详情左侧列表无背景色，点进条目后又有）；2026-09-27 确认**运行环境 = 浏览器**（走 `IndexedDbProjectBackend`）。

**症状**：同为无封面工程，有的条目是一片空白（无占位色），选中/进入详情后又出现背景色；「Fire Bird（副本）」尤其明显。

**已查事实**：`Cover`（`src/pages/ProjectsPage.tsx` L94-114）无条件给 `linear-gradient(135deg, hsl(hue 70% 55%), hsl((hue+40)%360 65% 35%))`，色相由 `projectCoverHue(id)` 从工程 id 派生，**与选中态无关**——所以「选中就有色」不是分支差异，只可能是背景被**后续声明覆盖**或 `backgroundImage` 被设成无效值。

**诊断（本票第一步，先别改代码）**：在浏览器里对每个渲染点（`pb-grid` 卡片 / 详情左侧列表项 / hero / 详情头图）打表 —— 工程是否有 `coverBlob`、`useCoverUrl` 返回值、`Cover` 实际 style。优先验三个假设：① `coverBlob` 是空 Blob / 上一次 `objectURL` 被 revoke → `backgroundImage: url('')` 压掉了 gradient；② `projectCoverHue` 得到 NaN（id 异常）→ `hsl()` 非法 → 整条背景声明失效；③ CSS 里 `.pb-cover` 的某条规则在无图时被 `background: none` 覆盖。

**修法（按诊断结果落到具体一行）**：候选方向 —— `Cover` 只在 `useCoverUrl` 返回非空时设 `backgroundImage`，否则回退 gradient；`useCoverUrl` 对空 Blob 返回 undefined；移除/修正覆盖 gradient 的 CSS。

**锁测**：
- `tests/dom/pages/ProjectCoverFallback.test.tsx`（依赖 08）：无 `coverBlob` → 断言 inline style 含 `linear-gradient` + 工程名首字母；有 `coverBlob` → 断言 `backgroundImage` 用该 Blob 的 objectURL；**空 Blob → 回退 gradient 且不设 backgroundImage**（这条直接锁住本 bug）。
- `tests/unit/chart/project/ProjectCoverHue.test.ts`：锁「对所有合法 id 返回 0..359 的有限数」（NaN 护栏）。
- 视觉仍需人工/截图门票（jsdom 无布局引擎，量不出「看不见」）。
