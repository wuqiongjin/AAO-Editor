# 18 · 只读浮条的「复制这张谱面」键暗色下不可读（引用了不存在的 token）

Type: bug
Status: resolved

**来源**：用户 2026-09-28，在 17 票收尾盘点时被报出，答复「先记下来，单独修」。

**症状**：工作台「已上传只读」浮条里的复制键，暗色主题下**浅字压浅青**（实测 1.8:1，读不出来）；
亮色看着正常（5.0:1）—— 所以从 chart-projects 06 落地起一直没人发现。

**根因**：`.readonly-toast__copy-btn` 的 `color: var(--accent-contrast)` —— 这个 token 在
tokens.css 里**根本不存在**，CSS 声明整条失效，文字色落到继承的 `--text`
（亮 #1f2633 / 暗 #e6e9ee）。死引用不报错、不进 lint、不影响布局，只能靠扫。

**修法**：改用主按钮那一对 —— `--accent-btn` 底 + `--accent-btn-text` 白字
（hover 走 `--accent-btn-hover`）。不能简单改白字：白字压在亮/暗两档 `--accent` 上只有
3.0:1 / 2.1:1，都过不了 AA；换深档后亮 7.9:1 / 暗 5.3:1。

**锁测**：
- `tests/static/TokenUsageWiring.test.ts`（新）：扫 src/**（css + tsx/ts）里每一个 `var(--x)`，
  要求全仓有定义 —— CSS 声明（裸 `--x:`）/ 内联 style 的键（`'--x':`）/ `setProperty` 三处都算；
  带兜底的 `var(--x, fallback)` 不豁免（兜底只是掩盖）。当前零例外。
  反向验证过：把 `--accent-contrast` 塞回 AppShell.css，这条断言立刻变红。
- 视觉：headless 出图复验（亮/暗），按钮计算样式读到 `rgb(255,255,255)` on
  `rgb(7,94,131)`（亮）/ `rgb(3,105,161)`（暗）。
