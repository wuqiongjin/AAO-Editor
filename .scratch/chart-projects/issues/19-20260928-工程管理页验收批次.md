## #1 hub ↔ detail 切换动效（feature）

**Status**: open

**症状**：主页进详情、详情回主页都是硬切。
**根因**：`ProjectsPage.tsx:488` 按 `detailId` 二选一直接渲染，两棵树挂 / 卸之间无过渡，页面也没有方向状态。
**修法**：
- 方向状态 `navDir: 'forward' | 'back'`（`goDetail` 置 forward、`goHome` 置 back）；视图包裹层 `key = detailId ? 'detail' : 'hub'`，详情内切工程不重放动画。
- `.pm-view--forward / --back` + 两个 keyframes（`translateX(±18px)` + opacity，170ms `var(--ease)`，`both`）；**末帧落 `transform: none`**（残留 transform 会给内部 sticky/fixed 建包含块）。
- 普通 CSS animation → `tokens.css` 全局 `prefers-reduced-motion` 自动兜底。
**锁测**：动效本身 jsdom 测不了 → DOM 测试锁 class 接线（点卡片 → `pm-view--forward`；点「主页」→ `pm-view--back`；详情内换工程不回 forward）+ 静态断言两份 keyframes 末帧 `transform: none`；观感走人工门票。

## #2 难度+等级徽标就地编辑（feature）

**Status**: open

**症状**：详情谱面行的「难度+等级」徽标不可点；改难度 / 等级只能点行尾铅笔开弹窗。
**根因**：`.pc-chart__diff` 是纯 `<span>`（`ProjectsPage.tsx:559`），零交互。
**修法**：徽标变按钮 → 锚定小浮层（复用 `Menu` 的 portal 定位范式）：5 个难度色块 + 等级输入；点色块即时提交 diff；等级 Enter / blur 提交；提交走 `mutate` + `updateChartInfo`（已上传谱面本就是 no-op，点击改为 toast 提示）。
**锁测**：DOM 测试：点徽标 → 浮层出现；点难度块 → memory backend 读回新 diff；等级回车 → 落库；已上传谱面点击只有 toast、不出浮层。

## #3 详情页封面首帧闪（bug）

**Status**: open

**症状**：每次切到详情页，封面先显示占位渐变、随后才出图（"闪一下"）。
**根因**：`useCoverUrl`（`CoverField.tsx:20-32`）在 `useEffect` 里才建 objectURL → **首帧必然是占位渐变**；且 hub 进详情时整棵 hub 卸载 → URL 被 revoke，详情重新建 URL + 重新解码（`ProjectCoverFallback.test.tsx:113-114` 现锁着"同一 Blob 每挂载建一份"）。
**修法**：模块级 `WeakMap<Blob, string>` 缓存 + 渲染期同步取（`createObjectURL` 是同步 API）：同一 Blob 全应用复用同一 URL，首帧即有图、不重复解码；不再按挂载 revoke。刚选的 File（临时预览）另走 `useEphemeralCoverUrl`（保持现行为：挂载建、卸载撤）。
**锁测**：改写 `tests/dom/pages/ProjectCoverFallback.test.tsx`：同一 Blob 的多个 Cover 实例只建 **1** 个 URL 且首帧即带 URL（不再出现渐变）；换 Blob 才新建；空 Blob 仍不建 URL。`CoverField.test.tsx` 的临时预览回收行为不变。

## #4 启动台排序（feature）

**根因**：`reload()` 写死 `sortProjectsByLastOpened`（`ProjectsPage.tsx:306`）；工程级没有修改时间字段；排序无持久位。
**修法**：

- `AppSettings` additive `projects: { sort }`（默认 lastOpened；default/merge/update/ConfigProvider setter 全接线；导入经 `loadSettings` 自动归一化）。
- 启动台「全部工程」标题行右侧放紧凑 `<select>`，改动即写 settings 并重排。
- hero / 默认选中恒定 = `lastOpened` 最大的工程（不受排序影响）；方向键导航按显示序。
**锁测**：新增 `projectSort.test.ts`（四键序 + 并列回退 + 派生口径）；`projectCatalog.test.ts` 既有排序断言保留；DOM 测试：换排序 → 卡片序变化且写回 settings；hero 默认仍是最近打开。

## #5 卡片流式铺满（bug）

**Status**: open

**症状**：全部工程卡片行右侧留一段空白（截图见用户报障 2026-09-28）。
**根因**：`.pb-grid` 固定 `repeat(auto-fill, 172px)` + 封面写死 172px（`ProjectsPage.css:87` / `ProjectsPage.tsx:799`），一行凑不满 172px 的余量全留在右侧。
**修法**：`repeat(auto-fill, minmax(172px, 1fr))`；`Cover` 加流式档（`width: 100%` + `aspect-ratio: 1`，占位字号仍按名义 172 派生）；hero / 详情 / 侧列表继续固定尺寸。
**锁测**：DOM 断言网格卡封面带流式样式；静态断言 CSS 为 `minmax` 而非固定轨道；像素（末列贴边）走人工门票 / Playwright 实测。

## #6 副本编号（bug）

**Status**: open

**症状**：同一工程连复制两次，名字都是「xxx（副本）」；复制副本会叠成「xxx（副本）（副本）」。
**根因**：`duplicateProject`（`projectCatalog.ts:93`）无脑拼「（副本）」且不去重；谱面复制早有 `uniqueCopyTitle`（`:148`）但没接到工程复制。
**修法**：`duplicateProject` 增 `taken: readonly string[] = []`，命名改走 `uniqueCopyTitle(projectDisplayName(src.name, untitled), taken)`；`ProjectsPage.copyProject` 传入当前全部工程显示名（以 `store.list()` 为准）。
**锁测**：`projectCatalog.test.ts` 扩：同源复制两次 →「（副本）」「（副本 2）」；复制副本 →「（副本）（副本）」叠加、不剥旧后缀（2026-09-28 修订，原定「（副本 2）」已推翻）；叠加重名 →「（副本）（副本 2）」；标记随界面语言：en UI →「 (Copy)」「 (Copy 2)」半角、未命名拼空格（zh 全角不变，2026-09-28 拍板）。
