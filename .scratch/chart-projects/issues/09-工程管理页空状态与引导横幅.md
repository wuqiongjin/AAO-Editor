# 09 · 工程管理页空状态与引导横幅

Type: feature
Status: open
Blocked by: 08

**来源**：用户 2026-09-26 #1（「布局太丑…横幅也没了」）；用户 2026-09-27 Q1=A。

**症状**：一个工程都没有时，工程启动台只剩「新建」两个 tile 与空的 `pb-grid`（大片留白），没有任何引导；顶部横幅（`pb-hero`）也整块不渲染，页面视觉塌陷。

**根因**：`src/pages/ProjectsPage.tsx` 的 `ProjectStartView` 没有空状态分支；hero 的渲染条件是 `resume = list.find(isProjectUnfinished)`，无工程 → `resume` 为 falsy → 整个 section 不渲染。仓里已有 `src/ui/EmptyState.tsx`（音频页在用），此页没用。

**定案（用户 2026-09-27）**：Q1=A —— 横幅位显示**引导横幅**（与有工程时的 hero 同位置、同尺寸，视觉不塌陷），空网格区用 `EmptyState` 给「创建第一个工程」的引导。

**修法**：
- `ProjectStartView` 里把「无工程」单独分支：`projects.length === 0` → 渲染 `GuideBanner`（新组件，占位 hero 同一节点）+ 网格区 `EmptyState`（主行动 = 新建空白工程）。
- 「无工程」之外（有工程哪怕全已完成）横幅必须常显 —— 内容跟随选中卡片，见 14；本票不重复做。
- 文案进 `src/i18n/messages/zh-CN.json`，不硬编码。

**锁测**：
- `tests/dom/pages/ProjectsPageEmptyState.test.tsx`（依赖 08）：list=[] 时断言引导横幅节点存在 + EmptyState 引导文案 + 主行动按钮；list=[单个已完成工程] 时断言 hero 仍渲染（防「横幅没了」回归）。
- 视觉几何（占位不塌陷）jsdom 测不了 → 人工门票：并列截图（0 工程 vs 1 工程）对比 hero 区高度一致。
