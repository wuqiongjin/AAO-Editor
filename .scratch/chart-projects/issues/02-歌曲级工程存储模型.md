# 02 · 歌曲级工程存储模型

Type: feature
Status: open
Blocked by:

## 来源

[01](./01-谱面工程管理与启动流程定案.md) 定案 2 / 7 / 8 / 14；[ADR-0015 §1 / §5](../../../docs/adr/0015-歌曲级谱面工程与工程管理页入口.md)。

## 要做

- `ChartProject`（`src/chart/project/ChartProject.ts`）从「一份 notes + 时长 + 音频」改为：工程信息（工程名称、歌手、曲目来源、封面）+ 音频 + 谱面时长 + `charts[]`；每张谱面 = id、谱面代码源数据（ADR-0014 保真口径不变）、谱面名称（可空）、难度、等级、完成标记、上传记录（可空）、**上次修改时间**（不存创建时间）。
- 存储后端（IndexedDB 与 Electron 文件后端）支持列出全部工程、按 id 读写、删除；记录「最近打开时间」。封面与音频一样和 JSON 分离存字节。
- 新 `schemaVersion`；旧 `default` 工程不读、不删。
- 删除 issue 25 的 IndexedDB → 文件后端迁移代码（`ChartProject.ts`、`electron/main.cjs` 相关分支及测试）。
- 本票只改存储层与类型；UI 仍只操作一个工程，由 03 接入。

## 锁测

- `tests/platform/electron/ChartProject.test.ts`：改为多工程读写 / 列表 / 删除往返；删掉迁移用例。
- 新增 `tests/unit/chart/project/` 下的工程记录往返测试：多谱面、同难度两张、谱面名称为空、有 / 无封面音频，保存再读回逐字段相等；未知字段按 ADR-0014 保留。
- 旧 `schemaVersion` 的记录读回为「不存在」、磁盘文件不被删除。
