# 15 · 音频归属谱面工程（唯一入口收到工程管理页）

Type: grilling
Status: open
Blocked by: —

**来源**：用户 2026-09-26 #6（「音频到底如何与谱面工程绑定？BUG 太多，先定规格」）+ 用户补充场景 a)/b)/c)；用户 2026-09-27 Q13=B、Q18=A、Q12=OK、Q14=同意推荐。

**症状**
- a) 有工程 A、B：进 A 的工作台 → 音频页上传音频 → 切到 B 的工作台 → 音频页显示的**还是 A 的音频**。
- b) 音频与谱面工程之间**看不出任何绑定关系**（音频页是全局单例，不显示所属工程）。
- c) 若让工程管理页管音频，则音频页里的「音频素材」又与它矛盾割裂。

**根因（初步，实现时复现确诊）**：`AudioSession` 是应用级单例；`useChartProjectPersistence` 的恢复判定是 `restoreAudio = projectChanged && !epochChanged`，任何把 epoch 顶掉或走别的入口的路径都会跳过 `hydrateFromProject` → 引擎里留着上一个工程的音频。`AudioPage` 只读 `useAudioSession()`，既不显示也不校验所属工程。

**冲突提示（已在会话中告知用户）**：本次方案推翻 `CONTEXT.md` L199「音频页承载当前工程音频导入/换/清除/时长」及其 `_Avoid_: 在工程管理页再做一套音频导入`，并修订 `ADR-0015 §1`。用户 2026-09-27 明确回答：「以前的方案没考虑到谱面工程，想让音频与工程绑定，就无法单独把音频独立出来当一页，这样语义很贵」。

**定案（用户 2026-09-27）**
1. 音频是**工程级资源、唯一入口**：导入 / 更换 / 清除 / 时长全部收进**工程管理页·工程详情**的新「音频」区块；`durationSeconds` 仍是**工程级**（工程内所有谱面共用），有音频锁为音频时长，无音频默认 30s 可手动改 —— 维持现状（Q12）。
2. 「编辑工程信息」弹窗**不动**（仍只管名称 / 歌手 / 曲目来源 / 封面），音频不塞进去（Q18=A）。
3. 音频页移除音频管理，仅剩**键音素材包 + SE 音量**（页面名是否需要随「音效」改名，在实现时按导航语义定，不改 i18n 之外的结构）。
4. 音频**锁**保留：工程内任一谱面有上传记录 → 音频与时长不可更换/清除；提示改为**可解释文案**（指明是因哪张谱面已上传），不再是泛泛的警告条（Q14）。
5. 文档：实现时同步修订 `CONTEXT.md`（音频页、工程信息、音频域三处词条）并修订 `ADR-0015 §1`（或另起短 ADR 记「为何取消音频页管音频」）—— 与代码同步落地，避免文档与行为脱节。

**实现落点**
- `src/pages/ProjectsPage.tsx`：工程详情新增「音频」区块（文件名 / 时长展示 + 上传 / 更换 / 清除 + 锁定态说明）；删除 / 更换时先 flush 再 hydrate，确保**切换工程必同步**（修症状 a）。
- `src/audio/AudioPage.tsx`：移除 `AudioSection`，保留 `KeySoundSection` / `SeVolumeSection`。
- `src/audio/AudioSession.ts` + `src/chart/project/useChartProjectPersistence.ts`：审视 `restoreAudio` 判定与 epoch 来源，补「无音频工程 → 引擎必清空」的不变量。
- `src/pages/WorkspacePage/ChartSwitcher.tsx` 等工作台侧入口如需跳「音频」，改跳**工程详情·音频区块**。

**锁测**
- `tests/unit/audio/AudioSessionProjectBinding.test.ts`（**不依赖 08**）：`hydrateFromProject({ audioName: null })` 后 `audioName/blob` 必为空；有音频时按工程的 blob 恢复；锁定态下 `importAudio` / `clearAudio` 无操作。
- `tests/dom/pages/ProjectAudioSection.test.tsx`（依赖 08）：详情页显示所属工程音频文件名与时长；无音频 → EmptyState + 上传入口；清除 → 回空态；锁定 → 按钮禁用且文案点名「因谱面 X 已上传」。
- `tests/dom/app/ProjectSwitchAudioIsolation.test.tsx`：工程 A 有音频、B 无音频，切换后音频会话不含 A 的音频（把用户场景 a) 直接锁成回归）。
- `tests/static/AudioOwnership.test.ts`：静态断言 `AudioPage` 内不再出现 `importAudio` / `clearAudio` / 音频时长编辑调用。
