# 15 · 音频归属谱面工程（音频页 = 工程音频的唯一管理入口）

Type: grilling
Status: open
Blocked by: 22（作用域 UI 部分；症状 a 的会话不变量、写路径参数化、时长探针不依赖 22，可并行）

**来源**：用户 2026-09-26 #6（「音频到底如何与谱面工程绑定？BUG 太多，先定规格」）+ 场景 a)/b)/c)；2026-09-27 首轮定案（唯一入口收进工程详情）与 2026-09-28 早间定案（详情只读、不做跳转、ADR 主文无需修订）均已被 2026-09-28 晚间的**作用域**一轮**部分推翻**——见定案与被否决方案。

**症状**
- a) 有工程 A、B：进 A 的工作台 → 音频页上传音频 → 切到 B 的工作台 → 音频页显示的**还是 A 的音频**。
- b) 音频与谱面工程之间**看不出任何绑定关系**（音频页不显示所属工程）。
- c) 若让工程管理页管音频，音频页里的「音频素材」会与它矛盾割裂。

**根因（初步，实现时复现确诊）**：音频的存储归属本来就是工程记录（`ChartProject.audioName/audioBlob/durationSeconds`），`AudioSession` 只是当前工程的视图/缓存；`useChartProjectPersistence` 的恢复判定是 `restoreAudio = projectChanged && !epochChanged`，任何把 epoch 顶掉或走别的入口的路径都会跳过 `hydrateFromProject` → 会话里留着上一个工程的音频。`AudioPage` 只读 `useAudioSession()`，既不显示也不校验所属工程。**修法在会话/持久化层，与入口在哪无关。**

**定案（用户 2026-09-28；晚间轮修订 2 / 3 / 8，新增 9 / 10）**
1. 数据归属维持现状：音频与 `durationSeconds` 是**工程级资源**（工程内所有谱面共用；有音频＝音频时长，无音频默认 30s 可手改），本次只定 **UI 入口与写路径**。
2. **音频页 = 工程音频的唯一管理入口**（导入 / 更换 / 清除 / 时长）；工程详情保持**只读展示行**（文件名 · 时长 · 锁提示），**不在详情做管理 UI**。
   - **修订（09-28 晚间）**：作用对象不再是「恒为当前工程」——**默认作用于当前工程，可临时作用于其它工程**（页面作用域机制见 **票 22 / ADR-0015 §6**）。相应地在详情音频行加一枚**「管理音频」跳转 chip**（带 scope 跳过去，**不切当前工程**）；那把一次点击换成"两条写路径 + 一个不在前台的编辑上下文"，账算得过来。
3. ~~音频页新增「当前工程」面包屑（抽公共「工程·谱面上下文面包屑」组件，未来预览页复用）~~ → **改由票 22 的「作用域条 / ScopePicker」承担**（09-28 早间那句"支持传入非当前 context"就是它）。本票只消费该组件，不自己实现；旧名「上下文面包屑」作废（"上下文"已被 React Context 占用）。
4. 进音频页**不再自动 `ensure`**（未实现）：无当前工程（或记住的工程已不存在）→ 音频区块空态「先去工程管理选一个工程」+ 跳转入口；键音素材包 / SE 音量不受影响；不因进页面而新建 / 打开工程（现状进页面会新建「未命名工程」，foot-gun）。作用域失效（条 9 of 票 22）也收敛到这个空态。
5. 工作台 `ChartSwitcher` 菜单增一枚**「音频管理」**（工程级动作组，与「返回工程管理」并列）→ 跳音频页（scope = 当前工程，等价于不带 scope）。
6. 音频**锁**保留：工程内任一谱面有上传记录 → 音频与时长不可更换 / 清除；提示改为**可解释文案**（点名是哪张谱面）；音频变更后**工程详情展示行刷新**（两处显示一致）。
   - **补充（09-28 晚间）**：**锁定工程可以被选为作用域**（进去只读看，将来也能播）。锁只挡「改变共享资源的动作」，不挡「看和听」。反馈形态 = 动作按钮**禁用** + 横幅点名谱面（**不给 toast**——disabled 的按钮本来就不触发点击，两者互斥）。
7. 「编辑工程信息」弹窗**不动**（仍只管名称 / 歌手 / 曲目来源 / 封面）。
8. **写路径参数化**（新增）：音频页**不再直连** `AudioSession.importAudio / clearAudio / setChartDuration`，改为按 `projectId` 的接缝（暂名 `projectAudio`）：`read(projectId)` / `importAudio(projectId, file)` / `clearAudio(projectId)` / `setDuration(projectId, seconds)`，锁判定（`isProjectAudioLocked`）在接缝里**再挡一次**（纵深防御）。两条写规则：
   - **目标 == 当前工程**：先 `flushPersist()`（把工作台正在编辑的谱面落盘，否则读-改-写整条记录会盖掉在飞内容）→ 改记录 → `notifyCatalogChanged()`；并补上不变量「**工程记录的音频与 session 快照不一致 → 必须 hydrate**」。**不要去改 `restoreAudio` 那个布尔**——它承载着别的东西；在会话/持久化层加这条显式不变量。
   - **目标 ≠ 当前工程**：纯 store-direct，不碰 session，只 `notifyCatalogChanged()`（让目录 / 详情行刷新）。
9. **时长探针**（新增）：非当前工程导入也必须拿到时长（有音频 = 音频时长），而唯一解码入口是共享 `AudioEngine.load()`——借它必然顶掉工作台那份。新增**一次性探针** `probeAudioDuration(file): Promise<number>`（离线解码，拿到 `duration` 即丢，不常驻、不进采样缓存）；**scope == 当前工程时也走探针**（真正的播放解码交给条 8 那条"重新对齐 → hydrate"）。音频页永远不持有第二份解码音频。接缝返回值要**留出"解码结果"的扩展位**（票 22 定案 11：将来播放按需解码、用完释放）。
10. 文档：`CONTEXT.md` 音频页 / 工程详情词条补作用域口径（+ 新增「作用域」词条，归票 22）；**`ADR-0015` 需修订**——§后果「音频页作用于当前工程的共享音频」改口径并链 §6（§6 本身归票 22）。

**到达路径**
- 全局入口 = 应用壳**左栏导航**的「音频」（`⇧⌘2`）——所有页面常驻（工程管理页也在内），点它即达音频页，**默认作用对象 = 当前工程**。
- 要改**非当前工程**的音频：**工程管理页 → 工程详情 → 音频行「管理音频」**（带 scope 跳转，不切当前工程）——本票新增的短路径；或仍走旧路径：先进它的工作台（这一步同时把它设为当前工程）→ 左栏「音频」。
- 工程管理页里「正在浏览 / 选中的工程」本身**不参与**（选中 ≠ 作用域，票 22 定案 2 的入口语义）。
- 无当前工程 → 音频页空态给「先去工程管理选一个工程」指引（定案 4）。

**被否决方案（记录理由，防回潮）**
- **收进工程详情（09-27 定案）**：要删可用 UI、推翻已接受 ADR 口径；详情侧管理要么造第二条 store-direct 写路径（独立解码 / 时长跟随 / 与当前工程同步），要么「看一眼详情、管一下音频就把当前工程切了」——两者都贵。
- **详情再加一套直管（双管理面）**：一致性与双写路径的税；09-28 判定不值得。
- **「详情管理 → 跳音频页」**（09-28 早间否决）→ **本票推翻该否决**：当时否决的理由是"显示当前工程则跳转无意义、显示被选工程则强制切换当前工程"，即**跳转必然等价于切当前工程**。作用域机制把这个前提解掉了，跳转不再需要切当前工程，故 09-28 晚间重新采纳。
- **scope ≠ 当前工程时走另一条解码/写路径**（双路：当前走 session、非当前走 store-direct）：正是"双写路径"的旧税，被 `projectAudio` 单接缝 + 探针取代。
- **音频页改非当前工程时先把它设为当前工程**：违背用户诉求（不能切走工作台正在编辑的工程）。

**实现落点**
- `src/audio/AudioPage.tsx`：保留 `AudioSection`；区块头右侧挂作用域控件（来自票 22）；无当前工程 / 作用域失效 → 音频区块空态（键音 / SE 照常）。
- `src/layouts/AppShell.tsx`：`NEEDS_CURRENT_PROJECT` 去掉 `'audio'`（当前为 `new Set(['workspace', 'audio'])`，定案 4 尚未实现）。
- 新增 `src/audio/projectAudio.ts`（或 `src/chart/project/`）：按 `projectId` 的读 / 导入 / 清除 / 改时长接缝 + `isProjectAudioLocked` 复核。
- 新增 `probeAudioDuration`（落点同域；离线解码，不常驻）。
- `src/pages/WorkspacePage/ChartSwitcher.tsx`：菜单加「音频管理」→ `setActivePage('audio')`（当前菜单项为空，定案 5 未实现）。
- `src/pages/ProjectsPage.tsx`：详情行锁文案点名谱面；音频行加「管理音频」跳转 chip；音频变更后刷新展示行（「音频管理」二字不违反 ADR-0015 定案 2——那条约束的是"不开第二个管理面"，不是禁用该词）。
- `src/audio/AudioSession.ts` + `src/chart/project/useChartProjectPersistence.ts`：补「工程记录的音频与 session 快照不一致 → 必须 hydrate」与「无音频工程 → 引擎必清空」两条不变量（修症状 a 根因）。

**锁测**
