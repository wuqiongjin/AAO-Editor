# 26 · 切谱面进工作台画面残留

Type: bug
Status: resolved

## 来源

用户 2026-10-07 反馈：切换谱面后立刻进入工作台，能看到上一个工程谱面的残留画面（几帧的时间），如果在这个几帧的时间点击播放时，仍然播放的是上一个工程谱面的谱面，然后当刷新回到新工程谱面后，会强制回到开头重新播放。

## 症状

1. 在工程管理页（工程详情或启动台）选择某工程/谱面点击「在工作台打开」或「打开」；
2. 工作台激活可见的瞬间，画面残留着上一个工程的音符、轨道与音频状态（约数十至数百毫秒）；
3. 在此窗口期点击播放（或按空格），播放器会启动播放上一个工程的音频与音符；
4. 随后异步的 `store.get` 终于返回，`handleProjectRestore` 执行，画面刷新为新工程，并触发 `stopPlayback()` 和 `setCurrentSeconds(0)`，强制回到开头。

## 根因

1. **切页与数据恢复时序脱节**：`ProjectsPage.tsx` 中的 `enterWorkspace` 在调用 `open(id, chartId)` 后立即执行 `setActivePage('workspace')`，此时只更新了 Context 中的 ID，工作台组件因保活挂载（keep-alive）立即对用户可见；
2. **工作台内的数据恢复是滞后的异步副作用**：`useChartProjectPersistence` 在工作台挂载后才在 `useEffect` 里异步调用 `store.get(wantedProject)`，在这数十毫秒空档期内，工作台完全由上一个工程的内存数据驱动；
3. **残留期可交互导致动作打断与强制归零**：旧状态下允许触发播放，随后滞后的 `handleProjectRestore` 强制调用 `stopPlayback()`、`setCurrentSeconds(0)` 并覆盖音符；
4. **切谱面未复位播放进度**：旧实现中 `handleProjectRestore` 在同工程切谱面时因 `!opts.restoreAudio` 提前返回，未复位播放头；且此前仅改动 `setCurrentSeconds(0)` 而未调用 `seek(0)`，导致引擎内部与滚动条未归零，新谱面点击播放继承了上一首歌曲的播放秒数。

## 修法

1. **进入工作台前置确保数据就绪（方案 A）**：
   - `CurrentProjectProvider` 暴露 `registerRestoreWaiter` 与 `waitForRestore(targetProjectId?, targetChartId?)`；
   - `useChartProjectPersistence` 接入 `registerRestoreWaiter`，实现针对目标工程/谱面的 `waitUntilSettled` 等待机制与 `isSettled` 实时状态检查；
   - `ProjectsPage` 的 `enterWorkspace` 在切页前 `await waitForRestore(id, chartId)`，确保工作台编辑态（音符、代码保真、时长）完全换新后才翻转可见；
   - 工作台内部切换谱面（`ChartSwitcher`）在 `selectChart` 与 `mutate` 换谱面后同样 `await waitForRestore(projectId, targetId)`；
   - `WorkspacePage` 的 `handleTogglePlay` 增加守卫：`!persistence.isSettled` 期间拦截播放触发，双重兜底杜绝过渡期间播错工程；
   - `WorkspacePage` 的 `handleProjectRestore` 与 `handleRecordAudioChanged` 统一无条件执行 `seek(0)` 与 `setMarker(null)`，彻底复位播放头、引擎进度、画布视口与滚动条位置。

## 锁测

1. `tests/unit/project/ProjectSwitchTransition.test.ts`：锁定 `useChartProjectPersistence` 在切换工程/谱面时 `waitUntilSettled` 正确阻塞并等待 `onRestore` 结算，目标不匹配不提前 resolve，已结算目标立即 resolve，同工程切换谱面触发 `onRestore` 且支持进度复位；
2. `tests/static/WorkspaceEntrySingle.test.ts`：静态断言单点进入保持通过；
3. `tests/dom/pages/WorkspaceEntryPoints.test.tsx`：5 个进入工作台入口全绿。
