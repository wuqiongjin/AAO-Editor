# map — bestdori-integration

## Notes

- 目标：让编辑器与 Bestdori 平台互通（官方/社区谱面浏览 → 内置登录直传发布）。
- 事实底座：`docs/research/bestdori-api.md`（只读端点）+ `docs/research/bestdori-community-upload.md`（2026-09-24 写路径实测）。
- 格式互通已在 `basic-editor/issues/02` 定案：编辑器谱面代码与 Bestdori 高度兼容，仅需导出字段规范化。
- 产品形态定案（2026-09-12）：本地客户端（Electron）为唯一正式形态；Web 仅纯前端静态演示（不带 Bestdori 在线功能）。

## Decisions-so-far

- 01 Bestdori API 全量调研（research，resolved）：a 脚本非风险点（再分发才是）/ b 端点齐但无 CORS 需代理 / c 无 OAuth 仅账密会话。
- 02 公开版素材策略（grilling，resolved）：维持现状继续捆绑；版权问题拆 05；公开运营/变现前复审（ADR-0011 §4）。
- 03 谱面浏览的网络架构与数据边界（grilling，resolved）：本地客户端形态 → Electron 主进程网络层为唯一产品通道；静态演示版离线降级（ADR-0011 §1–2）。
- 04 Bestdori 账号授权与上传形态（grilling，resolved）：内置登录直传；密码不落盘、仅本地会话 Cookie、凭据不经第三方服务器（ADR-0011 §3）。
- 05 素材版权与使用边界调查（research，open）：本轮事实结论已记录在票内（无官方授权/粉丝惯例容忍/风险梯度）；待查版权方 guideline 与同类案例后回填 ADR-0011 §4。**2026-10-08 部分回填**：§4 已按 release-pipeline 02 回写「仓库不含二进制 / 发布物仍携带 / 风险档不降」；本票剩下的问题（版权方态度与同类案例）不变。
- 06 社区能力层地基（grilling，resolved 2026-09-30）：能力域目录 `src/community/` + 平台子目录、薄主进程（方案 a）、16 项能力清单、**上传 / 发布**二分、**谱师**、会话与 Cookie 存放；地基先于业务场景落地，实现票 07–11。
- 07 网络 IPC 面与主进程网关（feature，**resolved 2026-10-09**）：主进程只做发请求 + 管 Cookie + 限流；二进制不过 IPC（回落路径，落 `<数据根>/downloads/`，启动清空）；锁测口径改为「域名白名单 + 出口唯一」，取代 03 那条旧口径。落地口径（用户拍板四问 + 文件清单 + 真机三态验收）见票内 Comments —— 主进程 `net.fetch` + 07 自带内存 cookie jar（10 接 safeStorage）+ 重试归 renderer，08 起可解阻塞。
- 08 曲库浏览与官方曲导入（feature，open，T1 竖切）：A 素材默认 / B 官方谱面代码默认关、产出空 Expert 谱面、等级不预填、下载暂存、换音频即把曲目来源置 `custom`。**2026-10-09 归位 = 新建入口四支里的「从官方谱面导入」（12 票）**；换音频的落点是 `src/audio/projectAudio.ts`（原票写的 `projectCatalog.ts` 已订正）。
- 09 社区帖浏览与导入（feature，**resolved 2026-10-12**）：`post/list` 上拉加载 + 客户端过滤等级难度、谱面名称留空不预填帖子标题、按 `song.type` 处理曲目。**2026-10-09 归位 = 「从社区谱面导入」**；**2026-10-12 落地**（拍板四问 + 落点 + 真机待验见票内 Comments）：llsif 帖不显示（素材域在白名单外）、工程名 / 歌手 / 谱面名称全空（防回潮锁测）、面板复用官方骨架、筛选自动补扫带 500 条上限（实测校准）。**2026-10-12 第二轮反馈（三条）**：①**筛选加回来**（口径：筛选只作用于已加载条目、不自动补扫；理由是平台的 `search` 是服务端搜索且典型结果很小 —— 实测 habit 4 / BLACK SHOUT 22 / roki 29 条，而 level/diff 拼不进服务端请求）；②**官方面板补同一颗刷新钮**（`refreshSongCatalog` = 清会话模块缓存 + `revalidate` 真拉；此前官方曲库的会话缓存不过期、后台补枪要下次启动才可见）；③搜索占位符改「搜索歌曲标题」。**2026-10-12 验收批次（六条反馈）+ 两处口径修订**：①**撤销**等级/难度筛选与补扫（平台无服务端字段；深 offset 是 O(offset)：47000 处 18.5s → 全量索引 ≈3 小时，不做热窗口票）；②**列表加两层缓存** + 面板「刷新」钮，并**修订 07/14「只缓存 GET」**为「显式 `cacheable` 的读型 POST 也进 json 档（key = URL + body 哈希），跨会话只存第一页」；③发布时间进列表行、预览栏回归官方布局（原型三变体对照选 A，原型代码与截图按先例删除）；④**缩略图根因**：站点对自己上传的文件回 `application/octet-stream`，按 `image/*` 拦导致封面永不进缓存（renderer + 主进程两处一起改成「只拦 text/*，其余交解码器嗅探」）；⑤补上「同步导入谱面」芯片（默认开，关掉 = 空 Expert + 不请求详情）。**2026-10-13 验收回修**：计数单位 条→首（`community.count` / `filterScope` / `emptyFiltered`，对齐官方面板「N 首」；「帖子」这个实体词不动）。
- 10 账号与会话（feature，**resolved 2026-10-14**）：内置登录直传、Cookie 存 `safeStorage`、会话唯一真相、失效 = 写能力变灰而读能力保留。**落地**：`bestdori/account.ts`（单例会话 + `start`/`login`/`logout`；平台明确拒凭据才清本机，离线只留 Cookie）+ `community/sessionPersistence.ts`（三条**零入参**桥）+ 主进程 `communitySession.cjs`（safeStorage 加密落 `<userData>/community-session.bin`，**不支持加密就不落盘**）+ `posts.ts` 的 `username` / `fetchMyPostsPage`（我自己的作品列表）；启动校验挂工程管理页挂载。锁测与真机待验（`net.fetch` 吐不吐 `Set-Cookie`）见票内 Comments。
- 11 发布（feature，**resolved 2026-10-15**）：三步二进制上传（multipart 走网关新请求字段、字节不过 IPC：renderer 递路径、主进程读文件拼体；`ALREADY_UPLOADED` 跳过上传与轮询）+ 必填预检（纯函数，弹窗与能力层共用）+ 静默 sanitize + 一次性实底红确认 + **发布成功写 `upload` 记录**（mutateProject 唯一写入口、只写一次；记录写不进而帖子已发时结果仍 ok + warn）。入口在工程详情谱面行，写能力灰化用票 39 交下来的 CapabilityStatusLine。上传引用经新桥 `project:uploadRefs`（路径 + 字节数 + SHA-1）。真机待验（custom / bandori 各真发一次、无封面可发性、429 阈值）见票内 Comments。
- 12 新建工程的导入入口归类（grilling，resolved 2026-10-09）：用户视角四项 —— **空白创建 / 从本地谱面导入 / 从官方谱面导入 / 从社区谱面导入**；「Bestdori」不进用户文案；官方 / 社区的区分与 `曲目来源` 是两个维度；取代 01-chart-projects 定案 11/13 的三来源。实现落在 08 / 09（本地导入 = 既有复制工程改叫法）。
- 13 2026-10-09 新建入口验收缺陷批次（grilling，resolved 2026-10-09）：#1 主页大卡保留；#2 EN tab 短标签；#3 禁用态；#4 曲库会话缓存；#5/#6 官方/社区 lg 且**同一颗窗改 size**；#7–#11 选曲台原型 B（筛选手风琴、预览在左、同步导入芯片）。不重开 08。
- 14 素材缓存与过期策略（grilling，**resolved 2026-10-10**）：用户反馈「启动全清」——原本只有 downloads/ 暂存（启动清空）+ 会话内曲库缓存，**无跨启动资源缓存**。**定案 + 落地：全量分级缓存（索引 / 详情 / 谱面原文 / 封面与缩略图 / 音频）+ 24h / 30 天 / 1GB 回收 + 缓存取代 `downloads/` 暂存 + 设置页「存储与数据」占用/清除块（不新增侧栏项）**；`electron/assetCache.cjs` + 网关缓存（回退页 1 小时负缓存）已上，全量 2544 条绿。
- 15 选曲列表封面缩略图（grilling，**resolved 2026-10-10**）：站点无缩略图端点（13 #10 实测），缩略图必须本地生成 + 缓存；**形态定案（2026-10-10）：B · 48px 圆角（行高略增，原型对照后拍）**；**已落地**：图片进缓存顺手产 96×96（主进程 `nativeImage`）+ 只读协议 `aao-asset://thumb/?url=…` 读缓存（「与 16 同一条通道」）+ 行内懒加载（提前一屏取、占位 / 淡入 / 无素材与失败两档降级、老缓存自愈）；原型代码拍板后已删。
- 16 导入复用已取素材（grilling，**resolved 2026-10-10**）：**导入 cache-first 已随 14 满足**（网关 binary 命中即回缓存路径，导入侧零改动）；**落地**：Q2 预览缓存优先 —— 封面大图 / 试听本机优先（协议 raw 支只读缓存原始字节，音频含 Range 206/416，未缓存 404 落回直链）、选中即收封面进缓存；音频进缓存仍只有导入一条路（Q2 只承诺封面）。命名去 tsugu：只读协议 scheme 改 `aao-asset`（原 `tsugu-asset`；`aao-` 为占位前缀，产品名未定留后续 issue）、UA 改 `aao-bestdori-*`。
- 17 缩略图加载速度（grilling，**resolved 2026-10-10**，2026-10-10 验收开票）：15 落地版真机验收 —— 缩略图 ~10s/首，根因是**全应用一条串行网络队列**（07 单飞 + ≥400ms 间隔）撞上跨境慢且会 stall 的链路。**拍板 = 选项 3（直链即时显示 + 队列也放宽）+ 素材档 4 并发 / 100ms（API 档仍 1 并发 / 400ms）**；落地：行内「本机优先 → 直链兜底 → 图标」+ 后台并发入缓存 + 封面单独一档 30s 超时；顺带把「一条 stall 阻塞全局」隔离开。**这是对 07「单飞」口径的修订**（当初是为 API 设计的）。
- 18 缓存清理策略可设置与设置页文案（grilling，**resolved 2026-10-10**，2026-10-10 验收开票）：14 那块「社区素材缓存」hint 太啰嗦（内部行话上界面），用户只要「占了多少 + 怎么清」；且回收参数想可配。**拍板 = 可配「闲置天数 + 总量上限」，默认 30 天 / 1GB，改了立即生效（下次清扫就按新值算，不用重启）**；落地：`settings.cachePolicy`（additive）+ `assetCache:configure` 第三条 IPC + 界面只留占用一行与两个数字行，那句口径说明删掉。
- 19 存储与数据：加「打开数据目录」+ 缓存文案与行为对齐（feature，**resolved 2026-10-11**）：新增「打开数据目录」按钮（`dataRoot:open` / `shell.openPath`）；按钮改名「更改数据目录位置」/「使用已有数据目录」；占用只留总占用（删条数与分桶）；两项策略改名「缓存闲置天数」/「缓存上限（MB）」并各配解释性 hint；全文统一用「素材」。
- 20 重复点击已选曲目封面消失（bug，**resolved 2026-10-11**）：`pick()` 无条件重置 `coverReady`，而 `<img src>` 未变不会重发 `onLoad` → 封面永久透明。**修法 = `pick()` 加两处守卫：封面四态只在换歌时重置；详情已到手时重复点击直接 return（详情取失败仍可重跑 = 现有唯一重试入口）**。
- 21 官方选曲预览栏手风琴折叠（feature，**resolved 2026-10-11**，用户真机验收通过）：**定案 = 未选曲时预览区收起（列表占满）、选中展开（180ms 列宽过渡）、再点同一条目收起即取消选中**；落地：三层结构（首列轨道 / `.off-preview` 裁切 / `.off-preview__inner` 钉住 `--off-preview-w`）+ 新 `expanded` 状态（收起只关窗不清内容：动画有东西可滑、再展开不重取详情不重载封面）+ 收尾用延迟 visibility（不用 opacity）+ 试听掐 src 静音 + detail 未到位用等高骨架 + `projects.official.pickHint` 删除。**三个踩坑见票内**（裁切层不能是 `.off-split` / 别用 opacity / `flex:1` 的 flex-basis 会吃掉 width）。副作用：票 20 的守卫退成防御性守卫，其用例已按新口径改写。
- 22 试听播放条：音量可调 + 播放图标居中 + 音频加载/失败三态（feature，**resolved 2026-10-12**）：**定案 = 音量内嵌小滑条（B）且跟随 `settings.audio.volume`（`setAudioVolume`）；播放钮 `padding:0` 正圆 + Play 三角 -1px 光学校正；音频三态 —— 加载中按钮位 12px spinner、失败 RotateCcw 重试（重挂 audio 重走本机→直链；只许 onError 后触发）、i18n `projects.official.audioRetry`**。**已落地 + 验收回修**：`CompactAudio` props 化（volume/onVolumeChange/onRetry + key nonce 重挂）+ `OfficialSongPanel` 经 `useConfig` 接线 + `ui.css`（padding:0 / min-width:0 / nudge）；回修 = 折叠掐 src（src→null）不再闪出 spinner（`spinning` 加 `src != null` 门禁；重展开的真实元数据加载保留 spinner）。
- 23 预览栏布局：栏宽 300px（勾选态不位移）+ 封面居中 + 试听条进自然流（bug，**resolved 2026-10-12**）：**定案 = 栏宽 240→300px + 封面居中放大 180px、整摞文字居中 + 芯片钉 `line-height:14px` + 试听条移进 stack 末项（`align-self:stretch`，禁 `width:100%`）**。**已落地**：ProjectsPage.css 全部修法 + 820px 媒体查询改引用变量；锁测 = Accordion（300px）+ Batch 静态（媒体查询/line-height/stretch）。
- 24 封面加载三态 + 可复用加载组件（feature，**resolved 2026-10-12**）：**定案 = 加载中 12% 微光 + 18px spinner / 失败态「封面加载失败，点击重试」整块可点 / 无封面裸图标；抽 `src/ui/LoadingShimmer` 上收关键帧**（动态预览接入另开票）。**已落地 + 验收回修**：LoadingShimmer 组件 + 封面三态与 `retryCover`（key nonce 强制重挂 + 降级链打回）+ 缓存竞态补判 effect + i18n `coverFailed`；缩略图占位与试听骨架改复用（微光统一 12%）。回修 = **加载动效延迟 150ms**（`useSlowLoading`）：根因是动效绑定「img 未 ready」而 `aao-asset://` 本机命中也异步（定案时「cache 秒开看不到属预期」被实测证伪）—— 缓存秒开零闪感、网络慢路径反馈保留（用户拍板「延迟显示」档，否掉去淡入 / 都做 / 不改）。

## Fog

- （2026-10-10 网络实验 → OSS 镜像搁置）用户代理实测：bestdori 资源走代理后**快非常多** → 17 的「慢」根因是**跨境链路（国内直连）**，不是站点 CDN。**OSS 镜像不做**：① 产品面向全球，海外用户直连本就快；② Electron `net` 不绕系统代理（代码无任何 `setProxy`），有系统代理 / TUN 的用户**自动受益，零代码**；③ 无代理用户由 14/17 的回退链 + 缓存兜底成「只慢一次」；④ 镜像 = 再分发，比本机缓存高一档合规风险（挂 05）。事实修正：社区谱约 **80% 用用户自传的封面/音频**——镜像本来就救不了，只有缓存能救。若将来真实反馈「无代理慢到不可用」，第一步是应用内提示配代理，仍不是自建镜像。
