# 45 · 官方/社区导入：下载中无法取消

Type: grilling
Status: resolved
Blocked by: —

## 来源

用户 2026-10-16 真机 #2：从「官方谱面」「社区谱面」导入时没有取消；音频下载特别长时只能干等，其它操作全无效。

## 症状

点创建后弹窗进入 busy：取消键禁用、关窗被拦、切 tab 不行，阶段文案停在「正在下载音频…」（官方 / 社区同构）。音频未命中缓存时走 120s 超时 × 最多 3 次退避，弱网可空等数分钟。

## 根因

**不是漏做，是当时故意锁死。** `ProjectDialogs.tsx` 注释原话：下载期间不许关窗，因为网关请求已经在飞，关掉会让人以为取消了，结果工程照样建出来。

现状：

- `officialImport` / `communityImport` 编排是一条不能中断的 Promise，无 `AbortSignal`、无取消令牌。
- 网关 `CommunityRequest` 也没有「取消这次 IPC」的通道；超时到点才 abort。
- UI：`busy = stage !== null` → 取消键 `disabled`、`close` 空操作、遮罩关不掉。
- 发布弹窗同一套 busy 锁（对照，不在本票修，除非拍板说一并做）。

取消一旦要做，必须同时定：**关窗算不算取消**、**已写入素材缓存的半成品怎么办**、**abort 之后工程绝不能建出来**。

## 定案（用户 2026-10-16）

取消 = 中止这次下载、**不建工程**；关窗 / 取消键同等。已进素材缓存的文件当缓存留下，不为取消专门清盘。取消后弹窗关掉，其它操作恢复。本轮只做官方/社区导入，发布弹窗 busy 锁另票。

## 实现落点

`AbortSignal` 穿到 `importOfficialSong` / `importCommunityPost`，落盘前若 aborted 就不建。弹窗取消键导入中可用，关窗即 abort。当前这一枪下载会跑完并进缓存，不另开 IPC 取消通道。

## 锁测

`tests/unit/project/OfficialImport.test.ts`（已 abort 不落盘）；`tests/static/NewProjectSourceCopy.test.ts`（取消键不 disabled）。
