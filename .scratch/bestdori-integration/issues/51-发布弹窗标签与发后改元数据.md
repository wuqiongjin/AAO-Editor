# 51 · 发布弹窗：标签、发后改元数据、再打开

Type: grilling
Status: resolved
Blocked by: —

## 来源与诉求

用户 2026-10-26 一批三条（本票 = 同一张弹窗的生命周期）：

1. 发布时要支持携带 Tags（先调查 Bestdori 再决定怎么支持）。
2. 上传的谱面并不是完全无法修改：难度、等级与标签应该可以改；当前没支持。
3. 发布后无法再打开「发布」弹窗（信息比较全）——希望改难度 / 等级 / 标签继续走整张弹窗（可能就不能再叫「发布」）。

描述可选 / 自动生成另见 [52](./52-发布描述可选与自动生成.md)。

## 现状

- 发帖 `POST /api/post` 写死 `tags: []`（`publish.ts`）；`PublishInput` 无 tags 字段；弹窗无标签 UI。
- 发成功写 `chart.upload = {postId, at}` 后：**「发布」按钮卸掉**（`ProjectDetail.tsx`）；再开弹窗会被 `already-published` 挡住。
- 本地难度 / 等级一并冻死：`updateChartInfo` 遇 `c.upload` 直接 return；`ChartInfoDialog` / `DiffLevelBadge` 全锁。谱面本体只读闸门（`chartReadonlyGate`）正确，但元数据被一锅端。
- 产品文案已经承诺「发后只能改难度、等级与标签」（`projects.publish.confirmMessage`、CONTEXT「发布」）。**实现没兑现这条。**

## 根因

不是漏了个输入框，是三层口径拧在一起：

1. **平台**：谱面本体 / 标题 / 歌手 / 曲目 / 描述发后都不能改；谱面帖能改的是 `POST /api/post/edit` 的 `diff` / `level` / `tags`。`rating` 与四条 `warning*` 是**社区故事**的分级 / 内容警告，谱面发帖页没有（见 research §5，2026-10-26 补）。
2. **CONTEXT「发布」**写了「只能改难度 / 等级 / 警告 / 标签」——「警告」是跟着通用 edit 接口抄的，谱面帖并不适用；**ADR-0015 §4 / 「上传记录」**把已上传谱面定义成全面只读。实现跟了 ADR 的一刀切。
3. **入口**：票 11 把「至多发一次」做成「发布按钮消失」。弹窗没有「已发 / 只改元数据」这一态，所以发后那张信息最全的界面也一起没了。

标签本身：Bestdori **支持**，可选，元素是 `{type:"text", data:"…"}` 自由文本（帖 111533 有 8 条；`GET /api/post/tag` 可搜）。**写路径尚未用非空 tags 实测。** 本仓库一直发空数组。

## 定案（用户 2026-10-26 · grill 第 1 轮）

- **Q1** 发后仍用同一张弹窗：标题 / 歌手 / 封面 / 音频 / 音符 / 描述只读，难度 / 等级 / 标签可改。
- **Q2** 元数据只从这张弹窗写。已发谱面的难度徽标、谱面信息弹窗继续锁。谱面本体只读闸门不动。
- **Q3** 标签 = `{type:"text", data}` 自由文本芯片；空数组合法；不造预置目录；自动补全不做也不挡；条数上限等平台拒绝再收。
- **Q8** 标签落在谱面记录上（照 `publishDraft`），复制带走，发布成功后**不清**。`post/edit` 成功后本地 diff / level / tags 与平台对齐。
- **Q10** 先不出布局原型，在现有 `PublishDialog` 上加标签行和已发态。
- **Q6** 账号区钉视口底 → 票 53，不归本票。

## 定案（用户 2026-10-26 · grill 第 2 轮）

- **Q7** 内容警告与 `rating` 本轮不做。它们是社区**故事**的分级 / 敏感内容勾选，不是谱面帖字段（见 research §5）。CONTEXT「发布」里的「警告」实现时改掉。
- **Q11** 谱面行 / 弹窗标题：未发「发布」，已发「社区帖」。已发态主按钮是 **「更新」**（不是「保存」）。第一次发布仍走红底「确认发布」。
- **Q13** 发布成功后**不再清空** `publishDraft`，发后只读展示当时那份描述。不打开就去平台拉帖。
- **Q14** 改元数据不二次确认：点「更新」直接 `post/edit`。
- **Q15** `post/edit` 失败则本地不动、弹窗留着报错；成功后再写本地。

- 谱面本体只读闸门不动。

## 锁测

- `tests/unit/community/bestdori/publish.test.ts`：非空 tags 进 POST body；`post/edit` 只发 `{id,diff,level,tags}`，失败映射为 PublishFailure。
- `tests/unit/project/projectCatalog.test.ts`：tags 读写 / 复制带走 / 发后不清；`updateChartInfo` 对已发仍锁；`updateChartTags` 对已发不动；`updateUploadedChartMeta` 只改已发；Q13 `recordChartUpload` 保留 `publishDraft`。
- `tests/dom/pages/ProjectPublishConfirm.test.tsx`：回车加芯片；已发只读 vs 可改；点更新无二次确认；edit 失败不关窗。
- `tests/static/PublishEntryWiring.test.ts`：已发入口改「社区帖」；hook 接 `editChartPost` + `updateUploadedChartMeta`。
- 真机：非空 tags 发一次 + 发后改 diff/level/tags 各一次（测试帖）——本轮未做。

## Answer

落地：同一张 `PublishDialog` 两态（未发「发布」+ 确认门；已发「社区帖」+「更新」、无二次确认）。标签自由文本芯片（Enter 添加，无自动补全）。发帖带 `tags`；已发走 `POST /api/post/edit`，成功才 `updateUploadedChartMeta`。Q13：`recordChartUpload` 不再清 `publishDraft`。ADR-0015 §4 / CONTEXT「上传记录」「发布」已切开谱面本体 vs diff/level/tags，删掉误抄的「警告」。
