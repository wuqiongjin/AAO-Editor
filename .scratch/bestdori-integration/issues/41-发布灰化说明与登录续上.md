# 41 · 发布灰化说明改挂按钮，未登录点发布续上确认

Type: feature
Status: resolved
Blocked by: —

## 来源

用户 2026-10-15：谱面列表上方「登录后可发布谱面」像孤儿行。本轮 grill（Q1–Q6，用户 2026-10-15）。

## 定案（用户 2026-10-15）

- 未登录仍露出「发布」，看起来禁用，**要点得开** → 登录弹窗（`aria-disabled`，不是原生 `disabled`）。
- 账号行保持动作式「登录」；why 不搬回账号行。
- 「登录后可发布谱面」只挂在「发布」按钮（`title` / 同一 i18n 键）；列表上方常驻行删掉。
- `offline` / `unsupported-runtime` 同样不占列表行，改挂按钮；这两档保持真禁用、不弹登录。
- 未登录点「发布」→ 登录成功 → **直接打开发布确认**；已登录点「发布」同样打开。
- 发布弹窗增加只读身份（昵称为主、账号名小字，与菜单信息头同形）。换号仍走左下角，弹窗内不放退出。
- 登录成功不自动按「确认发布」。

## 修法

`ProjectDetail` 去掉 `CapabilityStatusLine` 挂载；文案函数仍只从该文件的键表取。`SignInDialog` 增加可选 `onSuccess`。`PublishDialog` 读会话画身份行。

## 锁测

1. `tests/static/PublishEntryWiring.test.ts`：详情源码不再渲染 `<CapabilityStatusLine`；未登录发布钮走 `aria-disabled`。
2. `tests/dom/pages/ProjectPublishGate.test.tsx`（新）：未登录无列表上方那句；点「发布」开登录；登录成功后续上发布弹窗且能看到昵称 / 账号名。
3. `tests/dom/pages/ProjectPublishConfirm.test.tsx`：有会话时弹窗出现「将以 … 发布」。
