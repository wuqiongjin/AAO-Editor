# 27 · 社区谱面详情缺少 id 导致导入失败与报错无法关闭

Type: bug
Status: open

## 来源

用户 2026-10-12 反馈 #2：
> 社区谱面，我现在不知道为什么一直导入失败(之前导入成功过1次，然后我把这个导入成功的工程删掉了，后续所有其它社区谱面都导入失败)：
> 弹出如下的报错区域(这个区域还关不掉...)：
> 导入失败
> 导入社区谱面失败，请重试。

## 症状

1. 在新建工程弹窗中选择社区谱面（勾选默认的「同步导入谱面」）点击创建时，100% 报错：「导入失败：导入社区谱面失败，请重试。」
2. 弹窗内的错误横幅（error-banner）没有关闭按钮，切换选曲或重新操作也无法关闭，一直滞留在弹窗中。

## 根因

### 1. 社区帖详情（post/details）响应缺少 `id` 属性触发严格校验崩溃（导入失败根因）
- Bestdori 服务端 API 的 `post/details?id=<postId>` 响应结构为：
  `{ "result": true, "post": { "categoryName": "SELF_POST", "title": "...", "song": {...}, "chart": [...] } }`
  **其内部的 `post` 对象本身不包含 `id` 字段**（列表条目有 `id`，详情对象的 `id` 来自请求参数）。
- `src/community/bestdori/mapping.ts` 的 `toPostDetail(raw)` 实现中：
  ```ts
  const post = toPostCandidate(raw.post);
  ```
  直接将 `raw.post` 传给了 `toPostCandidate`。而 `toPostCandidate` 中执行了硬门槛校验：
  ```ts
  const postId = raw.id;
  if (typeof postId !== 'number' || !Number.isFinite(postId)) return null;
  ```
  因为 `raw.post.id` 是 `undefined`，`toPostCandidate` 恒定返回 `null`，导致 `toPostDetail` 恒定返回 `null`。
- `fetchPostDetail` 随即抛出 `invalid-response` 错误。`importCommunity.ts` 的统一错误翻译器对 `invalid-response` 缺省回退为 `t('projects.community.err.generic')`（即「导入社区谱面失败，请重试。」）。
- **用户此前导入成功 1 次的原因**：用户此前导入成功时关掉了「同步导入谱面」开关（`withChart: false`）。关掉该开关时，编排层直接跳过 `fetchPostDetail`，因而能成功建工程；后来重新打开弹窗时该开关恢复为默认的勾选状态，便持续 100% 失败。

### 2. error-banner 无重置与关闭机制（报错关不掉根因）
- `ProjectDialogs.tsx` 的 `error` 状态挂在 `NewProjectDialog` 上，错误横幅无关闭按钮。
- `CommunityPostPanel` / `OfficialSongPanel` 发生选曲变更、Tab 切换时，未通知父组件清空 `error`，导致错误横幅永久挂死在底部。

## 修法

1. **领域映射修补**（导入崩溃根因）：
   - `fetchPostDetail(transport, postId)` 在解析时，将 `postId` 透传或合并入待解析对象（例如 `toPostCandidate({ ...raw.post, id: postId })`），确保 `PostCandidate` 正常产出。
2. **错误提示交互优化**（用户拍板：改用全局 Toast）：
   - 废除弹窗内笨重且易残留的 `error-banner`，导入失败时统一调用全局成熟组件 `showToast(errorMessage, 'danger')`；
   - 弹窗内无需维护脆弱的 `error` 状态，报错自动带 5s 延时淡出和右上角 `✕` 手动关闭，彻底根除「关不掉、卡死在界面」的问题，并与 ADR-0018 的警告 Toast 出口保持一致。

## 锁测

- 单元测试：`tests/unit/community/bestdori/posts.test.ts` 新增对真实 Bestdori `post/details` 载荷（`post` 对象无 `id` 字段）的测试用例，断言 `toPostDetail` 能正确补齐并解析。
- 集成测试：`tests/unit/project/CommunityImport.test.ts` 补充带真实详情载荷的完整导入断言，验证 `importCommunityPost` 成功创建工程。
- DOM 测试：`tests/dom/pages/ProjectNewSourceTabs.test.tsx` 验证点击关闭按钮或切换选曲能清空 error-banner。
