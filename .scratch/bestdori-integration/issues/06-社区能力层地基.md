# 06 · 社区能力层地基（分层 / 能力清单 / 术语）

Type: grilling
Status: resolved

## 来源

用户 2026-09-30：先为 Bestdori 集成打**基础能力**的地基，之后再按业务场景（管理页「从 Bestdori 导入」、谱面上传、未来的谱面浏览）调用。
底座：ADR-0011（产品形态 / 网络边界 / 凭据红线）、`docs/research/bestdori-api.md`（只读端点）、`docs/research/bestdori-community-upload.md`（写路径实测）。

## 已定

- **目录**：能力域 `src/community/`，平台做二级目录 `src/community/bestdori/`（沿用 `src/upload/bestdori/` 既有形态）。跨平台接缝 = 中立领域类型 + 一个 transport 接口；**不做**动态注册表 / 插件加载器（留缝不建框架）。
- **分层 = 薄主进程（方案 a）**：主进程只做「发 HTTP + 管 Cookie + 限流」的通用网关；端点、领域转换、搜索跑在 renderer，靠注入 transport 收发，便于单测。
- **二进制不过 IPC**：主进程把音频 / 封面落到数据根下的**下载暂存**后回一串路径，不回字节流。
- **能力清单**（16 项，编号见下）：曲库索引 / 歌曲详情 / 官方谱面代码 / 官方音频 / 官方封面 / 社区帖列表·搜索·分页 / 社区帖详情 / 按谱师列作品 / 登录·登出·会话 / 当前用户 / 二进制上传三步 / 发帖 / 改帖元数据 / 限流·重试·超时·响应校验 / 可用性探测 / **领域映射**（Bestdori 形状 → 中立领域对象）。
- **暂不做**（能力上可行，非技术阻塞）：点赞（范围）、评论（= 回复帖，需整套回复列表模型）、注册（替用户在第三方站开户，责任边界不清）。
- **会话**：Cookie 存 Electron `safeStorage` 加密；能力层持**一个**会话对象作唯一真相，登录成功与启动时各查一次 `user/me`；失效 = 写能力变灰、保留读能力，不弹窗打断。**不给**手动粘贴 Cookie 的入口。
- **术语**（已入 `CONTEXT.md`「社区互通」节）：社区平台 / 曲库 / 社区帖 / **谱师** / **上传（字节）** / **发布（发帖）** / 下载暂存。
- **节奏**：沿用 map 的三期（通道 → 浏览 → 登录上传），但在 T1 里**竖切一刀**：官方曲 → 建工程（音频 + 封面 + 一张空谱面），端到端验证通道、限流、暂存、降级。

## Fog

- Cookie TTL / 多点登录、`token` 失效的确切返回形态、429 阈值 → `bestdori-api.md` §8，实现期实测。
- 首次竖切是否需要真实账号登录，取决于 T1 切到哪一步。
