# 40 · 换账号后左下角仍显示上一份身份

Type: bug
Status: resolved
Blocked by: —

## 来源

用户 2026-10-15 真机：登录一次 → 退出 → 换另一账号登上，左下角账号行仍是上一份。本轮 grill 定案见对话；实现按下列修法。

## 症状

B 的登录 POST 成功（弹窗关），账号行仍展示 A 的昵称。Cookie 已是 B，界面身份是 A；若此时发布，帖子会挂在 B 名下。

## 根因

网关把 **所有 GET json** 按 URL 缓存 24h，键不含 Cookie。`GET /api/user/me` 是会话身份，A 登录写入的副本在登出后仍被当作新鲜；`verify()` 不带 `revalidate`，换号后读到 A。能力层单测走假 transport，锁不住这条。

## 修法

1. 网关：`/api/user/me` **不读不写**素材缓存（会话身份不是曲库这类共享资源）。
2. `account.ts` 的 `verify()` 一律 `revalidate: true`（登录 / 启动校验都走它）。

## 锁测

1. `tests/platform/electron/CommunityNetGateway.test.ts`：`GET /api/user/me` 连打两次都进网络；同目录下普通 GET json 仍命中缓存。
2. `tests/unit/community/bestdori/AccountSession.test.ts`：登录后那条 `user/me` 带 `revalidate: true`。
