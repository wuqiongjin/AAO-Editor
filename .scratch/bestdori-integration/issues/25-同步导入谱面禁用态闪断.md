# 25 · 「同步导入谱面」禁用态闪断

Type: bug
Status: resolved 2026-10-12
Blocked by: —

## 来源

用户 2026-10-12 验收反馈 #6 + 本轮追问原话：「就因为是转瞬即逝的，所以看起来像是有 BUG 一样，闪了一下。」

## 症状

点开一首歌（换歌 / 从收起态展开）时，「同步导入谱面」按钮瞬间变灰禁用并加微光，detail 到位后恢复 —— 用户观感「像 BUG 一样闪了一下」。

## 根因

`OfficialSongPanel.tsx:333` `disabled={detail == null}`：`pick()` 换歌即 `setDetail(null)` 再拉 `fetchSongDetail`，拉详情期间禁用（票 21 验收回修定的骨架态，`is-loading` 微光 + `aria-busy`）。这是**设计态、不是 bug**，但闪断观感差。且开关本身并不依赖 detail：`toggleSync` 只用 `selected`（`:173-181`），`onSelectionChange` 与「创建」按钮本来就另行等 detail（`:143-145` + `ProjectDialogs.tsx:66-67`）—— 禁用并没有在保护什么。

## 定案（用户 2026-10-12）

去掉 detail 门禁：**detail 未到位也允许勾选**（「创建」仍等 detail，语义不变）；加载信号由试听条骨架微光承担，按钮不再闪灰。

## 修法

- `OfficialSongPanel.tsx:326-338`：删 `disabled={detail == null}` 与 `is-loading` 微光 / `aria-busy`；
- 若需给读屏留加载信号：用**已存在但无人使用**的 `projects.official.detailLoading`（zh-CN「正在取这首曲子的信息…」）挂一个 `role="status"` 文本（默认不加，落地时按需要二选一）。

## 锁测

1. `tests/dom/pages/OfficialPickerPreview.test.tsx`：detail 卡闸门（`installFakeBridge({ holdDetail: true })`）时点开关 → `withChart` 真变、`aria-pressed` 同步；`onSelectionChange` 仍不上抛（「创建」依旧禁用）；
2. 真机：点开歌曲，开关不再出现灰禁用闪断；试听骨架微关照旧。
