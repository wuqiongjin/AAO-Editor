# 60 · 社区列表与预览的信息层级（artist 入列）

Type: feature  
Status: resolved  
Blocked by: 59（同一面板，一起改）

## 背景

用户反馈两点：

1. 从社区导入的谱面列表条目需要展示 artist（歌手），因此要重新设计行内信息布局 —— 尤其是展开左侧预览栏、列表收窄之后。
2. 预览栏里「谱师」与「artist」的排布要调整。

## 根因（2026-11-26 实测，真实 CSS + 200 条真实帖子）

1. **行骨架是为两个事实设计的**：照官方面板的「标题 + 副行」，社区版把副行给了谱师，artist 从没渲染（`PostCandidate.artists` 一直有值）。
2. **列宽预算被右列吃死**：1280px 展开预览后列表 566px，右列（`#id` / 难度芯片 / 日期）实测固定占 172px，文本列只剩 **282px**。200 条真实数据：标题 p90 22 字、谱师 p90 13 字、歌手 p90 24 字；「谱师 · 歌手」一行 p90 约 39 字，282px 只放得下约 23 个汉字 → 必然折行。
3. **行高会跳**：不截断时，两行合并在 1280 / 900 / 860 三档窗宽下行高在 66 与 82 之间跳；三行不截断更差（67↔83）。
4. **预览栏两个「人」同档同样式**：谱师与 artist 共用 `.off-preview__artist`、同字号同颜色、无标签、上下堆叠 → 只能靠顺序猜谁是谁。
5. **数据源不一致**：bandori 帖的 `post.artists` 是谱师自填，26 条样本里 5 条是 `ras` / `91` / `ykn`；而导入后工程的 artist 用的是曲库官方乐队名（`communityImport.projectMeta`）→ 列表/预览写 `ykn`、建出来是 `Roselia`。另有 10/26 条 bandori 帖标题与官方曲名无关（`神秘` → `FIRE BIRD`），artist 确实是识别歌曲的关键补充。

## 原型对照（1280px 展开态，真实 CSS）

| --- | --- | --- |
| 现状（两行，副行折行） | 282 | 66 / 82 跳 |
| 两行合并（歌手 · 谱师），不截断 | — | 66 / 82 跳 |
| 三行，不截断 | — | 67 / 83 跳 |

变体结论取自 `.scratch/bestdori-integration/prototypes/community-row.html`（临时产物，按先例不入库）。

## 定案（用户 2026-11-26）

- **Q2=A**：三行文本（标题 / 歌手 / 「谱师 · X」）+ 右列拆两行（难度芯片 / `#id · 日期`）+ 每行单行截断（`title` 提示全文）。
- **Q3=A**：bandori 帖的 artist 取**曲库官方乐队名**（候选未到时退帖子自填），custom 帖用自填 —— 与导入产物一致。
- **Q4=A**：预览栏顺序 = 标题 → 歌手 → 谱师（谱师带「谱师 ·」标签）。

## 落地口径

- 行：`.off-row--post` 修饰类只作用于社区行，不改官方面板的折行行为；文本三行各自 `nowrap + ellipsis`，`title` 给全文；右列 `.off-row__aside` 两行右对齐（芯片复用 `.off-row__levels`，覆盖 `max-width`）。
- 行高恒定：`contain-intrinsic-size` 按实测上调（社区行三行文本 + 缩略图 48）。
- 歌手解析收敛成 `mapping.postArtist(post, official?)`：bandori 取官方乐队名、缺失退自填；custom 取自填。行与预览共用这一处，避免两处口径漂移。
- 预览栏：歌手行常显（缺失走 `projects.artistMissing`）；谱师行带标签、可点（走票 59 的账号名筛选）。
- 验收：jsdom 锁结构与文案；视觉走 headless Edge 真渲染（1280 / 900 / 860 三档 × 展开/收起），判据 = 同一窗宽下所有工程行的 y / 高度唯一、按钮行数恒为 1。

### 2026-11-27 · 评审回修（双轴 code review）

- **分隔符统一为「谱师：X」**（en `Charter: X`）：列表行、预览栏、筛选芯片同一口径，对齐 ADR-0024 §5 的「角色名 + 全角冒号」。此前行内是「谱师 ·」、芯片是「谱师：」。
- `.off-row__song` 并入 `.off-row__artist`：同一件事两个类名、声明逐字相同，官方行与社区行共用一条规则。
- 谱师展示名回落收进 `charterName(post)`（列表行与预览栏两处共用）。
- DOM 断言改按 `role` / 文案（不再拿 class 与 `children` 下标断版式；阅读顺序用 `compareDocumentPosition`，版式仍归真渲染验收）；`NewProjectSourceCopy` 的静态锁改锁 `isBrowsing` 这层语义，不再把局部变量名钉进正则。
