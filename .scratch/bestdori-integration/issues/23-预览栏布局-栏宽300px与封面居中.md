# 23 · 预览栏布局：栏宽 300px（勾选态不位移）+ 封面居中

Type: bug
Status: open
Blocked by: —

## 来源

用户 2026-10-12 验收反馈（同批 6 条中的 #3 / #4）。

## 症状

1. 五档难度（EZ/NM/HD/EX 之外多个 SP）的芯片折成两行，SP 单独掉第二行（原话「效果非常丑」）；**勾选「同步导入谱面」后芯片带 ✓ 前缀变更宽，同样折行** —— 用户明确要求勾选前后布局不能变；
2. 封面贴左，右侧一大片空白（实测左 gap 0 / 右 gap 78px）。

## 根因

- `--off-preview-w: 240px`（`ProjectsPage.css:386`）装不下五档芯片：实测未勾选态芯片行总宽 264px、勾选态（`✓ EX 25`，前缀 +10.7px）274.7px → 两态都折行；
- `.off-preview__inner` 是 column flex、默认 `align-items: stretch`，而 `.off-cover` 是 `width:100%; max-width:160px`（`ProjectsPage.css:532-545`）→ 实际渲染 160px 贴左，余量全留在右侧。

## 定案（用户 2026-10-12）

- 栏宽 **240 → 300px**。实测依据：勾选态最坏 274.7px，300px 余量 25px；280px 只剩 ~5px 太贴边；列表列仍剩 ~566px（弹窗 lg 920px 下）。勾选 / 不勾选两态芯片都必须一行且行内元素不位移；
- **两态零位移（反馈 2）**：芯片钉 `line-height: 14px`。根因：`✓`（U+2713）不在 Geist Variable → 回退字体行盒高 1px → 选中态芯片 23px（其余 22px）→ flex 行默认 `align-items: stretch` 把 1px 传染整行 → 「同步导入谱面」被顶下 1px（实测 dy=1.0，两个视口稳定复现；钉 line-height 后 dy=0、两态芯片恒 22px）；
- 封面**居中并放大到 180px**；标题 / 歌手 / 芯片行随封面整摞居中（同步开关保持通栏）；
- **试听条进自然流（反馈 4，位置经复看定在同步开关下面）**：从「钉在栏底」移出，作为自然流的**最后一项**跟在「同步导入谱面」下面（试过放歌手上面，用户复看：「放上面感觉有点丑，但是像之前一样固定到最下面也不好看」），剩余空白沉到栏底。detail 未到位的等高骨架占同槽位（32px），到位后原地替换、零布局变化。

## 修法

- `.off-split { --off-preview-w: 300px }`；`@media (max-width: 820px)` 里的 `.off-preview { max-width: 260px }`（`ProjectsPage.css:635`）同步改成 `var(--off-preview-w)`，否则窄屏单列下钉宽内层被裁；
- `.off-preview__stack { align-items: center }` + `.off-cover { align-self: center; max-width: 180px }` + 标题/歌手 `text-align: center` + `.off-preview__levels { justify-content: center }`；
- `.off-preview__levels button { line-height: 14px }`（与同规则的 `font-size: 11px` 配套，纯钉死回退字体膨胀）；
- **试听条移进 `.off-preview__stack`**（同步开关之后、stack 末项）：`.off-preview__inner` 不再直接持它；B/C 整摞居中下用 `align-self: stretch` 保通栏 —— **不许同时写 `width: 100%`**（实测 `width:100%` 会把 padding+border 再加一遍：300→318，顶出横向滚动条；stretch 单独用正好 300）。

## 锁测

1. CSS 事实 → **静态源码断言**：`--off-preview-w` 值为 300px；820px 媒体查询引用同一变量（不许再写死 260px）；`.off-preview__levels button` 含 `line-height`；
2. **真机验收**（原型已量）：勾选前后芯片一行且 `.off-sync` 的 dy=0（反馈 2 的验收式）；封面左右 gap 相等（B 变体实测 59/59）；试听条跟在同步开关下（gap 8px）、剩余空白沉底（实测 90.6px）。
