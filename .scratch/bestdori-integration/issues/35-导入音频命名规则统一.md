# 35 · 导入音频命名规则统一

Type: grilling
Status: resolved (2026-10-13)

## 来源

用户 2026-10-13：「官方谱面导入后的音频名称、社区谱面导入后的音频名称，统一一下命名规则！」

## 现状（实际是三套规则并存）

| 场景 | 规则 | 代码 |
| --- | --- | --- |
| 官方导入 / 社区 bandori 帖 | `bgmId.mp3`（如 `bgm001.mp3`，平台内部音频文件名主干） | `songs.ts:217-220` `audioFileName()` |
| 社区 custom 帖 | `post-<postId>-audio.mp3`（自传直链无语义名，退帖 id 派生） | `posts.ts:221-224` `customAudioName()` |
| 手动换音频 | 用户原始文件名 `file.name`（且 `source` 置 custom） | `projectAudio.ts:163` |

## 根因

- 官方/bandori 帖音频走官方素材路径，名字沿用**平台内部文件名**（`bgmId` 对用户是黑话，且与 bandori 帖、官方导入"同名"——不同曲各自有 bgmId，不冲突，但用户看不出是什么歌）。
- custom 帖音频是站内上传直链，没有可靠语义文件名，故用帖 id 派生。
- 三套规则各自独立演化，从未统一约定。

## 定案（用户 2026-10-13，自定义方案）

统一规则 = **来源前缀 + 谱面 ID + 歌曲名**：

- bandori 来源（官方导入 / 社区 bandori 帖）= `official-<songId>-<曲名>.mp3`
- custom 来源（社区 custom 帖）= `community-<postId>-<曲名>.mp3`

实现口径（待验收）：

- 曲名做文件名非法字符清洗（`\/:*?"<>|`、首尾空格与点），超长截断。
- custom 帖标题缺省时退 `community-<postId>.mp3`。
- 封面命名（`coverFileName` / `customCoverName`）**建议同步同一规则**（`official-<songId>-<曲名>.png` / `community-<postId>-<曲名>.png`）——用户未明确拍，按一致性先做，验收可砍。
- 手动换音频维持 `file.name` 不变；**只对之后的导入生效**，已落盘工程 `audioName` 不回改。

## 实现落点（拍板后细化）

`songs.ts` / `posts.ts` / `officialImport.ts` / `communityImport.ts`。

## 锁测

- 单测：`tests/unit/community/bestdori/` 命名函数用例 + `tests/unit/project/` 导入编排断言 `audioName` 按新规则产出（官方/bandori/custom 三分支）。

## 实现细节（2026-10-13）

1. **新模块 `src/community/bestdori/assetNames.ts`**：统一落名规则与曲名清洗的唯一实现处。两支共用 `buildAssetName(prefix, id, title, ext)`；`songs.ts` 的 `audioFileName` 签名由 `OfficialSongDetail`（bgmId 黑话）改为 `SongCandidate`，`posts.ts` 的 `customAudioName` / `customCoverName` 改为委托同模块。`officialImport.ts` / `communityImport.ts` 只换调用点（bandori 分支传 `song`）。
2. **清洗细则**（超出票面清单的两处，评审后补）：控制字符一并换 `_`（帖子标题带换行/制表符是现实的）；截断到 60 字符后**再剥一次尾点尾空格**（切口可能正好踩在点上，Windows 会静默吞尾点）；截断**不劈代理对**（emoji 标题踩线留下孤单高位代理，落盘会编码失败）。标题缺省判定 = 空串或只剩分隔符（整行非法字符洗成 `___` 一样退 id）。
3. **封面两支同步同规则**（票内「建议同步、验收可砍」项，按一致性先做）：`official-<songId>-<曲名>.png` / `community-<postId>-<曲名>.png`；旧的 `jacket-<id>` 兜底随 `bgmId`/`jacketImage` 派生一起退役。
4. 手动换音频未动（`projectAudio.ts` 维持 `file.name`）；**只对新导入生效**，无迁移代码，已落盘工程 `audioName` 不回改。
