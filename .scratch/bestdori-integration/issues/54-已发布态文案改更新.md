# 54 · 已发布态文案改「更新」

Type: grilling
Status: resolved
Blocked by: —

## 来源与诉求

用户 2026-10-28：已发布后，原本的「发布」按钮变成「已发布」按钮；点「已发布」弹出的弹窗标题也是「已发布」——这两处读着别扭。诉求：已发布态下改成与发布前对偶的动作词：

- 工程详情谱面行的按钮：「发布」→**「更新」**
- 发布弹窗标题：「发布谱面」→**「更新谱面」**

（用户原话：「这样的话，能与发布前的内容对应上」。）

## 症状

- `ProjectDetail.tsx` 谱面行按钮与 `PublishDialog.tsx` 弹窗标题**共用一个键** `projects.publish.communityPost`（zh「已发布」/ en「Published」）。
- 按钮位置上给的是**状态词**（不是动作）：点它打开的是可改难度 / 等级 / 标签的弹窗，不是「查看发布记录」。
- 同一屏里语义打架：弹窗标题「已发布」+ 底部 CTA「更新」。

## 根因

1. **51 票 Q11 定案**写的是「未发『发布』，已发『**社区帖**』」（主按钮「更新」）。落地时文案被换成「已发布」，键名 `communityPost` 留着 —— 于是键名与文案两头不靠。
2. 「已发布」在**按钮位置**是状态陈述；已发布态的**状态信息另有承担**：谱面行的 `StatusBadge`「已上传」徽标（`projects.status.uploaded`）。按钮退化成纯动作、徽标承担状态，分工才干净。
3. 已发布态的**标题**与 CTA 不同层：标题该说「这张窗干什么」（更新谱面），CTA 才是按钮动作。

## 定案（用户 2026-10-28 拍板）

- 谱面行按钮：未发「发布」、已发**「更新」**（复用已有键 `projects.publish.update`）。
- 弹窗标题：未发「发布谱面」、已发**「更新谱面」**（新增键 `projects.publish.updateTitle`；en「Update chart」）。
- **退役** `projects.publish.communityPost`（两处消费 + 两条测试断言；键名与任何「已发布态文案」都不搭）。
- 不动 ADR-0015 §4 的语义（谱面本体只读 vs diff / level / tags 可改）；只改**文案口径**，并在 ADR / CONTEXT 里把「社区帖弹窗」这一提法改成「更新弹窗」。
- 键退役随本票同批落地，不单开 chore 票（体量一条 i18n 键，够不上批次票门槛）。
- **追加（用户 2026-10-28 拍板）**：原先记在「本票外」的两条遗留**在本票内一并做掉**——README（中英）与文档站功能页（中英）里「已发布的谱面只读 / Uploaded charts are read-only」的旧说法改成「**谱面本体**只读 + 难度 / 等级 / 标签仍可从「更新」弹窗改」；`projects.publish.err.already` 同样改成这个口径。并加锁测防回潮。

## 实现落点

- `src/i18n/messages/zh-CN.json` / `en.json`：删 `projects.publish.communityPost`；加 `projects.publish.updateTitle`；改 `projects.publish.err.already`。
- `src/pages/projects/components/ProjectDetail.tsx`：谱面行按钮取 `projects.publish.update`；注释同步。
- `src/pages/projects/components/PublishDialog.tsx`：标题取 `projects.publish.updateTitle`。
- `CONTEXT.md`「发布」「谱面状态」「上传记录」三条词条 + `docs/adr/0015`（§4 修订段与文件头修订索引）：把「社区帖弹窗」这一提法改成「更新弹窗」。
- `README.md` / `README.en.md` / `docs-site/guide/features.md` / `docs-site/en/guide/features.md`：「谱面只读」旧说法 → 「谱面本体只读 + 元数据可改」。

## 锁测

- `tests/dom/pages/ProjectPublishConfirm.test.tsx` —— 用例「已发布过的谱面：标题改「更新谱面」，主按钮是「更新」，不再挡成已发布错误」（`describe('票 11 · 发布弹窗：必填预检与确认门')` 块内）：断言标题 = 「更新谱面」、**不再是**「已发布」，CTA = 「更新」。原先断言标题「已发布」，本票改后变红。
- `tests/static/PublishEntryWiring.test.ts` —— 用例「入口在工程详情」原先硬断言源码含 `t(up ? 'projects.publish.communityPost' : …)`（本票改后变红，改断言 `projects.publish.update`）；新增 `describe('票 54 · 已发布态的文案口径')` 三条：标题取 `updateTitle`；`communityPost` **全仓 src 扫**（`sourceFiles('src')`）+ 两份字典都不再有它，且 `updateTitle` 的字面值锁住（zh「更新谱面」/ en「Update chart」）；**旧口径不许回潮**——四份对外文档不得再出现「已发布的谱面只读 / Uploaded charts are read-only」等旧说法，且必须含新口径关键词（`更新` / `Update`），`err.already` 文案同口径。
- 真机：本轮未做（纯文案口径；用户已在应用里确认过这两处读着别扭的现场）。

## Answer

落地（红→绿两轮）：

- **i18n**：退役 `projects.publish.communityPost`（zh「已发布」/ en「Published」），新增 `projects.publish.updateTitle`（zh「更新谱面」/ en「Update chart」）。行内按钮复用既有 `projects.publish.update`（「更新」）。`projects.publish.err.already` 一并改口径（见「遗留一并处理」）。
- **`ProjectDetail.tsx`**：谱面行按钮已发态取 `projects.publish.update`；注释改为「按钮位置只给动作词——状态由行内『已上传』徽标说」。
- **`PublishDialog.tsx`**：弹窗标题已发态取 `projects.publish.updateTitle`（未发仍是「发布谱面」）；头注记 ⑦。
- **文档**：`CONTEXT.md`「发布」「谱面状态」「上传记录」三条词条 + `docs/adr/0015`（§4 追加 2026-10-28 修订行 + 文件头修订索引补一条）：把「社区帖弹窗」这一提法改成「更新弹窗」（**语义不变**，只改入口文案口径）。
- **对外文档口径**（遗留一并处理）：`README.md` / `README.en.md` / `docs-site/guide/features.md` / `docs-site/en/guide/features.md` 四份里「已发布的谱面只读 / Uploaded charts are read-only」的说法全部改成「**谱面本体**只读（改音符要复制副本）+ 难度 / 等级 / 标签仍可从「更新」弹窗改」。
- **锁测**：`tests/dom/pages/ProjectPublishConfirm.test.tsx`（标题 = 「更新谱面」且不再是「已发布」）+ `tests/static/PublishEntryWiring.test.ts`（行内按钮取 `update`、标题取 `updateTitle`、`communityPost` 全仓 src + 两份字典都不再有它、字面值锁住、**旧口径文档不许回潮**）。
