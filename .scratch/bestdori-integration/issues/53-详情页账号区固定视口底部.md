# 53 · 详情页左栏账号区固定在视口底部

Type: feature
Status: resolved（2026-10-26 落地；待用户真机长列表验收）
Blocked by: —

## 来源 / 症状

用户 2026-10-26：谱面工程详情页左下角登录区希望是固定的。工程数量多时会被挤下去，要滚到最底才看得到。

## 根因

不是忘了 `sticky`，是票 39 把「左栏底部」（Q13）做成了**内容底**而不是**视口底**：

- `AccountBar` 是 `.pc-list` 最后一个子节点，和工程行在同一个 `overflow-y: auto` 里。
- `.pc-account { margin-top: auto }` 只在列表短于视口时把账号行推到栏底；列表一长，flex 的「底」就在最后一项工程后面，账号行跟着滚走。
- 只有 `.pc-list__head` 做了 `position: sticky; top: 0`。CSS 注释写明「列表短时钉底、长时跟在末尾」——这是实现者对 Q13 的解读，用户当时没拍过「长列表也要滚到底才看到登录」。

账号区是 Bestdori 社区登录（`AccountBar`），只挂在详情左栏（启动台没有，票 39 Q24 已接受）。

## 定案（用户 2026-10-26 · grill Q6）

钉在视口底：拆左栏，工程列表自己滚，账号行不滚。菜单仍向上弹。修订票 39「长时跟在末尾」。

## 本轮实现口径（待验收）

拆左栏：外层 `flex column; height:100%; overflow:hidden` → 中间工程列表 `flex:1; min-height:0; overflow-y:auto` → 底部 `AccountBar` `flex-shrink:0`。头仍 sticky。菜单继续向上弹（票 39 Q29）。不用 `position:fixed`（会跟左栏宽度 / 分栏拖拽打架）。

这是对票 39「长时跟在末尾」的修订，落点不变。

## 锁测

- 扩 `tests/static/AccountBarLayout.test.ts`（或 CSS 静态断言）：`.pc-list` 不再把账号行和工程行放进同一个滚动盒。
- DOM：详情左栏仍有 `.pc-account`；启动台仍没有。
- 手工：工程多到超出左栏高度时，不滚列表也能看到登录行。

## Answer

拆左栏：`.pc-list` 改为 `flex column; height:100%; overflow:hidden`；工程行进 `.pc-list__items`（`flex:1; min-height:0; overflow-y:auto`）；`AccountBar` 做兄弟底栏 `flex-shrink:0`。不用 `position:fixed`。头仍 sticky；菜单仍 `placement="up"`。票 39「长时跟在末尾」注释作废。

锁测：`tests/static/AccountBarLayout.test.ts` 票 53 段（滚动盒拆分 / 底栏 / 启动台无账号区 / 菜单向上）。`tsc -b` 过。全量 3682 绿；另 6 条 docs-site 静态锁在本机失败（`yamlBlock` 吃到空串 / getting-started 缺 json 样例），与本票无关。
