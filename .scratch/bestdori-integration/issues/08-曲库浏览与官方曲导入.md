issues/06 的 grill Q7 / Q8 / Q11 / Q12（2026-09-30 拍板）；落地 `chart-projects/issues/07` 里「BanG Dream 来源」那一支。

**2026-10-09 归位（用户拍板四项来源，见 [12](./12-导入入口四项归类.md)）**：本票 = 新建入口四支里的「**从官方谱面导入**」。标题里的「官方曲导入」与 12 票的「官方谱面」是同一件事的两种叫法，**实现落点以 12 票的入口名词为准**（`NewSource` 四值、Hub 四块 tile）。「官方」覆盖 BanG Dream 与 LLSIF 两库（曲目来源字段仍按 `bandori` / `llsif` 分记，那是上传时的数据指针，不是界面分支）。

## 定案（用户 2026-09-30）

官方曲导入 = **两件互相独立的事**：

- **A · 曲目素材（默认做）**：工程名称 ← 曲库标题、`artist` ← 官方歌手、`曲目来源` ← 官方曲 id、封面 ← jacket、音频 ← bgm rip。
- **B · 谱面内容（默认关，勾选才做）**：该难度的官方谱面代码 Apply 进工程里那张谱面（走 Apply 闸门 ADR-0014）。

其余：

- 默认产出 = 一个工程 + **一张空的 Expert 谱面** + 官方音频与封面；难度导入前可改。**等级不预填**（等级是作品属性，人还没作谱），勾了 B 才把官方 diff + level 一起带上。
- 选曲 UI：曲库**一次拉全**（`GET /api/songs/all.5.json`）+ 本地索引做瞬时搜索；**就地预览**（封面 / 难度等级表 / 试听），不必先导入。
- 素材落地走**下载暂存**：暂存 → 决定导入才写进工程自己的音频与封面。
- **换音频即改归属（Q12=a）**：用户在音频页导入或换音频时，`曲目来源` 自动置 `custom`，仍可在「编辑工程信息」改回。

这条竖切**不需要碰谱面代码 Apply**（B 默认关），所以它是验证通道成本最低的一刀（Q5）。

**只做在「新建工程」层**（用户 2026-10-09 确认，见 12 票「边角口径」）：官方谱自带曲目素材，往已有工程里导入会撞上「一个工程一首歌」的音频归属，所以「工程详情 → 新增谱面」不接这条来源。
