## 来源

issues/06 的 grill Q7 / Q8 / Q11 / Q12（2026-09-30 拍板）；落地 `chart-projects/issues/07` 里「BanG Dream 来源」那一支。

**2026-10-09 归位（用户拍板四项来源，见 [12](./12-导入入口四项归类.md)）**：本票 = 新建入口四支里的「**从官方谱面导入**」。标题里的「官方曲导入」与 12 票的「官方谱面」是同一件事的两种叫法，**实现落点以 12 票的入口名词为准**（`NewSource` 四值、Hub 四块 tile）。「官方」覆盖 BanG Dream 与 LLSIF 两库（曲目来源字段仍按 `bandori` / `llsif` 分记，那是上传时的数据指针，不是界面分支）。

入口现状：工程管理页「新建」里连占位都没有 —— `ProjectDialogs.tsx:13` 的 `NewSource` 只有 `blank | copy`；`ProjectHub.tsx:154-159` 的 `.pb-tiles` 与 `ProjectsPage.tsx:299-305` 的分裂按钮菜单都只有两项。静态演示版隐藏该入口（ADR-0011 §1）：现无专门的"演示版"标志，判定口径 = `window.electronAPI` 缺失（全仓既有惯例，如 `ChartProject.ts:187`）。

## 定案（用户 2026-09-30）

官方曲导入 = **两件互相独立的事**：

- **A · 曲目素材（默认做）**：工程名称 ← 曲库标题、`artist` ← 官方歌手、`曲目来源` ← 官方曲 id、封面 ← jacket、音频 ← bgm rip。
- **B · 谱面内容（默认关，勾选才做）**：该难度的官方谱面代码 Apply 进工程里那张谱面（走 Apply 闸门 ADR-0014）。

其余：

- 默认产出 = 一个工程 + **一张空的 Expert 谱面** + 官方音频与封面；难度导入前可改。**等级不预填**（等级是作品属性，人还没作谱），勾了 B 才把官方 diff + level 一起带上。
- 选曲 UI：曲库**一次拉全**（`GET /api/songs/all.5.json`）+ 本地索引做瞬时搜索；**就地预览**（封面 / 难度等级表 / 试听），不必先导入。
- 素材落地走**下载暂存**：暂存 → 决定导入才写进工程自己的音频与封面。
- **换音频即改归属（Q12=a）**：用户在音频页导入或换音频时，`曲目来源` 自动置 `custom`，仍可在「编辑工程信息」改回。

这条竖切**不需要碰谱面代码 Apply**（B 默认关），所以它是验证通道成本最低的一刀（Q5）。

**只做在「新建工程」层**（用户 2026-10-09 确认，见 12 票「边角口径」）：官方谱自带曲目素材，往已有工程里导入会撞上「一个工程一首歌」的音频归属，所以「工程详情 → 新增谱面」不接这条来源。

- **换音频处按 Q12 改写 `source` —— 落点是 `src/audio/projectAudio.ts`，不是 `projectCatalog.ts`**（2026-10-09 复记：换音频走的是票 15 定的 `projectAudio` 接缝，`projectCatalog.ts` 通篇没有音频函数；改这里时注意它已有的两条约束——目标是当前工程要先 `flushPersist` 落盘、锁定工程直接拒写）。这是本票唯一改动既有补丁语义的地方。

票里留给实现定的三处，落地口径：

- **暂存 → 工程的接缝**：扩 `ProjectPutWire` 收 `audioStagedPath` / `coverStagedPath`（07 留的那个岔口），主进程从 `<数据根>/downloads/` 拷进工程目录；渲染侧是 `ChartProjectBackend.save(project, staged?)`。**主进程校验暂存路径必须落在 downloads/ 内** —— 这个入参来自渲染进程，不卡等于交出「读任意文件」。
- **取消语义**：导入进行中**不许关弹窗**（Esc 与取消键一并挡）。请求已经在飞，关掉只会让人以为「取消了」而工程照样建出来。四段文案代替进度条。

**实测事实（2026-10-09，已回写研究文档）**：

2. 封面包 = `ceil(songId/10)*10`（1→10、29→30、100→100、500→500、822→830 全中真图；相邻桶回退页）。
3. 曲库条目与单曲详情**都没有 artist**：官方歌手 = 乐队索引 `bandName`。
4. 不存在的资源回 **200 + SPA 回退页**（`text/html` 约 14KB）：二进制落地前要按 content-type 判掉。
5. **合作曲只在首发服有素材**（song 1004 只有 en 有封面包与 `bgm1004.mp3`，其余四服全是回退页）→ 按 `publishedAt` 挑服务器。

### 2026-10-09 · 真机待验（单测覆盖不到）

1. **在线**：Electron 里「按流量确认」——打开官方 tab 只应有两条请求（曲库 397KB + 乐队 15KB）；选中一首歌才加一条详情 + 一张封面；不点播放不动音频。
2. **4MB 音频**：选实体曲（如 BLACK SHOUT）→ 试听能**边下边播**（不必等下完）；点创建后四段文案走完，工程详情里音频名 `bgm029.mp3`、时长 ≈ 官方 `length`、封面 = jacket。**粗记各段耗时**（网关一次性请求，无限流事件）。
3. **断网 / 限流**：拔网线打开官方 tab → 「连不上官方曲库，检查网络后重试」+ 重试键，不白屏、不循环报错；弱网下创建失败 → 弹窗内出「导入失败」横幅，工程不落盘。
4. **素材缺失**：选合作曲（song 1004 `See the world`）→ 封面预览失败显示占位、导入成功但**不带封面**；若音频也取不到 → 报错不建。
5. **静态演示版**（浏览器 dev）：官方 / 社区两块 tile 与两个 tab 都不出现；手动把 `source` 设成 official 也只会看到「官方曲库只在桌面版提供」。
6. **窄窗**：把窗口压到 820px 以下，选曲面板应折成单列（预览落到列表下方），四块 tile 折成两行。

### 2026-10-09 · 评审后补（两轴走查的整改）

- **音频 / 封面的名字原来没落进工程记录**（真 bug）：暂存的声明只带路径，`audioName` / `coverName` 留在了 null —— 工程详情行会显示「无音频」。现在名字由 `createOfficialProject` 收（`audioName` / `coverName` 进记录），`ProjectBinarySources` 收成 `{ audioStagedPath, coverStagedPath }` 两个纯路径（名字归工程，不归暂存），锁测补名字断言。
- **时长现在真的跟随音频**：原来只把官方 `length` 写进去、注释里说「音频落地后校正」而没人校正。现在落盘 → 读回 → 探针探实际音频时长 → 差值超 0.5s（与 `useChartProjectPersistence` 同容差）再写一笔；探不到就留官方值（ADR-0005 §4）。
- **二进制只在「像才收」**：`text/html`（回退页）之外，`application/json` 这类也判非法（音频直接失败、封面当没有）；**拿不到 content-type 放行** —— 平台哪天不回这个头，拒绝它会让主线全断，而回退页只要带头就认得出来。
- **一张难度表**：`OfficialDifficulty → 0..4` 原来在编排与面板各写一份，收进 `endpoints.officialDiffIndex`（官方编号与工程难度同值，只此一份）；「难度 → 等级」「换歌后的难度兜底」收进 `mapping.songLevel` / `resolveSongDiff`。
- **阶段文案键**改成 `satisfies Record<OfficialImportStage, MessageKey>` 表（原来靠模板串拼 + 类型断言），并补上转圈（Q3 说的「+ 转圈」）。
- `staging-failed` 单独一句（本机磁盘 / 权限），不再混进「读取失败」；顺手删掉零消费者的假出口 `makeUnsupportedCommunityTransport`。

### 2026-10-09 · 已知未做 / 边界（另开票或另议）

- **LLSIF 不在本票**：票面「官方覆盖两库」说的是**入口名词**（用户视角的「官方谱」），落点写的是 `chart-projects/issues/07` 里「**BanG Dream 来源**」那一支、锁测只认 `songs/all`。LLSIF 是另一套端点与素材域（`/api/misc/llsif.10.json`，封面 / 音频在 `card.niconi.co.ni`），要另开票。
- **「难度导入前可改」的读法**：按 06 Q8 原文「勾 B 才带官方 **diff** + level」理解为**B 的难度选择**（默认 Expert）。不勾 B 时产出 Expert（与「默认产出 = 一张空的 Expert 谱面」一致），改难度走工程详情的「编辑谱面信息」。若原意是「不勾 B 也能在建工程前选那张空谱面的难度」，是面板上挪一个控件的事。
- **暂存文件导入后不删**：清理靠 07 的「启动清空 `downloads/`」，数据根会短期留一份 4MB 音频（下一轮启动即清）。导入即删要主进程参与，先不做。
- **网关的流式下载 / 字节级进度 / 断点续传**：现在是一次性请求 + 退避重试（3 次含首次），弱网下 4MB 可能白等一轮。要动 07 的稳定面，不塞进这一刀。
- **09**：社区那一支的实做（面板现在是占位）。
- 名词小账：12 的表里第 1 项写「空白创建」，本票未动 `projects.newBlank` 的值（仍是「空白新建」），改名要连带改既有 DOM 测试，等有人要动入口文案时一起做。
