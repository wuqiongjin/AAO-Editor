# 56 · 导入谱面时音频或封面资源失效的处理

Type: grilling
Status: resolved
Blocked by: —

## 来源与诉求

用户 2026-11-14：

> 1. 导入谱面，如果谱面的音频资源挂了/封面图挂了，怎么处理？

## 现状

1. **封面图**：
   - 官方导入（`src/pages/projects/officialImport.ts` → `fetchOfficialCover`）：仅在响应为 `200 + text/html`（SPA 回退页）时返回 `null`，放行建工程并 Toast 提醒 `"该曲目未提供官方封面，工程未包含封面。"`；遇到 HTTP 404/403/5xx（`http`）、超时（`timeout`）、离线（`offline`）或限流时**整笔抛错阻断创建**（ADR-0020 §2）。另：`song.jacketImage === ''` 时仍发一次空封面名请求并写 1h 负缓存。
   - 社区导入（`src/pages/projects/communityImport.ts` → `fetchCustomCover` / `fetchOfficialCover`）：`custom` 帖仅吞掉 `kind === 'invalid-response'`（如 SPA 回退页）并返回 `null`。若 `coverUrl` 为非 `bestdori.com` 外链（网关白名单 `ALLOWED_HOSTS` 拒收 → `request-rejected`）、HTTP 404/410/5xx（`http`）、超时或离线，**一律整笔失败阻断创建**。
   - 坏文件漏网：`posts.ts` 的 `looksLikeMedia` 放行 `application/octet-stream`，落盘前不验证字节是否真是合法图片，损坏数据会写入工程 `cover.bin`（`coverPresent: true`）。
2. **音频资源**：
   - 官方与社区导入（`src/pages/projects/chartImport.ts` `runChartImport`）：音频作为第一步硬前置（`await source.audio(input)`），无论官方还是社区、无论是否勾选「同步导入谱面」，只要音频不可达（404 / `text/html` 回退页 / 站外外链 `request-rejected` / 超时 / 离线），**整笔导入立即失败**，无法建出含谱面代码的工程。
   - 报错提示失焦：`officialErrorText` / `communityErrorText` 未映射 `http`、`invalid-response`、`request-rejected`，遇到链接失效/404/外链被拒时统一显示泛化错误（`"读取官方曲库失败，请重试。"` / `"导入社区谱面失败，请重试。"`）。
   - 坏音频漏网：若返回 `200 + application/octet-stream` 但字节损坏不可解码，`probeProjectDuration` 失败被 `try/catch` 静默吞掉（留 `30s` 占位或官方时长），坏 `audio.bin` 依然落盘。

## 根因

1. **封面降级矩阵不完整**：ADR-0020 只覆盖了官方曲「平台返回 `text/html` 回退页」一种无图情况，`custom` 帖与 HTTP 404/5xx/超时/外链被拒均未被归入可选封面的降级路径。
2. **音频硬阻断 + 社区 `custom` 外链与死链现实**：ADR-0020 §4 曾基于「没有稍后补官方音频的入口」而否决无音频降级；但实际上工程创建后可在音频页导入本地音频，且社区 `custom` 帖支持外链（`docs/research/bestdori-community-upload.md` §3.2）或存在历史死链，硬阻断会导致**连谱面代码都导不进来**。
3. **媒体载荷校验与错误域映射缺失**：导入路径对 `application/octet-stream` 仅看 Content-Type 未验解码有效性；`http` / `invalid-response` / `request-rejected` 无对应 i18n 文案。

## 定案（用户 2026-11-14 · grill 第 1–3 轮）

1. **Q1 封面失效**：任何封面获取或校验失败（平台无图 / HTTP 404/5xx / 站外外链被拒 / 超时离线 / 非图片或坏字节）均**不阻断创建**，一律按无封面照常创建工程，并在创建后 Toast 提示（区分「未提供封面」与「封面获取失败」）。同步修订 ADR-0020。
2. **Q2=A 音频失效**：
   - **同时带了有效谱面代码（`withChart: true`，非降级，且通过 Apply 闸门）**：允许降级创建**无音频工程**（`audioName: null`、不写入 `audio.bin`）+ Toast 警告提醒稍后在音频页导入本地音频；
   - **未带谱面（`withChart: false`）**：维持整笔阻断并给出明确错误原因。
3. **Q8 ① 双挂防线**：勾选同步导入谱面时，若官方谱面也因网络失败降级为空白谱面（`chart.degraded === true`）且音频也失败，**禁止创建空白空壳**，维持整笔阻断。
4. **Q8 ② 无音频降级时的工程时长**：
   - 社区 `custom` 帖：`clampChartDuration(Math.max(DEFAULT_CHART_DURATION_SECONDS, maxNoteEndSeconds(...)))`（30s 与最后音符结束时间取大）；
   - 官方导入 & 社区 `bandori` 帖：`clampChartDuration(Math.max(detail.lengthSeconds, maxNoteEndSeconds(...)))`（官方元数据曲长与最后音符结束时间取大）。
5. **Q3=A 站外外链**：维持网关 `ALLOWED_HOSTS = ['bestdori.com']` 安全白名单不变；`custom` 帖第三方外链归入「不支持自动下载的外链资源」，按上述 Q1/Q2 规则降级或明确提示。
6. **Q4=A 落盘前验真**：下载回二进制后、写入工程前校验媒体有效性（封面验证可解码为图片，音频经探针/解码验证可用）；验不过视为「资源挂了」走上述 Q1/Q2 降级/阻断与报错，不把损坏的 `cover.bin` / `audio.bin` 写进工程。
