### #1 工程主页四块新建 tile 占位过大

- **症状**：`ProjectHub`「新建」区 2×2 大卡片，空列表时几乎把首屏占满，看起来丑。
- **根因**：票 12 把原先**一行两块**的 `.pb-tiles` 原样扩成四块，CSS 未改（`padding: 16px`、图标 + 标题 + 说明）。英文说明更长（`newBlankDesc` 两行），卡片被撑更高。主页 tile 与弹窗 tab、顶栏分裂菜单是**三处重复入口**。
- **修法**：不改。主页仍 2×2 大卡（图标+标题+说明，英文说明也不收）。最初「占位太大」撤回。
- **Status**: 定案（用户 2026-10-09）Q1b=A · **won't fix**

### #2 新建弹窗四个来源 tab 英文被挤爆

- **症状**：英文下「Import from local/official/community charts」在同一行被压扁、折行、裁切。
- **根因**：`.dialog-tabs` 是 `display:flex` + 每钮 `flex:1` + **固定 `height: 30px`**，按两钮短中文设计。四钮后英文标签远超单元格；空白/本地档弹窗是 `md`（560px），扣除内边距每钮约 120px，装不下「图标 + 长句」。中文四词能塞进，所以中文不明显。票 12「入口名短」只收紧了中文。
- **修法**：英文 tab 改为 Blank / Local / Official / Community；中文仍用现句。不改 tab chrome 形态。
- **Status**: 定案（用户 2026-10-09）Q2=A

### #3 无既有工程时「从本地谱面导入」看不出禁用

- **症状**：`list.length === 0` 时按钮不可点，但看起来仍像能点。
- **根因（两处，同一漏）**：
  1. **弹窗 tab**（截图主因）：`.dialog-tabs button` **没有 `:disabled` 样式**，未选中已经是 `--text-muted` + `cursor: pointer`，`disabled` 几乎无差。全仓无对应测试。
  2. **主页 tile**：有 `opacity: .55; cursor: not-allowed`，但图标仍走 `.pb-tile svg { color: var(--accent) }`，半透明强调色仍像可点；也没有「为什么灰」的说明。
- **修法**：tab 补 `:disabled`（降对比、`cursor: not-allowed`、可加 `title`）；tile 弱化图标色并可加一句「需要已有工程」。不改「无工程则禁用」语义。
- **Status**: 已落地（2026-10-09）

### #4 点「从官方谱面导入」长时间停在「正在拉取官方曲库…」

- **症状**：切到官方支，只有这一句，很久没列表。
- **根因（叠加，不是死锁）**：
  1. **定案就是一次拉全**：`GET /api/songs/all.5.json`（约 397KB）+ `GET /api/bands/all.1.json`，面板在 `catalog === null` 前只渲染这一句。
  2. **网关单飞 + 400ms 间隔**：`Promise.all` 在 renderer 并发，主进程 `schedule` 仍串行；且 `cache: 'no-store'`，每次实打。
  3. **约 400KB JSON 过 IPC**：主进程 `JSON.parse` 后再 structured clone 到渲染进程。
  4. **无会话缓存**：`source === 'official'` 才挂载 `OfficialSongPanel`，切走即卸载，再点再拉。
  5. **超时 30s、最多 3 次、失败才出重试键**：弱网/跨境可白等到近 30s×3；`onRetry` 面板没用，重试中仍是同一句。
- **修法（不推翻「一次拉全」）**：进程内缓存曲库；面板保活避免切 tab 重拉；加载中区分「首次 / 重试中 / 已过 Ns」；`onRetry` 接到文案。预取 / 索引走并发例外要另拍（Q4）。网关字节级进度属 07 稳定面，本批不做。
- **Status**: 定案（用户 2026-10-09）Q4=A · 打开后再拉 + 会话缓存；不预取、不开网关并发例外

### #5 切官方/社区后整窗突然变很大

- **症状**：空白/本地是小表单；官方/社区变成接近全屏。
- **根因**：`NewProjectDialog` 写死 `size={official|community ? 'lg' : 'md'}`。`md` = 宽 560、高度随内容；`lg` = **920×640 固定**（谱面代码弹窗那档）。社区支目前只有一句占位，仍开 `lg`。选曲目录+预览确实需要面积，但和「同一颗弹窗换档」绑在一起，切换必跳。
- **修法**：用户同意 **shell**（2026-10-09）：空白/本地小表单；官方/社区另一块**同规格**大选曲台。切 tab 不是同一颗窗换档。
- **Status**: 已落地 shell（2026-10-09）；二次验收见 #6（换壳入场动画闪一下）

### #6 从 Blank 切到 Official / Community 弹窗闪一下

- **症状**：切 tab 尺寸变化本身顺，但整窗会闪一帧（诡异）。
- **根因**：票 13 #5 落地用 `key={picker|form}` **卸掉整颗 Dialog 再挂另一颗**（`ProjectDialogs.tsx`）。`Dialog` 没有离场动画；`.dialog` / `.dialog__scrim` 每次挂载都重放 `dialog-in` / `dialog-scrim-in`（opacity 0 + 面板 `scale(0.98) translateY(6px)`，约 120ms）。中间至少一帧：遮罩和面板都没了，然后新遮罩从全透明淡入。用户看见的「闪」是换壳副作用，不是尺寸过渡本身。Official ↔ Community 同 `key=picker`，不换壳，不该闪。
- **修法**：定案 **Q1=A**（用户 2026-10-09）：仍两档尺寸，**同一颗 Dialog 改 `size`**，遮罩不卸、不重放入场；用宽高过渡代替卸挂。与 #5「不是同一颗窗换档」的落地手段冲突，以本轮为准（两档还在，手段改回改 size）。
- **Status**: 已落地（2026-10-09）Q1=A

### #7 Official → Community 时四个 tab 文字左移

- **症状**：切到社区后 Blank / Local / Official / Community 整组左移。用户怀疑社区没有滚动条。
- **根因**：说对了，但滚动条不在列表里、在 **tab 所在的 `.dialog__body`**（`overflow-y: auto`，无 `scrollbar-gutter`）。官方支：tab + 搜索 + `.off-list{max-height:400px}` 超过 lg 正文剩余高度（约 450px），body 出现 Windows 经典滚动条，吃掉右侧 ~15–17px；四钮 `flex:1` + `justify-content:center`，每个标签中心左移。社区支只有一句占位，body 不溢出，条消失，标签弹回。列表自己的条在 `.off-list` 内，动不到 tab。
- **修法**：选曲台正文 `overflow: hidden`，**只有目录列表滚**；tab 不进滚动盒。与 #11a 同源。
- **Status**: 已落地（2026-10-09）跟 #11 一起

### #8 列表条目难看、乐队名显示不全

- **症状**：右列乐队被裁成 `Hello, …` / `Po…` / `R…`。用户要整改「每个条目」而不只是加长省略号。
- **根因**：`.off-row` 是两列网格（标题 | 乐队），`.off-row__artist { max-width: 40%; white-space: nowrap; text-overflow: ellipsis }`。乐队名（官方歌手 = `bandName`）被故意单行裁切。难度芯片另起一行。信息层级是「标题与乐队抢同一行」，长名必残。
- **修法**：定案（用户 2026-10-09，原型 B）：横排 = 曲名+完整乐队（可折行）在左，难度芯片在右。不裁 40%。
- **Status**: 已落地（2026-10-09）原型 B 行结构

### #9 只有搜索、没有筛选

- **症状**：只能搜曲名/歌手；要乐队、难度、等级等。
- **根因**：能力上就没做。`searchSongCandidates` 只 `title`/`artist` 包含。`SongCandidate` **丢掉了** 曲库里已有的 `bandId`、`tag`（`normal` 等）、`publishedAt` 服标记，界面没法按乐队身份筛（重名合作艺人会糊）。Bestdori 曲库页（`/info/songs`）常见筛：乐队、曲种 `tag`、已实装难度、等级范围、发布服。本仓曲库索引一次拉全，筛选可全本地、不必新接口。
- **修法**：范围 **Q4=A**；形态 **Q10=B** 手风琴（搜索旁「筛选」点开展开）。**Q11=A** 折叠仍生效，选项保留；清空只走面板「清除」或按钮旁 ×。等级不硬夹 min/max，左右填反按数值 min/max 筛。映射回填 `bandId`。
- **Status**: 已落地（2026-10-09）Q4=A · Q10=B · Q11=A

### #10 点歌曲后封面从上到下慢慢出来

- **症状**：慢，且像渐进式从上往下刷。问是不是预期。
- **根因**：**不是**产品做的渐进加载，也 **不是文件太大**。预览 `<img src={jacketPreviewUrl}>` 直链 Bestdori `jacket.png`（票 08 Q1）。实测 song 1：`image/png`、**97764 字节、400×400 索引色**（研究文档同口径 39–98KB）。本机 `curl` 冷取同一张 **7.7s**，Cloudflare `CF-RAY` 落在 **LAX**；站点无更小缩略图端点。5–10s 是 **中国到 CF 洛杉矶的跨境路径**，不是「全尺寸很大」。扫刷 = 浏览器对非交错 PNG 边下边画。`Cache-Control: max-age=14400`。
- **修法**：**Q5=A** 占位 → `load` 后短淡入；仍 `<img>` 直链。不悬停预取（Q7 否）。首点跨境仍可能 5–10s。
- **Status**: 已落地（2026-10-09）Q5=A · 不预取

### #11 选曲台布局（用户 #6 a–g）

- **症状**：左列表底下空白；右栏整体丑；EZ/NM/HD/EX/SP 斜体没必要；系统 `<audio controls>` 突兀（还可能复用）；「官方音频与封面会一起带进新工程」是废话；「把官方谱面一起导入」勾选及展开更丑。
- **根因**（逐条，都不是「没时间微调」而是结构）：

  - **b**：右栏是封面 → 标题 → 五级表 → native audio → 说明 → checkbox → 展开 `<select>` 的直筒堆叠，没有分组/主次。
  - **c**：列表芯片 `.off-row__levels em` 写了 `font-style: normal`；右栏 `<em class="pp-pill__diff">` **没写**，HTML `em` 默认斜体。
  - **e**：就地试听用浏览器原生 `<audio controls>`（`.off-audio { height: 32px }`）。工作台/预览已有 `PlayBar`，但那是页底栏几何（时间码编辑、锁定、倍速 slot），不能原样塞进弹窗。

  - **g**：B 选项是原生 checkbox + 勾选后套用表单 `.dialog-field` 的 `<select>` + `<small>` 闸门说明，和选曲台密度、视觉层级都不配。
- **修法**：定案（用户 2026-10-09，原型 B）：
  - 预览在左、列表在右；筛选通栏在双栏之上（手风琴，见 #9）。
  - 列表吃满剩余高度（#7 / a）。
  - 去斜体（c）；删 `assetsNote`（f）。
  - 紧凑试听条钉在左栏底（e）；导入展开不把它顶下去。
  - 「同步导入谱面」开关，无附加说明；默认关。开后用**预览那一排**芯片选难度（默认 EX，未实装不出现）。关 = 芯片只展示；开 = 未选空心、选中实心+✓+**内描边**（外圈会撑破窄栏，不用）。
- **Status**: 已落地（2026-10-09）原型 B
