# 09 · 社区帖浏览与导入

Type: feature
Status: open
Blocked by: 07

## 来源

issues/06 的 grill Q9 / Q10（2026-09-30 拍板）；落地 `chart-projects/issues/07` 里「Community 来源」那一支。

## 定案（用户 2026-09-30）

- 列表 / 搜索 / 分页走 `POST /api/post/list`；**等级与难度只能客户端过滤**（`docs/research/bestdori-api.md` §2.2）；**上拉加载**，不做页码。
- 详情 `GET /api/post/details?id=`。
- **谱面名称留空**（动态跟随工程名称，见 CONTEXT「谱面名称」）；原帖标题与**谱师**只在导入会话里显示，**不落进新谱面的 `title`** —— 避免「转手别人的谱，连名字一起转」。
- 曲目按帖子的 `song.type`：
  - 官方曲 → 记曲目来源 id 并下载音频与封面（复用 08 那条素材路径）；
  - 自定义曲 → 按帖内 URL 下载音频与封面，工程 `曲目来源` = `custom`。
- 导入的谱面代码一律走 Apply 闸门（ADR-0014）；官方 / 社区谱面代码与本编辑器格式一致（`basic-editor/issues/02`），不做格式重设计。
- 「广场」不新增应用页面（Q4）：浏览能力长在工程管理页的这个入口里。

## 实现落点

- `src/community/bestdori/posts.ts`（能力 6–7）+ `mapping.ts` 的社区帖部分。
- 导入的谱面代码走既有 `ChartConverter` 链路接受 Apply 闸门（ADR-0014），不新开一道入口。
- 文案进 `src/i18n/messages/{zh-CN,en}.json`。

## 锁测

1. `tests/unit/community/bestdori/posts.test.ts`（新）：内联 fixture —— 列表形状 → 中立「谱面候选」映射；等级 / 难度过滤在客户端生效；`song.type` 两种分支各自产出正确的曲目来源。
2. 名称口径：新增一条锁「社区帖导入后 `ProjectChart.title` 为空」的用例（防止将来有人图省事预填帖子标题）。
3. 若新增测试大类需登记 `vitest.config.ts` 的 `include`；本票用既有 `tests/unit/` 即可。
4. 单测覆盖不到的：上拉加载时序、封面墙 / 预览窗 —— 走 `tests/dom/` + 手工验收清单。
