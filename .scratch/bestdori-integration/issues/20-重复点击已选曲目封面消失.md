# 20 · 重复点击已选曲目，封面消失且不再回来

Type: bug
Status: resolved
Blocked by: —

## 来源

用户 2026-10-11 在讨论 #4（预览栏折叠）时顺带实测发现，原话：

> 当再次点击已经「展开歌曲详情」的条目时，会导致已经加载好的封面图消失。

## 症状

官方选曲面板点某首歌 → 封面正常加载；**再次点击同一行** → 封面消失，且不会自己回来。同一次点击还伴随：试听播放器被重置、底部「创建并打开」按钮瞬间禁用再启用。

## 根因

`OfficialSongPanel.tsx:339-345` 的行点击没有去重，点谁都直接 `pick(song)`；而 `pick()`（`:97-104`）把封面与详情状态全部清零：

1. `setCoverReady(false)` → `<img>` 失去 `.is-in`，CSS 里 `.off-cover img { opacity: 0 }`（`ProjectsPage.css:512-520`）→ 封面**立刻变透明**；
2. 但 `<img>` 的 `src` 字符串没变（仍是缓存里的 `aao-asset://raw/...`，元素也没有 `key` 变化），图片已经 complete，**浏览器不会再触发一次 `onLoad`** → `coverReady` 永远回不到 `true` → 封面再也显示不出来；
3. `setDetail(null)` 连带 `CompactAudio` 的 `src` 变 `null`（`:316-322`）与 `onSelectionChange(null)`（`:116-118`）→ 另外两个症状同源。

不是加载失败，是**状态被重置后没有任何事件能把它恢复**。

## 修法

`pick()` 对同一首歌幂等：`song.id === selected?.id` 时直接返回（至少不重置 `coverReady` / `coverUseDirect` / `detail` / `detailError` / `loadingDetail`）。

## 锁测

1. `tests/dom/pages/OfficialPickerPreview.test.tsx`：新增「重复点击同一行 —— `<img>` 的 `is-in` class 保持、`src` 不变、`onSelectionChange` 不额外抛 `null`」。
2. jsdom 不发 `onLoad`、无法验证真实图片加载时序 → **真机验收**：连点同一行 3 次，封面始终在，试听不闪，按钮不闪禁。

## Comments

### 2026-10-11 · 落地记录

`src/pages/projects/components/OfficialSongPanel.tsx` 的 `pick()` 加两处守卫（同一首歌不再重跑整条链）：

- `sameSong = selected?.id === song.id`；封面四态（`coverFailed` / `coverReady` / `coverUseDirect` / `audioUseDirect`）**只在换歌时**重置 —— 这是根治点：`<img src>` 不变就不会再发 `onLoad`，`coverReady` 一旦被打回 `false` 就再也没有事件能点亮它。
- 详情**（`detail != null || loadingDetail`）时重复点击直接 return** —— 顺带消掉试听重置与 `onSelectionChange(null)` 导致的按钮闪禁。
- 保留「详情取失败时重跑」：`sameSong && detail == null && !loadingDetail` 仍走重取分支，因为重复点行是目前 `detailError` 唯一的重试入口（UI 上没有重试按钮）。
- `pick` 的 deps 相应加上 `selected` / `detail` / `loadingDetail`。

**锁测**：`tests/dom/pages/OfficialPickerPreview.test.tsx` 新增 2 条（同文件 `describe('票 20 …')`）：

- 「再点同一行」：`fireEvent.load` 点亮封面后重复点击 —— `is-in` 保持、`src` 不变、`audio` 不消失。修复前这条是红的（`expected false to be true`）。
- 「换一首歌照旧重置封面」：防止把换歌路径一起短路（修复前后都是绿的，是反向护栏）。
- 配套：`SONGS_INDEX` 加 song 30「LOUDER」+ `/api/songs/30.json` 打桩。

**门禁**：`npx tsc -b` 0 错误；`eslint` 改的两个文件 0 问题；`npx vitest run` = **233 文件 / 2606 条全绿**。

**真机待验**：连点同一行 3 次封面始终在；换歌仍正常淡入。
