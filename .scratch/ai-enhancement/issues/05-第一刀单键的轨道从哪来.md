# 05 · 第一刀单键的轨道从哪来

Type: grilling
Label: wayfinder:grilling
Status: resolved
Blocked by: 03

## Question

[智能制谱的输入是否包含采音标记](./03-智能制谱的输入是否包含采音标记.md) 已经写明：用户不必先做辅助采音。程序可以自己从音频算出一批时刻，但那些时刻不是采音标记，也给不出 `lane`（0..6）。

本编辑器的单键至少要有 `beat` 和 `lane`。时刻再加范围内的 BPM，只能得到 beat，得不到轨道。已发表的制谱做法里，轨道来自另一段模型、人类谱面模式库，或端到端一次生成，不是固定程序从「这一刻有个音」推出来的。

要拍板的是第一刀（单键 + BPM）的轨道：

- 允许用模型（或端到端）决定 `lane`。没有选定轨道做法之前，不把「只有时刻、没有轨道」当成智能制谱已经落地。
- 或者第一刀先用一条固定规则铺轨道（例如全放在中间轨），并承认这还不是合理谱面。

推荐：轨道允许来自模型。固定规则铺轨不算这一刀的完成。采音标记仍然不是制谱的输入。

## Answer

**轨道用模型决定。** 固定规则铺轨（例如全放在中间轨）不算第一刀完成。没有选定的选轨模型之前，智能制谱不算落地。

起音和采音标记都没有 `lane`。秒可以来自复用的标记（含手改），或来自内部起音；两条路都还要另定轨道。票 03 之后，复用开关默认开，见 `CONTEXT.md`「复用采音标记」。本票不改那条开关。

具体哪一种选轨模型，本票不选。
