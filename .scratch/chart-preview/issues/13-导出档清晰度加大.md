# 13 · 导出图清晰度：加大导出档

Type: bug
Status: resolved 验收通过（2026-10-06）
Blocked by: —

## 来源

2026-10-05 用户：「导出的图片感觉非常糊」。

## 事实（现状 = Bestdori 缩略档）

- `src/preview/static/exportPanels.ts` L26-35：`EXPORT_PANEL_H = 537`、`EXPORT_DPR = 2`、`EXPORT_ES = 1/3` → 面板 130 CSS px 宽；音频尺寸 ≈ 预览默认档（es 0.74）的 **45%**。
- 该档是 ADR-0016 §7「导出与预览解耦」的定案参数（独立常量、不跟预览基准漂移），此前对齐的是 Bestdori 静态预览的 130×537 观感，不是"看清谱面"。

## 定案（用户 2026-10-05）

**加大导出档**（提高导出面板尺寸），具体参数按实测校准；「导出与预览解耦」原则保留（仍是独立常量，不跟预览当前缩放走）。

## 本轮实现口径（待验收）

- 候选 = 对齐预览默认档（`PREVIEW_ES_STANDARD = 0.74` → 面板 289 px 宽），密度仍走 `EXPORT_DPR`。
- 先算术后实测：单边上限 65,535 px / 面积 2^28 —— 该档下 3 分钟谱**约** 100+ 面板 × 289 ≈ 29,000 CSS px（dpr 2 ≈ 58,000 px），单行只余 **<10%**；更长的谱面必须折行或降档。落档前用真实谱面实测余量。
- 实测后把常量钉死，并**回写 ADR-0016 §7**（此处是 ADR 常量修订，结论随票记录）。

## 锁测

- `tests/static/PreviewBinarySaveWiring.test.ts` L58-61 的常量锁（537 / 2 / 1/3）**必红** → 按新档更新，值须来自实测。
- `tests/unit/preview/static/PanelLayout.test.ts` L201-251 宽图排布用例复核/更新（新增"3 分钟谱不越单边上限"一条）。
- 面板尺寸变化会牵到沟槽布局用例：`tests/unit/rendering/render/TimeMarks.test.ts`、`ComboMarks.test.ts`（130px 面板口径）复核。
- 清晰度本身是像素事实：Playwright / 手工导出实测（导出图里音符物理 px 与预览默认档的可比性），写进验收清单 —— 单测画不出"糊"。
