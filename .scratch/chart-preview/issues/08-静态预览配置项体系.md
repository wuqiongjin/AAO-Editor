# 08-静态预览配置项体系（标注开关 + 画布共享项入口）

Type: grilling
Status: resolved
Blocked by: 03

**来源**：2026-09-30 用户对票 03 的验收意见第 3 条 —— 「沟槽文字」这个选项太笼统、太单薄；配置项该按 Bestdori 静态预览那一套系统性地列出来（音符皮肤 / 音符大小 / 长条不透明度 / 镜像 / 双压线 / Off Beat / Combo 数量标记 / Fever 标记 / BPM 标记 / Time 标记 / Beat 标记 / Skill 标记 / Vertical Scale / Zoom / Graphics Quality）；并且 Bestdori 的这些开关**在预览页可直接点**，共同项（双压线、Vertical Scale、Graphics Quality、音符皮肤、音符大小、长条不透明度…）与谱面画布**双向生效**；我们的「画布显示」藏在设置页，不方便。

## 定案（用户 2026-09-30 四答）

1. **面板形态 = 工具栏「显示」钮 → 弹出面板**，面板分两组：
   - 【标注（预览）】BPM 标记 / 时间标记 / 节拍线 —— 落 `settings.preview`；
   - 【画布（与工作台共通）】音符大小 / 长条不透明度 / 纵向比例 / 文字大小 / 同时点击线 / 图像品质 / 轨道颜色 —— **直接写 `settings.display`**（与设置页「画布显示」同一份数据，改了双方生效 = Bestdori 行为；设置页那一节保留为通性设置的家，不复制状态）。
2. **持久化**：标注开关落 `settings.preview`（跨会话记住"我习惯的看谱方式"）；**缩放 / 全屏仍属"这一屏怎么看"**，继续留在页面内 state。
3. **本轮范围**：面板 + 共享项互通 + **BPM 标记**（现「沟槽文字」改名）+ **Beat 标记**（现网格档扩成 off / 1-1 / 1-2 / 1-3 / 1-4 / 1-6）+ **Time 标记**（沟槽左侧按 1/2/5/10 秒刻度）。Combo 数量标记、Skill 矩形**各开后续票**；**Fever 标记挂起** —— 我们谱面数据里没有 fever 段（Bestdori 的 `cmd_fever_*.wav` 是音效、System note 只作 opaque 保留），要先查数据来源再定。
4. **音符皮肤给入口**：面板第三组显示当前**整包名**（六条目命中某个整包时）/「已自定义」+ 一个「去素材页」按钮；不在面板里做第二套皮肤选择器。
