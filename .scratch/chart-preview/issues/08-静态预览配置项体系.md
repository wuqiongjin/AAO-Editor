# 08-静态预览配置项体系（标记开关 + 画布共享项入口）

Type: grilling
Status: resolved
Blocked by: 03

**来源**：2026-09-30 用户对票 03 的验收意见第 3 条 —— 「沟槽文字」这个选项太笼统、太单薄；配置项该按 Bestdori 静态预览那一套系统性地列出来（音符皮肤 / 音符大小 / 长条不透明度 / 镜像 / 双压线 / Off Beat / Combo 数量标记 / Fever 标记 / BPM 标记 / Time 标记 / Beat 标记 / Skill 标记 / Vertical Scale / Zoom / Graphics Quality）；并且 Bestdori 的这些开关**在预览页可直接点**，共同项（双压线、Vertical Scale、Graphics Quality、音符皮肤、音符大小、长条不透明度…）与谱面画布**双向生效**；我们的「画布显示」藏在设置页，不方便。

## 定案（用户 2026-09-30 四答）

1. **面板形态 = 工具栏「设置」钮 → 弹出面板**，面板分三组：
   - 【标记】BPM 标记 / 时间标记 / 节拍线 / Combo 标记 / 镜向 —— 落 `settings.preview`；
   - 【画布显示】节奏图示大小 / 长压线不透明度 / 同时点击线 / 色觉辅助 / 纵向比例 / 图像品质 / 轨道颜色 / 线形分层 / 轨道线透明度 / 文字大小 —— **直接写 `settings.display`**（与设置页「画布显示」同一份数据，改了双方生效 = Bestdori 行为；设置页那一节保留为通性设置的家，不复制状态）。选项顺序照设置页。
2. **持久化**：标记开关落 `settings.preview`（跨会话记住"我习惯的看谱方式"）；**缩放 / 全屏仍属"这一屏怎么看"**，继续留在页面内 state。
3. **分批**：08 票 = 面板 + 共享项互通 + **BPM 标记**（现「沟槽文字」改名）+ **Beat 标记**（现网格档扩成 off / 1-1 / 1-2 / 1-3 / 1-4 / 1-6）+ **Time 标记**（沟槽左侧 1/2/5/10 秒刻度）+ **Combo 标记**（二轮追加）+ **镜向**（二轮追加）；**技能标记** → 09 票（用户选"下轮单独做"）；**Fever 标记挂起**（谱面数据里没有 fever 段）。
4. **音符皮肤给入口**：面板第三组显示当前**整包名**（六条目命中某个整包时）/「已自定义」+ 一个「去素材页」按钮；不在面板里做第二套皮肤选择器。

## Comments

- 2026-09-30 首轮实现（票内范围一次落地）：
  - 面板：`PreviewDisplayPanel`（触发钮 + 浮层 + 三组），量尺挂在触发钮外壳上（`IconButton` 不是 forwardRef）；Esc 关并把焦点还给触发钮内的 `<button>`。
  - 文案：共享项**复用设置页那套 i18n**（节奏图示大小 / 同时点击线 / 图像品质 / 轨道颜色…）—— 面板是同一份设置的第二个入口，两处名字必须一样；「沟槽文字」按 Bestdori 改名 **BPM 标记**。
  - `gridDetail` 是**破坏性数据类型变更**（`'beats'|'none'` → 数字档）：同一票内改完所有消费点（渲染过滤 / `staticLayerCache` 失效依据 / 预览档映射），旧枚举值属内部口径、不入持久层（settings 里存的是 `preview.beatMarks` 白名单）。
  - 已知取舍：Time 标记与 BPM 标记同带（都贴轨道左外缘 − 8px），同屏撞位时后画的 BPM 数值盖在上面；窄面板靠钳制保住可读性（代价是标签可能压到轨道最左 1–2px）。
- 2026-09-30 二轮验收（用户九条意见；Bestdori bundle 抓下来核对语义，纠正了三条凭印象的说法）：
  1. `styleOffBeat` 的界面名就是 **「色觉辅助」** —— 与我们已有的 `display.colorAssist` 同一件事（用户问"Off Beat 有啥用" = 我们早就实现、只是没摆进面板）。
  2. `styleMirror` 界面名 **「镜向」**，语义 = 整轨水平镜像（`mirrorMultiplier = 0===styleMirror ? -1 : 1` + 方向键 `isLeft` 取反，**连箭头一起翻**），默认 1 = 不镜像；用户印象里"红色的技能框"实际是**黄色**（`rgba(255,255,0,0.5)`）。
  3. 档位取值与我们的实现完全一致：`[0,1,2,5,10][chartTime]` / `[0,1,2,3,4,6][chartBeat]` / `[0,5,7,8,8][chartSkill]`；默认 `chartTime` 3 = **5 秒**、`chartBeat` 1 = **1/1**、`chartSkill` 4 = 全部。
  - **二轮落地**：
    - 默认值改用户指定档：BPM 标记**开** / 时间标记 **5 秒** / 节拍线 **1/1** / Combo 关 / 不镜像；`settings.display.imageQuality` 默认改 **高清**。共享设置的默认值与宽图导出**解耦**：导出走新常量 `EXPORT_MARKERS`（精简档）——用户改的是自己看谱的习惯，不该顺手改掉导出物的样子。
    - 「显示」钮改名 **「设置」**；分组标题收敛为 **标记 / 画布显示 / 音符皮肤**，去掉组说明与行内说明（说明留在设置页）；画布组补齐设置页那 10 项（新增 色觉辅助 / 轨道线透明度 / 线形分层），顺序照设置页。
    - Tooltip 瘦身：全屏 → 「Esc 退出」、缩放 → 「Ctrl/⌘ + 滚轮同款」、导出 → 「{{w}} × {{h}} px」。
    - **「高清下音符边缘非常诡异」修因**：音符层的瓦片 blit 一直把 `imageSmoothingEnabled` 关着（为播放帧减填充），密度不整除时就是最近邻采样 → 音符内部留硬缝。新增 `FrameView.directNotes`（缺省 = 编辑器现状），预览面板与宽图导出**直渲音符**（不再经瓦片位图），顺带去掉"每面板重建一遍瓦片"的白付；首轮为预览加的 `tileDprCap` 随之删除。密度档位保持不变（高清 = 3×），因为"清晰度"的天花板在面板尺寸（130px 宽 / 7 车道）而不是密度。
    - **工具栏布局**：两个簇（左 = 在看哪张谱面；右 = 显示控件 + 作用域），控件那排给 pill 容器（与全屏浮层同形态）。
    - **镜向**：`settings.preview.mirror` → `RenderDisplayOptions.mirror` → `makeCoords(..., mirror)` 翻转车道映射（复用 `mirrorLane`，**不动 geometry 自己的命中/圈选**）+ `dirSideOf` 互换方向键侧别。注意：组内偏移**不要**再取反一次（侧别再翻 = 双重翻转）——这条被 `MirrorPreview.test.ts` 的"逐点一致"断言当场抓出来了。
    - **Combo 标记**：`renderComboMarks` 每 50 combo 在**右沟槽**写数字（落点 = 第 N 个可击打结点；横向越界左移、纵向钳进画布、窗外的刻度直接跳过）。
  - 验证：`npx tsc -b` + 全量 **194 文件 / 2136 例** + `vite build` + 改动路径 eslint 无新增问题。
  - **留给 09 票**：技能标记（用户选"下轮单独做"；右沟槽的排布要先跟 Combo 数字 / BPM 数值理顺）；Fever 标记仍挂起。
