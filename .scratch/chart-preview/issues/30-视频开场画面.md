# 30 · 视频开场画面

Type: grilling
Status: resolved（**已拍板** 2026-10-10；原型定档后于 2026-10-11 落地，`src/preview/video/opening/`；**手工验收（导一条真实视频看开场段）待用户在本机做**）
Blocked by: —

**来源**：2026-10-10 用户提需求（附**游戏内该画面的参考图**）：「针对动态预览的导出……增加动态预览的歌曲开场画面。在游戏中，每个曲子实际游玩时，会先展示出一个类似歌曲的封面和信息展示的页面，然后再慢慢进入到正式游戏场景，开始播放。这个功能对于那些希望将谱面的预览视频发布到互联网上的人非常有用，有这个开场画面便于知道接下来是哪个曲子。（这个功能也是要作为一个配置项，放到导出里面，默认开启）」

**为什么是 grilling**：导出物的时间线**第一次出现"前置段"**（此前第 0 帧 = 谱面 0 秒、总长 = 谱面时长），牵动 ADR-0016 §5 的视频导出口径、`settings.export` 的形状、以及"开场写哪些信息"（会碰到工程信息面 / credits）。语义未定 ⇒ 先拍板，拍完的实现落本票。

## 现状（开工前的事实，2026-10-10 核实）

- **单一时间线，无前置机制**：`buildExportTimeline` 帧数 = `ceil(duration × 60)`、`frameSecondsAt = k/60`（起点 0）；`renderAudioTrack` 的 BGM `src.start(0)` + 键音事件 `0 ≤ t < duration`；`frameDriver` 每帧 = `SIM_FALLBACK_BG` + `drawSimFrameAt(ctx, input, t)`。全仓无任何 intro / opening 相关代码。
- **导出面板无配置持久化**：`VideoExportControl` 三行（文件格式 / 清晰度 / 声音）落在 `useVideoExport` 的页面内 state，**刻意不落设置**（"与倍速同性质，是当次的事"）。导出的数据面 `VideoExportRequest` 只有 scene / audio / 时长 / 音量 / 皮肤 / 文件名——**没有**封面、标题、难度、艺人。
- **可复用的数据与绘制**：页面层能拿到 `project.coverBlob` / `project.artist` / `projectCoverHue(id)` / `DIFF_NAMES|DIFF_SHORT|DIFF_COLORS` / `chartEffectiveTitle`；封面解码有 `loadCoverImage`（`createImageBitmap` → `ImageBitmap|null`）；长图头带的 `buildSheetHeaderModel` + 版式函数是**纯 ctx 绘制、不绑定长图**，但 `EXPORT_HEADER_H = 440` / 字号 120-44-32 是**长图档常量**，视频用不了。
- **素材**：仓库里**没有任何**游戏开场 / 加载 / 选曲画面素材与参考图；`assets-sync` 只认 5 个根（新增素材要外部快照仓配合）。工程封面目前只在静态导出链路里解码，仿真场渲染器拿不到封面。
- **工程信息**：`ChartProject` 只有 `name / artist / source / durationSeconds / cover*`；**不存在**作词 / 作曲 / 编曲字段（全仓零命中），Bestdori 曲库也不可取（应用内无曲库缓存、"从 Bestdori 新建工程"未实现且被 Electron 网络 IPC 阻塞、Bestdori 无 CORS）。
- **会红的既有锁测**：`tests/static/VideoExportWiring.test.ts` 锁"画面只经 `drawSimFrameAt`"；`tests/unit/preview/video/ExportTimeline.test.ts` 锁总帧数 / 第 0 帧 = 0 秒。

## 定案（用户 2026-10-10 逐条拍板；原型期微调见「版式规格」与 Comments）

1. **形态 = 照参考图**（游戏内歌曲信息画面）：黑底 + 装饰（音符 / 星星 / 闪光）+ 居中方形封面 + 难度徽章 + **全宽标题条** + 艺人行。**本期不做 credits**（作词/作曲/编曲那三行）。
2. **开场是纯前置段**：视频总长 = **5.0s + 谱面时长**（第七轮定档；第五轮前是 3.0s）；开场段**无声**；音轨整体后移 5.0s、谱面 0 秒映射到开场段结束那刻。**绝不与歌曲前奏重叠**（重叠会吃掉谱面开头的接近窗口：默认 noteSpeed 9.5 时 ≈1.25s，开头就有音符的谱会直接漏掉可见期，让"预览"本身失真）。_注：5.0s = ①1.0 + ②1.5 + ③1.0 + ④1.5，即导出视频最前面有 5 秒静音 + 纯开场画面，这是用户逐段拍板的结果。_
3. **开场段四段式**（时长 = 2026-10-10 第七轮**逐段拍板**，定档后钉死常量）：
   ① **开场淡入**——视频第 0 帧纯黑 → 开场画面浮现（**1.0s**）；
   ② **停留**——整屏静止读信息（**1.5s**）；
   ③ **入场过渡**——开场画面淡出到只有表演背景图的场地上（**1.0s**，即"慢慢进入游戏场景"）；
   ④ **轨道淡入**——整块轨道（场地图的扇形车道 + 判定线）浮现（**1.5s**）。
   四段**合计 5.0s**（初版是 1.0/1.5/0.5 = 3.0s，第四段为第五轮追加）。四段都是**交叉淡入淡出**，不做缩放 / 位移 / 倒计时。③ 期间**只画表演背景图**（bgskin `liveBG_normal.png`，没有轨道素材），开场画面在纯背景上淡完；④ 才让**整块轨道**淡入（学游戏官方，让轨道素材晚出现，缓解"轨道出现了还挂着开场装饰残留"）。
   **（第六轮澄清）"轨道"= 场地图 + 判定线两张素材**（用户："不单单只判定线，还有后面这大块空间的轨道都要一起过渡"）：`fieldskin/bg_line_rhythm.png`（扇形车道 / 车道线，就是那句"大块空间的轨道"）+ `fieldskin/game_play_line.png`（判定线），**两者一起在 ④ 里淡入**；③ 里剩下的只有 bgskin 的背景图。
4. **配置项**：动态形态工具栏「导出」弹窗内加一行总开关**「歌曲开场画面」**（默认开），**其下一块缩进的子条目区**（三行：难度徽章 / 标题条 / 艺人行）；**总开关关掉时子项置灰不可改**（同静态形态「导出信息」组的既有交互）。关掉 = 现状（第 0 帧即 0 秒、总长 = 谱面时长）。
5. **落设置、跨会话记住**：`settings.export.opening = { enabled, items }`，**默认全开**，additive（不 bump schemaVersion），**缺字段回落 `true`**（老用户不得被静默关掉）。
6. **信息 = 固定一套"歌曲信息"**：难度徽章 / 标题条 / 艺人行；**不跟** `settings.export` 那 7 个「信息区字段」开关走（那是长图头带的谱面统计信息）。不引入时长 / 音符数 / BPM / 工程名 / 导出时间。
7. **信息项做成声明式列表**（`OpeningItemId` + 默认值表）：未来加「谱师名称 / 歌手名称 / credits」= 加一个 id + 默认 + 文案 + 一处绘制或数据接线，版式（居中堆叠、空项不占位）与开关行自动跟着长。**本期不加工程信息字段**。
8. **难度徽章只写难度名**（全大写英文，`DIFF_NAMES[diff].toUpperCase()` ⇒ `EXPERT`），**不带等级**；底色 = `DIFF_COLORS[diff]`（由页面传入，preview 域不 import 工程域）。
9. **标题条**：标题取谱面标题、未填回落工程名（`chartEffectiveTitle` 链）；**原样绘制、不强制大写**；超宽**先自适应缩字号（下限基准 60%）**、仍放不下才省略号截断。
10. **回落**：封面缺 → `projectCoverHue` 派生的深色渐变占位块（同头带口径）；艺人空 → **不画那行**，整块按实际画出的项重新垂直居中；无音频的谱照演（本就无声）。
11. **只在导出里演**：实时预览回放不演开场（播放条的时间码 / 量程 / 暂停语义一律不动）。
12. **不做"面板内首帧缩略图"**（用户："没必要吧，导出面板也没有这个空间吧"）。版式调优与看效果走**原型页**（`?prototype=opening-screen`，throwaway，见「原型」一节）：可直接开页面看、拖比例、拖真封面、导出 3840×2160 样张；**定档后原型删除**，只留常量。最终验收仍由用户导一条真实视频。
13. **零素材改动**：装饰**程序化路径自绘**（单 / 双音符、五角星），布点**照游戏截图提取的固定斜链**（5 张截图逐像素互比布点完全一致 ⇒ 游戏本身就是固定模板）+ **每类一个固定倾角** + **尺寸梯度（越靠边越大、越靠中越小）**，不随机、**不读时间与窗口尺寸**（导出物确定性）；**不新增素材、`assets-sync` 不动**。具体布点 / 倾角 / 尺寸属观感，**不锁进测试**。**（第五轮补）字形与尺寸按用户新给的官方截图重标**（那张图与本原型样张同一比例，可直接逐像素比）：★ 内径比 `0.42 → 0.55` + 圆角尖端；♪ 旗子从"细月牙"改成**一整块厚叶形**；♫ 横梁**明显上斜**（≈11°）且右端超出去；音符头改成接近圆（长轴 ≈ 1.35 × 短轴）；尺寸梯度三个系数整体上调（★ ×1.35 / ♫ ×1.3 / ♪ ×1.6）。
    **（第六轮补）★ 不是独立元素**：用户给的规律是"**每枚 ♫ / ♪ 旁边一定有一枚与它配对的 ★**"。照官方截图实测，配对偏移是**固定**的（三对独立实例互相印证）：星左缘 = 音符右缘 + **0.0084 W**、星顶缘 = 音符顶缘 + **0.0377 H**。装饰表因此**只列音符**、配对星在绘制时算出来（结构上不可能缺配对星 / 出孤儿星）。同轮还按官方剪影重画 ♫（厚横梁 0.27 size、大音符头 1.25 倍、右端不拖尖角），并把整条链改成**相对白条上缘**定位（左簇四对贴白条上方、中间两对整对沉在白条后、右簇四对在白条下方）。
14. **几何全按帧高比例定义**（1080p / 720p 等比一致，观感不随档位变）；文字走系统回退链——**标题字体 = 系统无衬线**（用户 2026-10-10 第四轮拍板「最好看的还是系统无衬线」；字体比对面板已撤），全部沿用 `HEADER_SANS`（**不打包字体**，本票不动字体工程）。
15. **术语**（已入 CONTEXT.md）：**视频开场 / 开场画面 / 开场淡入 / 入场过渡 / 标题条 / 开场信息项**；与长图的「头带」严格区分，互不混称。
16. **形态以原型 A 为底子**（用户："A 的底子好一点"）：三种结构变体里 **B（左封面横排）/ C（封面铺底叠字）删除**，原型收敛为单变体 A。用户同时指出"A 有很多需要优化的" ⇒ 优化项在原型期**逐条给、逐条落**（清单与结论见「版式规格」与 Comments；原型页备好了可调项：封面 / 白条高·亮度 / 字号 / 装饰透明度 / **垂直位置** / 三段时长）。
17. **难度色 = 全应用唯一标准**（2026-10-10 第三轮拍板）：`DIFF_COLORS`（`src/project/projectCatalog.ts`）照游戏内开场画面截图（5 张不同难度）逐像素实测：**EASY `#3464fc` / NORMAL `#64fd33` / HARD `#ffcc35` / EXPERT `#ff3e40` / SPECIAL `#e22c94`**。界面徽标、谱面预览、切换器、开场画面垫层**全部共用这一份**，别处不得再硬编码难度色（堆叠垫层也从这张表取色）。

## 版式规格（初版读数，实现时以样张校准）

按参考图按帧高（H）折算，**全部用比例**，两档等比：

| 元素 | 初版取值 |
| --- | --- |
| 底色 | 纯黑；装饰层在最下 = **照游戏截图提取的固定布点**，且**音符与星成对**：每枚 ♪/♫ 右侧紧跟一枚 ★（**★ 不是独立元素**）。链分两簇（左簇四对贴白条上方、中间两对整对沉在白条后、右簇四对在白条下方），坐标**相对白条上缘**存（改封面大小 / 垂直位置时整链跟着白条走）。**每类一个固定倾角**（♪ −9° / ♫ +26° / ★ 顶尖朝上 −7° / ★ 平顶位 +29°，第四轮 IoU 逐实例拟合）与**尺寸梯度**（越靠边越大、越靠中越小，直线 `size = c0 + c1·|x − 0.5|`）；配对偏移固定：星左缘 = 音符右缘 + 0.0084W、星顶缘 = 音符顶缘 + 0.0377H（详见 Comments 第三、四、五、六轮）。**与封面同层同时机**：整屏只有**一个**三段 alpha，装饰与封面 / 垫层 / 徽章 / 标题条统一相乘进出（**无错峰**，第四轮用户修正）。**（第五轮）装饰"浓度"不再是独立 alpha**——独立 alpha 会在淡入 / 淡出期与整屏 alpha 打架（装饰先浮现 / 后消失），改成按倍率推**灰阶**（≤1 推黑、>1 推白），进出时机严格由那唯一一个 alpha 决定 |
| 封面 | 方形，边长 ≈ **0.48 H**，水平居中，不加圆角（短边居中取满裁切）；**难度色堆叠垫层**：垫层方形右缘 / 顶缘比封面各多出 t（t ≈ **0.011 H**），左缘 / 底缘按 i 内缩（i ≈ **0.01 H**，第三轮用户修正）⇒ 边长 = 封面 + t − i、**比封面小一点**；露出「顶条 + 右条」的 L 形（右上角连续），颜色 = `DIFF_COLORS[diff]`（标准色见定案 17）；封面四周一圈**细白框**（≈ 0.0035 H，垫层在白框之外）。**（第五轮）垫层只画露出来的 L 形，不画整个方形**——否则封面缺位 / 还没浮现时，会在封面的位置看到一整块纯色方块 |
| 难度徽章 | 封面下缘下 ≈ 0.025 H；微圆角实底胶囊，白字全大写，字号 ≈ **0.024 H**；底色 = `DIFF_COLORS[diff]`（标准色见定案 17） |
| 标题条 | **全宽贴左右缘**，高 ≈ **0.110 H**；底色 = **#ebe8eb**（用户 2026-10-10 给定，= `hsl(300, 7%, 91.6%)`，亮度可微调）+ 深灰字 **#38383c**（**非纯黑**）；标题字号 ≈ **0.050 H**、**常规字重（不加粗）** + 轻微字距；字体 = **系统无衬线**（用户 2026-10-10 第四轮拍板「最好看的还是系统无衬线」，即 `HEADER_SANS`）——**不打包字体** |
| 艺人行 | 标题条下 ≈ 0.03 H；白字，字号 ≈ 0.040 H |
| 整块 | 水平居中；垂直居中**按实际画出的项组成的栈**算（上 / 下留白相等） |
| 文字居中 | 一律按**墨迹框**（`actualBoundingBox*`）居中 —— **不用** `textBaseline='middle'`（它按字面框居中，字会压在视觉中心**下方 ≈0.14 em**，标题尤其显眼）；横向也不按 advance 宽（`textAlign='center'` 把 letterSpacing 的尾随空隙算进去，字带偏左）——原型期报「标题不居中」即此因 |
| 首帧 | 纯黑（开场淡入的起点）；整屏（封面 / 垫层 / 徽章 / 标题条 / 艺人 / 装饰）**同一个三段 alpha 一起浮现**——装饰与封面**同层同时机**（第四轮修正），不再逐枚错峰 |
| 尾段 | **（第五轮）④ 轨道淡入**（**1.5s**）：③ 结束时开场画面已归零，此刻画面 = 表演背景图；④ 里再让**整块轨道**（场地图的扇形车道 + 判定线）在 1.5s 内浮现。**（第六轮）**背景与轨道**分开出场**，且背景 = bgskin 的表演背景、轨道 = fieldskin 两张 —— 避免"轨道已经出现、开场装饰还挂在上面"。**（第七轮）**四段时长定档：① 1.0 / ② 1.5 / ③ 1.0 / ④ 1.5 = **5.0s** |

> 表里的比例值在原型 `?prototype=opening-screen` 上逐项定下来；**实现时本表改成钉死的常量表**（外加装饰布点表——照游戏截图提取的固定音符表，配对星由两条固定偏移算出）。四段时长已定（见定案 3）。

### 原型定形（2026-10-10）

原型（`?prototype=opening-screen`）用来定版式与观感，用户逐条给形。下面是**最终结论 + 两条实测根因**。

**结论**

- **形态**：首版给过三种结构不同的变体（A 照图 · 纵向堆叠 / B 左封面横排 / C 封面铺底叠字），用户定 **A 为底子**、"B 和 C 可以删掉" ⇒ 原型收敛为单变体（B / C 与变体切换机制一并删除）。
- **过渡三段**（用户给的形态）：黑屏 → 开场画面 → 游戏场景，即**开场淡入 / 停留 / 入场过渡**；时长 **1.0 / 1.5 / 0.5 = 3.0s**，两段都是交叉淡入淡出。
- **版式落定四项**：① 标题字号 **0.056 H**；② 标题条底色改成**可调亮度的浅灰**（`hsl(220, 8%, L)`，默认 90% ≈ `#e4e5e8`，**刻意不纯白** —— 用户："白条颜色太白了"）；③ 装饰扩成**五类**（单 / 双音符、五角星、**四角闪光**、**小光点**），配比约 0.34 : 0.21 : 0.17 : 0.18 : 0.10，星星闪光尺寸整体偏小；④ 装饰**跟随三段过渡进出**（淡入期按各自 `delay` 错峰浮现、停留期静止、淡出期随整屏淡出）。
- **试过但被否**：装饰的"星星闪烁 / 呼吸"（用户："呼吸效果可以不要"）⇒ 呼吸乘子、开关与相位字段全部删除。**副产品是好的**：装饰变成纯 `(seed, enter, 整屏 alpha)` 的函数，连时间都不依赖，确定性更强。
- **原型期新增的可调项**（定档后全部变常量）：封面边长 / 白条高 · 亮度 / 标题·艺人·徽章字号 / 装饰数量 · 透明度 · **种子** / 垂直位置 / 三段时长；种子决定布点与 delay。

**实测根因 ①：装饰不跟过渡**（用户报"音符图标啥的应该也要跟随这个过程动画进入、停留和消失"）—— `drawDecor` 里每枚装饰写 `ctx.globalAlpha = 自身透明度`，**是赋值不是相乘**，把 `drawOpening` 设的整屏过渡 alpha **整个覆盖掉**了 ⇒ 装饰在淡入 / 淡出时**全亮度常驻**（"啪"地出现、也不跟淡出），看起来就像没参与过渡。修法 = 相乘（`整屏 alpha × 自身 × 透明度倍率 × 错峰`），并给每枚装饰加 `delay ∈ [0, 0.45]`（占淡入窗口的比例）做**错峰浮现**。

**实测根因 ②：标题不居中**（用户报"歌曲标题有点不太居中"）—— 画面里文字一律用 `textBaseline='middle'` 居中，它按**字面框**（em box）算，而拉丁大写 / 中文的墨迹中心在字面中心**下方 ≈0.14 em**（67px 字号 ≈ 9px），在 108px 高的标题条里读起来就是"偏低"；横向另有 `textAlign='center'` 按 advance 宽算、把 letterSpacing 的尾随空隙计入 ⇒ 字偏左。修法 = `inkCentered()`：用 `measureText` 的 `actualBoundingBox*` 把**墨迹框**中心对到目标点，标题 / 艺人 / 徽章三处（含缩字号与截断路径）统一走它。**实现时必须照抄这条。**

**验收手段**：用户开原型页看 / 点「导出 PNG」拿 3840×2160 样张；本容器 Playwright 起不来（`chrome-headless-shell` 缺 `libglib-2.0.so.0` 等 GUI 库），探针留在 `.cache/osp-shots.mjs`。

**根因（一条，坐实）**：第五轮重写 `drawDecor` 时为了"装饰与封面严格同时机"，改成在**函数入口**设 `ctx.globalAlpha = a`、**出口**复位 `ctx.globalAlpha = 1`。但 `drawOpening` 的整屏 alpha 是**外层的**（`ctx.save()` 之后设的），装饰画完就被复位成 1 ⇒ **封面 / 垫层 / 白框 / 徽章 / 白条 / 标题 / 艺人行全部不再淡**，只有装饰在淡 —— 正好就是用户看到的现象。

**修法**：**整屏 alpha 只在 `drawOpening` 那一层设一次**；`drawDecor` 里每枚字形在自己的 `save()/restore()` 里设同一个 `a`，出口**不还**（也不复位）。这样"装饰与封面共用同一个三段 alpha"的口径不变，但外层 alpha 不会被吃掉。

**④ 时长**：默认 `0.5s → **1.0s**`（用户拍板）⇒ 开场段总长 **3.0 + 1.0 = 4.0s**。定案 3 / 版式规格尾段 / 实现落点的常量表一并改（`OPENING_TRACK_IN_SECONDS = 1.0`、`OPENING_SECONDS = 4.0`）。

**教训（写进实现口径）**：整屏 alpha 的 setter **只有一处**（`drawOpeningFrameAt` 的入口 `ctx.globalAlpha = alpha`）；任何子层的绘制函数都**不得**在函数级改 `globalAlpha` 后不还原——要改就在自己的 `save/restore` 里改。实现时这条值得一条锁测盯着（否则同样的 bug 会静默复发）。

**验证**：`npx tsc --noEmit` + `eslint` 通过；`?prototype=opening-screen` 200、模块编译无错。观感仍需用户开原型页复验。

**（续）四段时长定档**：用户紧接着给"效果 OK 了。再调整一下时间：① 开场淡入 →1s；② 停留 →1.5s；③ 入场过渡 →1s；④ 轨道淡入 →1.5s" ⇒ **1.0 / 1.5 / 1.0 / 1.5 = 合计 5.0s**（③ 从 0.5 翻倍、④ 从 1.0 再加 0.5）。定案 2（总长 / 音轨后移 3.0s → **5.0s**）、定案 3、版式规格尾段、实现落点常量表一并改完；④ 滑条上限 1.5 → 2.5（别让默认值顶到头）。
**副作用要记住**：导出视频最前面是 **5 秒静音 + 纯开场画面**、BGM 从第 5 秒起 —— 这是逐段拍板的直接结果，不是 bug；实现时 `renderAudioTrack` 的 `start(OPENING_SECONDS)` / 事件 `+OPENING_SECONDS` 用的是同一个常量，自动跟着走。
