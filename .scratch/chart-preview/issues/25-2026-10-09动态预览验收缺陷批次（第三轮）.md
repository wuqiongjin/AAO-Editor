### #1 方向滑键本体没有按各自轨位贴舞台平面

Status: resolved（2026-10-09 实现，待用户验收）

- **症状**：整组本体同一个倾斜角，越靠轨道外侧越显直立、不贴舞台平面；用户截图中只有最根部那只"有倾斜角度"。
- **根因**：仿真场沿用了**编辑器画布的扁平化口径**——`noteSkin` 的 `FLAT_LANE = 3`（2026-08-24 视觉修订，针对俯视编辑器），`ActiveNoteIcons.dirFor(type, lane)` 收了 `lane` 但丢弃，恒回 lane 3 那张 308×120；`simField.drawElements` 逐 `el.dirLanes` 画的全是同一张图。而 Bestdori **模拟器**逐本体取图：`skinDirectionalFlickSprites["note_flick_" + (l/r) + "_" + Math.max(0, Math.min(6, K + 3))]`（bundle 原文）——图集里 0..6 七张的倾角是**逐轨递增**的舞台透视（本机图集实测：lane 0 逆时针 ~12° → lane 6 顺时针 ~18°）。固定 `_3` 的是 Bestdori 的**静态面板**渲染器（与我们编辑器同口径），模拟器不是——我们的仿真场错拿了静态面板那份。
- **修法方向**：给 `ActiveNoteIcons` 开按轨取图通道（注册表 `dirL[0..6]` / `dirR[0..6]` 数据已在），编辑器维持扁平化、仿真场按 `dirLanes` 逐轨取图 + `clamp(0..6)`；镜向沿用 `dirSideOf`。外侧箭头（chevron）无逐轨图，不动。
- **锁测**：`SimField` 静态断言"本体 sprite 随 lane 变化、越界 clamp"；像素验收用 `.cache/sim-dir-shot.mjs` 出帧对照图集逐轨倾角（单测覆盖不了 Canvas 像素）。

### #2 滑条按住缺"滑条端点"持续状态（票 21 尾巴）

Status: resolved（2026-10-09 实现，待用户验收）

- **症状**：按住时判定线上只有几只环；Bestdori 还有一枚**绿色长条端帽**（`note_long`）贴在接触点上随插值轨位移动。
- **根因**：bundle 里按住相关是**三段** `y.forEach`，票 21 只誊了两段——漏掉的第一段：`setTransform(laneWidth,0,0,laneHeight,W/2,0)` 下画 `skinNoteSprites["note_long_" + Math.round(e + 3)]`（`e` = 按秒插值的接触轨位，**逐轨精灵**，自然比 `[e−a/2, 1−s/2, a, s]`）；我们的 `drawHoldEffects` 只有 connectionRing + 旋转环。
- **修法方向**：`drawHoldEffects` 补端点层（`slideEndpointFor` 也要逐轨版，同 #1 的通道）；画序照 bundle 在两环**之下**（先端点后特效）。
- **锁测**：`SimField` 静态断言按住帧存在端点绘制 + 端点 sprite 随插值轨位取整换图；像素验收同 #1 通道。

### #3 按住旋转环"3D 转圈"，应为舞台平面内转圈（票 21 尾巴）

Status: resolved（2026-10-09 实现，待用户验收）

- **症状**：我们的旋转环像 3D 翻面；Bestdori 是**椭圆轮廓恒定**（横长轴）、纹样沿椭圆面内扫。
- **根因**：变换复合顺序。Bestdori：`setTransform(i, 0, 0, 2i/3, W/2 + e·laneWidth, laneHeight)` **之后** `rotate(t·2π)` 再画 1×1 图——即 `S·R`：方图先在舞台平面内转、再被 3:2 非均匀压缩 ⇒ 轮廓恒为横椭圆、内容面内旋转；我们（`drawHoldEffects`）：`translate + rotate(spin)` 后直接画 3:2 椭圆图——即 `R·S`：已压扁的椭圆整体刚体翻转 ⇒ "3D 转圈"。尺寸（`2·laneWidth·n` 与 ×2/3）、双环（0.75× 反向）、角速度（`±t·2π`）两处一致，**只有顺序不同**。
- **修法方向**：`drawHoldEffects` 把压缩放到 rotate 之前（`ctx.scale(1, 2/3)` 后再 `rotate`、按单位尺寸画图），第二环同批。
- **锁测**：静态断言 ctx 调用次序（scale 先于 rotate）+ 像素实测（同秒与 Bestdori 对照，单测覆盖不了 Canvas 合成结果）。

## Answer

**2026-10-09 实现（三条同日落地，`npm test` 214 文件 / 2,374 例全绿 + 真机像素复验）。**

- **逐轨取图通道**（#1、#2 共用的地基）：`noteSkin` 新增 `dirLaneFor(type, lane)` / `slideEndpointLaneFor(lane)`——轨号**就近取整钳到 0..6**（与 bundle 的 `clamp(K+3, 0, 6)` / `Math.round(e+3)` 同口径），该轨缺图回落扁平轨那张；**编辑器画布那份 `dirFor` / `slideEndpointFor` 一字未动**（视觉修订 1 的扁平化口径只属于俯视编辑器）。
- **#1**：`simField.drawElements` 方向键本体改走 `dirLaneFor`（按 `el.dirLanes` 逐轨），盒子口径（设计宽 45 + 源格自然比 2.567）不动；外侧箭头无逐轨素材，不动。
- **#2**：`drawHoldEffects` 补**端点层**——按住期间在插值接触点上画 `slideEndpointLaneFor(round(lane))`，单键同款盒子（`simNoteRect`，noteSize=1）、压在判定线上，画序在两环**之下**（照 bundle）。
- **#3**：旋转环改为**方图**（2·laneWidth·n）+ `ctx.scale(1, SIM_HOLD_RING_SQUASH)` **先于** `rotate(t·2π)`（`S·R`：先在舞台平面内转、再压 2/3）⇒ 椭圆轮廓恒定、纹样平面内扫；新常量 `SIM_HOLD_RING_SQUASH = 2/3`（`simGeometry`，唯一定义处）。
- **锁测**：`NoteSkin.test.ts` +2（逐轨七张互异 / 取整钳制 / 扁平口径未动）；`SimField.test.ts` +2（整组三枚互不相同且非扁平那张 + 盒子不变；按住帧端点随插值轨位走、松手即收）；`SimEffects.test.ts` 回修 1（旋转环改锁"方图 + `scale(1, 2/3)` 先于 `rotate`"的复合顺序，屏上高 = 2 × 2/3 = 4/3·laneWidth 与 bundle 同值）。
- **真机像素**：`.cache/sim-dir-shot.mjs` 修前 / 修后对照（同一测试谱同秒抓帧）——整组本体逐轨倾角逐轨变化、按住点出现绿色 `note_long` 端帽 + 恒定横椭圆的双环，与 Bestdori 实机（用户截图）同构。
