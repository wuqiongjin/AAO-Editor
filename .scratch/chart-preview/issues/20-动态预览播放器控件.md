# 20 · 动态预览播放器控件（音量 / 倍速 / 循环 / 全屏 / 导出入口）

Type: feature
Status: open

**来源**：票 05 验收问题 2（"播放界面，没有声音、倍速设置。这些应该是作为播放器本身具备的功能"）+ 问题 3（"这个页面是不是也要提供「导出」、「全屏」的按钮。（类似静态预览的）"）。

**对照 Bestdori**（bundle `691780a2`）：播放条 = 播放/暂停 + 时间 + 进度 + **折叠扩展行**（音量 ±5%、倍速在 `[0.5, 0.75, 1, 1.5, 2]` 五档步进、循环开关）+ **全屏**钮；它**没有导出**。我们的播放条只有：播放/暂停 + 当前时间 + 进度（可拖）+ 总时长 + 回开头。

## 定案（用户 2026-10-07）

> 用户原话："我说的是没有「音量调节」、「倍速调节」的功能，不是没有声音。声音本身暂时没听出来问题"；「导出钮」= 按推荐来。

1. **"没有声音" = 缺功能**（不是没声音）：本票 = **音量调节 + 倍速调节**（+ 循环开关：Bestdori 同排一起给，成本一条 UI）。
2. **倍速要做** ⇒ 引擎侧 rate 支持纳入本票（§现状盘点那一段的成本照收）。
3. **导出入口 = 等 07**（推荐案）：本轮动态工具栏只加**全屏**；视频导出的按钮 / 规格 / 进度 / 取消随 07 落地（07 票已含"导出 UI"落点，本票在 07 的 Comments 挂一行指针，避免漏）。
4. **音量落 `settings.audio.volume`（新字段，持久化）**，键音音量沿用 `settings.audio.seVolume`；预期 07 的视频导出按这两档取（"与播放一致"）。工作台那档页面内主音量是既有独立口径，本票不动（登记在 Comments）。

**实现的验收口径（待验收）**：音量 0..1（含静音，步进 5%，照 Bestdori）；倍速五档 `[0.5, 0.75, 1, 1.5, 2]`（照 Bestdori），**只影响回放速度，不改谱面秒数与进度条量程**；循环开关到终点回绕到 0 继续播。

## 现状盘点（代码走读）

- 音频链路本身**没有明显阻塞**：`simPlayback` 自持 `AudioEngine`（BGM = 作用域工程音频；无音频走合成时间线；键音 = `buildKeyEvents` 同一份事件表），`play()` 在用户手势里 `ctx.resume()`；主音量固定 1（工作台那档是页面内 state、不落设置）。**未实测**（自动化环境需要"带音频的工程 + 用户手势"；本轮没做）。
- `AudioEngine` **无 rate 支持**：`getSeconds` 的两条时钟（audio / synthetic）、`tick()` 的 horizon、`playSampledTick` 的 `src.playbackRate`、`seek` 的游标都要按 rate 走；合成时间线的 `performance.now` 也要乘 rate。改动集中在 `src/audio/AudioEngine.ts`（工作台共用，要保证 rate=1 时行为逐位不变）。
- **全屏**：`PreviewPage` 的 `stageRef` + `toggleFullscreen` 是形态无关的（动态形态也在同一块 `.preview-stage` 里）；缺的只是工具栏那枚钮 —— 复用 `PreviewStaticToolbar` 的 `Maximize2` 钮 + 浮层 `PreviewExitFullscreenButton`（票 12 定案的形状）。
- **导出**：视频导出是 07 的整条链路（离线逐帧 + 音轨 + 封装 + 落盘），本票只负责"入口"，不碰 07 的实现。
