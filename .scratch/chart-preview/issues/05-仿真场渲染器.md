| 带体 | 长条 / 滑条：相邻结点 `(lane, A)` 两点构成的四边形填充（颜色取皮肤带体图或采样中心色） |

## 复用与边界

- **复用**：`src/rendering/skin/noteSkin.ts` 的 `buildActiveNoteIcons`（per-lane 精灵 rect / `slideBand` / `slideBandSp` / `slideAmongFor` / `slideEndpointFor` / `dirGroup` / `preloadSrcs`）+ `src/ui/CanvasSpriteIcon` 的图集缓存与预热（`ensureImagesLoaded`）。跨域引用沿用既有 deep import 惯例（`rendering/skin/noteSkin`）；若要过 barrel，同票在 `src/rendering/index.ts` 补出口。
- **不复用**编辑器画布渲染（那套是扁平轨道 + 沟槽 + 瓦片缓存 + 动态渲染面）；仿真场是**独立绘制**，落 `src/preview/video/sim/`，不进 `src/rendering/`（它是预览专用画法，不是编辑器画布的第二种形态）。
- **口径一致（不另立一套）**：`beat < 0` 不渲染 / 不键音 / 计 combo（ADR-0014）；倒流区的元素位置按 `displayConnections` 同一显示投影（ADR-0009 §2.2 / issue 115）。
- 素材仅从 04 的**开发期直读通道**取；无素材时给空态与提示，不影响页面其余部分。

## 锁测

- `tests/unit/preview/video/SimGeometry.test.ts`（纯函数）：`A(t_note) = 1`、`A(t_note − T) = 0.05`；`lane → x`（含 mirror 的符号）；带体四边形顶点顺序；`noteSpeed` 档位 → `T` 的映射；设计面在窄 / 宽比例下的钳制。
- `tests/static/SimRendererWiring.test.ts`：仿真场不 import `pages/`、不 import 编辑器画布渲染模块、素材只走直读通道（防悄悄拷进 `public/assets/`）。

- 口径一致性语料：用 `docs/resource/SampleChartCode/` 的样本谱 + 现有倒流区语料，逐条对照"画布播放的同一时刻"（`beat < 0`、倒流区折返都不许另说一套）。
