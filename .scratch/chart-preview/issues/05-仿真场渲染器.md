## Answer

2026-10-07 实现（待用户验收）。开工前三问已确认：**音频口径 = BGM + 键音、仿真场自持引擎**（读作用域工程的音频）、**播放控件 = 舞台底部一排**、**音符速度默认 9.5**（用户："比较适合预览谱面的速度"；游戏里速度档是 1–12，本模型取 1..11 —— 12 会让 `T = (12 − n)/2` 退化成 0，票面的档位表也是 1..11）。

**改了什么（新增）**

- `src/preview/video/sim/simGeometry.ts`：设计面（`1334×750`、`laneWidth = 154 × W/1334`、`laneHeight = 0.82H`、原点 `(W/2, 0)`）+ 接近模型（`A = 0.05 + 0.95 × 1.1^(50Δ/T)`、`T = (12 − noteSpeed)/2`）+ lane↔坐标 + 带体四边形 + 特效参数 + combo 落点（`0.85W × 0.4375H`）。设计面按 **contain** 进舞台（宽高比不拉伸），宽 / 窄两侧钳制 `[320, 1920]` CSS px。
- `src/preview/video/sim/simField.ts`：**任意秒出帧** `drawSimFrameAt(ctx, frame, seconds)` + 谱面派生表 `buildSimChart`（元素 / 带体 / 同时点击线 / combo 时刻）。绘制顺序 = 场地（背景 cover + 场地图 + 判定线贴线）→ 带体 → 同时点击线 → 音符 → 特效 → combo，与票面「画面要素」表同序。
- `src/preview/video/sim/simAssets.ts`：素材**只走 04 的直读通道**（`/__bestdori-assets/<server>/…`，逐服探测、jp 打头），带体颜色取皮肤带体图中心像素；缺席 = `emptySimAssets()`（空态由页面画）。
- `src/preview/video/sim/simPlayback.ts`：实时回放 —— 自持 `AudioEngine` 当秒源（有音频放 BGM + 键音，无音频走合成时间线；键音 = 引擎内部的 `buildKeyEvents` + `settings.audio` 音量口径），rAF 驱动同一份出帧函数；播到谱面长度停住。07 的离线导出只要自己驱动帧循环调 `drawSimFrameAt` 即可。
- `src/pages/preview/PreviewVideoStage.tsx`：舞台装配（量舞台 → 建回放 → 一帧输入 → 播放条），页面失活即停声；`PreviewDisplayPanel` 加 `mode`：动态形态显示【仿真场】（音符速度 + 镜向）+【画布显示】+【音符皮肤】，静态形态那两组（标记 / 导出信息）不显示。
- `scripts/sim-shot.mjs` + `scripts/README.md`：像素验收脚本（照 `preview-shot.mjs` 的惯例）——建工程 → 贴样例谱 → 动态预览 → 抓场地原生位图（暂停 / 播放中 / seek 中段 / 末段）+ 页面截图，打印场地比例与位图尺寸；素材缺席时打印空态与获取命令。

**改了什么（既有文件）**

- `AppSettings`：`settings.preview.noteSpeed`（新增字段，additive 不 bump schemaVersion）+ `SIM_NOTE_SPEED_RANGE`（1..11 步长 0.5 默认 9.5）+ 归一化；`EXPORT_MARKERS` 补该字段的默认值（导出面板出图不读它）。
- `rendering/skin/noteSkin`：`ActiveNoteIcons.simultaneousLine`（新出口，同时点击线官方精灵；进 `preloadSrcs`）。
- `rendering/render`：`singleIconConfig` / `slideNodeIconConfig` / `dirSideOf` 的入参由 `RenderCtx` 收窄成结构子集 `IconChoiceCtx`（行为不变；仿真场因此能用**同一份选款口径**，不必造一整个帧上下文），`dirSideOf` 转为 export。
- `CONTEXT.md`：仿真场 / 接近模型 / 设计面 三条词条按实现收紧（音频与播放条、`t_now − t_note ∈ [−T, 0]` 的渲染窗口与档位取值、设计面的 contain 与钳制）；「预览标注」词条补一句"同段还带音符速度"。
- `docs/adr/0017`：§2 表登记新链路「仿真场舞台画布」= **同"工作台画布"那一行**（`min(设备像素比, 画质档)`；逐帧直绘，没有"烘一次位图再交给浏览器显示"的环节），§变更触发补一句"逐帧直绘的画布不是本不变量的对象"。

**口径（不另立一套）**

- `beat < 0` 的可击打物：**不渲染、不键音、但计 combo**（负 beat 击打物，ADR-0014 / CONTEXT）——所以仿真场的 combo 走**画布那份枚举** `NoteEditing.comboNodePreciseBeats`（单键/方向键各 1、滑条逐非 hidden 结点），不是键音事件表；实现在 t = 0 时就已经把负 beat 那批算进去了。
- 倒流区：带体取点走 `displayConnections` 同一显示投影（排序 + 掐首尾 hidden）；元素按**播放时钟**升序排（折返层里先画时间早的那一点），带体两端照实折返、不做任何"排序修正"。
- 带体：票面的「相邻 `(lane, A)` 两点构成四边形」——投影序相邻两点各一个四边形（SP 曲线由段内 hidden 采样点折出多个四边形），不透明度过线 / 未进场的一端由 `clampApproach` 钉在 `[0.05, 1]`。
- 镜向：车道对调用编辑器那份 `mirrorLane`（`NoteEditing` 的唯一实现），侧别翻面用 `dirSideOf`；方向键的**外侧箭头按原始 `length` 定位**（源数据允许小数，ADR-0014 §3），本体数仍 `ceil`。
- 同时点击线：同 tick 分组、链式相邻、只端点（含滑条起止结点）参与 —— 与编辑器那份同口径；线上用官方 `simultaneous_line.png` 精灵横向拉伸（编辑器画布那套自绘细线不动）。
- 音符尺寸：`1.35 × noteSize × laneWidth × A`（照 Bestdori `a = 1.35 × styleNoteSize`），三类音符共用一份基准缩放、按 `rendering/primitives/noteMetrics` 的设计尺寸折算（方向键自然比单键宽 1.25 倍，与画布相对比例一致）。

**code-review 两轴走查后回修**（Standards / Spec 各一轮，见下）：combo 口径（原按键音事件表数 → 改成画布那份枚举，负 beat 那批开播即计）、带体分片改回"两点一个四边形"、方向键箭头按原始 length 落位、页面失活停声、`IconChoiceCtx` 去掉没人读的 `noteSize`、`SimPlayback` 去掉没人用的 `isPlaying/seconds`、barrel 只留消费方要用的面、`.preview-static` 更名为 `.preview-controls`（05 起动态形态也用这条壳）。
