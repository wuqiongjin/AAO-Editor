# 09-静态预览：技能发动标记（Skill 矩形框）

Type: feature
Status: open
Blocked by: 08

**来源**：2026-09-30 用户对票 08 二轮的意见第 9 条（"Skill 这个确实值得探索一下"）；用户在四答里选了**下轮单独做**。语义调研已在 08 票完成（Bestdori bundle 实证，见其 Comments）。

## Bestdori 实证（`ToolChartSimulator.95b33d9b.js`，08 票二轮核对）

- 选项 `chartSkill`：`my-text-select-single`，选项 = **关 / 5秒 / 7秒 / 8秒 / 全部**，默认 **全部**。
- 取值：`B = [0,5,7,8,8][chartSkill]` 秒 —— 「全部」在静态预览里与 8s 同值，但**额外**把 5s / 7s 两条刻度也画出来（`4 === chartSkill && [5,7].forEach(...)`）。
- 画法（静态预览 `MySongChart`）：
  - 竖线 = 轨道右外缘 + 1 个车道宽（`u = s + 1 * laneWidth`），从技能起点画到 `起点 + B 秒`；
  - 横线（上/下边）从**轨道左缘**（`c = n`）画到那条竖线 —— 即一个横跨轨道 + 右沟槽的"矩形带"；
  - 标签 = `#(序号)`，写在 `s + 1.5 * laneWidth`（右沟槽），字号 = 1 个车道宽，纵向钳进画布；
  - 颜色 = `rgba(255, 255, 0, 0.5)`（**黄色**，不是红色 —— 用户记忆有偏差，取色要重定）。
- 数据源：Bestdori 的 `skills[]` = 技能键的时间数组。

## 我方数据面

- 技能键 = **带 `skill: true` 的单键**（`ChartNote.skill`，issue 147：只有不带 flick 的单键才是技能键款式）。数量足够画框；**没有**技能时长数据（Bestdori 的 5/7/8 是"技能效果持续秒数"的档位选项，不是谱面数据）。

## 要拍板的口径（开票时逐条问）

1. **右沟槽排布**：Combo 数字（08 票已落）与技能框标签同在右沟槽，BPM 数值在我们这侧在左沟槽 —— 撞位时谁让谁（Bestdori 自己是叠着的）。
2. **取色**：照 Bestdori 的黄，还是用户印象里的红（与 START 青 / END 橙 / 选中黄 / 危险红 的既有语义色错开）。
3. **「全部」档**：照 bundle = 5s、7s、8s 三条刻度同标（推荐照抄）。
4. **框的几何**：照 Bestdori（横线跨轨道 + 右侧竖线）还是只画右侧竖带（130px 面板里横跨轨道的框可能压住音符）。
5. **落设置**：`settings.preview.skillMarks: 'off' | 5 | 7 | 8 | 'all'`（白名单 + 归一化 + 面板下拉，照 08 票的时间标记同款）。

## 落点（预案）

- `src/chart/config/AppSettings.ts`（`preview.skillMarks` + 白名单）、`src/rendering/types.ts`（`skillMarks?: number | 'all'`）、`src/rendering/render.ts`（`renderSkillBands`，编排在沟槽层）、`src/pages/preview/PreviewDisplayPanel.tsx`（标记组加一行）。
- 渲染顺序：与 `renderComboMarks` 同层（沟槽层），在 BPM 数值之下。

## 锁测（预案）

- 单测：每个技能键一枚框；时长换算（5/7/8 秒 → 布局轴长度 = 秒 × virtualPxPerSecond）；「全部」档三条刻度；纵向/横向钳制；`skillMarks` 缺省 = 不画。
- DOM/像素：技能键谱面截图人工验收（单测测不到观感）。
