# 31 · 开场段现场环境音

Type: grilling
Status: open
Blocked by: 30（开场功能本体落地后才有可挂的时间线；07 的导出链路也要通）

**来源**：2026-10-11 用户提（在票 30 原型定档之后）：「在这 5s，官方游戏中有对应的音效，类似那种 live house 中台下人潮中的嘈杂声音，然后等到游戏正式播出（live 开始），台下声音就没了。」

**用户问过"现在做还是先按原型把票 30 完成"** ⇒ 结论是**先做票 30**（已记在票 30 第七轮与 ADR-0016 §5.1）。理由留档：
① 票 30 落地前，`renderAudioTrack` 连 `OPENING` 偏移都还没有 ⇒ 环境音要对着一条尚不存在的时间线写，本体落地后要重接；
② 它是**纯听感**观感（"像人潮"还是"像电流沙沙声"），只能在导出物上验收，得先把导出接通。

## 现状（2026-10-11 核实）

- **素材侧没有任何环境音**：全仓只有 12 个键音 mp3（`src/assets/audio/keysounds/`），无 crowd / ambient / live / 人声 / UI 音效。
- **也没有取件通道**：`scripts/assets-sync.mjs` 只整根同步 5 个根（含 `src/assets/audio/keysounds`），且**整根覆盖**（手加文件会被下次 sync 抹掉）；`AssetsSync.test.ts` 反向断言这些根不在 git 索引。能拉音频的脚本（`fetch-bestdori-official.mjs` / `fetch-bestdori-community.mjs`）**只拉 BGM**。⇒ 新增素材要动外部快照仓，且撞 ADR-0016 §5.1 的「零素材改动」。
- **离线音轨结构够用**（`src/preview/video/encode/renderAudioTrack.ts`）：`OfflineAudioContext` + `master`(主音量) / `se`(键音) 两层 gain + 每事件 `source → gain(envelope) → dest`。再加一路环境音 = 多一个 `AudioBufferSourceNode` + 一个 gain + 一条包络（写法可抄 `keySoundSamples.ts` 的 `scheduleKeySample`）。
- **程序化合成无先例**：仓内 `createBuffer(` / `getChannelData(` 只出现在 muxer 的读 PCM 平面，**没有任何手动填 Float32Array 生成声音的先例，也没有 `createBiquadFilter`**。有 `scheduleKeyTone`（OscillatorNode + 包络）可参考包络写法。

## 要拍板的三条（本票的 grill 点）

1. **素材 vs 程序化**：倾向**程序化合成**（白噪声 + 滤波 + 包络 ⇒ 零素材、零取件、与「程序化 / 确定性」取向一致），但要接受"可能听起来像电流声、要反复调"；若坚持素材路线，要先解决快照仓与 ADR 冲突。
2. **口径变更**：ADR-0016 §5.1 现在写的是「**开场段无 BGM / 无键音**」（定案 2 的"开场段无声"）。加环境音 = 把这条改成"有声"，属于 ADR 口径变更，要用户点头。
3. **配置与文案**：总开关下再挂一项？默认开还是关？有没有独立音量（还是跟 `settings.audio.volume`）？i18n 键？锁测怎么写（单测覆盖不到听感，需像素/波形断言 + 手工验收）。

## 实现落点（拍板后填）

- `renderAudioTrack` 增一路 ambient：`source → ambientGain(envelope) → master`，起点 0、长度 = `OPENING_SECONDS`，尾端**短淡出**掐掉（"live 开始就没了"）。
- 帧数公式不变（`OPENING_SECONDS + 谱面时长`），BGM 仍 `start(OPENING_SECONDS)` —— 环境音与 BGM 在时间上**首尾相接、不重叠**。
- 配置项：`settings.export.opening.ambient`？还是挂在 `settings.audio`？待拍板。

## 锁测

- 待拍板后补。方向：`renderAudioTrack` 在 `opening != null` 时**前 N 秒有非零采样、第 `OPENING_SECONDS` 秒之后为静音**（用 OfflineAudioContext 渲出 buffer 断言 RMS），以及"关掉环境音时开场段全静音"。
