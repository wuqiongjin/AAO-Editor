# 26 · 模式切换（静态 / 动态）：页头「静态预览 / 动态预览」两枚按钮整体位移

Type: bug
Status: open（2026-10-09 根因已实测坐实，未改代码；修法待拍板）
Blocked by: —

## 来源

2026-10-09 用户：预览页从静态预览切到动态预览后，左上角这两枚模式按钮的位置会移动（附截图）。

## 症状（本机 Playwright 实测，1490×900 / DPR 1）

| | 页面 padding | `.preview-header` top | 静态预览 btn (x,y) | 动态预览 btn (x,y) |
|---|---|---|---|---|
| 静态 | `24px 24px 16px 24px` | 24 | (76, 24) | (192, 24) |
| 动态 | `12px 12px 8px 12px` | 12 | (64, 12) | (180, 12) |
| Δ | | **−12** | **(−12, −12)** | **(−12, −12)** |

两枚按钮自身尺寸不变（`110×34` 两种模式相同），是**整块页头被页面留白推着走**。

## 根因（已实测坐实）

`src/pages/preview/PreviewPage.css` 里，动态形态挂 `.is-video`（`PreviewPage.tsx` L211），而：

- `.preview-page { padding: 24px 24px 16px; }`（L17）
- `.preview-page.is-video { padding: 12px 12px 8px; }`（L744）—— 票 19 的「动态形态减 chrome，把高度还给画面」

**页面 padding 同时是页头（`.preview-header` → `.preview-modes` → 两枚按钮）的起始锚点**，于是 padding 一收，页头整体上移 12、左移 12（Δx = Δy = −12）。

这与票 19 §3 的既定口径直接冲突：票 19 §3 写「页头（模式切换行）/ 工具栏 / 谱面切换器**不动**」，但 §2 的 padding 覆盖把这个"不动"破坏了 —— 这是本票要修的口径矛盾，不是新增语义。**不属票 15**（票 15 是工具栏行高，动的是工具栏左簇；本票动的是页头按钮，且幅度是整 12px 而非亚像素）。

## 修法（用户 2026-10-09 拍板：**A · 页头优先**）

本质是**取舍**：票 19 想要"把 chrome 的高度让给画面"，而页面 padding-top / padding-left 贡献的那点高度，正是页头锚点。二者不可兼得。

- **A · 页头优先（拍板）**：动态形态只收底部 padding，`padding-top` / `padding-left` 保持与静态态同源的 `24px` ⇒ 页头两按钮切换时纹丝不动。
  - 落点建议：`.preview-page.is-video` 由 `padding: 12px 12px 8px` **收成只覆盖 `padding-bottom: 8px`**，其余三条继承 `.preview-page` 的 `24px 24px 16px`（左右那 12px 不必收 —— 见下）。
  - **左右 padding 收不收对画面没影响**：contain 是**高度受限**（实测左右剩余黑边各 94px），宽度有富余 ⇒ 收左右的 12px 让不出任何场地尺寸（实测 A1 `24 24 8 24` 与 A2 `24 12 8 24` 场地尺寸**完全相同**）。故左右干脆不收，省一处不对称。
- ~~B · 画面优先~~（未采纳）：维持现状，把位移登记为既定行为。
- ~~C · 只钉页头~~（未采纳）：给 `.preview-header` 单独补偿 padding，等于 A 的等价形态但多绕一层。

**A 的画面代价（实测，`.cache/pv-size.mjs`）**：场地 `−21 × −12` px，面积 **−2.5%**（1920×1080）/ **−1.8%**（2560×1440）—— 肉眼不可见（对比票 19 当年给的收益 1920×1080 仅 +7%，本处吐回 2.5% 属可接受）。

## 锁测（Type: bug 强制）

jsdom 无布局引擎、`getBoundingClientRect()` 恒 0，量不到几何 ⇒ 走 **Playwright 几何实测**（手法照票 15 末尾）：起 dev server → 打开预览页 → 切静态 / 动态 → 断言 `.preview-modes__btn` 的 `x` / `y` **都不变**（当前实现必红：Δ = −12，−12）。接线层（`.is-video` 是否挂上）可由 `tests/static/PreviewPageWiring.test.ts` 兜住。
