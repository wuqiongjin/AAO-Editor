## 用大白话讲清楚「现在哪里不统一」

现在有**两个互不相干的音量数值**：

- **A = 全局值**（`settings.audio.volume`，存盘，默认 1）：动态预览播放条、导入详情试听条、
  视频导出都读它，任一处调了另外两处跟着变。
- **B = 工作台专用值**（`PlaybackContext.volume` + `AudioSession._volume`，不存盘，默认 0.8）：
  只有工作台播放条用它。

用户能感知到的三件事：

1. 在工作台把音量调到 0.3 → 切到动态预览还是 1（反过来也一样）；
2. 重启软件 → 工作台又回 0.8；
3. 什么都不动时，工作台比另外两处**小声**（0.8 vs 1）。

「统一」= 撤掉 B，让三处都读写 A。它**不**包含「三处听起来一样响」：导入详情那条是纯
`<audio>` 试听条，不播键音，本来就不是同一种声音（见下）。

## 关于「0.8 还是 1」（事实澄清）

两份默认值来自两处代码，互不覆盖：
`src/settings/AppSettings.ts:496` `defaultSettings().audio.volume = 1`（全局、存盘）；
`src/app/providers/PlaybackProvider.tsx:38` `useState(0.8)` 与 `src/audio/AudioSession.ts:134`
`_volume = 0.8`（工作台、纯内存）。Q7 统一 = **丢弃 B、保留 A**，因此全局默认值**仍是 1，没有被改**；
变的只是工作台的「有效默认」从 0.8 变成 A 的当前值。凡是曾在动态预览 / 导入试听条动过音量滑杆的
用户，A 里已存着他们自己的值，工作台会直接沿用，对他们没有响度变化。

若把「统一后的默认」也定为 0.8，就得把 `defaultSettings().audio.volume` 与 `mergeSettings` 的
回落值从 1 改成 0.8 —— 会**连带调低动态预览、导入试听条、视频导出**的默认响度，
且只作用于「设置里还没存过这个字段」的旧存档（已存 1 的用户仍是 1）⇒ 同类用户两种结果。

## 根因（已核实）

- 已共享 A：动态预览 `src/pages/preview/PreviewPage.tsx:434-435` → `PlayBar` → `AudioEngine.masterGain`；
  官方 / 社区导入详情试听条 `OfficialSongPanel.tsx:568-569`、`CommunityPostPanel.tsx:632-633`
  → `src/ui/CompactAudio.tsx:44-48` 的 `<audio>.volume`；视频导出
  `src/preview/video/encode/renderAudioTrack.ts:79-84` 只读它。
- 唯一断点 = 工作台：`src/app/providers/PlaybackProvider.tsx:38` `useState(0.8)` +
  `src/audio/AudioSession.ts:91,134` `_volume(0.8)`；`src/app/providers/AudioSessionRoot.tsx:18-32`
  构造与 settings 同步 effect 都**只注入 keySet / seVolume**；`WorkspacePage.tsx:340-343` 的滑杆只写这两份内存态。
- 这是 [20](./20-动态预览播放器控件.md):18,92 的定案「工作台那档页面内主音量…本票不动」，不是漏实现；
  票内留了「若验收时觉得别扭，再开票收敛」，该收敛票即本票。
- 结构性差异（与本票无关，别混）：导入详情试听条是 `<audio>`，无键音、无 `seVolume` 层；
  `settings.audio.seVolume` 是另一根独立滑杆；音频页键音试听的前置增益反而取自工作台的 B
  （`AudioPage.tsx:336-341` ⇒ `AudioSession` ⇒ `AudioEngine.seBus()`）——退役 B 后它自然跟 A 走。
- 本票按「第三处 = 导入详情里的 `CompactAudio` 歌曲试听条」记账（已核实：该处没有谱面画面回放 /
  键音；工程详情的「预览」按钮是跳预览页，也已用 A）。用户未更正，视为确认。

## Answer（用户 2026-11-07 Q7 / Q9 = OK）

**定案（用户 2026-11-07）**

1. **统一**：撤掉工作台那份 B，工作台播放条读写 `settings.audio.volume`（跨重启记住）、
   退役 `PlaybackContext.volume` 与 `_volume` 的独立 0.8；不改引擎、不动导入试听条、
   **不给试听条加键音**、`settings.audio.seVolume` 保持独立。
2. **默认保持 1**：`defaultSettings().audio.volume` 与 `mergeSettings` 回落值**一字不改**，
   不改动态预览 / 导入试听条 / 视频导出的既有响度；工作台只是从 0.8 跟到 A。
3. 没有其它待拍板项；`0.8 → 0.8` 的「全局默认改小」方案**否决**。
