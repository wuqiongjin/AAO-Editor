# 29 · 预览页「设置」面板：窗口伸缩时停在原地不跟随

Type: bug
Status: resolved（2026-10-09 实现 + 锁测 + 真机复核全过；**待用户验收**，实现与复核数值见文末 Answer）
Blocked by: —

## 来源

2026-10-09 用户报障（静态 / 动态两种形态都有）："预览页面的设置按钮点击后的设置弹窗，当窗口尺寸变化时，弹窗不会跟随位置，而是停留原地。"

## 症状（Playwright 实测，`.cache/pv-panel-follow.mjs`）

1600×900 点开「设置」→ 一次性放大到 1920×1080（模拟最大化：单发 resize）：

| 静态形态 | 触发钮 right | 面板 left | 贴右缘差（面板 right − 钮 right）|
|---|---|---|---|
| 开面板 | 1418 | 1098 | +14（见根因 #2）|
| 放大后 | **1738** | **1098（没动）** | **−306** |
| 缩到 1180 | 998 | 1098（没动） | +434 ⇒ 面板右缘 1432 超出视口 252px，**右侧控件跑到屏幕外** |

动态形态（.cache 同脚本 `video` 档）同一组数：触发钮 right 1497 → 1817 / 1077，面板恒 stop 在 left 1177。
两种形态共用同一份组件（`PreviewDisplayPanel`），故一起坏。

## 根因（代码走读 + 实测坐实）

**#1 快照式定位，无伸缩监听**：`src/pages/preview/PreviewDisplayPanel.tsx` L254-264 —— `pos` 只在**点开那一刻**量一次触发钮矩形（`getBoundingClientRect()`），此后没有任何 `resize` 监听。
同仓同款浮层 `src/ui/ScopePicker.tsx` L94-102 / L118-137 早有「开着时跟随」（2026-10-05 票 11 #1 音频页报的同一现象）：`resize` → 重新量 → 双层 rAF 补测 + 等值守卫。本组件缺的正是这一段。
（对照实测 `.cache/pv-panel-follow2.mjs`：ScopePicker / ChartSwitcher 在 1600 → 1920 下触发钮一动不动、面板当然也不动；只有右簇的设置面板触发钮 right 1418 → 1738 ⇒ 病灶只在"右锚 + 触发钮随窗宽移动"这条路径上。）

**#2 用内容宽当盒宽（顺带发现，同一处公式）**：`PANEL_W = 320`（L44）被当成面板总宽用（L259 `left = r.right - PANEL_W`），而 `.pdp__panel` 是 content-box（`width: 320px` + padding 6×2 + border 1×2）⇒ 实测盒宽 **334**，**开面板那一刻右缘就偏 14px**（上表第一行）。用户 2026-10-09 拍板一起修。

## 修法（本轮口径，待验收）

1. 照 `ScopePicker` 补「开着时跟随」：`open` 期间挂 `window.resize` → 重新量触发钮（当帧快测 + 双层 rAF 补测）→ 等值守卫防冗余重渲；视口夹取沿用开面板那条（`left` 夹进 8px 留白、`top = r.bottom + 3`）。
2. `PANEL_W` 改按**盒宽**算（320 内容 + 14 壳 = 334），并加静态锁盯住 CSS（`.pdp__panel` 的 width / padding 与 `.pp-menu__panel` 的 border 任一变动 → 测试红）。备选：面板改内联 `width` + `boxSizing: border-box` 让 JS 成单一真源（照 `ScopePicker` 的做法），代价是内容宽 320 → 306 的看相微变 —— 实现时二选一，默认走前者（看相零变化）。
3. **顺带同页谱面切换器**（`PreviewChartSwitcher.tsx` L32-40 同一病灶）：实测常规伸缩下它**没问题**（左簇左锚不动）；唯一破口是跨 720 断点（页面 padding 24 → 16）后 8px / 4px 脱节（`.cache/pv-switcher-follow.mjs`：721 → 719 时 Δ左缘 8 / Δ上缘 4，回宽自动恢复）。用户 2026-10-09 复核后按推荐一并修（同一段 effect）；要最小改动可只留第 1 / 2 条。
4. 工作台 `ChartSwitcher` / 工程页难度浮层同款病灶**不在本票**（"portal + 遮罩 + 定位各写一遍"的债，票 22 已登记）。
