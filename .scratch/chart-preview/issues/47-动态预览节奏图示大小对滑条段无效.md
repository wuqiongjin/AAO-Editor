# 47 · 动态预览「节奏图示大小」对滑条段无效

Type: bug
Status: resolved 实现（2026-10-17；待用户验收）
Blocked by: none

## 来源与症状

用户报：动态预览里调「设置 → 节奏图示大小」，单键 / 滑条结点图标都跟着变大变小，但滑条的**段**（相邻可见结点之间的带体）宽度纹丝不动。带子与音符的宽度比随 noteSize 漂移（本该是常数），调大后结点明显比带子宽，观感上"结点与带子脱节"。

## 根因

- `bandQuad`（`src/preview/video/sim/simGeometry.ts:270`）的边宽只有 `laneWidth × A`，**没有乘 `noteSize`**；唯一调用点 `drawBands`（`src/preview/video/sim/simField.ts:452`）也没把 noteSize 传进来。
- 同一条绘制链上其余尺寸都乘了 noteSize，只有带体漏了：
  - 音符盒子 `simNoteRect`（`simGeometry.ts:326`，宽 = `1.35 × noteSize × laneWidth × A`）
  - 同时点击线 `simDualLineThickness`（`simGeometry.ts:348`）
  - 按住端点 / 连按环 `drawHoldEffects`（`simField.ts:976 / 990 / 997`）
  - 命中特效 `drawSpriteEffect`（`simField.ts:832`，`EffectCanvas.size = noteSize`）
  ⇒ 用户看到的现象精确对应"只有段不变"。
- 画布侧口径本来就是同步的：`renderSpanBands` / `renderSegmentBand` 的 `half = LANE_WIDTH × viewport.scale × noteSize / 2`（`src/rendering/render.ts:894 / 918`，issue 39 #1 补修注释原文即"连接带宽度与结点图标同步 × noteSize，避免调大小后带与结点脱节"）。静态预览走同一套 `renderNotes` ⇒ **只有动态预览这一路漂了**。
- 量化（1334×750 场地，laneWidth 154；带 : 音符 宽度比）：noteSize=1 → 154 : 207.9 = **0.74**；noteSize=2 → 154 : 415.8 = **0.37**；noteSize=0.1 → 154 : 20.8 = **7.4**。画布侧该比值恒为 30 : 36 = 0.833（与 noteSize 无关）。
- 口径取舍：本票按**与画布一致**（issue 39 #1 补修）修，即段宽随 noteSize 缩放。若未来要严格照 Bestdori 的"带体恒 1 lane、只有音符随 styleNoteSize"对齐，得连画布一起改，属另一次口径变更，本票不涉及。

## 修法

- `bandQuad` 增 `noteSize` 入参，半宽改 `laneWidth × noteSize × A / 2`；`drawBands` 传 `scene.noteSize`。
  **实现偏离票面一处**：开票时写的是"默认 1"，实作为**必填参数**（不设默认值）—— 正是"漏传即漂"的缺陷本身，
  默认值会让下一个调用点静默回到本次的 bug；改成必填后由编译期逼出所有调用点（现只有 `drawBands` 一处 +
  两条锁测）。既有断言值一字未改，只是补传 `1`。
- 亮缘（`bandRimQuads`）从四边形自身半宽推出，自动跟随；绕向归一、自叠交集、过线端插值（`bandLaneAt`）、可见窗口、绘制序、材质采样**全不动**。
- 影响面：实时回放与离线视频导出共用 `drawSimFrameAt`，一处改对两处生效；画布 / 静态预览本来正确，不动。

## 锁测

- `tests/unit/preview/video/SimGeometry.test.ts`「带体四边形」：既有两条补传 `noteSize = 1`、断言逐位不变（仍绿）；新增一条 noteSize=2 ⇒ A=1 时 a 边宽 = 2 × laneWidth、A=0.5 时 = laneWidth（修前恒 laneWidth）。
- `tests/unit/preview/video/SimField.test.ts`：新增「scene.noteSize=2 ⇒ 体批次四边形 a 边宽 = 2 × laneWidth」与「亮缘宽度 = 段平均半宽 × rimFrac（跟着段宽走，放大后不变发丝线）」；既有 `t1 === t0` 顶点锁测（`laneWidth/2`、scene noteSize=1）保持绿。
- 单测即可覆盖（带体是几何填充，记录型 ctx 能拿到顶点）；本工作区无 `docs/resource/bestdori` 素材（仿真场空态），逐帧像素脚本跑不了，浏览器复核留给用户实机；回归清单 = issue 45 绕向归一 / issue 46 材质分层 / 票 23 #1 顶点序与过线端插值。

## 相邻观察（本票不修）
