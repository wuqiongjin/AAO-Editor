# 54 · 中央章入场重做：字母阶梯落下 + `!` 下的星标飞行

Type: feature
Status: resolved（2026-10-28 用户「原型已定」后落生产；待验收观感）
Blocked by: —

## 来源

用户 2026-10-28：中央章 `ALL PERFECT!` / `FULL COMBO!` 的入场「只是从左到右擦入」，要改成逐字母 + 星标分层的动效。
票 52 的 Comments 末尾「章入场逐字登场（登记后续）」即本条。

## 现状（改之前）

整张 `stamp-*.png` 一次 `destination-in` 羽化擦入；星星是图里的一块，跟着整块一起被擦出来。

## 本轮实现口径（待验收）

- **字形切块**：按彩色核心算 Voronoi 归属，白描边按就近分给相邻字 —— 切出 N 块，每块可独立动，落定后拼回原图（1:1 叠图实测只剩重采样边缘差）。
- **字母**：线性下落（`letterBounce = 0` 即等速，阶梯间距均匀）+ 入队即 `letterInAlpha`、落位补到 1；队列长度 ≈ `letterDur / 相邻间隔`。`!`（闪电）走同一套、排最后。
- **星标**：切块时把「贴底 + 近正方形」那块识别成星，从字母层摘出单独渲染 —— 正中变大 + 旋转 → 飞到 `!` 下方（缩小 + 转正）→ 落位。
- **两枚影子材质不同**：飞行时那枚是**纯色圆角五角星**（矢量绘制，`ghostTint`，`auto` = 按星的代表色自动取、往白里混 30%）；落位后那枚仍用原图贴图，只放大不旋转。
- 用户可调参数全部进 `ENDING_SPEC`（+20 键；另 `stampIn` 1→1.3），曲线 / 圆角这类形状常量留在绘制里，`public/proto/scenes.html` 可拖（含颜色选择器 + 「自动」回退）。

## 锁测

- `tests/unit/preview/video/EndingFrame.test.ts` 的参数表快照锁 20 个新键的默认值（含 `ghostTint` / `starHold`）。
- `tests/static/EndingWiring.test.ts` 新增「54 · 中央章入场分层」三条静态锁：① 切块 / 逐字母波 / 星标单画三层齐备且 `drawWordWipe` 兜底还在（星标必须从字母层摘出）；② 影子基准取 `inkW`（字芯）而不是整块框、飞行影子是矢量纯色星而落位影子走贴图；③ `starHold` 与「变大用 smooth」这两个时间轴口径。
- 切块 / 飞行 / 影子是 Canvas 像素与观感，**单测覆盖不到**（node 无 canvas，`wordLayer` 直接退化成纯字擦入）：替代验证 = 原型逐帧截图（`?scene=ending&stamp=ap|fc&t=…`）+ 上面的静态锁 + 手工验收清单（AP / FC 各导一条看章段）。

## Comments

- 2026-10-28 第一轮：`endingFrame.ts` 新增 `wordLayer`（切块 + 星识别）/ `drawGlyphWave` / `drawStampStar`，`drawWordWipe` 保留为缺件兜底。
- 2026-10-28 第二轮（用户纠正 5 点）：字母改「排队阶梯」（线性位移 + 入队半透明）；`letterDrop` 上限 30→120；飞行影子改**纯色**（第一版用贴图 alpha 当遮罩，放大到 4× 糊成一团 → 改矢量圆角星）；`ghostGrow` 上限 4→12；落位影子不动。
- 2026-10-28 第三轮：`ghostTint` 可调（默认 `auto` = AP 淡蓝紫 / FC 淡粉）；圆角改逐顶点 `quadraticCurveTo` + 只 fill（同色描边会在半透明处二次叠加出深边）；默认值按用户新 JSON 写回（`letterSpan 50` / `letterDrop 32` / `ghostAlpha 0.6` / `ghostGrow 10` / `ghostSpin 35`）。
- 2026-10-28 第四轮：`starHold`（变大结束 → 起飞之间的停顿，%stampIn）从「easeInOut 的起步缓坡」变成显式参数，飞行改 `easeOutCubic`（起步就动）；`ghostTint` 默认值写回 `auto`。**FC 影子比 AP 大一圈**的根因 = 影子尺寸用了字形整块框（含白描边，两张章描边厚度不同），飞行影子改用 `inkW`（彩色字芯宽）后两边一致；**落位影子仍用整块框**——它是贴图复刻，1× 时必须与星本身严格重合。默认值按用户新 JSON 写回：`starAt 7` / `starGrow 35` / `ghostAlpha 0.7` / `ghostSpin 50`。
- 2026-10-28 第五轮：**`starHold = 0` 仍有停顿** —— 根源不在 `starHold`，在「变大」用的 `easeOutCubic`：它 60% 的时长就长到 95%，后 37%（≈0.17 s）几乎不动，看起来就是一段说不清来源的停顿。改成 `smooth`（尾段仍在变），`starHold` 默认写回 0，飞行保持 `easeOutCubic`（起步即走）。
- 2026-10-28 结票前评审修正：飞行影子的时间轴从 `growEnd` 改挂 `flyStart`（`starHold > 0` 时影子不该在停顿里先长大）；删掉没用上的 `inkH`。
