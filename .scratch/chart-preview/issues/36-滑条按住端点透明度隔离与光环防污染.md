# 36 · 滑条按住端点透明度隔离与光环防污染

Type: bug
Status: resolved
Blocked by: none

## 来源与症状

- **症状**：滑条在按住情况下，判定线上的端点图标显示效果异常：会先变"浅"（半透明发白），离滑条快结束时突然变深。
- **用户要求**：全程应该是一个效果，不应该发生明暗/透明度的跳变。

## 根因

1. **按住初期变浅（粒子特效残留 alpha 污染）**：
   - `src/preview/video/sim/simField.ts` 中 `drawEffects` 循环绘制命中特效时，`drawSpriteEffect` 直接把 `c.ctx.globalAlpha` 设为渐隐系数（例如 `A.ring * (1 - easeInCubic(p))`），循环结束后未重置 `ctx.globalAlpha = 1.0`。
   - 紧接着调用的 `drawHoldEffects` 在绘制判定线端点（`spriteIcon.render`）时，继承了该残留的超低 alpha，导致端点被绘制成浅色半透明；加之上方叠加的连接环与旋转光环，视觉上泛白变浅。
2. **快结束时变深（末结点自然下落与端点物理叠合）**：
   - 滑条末结点作为独立音符在 `chart.elements` 中下落。在快结束时（最后约 0.8s 内），末结点以正常不透明度落到判定线上，与判定线上原本被污染成半透明的按住端点发生物理重合，导致端点瞬间变深变浓。

## 修法

1. **严格隔离 Canvas globalAlpha 状态**：
   - 在 `drawEffects`、`drawSpriteEffect`、`drawHoldEffects` 确保绘制前后严格隔离 `ctx.globalAlpha`；
   - 在绘制按住端点精灵前显式强制 `ctx.save(); ctx.globalAlpha = 1.0; ... ctx.restore();`，彻底消除残余 alpha 污染。
2. **保证全程 100% 不透明度饱满渲染**：
   - 使判定线上的按住端点本体全程保持 1.0 不透明度，消除因 alpha 残留与末结点重叠引发的跳变。

## 锁测

- `tests/unit/preview/video/SimField.test.ts`：
  - 增加断言：在命中特效窗口内（`since ∈ [0, 0.6s]`），`drawHoldEffects` 绘制端点时的 `ctx.globalAlpha` 恒为 1.0，全流程无透明度降级。
- `tests/support/canvas.ts`：
  - 强化 `makeRecordingCtx`，支持状态属性与 `save`/`restore` 栈追踪。
