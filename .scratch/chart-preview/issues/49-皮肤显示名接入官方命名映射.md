# 49 · 皮肤显示名接入官方命名映射

Type: feature
Status: resolved（应用侧 2026-10-22 实现完毕并提交；取件侧升级后快照带 `skinName` 即自动生效）
Blocked by: —

## 来源与症状

用户 2026-10-22：素材仓三类皮肤（音符 / 轨道 / 背景）用户可见的名称是无意义编号——音符皮肤显示
"Skin 00"、轨道/背景在预览页设置面板直接显示包 ID（`skin00` / `skin_maid` / `collabo23_summer_g`），
用户大概率看不懂。要求：确定这些皮肤**有意义的命名**。

调研结论：`docs/research/skin-naming-sources.md`（2026-10-22 实测）——Bestdori 官方皮肤命名 API
存在（`/api/skin/{notes,directionalFlicks,lanes,backgrounds}.all.3.json`，五服本地化含简中），
无需人工起名。

## 根因

- **"Skin 00" 是手写的**：来自已删除的 `scripts/fetch-target-note-skins.mjs` 的 `label` 字段
  （git `7d482708` 可证）；取件侧迁出后随快照再生，来源依旧是人写，无权威依据。
- **轨道/背景压根没有名字段**：`simAssetPacks.gen.ts` 的 entry 只有 id + 文件名，UI 直接渲染
  包 ID（`PreviewDisplayPanel.tsx:321`）。
- ADR-0018 §1 原定「显示名 = 包 ID、不人工起中文名」是在不知道官方命名 API 存在的情况下做的；
  其否决理由（"编号包起不出名"）对轨道皮肤已不成立——官方恰好命名了 15 个编号轨道包（8 个乐队名）。

## 定案（用户 2026-10-22 四问拍板，已回写 ADR-0018 §1 修订 + 新增 §6）

1. 命名源分层：**官方命名 API > 社区 fallback > 包 ID**；
2. 无官方名的主题包（轨道 18 + 背景 21）用 Sonolus 社区 fallback 规则生成英文显示名
   （`skin_maid`→Maid、`collabo23_summer_g`→Collabo23 Summer G）；
3. 中文显示名取**官方 cn 服条目优先**（`按键条皮肤00` / `Poppin'Party的按键条皮肤`），回退 en → jp；
4. 音符 TYPE 编号错位**照官方显示**（skin05=TYPE7、skin06=TYPE6）；
5. 键音包不在本票范围（维持「官方键音 00」手写 i18n 名，后续单独评估）。

## 实现落点

### 取件侧（素材快照产出侧，不在本仓；本票定接口契约）

- 拉四个 `*.all.3.json`，把显示名映射随 gen 注册表一起生成进快照（与二进制同版本，照
  `noteSkinRegistry.gen.ts` / `simAssetPacks.gen.ts` 先例）。
- 契约（应用侧只认这个形状）：
  - `noteSkinRegistry.gen.ts`：每个 pack 增 `skinName: string[]`（五服原样 `[jp,en,tw,cn,kr]`）；
    directionalFlicks 的 `assetBundleName` 前缀拼合（`skin00` → `directionalflickskin00`）在取件侧做；
    无官方名的包由取件侧按社区清洗规则生成 fallback 名填进 `skinName` 五格同值。
  - `simAssetPacks.gen.ts`：field / background entry 增同款 `skinName`。
- **快照未带 `skinName` 时应用侧回落现行为**（label / 包 ID）——应用侧先落地不依赖取件侧升级，
  快照升级后显示名自动生效（灰度安全、零迁移）。

### 应用侧（本仓）

- 显示名解析（数据驱动，**不走 i18n 消息表**——官方名是名称不是文案，且 69 个包 × 2 语言建 key
  属自维护映射，正是本次要消灭的东西；照键音先例改进：键音无 API 只能手写，本类有 API 应查表）：
  - 新模块 `src/rendering/skin/skinDisplayName.ts`：纯函数 `pickSkinName(skinName: string[] | undefined, locale, fallback)`——
    zh-CN 取 index 3（cn）→ index 1（en）→ index 0（jp）；en 取 index 1 → 0；`undefined`/空串 → fallback。
  - `noteSkin.ts`：`noteSkinPresetLabel()` 与包 label 解析改经 `pickSkinName`（fallback = 现 label）；
    `listNoteSkinPacks()` 的消费方（`AssetsPage.tsx:118`、`NoteSkinPreview.tsx:139-142`）显示名 + title 保留包 ID。
  - `simAssetPacks.ts`：`listSimFieldPacks` / `listSimBackgroundPacks` 的 entry 暴露显示名（或消费方经
    `pickSkinName`）；`PreviewDisplayPanel.tsx:321` `{pack.id}` → 显示名，title 改 `${full} · ${显示名}（${pack.id}）`。
- 设置兼容：设置存包 ID 不变（`settings.visual.noteSkin` / `settings.preview.*PackId`），显示名纯查表。
