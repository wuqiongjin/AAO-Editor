# 34 · 动态预览导出面板与失败提示整改

Type: bug
Status: resolved
Blocked by: none

## 来源与症状

1. **导出失败提示卡无法关闭且常驻**：导出视频失败或取消后，右下角的提示卡片常驻不消失，且没有任何按钮能手动关闭。
2. **导出弹窗条目术语与文案**：
   - 视频开场名词不准确，改为「曲目信息片头」（英文 `Song Info Opening`）；
   - 难度徽章、标题条、艺人行不准确，改为「难度」、「歌曲标题」、「乐队」；
3. **导出弹窗布局与交互**：
   - 「曲目信息片头」右侧开关未与下层条目对齐；
   - 描述文本不应单独占行，改为点击 `?` 图标弹出 Popover 气泡浮层查看详细说明；
   - 子项条目（难度、歌曲标题、乐队）与上方普通行需逐像素左对齐。

## 根因

1. **提示卡常驻**：
   - `src/pages/preview/VideoExportControl.tsx` 渲染 `notice` 时未提供关闭按钮；
   - 无超时自动清除机制；
   - `VideoExportControlProps` 未接通 `useVideoExport` 的 `dismissNotice` 回调。
2. **开关未对齐**：
   - `PreviewPage.css` 中 `.pvex__group-head` 缺少 `padding: 5px 8px`，且其内部 `.pvex__group-title` 缺少 `padding: 0`。
3. **子项缩进未对齐**：
   - `PreviewPage.css` 中 `.pvex__group--sub .pvex__row` 设置了 `padding-left: 18px`，导致比上层条目缩进过多。
4. **提示信息占行**：
   - 之前将整句描述以 `<p className="pvex__note">` 占行放置，挤占面板空间。

## 修法

1. **提示卡**：
   - `VideoExportControlProps` 增加 `onDismissNotice?: () => void` 属性并接通 `useVideoExport.dismissNotice`；
   - 提示卡右上角添加 `<IconButton icon={<X size={14} />} ... />` 支持手动即时关闭；
   - 增加 5 秒超时自动关闭定时器（组件卸载及 notice 变更时安全清理）；
   - 国际化补齐 `"dialog.close"` 文案。
2. **文案更名与精简**：
   - 中文更名为「曲目信息片头」、「难度」、「歌曲标题」、「乐队」；
   - 描述说明去冗余废话，精简为「在视频最前面加上约 {{seconds}} 秒的曲目信息片头。」；
   - 英文更名为「Song Info Opening」。
3. **布局对齐**：
   - `.pvex__group-head` 补齐 `padding: 5px 8px` 与 title padding 重置，使开关与下方行逐像素对齐；
   - 移除 `.pvex__group--sub .pvex__row` 的额外 `padding-left: 18px`，实现逐像素左对齐。
4. **`?` 图标 Popover 浮层**：
   - 标题旁放置 `<HelpCircle size={13} />` 按钮，点击展开独立气泡 `.pvex__help-popover`，支持点击外部或再次点击收起，同时保留悬停快速预览。

## 锁测

- `tests/dom/preview/VideoExportFlow.test.tsx`：
  - 断言提示卡有关闭按钮且点击触发关闭，断言 5 秒后自动消失；
  - 断言更名后的文案（「曲目信息片头」、「难度」、「歌曲标题」、「乐队」）；
  - 断言点击 `?` 按钮展开/关闭 Popover 气泡浮层。
