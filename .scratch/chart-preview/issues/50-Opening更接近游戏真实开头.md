# 50 · Opening 更接近游戏真实开头

Type: grilling
Status: resolved（2026-10-27 落生产）
Blocked by: —

**来源**：2026-10-26 用户：「优化 Opening 效果，让其更加接近于游戏真实的开头。（先调研游戏 Opening 是什么样子）」；明确对标实机，不对标 Sonolus / Bestdori。

调研：`docs/research/gbp-live-cinematic.md` §1。既有票：30（夹克画面已落地）、31（开场环境音，仍 open）、39（credits 绘制兼容、工程无数据）。

## 症状

用户觉得当前 Opening 还不够像游戏进 live 的开头。

## 根因（不是「没画」）

票 30 已经按游戏夹克截图重建了四段交叉淡（5.0s），装饰/版式/时长用户逐轮拍过板。现在不像实机，主因是**范围与数据**，不是绘制漏了：

1. **实时预览不演 Opening**（票 30 定案 11 / ADR-0016 §5.1）——舞台从谱面 0 秒起，只有导出物前面有 5 秒片头。
2. **作詞/作曲/編曲常空**：绘制层有 `OpeningCredits`（票 39），工程没有对应字段；`PreviewPage` 的 `(project as { credits })` 实际恒 `null`。游戏夹克这三行是常驻的。
3. **开场段无声**：游戏有人潮环境音；票 31 待拍板（本票不吞 31）。
4. **刻意不做的**：3D/Live2D 角色、加载不定时长、游戏 UI 原版装饰素材。封面比例 0.48H vs 游戏约 0.383H 是票 30 为标题条定位做的取舍。
5. **观感残留**：装饰用户已评「基本 OK」；若仍有截图对不上的点，要用户点名，不在本票猜测重画。

## 定案（用户 2026-10-26 · grill 第 1 轮）

1. **Opening 只在导出里演**（否决「实时预览也演」）。票 30 定案 11 / ADR-0016 §5.1 这条保持。
2. **夹克卡不推倒**：四段时长、装饰链、封面比例、credits 工程字段这轮都不动。
3. **本轮观感只三件**：(a) 字体要调；(b) 封面后堆叠层向右上缓出（游戏没有，先看原型）；(c) 环境音走票 31。

## 定案（用户 2026-10-26 · grill 第 2 轮）

环境音的素材 / 开关 / ADR 口径 → **票 31**（Q9=OK）。本票不再问。

## 定案（用户 2026-10-26 · grill 第 3 轮）

1. **字体 = 现状**（`HEADER_SANS`）。三档原型里这一档最好；用户仍不满意，但另外两档更差。**不换伪造的「日式 / 加粗」**。真游戏字体只能等实机录屏 / 游戏图集对齐，不在原型里自造第四档。
2. **堆叠缓出 = A 轻推**（单层小位移）。B 折扇 / C 整板否决。

实现前仍要对着录屏核夹克字样（标题条 / 难度徽章 / credits），不改字级、不另造字体。

观感未按录屏核完前不改进正式 `openingFrame`。

## 本票不包含

- 环境音实现 → 票 31
- 判定 / AP combo / 结算 → 票 51 / 52

- 实时预览演 Opening
