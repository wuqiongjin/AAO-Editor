# 45 · 倒流区带体填充自抵消（动态预览不显示倒流区滑条）

Type: bug
Status: resolved 实现（2026-10-16：fillPolys 绕向归一 + 锁测 2 例 + Playwright 位图 A/B；**待用户验收**，实现与验证见文末 Comments）
Blocked by: none

## 来源与症状

- 用户以 `docs/resource/StressTestChart/Community/dzilas/150030.json` 测动态预览：首个倒流区（beat 48–78）的滑条**完全不显示**（谱面画布 / 静态预览均正常折叠显示）；判定线上却持续存在"滑条被按住"的连按特效（connectionRing + 旋转环 + 端帽）。
- 派生表无问题：`buildSimChart` 的 bands 与画布投影逐段一致（投影前后对比相同），带体段确实在表内。

## 根因

- `src/preview/video/sim/simField.ts` 的 `fillPolys` 把同组（普通 / SP）四边形**合成一条路径**一次 `ctx.fill()`（默认 **nonzero** 缠绕规则；合并是为消共享边接缝）。
- 倒流折返让同一段物理带子被两个 band 段同时贡献**几何完全重合、顶点绕向相反**的四边形：实测 s=12.5 时 lane 6 上，`(48→78)` 段 = `890.7,240.6 → 950.9,240.6 → 1338.0,682.2 → 1167.1,682.2`（顺）与 `(100→108)` 段 = 其反向——因为 beat 48 与 beat 108 同在 t=12.8（A=0.353），beat 78 与 beat 100 都已过线（A=1）。
- nonzero 下两个反向子路径重叠 ⇒ 缠绕数 0 ⇒ **互相抵消成洞，整条带子不填充**。s=8.0 时 8 个段正是 4 对反向重合 ⇒ 全部抵消。浏览器位图 + 最小 canvas 实验双重证实（A+B 同路径 nonzero → 内部黑；仅 A → 正常绿；A+B+C → 只有不成对的 C 显绿）。
- `drawHoldEffects` 逐段单独绘制、不走合并路径，故连按特效照常出现——与用户所见完全一致。
- 非倒流也可能触发：**同拍分组**里绕向相反的水平段（如 6→4 与 4→6 同拍）同样重合抵消。

## 修法（方向，未实施）

- `fillPolys`（或 `bandQuad` 出口）把每个四边形**归一成一致绕向**（有符号面积 < 0 则反序）再并入同一条路径：nonzero 下同向重叠 = 缠绕 2 仍填充，既消抵消又保留"一条路径填"的防接缝性质。逐段单独 `fill` 会退回接缝问题，不采纳。

## 锁测

- 单测 seam：`tests/unit/preview/video/SimField.test.ts` 驱动 `drawSimFrameAt`（记录型 ctx）抽取带体批次路径点，断言**同批次所有四边形绕向一致**（倒流折返 + 同拍反向水平段两个 fixture）——修前存在反向对 ⇒ 红，修后全一致 ⇒ 绿。
- 记录型 ctx 不做光栅化，nonzero 抵消须浏览器验：Playwright seek 到倒流区内若干秒（5.0 / 8.0 / 11.0 / 12.5）抓 `.pv-field__canvas` 位图，断言带体色像素沿期望带体中线存在（本次诊断已用过该探针）。
