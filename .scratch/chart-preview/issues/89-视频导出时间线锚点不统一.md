# 89 · 视频导出时间线锚点不统一（结尾切段 1 帧音画错位）

Type: bug
Status: resolved
Blocked by: none
Related: [74](./74-视频导出开头前导补偿.md)、[75](./75-视频导出末击收尾与结算画面残留.md)、[76](./76-跨段HUD入场退场与结尾图层顺序.md)、ADR-0016 §5.2

## 来源
2026-11-23 谱面预览架构评审候选 2；2026-11-26 对照 `feature/curve-template-and-dynamic-ending-enhancement`（`4d916841`）复核，倒推仍在。

## 症状
入口正向算出 `endingAtSeconds` 交给结尾 SE；帧驱动用 `总长 − simStart − endingSeconds` 倒推 `endingAt`。两处加法不结合时倒推值大 1 ULP，SE 起章那一帧 `t >= endingAt` 为 false，仍画仿真场。例：开场+结尾都开、60fps、`noteSpeed` 11.9、`durationSeconds = 17.5`（音频时长精确值）、tail=0 → 第 1480 帧。默认 9.5 档不中。
当前功能偏差只有这一帧（16.7ms）。音轨重加、`simStartSeconds ?? openingSeconds` 回落在生产路径上没有第二处故障。产品优先级低。

## 根因
票 75 有意让帧驱动从总长派生 `D+tail`，假定与入口加法相同。ADR-0016 §5.2「`endingAt` / 总长 / `stage.seconds` / 轨长都由它派生」未做到：公式在 `exportSpec.ts`，组合在入口、帧驱动、音轨三处。`EndingWiring` 把倒推公式锁成规格。轨长重加是同一裂缝，扫描里没有把采样数加错。

## 修法（本轮实现口径，待验收）
扩现有 `ExportTimeline`，一次算出 `endingAt` / `simStartSeconds`；画面切点与 `endingSfxCues.at` 读同一字段，删倒推。不新建时间线 module、不加 adapter，不必改 muxer。
现接口 `durationSeconds` 生产里已是成片总长，注释仍写「谱面长度」——扩锚点时改注释，不要再并列一个 `totalSeconds`。删回落、音轨改读总长字段是顺手硬化，不是修 1 帧的必做项。

## 锁测
1. `ExportTimeline.test.ts`：评审例（开场+结尾、11.9 / 17.5 / 60fps）builder 的 `endingAt` === `1480/60`；画面切点与 `endingSfxCues.at` 用同一字段。
2. `EndingWiring.test.ts` / `VideoExportWiring.test.ts`：现有断言把倒推公式锁成规格，本票必须改这些字符串锁，改为消费 builder 字段；不改会假绿。
3. 不要用 1× 肉眼当门禁（中央章 elapsed=0 不画字母）。验收以 1 为准。逐帧可选：同例第 1480 帧 combo 应已消失（`comboFadeDur=0`）且 SE 已起。
