# 89 · 视频导出时间线锚点不统一（结尾切段 1 帧音画错位）

Type: bug
Status: open
Blocked by: none
Related: [74](./74-视频导出开头前导补偿.md)、[75](./75-视频导出末击收尾与结算画面残留.md)、[76](./76-跨段HUD入场退场与结尾图层顺序.md)、ADR-0016 §5.2

## 来源
2026-11-23 谱面预览架构评审候选 2；2026-11-26 对照 `feature/curve-template-and-dynamic-ending-enhancement`（`4d916841`）复核，倒推仍在。

## 症状
入口正向算出 `endingAtSeconds` 交给结尾 SE；帧驱动用 `总长 − simStart − endingSeconds` 倒推 `endingAt`。两处加法不结合时倒推值大 1 ULP，SE 起章那一帧 `t >= endingAt` 为 false，仍画仿真场。例：60fps、开场 6.75s、`noteSpeed` 11.9、谱面 17.5s、tail=0 → 第 1480 帧。默认 9.5 档不易碰到。

## 根因
票 75 有意让帧驱动从总长派生 `D+tail`，假定与入口加法相同。ADR-0016 §5.2「`endingAt` / 总长 / `stage.seconds` / 轨长都由它派生」未做到：公式在 `exportSpec.ts`，组合在入口、帧驱动、音轨三处。`EndingWiring` 把三处重复加法锁成规格。

## 修法（本轮实现口径，待验收）
扩现有 `ExportTimeline`（或同文件一个 builder）一次算出分段与锚点；`driveExportFrames` / `renderAudioTrack` 只读 `endingAt` / `simStartSeconds` / `chartEndSeconds` / `totalSeconds`。不新建时间线 module、不加 adapter。删倒推、二次相加、`simStartSeconds ?? openingSeconds` 回落。编码侧不重建分段，不必改 muxer。

## 锁测
1. `ExportTimeline.test.ts`：评审例 11.9 / 17.5 / 60fps 下 builder 的 `endingAt` === `1480/60`；画面切点与 `endingSfxCues.at` 用同一字段。
2. `EndingWiring.test.ts` / `VideoExportWiring.test.ts`：改为锁消费 builder 字段，不再把倒推公式当规格。
3. 16.7ms 成片肉眼难验；手工若做，用 11.9 + 17.5s 谱看结尾 SE 是否与中央章同帧起。
