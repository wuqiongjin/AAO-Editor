# 02-预览页壳与入口

Type: feature
Status: open
Blocked by: —

**来源**：chart-preview/01 定案 4（用户 2026-09-30）：预览是**独立应用页面**，页面作用域绑「工程 + 谱面」。`src/layouts/pageScope.ts` 里 `chartId` 二级此前"只留形状、不做——预览类页面才需要它"（票 22 定案 10）——**本票就是那个第二个消费者**。

## 目标

- 新增应用页面 `preview`：应用壳第 7 页 + 左栏导航项 + 切页快捷键 + i18n（zh-CN / en）。
- **页面作用域二级（`chartId`）转正**：预览页据此定位"哪张谱面"。
- 入口两条（都带 scope，照票 22 定案 2「带 scope 的跳转 = 先写 scope 再激活」）：工作台（当前谱面）、工程详情（谱面行）。左栏导航入口 = 先清 scope 再激活（语义 = 去当前工程的这一页）。
- **域壳骨架**：`src/preview/`（barrel + `static/` / `video/` 两子目录 + 类型契约）。本票只立骨架与接缝，具体能力进 03 / 05 / 07。

## 本轮实现口径（待验收）

- **接入内容壳**：`AppPageShell` + `mode="fill"`，`<Sidebar>` = 页面模式两项（静态预览 / 动态预览，单组平铺）。按 ADR-0007 §6 四题作答：页内子类别切换"有且单组" → Sidebar 平铺；"有常驻工具栏" → fill。
  - 被否：自持布局（像工作台那样不接内容壳）。预览没有工具面板与内嵌分栏，借壳更省且与全站一致；`fill` 的正文自适应上限 1440 ≥ 1080p 仿真场的需要。
- **导航位次**：追加在**末位**（`⇧⌘6`），不动既有 `⇧⌘0..5`——插在工作台后面要给 5 个页面重编号（导航 / `PAGE_NAV` / 文档 / 测试四处同步），收益为零。
- **不进程"进页面即确保当前工程"集合**（`NEEDS_CURRENT_PROJECT` 不含 `preview`）：预览按作用域行事（与音频页同口径，ADR-0015 §6）。scope 缺失时回落「当前工程 + 当前谱面」；两者都没有 → 页面空态（**不新建工程**）。
- **作用域条**：复用 `src/ui/ScopePicker.tsx`（受控组件），落在模式切换区上方。
- **谱面切换**：作用域条只管工程（票 22 定案 7），谱面级定位是预览页自己的事——页面内给一个**受作用域工程约束**的谱面切换器；scope 只带工程时，缺省取该工程的当前谱面（`CurrentProjectSession` 的 `chartId`），无则取首张。
- **ADR 落点**：`docs/adr/0015-歌曲级谱面工程与工程管理页入口.md` §6 补修订段（二级 `chartId` 落地，原文"要有第二个真实消费者才做出来"兑现）。
