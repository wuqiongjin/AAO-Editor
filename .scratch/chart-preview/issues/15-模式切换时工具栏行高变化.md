# 15 · 模式切换（静态 / 动态）：工具栏行高随模式变 → 左簇（作用域条 / 谱面切换器）上下浮

Type: bug
Status: resolved 实现（2026-10-06：走修法 A，值取 1.3；**待用户真机验收**）
Blocked by: —

## 来源

2026-10-06 用户：预览页在静态 / 动态之间来回切时，「作用域条和 switcher 有上下浮动」。
追报：动的是**文件夹图标、`未命名工程` 文字、`EX` 徽标的红色底**（即左簇整体）。

## 症状

用户实测（Windows 10 / Edge 154 / DPR 1.25 / 界面字号档 1 / 窗内宽 1490）：

| | 行高 | 左簇 | 右簇 | 作用域条 top | 切换器 top | 舞台 top |
|---|---|---|---|---|---|---|
| 动态 | 40 | 30 | — | 88.4 | 86.0 | 126.0 |
| 静态 | 40.8 | 30 | 30.8 | 88.8 | 86.4 | 126.8 |
| Δ | **0.8** | 0 | | **0.4** | **0.4** | **0.8** |

`Δtop = (右簇 − 左簇) / 2 = (30.8 − 30) / 2 = 0.4` —— 与下面的机制逐位吻合。

## 根因（已确认）

`.preview-toolbar` 是 `display:flex; align-items:center`，**行高 = 两簇里较高者**，而右簇
（`PreviewPage.tsx` 里 `{mode === 'static' && !fullscreen && <PreviewStaticToolbar/>}`）**只在静态态存在**：
右簇一旦高过左簇，`align-items:center` 就把较矮的左簇在行内居中 → 静态态下沉、切回动态态回顶，
幅度 = (右簇 − 左簇) / 2。动的是左簇全部内容（图标 / 名字 / 当前 tag / 箭头 / `EX` 徽标）。

**为什么两簇会不等高** —— 两簇的高都是 `max(固定图标/徽标高, 文本行盒) + 12`，而**文本行盒跟字体走**：

- 左簇由**谱面切换器里的谱面名**撑：拉丁文本命中 `Geist Variable`，中文回落 `Microsoft YaHei`，
  同 12px 行盒差 **0.8~1px**；
- 右簇由**三个 IconButton 的中文标签（显示 / 导出 / 全屏）**撑 → 永远走中文回落那一档（更大）。

所以：**谱面名是拉丁（"FB"）时左簇比右簇矮 0.8px → 浮；谱面名是中文（"未命名工程"）时两簇等高 → 不浮。**
这正是 `ProjectsPage.css` L256-262 已经记过的那个坑（同字号拉丁 17px / 中文 18px 行盒），口径也照它：
**行高只跟字号走、不跟字体走（unitless，随 `--ui-type-scale` 缩放；写 px 会在字号档被钉死）**。

本机复现（谱面名改成拉丁 "FB"）：左簇 30 / 右簇 31 / 行高 40→41 / **Δtop 0.50** ✓
（谱面名原文"未命名工程"时 Δtop 0、Δ行高 0 —— 这就是我最初怎么都测不出来的原因）。

## 修法（两条，均已实测验证）

- **A（推荐）**：`.preview-toolbar__left, .preview-static { line-height: <unitless>; }`
  —— 行盒钉成只跟字号走，两簇必然等高，浮动与那 1px 舞台位移**一起消失**。
  实测钉 `1.35`：两簇都 30.89、行高 40.89 ↔ 40.89、**Δtop 0 / Δ行高 0**（与现状 40/41 几乎同尺寸）。
  取值硬约束：`12px × lh ≥ 16px`（`.pp-pill__diff` 的徽标高），否则又会被固定高度接管、重新分叉。
- **B（更保守，不改行盒）**：`.preview-toolbar__left { align-self: flex-start; }`
  —— 左簇顶钉死，右簇再高也不推它（实测 Δtop 0）；但行高仍 40↔41，舞台仍跳 1px。

倾向 A。窄窗换行口径（`PreviewPage.css` L86-95「窄窗换行、舞台让一行」）是既有定案，本次不动。

## 锁测

jsdom 无布局、量不到行高 → 走 **Playwright 几何实测**：

- 前置：把谱面切换器里的谱面名设为**拉丁**文本（触发行盒分叉，否则用例恒绿、等于没锁）。
- 断言切静态 / 动态后 `.scope-picker__trigger`、`preview-chart__trigger` 的 `top` 与
  `.preview-toolbar` 的 `offsetHeight` **都不变** —— 当前实现必红（Δtop 0.5 / Δ行高 1）。
- 静态源码断言（`tests/static/PreviewPageWiring.test.ts`）兜住「右簇只在静态态出现」的接线。
