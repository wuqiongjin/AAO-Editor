# 85 · 动态预览调设置 / 全屏误出「正在读取场地素材」

Type: bug
Status: resolved（2026-11-23 已实现，待手工验收）
Blocked by: none
Related: [42](./42-自定义表演背景图.md)、[69](./69-动态预览切换时长谱派生阻塞首帧.md)、[70](./70-静态预览切换时卡顿与陈旧帧分步可见.md)、[80](./80-动态预览清晰度与播放流畅度整改.md)

## 来源与症状

用户 2026-11-23：票 42 保活切回不再先闪内置包之后，动态预览**每次调节设置**屏幕中间都会冒出「正在读取场地素材…」，**进 / 出全屏也是**。观感像重新读了一遍场地，体验差。要求先分析、开票跟踪；优化时必须保住帧间隔、播放期不做一次性工作、内存不回退。

## 根因

页级遮罩（票 69/70）已经写了「未编辑与调设置项零遮罩」。舞台 `.pv-field__pending` 没有这条：`renderingReady` 用 **scene / metrics 对象身份**，任一不等就盖「正在读取场地素材…」。

`videoScene` 依赖整份 `settings.preview` / `settings.display`，亮度、HUD、甚至时间码精度这种 **不进仿真场** 的项也会 new scene。全屏则是工具条进出布局 → `ResizeObserver` → 新 `metrics`。

接着固定三步：遮罩 → `[scene]` 整表 `buildSimChartInChunks`（票 69 给长谱首载让出主线程的）→ `prepareSimRendering` 离屏多帧 + `getImageData`（issue 80 明确 **不在每次 play / seek 重跑**）。播放器 `setFrame` / `setOptions` 本就能热更新、不拆引擎。

票 42 把这层遮罩改成不透明（治自定义背景未就绪时包图从文案后面漏），于是「字飘一下」变成整块场地被盖住。遮罩本身仍该留给 **不安全像素**（首进、自定义背景还在读、换包、换谱）。

## 本轮实现口径（待验收，非用户逐字定案）

遮罩只盖「画面内容不能给看」；热路径只 `setFrame`，旧帧留到新帧。不跳过首播预热、不拆播放器、不把已 close 的自定义位图留在内存里。

| 该遮、该预热 | 不该遮，尽量只 `setFrame` |
|---|---|
| 第一次进动态、自定义背景还在读 | 亮度、HUD、AUTO、AP combo、带体透明度、同时点击线 |
| 换背景包 / 轨道包 / 自定义图 | 全屏进出、窗口缩放（可留一帧拉伸） |
| 换谱、音符真变了（页级 `videoPaintPending` 已在管） | 时间精度等根本不进 `SimScene` 的项 |
| 画质档 / 像素密度真变了 | 音符速度 / 镜向 / 音符大小：要重算派生，但留旧画面，不用这句文案 |

`prepareSimRendering` 只在冷路径可能变时跑：首帧、density、画布像素尺寸、素材、GPU 上下文。

## 锁测

1. `tests/dom/preview/PreviewVideoControls.test.tsx`：舞台已就绪后改亮度 / 只换 `metrics` **不得**再出 `preview.video.loading`；票 42「`liveBgPending` 盖住旧场地、不取内置包」与 issue 80「首播未预热拦住播放」必须继续红。现 `PreviewPageWiring` 的 `stageReady && (liveBgPending \|\| !renderingReady)` 会随遮罩收窄改写，不能当回归锁留着。
2. `tests/static/PreviewPageWiring.test.ts`：遮罩条件不再等于「任何 `!renderingReady`」；`prepareSimRendering` 的调用门禁能从源码看出不是「每次 scene 身份变化」。
3. jsdom 无真实 GPU / 全屏布局 ⇒ **手工验收**：拧亮度 / HUD / 全屏往返零加载文案、播放不卡一下；换包或自定义图未就绪仍出不透明「正在读取场地素材…」且不漏包图；长谱切动态仍先见加载再出画。掉帧仍按票 80 探针，不另起口径。

## Answer

舞台 `.pv-field__pending` 不再跟 `!renderingReady`（scene / metrics 对象身份）。遮罩只盖不安全像素：自定义背景 pending、还没出过帧、画质/素材/包 ID 对不上、播放器刚重建。亮度 / HUD / 全屏尺寸走 `setFrame`，旧画面留到新帧；`prepareSimRendering` 只在 density / 素材 / GPU 变时跑（全屏改 CSS 尺寸不重跑，避免播放中 `getImageData`）。派生表只跟 notes / 速度 / 镜向 / 色觉 / 细分档，亮度不再整表重建。音符大小实际不进 `buildSimChart`，热更新即可。

锁测：`PreviewVideoControls` 票 85 三条 + 票 42 / issue 80 原锁仍绿；`PreviewPageWiring` 不再钉旧遮罩表达式。
