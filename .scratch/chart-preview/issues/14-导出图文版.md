# 14 · 导出图文版：封面 + 谱面信息 + 预览谱面

Type: feature
Status: open（图文版本体 2026-10-06 实现完成，待用户真机验收）
Blocked by: —（票 13 已验收，2026-10-06）

## 来源

2026-10-05 用户（7）：导出增强 —— 当谱面工程设置了封面图时，导出「谱面封面 + 谱面信息 + 预览谱面」，而不是只有谱面。

2026-10-06 续（票 13 验收反馈）：导出图横向过长 —— 高度恒定 537 时每列只装 1.65 秒、列数过多。本票收编「加高每列」（只动 `EXPORT_PANEL_H`，音符大小 / 列宽 / dpr / 清晰度不动）。**格高 2026-10-06 定案 3,222**（grill Q5，见下）。

## 定案（用户 2026-10-05）

**一律图文版**：不管工程有没有封面，导出物都是「封面区 + 谱面信息 + 预览谱面」；没有封面走占位。理由 = 规格统一（用户原话：这样规格明确一些）。
## 定案（用户 2026-10-06 · grill Q5：格高取值）

**格高 = 3,222 CSS px = 6 × 537**（照 research §3.1 标准档 537 的第 6 倍档）→ 每列 ≈ **9.9 秒**；面板宽 289 不变。

用户先澄清意图（原话：「我的想法就是让一列轨道能更长，能放下更多音符，这样轨道数就变少了，也不会那么宽了。（高度是恒定的，只有宽度会跟随谱面长度而变化，高度恒定的这个值可能有待商榷）」）；四选一（k=4 / **k=6** / k=8 / 自适应）答「同意推荐」= k=6。

- 只动「一格多高」：音符大小 / 列宽 289 / 清晰度（es 0.74 · dpr 2）全不动；总像素基本不变（同一张谱只换切法）。
- 3 分钟谱对照：k=4 → 28 列 8,092×2,148（3.8:1）｜**k=6 → 19 列 5,491×3,222（1.7:1）**｜k=8 → 14 列 4,046×4,296（0.9:1）；现状 537 → 110 列 31,790×537（59:1）。
- 边界（用户已知悉）：很长谱仍会渐宽（5 分钟 31 列 / 10 分钟 61 列）；短谱会变瘦高条（30 秒 ≈ 1,156×3,222）。


## 定案（用户 2026-10-06 · grill：头带版式与字段）

- **头部版式**：封面 289×289 方形裁切**贴左缘**；右侧竖排信息（大字标题 / 副行 / 指标 chips）；横带高 = **337**（24 padding ×2 + 289 封面）；窄图（≤2 面板）封面自动缩窄（最多占图宽一半、289 封顶）、文字截断。
- **字段 7 项可开关**：工程名 / 谱面标题 / 难度+等级 / 时长 / 音符数 / BPM / 导出时间（**谱师姓名本票不做**，后续票再谈）；默认开 = 谱面标题 + 难度+等级 + BPM。
- **配置入口**：预览页「显示」面板新增「导出信息」组；落 `settings.export`（additive 段、不 bump schemaVersion、跨会话记住）。
- **BPM 口径**：多条取**绝对值** min–max（如「BPM 120–240」），单条只写一个值，空 / 0 不给。
- 文案 i18n 中英双语；谱面标题未填回落工程名、与副行重复自动去重。
