# 14 · 导出图文版：封面 + 谱面信息 + 预览谱面

Type: feature
Status: open
Blocked by: 13

## 来源

2026-10-05 用户（7）：导出增强 —— 当谱面工程设置了封面图时，导出「谱面封面 + 谱面信息 + 预览谱面」，而不是只有谱面。

## 定案（用户 2026-10-05）

**一律图文版**：不管工程有没有封面，导出物都是「封面区 + 谱面信息 + 预览谱面」；没有封面走占位。理由 = 规格统一（用户原话：这样规格明确一些）。

## 本轮实现口径（待验收）

- 封面数据已有：`store.get(scopeId)` 返回的 `ChartProject` 带 `coverName` / `coverBlob`（`src/project/ChartProject.ts` L58-59）；取图走 `useCoverUrl` 同款 objectURL 通道（`src/ui/CoverField.tsx`），无封面 → 占位块（不是空白）。
- 谱面信息字段与布局**待敲**（候选：工程名 / 谱面标题 / 难度 + 等级 / 时长 / 音符数 / BPM / artist / 导出时间；顶部横带、与面板同一宽度体系）。验收时逐项确认，不按"定案"入库。
- 排布：`planSheetExport` 要加"头部高度"再复算单边 / 面积上限；超限仍走既有"先降密度、再折行"。
- 文案走 i18n（新键在实现时加，中英双语）。

## 锁测

- `tests/unit/preview/static/PanelLayout.test.ts` 增"含头部高度"的排布与上限用例（头部把行高加高后不许算错 `rows` / `bufferH`）。
- 合成接线：静态源码断言或 DOM 断言"导出走图文版合成"（封面区 + 信息区 + 谱面区三段）。
- 出图像素事实：Playwright / 手工导出核对三段都在、封面占位可用 —— 单测画不出图。
