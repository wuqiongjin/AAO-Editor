## 逐条差距

1. **`!` 没有独立动效**。切块时 `!`（闪电 + 圆点）与相邻闪电粘连算作**一枚字形**，排在队列最后，
   与字母共用 `drawGlyphWave`（票 54 定案明确写了「`!`（闪电）走同一套、排最后」）。
   用户要的是：把它从字母队列摘出，锚在「星刚落定」的时刻，走「右上擦入 → 往左下过冲 →
   来回摇摆 → 退回终位」的飞镖动效。当前它比星落定**早约 0.4s** 入场。
2. **mark-ap 尺寸不可调**。`drawAp` 用 `u.hp('apH')`（`apH = 5`）给 AP / FC **共用同一高度**，
   宽度按原图宽高比推：AP 256/40 = 6.4、FC 221/40 = 5.525 ⇒ 同高下 AP 宽 **+15.8%**。
   且 `apH` / `apGap` / `apDX` 都不在 `KNOBS.ending` 里，原型拖不到。
3. **CLEAR 完全没有爆炸粒子**：`endingFrame.ts:1585`（章段）与 `:1593`（余烬）都写了
   `input.stamp !== 'clear'`。CLEAR 也不画中央章与结算角标。
4. **粒子只有 1 种形态**：全部用同一颗实心五角星贴图 `PAR_STAR = [153,278,79,76]` + 拖尾 +
   0.26s 起爆闪（`endingFrame.ts:985-1006, 1132-1166`）。「5 种」目前没有对应概念。
5. **普通烟花的实测口径**（与用户观感的差异要对齐）：
   - 颜色：`PALETTES` 有 4 套（warm/cool/pink/mix），每套 4 色，其中 1 色是白 ⇒ 用户看到的
     「3 种」= 3 个彩色 + 白，`WAVE_PALETTE` 按 5 波轮换出 4 套（`:121-127`）。
   - 次数：**已经是 5 波**，不是 3 次：中心 1 点 → 24% / 42% 各 1 点 → 62% 起 4 点齐爆 →
     80% 起 5 点齐爆（`:1030-1070`）。用户数的「3 次」应是前 3 个单点爆；后两波是多点齐爆，
     且起爆闪只有 0.26s，容易读成一次扩散。
   - 重叠：**技术上已重叠**（`at = 0.06 / 0.72 / 1.26 / 1.86 / 2.4s`，`life = 0.78~1.0s`，
     相邻波有 0.3~0.5s 共存），但 `fade = (1-age/life)^1.15` 让旧波在 0.6s 后几乎看不见，
     所以观感仍是「一发放完再放下一发」。
   - 位置：中心波定死 `(w/2, stampY)`；第 2/3 波由 `burst2X/Y`、`burst3X/Y` 定死；
     第 4/5 波 `scatterPoints()` 在椭圆 `rx=.335W / ry=.3H` 上均匀布点 + 角度抖动，固定种子
     41 / 97。这些 `burst*`、`partSize`、`palette`、`wordGlow` **全部不在原型面板**。

## 技术约束（实现前必须认）

- 新参数要同时改 `endingSpec.ts`（默认值）、`scenes.html` 的 `BASE` / `KNOBS.ending` /
  `endingSpec()` / `PROD` 四处，还要同步 `EndingFrame.test.ts` 的整表快照，否则测试必红。
- `particleCache` 的 key 只有 `` `${u.w}x${u.h}` ``（`:1075-1077`），**不含 spec**：同分辨率下
  拖 `partCount` / `partSpeed` / 任何 `burst*` 滑杆会复用旧粒子表，看不到变化。要调参必须先修它
  （key 带上影响生成的全部 spec 值，或每次覆盖后失效）。
- 新 `ENDING_SPEC` 键一落地就会**同时改变正式导出**（生产没有参数面板，只有
  `settings.export.ending.{enabled, stamp}`）。是否用 `enabled: false` 类开关把新效果默认关掉，
  等用户拍板。
- 「鼓肚子菱形」在图集 `tex_parSet_fever.png` 里没有现成精灵（现有四芒星是**凹腰**的），
  大概率要矢量自绘（与 `drawSolidStar` 同一套路）；顶点层与外环同理。

- 新增 `haloDiaFadeAt`（淡出起点占扩散用时的比例，默认 **0 = 一起飞就开始淡**；
  `1` 可复现旧口径），寿命改 `fadeAt + diaFade`，与 `diaDur` 解耦；
- 淡出曲线由 `smooth` 改成 `pow(1-q, 1.15)` 线性起跌，去掉视觉平台。

**验收观察（留给下一轮）**：`haloDiaTo 8.5 × 星标基准 ≈ 680px` 半径，已超过 1080p 的
半高 540px ⇒ 菱形到最外侧时上下大半出画；叠加「早淡」后，爆炸后半段观感偏弱。
这是用户自己调的值，本轮**未擅改**；若想让整圈留在画面内可把 `haloDiaTo` 降到 5–6。
