# 58 · 谱面画布也支持倍速播放（与动态预览共用一套）

Type: feature
Status: open（已解除阻塞，待实现）
Blocked by: 59

## 来源

用户 2026-11-07 第 1 问：谱面画布要支持倍速；可与动态预览共用一个模块，**不要自己另实现一套**；
并预告未来会同时改善倍速播放的声调问题（后者另立 [61](./61-倍速不变调（变速保调）.md)，短期内不做）。

## 症状

工作台（谱面画布）播放条没有倍速钮；动态预览播放条有（`0.25×…2×` + 手填 `0.1..4`）。

## 根因（已核实）

引擎层不缺能力：`src/audio/AudioEngine.ts:26` `PLAYBACK_RATE_RANGE 0.1..4`、`:162-179` `setPlaybackRate`、
`:82-90` 双时钟乘 rate、`:424-429` `AudioBufferSourceNode.playbackRate`、`:511-523` 键音调度按 rate 换算，
且 `getSeconds()` 仍是谱面秒 ⇒ 进度条量程 / 时间码不变。工作台与预览用的是同一个 `AudioEngine` 类
（不同实例、各自 rAF）。缺的是三层接线：

1. 倍速 UI 是 `src/pages/preview/PreviewVideoStage.tsx:62-197` 的**文件内私有组件** `PlaybackRate`，
   档位 / 归一化在 `src/preview/video/sim/simPlayback.ts:26-44`，都长在预览侧；
2. `src/playback/PlayBar.tsx:35-36` 的 `rateSlot` 是可选 slot，票 22 定案写「预览专属」，
   `src/pages/workspace/WorkspacePage.tsx:533-554` 确实没传；
3. 状态层无 rate：`src/app/providers/PlaybackProvider.tsx:10-40` 没有 rate 字段，
   `src/audio/AudioSession.ts` 全文无 `setPlaybackRate`，预览那份是 `PreviewVideoStage.tsx:268` 的 `useState(1)`。

即：**根因 = 票 20/22 把倍速当作「预览这一屏」的能力，状态、UI、接线三层都只落在预览侧**，
不是引擎不支持。

## 本轮实现口径（待用户验收，不是定案）

- 把 `PlaybackRate` 抽到 `src/playback/` 共用（值区间 / 常用档 / 归一化跟着抽，仍以引擎的
  `PLAYBACK_RATE_RANGE` 为唯一真相源），两处 `<PlayBar>` 都传 `rateSlot`；
- 倍速值只有**一个共享内存单点**（`src/playback/`，或 `PlaybackProvider` 扩字段），两处实时同步；
  **不落设置、不进 settings schema、不改 `CONTEXT.md:249` 与票 20 定案**，刷新 / 重启回 1×
  （[59](./59-倍速数值的保存与共用口径.md) Q6 = OK）；
- 工作台经 `AudioSession` 转发 `setPlaybackRate` 到引擎，不另起时钟、不另算秒；预览侧由
  `useState` 改读这个共享值；视频导出仍固定 1×；
- **声调改善只落 `AudioEngine` 单点**：现 `AudioBufferSourceNode.playbackRate` 是重采样，非 1× 必然变调，
  全仓无 `preservesPitch` / 时间拉伸代码。UI 层只持有数值，不得在两处各做一套补偿
  —— 这是 [61](./61-倍速不变调（变速保调）.md) 对本票的硬约束。

## 锁测

- `tests/static/PreviewPlayBarReuse.test.ts:33-44` 的工作台逐条 props 断言由「无 rateSlot」改「传 rateSlot」；
  `tests/dom/playback/PlayBar.test.tsx:173-179` 保持「不传就不渲染」仍绿。
- `tests/unit/audio/AudioEnginePlaybackRate.test.ts` 补工作台侧：rate=1 行为逐位不变、改速率不跳位置；
  `tests/dom/preview/PreviewVideoControls.test.tsx:180-268` 守抽取后预览侧档位 / 手填 / 不改量程不回退；
  `tests/dom/` 新增一条「工作台改值后动态预览回显一致」。
- 单测盖不到的：倍速听感、画布滚动与播放头同步、暂停态改速率 → **Playwright 真机手工验收清单**
  （工作台 0.5×/2× 起播、时间码与进度条量程不变、键音不错位、声调现状登记为已知问题）。
