# 12 · 全屏预览：控件收敛为「退出全屏」图标

Type: feature
Status: resolved（2026-10-05 用户验收通过；实施与验证见 Comments）
Blocked by: —

## 来源

2026-10-05 用户：全屏后右上角的「缩放条 / 设置 / 退出全屏 / 导出」区域太长，影响预览效果；并追问"全屏下这些真的需要显示吗"。

## 定案（用户 2026-10-05）

- **全屏下只留「退出全屏」一枚图标按钮，不显示文字**（节省占位）；设置 / 导出在全屏下不出现（先退出全屏再做）。
- 缩放能力不丢：全屏下仍可用 **Ctrl/⌘+滚轮**（`StaticPreviewView` 已接管该手势）。
- **否决**「鼠标静止淡出」方案 —— 用户：鼠标基本不会静止，没有淡出的机会。
- **退出钮外形 = 圆角方形**（与工具栏那排同脸：`IconButton` 的 `outlined` + 方形形态），**否决圆形胶囊**
  （用户 2026-10-05：圆形不太合适）；阴影留在钮身上（它浮在画面之上，光靠面压不住轨道花色）。
- **「全屏」钮在这一排末位**（用户 2026-10-05 定案 A）：进入钮贴右缘、退出钮浮在舞台右上角 —— 进出同一个角。
- **浮层不看画面**：谱面没有音符（舞台是空态文案）时退出钮照样在（用户 2026-10-05 同意）——
  全屏下不能只剩 Esc 一条路。
- **那一排一律不带面**（用户 2026-10-05 定案 A）：「导出」去掉 `outlined`（它自票 03 起独带一个中性实底，
  与同排的「设置 / 全屏」不一致，且 `outlined` 在本仓是中性面、不是主动作标记）。口径写进
  `src/ui/ui.css` 的 `.icon-btn--outlined`：**`outlined` 只留给浮在画面之上、需要自己带面的钮**（退出钮）。

## 实现落点

- `src/pages/preview/PreviewPage.tsx` L208-220 的 `.preview-fs` 分支：不再整体挂 `PreviewStaticToolbar`，只挂退出钮。
- `src/pages/preview/PreviewStaticToolbar.tsx`：退出钮取 icon-only 形态（`IconButton` 现有 `label` 会出文字；保留 `title` / 可访问名）。
- 非全屏那排工具栏**维持现状**（它独占一行、不压画面）。
- Esc 退出全屏、`fullscreenchange` 同步状态的既有机制不动。

## 锁测

- DOM：进全屏态（`document.fullscreenElement` 用 `defineProperty` 打桩 + 派发 `fullscreenchange`）断言 `.preview-fs` 内只有一枚退出钮，且无滑杆 / 设置 / 导出。挂到 `tests/dom/preview/StaticPreview.test.tsx` 或同目录新文件。
- 静态接线断言：`tests/static/PreviewPageWiring.test.ts` 里 `.preview-fs` 不再整体挂 `PreviewStaticToolbar`。
