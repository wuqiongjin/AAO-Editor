# 37 · 静态预览导出面板与导出信息迁移

Type: grilling
Status: resolved
Blocked by: none

## 来源与诉求

用户诉求：
针对静态预览功能，将「设置」面板（`PreviewDisplayPanel`）中的「导出信息」条目（头带总开关 + 7 项信息字段），转移到「导出按钮」当中，交互与版式对齐动态预览的导出按钮实现（`VideoExportControl`）。

## 现状盘点

1. **设置面板现状**（`src/pages/preview/PreviewDisplayPanel.tsx`）：
   - `mode === 'static'` 时包含了四组：标记、画布显示、音符皮肤、导出信息（`settings.export.enabled` + 7 字段）；
   - `mode === 'video'` 时包含了三组：仿真场、画布显示、音符皮肤。
2. **静态导出按钮现状**（`src/pages/preview/PreviewStaticToolbar.tsx`）：
   - 仅一枚裸 `IconButton`，点击直接在主线程触发导出并保存；
   - 预估尺寸仅在按钮 tooltip 展示。
3. **动态导出按钮参考**（`src/pages/preview/VideoExportControl.tsx`）：
   - 触发钮点击弹出 portaled 浮层；
   - 浮层内部有规格选择、子项折叠组（总开关 + `?` Popover 气泡 + 缩进子项列表）、底部「开始导出」按钮；
   - 浮层支持 Esc / 点击外部关闭、窗口 resize 动态跟随。

## 待拍板设计项（Grill Round 1）

- **Q1 弹窗顶层标题与分组术语**：弹窗顶层标题建议「图片导出」（与动态形态「视频导出」对称）；头带信息组标题保持「导出信息」还是更名为「曲目信息头带」？
- **Q2 尺寸与排布信息展示**：是否在弹窗内展示当前预计出图尺寸（`exportPlan.sheetW × exportPlan.sheetH`）及降密度 / 超限说明？
- **Q3 帮助气泡**：头带组标题旁是否配置 `?` Popover 解释气泡（说明「在长图顶部添加包含封面与曲目信息的横带」）？
- **Q4 超限时的导出按钮状态**：当尺寸超出 Canvas 极限时，「开始导出」按钮是置灰禁用并给出错误文案，还是保持可点击并由 Toast 提示详细原因？

## 定案（用户 2026-10-11 拍板）

1. **Q1 顶层标题与分组术语**：
   - 弹窗顶层标题为「导出图片」（对齐动态视频导出的「导出视频」）；
   - 分组名称保持为「导出信息」（英文 `Export Info`），总开关 aria-label 保持「启用头带」。
2. **Q2 尺寸信息展示**：
   - 弹窗内不增加多余的尺寸显示行，保持面板清爽（尺寸预估保留在按钮 tooltip 与导出规划中）。
3. **Q3 帮助气泡**：
   - 「导出信息」标题右侧配置 `?` 按钮展开 Popover 浮层；
   - 浮层文案末尾不加句号，精简为：「在长图顶部添加包含封面与曲目信息的横带」；
   - 同步将动态预览片头说明末尾的句号去掉（「在视频最前面加上约 {{seconds}} 秒的曲目信息片头」）。
4. **Q4 超限时的导出操作行为**：
   - 当尺寸超出 Canvas 极限时（`exportPlan.ok === false`），弹窗内的「开始导出」按钮置灰禁用（`disabled`）。

## 实现落点

- `src/pages/preview/PreviewDisplayPanel.tsx`：移除 `mode === 'static'` 下的「导出信息」组与 `settings.export` 依赖；
- `src/pages/preview/StaticExportControl.tsx`：新建静态预览专属导出控件（弹窗、头带总开关 + `?` 浮层 + 7 项子开关、开始导出）；
- `src/pages/preview/PreviewStaticToolbar.tsx`：将裸 `IconButton` 替换为 `StaticExportControl`；

  - 增补 `preview.static.export.title`（「导出图片」）、`preview.static.export.start`（「开始导出」）、`preview.static.export.note`（「在长图顶部添加包含封面与曲目信息的横带」）；
  - 去除 `preview.video.export.opening.note` 末尾句号；

## Answer

已按定案全部实现：
1. **新建组件**：创建 `StaticExportControl.tsx`，形态完全对齐 `VideoExportControl.tsx`，包含 `IconButton` 触发钮、portaled 浮层面板、`?` 按钮与 Popover 说明气泡（无句号）、总开关右侧悬挂与子项置灰联动、超限禁用「开始导出」并展示超限原因；
2. **迁移入口**：`PreviewDisplayPanel.tsx` 移除 `export` 配置分组与对 `settings.export` 的写回依赖，设置面板专注「标记 / 画布显示 / 音符皮肤」；`PreviewStaticToolbar.tsx` 接入 `StaticExportControl`；同步修订 `docs/adr/0016-谱面预览与游戏仿真导出.md` §7 头带入口定义；
3. **文案规范**：中英文补齐 `preview.static.export.*`（含 `open`、`title`、`start`、`note`），同步去除动态预览 `preview.video.export.opening.note` 结尾多余句号；
4. **锁测**：新增 `StaticExportFlow.test.tsx` 锁定 10 条弹窗交互断言，更新 `PreviewDisplayPanel.test.tsx` 与 `PreviewBinarySaveWiring.test.ts`。全量 20 个测试套件 / 331 项测试全绿，`npx tsc -b` 干净通过。
