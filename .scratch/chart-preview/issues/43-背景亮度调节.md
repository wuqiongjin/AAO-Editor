# 43 · 背景亮度调节

Type: grilling
Status: open（2026-10-11 开票；grill 完成 · 已定案见 ADR-0018 · 待实现）
Blocked by: 41, 42

## 来源与诉求

2026-10-11 用户提需求：「（自定义背景）还要支持背景亮度调节」。

## 现状（实测）

- 仿真场背景层目前**没有任何亮度 / 遮罩旋钮**；`drawField` 直接 `drawImage` 内置背景图。
- 画布那套「谱面背景皮肤」已有 `opacity`（0–100%）旋钮，但那是**背景图自身的不透明度**
  （透了就露出画布底色），不是"压暗"。二者不是同一个东西，勿混。
- 视频导出与实时预览共用 `drawSimFrameAt` ⇒ 一个亮度旋钮天然对两处同时生效（若放在绘制层）。

## 待拍板（grilling）

1. **作用对象**：只作用于自定义背景（42），还是对所有背景（内置包 / 自定义图 / 视频背景 44）统一？
2. **方向**：只可**压暗**（0–100% 的黑罩）还是**双向**（暗 ↔ 亮，如 −50%…+50%）？
3. **实现口径**：叠加一层纯色遮罩（黑 / 白 + alpha）vs canvas `filter: brightness()`
   （后者影响范围与性能特征不同，且离线导出逐帧都要带）。
4. **范围**：只压背景层，还是连轨道（场地图 / 判定线）一起压（观感差异大）。
5. **旋钮落点与持久化**：预览页「设置」面板 / 视觉素材页；落 `settings.preview` 还是跟随背景配置。
6. **与画布 `opacity` 的关系**：仿真场要不要也引入"不透明度"旋钮（两套旋钮并存 vs 只要亮度）。

## 定案（用户 2026-10-11 · grill 第 1 轮）

1. **对所有背景统一生效**（内置包 / 自定义图 / 未来的视频背景）⇒ **本票保持独立**，不并入 42。
2. **只做压暗**（0–100% 黑罩），**不做提亮**（提亮会把画面洗白；刚需是"亮背景压暗以便看清音符"）。
3. **只压背景层**，不动轨道（场地图 / 判定线）与音符。
4. **落预览页「设置」面板 + `settings.preview`**。
5. 全量定案见 **ADR-0018**。（档位按全站滑杆惯例：0–100%、步长 5%、默认 0 = 原图。）

## 实现落点（预期，实现时按实际调整）

- `src/preview/video/sim/simField.ts`：`drawField` 在背景层之后、场地图之前叠一层**纯黑罩**
  （alpha = `bgDim / 100`）；只压背景层，不动轨道与音符。
- `src/chart/config/AppSettings.ts`：`settings.preview.bgDim`（默认 0）+ 迁移兜底。
- 预览页「设置」面板：滑杆一行（与缩放滑杆同款控件）。
- 视频导出复用 `drawSimFrameAt` ⇒ 自动同口径，无需第二条链路。

## 锁测

- 单测：纯函数 `resolveBackgroundDim`（钳制 / 默认 0）+ 绘制顺序断言（黑罩在场地图之前）。
- Canvas 像素与逐帧行为单测替代不了 ⇒ **离屏像素实测**（同一帧 `bgDim = 0 / 50 / 100` 三点取样，
  断言背景变暗而**判定线像素不受影响**）+ 手工验收（导出 5 秒视频看开场③段与正片一致）。
