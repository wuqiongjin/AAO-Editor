## 现状（事实）

- 唯一一份倍速值 = `src/pages/preview/PreviewVideoStage.tsx:268` `useState(1)`，经 `rateSlot` →
  `createSimPlayback` → `engine.setPlaybackRate`；刷新 / 重启回 1×。
- 应用壳 `src/layouts/AppShell.tsx:114-116` 是**保活挂载**：切页不卸载组件 ⇒ 页面内 state 能跨切页存活，
  但**跨刷新 / 重启必丢**；[58](./58-谱面画布倍速播放与控件共用.md) 若再放一份 `useState`，
  两处会各自漂移（同一首歌两种速度）。
- 设置对象是单键 `aao.settings.v1`（`src/settings/AppSettings.ts:455`），新增字段按仓库惯例 additive、
  不 bump `schemaVersion`，且会随设置页 JSON 导出 / 导入（`SettingsPage.tsx:469-493`）。
- 视频导出 `src/preview/video/encode/renderAudioTrack.ts:16-40` **不吃 rate**（导出的是作品，不是观看速度）。

## 两案成本对照（Q6 已采纳 A）

| | A：不落设置，但两处共用「本次运行」的一个值 | B：落设置，跨重启记住 |
|---|---|---|
| 两处一致 | 是（共享内存态 / context，保活挂载天然跨切页） | 是 |
| 刷新 / 重启 | 回 1× | 沿用上次值 |
| 改文档 | **不用**（`CONTEXT.md:249` 与票 20 定案保持） | 要回写 `CONTEXT.md:249`、ADR-0004 / 0016、票 20 Comments |
| 改设置 schema | 不用 | `AppSettings.ts` 增字段 + `mergeSettings` 钳制 + ConfigProvider setter + JSON 导入导出白名单 |
| 代价 / 风险 | 想跨重启记住得再拍一次 | 「上次 0.25× 忘了改回来」；倍速会随设置 JSON 带到别的机器 |

_2026-11-11 补记：A 案「不改定案」成立，但 `CONTEXT.md` 的倍速措辞于票 58 验收后就地回写（只修文字、
不落设置不变）；上表「改文档 = 不用」指**不改定案**，不含这次文字回写。_

理由（已采纳）：倍速是「临时放慢看一段密集谱」的观看工具，不是「我的习惯」

持久化并不增加这个收益。

## Answer（用户 2026-11-07 Q6 = OK）

**定案（用户 2026-11-07）**：**A 案 —— 不保存，但两处共用一个「本次运行」的值**。

1. 工作台与动态预览实时同步同一份倍速值；刷新 / 重启回 1×；
2. **不改**票 20 定案、`docs/adr/0004` / `0016`、设置对象 schema；倍速仍不随设置 JSON 导入导出；
3. 视频导出仍固定 1×（不吃观看速度）；
4. B 案（落 `settings.audio.playbackRate`）**否决**，本轮不实现。
