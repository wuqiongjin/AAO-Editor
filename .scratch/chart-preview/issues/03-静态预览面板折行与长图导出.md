# 03-静态预览：面板折行 + 长图导出

Type: feature
Status: open
Blocked by: 02

**来源**：chart-preview/01 定案 1 + 5（用户 2026-09-30）。对标实现：Bestdori `/tool/chartsimulator` 的 `MySongChart`（反编译证据见 `docs/research/chart-preview-technical-baseline.md` §1.1）。

## 形态

- **面板 = 一次 `target.renderFrame(view)`**：`surface = { w: panelW, h: panelH }`、`scale = es`（经 `fitScale` 钳制）、`scrollY` 由面板序号推出（面板 = 布局轴上的定长窗口 `[k·panelH/es, (k+1)·panelH/es)` 虚拟 px）。
- **排布**：面板按序号**横向**排开 + 容器横向滚动；可见面板区间 = `[floor(scrollLeft/panelW), floor((scrollLeft + clientW)/panelW)]`；**只画还没画过的面板**（懒绘制 + 记账），滚出视口不销毁（内存上限与淘汰口径实现时定）。
- **面板内时间向上**：与现有渲染天然一致（判定线 = 画布底边、谱面在下），不需要额外翻转。
- **默认档（对齐 Bestdori 观感）**：`panelW ≈ 130 CSS px`、`panelH = 容器高`、`es ≈ 0.3` → 每面板 `panelH/es ÷ 440` ≈ **4.1 秒**（Bestdori 默认 150 px/s × 537px ≈ 3.6 秒，同档）。
- **可定制（本票范围）**：每面板秒数（密度）/ 面板宽高 / 叠加项（节拍线、BPM 数值、沟槽读数、时间刻度等，取决于"预览显示档"能表达多少）。

## 预览显示档（定案 5）

- 复用同一渲染入口（`renderChart` / `RenderTarget`），预览页自带一组 `FrameView.display` 覆盖；默认**精简**（关掉网格细节 / 沟槽文字 / END 线这类"编辑器装饰"），可手动开回（一组开关写在预览页工具栏）。
- 首期优先用**现有 display 字段**表达（`gridStyle` / `gridOpacity` / `lineShapeTiers` / `labelScale` / `noteSize` / `slideOpacity` / `colorAssist`）；确需新开关（如"关沟槽 / 关 END 文字"）时才在 `FrameView.display` 加字段——**不新开第二份绘制**：面板里画的就是同一套渲染。

## 交互

- **hover 横线 + 两沟槽读数**：现有「实时显示线 + 分内时间（左）+ 已过音符数（右）」已有实现，直接复用；面板内需把指针 y 换算成布局轴 pos / 秒（`virtualYToSeconds`——倒流区里 y→秒恒单值，ADR-0010 结论）。
- 滚动 = 原生横向滚动。**不做**虚拟滚动条 / 缩略图导航（一屏总览留作未来扩展，见 map 的 Fog）。

## 长图导出（副产物，不是主要目标）

- 复用**同一份面板模型**：离屏按同一参数逐面板出图 → 拼成一张网格图（多行）或按面板导出多张 PNG（实现时定，默认**网格单图**）。
- **尺寸算术**（照 06 票实测校准）：3 分钟谱 ≈ 45 面板 ≈ 5,850 × 537 ≈ 3.1M px²；Chromium 上限单边 65,535 px、面积 2^28 ≈ 268M px²。**不做单条超高长图**（3 分钟内容高 79,200 px 已超单边上限）——"长图"的落点即"折行网格 / 分栏图"。
- 导出必须**不依赖窗口尺寸**：固定 `surface` / `dpr`（`resolveCanvasDpr` 用显式入参，不读 `window.devicePixelRatio`）。
- **落盘**：现有通道没有二进制另存 → 新增 `preview:saveBinary` 式通道（preload + main：`dialog.showSaveDialog` + `fs.writeFile(Buffer)`，入参 `Uint8Array` + 建议文件名 + mime），浏览器降级 `Blob` + `<a download>`（照 `src/project/exportChartCode.ts` 先例）。**07 的视频导出复用它**（通道本票建、07 消费）。

## 锁测

- `tests/unit/preview/static/PanelLayout.test.ts`（纯函数）：面板数 = `ceil(chartEndVirtualY ÷ (panelH/es))`；面板 k 的 pos 区间；可见面板区间；指针 → pos / 秒（含倒流区里 y→秒单值）；网格图排布与尺寸上限断言（超限时给出降密度方案，而不是画爆）。
- `tests/dom/preview/StaticPreview.test.tsx`（jsdom + stub canvas）：滚到第 N 面板才建第 N 张位图、同一面板只画一次；换密度后重排并重画；hover 读数与画布同一口径（`分内时间` / `已过音符数`）。
- `tests/static/PreviewBinarySaveWiring.test.ts`：preload 暴露 + main 注册 + 类型闸（`Uint8Array`）+ 浏览器降级分支存在 + 不出现硬编码色值（走 token）。
- **像素实测**（单测测不到真实光栅与上限）：Playwright 打开预览页，截一张真实谱面的面板 + 导出一次网格图，人工验收；尺寸 / 耗时 / 峰值内存三数写进 06 票的 research 笔记。

## Answer

2026-09-30 实现（**二轮**：先出一版原型给用户看，用户七条意见 → 四个口径重定，见 Comments；票面原「密度 + 面板宽」两档被「一个缩放档」取代）。落点：

- `src/preview/static/panelLayout.ts`：面板模型纯函数。一个旋钮 —— 面板宽 = 13 车道宽 = `390 × es`；每面板秒数 = `panelH / es / 440`；面板数 = `ceil(chartEndVirtualY ÷ W)`；面板 → `scrollY` / pos 窗口；指针 → pos / 秒（布局轴直读）；可见区间；宽图排布 `planSheetExport` + 画布上限校验。
- `src/preview/static/panelPainter.ts`：**一份共享离屏 target** 逐面板代画（`createRenderTarget` + `renderChart`）——每面板只留自己的显示 canvas（3 分钟谱 ≈50MB，而非每面板一个 target 的 180MB+）。
- `src/preview/static/displayProfile.ts`：预览显示档（默认精简：只整拍线 / 无沟槽文字 / 无起止线；`labelScale` 0.7）。
- `src/preview/static/StaticPreviewView.tsx` + `.css`：横向滚动宿主 + 面板行（面板高 = 容器高）+ 懒绘制记账（同一画家出过就不再出；换缩放/换谱/换皮肤/容器尺寸变化即换代重出）+ hover（指针交给同一渲染入口）。
- `src/preview/static/exportPanels.ts` + `saveBinary.ts`：宽图导出（**固定档** 537 高 / dpr 2 / 缩放 100% / 精简显示档）+ 二进制另存（Electron 桥 / 浏览器降级）。
- `electron/preload.js` / `electron/main.cjs`：`preview:saveBinary`（`Uint8Array` + 建议文件名 + mime；`dialog.showSaveDialog` + `fs.writeFile`；defaultPath 只取 basename）。
- `src/rendering`：`RenderDisplayOptions` 新增 `gridDetail` / `gutterLabels` / `boundLines`（都带"缺省 = 编辑器现状"语义）；`renderHoverInfo` 把读数盒钳进画布（窄画布不切字）；抽出 `displayOptions.ts`（`settings.display` → 显示参数的唯一映射，工作台与预览共用）；`staticLayerCache` 失效依据补两个字段。
- `src/pages/preview/PreviewStaticToolbar.tsx` + `PreviewPage.tsx`：真预览页消费（缩放分段档 + 三个图标钮 + 导出按钮带尺寸预告；舞台接画面、无音符时给空态）。

锁测：`PanelLayout` 21 例 + `StaticPreview`（DOM）8 例 + `PreviewBinarySaveWiring` 18 例；全量 **188 文件 / 2085 例** + `npx tsc -b` + `npx eslint` 全绿。

## Comments

- 2026-09-30 二轮（用户看过原型后的七条意见 → 四个口径定案 + 两处实现回填）：
  - **一个旋钮**（用户拍板）：面板宽不再手调，由缩放推出（13 车道宽，照 Bestdori `panelWidth = 13 × laneWidth`）；缩放↑ → 轨道变宽、音符变大、每面板时间缩短、面板数变多（横向滑条自然出现）。
  - **面板高跟容器高**（用户给 Bestdori 语义）：窗口矮 → 面板矮 → 每面板秒数少 → 面板数多。票面「高度恒定」落点 = **预览区高度不随内容增长**（绝不变成一条纵向长卷），不是"面板高固定 537"。
  - **导出与预览解耦**（用户：同一张谱面导出总该一个样）：固定档（缩放 100% / 537 高 / dpr 2 / 精简显示档）；形态 = **高固定、宽随谱长**的单行宽图，宽度超单边上限才折行、再超降密度（dpr 2 → 1）。导出按钮走系统另存，tooltip 预告尺寸。
  - **原型独立页面已撤**（用户：原型不是预览页的样子，不代表布局）：画面直接长在真预览页上；`?prototype=static-preview` 入口与 `src/prototypes/StaticPreviewPrototype.*` 一并删除。
  - **工具栏控件**（用户：原型那排原生 select/checkbox 太丑）：缩放 = 分段档（50/100/150/200%），叠加项 = 三个带 tooltip 的图标钮（走全站 `IconButton`），导出 = 描边按钮。全站还没有分段件，本页起了一个（`.preview-zoom`，token 样式）。
  - 回填票面：hover 读数**保留**但要在共享渲染里钳进画布（用户选 A 方案）；背景皮肤**不进**预览面板（130px 面板里只会盖住轨道）；缩放 / 显示档 / 导出是**页面内 state**（不落设置，跟"这一屏怎么看"同性质）。
  - **尺寸上限常量待 06 校准**：`SHEET_LIMITS`（单边 65,535 / 面积 2^28）是 research §3.3 的 Chromium 基线，06 实测出真数后只改这一个常量。
  - 已知债（本票不动）：`StaticPreviewView` 的出图注入点 `painterFactory` 目前只服务测试；面板位图"滚出视口不销毁"（内存上限与淘汰口径留待真机压测后定，见 06 的 research 笔记）。
