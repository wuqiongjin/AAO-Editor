# 03-静态预览：面板折行 + 长图导出

Type: feature
Status: open
Blocked by: 02

**来源**：chart-preview/01 定案 1 + 5（用户 2026-09-30）。对标实现：Bestdori `/tool/chartsimulator` 的 `MySongChart`（反编译证据见 `docs/research/chart-preview-technical-baseline.md` §1.1）。

## 形态

- **面板 = 一次 `target.renderFrame(view)`**：`surface = { w: panelW, h: panelH }`、`scale = es`（经 `fitScale` 钳制）、`scrollY` 由面板序号推出（面板 = 布局轴上的定长窗口 `[k·panelH/es, (k+1)·panelH/es)` 虚拟 px）。
- **排布**：面板按序号**横向**排开 + 容器横向滚动；可见面板区间 = `[floor(scrollLeft/panelW), floor((scrollLeft + clientW)/panelW)]`；**只画还没画过的面板**（懒绘制 + 记账），滚出视口不销毁（内存上限与淘汰口径实现时定）。
- **面板内时间向上**：与现有渲染天然一致（判定线 = 画布底边、谱面在下），不需要额外翻转。
- **默认档（对齐 Bestdori 观感）**：`panelW ≈ 130 CSS px`、`panelH = 容器高`、`es ≈ 0.3` → 每面板 `panelH/es ÷ 440` ≈ **4.1 秒**（Bestdori 默认 150 px/s × 537px ≈ 3.6 秒，同档）。
- **可定制（本票范围）**：每面板秒数（密度）/ 面板宽高 / 叠加项（节拍线、BPM 数值、沟槽读数、时间刻度等，取决于"预览显示档"能表达多少）。

## 预览显示档（定案 5）

- 复用同一渲染入口（`renderChart` / `RenderTarget`），预览页自带一组 `FrameView.display` 覆盖；默认**精简**（关掉网格细节 / 沟槽文字 / END 线这类"编辑器装饰"），可手动开回（一组开关写在预览页工具栏）。
- 首期优先用**现有 display 字段**表达（`gridStyle` / `gridOpacity` / `lineShapeTiers` / `labelScale` / `noteSize` / `slideOpacity` / `colorAssist`）；确需新开关（如"关沟槽 / 关 END 文字"）时才在 `FrameView.display` 加字段——**不新开第二份绘制**：面板里画的就是同一套渲染。

## 交互

- **hover 横线 + 两沟槽读数**：现有「实时显示线 + 分内时间（左）+ 已过音符数（右）」已有实现，直接复用；面板内需把指针 y 换算成布局轴 pos / 秒（`virtualYToSeconds`——倒流区里 y→秒恒单值，ADR-0010 结论）。
- 滚动 = 原生横向滚动。**不做**虚拟滚动条 / 缩略图导航（一屏总览留作未来扩展，见 map 的 Fog）。

## 长图导出（副产物，不是主要目标）

- 复用**同一份面板模型**：离屏按同一参数逐面板出图 → 拼成一张网格图（多行）或按面板导出多张 PNG（实现时定，默认**网格单图**）。
- **尺寸算术**（照 06 票实测校准）：3 分钟谱 ≈ 45 面板 ≈ 5,850 × 537 ≈ 3.1M px²；Chromium 上限单边 65,535 px、面积 2^28 ≈ 268M px²。**不做单条超高长图**（3 分钟内容高 79,200 px 已超单边上限）——"长图"的落点即"折行网格 / 分栏图"。
- 导出必须**不依赖窗口尺寸**：固定 `surface` / `dpr`（`resolveCanvasDpr` 用显式入参，不读 `window.devicePixelRatio`）。
- **落盘**：现有通道没有二进制另存 → 新增 `preview:saveBinary` 式通道（preload + main：`dialog.showSaveDialog` + `fs.writeFile(Buffer)`，入参 `Uint8Array` + 建议文件名 + mime），浏览器降级 `Blob` + `<a download>`（照 `src/project/exportChartCode.ts` 先例）。**07 的视频导出复用它**（通道本票建、07 消费）。

## 锁测

- `tests/unit/preview/static/PanelLayout.test.ts`（纯函数）：面板数 = `ceil(chartEndVirtualY ÷ (panelH/es))`；面板 k 的 pos 区间；可见面板区间；指针 → pos / 秒（含倒流区里 y→秒单值）；网格图排布与尺寸上限断言（超限时给出降密度方案，而不是画爆）。
- `tests/dom/preview/StaticPreview.test.tsx`（jsdom + stub canvas）：滚到第 N 面板才建第 N 张位图、同一面板只画一次；换密度后重排并重画；hover 读数与画布同一口径（`分内时间` / `已过音符数`）。
- `tests/static/PreviewBinarySaveWiring.test.ts`：preload 暴露 + main 注册 + 类型闸（`Uint8Array`）+ 浏览器降级分支存在 + 不出现硬编码色值（走 token）。
- **像素实测**（单测测不到真实光栅与上限）：Playwright 打开预览页，截一张真实谱面的面板 + 导出一次网格图，人工验收；尺寸 / 耗时 / 峰值内存三数写进 06 票的 research 笔记。
