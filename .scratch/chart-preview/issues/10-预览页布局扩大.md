# 10 · 预览页布局扩大（区域宽 + 高）

Type: grilling
Status: resolved（2026-10-02：Q1–Q9 落地 —— 全幅壳 + 页头变体 D + 控件外壳撤销；舞台实测 1390×603；Q6 二次重定基定案）

## 来源

2026-09-30 音符边缘四轮验收讨论（伴随 ADR-0017 定案）。用户：「当前静态预览区域还是太小了，相比 Bestdori 的都小一圈」「左侧的索引 + 空白区域挤占了很大空间，本来可以看到更加宽广的预览区域的（甚至也可以增加预览区域的高度）」。

## 诉求

扩大静态预览的显示区域（宽度 + 高度），让默认缩放下同屏看到更多面板 / 更完整的面板，同时为更高的默认缩放档（= 更大的音符物理尺寸，根治残余锯齿）腾出预算。

## 事实（已查明，不需要重新调研）

- **音符物理像素只由缩放档（es）决定**：`panelLayout.ts` 的"一个旋钮"模型——面板宽 = 13 车道宽 = 390×es，两轴同倍率；面板高（= 容器高，Bestdori 语义）只决定"每面板装多少秒"，**不放大音符**。所以"扩大区域让音符更清晰"的准确表述是：扩大区域不加像素，但它是**预算来源**——让更高的默认缩放档不再牺牲视野。
- 采样链已由 ADR-0017（整数比不变量）收干净（实测 bitmap:physical ≈ 2.002、受控判决实验无差异）；残余锯齿 = **尺寸预算本身**（默认档下音符 ≈27.7 物理 px、白环 ≈2px；1490×748 视口 / dpr 1.25 实测）。根治路径 = 更大的默认音符。
- 横向挤占实测（同上视口）：舞台仅 1121.3 CSS px 宽——被 shell 左 padding 51 + 模式侧栏 179.8 + gap 24 + 右 padding 62 = 316.8 吃掉；纵向：舞台 509.5 = 748 − padding-top 42 − header 110.5（含描述段）− 工具栏 54 − padding-bottom 32。
- 缩放连续可调（滑杆 + Ctrl/⌘+滚轮）；默认档 2026-10-02 已重定基为**读数 100% = 物理表现 1.85**（ADR-0017 §5 修订）。

## 定案（用户 2026-10-02 九答）

1. **Q1 = A**：预览页**脱离 AppPageShell**，做专属全幅布局（自渲染 header + 工具栏 + 舞台）。
2. **Q2 = A**：**不设面板高上限**（面板高=容器高，Bestdori 语义不引入上限）。
3. **Q3**：**维持 13 车道面板口径**（130px 几何基准不动）。
4. **Q4 = A**：**保留全屏**（stageRef / `.preview-fs` 机制照旧）。
5. **Q5**：**静态 / 视频两模式共用新布局**。
6. **Q6**：**布局落地后实测定默认缩放档**（候选 ≈115–130%；读数口径届时定）。
   → **2026-10-02 实施后实测定案**：物理档取 **+20%**（音符 33.2 物理 px；一屏 8.91 秒 ≈ 旧 8.74）；读数口径取**二次重定基**（`PREVIEW_ES_STANDARD = 0.74`，默认位置仍读 100%）。数字见「实施记录」。
7. **Q7**：**模式切换收进工具栏左端**（左侧索引栏随之消失）。
   → **2026-10-02 用户验收推翻**：模式切换升为**页头独占一行**（静态/动态是页头级层级，不与作用域条、显示控件同行）；工具栏左簇 = ScopePicker + PreviewChartSwitcher。
8. **Q8**：**保留 eyebrow + 标题；删除描述段**（"描述纯属废话"）。
   → **2026-10-02 用户验收推翻**：eyebrow + 标题**整块撤销**（模式名即标题；"删掉标题后现有模式样式不足以立标题" → 模式切换升页头级并重做样式）；页头样式**变体 D**（四变体原型实测后用户定案：图标大字按钮 + 整行下缘分割线）。
9. **Q9**：**noteSize 不纳入本票**（保持既有「节奏图示大小」共享设置语义，不做预览专属放大）。

既定前提（grill 陈述、用户未反对）：全局导航维持常驻；窄屏沿用 720 断点行为。

## 几何目标（估算，落地实测校准）

## 结构定案（实现落点）

1. `PreviewPage.tsx` 脱离 `AppPageShell` 自渲染壳：header（eyebrow + 标题，无描述）→ 工具栏 → 舞台；`preview.header.description` 不再渲染。
2. 工具栏左端 = **模式切换（静态/视频）+ ScopePicker + PreviewChartSwitcher**；右簇 = PreviewStaticToolbar 保持现状。
3. 舞台 `flex:1` 吃满；`.preview-stage.is-filled` / 空态 / 全屏 / 窄屏 720 换行行为照旧。
4. `AppPageShell` 与其余四页**零改动**。

## 实施记录（2026-10-02）

- **结构**：`PreviewPage` 脱离 `AppPageShell` 自渲染全幅壳 → 页头（模式切换 + 整行下缘分割线）→ 工具栏行（左 = ScopePicker + PreviewChartSwitcher；右 = 显示控件贴右缘）→ 舞台。
- **控件外壳撤销**（用户追加验收）：`.preview-toolbar__controls` 胶囊壳删除（"太占空间、与上面分割线的布局间隙过大"）；`.preview-fs` 全屏浮层壳保留（浮在画面之上，不同语境）。
- **页头样式**：四变体原型（A 下划线 tab / B 大号分段胶囊 / C 图标大字按钮 / D = C + 整行分割线）挂 `?variant=` 实测对比，用户选 **D**；原型原件留档分支 `proto/chart-preview-10-preview-header`（commit `b9fc325`，不入 main）。
- **Q6 定案**：默认档物理 +20%、读数仍 100%（`PREVIEW_ES_STANDARD` = 0.74、`DEFAULT_PREVIEW_ZOOM` = 1）；音符 27.7 → 33.2 物理 px、一屏 12.82 → 8.91 秒（旧舒适 8.74 的 +1.9%）。
- **锁测**：`PreviewPageWiring.test.ts`（不为 AppPageShell / 页头分割线样式 / 外壳不存在）、`PreviewPageScope.test.tsx`（模式按钮在 `.preview-header`、不在 `.preview-toolbar`）；面板模型断言随二次重定基更新（289 宽 / 33 面板）。
