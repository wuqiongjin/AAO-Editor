## 症状

播到谱面长度就停在场地末帧；导出视频也在此切断。没有中央章、没有入结算过渡、没有结算画面。

## 根因

时间线 **没有后置段**：

- 实时：`simPlayback.stopAtEnd()` 在 `seconds >= duration` 时 pause + seek(duration)。
- 导出：总长 = `OPENING_SECONDS + duration`，`frameDriver` 在谱面段之后没有第五段以后的「Ending」。

游戏顺序是：最后一音 / 曲终 → **中央章**（AP 彩虹条替换 FC；普通 Clear 不盖章）→ **过渡** → **结算**（分数、等级、判定内译、combo、AP/FC、编成、奖励）。

分数 / 等级 / 编成 / 奖励 **不能从谱面单独算真**（卡组、技能、fever、活动倍率）。预览做成「看起来像结算」只能是视觉仿造。官方オートライブ / デモプレイ自己也不在结算里展示完整分数与判定内译——本票若做满游戏结算，会比游戏的 Auto 还「假完整」。

用户点名的三档中央章（AP / FC / 无）在永远 PERFECT 的 Auto 下默认只会走到 AP；另外两档要另给触发（例如导出/预览的「结算形态」覆盖）。
