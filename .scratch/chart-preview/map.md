# Map: 谱面预览能力

> Effort: `chart-preview` · 2026-09-29 · 定案修订 2026-09-30

## Destination

走到尽头 = 谱面作者可以在编辑器画布之外，看到 / 导出自己的谱面：

1. **静态预览**：**面板折行全景**（时间竖切 → 面板横排 → 横向滚动 + 懒绘制），复用编辑器渲染 + 预览显示档；长图导出复用同一份面板模型（副产物，不是主要目标）。_2026-09-30 定案修订：原「整首切片分栏，离屏全景导出为长图」把导出当成了主要形态，与用户诉求不符（谱师要反复看，长图不方便）_
2. **动态预览**：**游戏仿真场**回放（场地 + 音符 + 带体 + 程序化特效 + combo HUD + 键音）+ **离线逐帧视频导出（含音频）**；效果**流畅、可定制、便捷、快速**——尤其服务"观赏性谱面"作者；
3. 预览与 `src/chart/`（数据）、`src/rendering/`（绘制）、`src/audio/`（音频）、`src/playback/`（时钟）保持**单向依赖**。

## Notes

- **从零开始的基础能力**：仓库当前无任何预览 / 导出成图代码，是新建能力（非对已有能力的增强）。
- **质量门槛是验收维度，不是能力分类**：流畅度 / 可定制 / 便捷 / 快速写入各票锁测，不写进 effort 名。
- **跨 effort 依赖已解**（2026-09-30 修订）：`architecture-refactor/03`（+ 08）均 resolved——`src/rendering/index.ts` 是唯一绘制入口，`createRenderTarget` / `frameFor` / `renderFrame` 即离屏出帧的地基（文件头注释本就为"离屏导出 / 未来预览"预留）。
- 具体要做哪些子能力：2026-09-30 定案（见「Decisions so far」与票 01 的 Answer），拆分见 Frontier。
- 仓库没有 `npm run typecheck`；类型门禁 = `npx tsc -b`。
- 测试基线 **183 文件 / 2028 用例全绿**（2026-09-30 实测；票 01 正文里的 164 / 1919 是开票时的旧数）。
- **调研已落盘**：`docs/research/chart-preview-technical-baseline.md`（Bestdori 静态预览与模拟器的反编译事实、我方可复用面、尺寸与缓存算术、待实测清单）。
- 落地时补 CONTEXT.md 词条：面板折行 / 预览显示档 / 长图导出 / 仿真场 / 接近模型 / 设计面 / 视频导出 / 离线音轨。

## Decisions so far

- 命名定为 `chart-preview`（谱面预览）。
- [2026-09-30 定案 · 票 01 Answer 七答]（用户逐问拍板）：① 静态 = **Bestdori 式面板折行**；② 动态画面 = **游戏仿真场**（首期对标 Bestdori 模拟器：场地 / 音符 / 带体 / 程序化特效 / combo / 键音；**不含**判定文字与分数）；③ 导出 = **离线逐帧 + 含音频**（WebCodecs）；④ 入口 = **独立应用页面**，作用域绑「工程 + 谱面」（`chartId` 二级落地）；⑤ 静态面板 = **复用编辑器渲染 + 预览显示档**；⑥ 仿真场素材 = **扩展归档 + 开发期直读**（不入 git、不进安装包）；⑦ **不做**"编辑器观感的过渡视频"——导出链路与仿真场渲染器拆两条子线并行。
- [2026-09-30 登记 · 未开票] 未来扩展：判定文字 / 分数 / 技能 / fever 表现、自定义背景图 / 背景视频（用户："纳入计划、具体做哪些到时候再定"）。
- [2026-09-30 · 票 02 已实现] 预览页落 `⇧⌘3`（紧随音频页；用户验收改位，素材/快捷键/设置各顺延一位）；作用域二级 `chartId` 由形状转正，失效时**只清二级**回落该工程；`src/preview/` 域骨架已立（不 import `pages/`）——03 / 05 从这里接。
