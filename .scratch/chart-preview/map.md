# Map: 谱面预览能力

> Effort: `chart-preview` · 2026-09-29 · 定案修订 2026-09-30

## Destination

走到尽头 = 谱面作者可以在编辑器画布之外，看到 / 导出自己的谱面：

1. **静态预览**：**面板折行全景**（时间竖切 → 面板横排 → 横向滚动 + 懒绘制），复用编辑器渲染 + 预览显示档；长图导出复用同一份面板模型（副产物，不是主要目标）。_2026-09-30 定案修订：原「整首切片分栏，离屏全景导出为长图」把导出当成了主要形态，与用户诉求不符（谱师要反复看，长图不方便）_
2. **动态预览**：**游戏仿真场**回放（场地 + 音符 + 带体 + 程序化特效 + combo HUD + 键音）+ **离线逐帧视频导出（含音频）**；效果**流畅、可定制、便捷、快速**——尤其服务"观赏性谱面"作者；
3. 预览与 `src/chart/`（数据）、`src/rendering/`（绘制）、`src/audio/`（音频）、`src/playback/`（时钟）保持**单向依赖**。

## Notes

- **从零开始的基础能力**：仓库当前无任何预览 / 导出成图代码，是新建能力（非对已有能力的增强）。
- **质量门槛是验收维度，不是能力分类**：流畅度 / 可定制 / 便捷 / 快速写入各票锁测，不写进 effort 名。
- **跨 effort 依赖已解**（2026-09-30 修订）：`architecture-refactor/03`（+ 08）均 resolved——`src/rendering/index.ts` 是唯一绘制入口，`createRenderTarget` / `frameFor` / `renderFrame` 即离屏出帧的地基（文件头注释本就为"离屏导出 / 未来预览"预留）。
- 具体要做哪些子能力：2026-09-30 定案（见「Decisions so far」与票 01 的 Answer），拆分见 Frontier。
- 仓库没有 `npm run typecheck`；类型门禁 = `npx tsc -b`。
- 测试基线 **194 文件 / 2140 用例全绿**（2026-10-02 实测，票 10 实施后；票 01 正文里的 164 / 1919 是开票时的旧数）。
- **调研已落盘**：`docs/research/chart-preview-technical-baseline.md`（Bestdori 静态预览与模拟器的反编译事实、我方可复用面、尺寸与缓存算术、待实测清单）。
- 落地时补 CONTEXT.md 词条：面板折行 / 预览显示档 / 长图导出 / 仿真场 / 接近模型 / 设计面 / 视频导出 / 离线音轨。

## Decisions so far

- 命名定为 `chart-preview`（谱面预览）。
- [2026-09-30 定案 · 票 01 Answer 七答]（用户逐问拍板）：① 静态 = **Bestdori 式面板折行**；② 动态画面 = **游戏仿真场**（首期对标 Bestdori 模拟器：场地 / 音符 / 带体 / 程序化特效 / combo / 键音；**不含**判定文字与分数）；③ 导出 = **离线逐帧 + 含音频**（WebCodecs）；④ 入口 = **独立应用页面**，作用域绑「工程 + 谱面」（`chartId` 二级落地）；⑤ 静态面板 = **复用编辑器渲染 + 预览显示档**；⑥ 仿真场素材 = **扩展归档 + 开发期直读**（不入 git、不进安装包）；⑦ **不做**"编辑器观感的过渡视频"——导出链路与仿真场渲染器拆两条子线并行。
- [2026-09-30 登记 · 未开票] 未来扩展：判定文字 / 分数 / 技能 / fever 表现、自定义背景图 / 背景视频（用户："纳入计划、具体做哪些到时候再定"）。
- [2026-09-30 · 票 02 已实现] 预览页落 `⇧⌘3`（紧随音频页；用户验收改位，素材/快捷键/设置各顺延一位）；作用域二级 `chartId` 由形状转正，失效时**只清二级**回落该工程；`src/preview/` 域骨架已立（不 import `pages/`）——03 / 05 从这里接。
- [2026-09-30 定案 · 票 08 四答]（用户逐问拍板）：① 预览页配置 = 工具栏「设置」钮 → 弹出面板，**共享项直接写 `settings.display`**（与设置页「画布显示」同一份数据、改了双方生效 = Bestdori 行为；设置页保留）；② 标注开关落**新 `settings.preview`** 持久化（缩放 / 全屏仍属页面内 state）；③ 首轮 = 面板 + 共享项互通 + BPM / Beat / Time 标记，二轮追加 **Combo 标记 + 镜向**，**Skill → 09 票**、**Fever 挂起（谱面数据里没有 fever 段）**；④ 音符皮肤 = 面板给入口（当前整包名 + 跳素材页），不做第二套选择器。
- [2026-09-30 · 票 08 二轮（九条意见）] Bestdori bundle 实证（`ToolChartSimulator.95b33d9b.js`）：`styleOffBeat` = **色觉辅助**（我们已有）、镜向 = 整轨镜像含方向箭头翻面（默认不镜像）、技能框是**黄色**不是红、各档位取值与我们一致（时间默认 5s / 节拍默认 1/1）。默认值改用户指定档（BPM 开 / 5s / 1/1 / 画质默认高清，导出走固定精简档 `EXPORT_MARKERS` 不跟走）；「音符边缘诡异」修因 = 瓦片 blit 关平滑的最近邻采样 → 新增 `FrameView.directNotes` 让预览/导出**直渲音符**；工具栏两簇 + 控件 pill。
- [2026-09-30 定案 · 票 08 四轮 · ADR-0017]（用户逐问拍板 Q5–Q9）：新不变量 **位图:物理 = 整数**（`density = dpr × k`，整数阶梯只在 dpr-1/2 屏凑巧成立；用户实机 dpr 1.25 下全档位 1.6×/2.4×/3.2× 非整数重采样 = 残留锯齿根因，工作台工具栏图标同根因）。面板 k = 流畅1/标准1/高清2；工具栏 backing = dpr×2 + resize 重绘；mip 钳制收紧 `min(lMax, lNoUp)`；`DEFAULT_PREVIEW_ZOOM` 1 → **1.85**（锚点换用户舒适度；UI 无百分比标签 → 零口径迁移）；dpr-1 标准档超采样余量回退被接受。_2026-10-02 修订：**默认档重定基** —— `PREVIEW_ES_STANDARD` 1/3 → **1.85/3**、`DEFAULT_PREVIEW_ZOOM` 1.85 → **1**（滑杆读数 100% = 用户舒适档，物理尺寸不变；旧说法「UI 无百分比标签」有误），导出改独立常量 `EXPORT_ES = 1/3` 钉住不随预览基准漂移。_
- [2026-09-30 登记 · 票 10 已开] 预览页布局扩大（宽 + 高）：方向已拍板（扩），实施前需专门 grill（是否脱离 AppPageShell / 左索引抽屉化 / 高度上限）；前置 = ADR-0017 落地并实机验收。
- [2026-10-02 定案 · 票 10 实施]（用户验收 + 逐问拍板）：页头 = **模式切换独占一行 + 整行分割线**（eyebrow/标题整块撤销；原 Q7/Q8 答案被验收推翻）；工具栏右簇**撤掉控件外壳**（"多余、占空间"）；默认档**二次重定基** —— 物理 +20%、读数仍 100%（`PREVIEW_ES_STANDARD` 0.74；ADR-0017 §5 第二次修订）；原型留档 `proto/chart-preview-10-preview-header`。
- [2026-10-05 定案 · 预览反馈 7 条 → 票 11–14]（用户四答）：① 全屏下**只留图标化「退出全屏」**（缩放走滚轮；否决"静止淡出"）；② 导出**加大档位**治"糊"（参数实测校准，改 ADR-0016 §7）；③ 导出**一律图文版**（封面 + 信息 + 谱面，无封面走占位）；④ 作用域条与谱面切换器之间**只加「/」分隔符**。其余 3 条（下拉左对齐 / 切页数据与位图不同步 / 缩放滚动条弹跳）入批次票 11，根因待实证。
