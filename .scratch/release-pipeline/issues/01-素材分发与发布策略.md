# 01-素材分发与发布策略（CI 构建期注入 + release 镜像）

Type: grilling
Status: open
Blocked by: —

**来源**：chart-preview 04 的留后票（打包进安装包 / 运行时拉取 / 用户自备）+ 用户 2026-10-07 新诉求：项目要用 GitHub Actions 自动发版，**发布物携带 Bestdori 素材、仓库不含二进制**。横跨 basic-editor/29（"产物入库、离线零配置"）、bestdori-integration/02 + 05（捆绑现状与版权梯子）、chart-preview/04（仿真场素材口径）。

## 已拍板（用户 2026-10-07）

- **形态 = CI 构建期注入**：安装包内嵌素材，但素材由 CI 在构建前注入，**不进 git**、不占仓库体积。
- **否决「release 附素材包、用户自己导入」**（原话："用户要自己导入，有门槛"）。
- **素材源 = release 镜像为主**：不能每回拉 Bestdori（原话："bestdori 万一维护了就完了"）——**发版链路与 Bestdori 在线状态完全解耦**；碰 Bestdori 只发生在"更新镜像"那一步，那一步失败也不阻塞发版。
- **发布范围 = 内部**（仓库 + release）：素材不对外分发；"公开分发"是另一个决定（ADR-0011 §4 的运营前复审点，本票不触发）。
- **镜像粒度 = 构建选集**（几 MB：脚本选定的皮肤 / 键音包 + `fieldskin/skin00` + `bgskin/skin00` + 版本清单）；全量归档不进镜像（任何机器都能用 04 脚本重建）。
- **已入库的 skins / 键音 = 迁出 git**：`git rm --cached`（本地文件保留、仓库不再跟踪）+ `.gitignore`；registry `.gen.ts`（文本）留库。已知代价：迁出只让**当前树**无副本，历史里仍有；要连历史也清得 `git filter-repo`（成本高，本票不做）。

## 术语：release 镜像是什么

不是 Bestdori 的镜像，是**我们自己归档 / 构建产物的异地副本**：挂在一个独立 release tag（如 `assets-2026-10-07`）下的二进制 asset（zip），不进 git、不占仓库体积、不参与 clone。本仓已有这个约定的先例——`docs/resource/bestdori/README.md`："完整 `manifest.json` / `failures.json` 上传 release 渠道，其它贡献者从 release 拉到本地"；本票把"清单 JSON"扩成"清单 + 构建选集产物的 zip"。

## 方案（本轮实现口径，待验收）

```
[镜像更新 · workflow_dispatch，可选每月定时]      ← 唯一碰 Bestdori 的环节，失败无害
  fetch-bestdori-skins.mjs（选集或全量）→ build-note-skins / build-key-sounds
  → 组 runtime-assets.zip（解包即"工作区状态"：public/assets/skins + src/assets/audio/keysounds
     + docs/resource/bestdori/<server>/{fieldskin,bgskin}/skin00_rip + assets.json 逐文件 sha256）
  → gh release upload assets-<日期>

[发版 · push tag / 手动]
  gh release download 镜像（固定 mirror tag，可复现）→ 解包 + sha256 校验
  → npm ci && npm test && npm run electron:build → release 上传安装包 + manifest/failures

[本地开发兜底] npm run assets:sync —— 同一镜像拉取解包，起 dev 不再需要 Bestdori
```

- 镜像自带版本清单（逐文件 sha256 + 来源 server / 包含哪些包 / 生成时间），CI 与本地都先校验再解包。
- 固定 mirror tag 保证"同一代码 tag 重建 = 同一批素材"；更新素材 = 出新的镜像 tag，改一处引用。

## 实现落点（拍板完成；按本仓约定实现写进本票，不另开）

> 前置约束：隔离仓库尚未建立 —— workflow 文件先落草稿，**本仓 / 本机无法真跑**；可本地验证的部分（`assets-sync` 解包校验、dev 兜底提示、`git rm` 复核）先行，workflow 待仓库就绪后按本票冒烟。
>
> **排期（用户 2026-10-07）：等仓库隔离方案确定后再实现——本次不动。**

- `.github/workflows/assets-mirror.yml`（更新镜像）/ `.github/workflows/release.yml`（发版）
- `scripts/assets-sync.mjs`（拉镜像 / 解包 / 校验；本地与 CI 共用）
- `.gitignore` + `git rm`（若迁出）；`dev.sh` / `setup.sh` 缺失时提示一条命令（照 chart-preview 04 空态口径）
- ADR 回写：ADR-0016 §6（素材口径一族）、ADR-0011 §4（复审提前）、ADR-0003 §12.4

## 锁测

- 决策部分：无行为变更，无锁测（已随 2026-10-07 三答完成）。
