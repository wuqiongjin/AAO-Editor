# 06-应用更新

Type: grilling
Status: resolved
Blocked by: —

**来源**：用户 2026-10-19「给当前产品增加版本更新，设置页加新条目」。`/grill-with-docs` 拍板后写入 [ADR-0021](../../../docs/adr/0021-应用更新.md) 与 `CONTEXT.md`。本票跟踪落地。

## 症状

已安装包看不到应用版本，也不能在应用内换掉当前二进制。设置页只有外观与存储。

## 根因

应用更新边界没定：检查/安装落点、自动检查是否进设置对象、更新源，都还没写进 ADR。

## 为什么在 release-pipeline

本 effort 边界已写明：自动更新（electron-updater）、release 渠道与版本策略归这里。设置页 **关于** 是同一能力的产品面，不另开 effort。代码签名、发版 CI、`latest.yml` 上 GitHub 仍是后续票，不挡本票客户端行为。

## 定案（用户 2026-10-19）

全文以 ADR-0021 为准。摘：

- 术语：**应用版本** + **应用更新**；不用「版本更新」。设置内容页新侧边 **关于**。
- 已安装正式产品：关于里 **检查更新**；就绪后该行改成 **立即重启**。**自动检查** 默认开、只在启动一次、写入设置对象（导入导出带走）。无「永不更新」、无「跳过此版本」、不轮询。
- 下完用弹窗壳请重启（新版本与当前；有发行说明则附上），可稍后（关弹窗继续用；下次启动若自动检查仍开会再查发行，不是跳过）。进度只写在关于。启动检查失败安静；手动失败或已是最新用 toast。
- 源：这一期只认 `github.com/wuqiongjin/AAO-Editor` 正式 Release。不做第二源、不做更新源选择器。
- 浏览器 / 静态演示 / 未打包 Electron：关于只展示应用版本；导语不承诺下载/重启。

## 实现落点

- 设置对象 `autoCheck`；关于：身份卡（产品名 + 应用版本）+ 已打包才露出自动检查 / 检查更新。
- 渲染：`src/app/appUpdate.ts`、`AppUpdateHost.tsx`、`appVersion.ts`（`APP_VERSION` 与 `package.json` 同步）。
- 主进程：`electron/appUpdate.cjs` + preload IPC；`electron-updater` GitHub `wuqiongjin/AAO-Editor`；未打包不调 updater。
- 下完重启确认走 `ui/Dialog`（稍后 / 立即重启）。就绪后关于该行改成立即重启。
- 启动自动检查失败安静；手动失败或已是最新 toast，关于行不写终态。
- 应用版本、已下载包不进设置 JSON。

## 锁测

1. `tests/unit/chart/config/AppSettingsAutoCheck.test.ts`：默认开 / 缺字段 / 导入导出带走。
2. `tests/dom/pages/SettingsPageAbout.test.tsx`：未打包无检查控件；已打包有自动检查；启动失败无 toast；手动已是最新 / 失败各一条 toast；就绪后稍后 → 关于变立即重启。
3. `tests/platform/electron/AppUpdate.test.ts`：未打包不调 updater；packed 下完 → ready → install；GitHub owner/repo 与 `APP_VERSION`。
4. `tests/static/AppUpdateWiring.test.ts`：Dialog 壳、渲染进程不直连 electron-updater。
5. `tests/dom/pages/SettingsPageFlatSidebar.test.tsx` / `PageHeadersCopy` / `HeaderDescriptionsNormalize`：关于侧边与设置头。
6. 真机（单测覆盖不到）：已安装包打到 GitHub 正式 Release 的检查 / 下载 / 重启；国内打不开时启动不吵、手动检查 toast 失败。

## Answer

客户端已落地，行为以 [ADR-0021](../../../docs/adr/0021-应用更新.md) 为准（含 2026-10-19 验收改口：toast、就绪改立即重启、稍后仍会再查发行、关于导语不承诺下载）。发版 CI、代码签名、国内第二源不在本票。

## Comments

### 2026-10-19 拍板存档

- Q1–Q4：真·应用更新；检查只在 Electron 已安装包；术语拆开；关于不塞进外观/存储。
- Q5–Q7、Q9：启动自动查 + 关于可再查；下完请重启可稍后；三平台同一能力；只跟正式 latest。
- Q8：关于里一档自动检查（默认开），没有永不更新。
- Q10：自动检查进设置对象（导入导出带走）；应用版本与已下载包不进 JSON。
- Q11：这一期只认 GitHub；第二源等真有同一份发行的国内副本再开。
- Q12–Q13：弹窗带版本与发行说明；启动失败安静，手动失败说清。
- Q14–Q17：未打包/浏览器只展示版本；无跳过此版本；进度只在关于；一次运行只自动查一次。

### 2026-10-19 验收改口（用户）

- 手动检查失败 / 已是最新：toast，不在关于行重复。界面不提 GitHub。
- 就绪后关于该行变成立即重启，不并排留检查更新。
- 稍后 = 关弹窗继续用，不是跳过下次检查；自动检查仍开则下次启动再查发行（其间若有更新的正式版就改下新的）。自己关窗口不会装上。
- 关于导语收成「查看当前应用版本。」未打包不承诺下载/重启。
- 身份卡：产品名 + 「版本 {semver}」。
