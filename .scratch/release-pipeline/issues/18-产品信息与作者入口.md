# 18-产品信息与作者入口

Type: grilling
Status: resolved
Blocked by: —

**来源**：用户 2026-10-28 提出——产品首次发布前，把**产品主页 / 文档 / GitHub** 这类地址放进应用（落在「设置 → 关于」），并在**应用导航左栏偏下**给一档作者入口（名字 → 个人主页）。要求不堆叠、按信息类型配图标、网址处理优雅。

## 定案（用户 2026-10-28，三轮拍板）

1. **关于页四行入口**，排在身份卡之下、**不另起小标题**，顺序固定：**产品主页 → 使用文档 → GitHub 仓库 → 问题反馈**。不做「许可证」行（许可证在 README / `LICENSE`）。
2. **排布沿用 `settings-row` 视觉**（左图标 + 名称、右侧一枚外链箭头），整行可点；不另做卡片式按钮墙。
3. **网址不写进正文**：行内只有图标 + 文案 + 外链箭头；真实地址只进 hover tooltip，且**去掉 `https://`**（`github.com/wuqiongjin/AAO-Editor` 形态）。不做「复制链接」按钮。
4. **作者入口进应用导航**，位于页面项与折叠钮之间、贴底：展开态一行小字 `作者 wuqiongjin`（`作者` 用 `--text-subtle`，名字用 `--text`），**hover 才浮出外链箭头**；折叠态只剩一枚 18px 线性图标；**不用头像**（首字母徽章与 GitHub 头像都不做：一是不想显眼，二是外链图片会因网络问题空掉）。整块可点 → GitHub 个人主页；**tooltip 用原生 `title`**（不养第三套气泡）。
5. **博客本期不进产品**（`https://wuqiongjin.github.io/`）：内容尚单薄，摆进首版会反伤信任。域名本来就在白名单覆盖范围内，将来补一行即可，不必动主进程。
6. **桌面端打开方式** = `shell:openExternal`，**新增独立的「产品链接白名单」**（`github.com` + `wuqiongjin.github.io`），与社区 `communityNet.cjs` 的 `ALLOWED_HOSTS` **各存一份、不合并**（社区那份是网络出口的信任边界）。浏览器版（在线版）走 `window.open`。
7. **顺带**：README「文档」一节的占位符回填为文档站地址；文档站本身**不加**作者页。

### 二次改版（用户 2026-10-28 验收反馈，推翻上面 2/4 两条的**布局**）

用户看过首版实机后判定两处布局不合格，语义不变、形态重做：

1. **关于页四行 → 身份卡内的一行紧凑 chip**。原话：「这个占用空间比较大……信息密度还很低，用户肯定要滚动到下面才能看到」。四行 46px（连分隔线近 190px）换成一行 28px 的 chip（整行含内边距 42px），并与身份卡合成"产品信息"这一块；窄窗口 `flex-wrap` 换行，不另做折叠。chip 内仍是图标 + 文案 + 小号外链箭头，地址只进 tooltip。
2. **导航作者块整体重做**（第一版：折叠态一枚 `User` 图标 + 展开态 `图标 + 作者 + 名字`）：
   - **折叠态禁止 `User`/人形图标** —— 用户原话「这会让用户以为这是"登录"账号的功能（和 bestdori 账号登录的那块有冲突）」。改为**一枚 GitHub 标记**（点开的是作者 GitHub 主页，标记即目的地）。
   - **tooltip 改语义**：原先两种状态都显示「作者 · wuqiongjin」（意义不明），改为「打开 wuqiongjin 的 GitHub 主页」/「Open wuqiongjin's GitHub profile」——说"点了会发生什么"，不说"这是谁"。
   - **展开态去掉图标**：156px 里再加一列图标，名字会被顶到箭头位上（首版实机已叠字）。展开态只留一行小字，箭头绝对定位、hover 才出现。
   - 作者块与页面项之间加**一道细线**：它不是一个页面，不能混进导航项那串。

## 实现落点

1. `src/app/productLinks.ts`（新增）：`PRODUCT_LINKS = { home, guide, repository, issues, author }` —— 地址只住这一处，改域名只改一份。
2. `src/app/openExternal.ts`（新增）：统一出口 —— 有 `window.electronAPI.shell.openExternal` 就用它，否则 `window.open(url, '_blank', 'noopener,noreferrer')`；失败静默降级（与社区那套同款）。
3. `src/ui/ExternalLinkAnchor.tsx`（新增）：站外链接的唯一实现 —— `<a href>` 外形 + 「`preventDefault` 后走统一出口」。两个调用点（关于页四行、导航作者块）都用它，纪律不再靠复制粘贴维持。
4. `SettingsPage.tsx` 的 `AboutSection`：身份卡**内**（在线版说明之下）加一行入口 chip（图标 `House` / `BookOpen` / `Github` / `MessageCircleQuestion`），行体是 `ExternalLinkAnchor`；`.about-links` 用 `flex-wrap`，`.about-link` 是 28px 的 chip。
5. `AppNav.tsx` + `AppShell.css`：分隔线（`.app-nav-divider`，`margin-top: auto` 住它）+ 作者块；展开态一行小字（无图标，箭头绝对定位、hover 出现），折叠态只剩 `Github` 标记；两处折叠口径（`is-nav-collapsed` 与 `@media (max-width: 1080px)`，后者是"物理收窄"，与折叠状态无关）。
6. `electron/externalLink.cjs`：新增 `PRODUCT_HOSTS` 与 `isProductUrl`，`shell:openExternal` 放行"社区 URL 或产品 URL"，其余照旧抛错；子域按与社区同一条规则放行（都是同一持份者名下的主机）。
7. `src/i18n/messages/{zh-CN,en}.json`：四行标签、作者块文案、tooltip 文案（中英双语）。
8. `README.md` **与 `README.en.md`**：「文档」一节的占位符换成产品主页 + `/guide/` 两个地址（双语对等，票 05 的约定）。
