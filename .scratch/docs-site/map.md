# Map: 产品文档站与宣传页

> Effort: `docs-site` · 2026-10-13 · 开于用户发布前评估（"产品缺少文档，想制作宣传页静态网站放 GitHub Pages"）

## Destination

本 effort 是**用户文档站**的家：静态站点 = 轻量宣传 landing（产品介绍 + 下载入口）+ 产品使用文档。内部领域文档（`CONTEXT.md` / `docs/adr/` / `docs/research/`）不搬进来——站点只面向终端用户。

**边界**（建议，用户可调）：站点构建 / 部署 / 内容归这里；应用功能不归。

## Notes

- 站点文案不得宣传未发布功能（沿用 release-pipeline 2026-10-11 口径：用户可见文案只陈述事实）。
- ~~仓库目前零 CI~~（2026-10-23 更正：已有 PR 门禁 `ci.yml`、发版 `release.yml` 与 CNB 流水线）——本 effort 的部署 pipeline 与 `release-pipeline` 的发版 pipeline 各自独立、互不依赖。

## Decisions so far

- [2026-10-13 用户拍板] 站点形态 = **文档为主 + 轻量 landing**（首页承担"这是什么 / 去哪下载 / 怎么上手"），不做完整营销站。
- [2026-10-13 用户拍板] 语言 = **中文优先，i18n 结构预留，英文内容后补**。
- [2026-10-13 用户拍板] 部署 = **GitHub Actions → gh-pages，默认 github.io 域名**，自定义域名后置。GitHub 为未来正式仓库，当前开发环境是过渡性的、不纳入记录。
- [2026-10-13 用户拍板] 可观测性形态见 [ADR-0019 本地日志与诊断包](../../docs/adr/0019-本地日志与诊断包.md)：纯本地日志 + 诊断包、无远程遥测；本站「排障」章节指导用户导出诊断包附 Issue。
- [2026-10-13 用户拍板] SSG = **VitePress**（同 Vite 血统、i18n 内置匹配中文优先、配置最轻）；否决 Docusaurus（过重）与 Astro Starlight（为一个文档站引入第二套前端生态不划算）。
- [2026-10-13 用户拍板] 位置 = **同仓 `docs-site/` 子目录、独立 package.json**；否决塞进 app route（`base: './'` 与 Pages 的 `/repo/` 构建目标根本冲突）与独立仓库（多仓同步成本对单人项目不成比例）。
- [2026-10-13 用户拍板] v1 文档目录 = 完整核心集（landing / 安装 / 快速上手 / 功能指南 / FAQ / 排障）**+ Bestdori 章节**（社区浏览 / 账号上传）；Bestdori 章节随首发 release 同步上，站点先行时导航留占位。
- [2026-10-13 用户拍板] 排序 = 先合并 `feature/bestdori-integration` → 日志基建落稳定 main → 文档站先行上线（只述已发布功能）→ Bestdori 章节随首发补。
- [2026-10-13 用户拍板] 维护纪律 = 发版 checklist 固化「更新受影响章节」；ADR 级功能必须带指南页；否决 CI 强卡（单人项目过重）与按需更新（文档必然过期）。
- [2026-10-23 用户拍板] 范围追加**浏览器演示版**：静态站同时发布 `/demo/`，复用现有 `vite build`、**不做人为功能限制**（编辑 / 预览 / 谱面图 / 视频导出 / 皮肤设置能跑的全上）；Bestdori 在线能力受 CORS 硬限制天然缺失（ADR-0011），属平台边界、不计入「被砍的功能」。
- [2026-10-23 用户拍板] 素材口径 = **CI 取件**（`scripts/ci/ci-assets.sh` 读 `secrets.ASSETS_SOURCE`，GitHub 侧已配好），素材**不入仓**、不改 `.gitignore`；本地开发仍走 `npm run assets:sync`。
- [2026-10-23 用户拍板] 落地页 CTA 主次 = **「下载桌面版」为主、「在线试用」为次**（浏览器版有平台性缺失，不能当主入口）。
- [2026-10-23 实现口径（待验收）] 部署 = **构建与托管解耦**：GitHub Actions 产出单一 `site-dist/`（文档在根、demo 在 `/demo/`），托管只做最后一步；迁 Cloudflare Pages 只换 deploy job + 把 `DOCS_BASE` 从 `/AAO-Editor/` 改成 `/`。
- [2026-10-23 实现口径（待验收）] 服务端口径：托管只能在 GitHub（CNB 无 Pages 等价物）；新增独立 `deploy-site.yml`（`push: main` + 手动），**不跑测试**——门禁在 CNB 与 `ci.yml`，不构成 ADR-0022 §8 的「双边 CI」。
- [2026-10-23 实现] 票 01 已拍下去：`docs-site/` VitePress 1.6.4 + 按原型重做的落地页（hero / 三块能力 / 轮播 + 灯箱 + 进度条 / 本地优先条 / 双下载卡 / 声明），`guide/` 七章占位；「在线试用」以 `DEMO_AVAILABLE=false` 暂不渲染，票 03 接 `/demo/` 后翻真。细节见票 01 的 Comments。
- [2026-10-23 用户拍板] 外观不再是「只深不浅」：默认深色（品牌调性），但支持切到亮色——文档页天然需要白底阅读，落地页另给一套亮色令牌（只覆盖令牌、组件样式不动）。顶栏日 / 月开关与文档页原生开关共用 `vitepress-theme-appearance`，两边状态互相同步。
- [2026-10-24 用户拍板] 主题开关维持「两个」：文档页**保留 VitePress 原生开关**（样式重置为站点 chrome 圆形、≥768px 一律内联），落地页保留圆形按钮；不得再 `display:none` 藏原生开关——2026-10-23 定案写的就是「文档页原生开关」。
- [2026-10-24 用户拍板] Bestdori 导航占位**撤掉**：与其在导航放一个「莫名其妙、本质指向 GitHub」的外链，不如等章节正文随首发 release 一起上（覆盖 2026-10-13「站点先行时导航留占位」）。
- [2026-10-24 实现] 票 02 发布流水线落地：`deploy-site.yml`（push main + 手动 dispatch，构建与托管解耦，单一 `site-dist/` 产物）+ 静态锁 `DocsSiteDeploy.test.ts`（含锁测 1「不纳入 PIPELINE_FILES」拍定负锁）；迁 Cloudflare 只换 deploy job + `DOCS_BASE`。细节见票 02 Comments。
- [2026-10-25 用户拍板] 票 03 的构建期断言**两个都加**：`assets:check`（独立于 `ci-assets.sh`，让素材问题在 Actions 上自成一步）+ 合并后对 `site-dist/demo/assets/{sim,skins}` 的产物断言。票 02「不跑 assets:check」的负锁据此拆开——它属构建自身的产物校验，不是 ADR-0022 §8 否决的测试门禁。
- [2026-10-25 实现] 票 03 浏览器演示版构建接入：`/demo/` 的子路径素材路径全对（`base: './'` 无需改码），`sim` 保持按需、**`skins` 首屏全量预加载不符票面口径（已开票 10 跟踪）**；落地页「在线试用」CTA 按票 01 的约定随本票开放。实测数字锁与细节见票 03 Comments。
