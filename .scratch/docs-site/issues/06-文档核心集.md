## 来源

## 章节

- 安装（三平台 + 未签名提示 + 首次打开方式）
- 快速上手（建工程 → 放音符 → 预览 → 导出）

- **浏览器版与桌面版的差异**（demo 所有限制提示的唯一权威落点）
- FAQ
- 排障（导诊断包附 Issue，ADR-0019）
- 免责与版权（非官方声明原文）

## 纪律

- 只陈述**已发布**事实；未发布功能不入正文。
- Bestdori 章节随首发占位，不先写空壳正文。
- 本票不阻塞上线：先有目录与首页，正文分批补，按章节开子任务。

## 验收

每章可从导航到达、无死链；「浏览器版与桌面版的差异」与票 04 的实际提示文案逐条对得上（口径唯一，不各写一套）。

## Answer

2026-10-25 实现。用户口径：正文写全、Bestdori 章节随本票上导航、事实基准 = `RELEASE_NOTES.md` 的 0.1.0 + 当前代码。

**落到站点的内容**

- 七章正文补实（中英各一份）：`install` / `getting-started` / `features` / `web-version` / `faq` / `troubleshooting` / `legal`，全部去掉「本章编写中 / Draft」占位。
- 新增 `guide/bestdori.md` + `en/guide/bestdori.md`，中英侧栏各加一项（`Bestdori 社区` / `Bestdori community`）：曲库与社区帖导入、登录、发布硬约束、上传记录与只读、素材缓存、错误对照。兑现 map 2026-10-24「章节正文随首发 release 一起上」——0.1.0 发布说明已含社区能力，导航不再放指向 GitHub 的占位。
- `guide/index.md` / `en/guide/index.md` 重写为「第一次使用 → 开始使用 → 使用指南 → 帮助 → 关于」四段入口。
