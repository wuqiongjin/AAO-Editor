# 05 · 预置样例工程

Type: feature
Status: open
Blocked by: 03

## 来源

`/demo/` 首次进入会落在空启动台——没有工程就没有可看的东西，演示感为零。本票把它变成「打开就有东西可玩」。

## 做什么

1. 示例谱面代码 + 封面放 app 侧静态资源（建议 `public/demo/samples/`，随 `/demo/` 一起发布；体量几 KB，进 Electron 包也可接受）。
2. 首次进入时写入 IndexedDB（`aao.chartproject`）：1–2 个工程，含工程信息、1–2 张谱面（难度 / 等级）、谱面时长。
3. **不带 BGM**（版权 + 体积），播放走合成时间线——这点要在样例工程名或横幅里不误导用户。
4. 只写一次：localStorage 标记；用户删光后不反复重建（是否给「恢复示例」入口：待验收）。
5. 与 Electron 版隔离：示例注入只在无 `electronAPI` 时生效，桌面版永远不注入。

## 锁测

- DOM / 集成测试：首次进入后工程列表非空；二次进入不重复写入（数量不变）。
- 手工验收：清空 IndexedDB → 重进仍恢复 1 个样例；桌面版启动台不受影响。
