# 01 · 站点骨架与落地页

Type: feature
Status: resolved

## 来源

map 2026-10-13 定案：VitePress、同仓 `docs-site/` 子目录、独立 package.json、中文优先 + i18n 结构预留。

## 做什么

- `docs-site/` 建 VitePress 工程：`package.json`（`dev` / `build` / `preview` 三脚本）+ **提交 `package-lock.json`**（票 02 的 CI 要 `npm ci`）。
- `.vitepress/config.ts`：`base` 读环境变量 `DOCS_BASE`、默认 `/AAO-Editor/`（GitHub Pages 项目站路径）；`locales` 只启用 `root`（zh-CN），预留 `en` 结构不填内容。
- 目录：`index.md`（landing）+ `guide/` 占位（安装 / 快速上手 / 功能指南 / FAQ / 排障 / 浏览器版差异 / 免责与版权）。
- 落地页内容：一句话定位（BanG Dream 自制谱编辑器）+ 三块能力（编辑 / 预览与导出 / 社区互通）+ 截图（复用 `docs/media/readme/`，拷进 `docs-site/public/`）+ 下载双入口（GitHub Releases 主、CNB 次）+ 非官方声明。
- CTA 主次按 map 2026-10-23：**「下载桌面版」为主、「在线试用」为次**；demo 未上线前次按钮指 `/demo/` 占位页或暂不渲染（实现时二选一）。

## 验收

`cd docs-site && npm run build` 通过；`npm run dev` 本地可看；375 / 768 / 1440 三档宽度不破版；所有外链可达。

### 2026-10-23 第四轮：动效重做 + 文案回到书面语

**首屏换字动效（用户否掉「上滑淡入」：像 PPT 过程动画）**
- 改成**逐字柔焦**：每条候选按字拆成 `<span class="ch">`，入场 `blur(7px) → 0` + `opacity 0 → 1` + 轻微上浮，按字序错开 15ms（从 110ms 起），整体 0.6s 收干；离场整句一起 0.16s 迅速虚化，不做倒放错开，避免新旧两段字叠在一起成糊团。
- 容器宽度 0.58s 缓动跟随，和「对上焦」同步；`.lead-line` 加 `nowrap`——宽度过渡途中会短暂比最终值宽，不禁用折行窄屏会把「打造的」挤到下一行（实测 1000px 时复现）。
- 又踩一次 scoped 坑：`.ch` 是 JS 建的节点，`.rotor-item .ch{}` 编译成带 `data-v` 的选择器永远不命中，动效整体失效（表现为退场靠父级 0.4s 后硬隐藏）。改 `:deep(.ch)`。
- 兜底：`.rotor-item` 默认 `opacity:0`（`.on` 才可见），没拆字（无 JS）时也只露第一条；`prefers-reduced-motion` 下 delay 一并归零，不轮换。
- 「xxx 打造的」之间补 0.28em 间距（`margin-inline-end`）。

**受众名词**
- 原四条是同一人群换说法（自制谱作者 / 音游自制谱作者 / 同人谱面作者 / 谱面创作者），改成四个维度：`BanG Dream! 自制谱作者` → `其它音游的谱面作者` → `同人企划的谱师` → `初次制谱的玩家`；英文 `BanG Dream! chart authors` / `rhythm-game chart authors` / `chartists on doujin projects` / `first-time charters`。
