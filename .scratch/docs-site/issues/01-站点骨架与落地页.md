Type: feature
Status: resolved

## 来源

map 2026-10-13 定案：VitePress、同仓 `docs-site/` 子目录、独立 package.json、中文优先 + i18n 结构预留。

## 做什么

- `docs-site/` 建 VitePress 工程：`package.json`（`dev` / `build` / `preview` 三脚本）+ **提交 `package-lock.json`**（票 02 的 CI 要 `npm ci`）。
- `.vitepress/config.ts`：`base` 读环境变量 `DOCS_BASE`、默认 `/AAO-Editor/`（GitHub Pages 项目站路径）；`locales` 只启用 `root`（zh-CN），预留 `en` 结构不填内容。
- 目录：`index.md`（landing）+ `guide/` 占位（安装 / 快速上手 / 功能指南 / FAQ / 排障 / 浏览器版差异 / 免责与版权）。
- 落地页内容：一句话定位（BanG Dream 自制谱编辑器）+ 三块能力（编辑 / 预览与导出 / 社区互通）+ 截图（复用 `docs/media/readme/`，拷进 `docs-site/public/`）+ 下载双入口（GitHub Releases 主、CNB 次）+ 非官方声明。
- CTA 主次按 map 2026-10-23：**「下载桌面版」为主、「在线试用」为次**；demo 未上线前次按钮指 `/demo/` 占位页或暂不渲染（实现时二选一）。

## 验收

## Comments

### 2026-10-23 实现

**结构**
- `docs-site/`：`package.json`（`dev` / `build` / `preview`）+ 已写盘的 `package-lock.json`（VitePress 1.6.4 / Vue 3.5 / @types/node）。
- `.vitepress/config.ts`：`base` 读 `DOCS_BASE`、默认 `/AAO-Editor/`（自动补尾斜杠）；`locales` 只启 root，`en` 以「注释里的完整骨架」预留（locale + nav + sidebar + 落点说明），不建空页。
- 页面：`index.md`（落地页）+ `guide/` 七章（安装 / 快速上手 / 功能指南 / 常见问题 / 排障 / 浏览器版与桌面版的差异 / 免责与版权）+ `guide/index.md` 目录页。
- 主题：`.vitepress/theme/Layout.vue` 在 `frontmatter.landing` 时渲染自定义 `Landing.vue`（自带导航与页脚），其余走默认主题；`style.css` 把品牌色对齐产品天蓝；`appearance: 'force-dark'` + `head` 内联脚本先打 `dark` 类，避免文档页进首屏闪浅色。
- 对外链接收敛到 `.vitepress/links.ts`（站点配置与落地页共用一份）。

**落地页**（三版：原型逐条搬，不再重写风格）
- `theme/landing.css` 直接搬原型第 10–412 行 CSS（令牌 / 字号阶梯 / 间距 / 阴影 / 关键帧原样），只做三处适配：令牌挂到 `.landing`、去掉两行 `html{scroll-behavior}`（已在全局样式里）、`.trust dl` 的 `display:contents` 改 flex 列（原型三列下 dt/dd 会错位）。
- `Landing.vue` 按原型 body 结构搬：顶栏（滚动 `scrolled` 态）、hero（分步入场 + eyebrow 画线 + 图 7s 浮动 + 指针微倾斜 + SCROLL 指示 + playhead 扫描线）、三块能力（左缘播放线 `edge-on`）、本地优先条、双下载卡、页脚、`<dialog>` 灯箱。
- 交互逐条搬自原型脚本：顶部进度条、灯箱（`showModal` / Esc / 点背景关闭）、轮播（克隆首尾无缝循环 + 5.5s 自动播放 + hover/focus 暂停 + 箭头 / 圆点 / 滑动手势）、reveal & stagger 入场、边缘线跟随、导航 scroll spy、playhead 宽度自适应、`prefers-reduced-motion` 兜底。
- 语言：原型自带的中 / EN 全量文案落成 `theme/landingCopy.ts`（键名与原型字典一致），做成真切换并 localStorage 记忆 `aao-lang`。

**验收**

- Playwright 实测 375 / 768 / 1024 / 1280 / 1440 / 1920：`scrollWidth === clientWidth`（无横向溢出），hero 主标题在各档都单行不折字，控制台与网络请求无报错。

**偏差 / 待补**
- 键型列表已按拍板去掉「长条」（中英同步）；alt 里的「长图」仍沿用原型原文，是否改成「谱面图」待拍板。
- 信任条 `display:contents` 的列错位属原型实现 bug，已改为 flex 列。
- 修掉轮播引起的横向滚动：`playhead` 的扫过距离误取整页宽度（宽屏会多扫出一截），改为取 `.hero` 宽度；`.carousel` 作为 grid item 的 `min-width:auto` 被克隆轨道顶宽（375 下撑到 768px），补 `min-width:0`。实测 375/768/1024/1440 连续采样 15s（覆盖 9s playhead 与 5.5s 轮播）`scrollWidth === clientWidth`。
- 修掉原型灯箱不居中：`width/height:auto + margin:auto` 会让 dialog 铺满视口、图贴左上角；改成 `[open]` 时 `position:fixed;inset:0;display:grid;place-items:center`。`display` 只能挂在 `[open]` 上——写在基础选择器会盖掉 UA 的 `dialog:not([open]){display:none}`，关着的灯箱会挡住整页点击。实测 375/768/1440 图片左右留白相等。
- 资源不再重复：favicon 由构建钩子从 `public/favicon.ico` 复制（副本进 .gitignore），顶栏品牌图标 `import '@app-public/icon.png'`，与 `@shots` 一样直接复用仓库现有文件。
- 下载卡去掉「未做代码签名…」一段（观感差，安装说明留在 guide/install 与 README）。
- 页脚声明按句拆成三段（无关联声明 / 素材版权 / 侵权联系），避免中文在句中硬断行。
- 顶栏与页脚各加「文档」入口（原型没有）：站点总得有一条到 guide 的路。
- CNB 环境：`vite.server.host/allowedHosts` 打开（照 `scripts/dev.sh` 口径），否则代理访问是 connection refused；本地预览用 `DOCS_BASE=/ npx vitepress dev --port 4300`。
