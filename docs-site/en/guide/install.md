## Installers

Desktop builds come from electron-builder. Primary channel: [GitHub Releases](https://github.com/wuqiongjin/AAO-Editor/releases). For networks in China, [CNB Releases](https://cnb.cool/AsterPicker/AAO-Editor/-/releases) mirrors the same artifacts (synced slightly later).

| Platform | Package |
| --- | --- |
| Windows | NSIS |
| macOS | DMG |
| Linux | AppImage |

## Unsigned builds

Installers are not code-signed yet. On macOS, right-click (or Ctrl-click) the app and choose **Open** the first time. On Windows, if SmartScreen appears, choose **Run anyway**.
