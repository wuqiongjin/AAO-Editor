# Web version vs desktop

The web version shares the same editing capabilities as the desktop build: editing, chart code, preview and chart images, the simulation field and video export, skins and appearance are all there. The only differences come from the environment — the browser has no desktop channels.

## Desktop-only features

**Some features are available only in the desktop app**, for example:

- Browsing the song catalog and signing in
- Importing official or community charts, and publishing

"Desktop-only" is the rule to remember — you don't need to keep a list: anything added exclusively to the desktop build later won't appear here on its own.

## Updates

The web version is released together with the site, so a refresh already gets you the latest build — no manual check needed. **App updates** (check for updates and auto check) exist only in the installed build.

## Project data

Projects are stored in **this browser on this machine**: another browser, another computer, or clearing site data means you won't see them. For long-term charting, use the [desktop build](./install.md).

## Where the app says so

- The first visit to the web version shows a one-time note (once per browser).
- After that, the same note lives in **Settings › About**.
