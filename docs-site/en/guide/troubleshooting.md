# Troubleshooting

::: info Draft
Step-by-step fixes will ship with the first release. When reporting a bug, attach the in-app diagnostic bundle.
:::

## Diagnostic bundle

The app can export a bundle with version, environment, logs, and a recent action trace. Attach it to your [GitHub Issue](https://github.com/wuqiongjin/AAO-Editor/issues) so we can reproduce faster.

AAO Editor has **no remote telemetry** — maintainers only see what you choose to send.
