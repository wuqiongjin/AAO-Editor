# Documentation

Install, get started, and troubleshoot AAO Editor. These pages describe the released app only. If something is missing, check the [FAQ](./faq.md); if that doesn't help, [export a diagnostic bundle](./troubleshooting.md) and open an Issue.

## First steps

1. [Install](./install.md) the desktop app, or open the [home page](../index.md) and choose **Try online** — see [web version vs desktop](./web-version.md) first.
2. Follow the [quick start](./getting-started.md) to create a project, place a few notes, and export your first chart image.
3. For details on a specific feature, see the [feature guide](./features.md).
