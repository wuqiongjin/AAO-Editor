A typical charting flow:

1. **Create a project** — blank, duplicate an existing project, or import from official / community charts.
2. **Place notes** — taps, slides, and holds on the beat grid; use the SP curve brush for curved slides.
3. **Preview** — static preview for the whole chart, or simulation for playback.
4. **Export** — chart image or offline simulation video.
