# 功能指南

本页按五个功能区说明应用能做什么、操作落在哪。按钮的确切位置以应用内为准；界面语言可在设置里切换。

## 工程管理

一个**谱面工程**就是一首歌：工程信息、音频、封面与多张谱面（各带难度 / 等级）集中保存。关闭应用再打开，会回到**工程管理页**的工程启动台，继续上次未完成的工程。

**工程启动台**

- **继续创作**：近期工程列表，可以按「最近打开 / 最近修改 / 谱面数量 / 工程名称」排序，点封面进工程详情。
- **四路新建**：空白新建、复制工程、从官方谱面导入、从社区谱面导入。后两路依赖桌面端通道，见 [Bestdori 社区](./bestdori.md)；在线版只出现前两路。
- **复制工程**：完整复制音频、封面与谱面内容；谱面状态重置为未完成，上传记录不跟着走。

**工程详情**

- 在同一页管理这首歌的多张谱面、查看封面与音频，并从这里进入各谱面的工作台。
- **谱面状态**自动派生：没有上传记录且未标记完成是「未完成」，标记完成是「已完成」，有上传记录是「已上传」。
- **已上传的谱面本体只读**：可以查看、预览与播放，改音符的入口会提示「复制这张谱面来改」。副本不带状态，改完可以再发。难度 / 等级 / 标签还能从详情页的「更新」弹窗改。
- 工程至少保留一张谱面；删工程会连音频、封面与全部谱面一起删除，需要二次确认。已发布到社区的帖子不受删除影响。

## 编辑与滑条

工作台里编辑当前工程的一张谱面。左侧是工具栏，画布中央是轨道，右侧是音符信息与播放控件。

**键型与放置**

- 完整键型：单键、滑键、技能键、左 / 右方向键、滑条、长条；BPM 线与负 BPM 倒流区原生支持。
- 键型工具是「持工具态」：选中后在轨道上点击即放置。单键、滑键、技能键互相替换；方向键在同一位置反复放置会按 1→2→3 循环跨轨宽度。
- **节拍吸附**：1/1、1/2、1/3、1/4、1/6、1/8、1/12、1/16，默认 1/4。放置、拖动、粘贴共用同一套吸附口径；改吸附档不会重排已有音符。
- 滑条点两下成条：第一下挂起点，第二下成条；同一拍再点一次可以取消。方向键落在滑条结点上会把它拆成两条。

**滑条深度编辑**

- 删除工具点中间结点：结点原地转为**隐藏结点**（SP 段的来源）；点端点才是真正移除。
- 删除工具点连接带：在该段处**拆条**。
- 滑条工具框选已有端点，或按 Ctrl+E：把选中的端点**组合**成一条。
- 镜像工具点选或框选：整条按轨道中线翻转。
- 曲线工具在工具态内空白拖动是**画笔**，沿轨迹实时采样；Shift + 拖动改为框选。

**SP 曲线工具**

- 10 族缓动（Sine / Quad / Cubic / Quart / Quint / Expo / Circ / Back / Elastic / Bounce）× 4 种缓动型（In / Out / In-Out / Out-In）。
- 采样精度三档：每拍 1/16、1/32、1/64。
- 形状模板（S 形、波浪 ×2、震动条、大弧、心形）与缓动配置二选一：选了模板，缓动族 / 型 / 精度会被禁用。

**选中、播放与历史**

- 框选、拖动、复制 / 粘贴 / 剪切、删除、镜像都作用于选区；撤销 / 重做覆盖编辑与画布操作。
- 空格播放 / 暂停。无音频时，播放条上的时间码可以双击输入 `mm:ss`，直接设定谱面长度。
- 双击轨道左侧空白处放置**播放起点**：钉在秒位上，改 BPM 不会让它漂。

**谱面代码**

- 工具栏的「谱面代码」打开整份谱面的 Bestdori 风格 JSON，与选区无关；「音符代码」工具（B，Ctrl+B 看光标处音符）只看单个音符 / 子段。
- 应用前会校验：必须是数组、第 0 拍必须有 BPM 音符、lane 在 0–6、BPM 不为 0、方向键的 `direction` / `width` 合法等。有错误会列出来并拒绝应用。
- 未知字段与扩展数据保真保留：应用后原样写回，不与社区格式脱节。
- 未应用的草稿不会被导出；「另存为」在代码未被画布改动过时输出源文本原文。

**快捷键**

- 快捷键页列出全部功能，每个功能恰好一个键；改绑时冲突会被拒绝，也可临时禁用某个功能。
- 切页：Ctrl+Shift+1…6 依次到工作台、音频、预览、素材、快捷键、设置；Ctrl+Shift+0 回工程管理页。
- 常用默认键：空格播放 / 暂停，Ctrl+Space 跳到播放起点，Ctrl+Z / Ctrl+Y 撤销 / 重做，Ctrl+Shift+B 折叠侧栏。
- 键型工具：F 单键、G 滑键、A 技能键、S 左方向、D 右方向、E 滑条、W 曲线、R 指针、T 删除、Q 镜像、V 粘贴。
- 快捷键表把修饰键统一写作 Ctrl；在 macOS 上对应的就是 ⌘。

## 预览与谱面图

**静态预览**

- 整首谱面竖切成面板、横向排开、横向滚动；滚轮横滚，Ctrl/⌘ + 滚轮缩放。
- 缩放 30%–300%，滑杆步长 5%，默认 100%；工具栏末位可以进全屏，Esc 退出。
- 标注档在「设置」面板里：BPM 标记、时间标记（关 / 1 / 2 / 5 / 10 秒）、节拍线（关 / 1÷1 / 1÷2 / 1÷3 / 1÷4 / 1÷6）、Combo 标记（每 50 combo）、镜向。默认开 BPM 与 Combo、时间 5 秒、整拍线。

**谱面图导出**

- 从静态预览导出 PNG，文件名形如 `<谱面标题>-<难度>-谱面图.png`。
- 头带默认开启，可整条关掉；条目有工程名、谱面标题、难度 + 等级、时长、音符数、BPM、导出时间，逐项开关。
- 导出档固定（面板尺寸、密度与预览缩放解耦），不跟当前画面走。超出画布上限时先降密度，仍放不下会提示导出失败。
- 头带是开关：关掉后导出的是不带曲目信息的纯面板谱面图。

## 仿真场与视频导出

**仿真场回放**

- 按接近游戏的形态回放：缩放后的音符、打击特效、Combo 数字、连按双环。
- 场地皮肤包与表演背景各自独立选择，**以预览页实际列出的包为准**（素材随版本更新）；轨道素材选择器采用 4 列等宽网格展示，支持悬停与键盘聚焦实时大图预览。
- 背景亮度 0%–100% 可调（默认 70%），压暗背景降低视觉干扰，提升音符辨识度，同时作用于实时回放与视频导出。
- 音符速度 1–12 可调（默认 9.5），只影响动态形态的观感。
- 倍速预设 0.25×–2×，也可以自定义输入（实际区间 0.1×–4×）。

**视频导出**

- 清晰度 1080p / 720p，固定 60fps。
- 格式「自动」优先 MP4 + AAC；这台机器导不出 AAC 时自动改用 WebM，也可以用下拉手动指定。手选 MP4 时若只有 Opus 音轨，会提示部分播放器可能不支持。
- 可关掉声音导出无声视频。
- 曲目信息片头固定 5 秒（难度 / 歌曲标题 / 乐队，可分别关）。
- 导出过程分五段：准备素材 → 合成声音 → 编码音轨 → 逐帧导出画面 → 生成视频文件；中途可取消。
- 需要浏览器支持 WebCodecs。不支持时会提示换用最新版 Chrome / Edge 或桌面客户端。

## 素材与外观

**音符皮肤**

- 整包预设一键写入六类条目：单键、滑键、技能键、左方向、右方向、滑条。
- 六类可以分别覆盖；预览区实时合成当前组合，并标出被改动的项数。

**键音素材包**

- 整包切换，切换立即对后续播放生效；当前正在播放的按键音在下一次暂停 / 重播后改用新素材。
- 每类击打样式都能试听；方向键按 1 / 2 / 3 连分档试听。
- 键音音量（节奏图示 SE 音量）0%–100%，默认 100%，不影响 BGM。

**画布背景**

- 本机图片，PNG / JPEG / WebP，单张不超过 20MB；只存本机。
- 显示范围：仅轨道外（默认，轨道区保持原始深色）或全画布（轨道区压暗）。
- 填充方式：铺满裁剪（默认）或完整显示（留黑边）。
- 不透明度 0%–100%，默认 55%。
- 「隐藏」保留图片、可一键恢复；「清除」彻底删除。

**外观与画布显示**

- 主题：亮色 / 暗色 / 跟随系统；界面语言：简体中文 / English。
- 界面字号 70%–150%（默认 100%），界面字体三档（Geist / 微软雅黑 / Noto·思源黑体）。这些只影响编辑器界面，不影响谱面画布。
- 画布显示一组的参数：节奏图示大小、长压线不透明度、同时点击线、色觉辅助、纵向比例、图像品质（流畅 / 标准 / 高清）、轨道颜色（灰阶 / 琥珀 / 青蓝 / 多彩）、线形分层、轨道线透明度、文字大小。
- 每组都有「恢复默认」，只重置本组，不动其它设置。
