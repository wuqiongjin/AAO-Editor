# 功能指南

::: info 本章编写中

计划覆盖的内容：

- **工程管理**——一首歌一个工程、多难度谱面、启动台四路新建、谱面状态派生
- **编辑与滑条**——完整键型、节拍吸附、滑条与 SP 曲线、快捷键与谱面代码
- **预览与谱面图**——静态预览、标注档、谱面图导出
- **仿真场与视频导出**——回放倍速、离线渲染与片头
- **素材与外观**——音符皮肤、键音素材包、画布背景、主题与字号
