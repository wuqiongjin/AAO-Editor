# 快速上手

这一页走完一条最短路径：建工程 → 放音符 → 预览 → 导出。全程不需要联网，也不需要先读完[功能指南](./features.md)。

## 1. 建一个工程

打开应用后落在**工程管理页**的工程启动台，点「新建工程」：

- **空白新建**：填工程名称、歌手（都可稍后补），选第一张谱面的难度，然后「创建」。
- **复制工程**：拿已有工程当模板，音频、封面与谱面内容都带过来，谱面状态重置为未完成。
- **从官方谱面导入 / 从社区谱面导入**：先选曲、试听，再按难度建工程，音频与封面一起落进工程。这两路只在桌面版可用，见 [Bestdori 社区](./bestdori.md)。

创建完成后会停在**工程详情**：一首歌下的多张谱面、封面与音频都在这里，点某张谱面的「打开」或「在工作台打开」进入工作台。

## 2. 导入音频（可选）

没有音频也能编辑和预览，谱面时长默认 30 秒、可以手动改。导入音频后，谱面时长会锁成音频的实际时长。

在**音频**页点「导入音频」，选一个本地文件即可。支持常见浏览器可解码的音频格式。

## 3. 放音符

工作台左侧是工具栏，从上到下大致是：指针、BPM、单键、滑键、技能键、左右方向键、滑条、曲线，以及编辑工具（复制 / 剪切 / 粘贴 / 删除 / 镜像 / 音符代码 / 撤销 / 重做）。

1. 选一个键型（例如「单键」）。
2. 在轨道上点一下，音符落在最近的节拍线上；吸附档位在工具栏里选（默认 1/4，可选 1/1 – 1/16）。
3. 拖动音符改位置，框选可以一次选一片；右侧面板显示选中数量，可以删除或镜像。
4. 滑条要**点两下**：第一下挂起点，第二下成条。想画弯带子，换「曲线」工具在空白处拖动，就是画笔。
5. 按空格播放 / 暂停。双击轨道左侧空白处可以放一个**播放起点**，之后用快捷键跳回来重听。

改动会自动保存，不需要手动点保存。

## 4. 预览

打开**预览**页：

- **静态预览**是整首谱面的全景：面板横向排开、横向滚动，缩放在 30%–300% 之间连续可调（滑杆或 Ctrl/⌘ + 滚轮）。可以开全屏，Esc 退出。
- **动态预览**是仿真场回放，按游戏里的形态跑一遍，适合检查手感与打击效果；倍速可调。

「设置」面板里可以开关标注：BPM 标记、时间标记、节拍线、Combo 标记、镜向。这些只影响预览画面，不改谱面。

## 5. 导出

- **谱面图**：静态预览工具栏点「导出图片」，得到一张带头带的谱面图（封面 + 曲目信息 + 全部面板），发社交平台直接可用。
- **视频**：动态预览点「导出视频」，选择清晰度与格式后离线渲染，开头会自动加一段 5 秒的曲目信息片头。

导出不依赖预览当前的缩放与开关——导出档是固定的，保证出图 / 出片的尺寸稳定。

## 示例谱面：直接粘贴就能看到东西

新建工程后如果不想从零摆音符，可以贴一份现成的谱面代码：

1. 在**工程详情**点「新增谱面」。
2. 展开「谱面代码（可选）」，粘贴下面这段 JSON。
3. 点「添加」，再进入工作台。

```json
[
  { "beat": 0, "type": "BPM", "bpm": 160 },
  { "beat": 0, "lane": 3, "type": "Single" },
  { "beat": 1, "lane": 2, "type": "Single" },
  { "beat": 1, "lane": 4, "type": "Single" },
  { "beat": 1.5, "lane": 4, "type": "Single", "flick": true },
  { "beat": 2, "lane": 1, "type": "Single" },
  { "beat": 2, "lane": 5, "type": "Single" },
  { "beat": 3, "lane": 2, "type": "Directional", "direction": "Left", "width": 2 },
  {
    "type": "Slide",
    "connections": [
      { "beat": 4, "lane": 5 },
      { "beat": 4.5, "lane": 4, "hidden": true },
      { "beat": 5, "lane": 3 }
    ]
  },
  {
    "type": "Long",
    "connections": [
      { "beat": 6, "lane": 0 },
      { "beat": 7, "lane": 0 }
    ]
  },
  { "beat": 8, "lane": 6, "type": "Single", "skill": true }
]
```

这段代码覆盖了最常用的几种写法：

- `beat` 是节拍位置，可以是小数；`lane` 是轨道，0–6 共 7 条。
- `type` 取 `BPM` / `Single` / `Directional` / `Slide` / `Long` / `System`。
- 单键加 `"flick": true` 是滑键，加 `"skill": true` 是技能键。
- 方向键用 `direction`（`Left` / `Right`）与 `width`（1–3）描述跨几条轨道。
- 滑条与长条用 `connections` 列结点；中间结点加 `"hidden": true` 就是 SP 段。

第 0 拍必须有一条 BPM 音符，否则应用会拒绝这份代码——这是谱面格式的硬约束，不是这段示例的特殊要求。
