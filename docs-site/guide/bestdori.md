# Bestdori 社区

官方曲库与社区谱面来自 [Bestdori](https://bestdori.com/)。这条通路需要桌面版：在线版没有访问社区平台的通道，入口不会出现，见[在线版与桌面版的差异](./web-version.md)。

## 从曲库建工程

工程启动台的「新建工程」里有两路来自社区：

- **从官方谱面导入**：浏览官方曲库，选曲、试听，再按难度建工程。
- **从社区谱面导入**：浏览玩家发布的谱面帖，同一套流程。

两路都能：

- 按曲名、乐队或曲库 ID / 帖 ID 搜索；官方曲库还可以按乐队、等级区间、必须已实装的难度筛选。
- 试听音频，看清难度与等级再决定导入哪一张。
- 用「同步导入谱面」决定是否连谱面一起导入：开着就按你选的难度取谱面，关掉只建一个带音频与封面的空工程。

导入会分阶段进行（下载音频 → 下载封面 → 取谱面 → 写入工程），中途失败会给具体原因。谱面代码过不了应用闸门、或者曲库里找不到对应曲目时，工程可能只落下一部分，提示里会说明。

## 登录

点工程管理页账号栏的「登录」，用 Bestdori 账号登录。注册与找回密码在 Bestdori 站点自己的登录弹窗里完成。

- 账号由 Bestdori 提供；**密码只发往 Bestdori**，本机不留存。
- 登录状态加密保存在本机，下次启动自动恢复。系统无法安全保存时会提前告知，那就每次启动重新登录。
- 登录只用于发布谱面；浏览曲库与导入不需要登录。

## 发布谱面

打开一张谱面，点「发布」。发布弹窗会先做预检，把缺的信息列出来：

| 项目 | 要求 |
| --- | --- |
| 标题 | 谱面名称，或工程名 |
| 歌手 | 工程信息里的歌手 |
| 难度 / 等级 | 难度 0–4；等级 1–35 |
| 描述 | 必填，不超过 5000 字 |
| 音符 | 至少有一个可发布的音符 |
| 音频 | 自定义曲目要先在音频页导入；官方曲目不用 |

上传音频、封面与发帖一次完成，中途取消不会留下半帖。

发布前请确认：**帖子发出后，谱面本体不能改、也不能删**，只能在社区平台上改难度、等级与标签。要改谱面就复制一份副本，在副本上改完再发；一张谱面只能发布一次。

## 上传记录与只读

- 工程详情的「上传记录」列出这个工程发过的帖子、帖子 ID 与发布时的账号名（支持多账号所有权识别）。
- 有上传记录的谱面状态变为「已上传」，并在编辑器里**只读**：能看、能预览、能播放，任何编辑入口都会提示先复制这张谱面。
- 副本不带上传状态，可以自由编辑，改完作为一张新谱面发布。

## 社区素材缓存

从曲库导入时下载的音频与封面会缓存在本机，下次导入同一首曲子不必重新下载。缓存可在 **设置 › 存储与数据 › 社区素材缓存** 里管理：

- 闲置天数：超过这个天数没用过的素材会被自动清理（默认 30 天）。
- 上限：占用超过上限时自动清理（默认 1024MB）。
- 也可以手动「清除缓存」，清除后不影响已有工程里的音频与封面。

## 出错时

| 提示 | 原因与处置 |
| --- | --- |
| 连不上社区平台 / 官方曲库 | 检查网络后重试；长时间无响应可以先刷新歌曲列表 |
| 社区平台限流了 | 请求太频繁，等一会儿再试 |
| 社区谱面 / 官方曲库只在桌面版提供 | 在线版没有这条通道，换桌面版 |
| 本机素材缓存写不进去 | 磁盘满或数据目录没有写权限，清理空间或检查数据目录 |
| 登录状态已失效 | 重新登录后再发布 |
| 社区平台拒绝了这次发布 | 检查谱面与各项信息后重试 |
| 这张谱面已经发布过了 | 复制这张谱面，在副本上改完再发 |

发布或导入失败时，错误信息里通常会带下一步该做什么；拿不准就带上[诊断包](./troubleshooting.md)提 Issue。
