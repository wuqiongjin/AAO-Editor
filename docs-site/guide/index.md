# 使用文档

AAO Editor 的安装、上手与排障说明。文档只写已经发布的用法；找不到答案时先看[常见问题](./faq.md)，仍然解决不了就带上[诊断包](./troubleshooting.md)提 Issue。

## 第一次使用

1. [安装](./install.md)桌面版，或在[站点首页](../index.md)点「在线试用」，先看[在线版与桌面版的差异](./web-version.md)。
2. 跟着[快速上手](./getting-started.md)建一个工程、放几个音符、导出第一张谱面图。
3. 需要具体功能的细节时，查[功能指南](./features.md)。
