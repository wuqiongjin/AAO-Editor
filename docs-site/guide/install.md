## 安装包

桌面版由 electron-builder 打包，首发渠道是 [GitHub Releases](https://github.com/wuqiongjin/AAO-Editor/releases)；国内网络可用 [CNB Releases](https://cnb.cool/AsterPicker/AAO-Editor/-/releases)，是同一批安装包、同步略晚。

| 平台 | 安装包 |
| --- | --- |
| Windows | NSIS |
| macOS | DMG |
| Linux | AppImage |

## 未签名提示
