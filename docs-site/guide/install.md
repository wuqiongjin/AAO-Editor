# 安装

AAO Editor 提供 Windows、macOS、Linux 三个平台的桌面安装包。不想先安装的话，也可以在[站点首页](../index.md)点「在线试用」，先用浏览器里的[在线版](./web-version.md)试试。

## 下载

安装包发布在 [GitHub Releases](https://github.com/wuqiongjin/AAO-Editor/releases)。国内网络可以从 [CNB Releases](https://cnb.cool/AsterPicker/AAO-Editor/-/releases) 下载同一批文件——同步略晚，只作下载镜像；应用内的更新仍然走 GitHub。

| 平台 | 安装包 | 说明 |
| --- | --- | --- |
| Windows | NSIS（`.exe`） | 按向导安装，可以改安装目录 |
| macOS | DMG（`.dmg`） | 同时提供 Intel 与 Apple 芯片两种构建 |
| Linux | AppImage（`.AppImage`） | 免安装，赋予执行权限后直接运行 |

## 安装

### Windows

1. 运行下载的 `.exe`。
2. 若出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
3. 选择安装位置，按向导完成安装。

### macOS

1. 打开 `.dmg`，把 AAO Editor 拖进「应用程序」。
2. 首次打开不要双击：在「应用程序」里右键（或按住 Control 点按）图标，选「打开」，再在弹窗里点一次「打开」。
3. 之后双击图标即可正常启动。

### Linux

给 AppImage 加上可执行权限后运行：

```bash
chmod +x AAO-Editor-*.AppImage
./AAO-Editor-*.AppImage
```

也可以在文件管理器里右键 → 属性 → 权限 → 勾选「允许作为程序执行」，再双击打开。

## 未签名提示

安装包暂未做代码签名与公证，系统会按未签名应用处理，这是预期的：

- **macOS**：首次打开会提示应用来自身份不明的开发者。用上面的右键 →「打开」放行一次即可，之后不再拦截。
- **Windows**：SmartScreen 会提示已保护你的电脑。点「更多信息」→「仍要运行」。

## 首次打开

首次启动直接落在**工程管理页**的工程启动台。一个工程都没有时，主页会给出「创建第一个工程」的入口；不需要注册账号，也不要求联网。

- 想马上看到东西：跟着[快速上手](./getting-started.md)走一遍。
- 想先调界面：设置里的外观、画布显示、快捷键都可以改，改完立即生效。

## 数据存在哪

谱面工程、素材缓存与画布背景默认保存在本机的应用数据目录，不经过任何业务服务器。实际位置可以随时查看：

**设置 › 存储与数据 › 谱面与素材** 里显示当前路径，并提供「打开数据目录」；也可以在那里更换位置，或指向一份已有的数据目录（换机迁移时用）。

## 更新

安装版启动时会在后台检查一次新版本（**设置 › 关于** 的「自动检查」默认开启，一次运行只查一次）。下载完成后会提示「重启以更新」，点「立即重启」完成安装。

也可以随时在 **设置 › 关于** 手动点「检查更新」。更新源是 GitHub Releases；CNB 只镜像安装包，不参与应用更新。
