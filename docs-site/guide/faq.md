# 常见问题

## 这是官方工具吗？

不是。AAO Editor 是非营利的粉丝自制工具，与 Bushiroad、Craft Egg 及 BanG Dream! 项目官方无任何关联，详见[免责与版权](./legal.md)。

## 支持哪些平台？有手机版吗？

桌面版提供 Windows（NSIS）、macOS（DMG，Intel 与 Apple 芯片）、Linux（AppImage）。没有 iOS / Android 版本。

## 必须联网才能用吗？

编辑、预览、导出都只在本机完成，不需要网络。需要网络的是：从曲库 / 社区导入谱面、发布谱面、检查更新。

## 谱面工程存在哪里？

桌面版存在本机的应用数据目录，不经过任何业务服务器；应用也没有远程遥测。具体路径与「打开数据目录」入口在 **设置 › 存储与数据**。

在线版存在浏览器里，清除站点数据会一起丢失——见[在线版与桌面版的差异](./web-version.md)。

## 换电脑怎么迁移？

- **设置**：在 设置 › 存储与数据 导出设置 JSON，在新机器导入。
- **工程**：把整个数据目录拷到新机器，在新机器的 设置 › 存储与数据 里用「使用已有数据目录」指向它。

## 支持哪些音频格式？

常见浏览器可解码的格式都可以，例如 MP3、OGG、WAV。解码失败时会提示更换文件。

## 谱面图 / 视频导不出来

- **视频**需要浏览器支持 WebCodecs。用最新版 Chrome / Edge，或直接用桌面版。
- **谱面图**超出画布尺寸上限时会先降密度；仍放不下会提示失败，这时可以关掉头带再试。
- 仿真场提示素材缺失时，先回预览页让素材取一次件再导出。

更多排查步骤见[排障](./troubleshooting.md)。

## 发布到社区后还能改吗？

不能改谱面本体，也不能删帖。社区平台上只能改难度、等级与标签；要改谱面就复制这张谱面，在副本上改完重新发布。见 [Bestdori 社区](./bestdori.md)。

## 快捷键可以改吗？

可以。**快捷键**页每个功能都绑一个键，支持改绑与临时禁用，冲突会被拒绝。恢复默认可以按功能、按分类或全部重置。

## 界面语言和字号能改吗？

可以。**设置 › 外观**里切换简体中文 / English、字号 70%–150%、界面字体三档。这些只影响编辑器界面，不影响谱面画布。

## 怎么反馈问题？

到 [GitHub Issues](https://github.com/wuqiongjin/AAO-Editor/issues) 提。附上应用内导出的诊断包（**设置 › 关于 › 诊断包**）会快很多；它不含登录凭据。见[排障](./troubleshooting.md)。
