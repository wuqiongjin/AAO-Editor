# 在线版与桌面版的差异

在线版与桌面版共用同一套编辑能力：编辑、谱面代码、预览与谱面图、仿真场与视频导出、素材与外观都在。差别只来自运行环境——浏览器里没有桌面端的那些通道。

## 应用里的那三条说明

首次打开在线版会弹出一次「在线版说明」，**每个浏览器只弹一次**，点「我已知晓」关闭；之后可以在 **设置 › 关于** 里再次查看。原文是这三条：

> 部分功能仅在桌面版支持，例如曲库浏览、谱面导入。
>
> 工程数据仅保存在本浏览器，清除站点数据后将一并丢失。
>
> 完整功能请使用桌面版。

下面按这三条逐项展开。三条说明与本节是同一口径，应用里换了说法，这里跟着换。

## 一、部分功能仅在桌面版支持

在线版缺的是**依赖桌面端的能力**，不是被砍掉的功能：

- **曲库浏览与登录**：官方曲库、社区帖、账号与上传都要经桌面端通道访问，在线版没有这条通道。
- **从官方或社区导入谱面、上传发布**：同一原因。在线版的新建工程只保留「空白新建」与「复制工程」两路。
- **诊断包导出**：**设置 › 关于** 里没有「诊断包」这一项。反馈在线版的问题时，写明浏览器版本与复现步骤即可。

按「是否只在桌面版支持」判断就够，不必逐条背：以后新增的桌面版专属能力，同样不会出现在在线版。具体用法见 [Bestdori 社区](./bestdori.md)。

## 二、工程数据仅保存在本浏览器

在线版的工程数据存在**这台机器上的这个浏览器**里：换浏览器、换电脑、清除站点数据，都看不到原来的工程。浏览器也没有「数据目录」这个概念，在线版的设置里不显示存储位置。

长期做谱请用[桌面版](./install.md)，工程会落在本机数据目录，可以备份、换机与改位置。

## 三、完整功能请使用桌面版

需要曲库、导入导出社区谱面、上传发布，或者要长期保存工程时，装桌面版：安装包见 [安装](./install.md)。桌面版与在线版可以同时用，互不影响。

## 更新

在线版随站点一起发布，**刷新即是最新版**，不需要手动检查更新。

桌面版的**应用更新**（启动时自动检查、关于页手动检查、下载后重启安装）只在安装版里出现——在线版没有安装包，也就没有这一套。
