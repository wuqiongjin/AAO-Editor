# 在线版与桌面版的差异

在线版与桌面版共用同一套编辑能力：编辑、谱面代码、预览与谱面图、仿真场与视频导出、素材与外观都在。差别只来自运行环境——浏览器里没有桌面端的那些通道。

## 仅在桌面版可用的功能

**部分功能仅在桌面版支持**，例如：

- 曲库浏览与登录
- 从官方或社区导入谱面、上传发布

按「是否只在桌面版支持」判断就够，不必逐条记：以后新增的桌面版专属功能，同样不会出现在在线版。

## 更新

在线版随站点一起发布，刷新即是最新版，不必手动检查更新；桌面版的**应用更新**（检查更新与自动检查）只在安装版里出现。

## 工程数据

工程数据保存在**这台机器上的这个浏览器**里：换浏览器、换电脑、清除站点数据，都看不到原来的工程。长期做谱请用[桌面版](./install.md)。

## 界面里的两处提示

- 第一次打开在线版会弹一次说明（每个浏览器一次）。
- 之后可以在 **设置 › 关于** 里看到同一段说明。
