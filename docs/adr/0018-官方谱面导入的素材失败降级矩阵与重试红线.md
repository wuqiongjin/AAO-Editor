# ADR-0018: 官方谱面导入的素材失败降级矩阵与重试红线

- **状态**：Accepted（2026-10-12，用户 grill-with-docs 三问拍板，票 26）
- **背景**：「从官方谱面导入」要拉三样东西——音频（~4MB 主线）、封面（可选）、谱面代码（可选，默认关）。三段都可能失败，失败时「创建」产出什么需要定案。此前只有隐式行为：音频/谱面失败整笔不建，封面静默跳过且无任何提醒。
- **结论**：见 §2 降级矩阵。
- **变更触发**：导入主线（`officialImport.ts`）的失败语义与本文件冲突时，须先更新本文件并经用户确认。
- **关联**：票 [26 定案记录](../../.scratch/bestdori-integration/issues/26-导入素材失败时创建是否降级放行.md)；[ADR-0011 §2](./0011-Bestdori集成与本地客户端网络素材边界.md)（取数走网关 / 媒体标签直链预览）；[ADR-0005](./0005-显式谱面长度与谱面工程持久化.md)（有音频 = 音频时长）；票 08（导入主线）、22/24（试听与封面的加载态、重试红线同源）。

---

## 1. 机制总览（既有口径汇总，详见 ADR-0011 与票 14/16/17）

- **取数走主进程网关**（曲库索引 / 歌曲元数据 / 谱面原文 / 二进制），cache-first：素材缓存（`<数据根>/cache/community/`）命中零网络，未命中下载并留缓存——**导入失败不进缓存**，重试即整段重下。
- **媒体标签按需预览走直链**（`<img>` / `<audio>` 不受无 CORS 头影响）：选曲预览的封面/试听是「本机缓存优先 → 直链兜底 → 降级态」三段。
- **落盘**：决定导入才把缓存字节拷进工程目录（字节不过 IPC），落盘后按**实际音频**校正时长（探针失败留官方值，不回退）。

## 2. 素材失败降级矩阵（本次定案）

| 素材 | 失败场景 | 创建语义 | 用户反馈 |
| --- | --- | --- | --- |
| **音频**（主线） | 下载失败（网络 / 限流 / 非音频响应） | **整笔不建**：错误 banner（按错误域 kind 翻文案），可重试可取消 | 维持现状（2026-10-12 拍板） |
| **谱面代码**·网络失败 | 拉不到原文 | **降级放行**：等同没勾 B（空 Expert 谱面）+ 创建成功后 Toast 警告「官方谱面获取失败，已按空白谱面创建，可稍后在谱面代码导入中补」 | 2026-10-12 拍板 |
| **谱面代码**·Apply 闸门拒绝 | 原文非法 / 过不了校验 | **整笔不建**：错误信息点名第一个校验错 | 维持现状（2026-10-12 拍板） |
| **封面**·平台无图 | 响应不是图片（SPA 回退页；非首发服合作曲属预期） | **降级放行**（票 08 既有）：工程照建不带封面 + 创建成功后 Toast 提醒「该曲目未提供官方封面，工程未包含封面」 | 提醒为 2026-10-12 新增 |
| **封面**·网络失败 | 下载失败 | **整笔不建**（与音频同路） | 维持现状 |

矩阵的判别基准：**有没有事后补救路**。谱面代码网络失败有（编辑器支持事后贴官方代码），所以放行；音频没有（音频页只收本地文件，「补官方音频」入口不存在），所以阻断；封面缺失本就不挡，补的只是一句说明。

## 3. 重试红线（对所有加载态通用，票 22/24 同源）

- **重试 / 重挂只许在请求终态后触发**（`onError` / `onLoadedMetadata`）。
- 对「飞行中」的同 URL 资源重挂 `<img>` / `<audio>`，Chromium 会让新请求**永久挂住**（票 24 原型实测：`naturalWidth` 有值但 `complete` 恒 false、load 事件永不来）。
- 自动降级链（本机缓存 → 直链）不受此限：那是同一元素换 `src` 重新发起，且逐段终态推进。

## 4. Considered Options（被否记录，防六个月后再提）

- **音频失败降级建无音频工程**：被否——「稍后补官方音频」没有入口（音频页只收本地文件），降级工程是没出口的死角；且 `audioName` 与「无音频字节」不能同时成立（落盘口径 STAGED_ON_DISK 会误判）。若未来做了「补官方音频」入口，本条可重开。
- **谱面网络失败维持整笔不建**：被否——编辑器支持事后贴谱面代码，阻断没有增益。

## 5. Consequences

- `OfficialImportResult` 的 ok 分支需能表达「成功但带降级警告」（`coverImported` 布尔已有；谱面降级需同型新增）。
- 警告落点 = 创建成功后的 Toast（复用 `src/ui/Toast`）；i18n 新增两条 zh/en（谱面降级警告 / 封面未提供提醒）。
- 实现细节与锁测见票 26（实现可并入票 22/24 批次）。
