# ADR-0020: 官方谱面导入的素材失败降级矩阵与重试红线

- **状态**：Accepted（2026-10-12 定案，票 26；**2026-11-14 修订**，[票 56](../../.scratch/bestdori-integration/issues/56-导入谱面音频或封面资源失效的处理.md)）
- **背景**：「从官方谱面导入」要拉三样东西——音频（~4MB 主线）、封面（可选）、谱面代码（可选，默认关）。三段都可能失败，失败时「创建」产出什么需要定案。2026-11-14 进一步核实了封面 HTTP/超时失败、社区 `custom` 帖外链与死链、以及带谱面时音频失效的诉求，经 grill 拍板修订 §2 与 §4。
- **结论**：见 §2 降级矩阵。
- **变更触发**：导入主线（`officialImport.ts` / `communityImport.ts` / `chartImport.ts`）的失败语义与本文件冲突时，须先更新本文件并经用户确认。
- **关联**：票 [26 定案记录](../../.scratch/bestdori-integration/issues/26-导入素材失败时创建是否降级放行.md)；票 [56 定案记录](../../.scratch/bestdori-integration/issues/56-导入谱面音频或封面资源失效的处理.md)；[ADR-0011 §2](./0011-Bestdori集成与本地客户端网络素材边界.md)（取数走网关 / 媒体标签直链预览）；[ADR-0005](./0005-显式谱面长度与谱面工程持久化.md)（有音频 = 音频时长；无音频导入代码按 `maxNoteEndSeconds` 延长）；票 08（导入主线）、22/24（试听与封面的加载态、重试红线同源）。

---

## 1. 机制总览（既有口径汇总，详见 ADR-0011 与票 14/16/17）

- **取数走主进程网关**（曲库索引 / 歌曲元数据 / 谱面原文 / 二进制），cache-first：素材缓存（`<数据根>/cache/community/`）命中零网络，未命中下载并留缓存——**导入失败不进缓存**，重试即整段重下；网关主机白名单维持仅 `bestdori.com`（站外外链不下载）。
- **媒体标签按需预览走直链**（`<img>` / `<audio>` 不受无 CORS 头影响）：选曲预览的封面/试听是「本机缓存优先 → 直链兜底 → 降级态」三段。
- **落盘与验真**：二进制写入工程前须经解码/有效性校验（防 `application/octet-stream` 装入损坏数据）；音频落地后按**实际音频**校正时长（探针失败判为坏音频，不静默写进工程）。

## 2. 素材失败降级矩阵（2026-11-14 票 56 修订）

| 素材 | 失败场景 | 创建语义 | 用户反馈 |
| --- | --- | --- | --- |
| **音频**·未带谱面（`withChart: false`）或谱面降级/失败 | 下载失败 / 外链被拒 / 坏字节 | **整笔不建**：不建空壳工程，Toast 明确提示原因（区分连接失败、资源失效、不支持的外链） | 2026-11-14 修订 |
| **音频**·同时导入了有效谱面（`withChart: true` 且谱面非降级、过 Apply 闸门） | 下载失败 / 外链被拒 / 坏字节 | **降级放行**：创建**无音频工程**（`audioName: null`，不落 `audio.bin`），时长取 `max(官方元数据曲长或30s, maxNoteEndSeconds)` 并钳位 | Toast 警告（提示音频获取失败，已按无音频创建，可稍后在音频页导入本地音频），2026-11-14 修订 |
| **谱面代码**·网络失败（官方导入） | 拉不到原文 | **降级放行**：等同没勾 B（空 Expert 谱面）；但若同时音频也失败则按上行「双挂」整笔阻断 | 创建成功后 Toast 警告「官方谱面获取失败，已按空白谱面创建，可稍后在谱面代码导入中补」 |
| **谱面代码**·Apply 闸门拒绝 | 原文非法 / 过不了校验 | **整笔不建**：错误信息点名第一个校验错 | 维持现状 |
| **封面**·平台无图（`200 + text/html` 或无图字段） | 无封面图 | **降级放行**：工程照建不带封面 | 创建成功后 Toast 提醒「该曲目/帖子未提供封面，工程未包含封面」 |
| **封面**·其他失效（HTTP 404/5xx / 外链被拒 / 网络失败 / 坏字节） | 下载或解码校验失败 | **降级放行**：不因可选封面阻断主线，工程照建不带封面 | 创建成功后 Toast 提醒「封面获取失败，工程未包含封面」（2026-11-14 修订） |

矩阵的判别基准：**有没有事后补救路 + 是否会留下无意义空壳**。封面可随时在工程信息里补传，任何失败都不阻断；音频可在音频页补本地音频，因此在带入了有效谱面代码时允许无音频放行以保住谱面，但绝不建出既无音频又无谱面的空壳工程。

## 3. 重试红线（对所有加载态通用，票 22/24 同源）

- **重试 / 重挂只许在请求终态后触发**（`onError` / `onLoadedMetadata`）。
- 对「飞行中」的同 URL 资源重挂 `<img>` / `<audio>`，Chromium 会让新请求**永久挂住**（票 24 原型实测：`naturalWidth` 有值但 `complete` 恒 false、load 事件永不来）。
- 自动降级链（本机缓存 → 直链）不受此限：那是同一元素换 `src` 重新发起，且逐段终态推进。

## 4. Considered Options（被否记录，防六个月后再提）

- **未带谱面也允许无音频降级**：被否——既无音频又无谱面只会造出一个完全空白的空壳工程，不如直接新建空白工程。
- **音频和谱面双挂时仍降级为空白无音频工程**：被否——同上，不建空壳。
- **放开主进程网关下载任意 `https://` 第三方外链**：被否——维持 `bestdori.com` 白名单安全边界，第三方外链视为不可抓取资源走降级与提示。
- **2026-10-12 初版「音频失败一律阻断、封面网络失败阻断」**：2026-11-14 票 56 已修订——工程音频页已具备本地补传音频入口，且社区 `custom` 帖存在外链与历史死链，一律阻断会导致连谱面代码也无法导入；可选封面亦不应因 HTTP 404/外链/超时拖垮整笔导入。

## 5. Consequences

- `ImportResult` / `OfficialImportReply` 的 `ok` 分支需能表达音频降级与封面缺失/失败两类警告（`audioDegraded` / `coverStatus`）。
- 网关维持 `bestdori.com` 白名单；渲染层错误文案映射需覆盖 `http` / `invalid-response` / `request-rejected`。
- 实现细节与锁测见票 26 与票 56。
