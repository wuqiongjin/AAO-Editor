# ADR-0006: 画布动态渲染面与判定线贴底

- **状态**：Accepted（定案于 grill-with-docs，2026-08-12）
- **背景**：编辑器画布 `FinalVirtualCanvas` 目前用**固定缓冲 750×900**，经 CSS `object-fit: contain` 等比缩放显示在"谱面画布"（sticky 容器）内。窗口比例与 750:900 不符时，画布四周留黑边/留白，与谱面画布区域不贴合；且判定线绘制在画布底部上方 60px 处（`JUDGE_LINE_Y = CANVAS_HEIGHT - 60`），下方留一段空轨道，视觉上与画布底边割裂。用户要求：①画布真正铺满谱面画布区域，任意窗口比例下贴合；②判定线直接以画布下边边缘为准；③轨道不变形、整体性能不劣化。
- **结论**：见本文件全文。本 ADR 是 [ADR-0004 §1](0004-播放预览交互.md) 判定线偏移模型 与 [ADR-0003 布局](0003-工作台UI与配置系统.md) "画布自适应"方向的修订。
- **变更触发**：本 ADR 只定案，不产代码；实现落为 issue 30 载体执行，先文档后代码。

# 画布动态渲染面与判定线贴底

## 1. 渲染面动态化（Q1/Q3 定案）

- **渲染面（surface）**：画布缓冲像素不再固定 750×900，改为随"谱面画布"容器 CSS 尺寸动态变化。`surface = { w, h }` 为容器的 CSS 像素宽高；`buffer = surface × dpr`。
- **清晰度（Q6 定案）**：`dpr = min(window.devicePixelRatio, 2)`；绘制前 `ctx.setTransform(dpr,0,0,dpr,0,0)`，此后所有绘制/命中均用 **CSS 像素**坐标。上限 2 兼顾高分屏锐度与缓冲大小（性能稳定）。
- **贴合（Q1=A）**：canvas 元素 `width/height:100%` 铺满谱面画布容器；去掉 `object-fit: contain` 与 sticky 容器内边距 `padding: var(--space-5)`，使画布边缘与谱面画布区域边缘完全重合、不留留白。
- **轨道不变形 + 水平策略（Q3=B + Q4=A）**：轨道水平居中，大小由 zoom 决定；新增 `effectiveScale(scale) = min(scale, fitWidth(surface.w))`（`fitWidth = (surface.w - chrome×2) / (LANES×LANE_WIDTH)`）——当容器比轨道窄时自动收缩到刚好放得下，**不裁剪、不变形**；容器比轨道宽时两侧为画布黑边，音符大小不随 resize 改变。

## 2. 判定线贴底（Q2=B 定案）

- `JUDGE_LINE_Y` 语义由 `CANVAS_HEIGHT - 60` 改为 **surface.h（画布下边边缘）**：判定线固定画布最底边，无下方空轨道区。
- 画布铺满谱面画布容器且容器位于 PlayBar 正上方 → 判定线恒落在 PlayBar 正上方，彻底消除此前"判定线被 PlayBar 遮挡"问题（issue 24 相关）。

## 3. 垂直窗口与滚动模型（Q5 确认）

- 画布仍是"滚动窗口"：滚动条移动窗口位置；`virtualHeight = chartEndVirtualY + surface.h / effectiveScale`。
- 容器 resize（surface 变化）时，按**当前秒数**重锚窗口底部（复用 issue 24 的三段式按秒重锚机制），保证判定线处秒数不变。

## 4. 几何层改动

- `ChartGeometry` 构造器新增 `surface:{w,h}`（默认 `{750,900}` 兼容既有测试），内部所有 `CANVAS_WIDTH/CANVAS_HEIGHT/JUDGE_LINE_Y` 引用改由 `surface` + `effectiveScale` 推导。
- 坐标/视口剔除/命中/渲染统一按 CSS 像素 + surface 尺寸计算；`RenderCtx` 注入 `surface` 与 `dpr`。
