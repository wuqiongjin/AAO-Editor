# ADR-0008: 工具交互机制（持工具态 × 选区）

- **状态**：Accepted（定案于 grill-with-docs，2026-09-07，issue 55）
- **背景**：原工具交互把"选着什么"和"拿着什么"焊在一根 `selectedTool` 轴上，圈选被硬编码锁在鼠标/镜像两态、编辑动作与放置工具语义含混、BPM 用 `prompt()` 打断输入、已放置音符无法拖拽移动。经三轮 grill 定案重构。
- **修订关系**：**取代** ADR-0002 §3（交互模型）并重定义 §2.1 中 BPM/滑条执行键语义（键位目录与配置机制仍归 ADR-0002）；**修订** ADR-0001 §2（横向禁令范围限定为两击直放路径）。
- **变更触发**：任何工具切换/点击/框选/执行键/退出行为与本文冲突时，须先更新本文并经用户确认。
- **2026-09-09 修订（issue 65②）**：§4 两击直放补「锚点的取消边界」——**起手框选 = 立即取消锚点**（本把手势改走 §4 组合）；拖拽音符不清。同日 issue 63 把"框选越出画布即取消"改为 window 级隐式指针捕获（该项**待用户验收确认**）。
- **2026-09-12 修订（issue 09 → ADR-0009）**：§2 原则 2 增「曲线工具态」框选例外（空白拖 = 画笔、Shift+拖 = 框选）；§4 SP 绿条预留行落定（曲线工具，模型归 ADR-0009）；§6 末条改写（hidden 结点不可独立拖 + slideRegion 可拖 = 拉弓变形）。
- **2026-09-16 修订（issue 108 / 109 定案，用户拍板）**：§6 末条 `slideRegion` 可拖由**拉弓变形**改为**捏形**（峰值在抓取点，模型见 ADR-0009 §4）；§7 Esc **四档链 → 五档链**，新增第②档「**进行中手势**」（详情见 §7）。
- **2026-09-21 修订（issue 137）**：§2 issue 88 补曲线行——命中 ∈ 选区 = 框选同一行（组合 + 刷当前缓动）；曲线无 Shift 按下命中选区内不启画笔。
- **2026-09-25 修订（issue 158）**：右键双模态——未过框选阈值 8px 仍点删（含 issue 88 整区）；过阈值 = 删除工具框选行（含 BPM、任意持工具态）。`canStartMarquee` 的粘贴/音符代码例外只约束左键。

- **2026-09-25 修订（issue 159 定案 2）**：沟槽 **BPM 摘要**（线 y 相同的多层）单击 = **展开**，不是就地编辑；展开后的真数字仍单击即编辑。Esc 取消编辑后留在展开态。手风琴同时最多一组。

> 实现载体 = issue 55。§4 组合规则表与 §2/§3 语义矩阵**必须逐行落单测锁表**（用户明确要求：规则表"明确地"落到文档和代码，未来变动走本票流程）。

## 1. 状态模型：两轴

- **工具轴 —— 持工具态（armedTool）**：单轴互斥，**所有**工具共驻一根轴（键型放置 / BPM / Slide / 编辑动作 / 指针）。指针态 = armedTool 为空，是默认底态。换工具 = 换手里拿的东西，**不需要经鼠标工具中转**——"放置与编辑都是工具、混在一根轴没有问题"是定案前提。
- **对象轴 —— 选区（selection）**：点选/框选/Shift 加选建立的音符（含滑条子部分，ADR-0001 §6）集合。**常驻、与持工具态解耦**：手持滑键工具的同时，选区依然存在。
- **执行（exec）**：**不是态**，是执行键的瞬时动作——无论当前持有什么工具，在谱面光标位置立即执行对应功能；该位置非法则**无事发生**、不留状态。

> **名词裁决**："选中/选中态"一词**永远只指音符进入选区**；工具被激活称"持工具态"。grill 会话中用户口径的"选中态/执行态"→ 即本节的 持工具态 / 执行键。

## 2. 统一交互原则

1. **按下移动 ≥ 阈值 = 拖拽 / 框选；< 阈值 = 单击**。**阈值按按下意图分档（issue 141 定案）**：
   - **拖拽移动 / 画笔 = 4px**（要跟手）；
   - **框选 = 8px**（防手抖）—— 4px 时持工具态放音符手一抖就越线，松手走 `commitBox`，
     那一击的放置被吃掉（框内有音符时还会变成批量换型）。
   单击的落点取**按下点**（不是松手点），故"移一点点再松手"本应是宽容的，阈值太高会把它变成框选。
2. **任何持工具态下都可框选**——废除 `mouse || mirror` 硬编码门控。
   - **例外（issue 59 §3 / issue 72）**：左键在「音符代码」与「粘贴」工具态**不可框选**——按下拖拽根本不启动框选
     （不画框选矩形），而不是"框了松手无反应"。音符代码是不改谱面的工具；粘贴作用于**位置**
     （把剪贴板组放到光标处），选中既有音符对它毫无意义。二者同由 `CanvasGesture.canStartMarquee` 门控。
     **右键不套此例外（issue 158）**：任意持工具态都可右键拖框，松手按删除工具框选同一行立刻删除。
   - **例外（issue 09 / ADR-0009，2026-09-12）**：「曲线」工具态**空白拖动 = 画笔**（沿轨迹采样成自由段），
     框选改由 **Shift+拖动** 触发（该态下框选作用仍为滑条组合）——画笔优先，Shift 保住"任意态可框选"的最小通路。
3. **所有工具一律驻留**，无一次性特例：放置类放完继续放，动作类执行完工具不丢。退出只有三出口：**按 Esc / 点击当前高亮的工具按钮 / 切换到其他工具（点按钮或按切换键）**。
4. **批量应用后选区保留**（便于连续操作、再移位）。例外：**组合类**（框选组合/Ctrl+E 组合）完成后清空选区——来源已被消耗，属一次性动作（§4，三轮修订）。
5. 框选拖拽期间的预览复用幽灵体系（issue 13 / ADR-0002 §4 精神）。
6. **非指针态单击画布 = 清空选区**（2026-09-08 追加，同日扩订）：选区是"待作用对象"，点了画布就意味着
   注意力已转移，旧选区留着既是噪音、其下标在谱面变更后也可能已错位。
   - **与落点是否合法、动作是否生效无关**：点轨道外 / 谱面末端外（落点非法）时动作按 §1"无事发生"，
     但选中态照样取消；键型放置被 ADR-0001 §1.2 忽略（如单键落到滑条结点）时也取消；Slide 挂锚点、取消锚点同样取消
     （不按"是否改谱面"做双轨判定）。
   - **保留选区的例外**：① 镜像、粘贴后选区 = **本次产物**（不是残留）；② 框选批量应用后保留（原则 4）；
     ③ 拖拽移动后保留（§6，便于连续移位）；④ 复制后必须保留（否则执行键无从作用）。
     ~~⑤「音符代码」工具态单击不清选区~~ **已作废（issue 83，2026-09-11 用户重新定案）**：
     实测反例 = 选中 A → 切「音符代码」→ 点 B，A 的选中框仍挂着 —— 用户点了画布注意力就已转移，
     与"改不改谱面"无关。故音符代码态单击**一律清选区**（命中 → 打开代码 + 清；未命中/落点非法 → 只清）。
   - ⑥ **命中项 ∈ 选区（issue 88，2026-09-11 用户拍板）**：该工具动作**作用于整片选区**，且**不清**选区 ——
     这一击被选区消费，清不清交给动作自身（删除清 / 镜像 → 选区 = 产物 / 键型保留 / 组合清）。
     点**选区外**音符仍是"清空旧选区 + 只作用被点那一个"（issue 83 口径不变）。详见下方单击矩阵后的说明。
   - 删除 / 镜像态点空白（**轨道内空白**原按 §2 单击矩阵"无效果、不清选区"——清选区走 Esc 或指针态点空白；
     **issue 83 2026-09-11 扩订后：轨道内空白与轨道外一律清选区**，不再按"落点是否合法"双轨判定，
     与本原则"与落点是否合法、动作是否生效无关"对齐）。删除 / 剪切执行后本就清空。

**单击语义矩阵**（按工具族）：

| 工具族 | 点击音符 | 点击空白 |
| --- | --- | --- |
| 指针（R） | 选中该目标（替换选区；Shift 加选；Ctrl 选整条滑条，ADR-0001 §6.1） | 清空选区 |
| 键型放置（F/G/A/S/D） | 在栅格位放置，走 ADR-0001 §1 覆盖/替换规则；**issue 88**：命中 ∈ 选区 → 整片按此规则换型 | 放置 |
| BPM（`） | **点击已有 BPM 线 = 无效果**（issue 56 Q14=A；BPM 的通路 = 完整框选 / 右键删除 / 沟槽数字就地编辑） | 放置（同拍已有 BPM 按覆盖处理）→ 进入 §5 就地编辑 |
| Slide（E） | **issue 88**：命中 ∈ 选区 → 先试整片组合（**与框选同源**）；否则 第一次点击=放**临时端点**，第二次合法点击=成条（现状两击保留） | 同左 |
| 删除/镜像（T/Q） | 选中该音符并立即执行（Model A 保留，ADR-0002 §3.2）；**issue 88**：命中 ∈ 选区 → 对**整片选区**执行；**删除对 BPM 生效**（删该线），**镜像对 BPM 不生效** | 无效果、**但清选区**（issue 83：轨道内空白与轨道外一律清，不再双轨） |
| 粘贴（V，持工具态） | 在点击位置粘贴（锚点语义见 §2.1）；**粘贴后驻留** → 可连续粘贴 | 同左 |
| 音符代码（B，issue 59 §3） | 打开该音符 / 结点的代码弹窗（粒度沿用 `findItemAt` 数组序首个；hidden 结点不可达；滑条**区域**回退整条视图）；**并清空选区**（issue 83 重定案）；弹窗关闭后**态驻留** | 无效果、**但清选区**（issue 83：落点非法/无命中同样清） |
| 复制/剪切（Ctrl+C / Ctrl+X） | **不占工具轴**（见 §2.1）——只在有选区时由执行键触发，无工具态 | 不占工具轴 |

> **issue 88（2026-09-11，用户拍板）：命中项 ∈ 选区 → 该工具动作作用于整片选区。**
> 触发条件 = 单击命中的条目 ∈ 当前选区（`sameSelectionItem` 口径，含滑条结点 / 区域）；
> 点**选区外**音符仍是「清空旧选区 + 只作用于被点那一个」（issue 83 口径）。**不设"选区 ≥2"门槛**
> （选区只有 1 件时两条路径结果等价）。
> **实现口径（2026-09-11 用户强调）：「先框选，再单击选区内音符」与「先切到该工具的持工具态，再框选」
> 是同一件事的两种先后顺序，表现必须恒等** —— 故单击路径**直接复用框选矩阵**（`boxSelectOps` 的同一行），
> **不另写一套**；框选行为怎么改，单击路径自动跟随。逐工具口径即该工具"框选"时的口径：
> - **键型** = 整片批量换型（`batchApplyKeyType` → ADR-0001 替换规则：滑条结点拆条 / 端点标记覆盖 /
>   **方向键 length+1、到 3 回 1**；不可替换的跳过），选区按结果 remap 保留；
> - **删除 / 镜像** = 整片执行（删除清选区；镜像 → 选区 = 产物）；**右键点删（issue 74/88 通路）同口径**；
>   **右键拖过 8px（issue 158）改走框选删除行**，不再按松手点做 issue 88 点删。右键**不**启动拖拽移动。
> - **Slide** = 整片组合（§4，**同拍横向合法**，与框选组合一致）；来源 <2 → 不组合、回落两击直放；
> - **曲线** = 整片组合 + 当前缓动/模板刷每一段（与 Shift+框选 `curveBoxOps` 同源）；来源不可组合时仍刷框内既有滑条；点选区外 = 清选区后走两击/点段；
> - **不适用（维持原行）**：BPM（栅格位放线）、粘贴（作用于位置）、音符代码（弹窗单例）、指针（选区语义本身）；
> - **执行键不在本例外内**：`Ctrl+F/G/A/S/D`、`Ctrl+V` 是"光标处放置 / 粘贴"，与"点了哪个音符"无关。
>
> 「点击已有 BPM 线 = 无效果」的**作用域只到非放置类工具**：
> - **不受限（照常按栅格位放置）**：键型 / Slide / 粘贴 —— 它们是"放置"，BPM 线不拦
>   （否则 lane 0 上恰好有 BPM 的拍就永远放不下音符）；
> - **受限（动作无效果，按 §2 原则 6 清选区）**：**BPM 工具自身**（点已有线不再覆盖值、也不开就地编辑；
>   要改值走沟槽数字）、**镜像**；
> - **例外（有明确语义）**：**删除** = 删除该线（beat 0 见下）、**音符代码** = 打开该 BPM 的代码。
> 两个例外：**删除** = 删除该线（beat 0 例外，见下）；**音符代码** = 打开该 BPM 音符的代码（issue 59 定案）。
> **beat 0 的 BPM 线不可删除**（ADR-0001 保底 + issue 59 定案）：删除动作（删除工具 / 右键 / 框选后 `Delete` /
> 剪切）退化为「**重置为初始状态**」——`bpm` 回到 `DEFAULT_BPM`（120），线本身保留。用户把初始 BPM 改成 180
> 后再删，看到的就是数值回到 120。非 beat 0 的 BPM 线照常删除。
>（谱面代码路径不在此例：代码里删掉第 0 拍 BPM 属"非法代码"，按 §1.2 整份拒 + 报错，不静默修正。）
>
> **命中几何 = 整条线**（横跨轨道、纵向 ±6px×scale 容差），且 **BPM 是最后才判的一层**：BPM 线画在音符层
> **之下**，判定顺序恒为 **音符 / 方向键 / 滑条结点 / 滑条段 → 最后才是 BPM 线**。实现上 `findItemAt`
> **完全跳过 BPM**（同时满足 56 的「指针态单击 BPM 不选中」「BPM 不参与 hover」），BPM 一律经
> `findBpmLineAt` 按整条线判定，只服务于删除 / 音符代码 / 右键删除三条通路。

| 工具族 | 拖拽框选并松开后 |
| --- | --- |
| 指针 | 建立选区（现状） |

### 2.1 粘贴语义（2026-09-08 六轮定案）

- **锚点 = 剪贴板组的包围盒左上角（min beat × min lane）对齐到光标**（维持既有实现）。理由：
  - 组形状与相对位移 100% 保留（纯平移，复制一段楼梯再粘到别处不变形）；
  - **保证没有任何音符落在光标的左侧/上方**——内容自光标起向右下铺开，与"放置"的直觉一致；
  - 备选方案「锚音符 = 排序最前的**实际**音符」（光标格必现音符）在常见选区下与本方案等价，仅在「最左音符不在最前拍」时才不同，而此时它会让内容溢出到光标左上侧，反而更不可预期。
  - 「不可预期」的剩余部分由**实时预览**消除：持工具态下悬停即显示整组幽灵落点（所见即所得）。
- **BPM / System 不参与锚点计算**：它们没有 lane，参与 min 会污染组的左上角；只按最终 beat 位移平移。
- **越界钳制**：组按光标 lane 对齐后右缘越出轨道 → 整体左移至恰好放下，**保持组宽不变**。
- **光标（鼠标）不在画布 = 非法位置 → 无事发生**（§1）；`Ctrl+V` 此时无效，工具栏按钮只是进/出持工具态，不受影响。
- **持工具态转正**：Toolbar「粘贴」= arm/释放（与删除/镜像同构、与 `V` 归位，Esc / 再点 / 切工具退出）；悬停 = 整组幽灵预览；单击 = 在该位置粘贴并**驻留**（连续粘贴）；粘贴产物 = 新选区（便于紧接着移动/删除）。执行键 `Ctrl+V` 保留（光标处即时粘贴，不占工具态）。
  - **空剪贴板 = 不可进态**（六轮追加）：粘贴是唯一"前提缺失即完全空转"的工具——无剪贴板时单击无事发生、**悬停预览也为空**（删除/镜像无选区时点中音符仍立即生效，键型/BPM/Slide 是放置、永远有产物）。故：Toolbar 按钮置灰并在 tooltip 说明"剪贴板为空，先 Ctrl+C 复制"，**`V` 键同步不进态**（键鼠一致，避免上轮 #6 的"界面无、键盘有"错位）。复制后按钮与键同时可用。
  - 判据只含剪贴板、**不含光标**：光标不在画布只是"落点非法 → 无事发生"（§1），不应阻止进态（旧实现把两者混为一谈，鼠标移到工具栏上按钮就灰掉）。
- **复制 / 剪切不占工具轴**（不 arm）：二者**必须有选区**才有意义（作用于对象而非位置），剪贴板只有一份、连续复制无意义，连续剪切还有误删风险。只保留 `Ctrl+C` / `Ctrl+X` 作用于选区；键盘 `switchCopy` / `switchCut` 随之从工具轴摘除。

## 3. 执行键语义（修订 ADR-0002 §2.1 注释）

| 执行键 | 语义 |
| --- | --- |
| Ctrl+F/G/A/S/D | 光标处立即放置该类型（光标在已有音符上 = 按 ADR-0001 替换，等价单击放置）；光标不在画布则忽略 |
| Ctrl+` | 光标处放置 BPM 线（默认值按 §5）→ 进入就地编辑 |
| **Ctrl+E** | **有选区** → 选区按 §4 组合成滑条（组合来源 <2 则无事发生）；**无选区** → 放临时端点，与鼠标两击**共用同一 slideBuffer**（"点一下画布 + 再按一次 Ctrl+E"亦可成条） |
| Ctrl+F/G/A/S/D | 光标处放置该类型 —— **与单击放置共用 `clickOps`**（经画布 `execPlace`），故 §2 原则 6（清选区）与 snapPos 的越末端判定自动一致；光标不在画布 / 越末端 = 无事发生 |
| Ctrl+C/X/T/Q | 作用于**当前选区**（C/X 无工具态，见 §2.1） |
| Ctrl+V | 当前光标位置粘贴；**光标不在画布 = 无事发生**（§2.1） |

> 原"复制/剪切等需回鼠标工具框选再执行"的流程（ADR-0002 §3.2 取舍条款）**作废**：任何持工具态下可直接框选（§2 原则 2），执行键与框选批量应用殊途同归。

## 4. Slide 放置 = 两击直放 + 框选组合（混合制）

两条路径并存，**组合为主力**（结点落在已放置音符位上，且能做出直放做不了的形态）：

- **两击直放**（保留现状）：快速在空位起条；**ADR-0001 §2"禁止横向"仅约束此路径**。
  - **锚点的取消边界**（issue 65②，2026-09-09 修订）：Esc ②档 / 第二击落在同位或同拍（含横向）/ 非法落点单击 / 切离 Slide 工具 / **从画布起手拉出框选**（跨过拖拽阈值那一刻）→ 立即清锚点。起手框选 = 本把手势改走 §4 组合，留着临时端点会让人误以为"框选之外还挂着一条待连接的起点"（与原则 6"点了画布 = 注意力已转移"同族）。**拖拽音符（指针态 / Shift+按住）不清**——那是移动语义，与两击路径无关。
- **框选组合**（新）：Slide 工具态框选（或"已有选区 + Ctrl+E"）→ 音符按 **beat+subBeat 升序、同拍按 lane 升序** 排成结点序列（N≥2 即成条）。组合**与 ADR-0001 §1.2 覆盖/替换规则无关**——框内任何键型一律吸入。同拍横向段在此路径合法（zigzag 样例 `1.5l1→1.5l5→2l1→2l5` 即由此排序重现）。

**形态归一表**（被吸音符 → 滑条结点；音符本体被**消耗**=删除，标记按下表转移；此表为独立规则，未来变动改本表）：

| 被吸音符 | 起始端点 | 中间结点 | 末尾端点 |
| --- | --- | --- | --- |
| 单键 | 普通端点 | 中间结点 | 普通端点 |
| 滑键 flick | **降为普通端点**（剥标记；与 ADR-0001 §5"滑键不可作起点"一致） | 统一化中间结点（剥标记） | 保留 `flick` |
| 技能键 skill | 保留 `skill` | 统一化中间结点（剥标记） | 保留 `skill` |
| 方向键 | 普通端点 | 统一化中间结点 | 普通端点 |

- **接合**：组合产生的端点若与**既有滑条端点重合**，仍走 ADR-0001 §3 滑条-滑条组合（合并）规则。
- **滑条吸入（2026-09-07 三轮修订、2026-09-08 四/五轮修订 = **触碰即整条入链**）**——框选组合的来源不限于键型音符：
  - **任一结点入框（`slideNode`）或整条选中（`kind:'note'`）即整条入链、本体消耗**，**不再区分完整/部分覆盖，也不再拆条**（五轮修订：组合 = 往滑条里并东西，不是切东西；要掐断请用方向键放置 / 删除结点）。三轮的「宿主未覆盖段拆条保留」条款**作废**（它会把 `A→B` 的 `B` 拆成孤立音符，与"向滑条中间插结点"的意图相反）。
  - **排序 = K 路保序归并**：每个被触碰滑条的结点序列是一整块（**块内保原顺序**，不重排宿主形状，如同拍回折段），键音符各为单例块，块间按上表排序规则取最小头。典型：`A→B` + 框 `A` 与中间的新音符 → `A→新音符→B`。全部单例块时退化为纯排序（与既有锁表一致）。
  - 被吸入的结点从宿主移除，**位置不重复**（ADR-0001 位置排他）。
  - 排序后**同位置结点重合**（一条的尾 = 另一条的头）→ 合并为单结点，接合处按两击路径同语义标记 `hidden:false`（可见接合点）；flick/skill 先 OR 汇集、再按归一表按位剥除。
  - **来源计数**：可组合判据 = 「**来源对象 ≥2**」（吸入键音符数 + 被触碰滑条数，触碰 = 至少 1 结点入框/整条选中）；单条滑条多结点入框不成链（来源=1，无事发生）。样例：`A→B`、`C→D` 两独立滑条，**只框 B、C** → 两宿主端点各在链端点 → 级联接合成 `A→B→C→D`（四轮修订；三轮的「成链 `B→C` + `A`/`D` 退化」作废）。
  - **结果 type**：任一被吸入/消耗滑条为 `Long` → 结果 `Long`，否则 `Slide`。
  - **组合是一次性动作**：执行完毕**清空选区**（来源已消耗、无可保留对象；结果滑条不自动进入选中态，也就无选中描边）。原则 4 的「批量后选区保留」不适用于组合。
  - **两击路径同规则**：单击接合（buffer 尾 + 点另一条头）经 `mergeChainWithSlides` **级联**合并两侧既有滑条（`A→B` + 两击 `B→C` + `C→D` → 一步成 `A→B→C→D`，2026-09-07 三轮修复：旧实现只并一侧即返回）。**点击次序无关**（四轮修复）：两点按 beat→subBeat→lane 升序归一为链 `[起, 止]`，先点后拍 `C` 再点前拍 `B` 与 `B`→`C` 完全等价（旧实现因 `||` 与 `<=` 优先级写错，beat 差非 0 时恒按点击顺序取链，`C→B` 两侧都不接合）。合并结果**写回首条被消耗滑条的原下标**（SlideExtendRepro 锁瓦片失效锚定）。
- **SP 绿条（issue 09，2026-09-12 定案 → ADR-0009）**：独立「曲线」工具——单击链式 = 按当前缓动配置烘焙缓动段（出生即 SP），拖动 = 画笔自由段；段参数按 §5 就地编辑模式即时重生成；结点来源机制 = 框选组合仍适用（N 结点天然支持）。数据模型（参数随行 / 点集唯一真相 / 三来源 / 一动就自由化 / 段级材质 / 40 缓动 × 3 精度档）权威 = **ADR-0009**。

## 5. 工具内参数 = 对象就地编辑（取代 `prompt()`）

- BPM 流程：放置 BPM 线 → 数值 = **首次用现默认值，此后沿用上一次放置所设的值** → 放置动作未结束：左侧沟槽的 BPM 数字自动进入编辑态（光标置于数字内并闪烁）→ **Enter 应用**；用户随时可再次编辑该数字，**无需切回 BPM 工具**。
- 编辑中 Esc = 取消本次编辑（保留放置时已应用的值）；输入框属 ADR-0002 §6 作用域放行（快捷键不抢键）。
- 手势仲裁：BPM **真数字**单击=进编辑（stopPropagation）；**BPM 摘要**单击=展开同位组（不进编辑）；左沟槽**双击**=临时起点标记（ADR-0004）不变。展开组内文字盒包络（含盒间缝）上的点击不折回摘要。
- **命中区 = 数字自身的文字盒**（2026-09-08 修订）：只认 `bpmLabelBox`（右缘 = 内带锚点、宽 = 等宽估算 + 容差、纵向骑线居中并沿用顶/底钳制），**不再把数字所在的整条水平线都判成命中**——否则该高度上左沟槽的双击永远被判为"数字命中"、起点标记手势放不下去。沟槽宽度不足、绘制时整体隐藏的数字同样不可命中。
- 适用面：后续任何对象参数（滑条结点缓动、长条数值微调等）一律复用此模式——**参数挂在对象上、就地改、无模态打断**，不再发明第二种输入打断。

## 6. 拖拽移动已放置音符（新增能力）

- 入口：指针态按下音符拖拽 = **移动**；**任意持工具态下 Shift+按住音符 = 移动**（三轮修订，用户验收反馈 #4：原「仅指针态」难发现且与放置态操作流冲突）。未达移动阈值即松开 = 取消拖拽、回落到该态原本的单击语义。空白按下拖拽 = 框选；非 Shift 的其他持工具态拖拽一律 = 框选（防误拖）。
- 反馈：拖拽进行中鼠标光标 = `grabbing`。
- 吸附：beat 栅格 × lane 整格（与放置同规则）；多选音符整体拖 = **组移动**（拖拽集合共用一个 delta，
  组内相对位移与成员顺序不变）；落点非法（越界/不可裁决的碰撞）= **整体回弹**（不改任何音符）。
  注：组移动**不复用** `shiftGroupToAnchor`（那是粘贴的锚定算法，语义是"钳制到恰好放下"，与此处"非法即回弹"相反）。
- 滑条：端点拖动 = 延伸/收缩（补 issue 07 遗留的端点扩展交互）；中间结点拖动 = 改形状。
- **落点碰撞不一律回弹**（2026-09-08 四轮修订）——按 ADR-0001 既有规则裁决，规则一律复用既有实现，不新造：

  | 拖拽件 \ 落点既有 | 键音符 | 滑条端点 | 滑条中间结点 |
  | --- | --- | --- | --- |
  | 键音符 | **§1.1 替换**：目标被拖拽件消耗（方向键 `length` 取拖拽件原值、不叠加——移动 ≠ 重复放置） | 回弹 | 回弹 |
  | 滑条端点 | **覆盖删除**（与放置/粘贴的 `removeOverlappedNotes` 同语义） | **§3 接合**：异条两端点并为一条链（可级联；共享点降 `hidden:false`，任一为 `Long` 则结果 `Long`） | 回弹 |
  | 滑条中间结点 | 回弹 | 回弹 | 回弹 |

  - 判定次序：先做越界/邻居序校验 → 再按上表裁决落点 → 全部可裁决才提交；任一件不可裁决 = 整个拖拽回弹。
  - 拖拽件之间**不自覆盖、不互接合**（同一位置被两件认领 = 回弹）；§1.2（flick/skill/拆条）属**放置**语义，键音符拖到滑条结点不处置、直接回弹。
  - 合并结果写回**被拖滑条**所在下标，其余被消耗滑条移除；选区条目按新下标重映射（覆盖/接合会增删元素，故幽灵预览由 `planDragMove.ghost` 显式给出，不再由新旧数组逐位比对）。
- hidden 结点 / SP 曲线拖拽（**2026-09-12 修订**，issue 09 / ADR-0009 落定，取代本票原"结点一等可拖对象"预留）：
  hidden 结点**不可**作为独立对象被选中/悬停/拖动（issue 56 Q36=D）；
  **`slideRegion` 可拖 = 捏形**（**2026-09-16 由"拉弓变形"改**，issue 108：峰值在**按下时锁定的最近段内 hidden 采样点**、分段线性权重、两端可见结点锚定、beat 不动、不跨段；抓段中点时与旧拉弓逐点相同）；普通段拨弯 = 补 1/16 采样点就地转化；拖带 → 段参数清除转自由段，即"一动就自由化"；拖端点 = 移动意图，解析段重烘焙 / 自由段形态重映射）。模型细节见 ADR-0009 §4。

## 7. 退出与 Esc 五档链

**【2026-09-16 修订（issue 109 定案，用户拍板）】** 四档 → **五档**，新增的「进行中手势」插在锚点之前。

Esc 依序消费（先到先吃，只吃一档）：**① 弹窗自消费（capture 层；弹窗内部可再细分，见下）→ ② 取消进行中手势 → ③ 取消 Slide/曲线锚点 → ④ 清空选区 → ⑤ 持工具态落回指针**。

**②–⑤ 的政策唯一入口** = `CanvasGesture.resolveEscapeTarget`（① 不进本函数）。Editor 组 `{ 手势四旗, 锚点, 选区, 持工具态 }` 后只消费吐出的一档；② 执行 `cancelActiveGesture`，③ 执行 `cancelPendingSlide`。

- **第②档 = 进行中手势（active gesture）**：对象 = 画笔 / 拖拽移动 / 拖带捏形 / 框选矩形 / 右键删除预览（`dragRef` / `penRef` / `selectionBox` / `marqueeCursorRef` / `rightButtonHeld` 等 ref 态），由 `cancelActiveGesture()` **单点**清除并 `detachWindowGesture()`。
  - **一次 Esc 只取消一层**：有进行中手势时，锚点 / 选区 / 工具态**一律不动**，再按一次才轮到③。
  - **取消后保持工具态**：取消画笔 = 作废这一笔、仍留在曲线工具；取消拖拽 = 音符回原位、工具不变。Esc 的语义是"撤销这次操作"，不是"退出工具"。
  - **取消后保留选区**：手势进行中不再顺带清选区；无手势时才走④。
  - **作废到 mouseup**：置 `gestureCancelledRef`，期间 mousemove/mouseup 全部短路（**不重新起笔、不变框选、不提交**），松手只清标志 —— 缺这一条就会出现"取消后手势变形"（旧状：画笔按 Esc 后这一笔变成框选并真的建立选区，且画笔光标残留）。
  - **Esc 硬编码、不进 ADR-0002 注册表**（不可改键、不可屏蔽）：取消是安全底线。

- **第①档 = 谱面代码弹窗：Esc 一律直接关弹窗**（issue 59，用户 2026-09-09 定案）。
  弹窗内**没有**逐档退：无论停在完整代码 / 整条音符 / 滑条结点哪一级，Esc 都是关掉整个弹窗。
  对象视图的**向上导航只走面包屑**（`完整谱面代码 › 所属滑条 › 滑条结点代码`，只向上、不下钻）。
  Esc 的按键自动重复（`e.repeat`）忽略，避免连发连吃。
- **侧栏折叠从 Esc 摘除**（原第三环，见 `Editor.tsx` onEscape 链）：进 ADR-0002 注册表成可自定义功能，
  语义 = 左右两侧面板**折叠/展开 toggle**（顺带修复现状"Esc 只能折不能开"的缺陷）。
  默认键 issue 59 §2 起由 `Ctrl+B` 改为 **`Ctrl+Shift+B`**（`Ctrl+B` 让给「执行-音符代码」）。
