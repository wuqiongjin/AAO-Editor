# ADR-0008: 工具交互机制（持工具态 × 选区）

- **状态**：Accepted（定案于 grill-with-docs，2026-09-07，issue 55）
- **背景**：原工具交互把"选着什么"和"拿着什么"焊在一根 `selectedTool` 轴上，圈选被硬编码锁在鼠标/镜像两态、编辑动作与放置工具语义含混、BPM 用 `prompt()` 打断输入、已放置音符无法拖拽移动。经三轮 grill 定案重构。
- **修订关系**：**取代** ADR-0002 §3（交互模型）并重定义 §2.1 中 BPM/滑条执行键语义（键位目录与配置机制仍归 ADR-0002）；**修订** ADR-0001 §2（横向禁令范围限定为两击直放路径）。
- **变更触发**：任何工具切换/点击/框选/执行键/退出行为与本文冲突时，须先更新本文并经用户确认。

> 实现载体 = issue 55。§4 组合规则表与 §2/§3 语义矩阵**必须逐行落单测锁表**（用户明确要求：规则表"明确地"落到文档和代码，未来变动走本票流程）。

---

## 1. 状态模型：两轴

- **工具轴 —— 持工具态（armedTool）**：单轴互斥，**所有**工具共驻一根轴（键型放置 / BPM / Slide / 编辑动作 / 指针）。指针态 = armedTool 为空，是默认底态。换工具 = 换手里拿的东西，**不需要经鼠标工具中转**——"放置与编辑都是工具、混在一根轴没有问题"是定案前提。
- **对象轴 —— 选区（selection）**：点选/框选/Shift 加选建立的音符（含滑条子部分，ADR-0001 §6）集合。**常驻、与持工具态解耦**：手持滑键工具的同时，选区依然存在。
- **执行（exec）**：**不是态**，是执行键的瞬时动作——无论当前持有什么工具，在谱面光标位置立即执行对应功能；该位置非法则**无事发生**、不留状态。

> **名词裁决**："选中/选中态"一词**永远只指音符进入选区**；工具被激活称"持工具态"。grill 会话中用户口径的"选中态/执行态"→ 即本节的 持工具态 / 执行键。

## 2. 统一交互原则

1. **按下移动 ≥4px = 拖拽；<4px 快速起按 = 单击**（阈值沿用现实现）。
2. **任何持工具态下都可框选**——废除 `mouse || mirror` 硬编码门控。
3. **所有工具一律驻留**，无一次性特例：放置类放完继续放，动作类执行完工具不丢。退出只有三出口：**按 Esc / 点击当前高亮的工具按钮 / 切换到其他工具（点按钮或按切换键）**。
4. **批量应用后选区保留**（便于连续操作、再移位）。
5. 框选拖拽期间的预览复用幽灵体系（issue 13 / ADR-0002 §4 精神）。

**单击语义矩阵**（按工具族）：

| 工具族 | 点击音符 | 点击空白 |
| --- | --- | --- |
| 指针（R） | 选中该目标（替换选区；Shift 加选；Ctrl 选整条滑条，ADR-0001 §6.1） | 清空选区 |
| 键型放置（F/G/A/S/D） | 在栅格位放置，走 ADR-0001 §1 覆盖/替换规则 | 放置 |
| BPM（`） | 放置（同拍已有 BPM 按覆盖处理） | 放置 → 进入 §5 就地编辑 |
| Slide（E） | 第一次点击=放**临时端点**，第二次合法点击=成条（现状两击保留） | 同左 |
| 复制/剪切/删除/镜像（C/X/T/Q） | 选中该音符并立即执行（Model A 保留，ADR-0002 §3.2） | 无效果（不清选区；清选区用 Esc 或指针态点空白） |
| 粘贴（V） | 在点击位置粘贴（作用于位置） | 同左 |

**框选语义矩阵**：

| 工具族 | 拖拽框选并松开后 |
| --- | --- |
| 指针 | 建立选区（现状） |
| 键型放置 | 框内音符**逐个应用 ADR-0001 替换规则**（可替换的换型、不可替换的跳过——如滑键框选含单键/滑条中间结点时按表各自处置） |
| BPM | 无效果 |
| Slide | **组合成滑条**（§4 表） |
| 复制 / 剪切 / 删除 | 对整个选区执行该动作（删除含 §6.2 拆条语义） |
| 镜像 | 拖拽期间预览镜像结果（含滑条连接区域，ADR-0002 §4），松开**立即执行**（无需二次确认） |
| 粘贴 | 无效果（粘贴作用于位置） |

## 3. 执行键语义（修订 ADR-0002 §2.1 注释）

| 执行键 | 语义 |
| --- | --- |
| Ctrl+F/G/A/S/D | 光标处立即放置该类型（光标在已有音符上 = 按 ADR-0001 替换，等价单击放置）；光标不在画布则忽略 |
| Ctrl+` | 光标处放置 BPM 线（默认值按 §5）→ 进入就地编辑 |
| **Ctrl+E** | **有选区** → 选区按 §4 组合成滑条（音符 <2 则无事发生）；**无选区** → 放临时端点，与鼠标两击**共用同一 slideBuffer**（"点一下画布 + 再按一次 Ctrl+E"亦可成条） |
| Ctrl+C/X/T/Q | 作用于**当前选区** |
| Ctrl+V | 当前光标位置粘贴 |

> 原"复制/剪切等需回鼠标工具框选再执行"的流程（ADR-0002 §3.2 取舍条款）**作废**：任何持工具态下可直接框选（§2 原则 2），执行键与框选批量应用殊途同归。

## 4. Slide 放置 = 两击直放 + 框选组合（混合制）

两条路径并存，**组合为主力**（结点落在已放置音符位上，且能做出直放做不了的形态）：

- **两击直放**（保留现状）：快速在空位起条；**ADR-0001 §2"禁止横向"仅约束此路径**。
- **框选组合**（新）：Slide 工具态框选（或"已有选区 + Ctrl+E"）→ 音符按 **beat+subBeat 升序、同拍按 lane 升序** 排成结点序列（N≥2 即成条）。组合**与 ADR-0001 §1.2 覆盖/替换规则无关**——框内任何键型一律吸入。同拍横向段在此路径合法（zigzag 样例 `1.5l1→1.5l5→2l1→2l5` 即由此排序重现）。

**形态归一表**（被吸音符 → 滑条结点；音符本体被**消耗**=删除，标记按下表转移；此表为独立规则，未来变动改本表）：

| 被吸音符 | 起始端点 | 中间结点 | 末尾端点 |
| --- | --- | --- | --- |
| 单键 | 普通端点 | 中间结点 | 普通端点 |
| 滑键 flick | **降为普通端点**（剥标记；与 ADR-0001 §5"滑键不可作起点"一致） | 统一化中间结点（剥标记） | 保留 `flick` |
| 技能键 skill | 保留 `skill` | 统一化中间结点（剥标记） | 保留 `skill` |
| 方向键 | 普通端点 | 统一化中间结点 | 普通端点 |

- **接合**：组合产生的端点若与**既有滑条端点重合**，仍走 ADR-0001 §3 滑条-滑条组合（合并）规则。
- **SP 绿条预留（issue 09）**：结点来源机制 = 框选组合（N 结点已天然支持）；过渡结点缓动参数 = 挂在结点上按 §5 就地编辑模式输入；结点拖拽整形 = §6 预留的"结点一等可拖对象"。09 自身只拍范围/格式字段/缓动算法，不再设计交互。

## 5. 工具内参数 = 对象就地编辑（取代 `prompt()`）

- BPM 流程：放置 BPM 线 → 数值 = **首次用现默认值，此后沿用上一次放置所设的值** → 放置动作未结束：左侧沟槽的 BPM 数字自动进入编辑态（光标置于数字内并闪烁）→ **Enter 应用**；用户随时可再次编辑该数字，**无需切回 BPM 工具**。
- 编辑中 Esc = 取消本次编辑（保留放置时已应用的值）；输入框属 ADR-0002 §6 作用域放行（快捷键不抢键）。
- 手势仲裁：BPM 数字**单击**=进编辑（stopPropagation）；左沟槽**双击**=临时起点标记（ADR-0004）不变，两者不冲突。
- 适用面：后续任何对象参数（滑条结点缓动、长条数值微调等）一律复用此模式——**参数挂在对象上、就地改、无模态打断**，不再发明第二种输入打断。

## 6. 拖拽移动已放置音符（新增能力）

- 入口：**仅指针态**。按下点决定语义：音符上按下拖拽 = **移动**，空白按下拖拽 = **框选**；其他持工具态下拖拽一律 = 框选（防误拖）。
- 吸附：beat 栅格 × lane 整格（与放置同规则）；多选音符整体拖 = 组移动（复用 `shiftGroupToAnchor`）；非法落点 = 回弹。
- 滑条：端点拖动 = 延伸/收缩（补 issue 07 遗留的端点扩展交互）；中间结点拖动 = 改形状。
- hidden 结点 / SP 曲线拖拽：本票只定"结点是可拖的一等对象"，交互细节归 09+56 联动（"像画画一样画谱面"是既定方向）。

## 7. 退出与 Esc 四档链

Esc 依序消费（先到先吃，只吃一档）：**① 弹窗自消费关闭（现状，capture 层）→ ② 取消 Slide 临时端点锚 → ③ 清空选区 → ④ 持工具态落回指针**。

- **侧栏折叠从 Esc 摘除**（原第三环，见 `Editor.tsx` onEscape 链）：进 ADR-0002 注册表成可自定义功能，默认 **`Ctrl+B`**，语义 = 左右两侧面板**折叠/展开 toggle**（顺带修复现状"Esc 只能折不能开"的缺陷）。
