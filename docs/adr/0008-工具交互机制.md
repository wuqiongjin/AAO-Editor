# ADR-0008: 工具交互机制（持工具态 × 选区）

- **状态**：Accepted（定案于 grill-with-docs，2026-09-07，issue 55）
- **背景**：原工具交互把"选着什么"和"拿着什么"焊在一根 `selectedTool` 轴上，圈选被硬编码锁在鼠标/镜像两态、编辑动作与放置工具语义含混、BPM 用 `prompt()` 打断输入、已放置音符无法拖拽移动。经三轮 grill 定案重构。
- **修订关系**：**取代** ADR-0002 §3（交互模型）并重定义 §2.1 中 BPM/滑条执行键语义（键位目录与配置机制仍归 ADR-0002）；**修订** ADR-0001 §2（横向禁令范围限定为两击直放路径）。
- **变更触发**：任何工具切换/点击/框选/执行键/退出行为与本文冲突时，须先更新本文并经用户确认。

> 实现载体 = issue 55。§4 组合规则表与 §2/§3 语义矩阵**必须逐行落单测锁表**（用户明确要求：规则表"明确地"落到文档和代码，未来变动走本票流程）。

---

## 1. 状态模型：两轴

- **工具轴 —— 持工具态（armedTool）**：单轴互斥，**所有**工具共驻一根轴（键型放置 / BPM / Slide / 编辑动作 / 指针）。指针态 = armedTool 为空，是默认底态。换工具 = 换手里拿的东西，**不需要经鼠标工具中转**——"放置与编辑都是工具、混在一根轴没有问题"是定案前提。
- **对象轴 —— 选区（selection）**：点选/框选/Shift 加选建立的音符（含滑条子部分，ADR-0001 §6）集合。**常驻、与持工具态解耦**：手持滑键工具的同时，选区依然存在。
- **执行（exec）**：**不是态**，是执行键的瞬时动作——无论当前持有什么工具，在谱面光标位置立即执行对应功能；该位置非法则**无事发生**、不留状态。

> **名词裁决**："选中/选中态"一词**永远只指音符进入选区**；工具被激活称"持工具态"。grill 会话中用户口径的"选中态/执行态"→ 即本节的 持工具态 / 执行键。

## 2. 统一交互原则

1. **按下移动 ≥4px = 拖拽；<4px 快速起按 = 单击**（阈值沿用现实现）。
2. **任何持工具态下都可框选**——废除 `mouse || mirror` 硬编码门控。
3. **所有工具一律驻留**，无一次性特例：放置类放完继续放，动作类执行完工具不丢。退出只有三出口：**按 Esc / 点击当前高亮的工具按钮 / 切换到其他工具（点按钮或按切换键）**。
4. **批量应用后选区保留**（便于连续操作、再移位）。例外：**组合类**（框选组合/Ctrl+E 组合）完成后清空选区——来源已被消耗，属一次性动作（§4，三轮修订）。
5. 框选拖拽期间的预览复用幽灵体系（issue 13 / ADR-0002 §4 精神）。

**单击语义矩阵**（按工具族）：

| 工具族 | 点击音符 | 点击空白 |
| --- | --- | --- |
| 指针（R） | 选中该目标（替换选区；Shift 加选；Ctrl 选整条滑条，ADR-0001 §6.1） | 清空选区 |
| 键型放置（F/G/A/S/D） | 在栅格位放置，走 ADR-0001 §1 覆盖/替换规则 | 放置 |
| BPM（`） | 放置（同拍已有 BPM 按覆盖处理） | 放置 → 进入 §5 就地编辑 |
| Slide（E） | 第一次点击=放**临时端点**，第二次合法点击=成条（现状两击保留） | 同左 |
| 删除/镜像（T/Q） | 选中该音符并立即执行（Model A 保留，ADR-0002 §3.2） | 无效果（不清选区；清选区用 Esc 或指针态点空白） |
| 粘贴（V，持工具态） | 在点击位置粘贴（锚点语义见 §2.1）；**粘贴后驻留** → 可连续粘贴 | 同左 |
| 复制/剪切（Ctrl+C / Ctrl+X） | **不占工具轴**（见 §2.1）——只在有选区时由执行键触发，无工具态 | 不占工具轴 |

**框选语义矩阵**：

| 工具族 | 拖拽框选并松开后 |
| --- | --- |
| 指针 | 建立选区（现状） |
| 键型放置 | 框内音符**逐个应用 ADR-0001 替换规则**（可替换的换型、不可替换的跳过——如滑键框选含单键/滑条中间结点时按表各自处置） |
| BPM | 无效果 |
| Slide | **组合成滑条**（§4 表；键音符 + 完整覆盖的滑条皆为吸入来源） |
| 删除 | 对整个选区执行该动作（含 §6.2 拆条语义） |
| 镜像 | 拖拽期间预览镜像结果（含滑条连接区域，ADR-0002 §4），松开**立即执行**（无需二次确认） |
| 粘贴 | 无效果（粘贴作用于位置；持工具态保留） |
| 复制 / 剪切 | 不占工具轴（框选后走 `Ctrl+C` / `Ctrl+X` 执行键） |

### 2.1 粘贴语义（2026-09-08 六轮定案）

- **锚点 = 剪贴板组的包围盒左上角（min beat × min lane）对齐到光标**（维持既有实现）。理由：
  - 组形状与相对位移 100% 保留（纯平移，复制一段楼梯再粘到别处不变形）；
  - **保证没有任何音符落在光标的左侧/上方**——内容自光标起向右下铺开，与"放置"的直觉一致；
  - 备选方案「锚音符 = 排序最前的**实际**音符」（光标格必现音符）在常见选区下与本方案等价，仅在「最左音符不在最前拍」时才不同，而此时它会让内容溢出到光标左上侧，反而更不可预期。
  - 「不可预期」的剩余部分由**实时预览**消除：持工具态下悬停即显示整组幽灵落点（所见即所得）。
- **BPM / System 不参与锚点计算**：它们没有 lane，参与 min 会污染组的左上角；只按最终 beat 位移平移。
- **越界钳制**：组按光标 lane 对齐后右缘越出轨道 → 整体左移至恰好放下，**保持组宽不变**。
- **光标（鼠标）不在画布 = 非法位置 → 无事发生**（§1）；`Ctrl+V` 此时无效，工具栏按钮只是进/出持工具态，不受影响。
- **持工具态转正**：Toolbar「粘贴」= arm/释放（与删除/镜像同构、与 `V` 归位，Esc / 再点 / 切工具退出）；悬停 = 整组幽灵预览；单击 = 在该位置粘贴并**驻留**（连续粘贴）；粘贴产物 = 新选区（便于紧接着移动/删除）。执行键 `Ctrl+V` 保留（光标处即时粘贴，不占工具态）。
  - **空剪贴板 = 不可进态**（六轮追加）：粘贴是唯一"前提缺失即完全空转"的工具——无剪贴板时单击无事发生、**悬停预览也为空**（删除/镜像无选区时点中音符仍立即生效，键型/BPM/Slide 是放置、永远有产物）。故：Toolbar 按钮置灰并在 tooltip 说明"剪贴板为空，先 Ctrl+C 复制"，**`V` 键同步不进态**（键鼠一致，避免上轮 #6 的"界面无、键盘有"错位）。复制后按钮与键同时可用。
  - 判据只含剪贴板、**不含光标**：光标不在画布只是"落点非法 → 无事发生"（§1），不应阻止进态（旧实现把两者混为一谈，鼠标移到工具栏上按钮就灰掉）。
- **复制 / 剪切不占工具轴**（不 arm）：二者**必须有选区**才有意义（作用于对象而非位置），剪贴板只有一份、连续复制无意义，连续剪切还有误删风险。只保留 `Ctrl+C` / `Ctrl+X` 作用于选区；键盘 `switchCopy` / `switchCut` 随之从工具轴摘除。

## 3. 执行键语义（修订 ADR-0002 §2.1 注释）

| 执行键 | 语义 |
| --- | --- |
| Ctrl+F/G/A/S/D | 光标处立即放置该类型（光标在已有音符上 = 按 ADR-0001 替换，等价单击放置）；光标不在画布则忽略 |
| Ctrl+` | 光标处放置 BPM 线（默认值按 §5）→ 进入就地编辑 |
| **Ctrl+E** | **有选区** → 选区按 §4 组合成滑条（组合来源 <2 则无事发生）；**无选区** → 放临时端点，与鼠标两击**共用同一 slideBuffer**（"点一下画布 + 再按一次 Ctrl+E"亦可成条） |
| Ctrl+C/X/T/Q | 作用于**当前选区**（C/X 无工具态，见 §2.1） |
| Ctrl+V | 当前光标位置粘贴；**光标不在画布 = 无事发生**（§2.1） |

> 原"复制/剪切等需回鼠标工具框选再执行"的流程（ADR-0002 §3.2 取舍条款）**作废**：任何持工具态下可直接框选（§2 原则 2），执行键与框选批量应用殊途同归。

## 4. Slide 放置 = 两击直放 + 框选组合（混合制）

两条路径并存，**组合为主力**（结点落在已放置音符位上，且能做出直放做不了的形态）：

- **两击直放**（保留现状）：快速在空位起条；**ADR-0001 §2"禁止横向"仅约束此路径**。
- **框选组合**（新）：Slide 工具态框选（或"已有选区 + Ctrl+E"）→ 音符按 **beat+subBeat 升序、同拍按 lane 升序** 排成结点序列（N≥2 即成条）。组合**与 ADR-0001 §1.2 覆盖/替换规则无关**——框内任何键型一律吸入。同拍横向段在此路径合法（zigzag 样例 `1.5l1→1.5l5→2l1→2l5` 即由此排序重现）。

**形态归一表**（被吸音符 → 滑条结点；音符本体被**消耗**=删除，标记按下表转移；此表为独立规则，未来变动改本表）：

| 被吸音符 | 起始端点 | 中间结点 | 末尾端点 |
| --- | --- | --- | --- |
| 单键 | 普通端点 | 中间结点 | 普通端点 |
| 滑键 flick | **降为普通端点**（剥标记；与 ADR-0001 §5"滑键不可作起点"一致） | 统一化中间结点（剥标记） | 保留 `flick` |
| 技能键 skill | 保留 `skill` | 统一化中间结点（剥标记） | 保留 `skill` |
| 方向键 | 普通端点 | 统一化中间结点 | 普通端点 |

- **接合**：组合产生的端点若与**既有滑条端点重合**，仍走 ADR-0001 §3 滑条-滑条组合（合并）规则。
- **滑条吸入（2026-09-07 三轮修订、2026-09-08 四/五轮修订 = **触碰即整条入链**）**——框选组合的来源不限于键型音符：
  - **任一结点入框（`slideNode`）或整条选中（`kind:'note'`）即整条入链、本体消耗**，**不再区分完整/部分覆盖，也不再拆条**（五轮修订：组合 = 往滑条里并东西，不是切东西；要掐断请用方向键放置 / 删除结点）。三轮的「宿主未覆盖段拆条保留」条款**作废**（它会把 `A→B` 的 `B` 拆成孤立音符，与"向滑条中间插结点"的意图相反）。
  - **排序 = K 路保序归并**：每个被触碰滑条的结点序列是一整块（**块内保原顺序**，不重排宿主形状，如同拍回折段），键音符各为单例块，块间按上表排序规则取最小头。典型：`A→B` + 框 `A` 与中间的新音符 → `A→新音符→B`。全部单例块时退化为纯排序（与既有锁表一致）。
  - 被吸入的结点从宿主移除，**位置不重复**（ADR-0001 位置排他）。
  - 排序后**同位置结点重合**（一条的尾 = 另一条的头）→ 合并为单结点，接合处按两击路径同语义标记 `hidden:false`（可见接合点）；flick/skill 先 OR 汇集、再按归一表按位剥除。
  - **来源计数**：可组合判据 = 「**来源对象 ≥2**」（吸入键音符数 + 被触碰滑条数，触碰 = 至少 1 结点入框/整条选中）；单条滑条多结点入框不成链（来源=1，无事发生）。样例：`A→B`、`C→D` 两独立滑条，**只框 B、C** → 两宿主端点各在链端点 → 级联接合成 `A→B→C→D`（四轮修订；三轮的「成链 `B→C` + `A`/`D` 退化」作废）。
  - **结果 type**：任一被吸入/消耗滑条为 `Long` → 结果 `Long`，否则 `Slide`。
  - **组合是一次性动作**：执行完毕**清空选区**（来源已消耗、无可保留对象；结果滑条不自动进入选中态，也就无选中描边）。原则 4 的「批量后选区保留」不适用于组合。
  - **两击路径同规则**：单击接合（buffer 尾 + 点另一条头）经 `mergeChainWithSlides` **级联**合并两侧既有滑条（`A→B` + 两击 `B→C` + `C→D` → 一步成 `A→B→C→D`，2026-09-07 三轮修复：旧实现只并一侧即返回）。**点击次序无关**（四轮修复）：两点按 beat→subBeat→lane 升序归一为链 `[起, 止]`，先点后拍 `C` 再点前拍 `B` 与 `B`→`C` 完全等价（旧实现因 `||` 与 `<=` 优先级写错，beat 差非 0 时恒按点击顺序取链，`C→B` 两侧都不接合）。合并结果**写回首条被消耗滑条的原下标**（SlideExtendRepro 锁瓦片失效锚定）。
- **SP 绿条预留（issue 09）**：结点来源机制 = 框选组合（N 结点已天然支持）；过渡结点缓动参数 = 挂在结点上按 §5 就地编辑模式输入；结点拖拽整形 = §6 预留的"结点一等可拖对象"。09 自身只拍范围/格式字段/缓动算法，不再设计交互。

## 5. 工具内参数 = 对象就地编辑（取代 `prompt()`）

- BPM 流程：放置 BPM 线 → 数值 = **首次用现默认值，此后沿用上一次放置所设的值** → 放置动作未结束：左侧沟槽的 BPM 数字自动进入编辑态（光标置于数字内并闪烁）→ **Enter 应用**；用户随时可再次编辑该数字，**无需切回 BPM 工具**。
- 编辑中 Esc = 取消本次编辑（保留放置时已应用的值）；输入框属 ADR-0002 §6 作用域放行（快捷键不抢键）。
- 手势仲裁：BPM 数字**单击**=进编辑（stopPropagation）；左沟槽**双击**=临时起点标记（ADR-0004）不变，两者不冲突。
- **命中区 = 数字自身的文字盒**（2026-09-08 修订）：只认 `bpmLabelBox`（右缘 = 内带锚点、宽 = 等宽估算 + 容差、纵向骑线居中并沿用顶/底钳制），**不再把数字所在的整条水平线都判成命中**——否则该高度上左沟槽的双击永远被判为"数字命中"、起点标记手势放不下去。沟槽宽度不足、绘制时整体隐藏的数字同样不可命中。
- 适用面：后续任何对象参数（滑条结点缓动、长条数值微调等）一律复用此模式——**参数挂在对象上、就地改、无模态打断**，不再发明第二种输入打断。

## 6. 拖拽移动已放置音符（新增能力）

- 入口：指针态按下音符拖拽 = **移动**；**任意持工具态下 Shift+按住音符 = 移动**（三轮修订，用户验收反馈 #4：原「仅指针态」难发现且与放置态操作流冲突）。未达移动阈值即松开 = 取消拖拽、回落到该态原本的单击语义。空白按下拖拽 = 框选；非 Shift 的其他持工具态拖拽一律 = 框选（防误拖）。
- 反馈：拖拽进行中鼠标光标 = `grabbing`。
- 吸附：beat 栅格 × lane 整格（与放置同规则）；多选音符整体拖 = 组移动（复用 `shiftGroupToAnchor`）；非法落点 = 回弹。
- 滑条：端点拖动 = 延伸/收缩（补 issue 07 遗留的端点扩展交互）；中间结点拖动 = 改形状。
- **落点碰撞不一律回弹**（2026-09-08 四轮修订）——按 ADR-0001 既有规则裁决，规则一律复用既有实现，不新造：

  | 拖拽件 \ 落点既有 | 键音符 | 滑条端点 | 滑条中间结点 |
  | --- | --- | --- | --- |
  | 键音符 | **§1.1 替换**：目标被拖拽件消耗（方向键 `length` 取拖拽件原值、不叠加——移动 ≠ 重复放置） | 回弹 | 回弹 |
  | 滑条端点 | **覆盖删除**（与放置/粘贴的 `removeOverlappedNotes` 同语义） | **§3 接合**：异条两端点并为一条链（可级联；共享点降 `hidden:false`，任一为 `Long` 则结果 `Long`） | 回弹 |
  | 滑条中间结点 | 回弹 | 回弹 | 回弹 |

  - 判定次序：先做越界/邻居序校验 → 再按上表裁决落点 → 全部可裁决才提交；任一件不可裁决 = 整个拖拽回弹。
  - 拖拽件之间**不自覆盖、不互接合**（同一位置被两件认领 = 回弹）；§1.2（flick/skill/拆条）属**放置**语义，键音符拖到滑条结点不处置、直接回弹。
  - 合并结果写回**被拖滑条**所在下标，其余被消耗滑条移除；选区条目按新下标重映射（覆盖/接合会增删元素，故幽灵预览由 `planDragMove.ghost` 显式给出，不再由新旧数组逐位比对）。
- hidden 结点 / SP 曲线拖拽：本票只定"结点是可拖的一等对象"，交互细节归 09+56 联动（"像画画一样画谱面"是既定方向）。

## 7. 退出与 Esc 四档链

Esc 依序消费（先到先吃，只吃一档）：**① 弹窗自消费关闭（现状，capture 层）→ ② 取消 Slide 临时端点锚 → ③ 清空选区 → ④ 持工具态落回指针**。

- **侧栏折叠从 Esc 摘除**（原第三环，见 `Editor.tsx` onEscape 链）：进 ADR-0002 注册表成可自定义功能，默认 **`Ctrl+B`**，语义 = 左右两侧面板**折叠/展开 toggle**（顺带修复现状"Esc 只能折不能开"的缺陷）。
