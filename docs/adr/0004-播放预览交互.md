# ADR-0004: 播放预览交互（判定线模型）

- **状态**：Accepted（定案于 grill-with-docs，2026-08-09）
- **背景**：[ticket 14](../../.scratch/basic-editor/issues/14-音频播放与预览线实现.md) 按 ticket 03 架构实现了"**静止谱面 + 移动预览线**"的首版播放：音频时间线在画布上随时间下移一条线，谱面不动。用户实测后判定此模型不符合制谱需求——期望的是音游标准的"**判定线固定 + 谱面随播放上移**"；并进一步提出"无音频也要能播谱面""临时起点回跳""官方键音素材接入"等诉求。经多轮对齐（Q1–Q14）定案，**取代 14 的第一版交互模型**。
- **结论**：见本文件全文。涉及"播放/预览/键音/播放条"的行为若与本文件冲突，须先更新本文件并经用户确认。
- **变更触发**：本 ADR 是 ticket 03/14 架构的**交互模型修订**，并把"预览线"概念替换为"判定线"；实现交由新 ticket（issue 17）载体执行，先文档后代码。

# 播放预览交互

## 1. 播放视觉模型（Q1 定案）

- **判定线模型**：播放（含暂停停住态）时，画布**底部一条固定横线 = 判定线**，代表"此刻"；谱面随音频时间沿判定线**向上滚动**（下落式），滚动条跟随播放头。
- **判定线锚定**：判定线固定于画布底部（即默认初始视口把 beat 0 放在底部的一侧，天然一致）；播放头 beat 依 BPM 事件换算秒→beat→虚拟 Y，逐帧驱动 `scrollY = beatToVirtualY(t) - 判定线画布偏移/scale`。
- **取消"移动线"**：移除首版"静态谱面+移动线"的预览线绘制；判定线常显（停/播同线）。
- **暂停/停住态滚动 = 设播放起点【修订 2026-08-09】**：暂停或停住时，用户拖动滚动条到某位置 = 把播放头 seek 到该处（更新 start 位置与时间码），**不自动播放**——因为暂停时滚动可能是"浏览查看"，不应触发播放。再次按 空格 即从该处开播。
- **播放中完全锁定滚动【修订 2026-08-09】**：播放中滚动条**禁用**、画布滚轮**禁用**（仅允许 Ctrl+滚轮缩放），播放头独占滚动；播放头是唯一滚动来源，**不反向回写滚动条事件**（消除"播放头↔滚动条"双向反馈导致的滚动自锁/抖动，见 issue 17 Bug1）。
- **播放结束**：播放到 音频/时长 终点**自动停住**并停在当前位置（不自动回卷、不自动循环）；再次按 空格 从头播、按 Ctrl+空格 跳回临时起点（§5）。

## 2. 时间轴（Q2 定案）

- **有音频**：`AudioContext` 时间线（既有 AudioEngine）。
- **无音频**：**合成时间线**——`performance.now` + RAF 驱动同一引擎（`getSeconds` 双时钟）；播放/暂停/seek/起点跳转行为与有音频完全同构。→ 有了合成时间线，无音频（含"跳过"模式）谱面照常"播放"。

## 3. 播放时长（Q3/Q4 定案）

时长优先级（只有无音频时才需要"算"；有音频即音频自身长度）：

1. **谱面末端**：所有音符（含滑条结点）最大 beat 经 BPM 事件换算为秒 + **1 小节尾部余量**【实现确认 2026-08-09：按 4/4 拍，尾部加 4 拍时长，经当前 BPM 换算，非固定秒数】；
2. **空谱兜底**：可编辑默认 30 秒（Q3 裁定：默认最长 30s）；
3. **可调**：无音频时播放条"时长"可直接改（仅本次会话，不写入谱面）。

**虚拟高度随谱面长度动态自适应【修订 2026-08-09】**：画布虚拟高度不再固定为 `220px × 360拍`，而按**谱面末端 beat（最大音符 beat + 尾量）**换算的像素高度动态设定 → 滚动条长度随实际谱面长度变化，播到谱面末端即到底、无多余空白区（issue 17 Bug3）。网格线只渲染到谱面末端对应的虚拟范围。

## 4. 起点标记与回跳（Q5/Q9/Q10 定案）

弃"循环区间"构想，改"**临时起点标记 + 一键回跳**"：

- **放置**：双击 画布左侧沟槽（轨道外、画布内）空白处 → 把鼠标 Y 对应 beat 记为**临时起点标记**，在该 beat 画一条标记线。
- **回跳**：按 **Ctrl+空格**（新增 FunctionId，见 §6）→ 播放头跳回标记 beat 并**自动播放**（播放中=跳转续播，暂停=从该点开播）。
- **删除**：双击标记线，或 鼠标工具左键选中标记后走 Delete/删除按钮（标记选中态与音符选择互斥）。
- **临时性**：标记属"临时组件"、**不入谱面数据**，随会话丢弃。
- **单一标记【确认 2026-08-09】**：全谱只有**一个**临时起点标记；在新位置双击放置新标记时，旧标记自动消失（不叠加）。
- **状态归属【实现确认 2026-08-09】**:标记 beat 与选中态放在 `FinalVirtualCanvas` 内部，经 ref 暴露 set/get/delete API；`Editor` 只负责 Ctrl+空格 触发回跳（与既有 `setScrollY` ref 模式一致）。
- 明确**不做自动循环**：播放到终点即停住，直到再次空格/Ctrl+空格（Q10）。

## 5. 播放条（Q12 定案）

底部一条播放条（约 32px），承载全部播放类控件：

- 播放/暂停、时间码、无音频时的"时长"编辑、音量、（未来）素材切换、起点标记提示。
- 顶栏保留"加载音频/BPM/节拍切换/快捷键设置"，不混入播放控件（ADR-0003 §2 的"加载音频=顶栏按钮"职责不变）。

## 6. 快捷键扩展（ADR-0002 追加）

- 新功能 **"回到起点标记"**（FunctionId 建议 `jumpToMarker`，类别 `播放`），默认绑定 `ctrl+空格`，纳入 ADR-0002 的单键配置/冲突检测/设置面板体系。
- 现有 `play`（空格）不变。

## 7. 键音素材（Q6/Q11/Q14 定案）

- **素材包 KeySoundSet**：`{ tap, flick, skill, slide }` 四类采样（按**击打样式**分类，**不做 per-lane 音高**）。
- **占位实现**：内置默认占位音（现有振荡器保留为"占位素材"），暴露统一的键音素材接口/注册表，未来替换为真实 WAV 采样（文件读入依赖 ticket 04 文件 IPC）。
- **切换与持久化**：播放条上可切换素材包；**当前激活素材持久化到 settings JSON**（ADR-0003 Settings 扩展 `audio.keySet`），打开软件沿用上次选择（Q14 裁定），默认"占位"。
- **settings 范围【实现确认 2026-08-09】**:本期新增轻量 settings 模块（localStorage `bangdream.settings.v1`）**仅存 `audio.keySet`**；ADR-0003 完整 settings（theme/layout/shortcuts 合并）后续再做，本期隔离不返工。
- 滑条**中间结点**沿用逐结点发声。

## 8. 布局 tab 化方向（Q13 定的方向，本 ADR 不实现）

用户指出当前配置项（节拍/缩放/组合/状态/播放）平铺散乱。**方向**：右侧面板 tab（音符/谱面/设置）、左侧只留工具 tab（编辑/状态）、播放类全部收敛进底部播放条、节拍/缩放等"配置"项归入面板 tab。**实现交由 ADR-0003 的正式 layout 改造**（不拆开）。
