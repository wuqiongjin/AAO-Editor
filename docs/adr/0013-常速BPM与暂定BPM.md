# ADR-0013: 常速 BPM 与暂定 BPM

- **状态**：Accepted（定案于 grill-with-docs，2026-09-23；依据票 02、04）
- **背景**：原先期待 BPM 自动识别写出一段音频里变速发生的位置。固定程序能给出的是一个正的常速，常常外加一组拍点秒；可靠的「变速发生在哪一秒、每段各是多少」做不到。倒流是作者轴上的事，音频里没有负 BPM。
- **结论**
  1. **BPM 自动识别是固定程序，不是模型。** 对圈定的一段音频给出一个正的常速 BPM。可以与范围之前那条相同。不写出变速位置，不写负数，不制造倒流区。
  2. **智能制谱不在生成时把这个数写成 BPM 线。** 它是范围内开头那条暂定 BPM 的初值。暂定 BPM 全部为正。开头一条可改数值，不可删；这段拍距不退回范围之前的 BPM。
  3. **接受前，提案音符和暂定 BPM 都在播放时钟的秒上。** 接受时才折成作者轴上的 beat 并写入。这次写入叫接受，不叫应用。
  4. **范围起点落在倒流区，或范围内会折进负 BPM 时，禁止这次智能制谱。** 接受之后是否插入负 BPM、做不做折返，由用户手摆。
  5. **识别器单独暴露给用户时，不用智能制谱的接受。** 从哪里启动、写在哪一拍、写之前看不看一眼，见票 06，本决定不定。
- **曾考虑**
  - 继续要求写出变速位置：固定程序填不上。要保住那条期待，就得把「不是模型」改掉。这一版不改。
  - 生成时直接落成谱面里的 BPM 音符：提案在接受前还不是谱面代码，秒上的暂定 BPM 可以改、可以删（开头那条除外）。
  - 用范围之前的 BPM 当这段的拍距，或在倒流区里制谱：拍距会借到区外或负值上。负 BPM 留着手摆。
