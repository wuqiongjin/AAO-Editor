# ADR-0012: 起音时刻与智能制谱第一刀

- **状态**：Accepted（定案于 grill-with-docs，2026-09-23）
- **背景**：辅助采音和智能制谱都要回答「落在播放时钟的哪一秒」。采音标记不是音符。AI 提案在接受前，音符也停在秒上；接受时才按暂定 BPM 折成作者轴上的 beat。
- **结论**
  1. **采音标记标的是起音。** 检出时，一次起音一处标记，时刻是播放时钟上的秒（可带小数）。用户可以增删；增上的标记可以不是检测器给出的起音。标记不进谱面代码，不读谱面状态，里面没有 beat。
  2. **对着标记做谱 = 普通放置。** 音符仍按当前细分网格吸附。标记不挪到网格上，也不变成音符。
  3. **复用采音标记默认开。** 选定范围内已有标记且开着时，提案音符的秒取这些标记，含手改。关掉，或范围内没有标记时，制谱自行从音频取起音，并且不把这些起音画成采音标记。用户不必先做辅助采音。对外不表现为先采音再制谱。
  4. **第一刀：每个这样的秒各成一颗提案单键。** 不删、不吸附到拍网格。疏密以后再谈；接受时的秒→beat 是坐标换算，不是吸附。
  5. **轨道由模型给出。** 起音和采音标记都没有 `lane`。把单键铺到固定轨道，不算第一刀完成。具体哪一种选轨模型，本决定不选；选定之前智能制谱不算落地。
- **曾考虑**
  - 标记表示「值得写进谱的击打」：标记就不再是起音。
  - 端到端一次给出秒和轨道、产品里不单独定秒：第一刀要能单独验收秒。
  - 制谱永不读标记，或必须先采音才能制谱：改成默认复用已有标记；没有标记时内部自算。
  - 第一刀用放置模型删起音，或先吸附拍网格：密度未做；吸附会改掉起音实际发生的秒。
  - 用 EASY / NORMAL / HARD / EXPERT 给采音分档：不采用。采音密度（百分比）未定，先不实现。
  - 单独做「标记变成音符」：不做。
  - 第一刀全放在中间轨：不算完成。
- **未定**：选轨模型的具体做法；采音密度留下哪些起音。
