# ADR-0005: 显式谱面长度与谱面工程持久化

- **状态**：Accepted（定案于 grill-with-docs，2026-08-11）
- **背景**：用户实测发现三个关联 bug——9「放置音符到最后 1 拍之后会自动伸展谱面长度，导致与歌曲时长不匹配」、10「加载音乐后谱面长度没有音乐长（因未放音符）」、11「无音频时谱面只有几拍长，期望默认 30s」。三者根因相同：**当前谱面长度是一阶导出量**（`computeChartEndBeat` = 最大音符 beat + 1 拍尾量，空谱兜底 8 拍），画布高度/网格/滚动范围/播放宽都跟着音符走。经多轮对齐（Q1–Q16），把谱面长度改为**显式、秒域、与音符解耦的第一性属性**，并引入**谱面工程**持久化单元。**本次仅定案设计，不实现。**
- **结论**：见本文件全文。
- **变更触发**：任何与谱面长度/谱面工程/音频持久化相关的行为与本文件冲突时，须先更新本文件并经用户确认。
- **关联**：修正并取代 [ADR-0004 §3 谱面末端模型](./0004-播放预览交互.md) 中"谱面末端 = 最大音符 beat + 1 拍尾量"的由音符推算语义；与 [ADR-0003 §6 配置系统](./0003-工作台UI与配置系统.md)（统一读写接口封装思想）配套；实现载体 = issue `23` 及后续 issue。

# 显式谱面长度与谱面工程持久化

## 1. 谱面长度（Q1 定案）

- **谱面长度是显式、第一性、与音符无关的属性**，以**秒**为单位（贴合音乐时间）。
- 它驱动：画布虚拟高度、网格渲染范围、滚动条范围、播放时长。
- **放置音符永不改变谱面长度**（修复 bug 9/10/11）。
- 规范术语：**谱面长度 Chart length**，取代 CONTEXT.md 中"谱面末端 Chart tail（由音符推算）"的语义。

## 2. 谱面工程（Q2/Q6 定案）

- 规范术语：**谱面工程 Chart project** = { 谱面代码(Json) + **谱面时长** + 音频引用/数据 }。
- **谱面时长不入 Json**（Json 面板/谱面代码格式无时长字段），是谱面工程的显式字段。
- 谱面信息（代码、音频、谱面时长）**按谱面工程隔离、持久化**，重开软件/网页需恢复，后期支持多谱面切换时**信息不丢失**。

## 3. 本期范围（Q5 定案）

- 本期只做：3 个 bug 的谱面长度模型 **+** 当前**单份**谱面工程的持久化（重开恢复）。
- **多谱面列表/切换**为独立产品能力，留后续单独 grill（登记 issue `26` 跟踪）。

## 4. 谱面长度 与 音频时长 的同步（Q3/Q10 定案）

- **有音频**：加载后**谱面时长 := 音频时长**（覆盖持久化值，锁定为音乐时间）。
- **无音频**：用**持久化的谱面时长**，默认 30s。
- **PlayBar 的"时长"编辑 → 改的就是谱面时长字段，并持久化**（不再是会话级临时值，废弃 `durationEditedRef` 的会话级语义）。
- **无音频导入谱面代码（§4.5）**：应用谱面代码后，若代码最后音符的结束时间（`maxNoteEndSeconds`，含滑条结点、不含尾量）**超过当前谱面长度**，则谱面长度自动延长到该结束时间（单据放置仍禁止自动伸展，见 §5；导入是批量载入，谱面应容纳所载内容）。

## 5. 超出谱面长度的放置（Q4 定案）

- 在**谱面长度之外放置音符 = 禁止**（超出谱面末端的放置不放音，需先手动加长谱面再放）。
- 要放置更长内容，先手动调节谱面时长来增加谱面长度。

## 6. 存储与持久化（Q7/Q8/Q9/Q13/Q15 定案）

- **音频**：IndexedDB 存 **Blob**（跨会话重载，浏览器/Electron 均可靠）。
- **存储后端**：本期用 **IndexedDB**（浏览器可用、无 5MB 限制、可存 Blob）；接口抽象化，未来 Electron 可换 `userData` 文件后端（**登记 issue `25` 跟踪该改造**）。
- **存储结构**：IndexedDB 设计为 **`谱面工程 id → 工程记录` 的键值表**（本期 UI 只操作一份，也带 id），未来多谱面只是加条目 + 加列表 UI，**不改存储结构**。
- **写入时机**：编辑**即自动保存**（防抖，如停顿 ~800ms 或切工具/切页时写入），无手动保存按钮；音频在加载时即写入，不随编辑重写。
- **与 settings 边界**：谱面工程（IndexedDB）= 代码 + 时长 + 音频 Blob（每工程专属）；settings（localStorage `bangdream.settings.v1`）= 用户偏好（主题/布局/快捷键/音量/素材包），跨谱面共享，**不含任何谱面数据**。

## 7. 画布与换算（Q11/Q12/Q14/Q16 定案）

- **取消 +1 拍尾量**：画布长度 = 谱面长度（秒）经 BPM 换算到拍，精确到终点，无多余空白区（ADR-0004 §3 的"由音符+尾量推算留白"废弃）。
- **谱面时长以秒锚定**；**拍**只是一层显示换算（`secondsToBeat(BPM时间线, 秒)`）。推论：谱面内加/改 BPM 事件只改变"这段秒数对应多少拍"（网格/播放范围随之伸缩），**不改变谱面长度本身**。
- 【2026-09-14 修订，折入 [ADR-0010](./0010-负数BPM与倒流区.md)】含**倒流区**（负 BPM）的谱面里，「秒 → 拍」是**多值**，上面这条"拍只是一层显示换算"不再无条件成立：**画布高度仍由谱面长度（秒）直接得出，不经过拍反查**；「秒 → 拍」只用于拍号显示与放置基准，且须显式指定取哪一解。
- **打开画布定位到谱面开头（beat 0）**，判定线落在起始处；修正当前 `initialScrollDone→ bottom` 的滚动到底逻辑。
- **谱面长度不设硬上限**；性能风险由既有的密集音符优化（issue 10）兜底。
