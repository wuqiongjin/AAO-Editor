# ADR-0001: 音符覆盖与滑条规则

- **状态**：Accepted（定案于 grill-with-docs，2026-08-08）
- **背景**：现有规则存在 5 处与预期不符——滑条可横向放置 / 滑条端点与滑键方向键关系不明确 / 方向键与滑条多节点无法 Ctrl+Z 逐步回退 / 技能键未序列化。经与用户逐轮对齐确定以下规则。
- **结论**：见本文件全文（第 1~6 节）。
- **变更触发**：任何覆盖/滑条行为与本文冲突时，须先更新本文并经用户确认。
- **2026-09-07 修订（[ADR-0008](./0008-工具交互机制.md) §4）**：§2"禁止横向"范围限定为**两击直放路径**；新增第二条放置路径"框选组合"（形态归一表与排序规则见 ADR-0008 §4，组合**与 §1.2 替换规则无关**、同拍横向段在组合路径合法）；§3 滑条-滑条接合对组合路径仍适用。

# 音符覆盖与滑条规则

> 实现时逐条与 [NoteReplacementRules.ts](../../src/utils/NoteReplacementRules.ts)、[FinalVirtualCanvas.tsx](../../src/components/FinalVirtualCanvas.tsx)、[Editor.tsx](../../src/pages/Editor.tsx)、[ChartConverter.ts](../../src/utils/ChartConverter.ts) 对应（见文末【实现映射】）。

## 1. 覆盖（Overwrite）

放置音符到已有音符/结点所在位置时的处理。覆盖分"普通音符互相覆盖"与"滑条结点行为"两类。

### 1.1 普通音符互相覆盖

- 放置到**空位** → 新增该音符。
- 放置到同位置已有**普通音符**（单键/滑键/技能键/方向键）→ **覆盖替换**为新音符：
  - 方向键放置在**同类型**方向键上 → `length + 1`；`length` 已达 `3` → 重置为 `1`。
  - 方向键放置在**不同类型**（或单键/滑键/技能键）上 → 替换为方向键（`length=1`）。
  - 单键/滑键/技能键相互覆盖 → 替换为相应类型（保留各自 `flick`/`skill` 标记）。

### 1.2 滑条结点行为

滑条结点分**端点**（头 `e0` / 尾 `eN`）与**中间节点**（`m1..m_{N-1}`）。下表"端点"列行为对称适用于头/尾，除非特别标注。

| 放置内容 | 中间节点 | 端点（头/尾对称，除非标注） |
| --- | --- | --- |
| **单键** | **忽略**（无法放置） | **覆盖替换**：清空该端点的 `flick` / `skill`（退化为普通端点），端点**保留在滑条上** |
| **滑键** | **忽略**（无法放置） | 仅**尾部**端点可覆盖：改 `flick:true`（并清掉 `skill`）；放**头部**端点无效果（§5：起点不携带 `flick`） |
| **技能键** | **忽略**（无法放置） | **不拆条**；给**点击的端点**改 `skill:true`（并清掉 `flick`），不联动另一端 |
| **方向键** | 该节点变**独立方向键**，并**拆条**（见 1.2.1） | **拆条**（见 1.2.2） |

> 注（issue 81 定案 2026-09-10）：端点上的 `flick` / `skill` 是**覆盖替换**关系 —— 后放的键型胜出、
> 清掉另一个标记，与 §1.1「普通音符互相覆盖」同口径。旧口径「只加不清、可并存」会让端点画成
> 「技能键底图 + 滑键箭头」的叠加样式，且带标记的端点**无法被单键覆盖**。
> - **中间结点不适用**（一律忽略）；
> - 标记**无变化**（如端点已是同一键型）视为**无操作** —— 不写历史快照；
> - 二者仍均需独立序列化（见 §5）。

#### 1.2.1 中间节点 + 方向键 → 拆条

该中间节点变为**独立方向键**（保留原位置），滑条在该节点两侧**拆成两条**：

- 左段：`[原起点 .. 该节点前一中间节点]`（若无则左段不存在）。
- 右段：`[该节点后一中间节点 .. 原终点]`（若无则右段不存在）。
- 若某一侧**仅剩 1 个结点**（无相邻滑条结点），则该结点**不消失**，按其自身标记退化为独立音符：`skill` → 技能键、`flick` → 滑键、无标记 → 普通单键。

#### 1.2.2 端点 + 方向键 → 拆条

该方向键成为**独立音符**（保留原位置）；滑条**去掉该端点**，相邻中间节点**升级为新端点**：

- 若滑条仅有 2 结点（无中间节点）→ 该滑条删除；被覆盖端点成为独立方向键，**另一端按其自身标记退化为独立音符**：`skill` → 技能键 `Single{skill:true}`、`flick` → 滑键 `Single{flick:true}`、无标记 → 普通单键 `Single`。

## 2. 滑条放置

> 2026-09-07（ADR-0008 §4）：本节仅约束**两击直放路径**；框选组合路径（选中音符串成滑条，含同拍横向段）见 ADR-0008 §4。

- **禁止横向放置（仅两击直放）**：同 `beat`（含 `subBeat` 相同）的两点**不可**连成滑条 → 忽略该次放置并清空缓冲（可提示"滑条不允许横向放置"）。
- **自动连接滑条**：两点击创建滑条，按 `beat`（再按 `subBeat`）升序排列结点。
- **滑条 - 滑条组合**：新滑条与既有滑条端点相接时合并（见第 3 节）。

## 3. 滑条 - 滑条 组合（Combine）

新滑条 `[S, E]`（起点 S、终点 E）与既有滑条端点相接：

- **S = 既有滑条终点** → 合并：E 追加到既有滑条终点之后，原终点转中间节点。
- **E = 既有滑条起点** → 合并：新起点并入既有滑条起点之前。
- 其余情况 → **不组合**，S/E 两端各自独立成新滑条（除非触发 1.2 的拆条/忽略）。

## 4. 撤销 / 重做（历史）

- **每次编辑操作 = 一个可回退快照**；历史快照必须**深拷贝**，禁止浅拷贝导致对象就地变异泄漏到多份快照。
- 以下变更**均可逐步** Ctrl+Z / Ctrl+Y 回退：覆盖替换、方向键 `length` 变化（1→2→3→1）、滑条端点变更/拆条/组合、增删移动。
- 规则实现不得就地变异 `notes` 中的音符对象（必须复制后再改），否则破坏本节。

---

## 5. 序列化

- 谱面代码需序列化 `flick`（滑键）与 `skill`（技能键）标记。
- **技能键可作滑条起点**：滑条起点端点可携带 `skill:true`；**滑键不可作滑条起点**（起点端点不携带 `flick`，由 1.2 节保证）。
- 覆盖/拆条等规则的结果必须真实反映到导出的谱面代码。

## 6. 滑条子部分选择与编辑（独立 feature，已定案 2026-08-08）

Slide 分为**区域（连接带）/ 端点 / 中间结点**三种可独立选中与编辑的子部分。选择以**选择条目（SelectionItem）**为单位：

```ts
type SelectionItem =
  | { kind: 'note';         noteIndex: number }                    // 整条音符（含 Ctrl+左键选中的整条滑条）
  | { kind: 'slideRegion';  noteIndex: number; connIndex: number } // 滑条"段/区域"：connIndex ↔ connIndex+1 两结点间的连接带
  | { kind: 'slideNode';    noteIndex: number; connIndex: number } // 滑条端点或中间结点
```

### 6.1 选择（Selection）

- **普通左键**：按命中部分选子部分（区域 / 端点 / 中间结点）；点空白清空。
- **Ctrl+左键**：直接选中**整条滑条**（`{kind:'note'}`），并**替换该滑条自身的子部分选择**。
- **Shift**：加选。
- **同一条滑条内，整条选择与子部分选择互斥**（选整条即清掉该滑条的子部分）。
- **矩形框选**：按命中子部分选中（框到区域→选区域；框到结点→选结点）。

### 6.2 删除（Delete）

- **右键** = 选中命中目标 + 删除，对**所有音符**生效（不只滑条）。
- **Delete / Ctrl+D** = 删除当前选中的（子部分或整条）。
- 滑条内：
  - 删**区域** → **拆滑条**：在该区域处把滑条拆成两段，区域两端结点**保留**并成为两段的新端点；任一侧仅剩 1 个结点时，该结点按其标记退化为独立音符（skill→技能键、flick→滑键、无→单键）。
  - 删**端点** → 移除端点（若滑条仅 2 结点，另一端按其标记退化为独立音符）。
  - 删**中间结点** → 仅移除该结点，其余结点保持连接（**不拆条**）。
  - **hidden 结点（issue 80 定案）**：hidden 对"段"透明（段 = 两端可见结点之间、可跨过 hidden）。
    - 删**区域**且该段**内含 hidden** → **只清掉段内的 hidden**，段本身保留、两端可见结点直连
      （反复点即逐步清空：先清隐藏、再断带子）。例：`A—H—B` 删该段 → `A—B`；`A—H1—H2—B` → `A—B`。
    - 删**端点** → 端点 + 与之相连的**整条线段一起删除**（含线段上的所有 hidden），
      另一端点按其标记退化为独立音符。例：`A—H—B` 删 A → `B` 退化为独立结点。
    - 任何产物都不得出现「首/尾结点为 hidden」（§1.2），实现侧负责收口。

> 拆滑条示例：滑条 `E(端点)—A(中间)—B(中间)—F(端点)`，删除区域 R1（A–B 之间的连接带）→ 拆为 `[E—A]` 与 `[B—F]` 两条滑条（A、B 保留为新端点）。删除端点区域 R0（E–A）→ `[E]` 退化为独立音符，`[A—B—F]` 保留为一条滑条。若任一侧仅剩单结点，一律按其标记退化。

### 6.3 复制 / 剪切 / 粘贴 / 镜像

复制 / 剪切在**复制时刻**将选中的子部分**物质化**为 `ChartNote[]` 存入剪贴板：

- 单个结点 → 独立音符（`skill`→技能键、`flick`→滑键、无标记→普通单键）。
- 区域（2 结点）或 >1 个结点 → 含这些结点的**连续连接区域段**（跳过中间结点也取连续段）。
- 整条音符（`{kind:'note'}`）→ 该音符本身。

| 操作 | 行为 |
| --- | --- |
| **剪切** | = **复制该区域 + 删除该区域**，与"删除"对区域的语义统一（拆滑条） |
| **粘贴** | 作为独立实体放入（复用 `shiftGroupToAnchor`），**不尝试重新连接** |
| **镜像** | 只翻转该子部分的 lane（结点→该结点；区域→两端点），不联动滑条其它结点 |

普通音符（单键/滑键/技能键/方向键）的复制/剪切/粘贴/镜像行为不变。
