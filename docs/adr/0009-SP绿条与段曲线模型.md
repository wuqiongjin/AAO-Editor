# ADR-0009: SP 绿条与段曲线模型（参数随行、点集唯一真相）

- **状态**：Accepted（定案于 grill-with-docs，2026-09-12，issue 09 三轮）
- **背景**：Bestdori 权威口径（制谱器 bundle + 5 份官方 SP 谱实测 + Sonolus bandori 引擎）：谱面代码 Slide connections 只有 `{beat, lane, hidden?, flick?, skill?}`（lane 允许小数），**没有缓动字段**——缓动是 Bestdori 曲线工具生成时**烘焙**成密集 `hidden:true` 采样点的（10 族 × 4 型，采样精度档位）；游戏内 SP 绿条无专属换色/材质，`longNoteLine2` = 同一绿色的无缝变体（Sonolus `NoteConnectionGreenSeamless`）。issue 09（SP 绿条，用户愿景"像画画一样画谱"）据此定模型。
- **修订关系**：**修订** ADR-0008 §2 原则 2（曲线工具态框选例外）、§4 SP 绿条预留行（本文落定）、§6 末条（hidden 不可独立拖 + slideRegion 可拖 = 拉弓变形）；与 ADR-0001 §6 hidden 口径（含 issue 92 删结点转 hidden）兼容并用，不改动其条文。
- **变更触发**：三来源语义、一动就自由化边界、烘焙规则未来变动须先更新本文并经用户确认。
- **范围切片**（issue 09，全纳入）：S1 材质接线 → S2 缓动生成 + 曲线工具 → S3 拖带弯曲 → S4 形状模板。负数 BPM 拆 issue 100，不属本模型。

---

## 1. 数据模型：参数随行，hidden 采样点是唯一真相

- **段（span）= 相邻可见结点之间的滑条子部分**，可含若干 hidden 过渡结点（与 ADR-0001 §6 / issue 93 口径同一段概念）。
- **段参数挂段上、随谱面工程保存**（缓动配置或曲线形态；谱面工程 JSON 可含此内部扩展信息）。选择"参数随行"而非"纯烘焙"（Bestdori 同构）的理由：模板、拖带再整形、就地编辑换缓动都依赖参数可再编辑；导出产物两种方案完全相同。
- **hidden 采样点是渲染、命中、导出的唯一真相**：渲染层完全不解释参数（逐段直线 quad 拉伸，密集采样自然成曲线——与 Bestdori 播放器 / Sonolus 同构，不引入贝塞尔渲染实体）。参数只服务"重新生成"。
- **一致性规则（简单清除）**：任何对段内结点集合的手工改动（issue 92 删结点转 hidden、issue 80 删段清 hidden、拆条、组合、粘贴改形……）→ 该段参数**清除**，退化为普通点集段。不做参数与点集的双向同步。
- **导出 = 必然烘焙**：段参数 → hidden 采样点，只写标准字段 `{beat, lane, hidden}`；内部参数字段**不导出**（Bestdori 导入会 sanitize 剥未知字段）。烘焙产物与 Bestdori 曲线工具产物同构 → **Bestdori 可直接导入游玩**。
- **导入 = 自由点集段**：Bestdori 谱导入后视觉 100% 恢复、既有 hidden 编辑全兼容；无解析参数（"原本是什么缓动"信息不在数据里）。**导入拟合不做**（易误判、收益小；自由点集已可拖带整形、可重新应用生成器覆盖），留作未来增强。

## 2. 段曲线三来源

段参数三形态，**互斥、可相互切换**（切换 = 按新来源重采样该段）：

1. **缓动（easing）**：10 族 `Sine / Quad / Cubic / Quart / Quint / Expo / Circ / Back / Elastic / Bounce` × 4 型 `In / Out / In-Out / Out-In` = **40 种全量**（对齐 Bestdori，官方谱曲线可精确重现）；**采样精度三档：每拍 1/16、1/32、1/64**（Bestdori curvePrecision 口径）。生成语义 = 段两端可见结点之间按拍差细分，逐采样点 `{beat, lane: 起点lane + lane差×f(进度), hidden: true}`，lane 钳制 0..6 允许小数。
2. **自由点集（free）**：任意 hidden 点集（画笔轨迹 / 导入 / 拨弯产物）。受数据模型硬边界：**beat 严格递增（时间单向）、lane 完全自由**（可来回摆：爱心、波浪、zigzag 皆可表达；"往下回头画"任何引擎不可表达）。
3. **模板（template）**：归一化相对形状库，套用时映射到起终点。内置预设（爱心/S 形/波浪/震动条 + 40 种缓动弧线本身也是预设）+ 用户对现有段"存为模板"。与 issue 58 划界不变：本票模板 = **单条滑条的相对形状**（一次放置），58 = 一组音符的快照；资产格式本票自定。

## 3. 放置：曲线工具（新持工具态工具）

- **单击链式**（Bestdori 同款）：首击 = 头端点，每击接一段；每段按当前缓动配置**出生即烘焙** hidden 采样点 → 直接得到 SP 绿条，**不需要**"放普通 Slide + 删中间结点"两段式。
- **拖动画笔**（超出 Bestdori 的增量）：曲线工具态下**空白按下拖动 = 沿轨迹实时采样**成自由段（起终点可见、途中密集 hidden），松手成条。这是"像画画"的本体。
- 配置 UI（族/型/精度/模板）挂曲线工具激活态，**默认沿用上次值**（ADR-0008 §5 先例）；放置后可对段**就地编辑参数即时重生成**（ADR-0008 §5 模式，无模态打断）。
- **框选例外（修订 ADR-0008 §2 原则 2）**：曲线工具态空白拖动被画笔占用；**Shift+拖 = 框选**保留（该态下框选作用仍为滑条组合），"任意态可框选"以最小代价保住。
- 普通直线绿条仍走滑条工具（两击直放 / 框选组合），曲线工具不取代它。Linear 不在 40 族内——直线 = 滑条工具的产物，两工具分野与 Bestdori 一致。

## 4. 整形：拖带弯曲（拉弓变形）与"一动就自由化"

- **`slideRegion` 可拖（修订 ADR-0008 §6）**：指针态拖段 = **拉弓变形**——两端可见结点锚定不动，段内 hidden 点按到两端的投影权重跟随拖拽位移（位移场，非贝塞尔控制点）。选位移场而非控制点的理由：画笔/导入的复杂形状一拖即被单弧压扁（破坏性），位移场无损且手感最接近"拨动绿条"。
- **拨弯即转化**：普通段（无 hidden 点）被拖带 = 自动在段内补 hidden 采样点 + 弯曲 → 就地转化为自由段（"普通绿条 → SP 绿条"的第四条创造路径）。
- **一动就自由化**：任何段被拖带弯曲 → 段参数清除、转自由段；要回解析缓动 = 对段重新应用生成器（覆盖）。
- **拖端点 ≠ 改形**：指针态拖端点（延伸/改形）= 移动意图——解析段按新端点**重新烘焙**（参数保留）；自由段点集**相对形态保持**、整体拉伸重映射。hidden 点不散架是硬要求。
- **镜像**：解析段 In↔Out 型翻转（真镜像），自由段点集 lane 翻转天然真镜像。
- **Long 与 Slide 数据/渲染同构，SP 段能力同款适用**，不做特判。
- hidden 结点本身**不可**作为独立对象选中/悬停/拖动（issue 56 Q36=D，ADR-0008 §6 原"结点一等可拖对象"预留作废）——谱师通过**拖带**间接生成与操纵它们。

## 5. 材质：段级判定（修订接线 `bandSp`）

段内任一结点 `hidden` → **该段**用 `longNoteLine2`（SP 无缝变体）渲染；皮肤包缺失该素材回退 `longNoteLine`。选段级而非整条级：与渲染真相（hidden 是段属性）、Sonolus `CurvedSlideConnector` 口径一致，混合条（直段+曲段）里直段保持普通材质更可读。

## 6. 被否决的备选（防复活）

- **纯烘焙（Bestdori 完全同构、参数不保存）**：再编辑只能重画，与模板/拖带/换缓动愿景冲突 → 否决。
- **渲染层解释参数（贝塞尔/样条实时成面）**：渲染层大改、导入谱（无参数）无法统一、且与"点集唯一真相"冲突 → 否决。
- **导入拟合恢复缓动参数**：易误判（Back/Elastic 与手工点集难区分）、复杂度高收益小 → 本期否决。
- **贝塞尔控制点拖带**：对复杂点集破坏性 → 否决（见 §4）。
- **曲线工具吞并直线放置 / 或不新增工具**：直线归滑条工具、曲线独立成工具，与 Bestdori 分野一致、矩阵加行成本最低 → 定案。

## 7. 实现约束（S1-S4 逐条核销）

- 密集 hidden 渲染走既有瓦片缓存（`noteLayerCache`；1/64 × 长条 = 数百段 quad，必要时段合并绘制）；缩放手势期渐进重建沿用 issue 96 先例。
- 一次放置/画笔/拖带/重新应用 = **一个 undo 步**。
- hidden 不计数（issue 84 口径）、无判定、不参与 `findItemAt`/`computeItemsInBox`（Q36=D）。
- 画笔采样需强制 beat 单调；生成点 beat 落在 1/精度 栅格（subBeat 承载细分）。
- 缓动库 = 纯函数表（族 × 型），与 Bestdori bundle 逐函数对齐并单测锁表。
