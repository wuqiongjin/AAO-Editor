## 1. 数据模型：参数随行，hidden 采样点是唯一真相

- **段（span）= 相邻可见结点之间的滑条子部分**，可含若干 hidden 过渡结点（与 ADR-0001 §6 / issue 93 口径同一段概念）。
- **段参数挂段上、随谱面工程保存**（缓动配置或曲线形态；谱面工程 JSON 可含此内部扩展信息）。选择"参数随行"而非"纯烘焙"（Bestdori 同构）的理由：模板、拖带再整形、就地编辑换缓动都依赖参数可再编辑；导出产物两种方案完全相同。
- **hidden 采样点是渲染、命中、导出的唯一真相**：渲染层完全不解释参数（逐段直线 quad 拉伸，密集采样自然成曲线——与 Bestdori 播放器 / Sonolus 同构，不引入贝塞尔渲染实体）。参数只服务"重新生成"。
- **一致性规则（简单清除）**：任何对段内结点集合的手工改动（issue 92 删结点转 hidden、issue 80 删段清 hidden、拆条、组合、粘贴改形……）→ 该段参数**清除**，退化为普通点集段。不做参数与点集的双向同步。
- **由段参数生成的 Bestdori 产物 = 必然烘焙**：段参数 → hidden 采样点，只写标准字段 `{beat, lane, hidden}`；内部参数字段**不导出**。这条只约束编辑器内部生成的曲线参数，不再覆盖用户谱面代码源数据的保真导出；源数据的字段生命周期与另存为规则改由 [ADR-0014](./0014-宽松谱面代码源数据与画布投影.md) 统一定义。烘焙产物与 Bestdori 曲线工具产物同构 → **Bestdori 可直接导入游玩**。
- **导入 = 自由点集段**：Bestdori 谱导入后视觉 100% 恢复、既有 hidden 编辑全兼容；无解析参数（"原本是什么缓动"信息不在数据里）。**导入拟合不做**（易误判、收益小；自由点集已可拖带整形、可重新应用生成器覆盖），留作未来增强。

## 2. 段曲线三来源

段参数三形态，**互斥、可相互切换**（切换 = 按新来源重采样该段）：

1. **缓动（easing）**：10 族 `Sine / Quad / Cubic / Quart / Quint / Expo / Circ / Back / Elastic / Bounce` × 4 型 `In / Out / In-Out / Out-In` = **40 种全量**（对齐 Bestdori，官方谱曲线可精确重现）；**采样精度三档：每拍 1/16、1/32、1/64**（Bestdori curvePrecision 口径）。生成语义 = 段两端可见结点之间按拍差细分，逐采样点 `{beat, lane: 起点lane + lane差×f(进度), hidden: true}`，lane 钳制 0..6 允许小数。
2. **自由点集（free）**：任意 hidden 点集（画笔轨迹 / 导入 / 拨弯产物）。段内**首尾按数组序**（画笔倒画落子时整串反转为升序）；**段内中间点的 beat 必须单调**——**【2026-09-14 八轮废止 / 2026-09-15 九轮更正机理（issue 106 定案）】**原「可倒退」条不成立——但**实机口径不是「忽略」中间结点**，而是「**按 beat 稳定排序 + 掐掉首尾 hidden**」后**按时间轴铺带**：带子**永不回头**，非单调点序只表现为**横向折线**（排序后落到首/尾之外的结点被裁掉，图1 看起来像「被忽略」；仓内 11 份样本 ≈1943 条 Slide/Long 非单调点序 0 例）。故：① 画笔**禁止回头**（回头不追加、也不改变产出，见 §7），折返一律由**倒流区**（负 BPM）产生，见 [ADR-0010](./0010-负数BPM与倒流区.md)；② 外部进来的非单调点序**代码原样保留、画布按实机口径投影显示**（见下条）。**布局折返仍需回折健壮**（见 §5）。lane 完全自由（爱心、波浪、zigzag 皆可表达——靠倒流区折返而非点序回折）。
   **非单调点序口径（2026-09-15 九轮 + 十轮校正，issue 106 定案，用户拍板）**：非单调点序**代码原样保留**（代码弹窗 / 导出 / 往返全保真，不凭空产生 diff），只有**画布**按实机口径显示——**显示投影** `displayConnections(connections)` = **两步：按 beat 稳定排序 + 掐掉首尾 hidden**（= 实机 `repair()`；**同拍组（`beat` 全等）一律保持数组序**——作者点序即带体走序，不可从代码重建（issue 115））（唯一入口、纯函数；实绘 / 选中·hover 描边 / 命中 / 幽灵 / 瓦片缓存 / 今后的完整谱面预览与播放模拟都从它取点，与 `slideBandGeometry` 同族「唯一定义处」）。数据层、段与参数、拖带权重、删结点、`planDragMove`、导出仍按数组序——排序只改「怎么连」，不改点位置。可见结点不足时按实机口径：**1 个 → 按单键形态显示**（数据仍是滑条，可选中可删；保留 `flick`/`skill`）、**0 个 → 数据原样保留、画布无任何效果**（实机也只是显示不出来、不会从代码里删掉；改由谱面状态图标告知）；相应地**不再整份拒收** `connections.length < 2` 与首 / 尾 hidden。谱面状态图标（三态 + 计数明细）、常驻报错区搬迁、以及把同一套口径**写回数据**的「规范化」动作**同在 issue 107**；文案**不出现第三方站名**。
3. **模板（template）**：归一化相对形状库，套用时映射到起终点。内置预设（爱心/S 形/波浪/震动条 + 40 种缓动弧线本身也是预设）+ 用户对现有段"存为模板"。与 issue 58 划界不变：本票模板 = **单条滑条的相对形状**（一次放置），58 = 一组音符的快照；资产格式本票自定。
   **点列即采样，密度固定（2026-09-17 定案，用户拍板，见 §6）**：模板的**点列就是采样点**（内置预设点数写死：大弧 12 / S 形 16 / 心形 16 / 波浪 24 / 震动条 25），**与段长无关、与 `precision` 无关**。因为形状是**归一化相对形状**，无论套到 0.5 拍还是 8 拍的段上，描述的是同一个形状，改变的只是"相邻采样点之间隔多少拍"。
   ⇒ **`precision` 只服务缓动与画笔**（`SpanCurve` 的 `ceil(diff × precision)` 与画笔步长 `1 / precision`），**不作用于模板**；曲线配置面板上"选了模板 → 采样精度置灰"是**正确行为**（改了也不生效），不是缺陷。
   **已接受代价**：平滑类模板（大弧 / S 形）套到长段、或在高缩放下，会显出折线棱角（采样点少 + 段在画布上被拉长）。接受——模板 = 固定预设，不满意的出路是**另建一个自定义模板**，而不是给模板加一个密度旋钮。

## 3. 放置：曲线工具（新持工具态工具）

- **单击链式**（Bestdori 同款）：首击 = 头端点，每击接一段；每段按当前缓动配置**出生即烘焙** hidden 采样点 → 直接得到 SP 绿条，**不需要**"放普通 Slide + 删中间结点"两段式。
  **（2026-09-13 修订：链式续段取消**——两击 = 一条滑条，落子即清草稿；下一击永远是新锚点，可直接重叠放置。多段形态走画笔/模板。原"每击接一段"被用户判定为过度设计：放置后光标跟随预览带常驻、误触即续段，且挡住重叠放置。）
- **拖动画笔**（超出 Bestdori 的增量）：曲线工具态下**空白按下拖动 = 沿轨迹实时采样**成自由段（起终点可见、途中密集 hidden），松手成条。这是"像画画"的本体。**（2026-09-13 修订：支持倒画**——从高拍向低拍绘制合法，落子时采样反转为升序段（形态不变、端点互换）；方向在第一次落采样时锁定，中途回头仍不可表达（不追加）。倒画仍受数据模型 beat 单调硬约束，只是把"方向选择"交给谱师。）
- 配置 UI（族/型/精度/模板）挂曲线工具激活态，**默认沿用上次值**（ADR-0008 §5 先例）。
  **【2026-09-16 修订（issue 114 定案，用户拍板）】**「沿用上次值」的持久化层级定死：配置写入 **`settings.curve`（全局一份、跨会话沿用）**，**不随谱面工程走**——它是"我的习惯"而非谱面属性（工程级记忆待 issue 26 多谱面工作区落地后再议）。四项（族/型/精度/模板）**全记**，含 `templateId`。画笔圆滑（`CurveConfig.smooth`）**删除**（只作用画笔自由段、默认关，且平滑窗口 σ≈1.7 **采样** ⇒ 拍域力度随 `precision` 漂移 4 倍，不满足所见即所得）；默认缓动型由 `In-Out` 改为 **`In`**；采样精度**保持三档** 1/16、1/32、1/64（不加档——它同时是画笔采样步长，加档直接翻倍点数与谱面体积）。放置后可对段**就地编辑参数即时重生成**（ADR-0008 §5 模式，无模态打断）。
- **框选例外（修订 ADR-0008 §2 原则 2）**：曲线工具态空白拖动被画笔占用；**Shift+拖 = 框选**保留（该态下框选作用仍为滑条组合 + 刷当前缓动）。**命中 ∈ 选区的单击**走同一行（issue 137 / ADR-0008 issue 88），按下不启画笔。
- 普通直线绿条仍走滑条工具（两击直放 / 框选组合），曲线工具不取代它。Linear 不在 40 族内——直线 = 滑条工具的产物，两工具分野与 Bestdori 一致。

## 4. 整形：拖带捏形（峰值在抓取点）与"一动就自由化"

- **`slideRegion` 可拖（修订 ADR-0008 §6）**：指针态拖段 = **捏形**——两端可见结点锚定不动，段内 hidden 点按**以抓取点为峰值的分段线性权重**跟随拖拽位移（位移场，非贝塞尔控制点）。选位移场而非控制点的理由：画笔/导入的复杂形状一拖即被单弧压扁（破坏性），位移场无损且手感最接近"拨动绿条"。
  **【2026-09-16 修订（issue 108 定案，用户拍板）】** 位移场由"拉弓变形"（峰值恒在段中点）改为：
  - **抓取点 = 按下瞬间**画布几何最近的**段内**采样点（段内无可见结点，故即 hidden 采样点），**按下即锁定**（整个拖拽期间峰值位置不变），随 `DragAnchor.rawPressBeat` 同款快照；
  - 权重 = **分段线性**：`t ≤ t_grab` 时 `w = t/t_grab`，`t > t_grab` 时 `w = (1−t)/(1−t_grab)`；两端 `w=0`（锚定不变）、`w(t_grab)=1`、`t` 按**拍**归一化（与旧 `bowWeight` 同源）。**抓段中点时与旧 `bowWeight` 逐点相同** —— 拉弓 = 峰值钉在中点的特例，能力零损失，故**取代**拉弓而非并存（无新增模式/修饰键，守 ADR-0008 §2 例外最小化）；
  - **beat 不动**（与拉弓同）：106 已定产不出非单调点序，纵向移动会让数据点与显示投影分叉；
  - **不跨段**（段 = 变形单元）、lane 仍 `clamp(0,6)`、**"一动就自由化"照旧**；
  - 被否决备选：局部半径衰减核（需新增半径参数）、只移动最近的那一个采样点（密集采样下出硬尖角）、与拉弓并存、允许纵向移动、抓取点每帧随光标更新（结果依赖路径、不可逆）。
- **拨弯即转化**：普通段（无 hidden 点）被拖带 = 自动在段内补 hidden 采样点（精度 **1/16**，不变）+ **同一位移场**捏形 → 就地转化为自由段（"普通绿条 → SP 绿条"的第四条创造路径）。
- **一动就自由化**：任何段被拖带弯曲 → 段参数清除、转自由段；要回解析缓动 = 对段重新应用生成器（覆盖）。
- **拖端点 ≠ 改形**：指针态拖端点（延伸/改形）= 移动意图——解析段按新端点**重新烘焙**（参数保留）；自由段点集**相对形态保持**、整体拉伸重映射。hidden 点不散架是硬要求。
- **镜像**：解析段 In↔Out 型翻转（真镜像），自由段点集 lane 翻转天然真镜像。
- **Long 与 Slide 数据/渲染同构，SP 段能力同款适用**，不做特判。
- hidden 结点本身**不可**作为独立对象选中/悬停/拖动（issue 56 Q36=D，ADR-0008 §6 原"结点一等可拖对象"预留作废）——谱师通过**拖带**间接生成与操纵它们。

## 5. 材质：段级判定（修订接线 `bandSp`）

段内任一结点 `hidden` → **该段**用 `longNoteLine2`（SP 无缝变体）渲染；皮肤包缺失该素材回退 `longNoteLine`。选段级而非整条级：与渲染真相（hidden 是段属性）、Sonolus `CurvedSlideConnector` 口径一致，混合条（直段+曲段）里直段保持普通材质更可读。

**横截面口径与实绘形态（六轮定案，材质之外的另一半"怎么画"）**：

- **口径 = 车道横向**，唯一定义处 `src/visual/slideBandGeometry.ts`（`bandRails` / `bandPolygon` / `bandPolygonAt` / `splitBandAtFolds`）。带体轮廓、选中·hover 描边（`collectSelectionOutlines`）、命中区（`hitTest` 的 `slideRegion` 平行四边形）**必须共用它**——三侧任一侧另写一份几何就会分叉（四轮-五轮正是把实绘单独改成垂直法线，才产生端点衔接台阶 + "亮的轮廓与画的带子不是一个形状"）。与 `noteMetrics`（渲染/命中尺寸同源）同一教训。
- **端点衔接**：封口过结点中心且水平，宽 = `LANE_WIDTH` < 端点图标墨迹宽 `SLIDE_ICON_SIZE` → 封口恒被图标盖住，带子看起来"穿进端点里"。**跨段衔接**：相邻逻辑段在共享可见结点上产生同一条封口线 → 天然连续，无需任何法线共享。
- **实绘形态**：SP 段（含 hidden）= 程序化分层条带（剖面与体色从带贴图运行时采样，单层一条连续路径，非零环绕留内孔）；普通单 region 段 = 同一平行四边形上的**剪切贴图**（贴图 X→世界横向、贴图 Y→段向，无需 clip）。中心线 = hidden 采样折线**原样**（七轮起不再有渲染期细分平滑）。
- **回折自叠（七轮，依据八轮改写）**：`slideBandGeometry.splitBandAtFolds` 按画布 dy 变号把中心线切成单调 run，`renderSpBandStrip` 逐 run 独立分层填充。**触发条件已改写**（八轮）：不再是"段内点序回折"（该形态实机不存在；这类点序我们不再按数组序画折返，而是按实机口径投影显示，见 §2.2），而是**倒流区造成的布局折返**——点序按 beat 单调、但布局 y 非单调（[ADR-0010](./0010-负数BPM与倒流区.md)）。动因不变：单路径"外环 + 反向内孔"在两臂自叠处环绕数相消 → 非零填充判成洞 → 重叠区一条黑线（用户图1）。拆 run 后 run 内不自叠、抵消不可能发生；跨臂重叠 = 两次 source-over → **叠亮**（与物理叠加一致。**注：该口径未经用户确认**——曾就此提问、回答被取消，按默认落地；若要求重叠处不加亮，需改为逐 run 归一 alpha 或单路径偶奇填充）。描边/命中不拆（描边自叠只是线交叉、无害；命中逐子 quad）。

## 6. 被否决的备选（防复活）

- **纯烘焙（Bestdori 完全同构、参数不保存）**：再编辑只能重画，与模板/拖带/换缓动愿景冲突 → 否决。
- **渲染层解释参数（贝塞尔/样条实时成面）**：渲染层大改、导入谱（无参数）无法统一、且与"点集唯一真相"冲突 → 否决。
- **导入拟合恢复缓动参数**：易误判（Back/Elastic 与手工点集难区分）、复杂度高收益小 → 本期否决。
- **贝塞尔控制点拖带**：对复杂点集破坏性 → 否决（见 §4）。
- **曲线工具吞并直线放置 / 或不新增工具**：直线归滑条工具、曲线独立成工具，与 Bestdori 分野一致、矩阵加行成本最低 → 定案。
- **带体保持法向等宽（垂直法线横截面，四轮-五轮实现）**：代价是"实绘自有一套几何"——端点封口转成斜线（纵向伸出 `half·cosθ` > 端点图标墨迹半高 → 戳出图标 + 楔形背景缺口），跨段还要额外发明角平分线共享法线补台阶，而选中/hover 轮廓与命中区仍是车道横向 ⇒ 同一条带子三种形状。用户以选中轮廓为预期口径否决 → 六轮改回车道横向（等宽性让位于"所见 = 所点 = 所亮"）。
- **保留垂直口径只把端点封口 mitre 成水平线**：封口交点横向伸出量 `half/tanθ`，θ=30° 时 ≈ 26 > 图标半宽 18 → 平缓端绿色横向戳出图标 → 否决。
- **模板按 `precision` 重采样（2026-09-17 复核否决）**：曾提议把模板点数改成 `n = clamp(ceil(段拍数 × precision), …)`，与缓动段同构，顺带解除面板上"选模板 → 精度置灰"。**否决理由 = 语义**：模板是**固定预设**——它的点列就是这个形状本身，密度是形状的一部分（震动条要 25 点才成立，大弧 12 点足够）；给预设加一个用户可调的密度旋钮，等于把一个"选一个形状"的动作变成"调两个参数"。**未来用户自定义模板同样固定死**（存的就是点列），不满意再多建一个模板即可。附带省掉三件事：点数上下限要另定、既有模板段重生成会产生谱面 diff、精度下拉的 disabled 逻辑要回改。已知代价见 §2.3（平滑模板在长段/高缩放下显棱角），**接受**。

## 7. 实现约束（S1-S4 逐条核销）

- 密集 hidden 渲染走既有瓦片缓存（`noteLayerCache`；1/64 × 长条 = 数百段 quad，必要时段合并绘制）；缩放手势期渐进重建沿用 issue 96 先例。
- **带体几何单一真相**：新增/修改连接带的任何画法（实绘、幽灵、live 预览、描边、命中）只能经 `slideBandGeometry` 取横截面，禁止就地再写一份偏移或法线（`tests/unit/visual/render/SlideBandGeometry.test.ts` 会失败）。
- 一次放置/画笔/拖带/重新应用 = **一个 undo 步**。
- hidden 不计数（issue 84 口径）、无判定、不参与 `findItemAt`/`computeItemsInBox`（Q36=D）。
- **画笔禁止回头（九轮改写，issue 106 定案）** = ①采样：**回头不追加**（绘制笔迹折返期间 samples 为空）；②产出：**回头不改变产出**——落子终点取「松手吸附拍位」与「锁定方向上最远采样点」中**沿锁定方向更远者**（`pen.last` 不再跟随光标，「从折返点续采」废止）；③预览：回头期间冻结在最远点、**不画折返**，预览与落子逐点一致；**不做回撤**（用户 2026-09-15 判定「行为怪、吃力不讨好」）。**"段内中段 beat 可回折"已废止**（§2.2）——采样序列 beat **恒单调**；折返只能由倒流区造成（[ADR-0010](./0010-负数BPM与倒流区.md)），画笔跨过折返带时**直接接续、不补中间点**（issue 106 修法 6）。单调性强制点：段首尾数组序（倒画落子整串反转）、画笔采样序列、烘焙/模板参数生成的等距采样、**显示投影（带子取点单一口径）**。
- **重烘焙后必须重映射下标**（七轮）：拖端点 → `reprojectSpanParams` 按新跨度增删 hidden → 可见结点**序数**不变、**下标**平移。落点裁决（`planDragMove` ③）与选区回写（④）一律经 `connIdxRemap`（原下标 → 新下标）换算后再索引；直接拿旧 `connIndex` 索引新数组 = 跨度变短时 undefined 崩溃（拖不动）、变长时裁决错点。
- **绘制起手清选区**（七轮，用户拍板）：画笔起笔、曲线工具首击挂锚点、单击放置（矩阵 clearSel）= 开始做新内容 → 旧选区即刻清空；链式草稿是独立状态，不受选区影响。
- 缓动库 = 纯函数表（族 × 型），与 Bestdori bundle 逐函数对齐并单测锁表。
