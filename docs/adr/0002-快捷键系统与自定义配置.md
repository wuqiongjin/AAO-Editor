# ADR-0002: 快捷键系统与自定义配置

- **状态**：Accepted（定案于 grill-with-docs，2026-08-08）
- **背景**：编辑器快捷键此前硬编码在 `Editor.tsx` 的 window keydown 监听里，无法自定义、且与"工具态 + 执行键"的交互模型不匹配。经多轮与用户对齐，确定统一的快捷键系统：每个**具体功能**绑定**恰好一个键**（一键不多功能、一功能一键），支持用户自定义并持久化。
- **结论**：见本文件全文（第 1~6 节）。
- **变更触发**：任何快捷键/工具态/预览行为与本文冲突时，须先更新本文并经用户确认。
- **2026-08-08 改版（Q2/Q3/Q6 定案）**：① 由「一动作多键 `string[]`」改为「按**具体功能**单键」，即「切换-单键」「执行-单键」为两个独立功能、各绑 1 键；② 新增 **BPM / 滑条 / 播放** 动作；③ 预览幽灵改为**真实图标**（放置 length=1，粘贴/镜像保留原样）；④ 工具提示（tooltip）动态读配置、按类别合并「切换/执行」。
- **2026-09-07 修订（[ADR-0008](./0008-工具交互机制.md)，issue 55）**：§3 交互模型整节由 ADR-0008 **取代**（持工具态×选区、任意态框选、全工具驻留）；§2.1 BPM/滑条执行键注释重写；新增功能「侧栏折叠/展开」，默认 `Ctrl+B`。**键位目录、一键一功能、配置持久化、作用域（§1/§2/§5/§6）仍以本票为权威。**
- **2026-09-09 修订（issue 59 §2）**：新增「音符代码」（切换 `B` / 执行 `Ctrl+B`）；`Ctrl+B` 由「侧栏折叠/展开」让出 → 该功能的默认键改 **`Ctrl+Shift+B`**（下文 §2.2 与本文件其余处提到 `Ctrl+B` 的旧表述均已作废）。
- **2026-09-09 修订（issue 65①③④）**：§4 预览表补「滑条工具态 · 悬停（未挂锚点 / 已挂锚点）」两档，并写明**滑条幽灵的结点选款 = 画布实绘同款**（端点端帽款 / 中间 among 款）——此前 `renderSlideGhost` 对所有结点一律取端点款，违反本节"幽灵 = 真实图标同形"的既有不变式。

> 本 ADR 与 `CONTEXT.md` 术语为**权威来源**，纳入版本控制。`docs/plans/` 下旧文档不作权威依据。

# 快捷键系统与自定义配置

> 实现时对应 [Editor.tsx](../../src/pages/Editor.tsx)、[Toolbar.tsx](../../src/components/Toolbar.tsx)、[FinalVirtualCanvas.tsx](../../src/components/FinalVirtualCanvas.tsx)（见文末【实现映射】）。现状：快捷键硬编码于 `Editor.tsx` 的 `onKeyDown`（Ctrl+C/X/V/Z/Y/A/M/D + Delete/Backspace），本次按新规则重建，**废弃旧键位**。

## 1. 概念

- **具体功能（Function）**：一个可被快捷键触发的**具体操作**，如「切换-单键」「执行-单键」「撤销」。每个具体功能有唯一 id（`functionId`）。
  - **切换（switch）**：裸键（如 `F`），用于**切换工具态**。id 以 `switch` 开头。
  - **执行（exec）**：`Ctrl+组合`（如 `Ctrl+F`），用于**立即执行**。id 以 `exec` 开头；`undo/redo/play` 亦属执行类。
- **单键绑定**：每个**具体功能**恰好绑定**一个**按键组合（"1 功能 1 键"）。「切换-单键」与「执行-单键」是两个独立功能、各绑 1 键。
- **一键不多功能**：同一按键组合**不得**绑定到多个具体功能（冲突，改键时拒绝）。
- **类别（category）**：用于展示分组，把某类别的「切换/执行」合并成一行 tooltip（如「单键：切换 F / 执行 Ctrl+F」）。

## 2. 功能目录与默认绑定

### 2.1 音符类型（放置）

| 类别 | 切换工具态 | 执行（光标处立即放置） |
| --- | --- | --- |
| 单键 | F | Ctrl+F |
| 滑键 | G | Ctrl+G |
| 技能键 | A | Ctrl+A |
| 左滑键 | S | Ctrl+S |
| 右滑键 | D | Ctrl+D |
| BPM | ` | Ctrl+` |
| 滑条 | E | Ctrl+E |

> - 执行键 = 在**当前光标位置**立即放置该类型音符（等价于"切工具后点一下"的快捷版）；光标不在画布上时忽略，不放置。
>   **2026-09-10 订正（issue 70 候选 3-a，经 ADR 变更确认）**：删除原"复用现有 `mousePosition`"的
>   实现指代——该字段已从 `UIProvider` 移除。光标规则改为：**按悬停像素结合
>   [当前视口] 用时现算**（画布 `hoverPos` → `cursorChartPos()`，经 ref 出口供 Editor 的 `Ctrl+V` 使用），
>   不缓存换算结果。原因是缓存的 beat/lane 在滚动/缩放后鼠标未移动时会失效，导致执行键落在旧拍（用户已复现）。
>   本条只修订实现载体，**放置语义本身未变**。
> - ~~BPM / 滑条为交互式放置，其「执行」键与「切换」键等价~~ **（2026-09-07 由 ADR-0008 §3 重写）**：`Ctrl+\`` = 光标处放置 BPM 线（默认沿用上一次值）→ 进入**就地编辑**；`Ctrl+E` = **有选区** → 选区组合成滑条（音符 <2 无事发生），**无选区** → 放临时端点（与鼠标两击共用 slideBuffer）。BPM 弹窗 `prompt()` 废除。

### 2.2 编辑与播放功能

| 类别 | 切换工具态 | 执行（立即作用于当前选择/光标） |
| --- | --- | --- |
| 鼠标（选择） | R | — |
| 复制 | — | Ctrl+C |
| 粘贴 | V | Ctrl+V |
| 剪切 | — | Ctrl+X |
| 删除 | T | Ctrl+T |
| 镜像 | Q | Ctrl+Q |
| 音符代码 | B | Ctrl+B |
| 撤销 | — | Ctrl+Z |
| 重做 | — | Ctrl+Y |
| 播放/暂停 | — | 空格 |

> - **撤销/重做/播放只保留执行键，不设工具态**（三者只有"执行"才有意义）。播放为**切换播放/暂停**（播放引擎尚未实现，仅保留绑定）。
> - **2026-09-08 修订（ADR-0008 六轮，issue 55）**：**复制 / 剪切摘除切换键**（C / X 不再进工具态，只留 `Ctrl+C` / `Ctrl+X` 作用于选区——连续复制无意义、连续剪切有误删风险）；**粘贴持工具态转正**（V 与工具栏按钮双向归位）。粘贴锚点语义见 [ADR-0008 §2.1](./0008-工具交互机制.md)。
> - 执行键作用于**当前持久选择**（用鼠标工具框选/Shift 建立），粘贴/撤销/重做/播放除外（作用于光标/历史/播放态）。
> - **废弃旧键位**：删除由 Ctrl+D 改为 Ctrl+T；镜像由 Ctrl+M 改为 Ctrl+Q；粘贴由 Ctrl+Y 改回 Ctrl+V；技能键执行占用 Ctrl+A（原"全选"不再占用）。
> - **2026-09-07 新增功能（ADR-0008 §7）**：「侧栏折叠/展开」toggle，可自定义；**侧栏折叠不再占用 Esc**（Esc 改为画布退出四档链：弹窗→滑条锚点→清选区→落指针）。
> - **2026-09-09 修订（issue 59 §2）**：新增**「音符代码」**——切换 `B` = 持工具态（点谁看谁，弹窗关闭后态驻留），执行 `Ctrl+B` = 打开**光标处**音符的代码（不切工具）。`Ctrl+B` 原属「侧栏折叠/展开」，**让出后改默认 `Ctrl+Shift+B`**（ADR-0008 §7 同步）。

## 3. 交互模型

> **本节已被 [ADR-0008 工具交互机制](./0008-工具交互机制.md)（2026-09-07）取代**，保留作历史。仍有效的两条款：编辑动作"点击音符=选中并执行"（Model A，进 ADR-0008 单击矩阵）与"粘贴作用于位置"。**§3.2"多选后统一操作须回鼠标工具（R）"的取舍作废**——任意持工具态下可直接框选并批量应用。

### 3.1 音符类型工具态（放置）

- 按工具键（F/G/A/S/D）切换到对应放置工具。
- 之后在画布**点击**放置该类型音符（走既有 `handleNoteReplacement` 覆盖规则，见 ADR-0001）。

### 3.2 编辑功能工具态（Model A：点击即执行）

复制 / 剪切 / 删除 / 镜像 / 粘贴 均设有工具态（粘贴除外语义见 3.3）：

- 按工具键（C/X/T/Q）切换到该**工具态**。
- 在工具态下**点击某音符 = 立即选中它并对其执行该操作**（每次点击一次性作用于该音符，可连续点击不同音符分别执行）。
- 工具态下的点击**不叠加**到旧选择上，每次都重新锁定当前点击的目标。
- 需要多选后统一操作时，回鼠标工具（R）用框选/Shift 建立选择，再用**执行键**（Ctrl+C 等）作用于整组。
- **取舍**：工具态下左键不再是"纯选择"，回到选择需按 R（用户已接受）。

### 3.3 粘贴工具态（作用于位置）

> **本节锚点语义已被 [ADR-0008 §2.1](./0008-工具交互机制.md)（2026-09-08 六轮）取代为权威**：锚点 = 包围盒左上角对齐光标、BPM/System 不参与锚点、光标不在画布 = 无事发生、粘贴后驻留（连续粘贴）。以下保留作历史。

粘贴作用于"位置"而非"音符"：

- 粘贴工具态下，**点击画布某位置 = 在该位置粘贴剪贴板内容**（复用 `shiftGroupToAnchor` 锚定逻辑）。
- 执行键 Ctrl+V = 在当前光标位置粘贴。

## 4. 预览（Preview）

工具态下、且**未真正执行**时，光标在谱面内显示**低透明度幽灵**，告知操作结果。点击才执行（点击不触发预览）。

> **幽灵外观（Q2/Q4/Q5 定案）**：所有预览幽灵均用**真实音符图标**（非占位圆圈），以较低透明度绘制。
> - 放置幽灵：显示该类型音符的实际图标；**方向键默认 length=1**。
> - 粘贴 / 镜像幽灵：**保留源音符原本外观**（方向键保留其 length 变体、滑条保留连接带与结点图标）。

| 场景 | 预览内容 |
| --- | --- |
| 音符放置工具态（F/G/A/S/D） | 光标处显示该类型音符的**放置幽灵**（真实图标） |
| 滑条工具态 · 悬停（未挂锚点） | 光标吸附位显示**滑条端点音符的幽灵**（与成条后端点同一枚 sprite，issue 65④） |
| 滑条工具态 · 悬停（已挂锚点） | 端点幽灵 **+** 锚点→当前落点之间的**连接带（段）幽灵**，实时预览即将成形的绿条形态（含斜向段）。落点与锚点**同拍**（同位或横向段，ADR-0001 §2 两击禁令）→ **不画带子**，只画端点，与第二击的实际裁决一致（issue 65④） |
| 粘贴工具态 | 光标处显示剪贴板组的**幽灵**（锚定逻辑，保留原样） |
| 镜像工具态 · 悬停 | 仅预览**单个键**；滑条无法预览连接区域，**中间结点视作普通单键**预览（真实单键图标） |
| 镜像工具态 · 框选（按下未松手） | 预览所选音符的**镜像结果**，**包含滑条连接区域**（镜像会翻转 lane，连接带是最大可见变化，批量预览必须呈现以免误导） |
| 复制 / 剪切 / 删除 | **无预览** |

> 判定：镜像框选预览**包含**滑条连接区域；悬停预览为轻量单键幽灵。
>
> **滑条幽灵的结点选款 = 画布实绘同款**（issue 65①）：端点用端帽款、中间结点用 among 款，
> `flick`/`skill` 覆盖照旧；实绘 / 选中描边 / 拖拽与镜像幽灵 / 待连接锚点四处共用同一份选款函数。

## 5. 自定义配置与持久化

- **可改范围**：本系统全部具体功能（2.1 / 2.2）的键位均可自定义。
- **单键约束**：每个具体功能恰好一个键；改键时若该组合已被其它功能占用则**拒绝并提示**。
- **屏蔽**：每个功能可**屏蔽其快捷键**（配置值置 `null`，即不绑定、不触发）；屏蔽项在 tooltip 与面板中显示为"已屏蔽"，重新启用恢复默认绑定。
- **持久化**：写入 **localStorage**（模块化封装为统一读写接口，便于未来切换为 Electron `userData` JSON 文件后端）。
- **配置 UI**：提供**设置面板**，按具体功能编辑单键（支持**按功能名部分匹配搜索**、即时冲突提示、恢复默认）。修改键位时**点击键位块弹出独立记录弹窗**（类 VSCode）——弹窗内提示"先按所需的组合键，再按 enter 键"，捕获用户按键组合，Enter 确认、Esc 取消；记录态下编辑器全局快捷键放行（`isCapturingShortcut` 标志），避免误触发。展示统一大写（不区分大小写）。
- **导出/导入**：可选将配置导出/导入为 JSON，便于迁移与分享。
- **Tooltip**：工具栏按钮悬停提示动态读取**当前配置**，按类别合并「切换/执行」键位（键位以 `Ctrl+F`/`Space` 形式展示）。
- **产品形态**：桌面软件（Electron，`package.json` 已配 dmg/nsis/AppImage）；网页版仅作开发/预览。打包后 Electron 内 origin 稳定，localStorage 会持久化到 userData，真实用户可用。

## 6. 作用域

- 快捷键仅在**画布上下文**生效；焦点在 `INPUT` / `TEXTAREA` / `SELECT` / contentEditable 时**放行原生行为**（保持现有 `Editor.onKeyDown` 判定）。
- 画布内 Ctrl+C/V/X 等拦截并执行编辑操作（非浏览器原生剪贴板文本复制）。
