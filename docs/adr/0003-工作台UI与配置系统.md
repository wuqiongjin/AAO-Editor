# ADR-0003: 工作台化 UI 与配置系统

- **状态**：Accepted（定案于 grill-with-docs，2026-08-09）
- **背景**：编辑器 UI 现状为"假 Tailwind className（无真实 CSS 支持）+ 内联 style + 硬编码色值"三混；整体布局为固定像素（左 470 + 右 300 + 画布 750 ≈ 1528px，窄屏溢出，见 issue 12）；无主题系统；仅有快捷键一项配置持久化；入口存在多余的上传页面；Electron/preload 为空壳；状态全部提升在 `Editor`。经多轮与用户对齐，确定工作台 UI 的形态、主题/布局/配置体系与架构演进方向。**本次仅定案设计，不实现。**
- **结论**：见本文件全文。
- **变更触发**：任何与主题/布局/配置/入口流程相关的行为与本文件冲突时，须先更新本文件并经用户确认。
- **关联**：与 [ADR-0002 快捷键与自定义配置](./0002-快捷键系统与自定义配置.md)（配置数据模型出处）配套；issue [12 布局自适应](../../.scratch/basic-editor/issues/12-编辑器布局自适应.md)、[04 Electron 文件持久化](../../.scratch/basic-editor/issues/04-Electron文件持久化与导出.md)、[10 密集音符性能优化](../../.scratch/basic-editor/issues/10-密集音符性能优化.md)、[14 音频播放与预览线实现](../../.scratch/basic-editor/issues/14-音频播放与预览线实现.md) 为后续实现载体。

# 工作台 UI 与配置系统

## 1. 里程碑定位与目标任务

本 ADR 只定"界面与配置"这一**第二轮里程碑**的设计。第一轮（编辑功能、替换规则、快捷键）已由 ADR-0001/0002 + 既有实现完成。本 ADR **不把**谱面编辑功能本身重写，只改造界面壳与配置体系。

## 2. 入口流程（Q1 定案）

- **取消独立上传页**：`App → SongUploader → Editor` 的三段流程改为 `App → Editor` 直达工作台（删除 `SongUploader` 组件与 `inEditor`/`onBack` 入口状态机）。
- **加载音频**降级为工作台内的一次可选操作：作为**独立音频面板/页面**（工作台内以页面/Tab 切换访问），承载**导入 / 换 / 清除**音频与无音频时长编辑；无音频状态可正常编辑，无音频时播放相关控件禁用或隐藏。
- 保留"无歌曲模式"，即无音频是常态而非特例。
- **页面管理方向**：工作台/音频等以"页面/Tab 切换"组织，避免单页堆砌；完整页面 Tab 架构（工作台/音频/设置/快捷键/多工作区）交由 issue `28` 单独 grill 与实现，issue `27` 先引入最简页面切换底层铺路。

## 3. 布局（Q4 定案）

### 3.1 目标平台与适配基准

- **平台矩阵**：Electron win/mac/linux + 浏览器（网页仅作开发/预览）。移动端 **OOS**（与 map 一致，但弹性布局不堵死未来移植）。
- **适配下限**：1280px 宽屏 + 浏览器 100%–200% 缩放 + Windows 125%/150% 显示缩放下不横向溢出；Electron 窗口最小 800×600。
- **本 ADR 立**：不再用固定像素总和约束总宽（旧的 1528px 布局被废弃）。

### 3.2 灵活度分级（Q4 定案）

- **L1 折叠与自适应（本期必做）**：
  - 左右面板可折叠/展开（侧栏收进），折叠状态写入配置。
  - 画布矩形随可用空间自适应：画布宽度不再固定 `CANVAS_WIDTH=750`，改为占满中间可用区（仍保虚拟坐标模型；渲染 scale 由画布换算，见 issue 11 坐标模型）。
- **L2 布局预设（本期做）**：把当前 面板宽度/折叠态/缩放 存为一次**命名快照**，可恢复；存储进 settings JSON（§5）。**约定**：预设只存"布局窗口"信息，不存音轨数据。
- **L3 面板自由停靠/浮动（dock 式）**：本期**不做**；两点约束——不引第三方 dock 库；志愿者暂时让现场实现，真正做到 L3 必须在 §3.1 弹性基底之上。

> 淘汰：现有"拖拽分隔条"宽度改为跟随视口比例化（`min/max` 约束用百分比而非固定像素）。

## 4. 样式体系（Q2 定案）

- **技术载体**：**CSS variables 设计令牌（design tokens）**，不引入 Tailwind/CSS Modules 等框架。项目至今仍为"零运行时样式依赖"。
- **令牌范围**：颜色（底色/文字/边框/主色/危险色/边缘色）+ 间距 scale + 圆角 + 字号 + 阴影 z-index。全部含 `var(--...)` 命名。
- **迁移方式**：渐进替换——先替换全局高硬编码色与面板底色；内联 style 引用 token 变量；不一次性大重写。
- **废弃**：现有 Tailwind 风格 className（`"h-full flex flex-col bg-white"` 等无 CSS 支撑的假类）；index.css/App.css 的 Vite 模板残留清理。

## 5. 主题系统（Q3 定案）

- **内置主题**：亮/暗两套；
- **注册机制**：token 全集与主题注册表（更多主题=向注册表加一套 token 覆盖，为皮肤留接口），但本期**不做皮肤库/主题包**。
- **切换**：默认跟随系统（`prefers-color-scheme`）+ 手动三选（亮/暗/跟随系统）。
- **边界**（重要）：**谱面画布始终固定深色**（音符对比度与可见性优先），主题只作用于面板/工具栏/弹窗等 chrome；画布背景不随主题变化。

## 6. 配置系统（Q5 定案）

- **统一设置对象**：把 快捷键（ADR-0002 已有）+ 主题 + 布局（宽/折叠/预设） 合并为一个 **versioned `settings` JSON**：

```ts
interface Settings {
  schemaVersion: 1;
  theme: 'light' | 'dark' | 'system';
  layout: {
    leftPanel: { width: number; collapsed: boolean };
    rightPanel: { width: number; collapsed: boolean };
    presets: Array<{ name: string; leftPanel: …; rightPanel: …; zoom: number }>;
  };
  shortcuts: Record<FunctionId, string | null>; // ADR-0002 现有结构
}
```

- **持久化**：localStorage（统一读写接口封装，将来可切到 Electron `userData` JSON 后端）。
- **导入/导出**：复用 SettingsPanel 现有"导出/导入 JSON"流程，从"仅快捷键"扩展为"全部配置"。
- key 命名沿用 `bangdream.*` 前缀；冲突/schema 损坏时回退默认再合并（沿用 ADR-0002 loadConfig 的合并策略）。

## 7. 状态管理（Q6a 定案）

- **Context 分域**，零新依赖：
  1. `EditingContext`：notes / history / selection / clipboard（数据与编辑）；
  2. `UIContext`：面板宽/折叠、缩放、工具态显示、正在编辑日志；
  3. `ConfigContext`：settings token + 导入导出的配置。
- Editor 只保留**组装**职责（挂 Provider；编排 edit/UI/配置流的调用），不再堆全部编辑状态。
- 将来如需要再轻量 store（zustand 等），仅替换 Context 层即可。

## 8. 技术架构现状与演进路线（Q6 定案）

### 8.1 现状（事实）

- Electron：`main.cjs` **无 `ipcMain.handle`**、preload 只有 platform/versions → 文件读写/保存/IPC 完全没接通（ticket 04 架构已定案但未实现）。
- 渲染：`FinalVirtualCanvas` rAF + **全量重绘** + 视口剔除，无离屏/增量（ticket 10 性能优化 pending）。
- 配置：仅 ShortcutConfig localStorage。
- 入口：`App(SongUploader) → Editor(song)`，song 经 Editor 后并未被消费（音频绑定未实现，ticket 14）。

### 8.2 演进路线（本期不实现，仅登记）

1. **12 布局自适应** → 按本 ADR §3 执行（L1 + L2）。
2. **10 密集音符性能** → 视口剔除已有，聚焦增量/离屏；渲染重构须复用 issue 11 已定案的坐标模型。
3. **04 Electron 文件持久化** → 实现 IPC（preload expose → main ipcMain.handle + dialog + fs）；settings 后端可选切 `userData`。
4. **14 音频播放与预览线** → 按 ticket 03 架构实施（AudioContext + decodeAudioData + RAF 预览线）。
5. 以上各自以 issue 为载体推进，本 ADR 只锁定 UI/配置/状态设计。

## 9. AI 辅助采音（Q7 定案）

- 保持状态：map "Not yet specified"/OOS 一句愿景；**本期不做任何设计/接口/占位代码**。
- 未来接入时，谱面代码 JSON 的已稳定双向转换（`ChartConverter`）天然作为 AI 输入/输出通道，届时重构，无需现在预埋。

## 11. 【issue 22 增补：布局信息架构与交互模型定稿】（2026-08-16）

> 承接 §3/§5/§7 的视觉基底（commit `3fc0f29`），对"布局合理性/操作便捷/按钮交互/舒服"做深度 grill 后的**定稿**。保留 tokens.css/theme.ts 视觉令牌层，只重排布局与统一交互。变更触发：任何与下述工作台布局/交互相关行为冲突时，先更新本节并经用户确认。

### 11.1 信息架构归位（单一职责）

- **播放**：全部播放类控件收敛到底部**播放条**（ADR-0004 §5）；**移除工具栏内"播放"区块**，消除双播放入口。
- **工具选择**：左侧面板"键型工具"（鼠标 + 8 键型）用**紧凑 3 列网格**（选中态/完整 tooltip），替代原长列表；高频操作置顶。
- **参数**：节拍吸附（`beatDisplay`）留在左侧"节拍吸附"select。
- **画布小工具（缩放）**：自左侧移入**画布顶栏右侧**（紧凑 +/− 与百分比），靠近用户视线；保留 Ctrl+滚轮快捷键；**双击百分比复原 100%**。
- **右侧面板**：删除原底部"谱面"死 footer；音符总数并入右侧面板头部（**去"共"前缀的底色徽标**），正文显示"已选中 n 个音符"。

### 11.2 顶栏实时信息区（画布顶栏右侧聚集）

- 顶栏左侧：`谱面画布` 标题（不显示工具徽标——工具栏已有选中态，冗余，final 移除）。
- 顶栏右侧（自左向右）：**当前播放线所在区间 BPM** + **缩放控件**（双击 % 复原 100%）。
- 起点标记提示（ADR-0004 §4）**迁往右栏底部 tip footer**（非顶栏）。
- 去除原顶栏的"HP 首 BPM/节拍文本"（与左侧参数/画布叠加去重）。

### 11.3 画布信息叠加层（常显，不拦截交互）

- **判定线 = 画布底边**（ADR-0004 §1），故信息叠加绝对定位贴底、`pointerEvents:none`、zIndex 高于 canvas。
- **左下角**：当前判定线**精确时间**（`mm:ss.s`，0.1s 精度，mono/tabular）。
- **右下角**：**已过判定线的可打击音符数**（`countNotesUpToBeat` 纯函数，口径见工具注释；不含总数——总数据右侧信息面板）。
- 常显（含暂停/停止），不随主题变化（画布固定深色）。

### 11.4 播放条改造（进度条 + 音量）

- **可拖拽进度条**：点击/拖动即 seek（`onSeek`→引擎定位）；**暂停/停止时设播放起点不自动播**，播放中 seek 后由 RAF 继续跟随（与 ADR-0004 §3 滚动=设起点一致）。**seek 后画布同步滚动到判定线处**（暂停时亦生效）。
- 进度条时间码用**0.1s 精度**（`formatTimePrecise`），与右侧总时长紧邻成组；**无音频时双击时间码原地编辑**（`mm:ss`/`mm:ss.s` → seek，替代原"时长"输入框，final）。
- **移除键音素材选择**（迁往未来 tab，issue 29 跟踪）；起点标记提示迁右栏底部（§11.2）。

### 11.5 按钮交互统一

- 新增统一 `IconButton`（hover/pressed scale/active/disabled/danger/outlined + focus-visible 焦点环），全站按钮收敛到它。
- 废弃 Editor 内联 `inlineIconBtn`/`railBtn`、PlayBar `onMouseEnter` 手写态等并存写法。

### 11.6 布局持久化（折叠/宽度回写 settings）

- 折叠态 + 面板宽度**持久化到 `settings.layout`**（ADR-0003 §6 字段级写回）；挂载时初始化、变更回写。
- `ConfigContext` 新增 `setLayout`（`useCallback` 保持引用稳定，避免持久化 effect 无限重渲染）。

### 11.7 final 交互细化（issue 22 收尾复现驱动）

- **编辑功能 2 列网格**：复制/剪切/粘贴/删除/镜像/撤销/还原 7 项 2 列排布，"谱面代码"铺满整行（非工具栏选中态冗余）。
- **折叠 rail 按钮对齐头部带**：两侧折叠窄轨的展开按钮置于 `--panel-header-h` 头部带内水平居中，与折叠前的面板头部按钮保持同一垂直位置（不再贴 rail 顶）。
- **时间码双击编辑**：见 §11.4（无音频时，替代"时长"输入框；有音频禁用）。

### 11.8 未作/边界

- L3 自由停靠/浮动（§3.2）仍不做。
- 工具栏保留 编辑(E) 分组（复制/剪切/粘贴/删除/镜像/撤销/重做 + 谱面代码弹窗）。
- 新增纯逻辑（`countNotesUpToBeat`、`formatTimePrecise/Whole`）可单测；本次新增 `tests/unit/NotePlayheadStats.test.ts`。
