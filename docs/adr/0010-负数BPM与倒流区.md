# ADR-0010: 负数 BPM 与倒流区

- **状态**：Accepted（定案于 grill-with-docs，2026-09-14 ~ 09-15，issue 100 多轮；本文件已按各轮结论回改，无残留待定项；**2026-09-15 按 issue 106 定案回改**：§9 例外句、术语表「非法结点」行、备注首条——实机口径由「忽略非单调中间结点」更正为「按 beat 稳定排序 + 掐首尾 hidden」，非单调点序改由**显示投影**处理（数据原样保留、画布按实机口径））
- **背景**：Bestdori 谱面代码允许 `bpm < 0`——制谱器不 ban，社区用它把滑条/曲线"往回画"（爱心、滑条折返等；社区帖 102178「Minus BPM can inverse the slides backward」）。本仓库 `validateChartCode` 一直以 `bpm > 0` 拒绝，导致这类已上传的社区谱**打不开**。issue 09 曾把该议题切出（见 ADR-0009 范围切片句），本文件给出定案。
- **关键事实**（实测所得，非推测）
  - **时间轴 = 带符号累加**：`t(beat) = Σ Δbeat × 60/bpm`，负 BPM 段的秒**倒扣**。证据：社区谱 150030「Retribution ~ Cycle of Redemption ~」（Ardolf vs. 天利，diff=4/level=35）自带音频实测 **173.376s**；同一份谱面代码的末音符（beat 1160）在带符号累加下 = **172.80s**（正好落在歌曲结束前 0.58s），按 `|bpm|` 累加 = 309.33s（远超歌曲，不可能）。**该谱的 BPM 事件序列完整留档于本文件**附录 A**（谱面文件本身不入库）。**
  - **播放时钟单调**：判定线不动、谱面正向播放、**没有"倒流演出"**；秒读数只由时钟驱动。
  - **所有音符一视同仁**（用户实机复核，收回先前"非 Slide 音符不受影响"的观测）：倒流区内**所有**元素（含 Single）都按自己的时间落在画布上，因此都会折返。
  - **倒流区内可击打元素 = 实机不可完成**：段内非 hidden 的滑条结点游玩 **100% MISS**（不可能完成的操作）。Bestdori 不拦（可存、可渲染），我们也不拦。
  - **`bpm = 0` 无意义**：Bestdori 可保存，但预览无限加载、游戏内 0 之后为空白。
  - **谱面以负 BPM 收尾会让 Bestdori OUT_OF_MEMORY 崩溃**：可连续多条负 BPM，但后面**必须**出现正 BPM。
- **结论**
  1. **放行 `bpm < 0`**（目标 = 对齐 Bestdori 能力，能打开并保真往返这类社区谱）。
  2. **倒流区（Backflow region）= 从一条 `bpm < 0` 的 BPM 事件起到「下一条 `bpm > 0` 的事件」为止的区间**（其间可含多条连续负值事件）。
  3. **时间轴 = beat 经 BPM 事件带符号累加得到的秒**，倒流区内随 beat 回退；**播放时钟 = 单调秒**，驱动判定线/滚动/音频。两者同量纲，但后者只增不减。
  4. **画布布局轴 = 时间轴**（沿用 ADR-0005 §7）。因此**画布高度 = 谱面长度（秒）× 像素密度，直接由秒得出，不经过拍反查**。
  5. **「秒 → 拍」在倒流区内是多值**：只允许在语义确实需要"拍"的地方（拍号显示、放置基准）使用，取值规则 = **取「最大 beat 解」**（时间轴上最后一个经过该值的段）——**与 Bestdori 编辑器逐操作等价**（用户实测：点倒流带 → 落到区后的拍）。作用域仅限「光标 → 拍」的**空白处新增**；**既有音符始终待在自己的层**（beat 是数据，不随光标所在层变化）；**拖拽的 Δy→Δ拍 换算锚定被拖元素自己所在的层**。几何、滚动、命中、瓦片失效一律走「拍 → 秒」正向，不得依赖该反查。**不做层切换 UI**。
  6. **倒流区内的可击打元素：不拒绝也不拦**（与 Bestdori 一致），但编辑器**不承诺实机可完成**；不为此新增放置限制。
  7. **校验边界**：`bpm = 0`（含 `-0`）、非有限数 → 拒；**beat 0 处为负 → 拒**；**末条 BPM 事件必须 `> 0` → 拒**（否则 Bestdori OOM）。负值**不设下限**。
  8. **编辑器内可创建负 BPM**：就地编辑框接受**负值与小数**（issue 143：Bestdori 的 `bpm` 是任意有限数，导入/导出两侧一直原样放行，手工输入不得截断）；`0` / `-0` / 非数字 / 非有限数 = 无效、取消编辑。放置工具**沿用上一次的值，但负值不进这个"上次值"**（issue 145：否则下次点 BPM 工具默认就是负数，一次手抖即误造倒流区）。
  9. **往返保真**：负值原样写出、不取绝对值、不 clamp、不归一化；同一 beat 多条 BPM 全部保留；导出排序改为**稳定排序**（同 beat 保持输入顺序，否则"导入 → 导出"会凭空产生 diff）。**例外**：滑条中 beat 非单调的点序**代码原样保留、只在画布上按实机口径投影显示**（带子取点 = 按 beat 稳定排序 + 掐首尾 hidden，不改数据、导出仍是原字节；可见结点 1 → 按单键显示、0 → 画布无效果（数据保留），口径见 ADR-0009 §2.2）——保真的参照系是 **Bestdori 语义**而非字节：实机**不是「忽略」这些结点**，而是排序后按时间轴铺带（带子永不回头、非单调只表现为横向折线；图证见备注）。
  10. **谱面长度不被倒流区改变**（仍是音频时长 / 无音频时手填秒数）。
  11. **视觉**：负值 BPM 的数值**改用另一种颜色**标识；不做区域底纹。
- **三个「回头」不是一回事（术语澄清，2026-09-15——混用会得出相反的结论）**

| 规范术语 | 俗称 | 是什么 | 规则 |
| --- | --- | --- | --- |
| **非单调点序** | 点序回头 / 点序回折 | 滑条 `connections` 里后一个结点的 beat 小于前一个 | **禁止产出**（画笔禁止回头，见下条）；**代码原样保留、画布按实机口径投影显示**——带子取点 = 按 beat 稳定排序 + 掐掉首尾 hidden（数据不动、导出原字节；可见结点 1 → 按单键显示、0 → 画布无效果）。实机口径：带子沿时间轴单向、**永不回头**，非单调点序只表现为横向折线（备注首条有像素实测）；谱面状态图标（三态明细）、报错区搬迁与「规范化」动作同在 issue 107。见 ADR-0009 §2.2 / issue 106 |
| **滑条折返** | 带子回头弯 | 滑条带在**画布上**先往上走、再往下走 | **允许**，且**只能**由倒流区造成——没有倒流区就永远画不出来（beat 单调 + y 随 beat 单调 ⇒ y 必然单调） |
| **绘制笔迹折返** | 手回头 | 绘制过程中手的方向反转（上划一段再下划一段） | **产出禁止**：折返期间**不追加采样点**；**交互不中断**：笔画不断，且**回头不改变产出**——落子终点取「松手吸附拍位」与「锁定方向上最远采样点」中更靠前者，预览冻结在最远点、不画折返（ADR-0009 §7）。即"手可以随便动，产出不受影响"。**注意与"跨层"区分**：光标跨过折返带边界时拍号会跳，但 beat **方向未变**，此时**直接接续**（不补中间点），见 issue 106 修法 6 |

- **与 Bestdori 的等价性（2026-09-15 定）**：取解 = 「**最大 beat 解**」= Bestdori 编辑器实测行为，故**逐操作等价**。
  - 导入 / 渲染 / 播放 / 导出 / 实机表现本来就零差异——这些链路都不经过「y → 拍」反查（beat 是数据；渲染走「拍 → 秒」正向）。**同一个 beat 序列，两边画布位置与判定时间必然一致**；不存在"我们的谱导入到 Bestdori 表现不同"。
  - 同为「在空白处新增」，同一个 y 写进代码的 beat 与 Bestdori **相同**。
  - 已知代价（接受）：落在折返带内的那些"**倒流区之前**"的拍（例中 beat 3.5–5）**无法用点击新增**——要放它们就回到「先画后折」的正路（先放音符、后插 BPM），**与 Bestdori 一致**。
  - 曾考虑「取与上一帧光标拍号最近的那一解」（光标不跳、上述那段可点），2026-09-15 因"与 Bestdori 逐操作等价"优先而**否决**。
- **折返的标准姿势 = 先画后折**：在**没有**倒流区时，先画一条**跨过目标拍的普通滑条**（画笔正常等步长采样、beat 单调），**然后**插一对 BPM 事件（中间那条为负、末条必须为正）→ 已画的点被折回去，回头弯出现。这与"倒流区生效那一刻区内音符反转"是同一件事，也是 `150030` 倒流区内 **0 个手放点**的原因——**不需要往里画**。倒流区**已存在**时想往区里补点，走「跨区段 + 烘焙/模板」通道（见备注）。
- **考虑过但否决的方案**
  - **拒绝（维持 `bpm > 0`）**：打不开任何用负 BPM 的社区谱。用户明确要求对齐 Bestdori、必须兼容。
  - **收下但按 `|bpm|` 归一化解释**：能存能读，但画布与实机不一致（该折返处不折返），照着改必然出错谱；且与歌曲长度证据直接矛盾。
  - **「只有滑条折返、音符不受影响」**：一度由用户观测支持，后经实机复核 + 音频长度证据推翻。
- **后果 / 影响面**
  - **正向链路本来就正确**：`perBeatValue = BEAT_HEIGHT·verticalRatio·120/bpm` 与 `60/bpm` 都带符号，负 BPM 下自动折返，与 Bestdori「`pixel = 时间 × pps`」同构。**渲染的正向映射不需要重写。**
  - 需要处理的是**反查与单调假设**：`BpmTimeline.beatOfPosition`（L77-95 二分假设 offsets 单调）、`AudioTiming.secondsToBeat` / `chartLengthToEndBeat` / `maxNoteEndSeconds`、`ChartGeometry.chartEndVirtualY`（L97）与 `virtualYToBeat`（L141-143）、`render.ts visibleBeatRange`（L112-117）与 hover 秒读数（L1306-1307）、`noteLayerCache.invalidateTilesForBeatRange`（L169-177，L163 注释明写「pos 随 beat 递增」）、`PlaybackScrollModel`（L72-85）、`Editor.currentRegionBpm`、`FinalVirtualCanvas.playheadBeat`。
  - 落地拆票：issue 103（校验与编辑入口）/ 104（时间轴与几何）/ 105（渲染与视觉）/ 106（画笔点序回折废止 + 折返产图通道 + 跨层接续）。
- **备注**
  - **折返只有一条合法来路：倒流区。** **2026-09-15 更正机理（issue 106）**：Bestdori 对非单调点序做的**不是「忽略中间结点」**，而是「**按 beat 稳定排序 + 掐掉首尾 hidden**」后**按时间轴铺带**——带子**永不走回头**，落到排序首/尾之外的结点被裁掉（看起来像「被忽略」），夹在中间的则表现为**横向折线/跳步**（像素实测：4 点判定实验的折点落在 bbox 25% / 50% 高度，与排序模型逐点吻合）。仓内 11 份样本 ≈1943 条 Slide/Long 非单调点序 **0 例**、`150030` 的 232 条滑条全部单调（折返纯粹来自负 BPM）仍然成立。ADR-0009 §2.2「段内中间点 beat 可倒退」据此废止；我们的口径 = 画笔**禁止回头**（不产出）+ 画布**显示投影**（数据原样保留），落地见 issue 106。
  - 因此本编辑器里"把滑条画成回头弯"的正路 = **先画平铺滑条、再插一对 BPM 事件把它折回去**（倒流区**已存在**时改用「跨区段 + 烘焙/模板」——一条跨过倒流区的段，烘焙点按拍细分后天然呈现「正向 → 折返 → 正向」，beat 严格单调、实机保真）。**手工往折返带里描线不作为产图通道**：倒流区已存在时，笔写进去的拍只会落在倒流区之前/之后那两层（取解规则），带子必然平——"回头"在这里天然不存在，**无需额外禁止**；见 issue 106 修法 5/6。负 BPM 的收益因此不只是"能打开别人的谱"。
  - **画笔跨层是允许的**：手穿过折返带时拍号会跳 2~4 拍，但两端在画布上几乎同一个 y——**几何本来就连续**，只需"跳变步直接接续、不补中间点"（不挡的话会补出几十个手没画过的点，画布上凭空多一段尖峰）。跨层绘制与 Bestdori 一致，见 issue 106 修法 6。
  - **我们比 Bestdori 多两条校验**（beat 0 负值、末条 BPM 负值）。这是"对齐能力"而非"复刻 bug"——Bestdori 在这两处分别是无意义输入与崩溃。
- **关联**：修订 [ADR-0005 §7](./0005-显式谱面长度与谱面工程持久化.md)（「秒 → 拍 只是显示换算」在倒流区不成立）；回填 [ADR-0009 SP 绿条与段曲线模型](./0009-SP绿条与段曲线模型.md) 的范围切片句；结论 3/5 保证与 [ADR-0004 §1](./0004-播放预览交互.md)（逐帧秒→beat 驱动滚动）、[ADR-0006](./0006-画布动态渲染面与判定线贴底.md)（判定线贴底滚动）的一致性。
- **变更触发**：时间轴符号语义、倒流区定义、校验边界变动须先更新本文件并经用户确认。

## 附录 B：最小复现谱面（倒流带三层 / 取解 / 跨层 的口径示例）

```
[{"type":"BPM","bpm":120,"beat":0},
 {"type":"BPM","bpm":-120,"beat":5},
 {"type":"BPM","bpm":120,"beat":6.5}]
```

- `t(0)=0 → t(5)=2.5s → t(6.5)=1.75s`（倒流区倒扣 0.75s）→ `t(8)=2.5s`。
- **折返带** = y ∈ [1.75s, 2.5s]，同一个 y 有**三解**：`L1` beat 3.5–5（向上）／`L2` **倒流层** beat 5–6.5（**向下**）／`L3` beat 6.5–8（向上）。
- **取解 = 最大 beat 解**：用户实测在该带内点击，命中得到 `6.75 / 7.75 / 8`，而三处的候选解分别是 `{3.75, 6.25, 6.75}`、`{4.75, 5.25, 7.75}`、`{5, 5, 8}` —— 三次都取最大者，据此坐实 Bestdori 口径。
- **画笔跨层**：光标跨过 y=1.75s 时拍号 `3.49 → 6.50`（两端画布位置 ≈ 同一 y）；处置 = **直接接续、不补中间点**（见 issue 106 修法 6）。
- 折返的形状必须由 **`L2` 的拍（5–6.5）** 构成；「先画后折」与「跨区段烘焙/模板」两条通道都能产出它们，手工描线产不出（取解取不到 `L2`）。
