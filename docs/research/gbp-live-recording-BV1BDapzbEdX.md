## 3. 判定字（票 51）

**2026-10-26 重测修正：上一版「字锚在该轨中线、换轨就换位置」是错的。** 逐帧量下来，字**固定在场中央一条**，不跟轨道走：

- 每个音符过线出一次 PERFECT（这点不变）。
- 水平：白描边包围盒 **t012 x 433–590（cx 511）**、**t030 x 439–593（cx 513）**、t020 同样量级（cx ~512，受立绘白衬衫干扰）⇒ 字心 = **~0.497 W**。判定线 7 个菱形实测在 **x 149 / 269 / 387 / 507 / 625 / 744 / 863**（间距 ~119 px = 0.116 W，正中那轨 507）⇒ 字心与正中轨中线重合。字宽 **~155–167 px = 0.15–0.16 W**（两读者差在描边阈值；≈1.3 个轨宽）。
- 反证：t012 正被击中 / 按住的是 x≈395 那轨，t030 判定线上左右两轨（x≈279、x≈632）同时有命中光斑，**场上仍只有一条、且都在中线** ⇒ 不是「每轨一条」。复核另抽 13.5 / 15.2 / 18.0 / 22.0 / 26.5 / 35.0 / 40.0 s 七帧：**35.0 s 命中在最左轨、40.0 s 在最右轨，字的左缘仍在同一列**。
- 注意字上方常有一行黄色「分数提升」小标（y≈442–455），别并进判定字的包围盒。
- 垂直：判定线 y≈546（本机 720p），字包围盒 **y 466–496**（高 ~30 px = 0.042 H）⇒ **字底离判定线 ~50 px = 0.069 H，字心 ~66 px = 0.092 H**；字压在判定线上方的下落区里，不是贴在菱形上。
- 字形：粉→青渐变填充 + 白厚描边 + 外发光，圆角，像 `judgeskin` 的 `judge_perfect`，不是系统字。
- 30 fps 跟踪 29.6–30.6 s：字上沿一直停在 462–466，**没有上浮**。
- 顶栏分数 / 生命这支片有；本票不做分数。

**UNCERTAIN（720p 量不准，不写死像素）：**

- 单次字停留几帧（连续音会互相顶替，跟踪里分不干净）；淡出曲线。
- 双押 / 多押时是否有第二条字或叠影：只看到「同时两轨命中、仍只有一条字」，**没看到第二条**，但也不能排除被同位置盖住。
- 这页与票 51 第 3 轮记的「该轨正中」字面冲突（用户原话「贴合轨道正中间」可读成场地中线）。**口径要用户点一句，本文件只登记事实、不改票。**

## 4. AP Combo（票 51）

- 位置：场地**右侧**。白描边包围盒（t030，含 COMBO 小字）**x 743–915 / y 260–359** ⇒ 0.72–0.89 W × 0.36–0.50 H；t012（37 COMBO）同量级。
- 大数字 + 下面「COMBO」小字。
- AP 续航时数字是**竖向虹彩渐变 + 白描边 + 粉/青辉光**：字上沿偏洋红（采样 #a824c1 / #bb42d9）、中部近白（#fdfffb）、下沿偏青绿（#51d7ae / #5bdeb9）。不是纯白、也不是金黄斜体。
- 「COMBO」小字仍是白字 + 深色描边，不跟着虹。
- 官方 FAQ「コンボ表示の色が変わります」对得上「描边变虹」，不是另做一套计数。

Bestdori 白 `digits` 原样不够；染色能不能仿这圈虹边 → **UNCERTAIN，实现前对着 `judge` / combo 图集再看，不手画假虹标。**

## 5. 中央章（票 52）

实测窗口 **108.50–109.93**（淡入 108.50–108.73、满强度到 109.65、之后淡到 109.93）⇒ **可见 ~1.4 s、满强度 ~0.9 s**。30 fps 逐帧量（中央带饱和度 / 亮度），上一版「0.4–0.6 s」是按 0.2 s 抽帧漏看 109.4 / 109.6 造成的低估。

- 居中一条 **ALL PERFECT!** 整块 logo：圆体（粗斜体感）、厚白边、粉→青彩虹填充、末字带闪电。包围盒（109.2 那帧）**x 183–857 / y 316–436** ⇒ 宽 **0.655 W**、高 **0.168 H**、中心约 (0.505 W, 0.52 H)。字在 108.6–109.9 之间是**逐帧放大 + 淡出**，尺寸按 109.2 帧记。
- 入场是「擦入」：108.6 只露 `ALL P` + 中央星，108.8 才完整。
- 起手一颗大星压在字中（108.8 帧），外圈粉 / 湖水绿 / 紫 / 黄 / 白星点串成大圆环（108.8 直径 ≈0.45 W，环心 ≈ (0.52 W, 0.45 H)）；环继续转到字消失之后。
- 判定线 / 轨道：108.8 时还在（线在 y≈546），**109.0–109.2 淡掉**；此后只剩立绘 + 顶栏分数 / 生命。章全程是**半透明覆盖层**，不暂停游戏（下落音符、HUD 都在）。
- 字收掉后（109.9）环炸成拖尾星点飞散，三圈（黄 / 绿 / 白）余烬拖到 ~111.4 散尽；立绘全程不切黑。
- **不是** `HEADER_SANS` 斜体纯字、也不是一行文字居中，是一整块 logo 图。仓里还没撕到 PNG（见 `gbp-live-cinematic.md` §5）。

这支是 AP，**FULL COMBO 条没出现**（AP 替换 FC，和既有调研一致）。FC 章长什么样 → **UNCERTAIN，这支片没有。**

## 8. 用户补料（2026-10-26 · 高清截图 + 两个 .mov）

### 8.1 `Opening.mov`（1920×1342 / 120fps / 8.28 s；曲目其实是「ヒカリへ」）

- 版式：封面 `0.369–0.640 W × 0.156–0.543 H`（红边 8 px + 白边 4 px）；难度徽章 135×36，`0.470–0.540 W × 0.566–0.593 H`；全宽灰条 `0.620–0.710 H`（先放曲名，2.30 s 换成「目标得分」）；乐队名 `0.736–0.768 H`；credits 三行 `0.785 / 0.819 / 0.847 H`，行距 ~45 px；♫/★ 只撒在灰条上下两侧，**没有四角边框**。
- 时间线：1.00 s 卡片**硬切**出现（无缩放/滑入）；1.2 s 装饰出现；2.30 s 灰条内容切换；5.30–5.90 s 卡片收掉、压暗层抬起；5.75 s 游戏 HUD 出现；7.82 s 轨道自下推入。
- 字体：拉丁（乐队名 / EXPERT）= grotesque 带人文细节、字端平切、Semibold、标准偏窄；近 Helvetica Neue / Gotham / FOT-Rodin。日文标题 = **丸ゴシック**（笔画等宽、转折全圆、字面宽、Bold、字距 +8%）；近 ヒラギノ丸ゴ ProN / M PLUS Rounded 1c / FOT-Rodin。`HIKARIE` 小标 = Light + ~45% 字距。
